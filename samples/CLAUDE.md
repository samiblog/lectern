# 이 프로젝트의 문서 규칙 (Claude Code 용)

이 프로젝트의 문서는 사람이 **Lectern**(Windows 문서 뷰어)으로 읽는다. 문서를 쓰거나 고칠 때 아래를 따른다. 자세한 규칙은 Lectern 의 작성 안내(`web/help/writing.md` — Lectern 설정 창의 'Claude Code 에 Lectern 알려 주기'가 경로를 알려 준다)에 있다.

## 파일

- 문서는 Markdown(`.md`)으로 쓴다. 보고서처럼 모양이 중요하면 HTML 도 되지만 **스크립트는 돌지 않는다** — 차트는 HTML 의 JS 대신 Markdown 의 차트 코드 블록으로 만든다.
- 문서 첫 줄은 `# 제목` 하나. 트리('제목' 버튼)·폴더 개요·창 제목에 이 제목이 쓰인다 (frontmatter 의 `title` 이 있으면 그것).
- 순서가 있는 문서는 `01-`, `02-` 처럼 번호로 시작한다 (`2-` 가 `10-` 보다 앞에 온다).
- 첫 문단은 문서를 한두 문장으로 요약한다 — 폴더 개요의 요약이 된다. 계획·결정 문서는 frontmatter 의 `description` 으로 따로 적어도 된다.
- `.` 으로 시작하는 폴더, `node_modules`·`dist`·`build` 안의 문서는 보이지 않는다. `src/`·`web/` 같은 앱 소스 폴더의 html 은 문서로 보지 않는다.

## 쓰는 법

- 제목 단계(`##` → `###`)를 건너뛰지 않는다. 오른쪽 목차·절 접기·장 하이라이트가 이것으로 나뉜다.
- 표의 칸에는 숫자만, 단위는 머리행에 (`가격 (USD/t)`). 숫자 열은 저절로 오른쪽 정렬된다.
- 강조할 말은 박스글: `> [!NOTE]`·`> [!TIP]`·`> [!IMPORTANT]`·`> [!WARNING]`·`> [!CAUTION]`.
- 코드 위치는 `src/report.py:14` 처럼 적는다 — 누르면 그 줄로 간다 (코드 블록 안에서는 링크가 되지 않는다).
- 그림·다른 문서는 이 문서 기준 상대경로로 링크한다. 절 링크는 `문서.md#제목-글자`.
- 다이어그램은 ```` ```mermaid ````, 차트는 ```` ```vega-lite ````·```` ```echarts ````·```` ```plotly ````·```` ```dot ```` 코드 블록.
  - 설정은 JSON 값만 쓴다 — 함수(`formatter: function…`)는 안 된다.
  - 데이터는 문서 안에 적거나, 프로젝트 안의 CSV·JSON 을 문서 기준 상대경로로 가리킨다 (Vega-Lite 의 `data.url`). 인터넷 주소의 데이터·그림은 읽지 않는다.
  - 문서 폭에 맞추려면 Vega-Lite 는 `"width": "container"`, ECharts 는 `"height"` 만, Plotly 는 `layout.height` 만 적는다.
- 발표 자료는 Marp 형식으로 쓴다: 맨 앞 설정에 `marp: true`, 슬라이드는 `---` 로 나눈다. 한 장에 제목 하나와 짧은 글머리표 대여섯 줄 — 넘치면 아래가 잘린다 (그림·다이어그램·차트는 줄여 맞춘다). 발표자 노트는 `<!-- … -->`, 쪽 번호는 `paginate: true`.
- 수식은 `$…$`·`$$…$$`. `$105` 같은 달러 금액은 그대로 둔다 (닫는 `$` 앞이 빈칸이면 수식이 아니다).

## 이 프로젝트

- `src/collect.py` 가 `data/월별-가격.csv` 에 월평균 가격을 덧붙이고, `src/report.py` 가 요약 문장을 만든다.
- 리서치 문서는 `research/`, 계획은 `plans/`, 보고서는 `reports/` 에 둔다.
- 숫자를 바꾸면 리서치 문서의 표와 보고서의 숫자를 함께 맞춘다.

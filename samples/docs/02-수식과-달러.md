### 코드 블록에 쓴 수식

Claude 는 식을 코드 블록에 쓰기도 합니다. `math`·`latex`·`tex` 코드 블록은 수식으로 그립니다.

```latex
\ln Z_t = r_0 + r_1 \ln X_t
```

LaTeX 문서 원문처럼 수식으로 읽을 수 없는 블록은 코드 그대로 둡니다.

```latex
\documentclass{article}
\begin{document}
\section{서론}
\end{document}
```

## 달러 표기

- 구리 가격은 $105에서 $110 사이에서 움직였다.
- 운임은 $95~$110/t 범위였다.
- 매출은 US$1.2bn, 영업이익은 $350m 이었다.
- 가격이 $5 오르면 마진은 $2 늘어난다.

위 문장의 `$` 는 금액이므로 수식으로 바뀌지 않아야 합니다. 여는 `$` 바로 뒤나 닫는 `$` 바로 앞이 공백이거나, 닫는 `$` 바로 뒤가 숫자이면 수식으로 보지 않습니다.

대괄호도 같습니다. 판독이 불확실한 곳은 \[판독 불확실\]로 표시했습니다 — 이렇게 대괄호를 글자로 쓴 `\[` 는 수식이 아닙니다. `\[…\]` 는 식이 줄을 통째로 차지할 때만 수식입니다.

수식을 쓰지 않는 프로젝트라면 설정 `math` 를 `false` 로 두면 됩니다.

# 렌더링 기능 점검

Lectern이 Markdown 문서를 어떻게 보여 주는지 한 번에 확인하는 예시 문서입니다. 표, 체크리스트, 각주, 코드, 콜아웃, 그림, 링크가 차례로 나옵니다. 절 제목을 누르면 그 절이 접히고, 다시 누르면 펼쳐집니다.

## 표

숫자가 대부분인 열은 오른쪽으로 정렬되고, 머리행은 스크롤해도 위에 붙어 있습니다. 아래 값은 모두 예시입니다.

| 품목 | 1분기 | 2분기 | 증감 | 비고 |
|---|---|---|---|---|
| 구리 | $8,950 | $9,420 | 5.3% | 재고 감소 |
| 알루미늄 | $2,310 | $2,265 | -1.9% | - |
| 니켈 | $16,800 | $17,950 | 6.8% | 인도네시아 증산 |
| 아연 | $2,640 | $2,705 | 2.5% | |
| 주석 | $31,200 | $33,900 | 8.7% | 공급 차질 |
| 철광석 | $104 | $98 | -5.8% | 단위: 톤 |

## 체크리스트와 각주

- [x] 숨김 파일과 `node_modules` 는 트리에 보이지 않는다
- [x] 숫자 열이 오른쪽으로 정렬된다
- [ ] Windows 실기 점검을 마친다

각주 번호를 누르면 문서 끝으로 가고[^1], 끝에서 ↩ 를 누르면 돌아옵니다. 출처는 보통 각주로 적습니다[^2].

## 코드

언어를 적은 코드 블록은 색으로 구분되고, 오른쪽 위 버튼으로 복사합니다. 다음 세 블록이 예시입니다.

```python
def moving_average(values: list[float], window: int = 3) -> list[float]:
    return [sum(values[i:i + window]) / window for i in range(len(values) - window + 1)]
```

```powershell
Get-ChildItem -Recurse -Filter *.md | Measure-Object | Select-Object Count
```

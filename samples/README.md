# Lectern 예제 — 여기서 시작하세요

Lectern 을 둘러보기 위한 예제 프로젝트입니다. Claude Code 와 함께 **구리 시장 리서치 자동화**를 하는 프로젝트라고 생각하고 보세요. 코드(`src/`), 자료(`data/`), 리서치 문서(`research/`), 계획(`plans/`), 보고서(`reports/`)가 있고, `guide/` 에는 Lectern 사용법이 있습니다.

> [!TIP]
> 왼쪽 트리에서 문서를 누르면 여기에 보입니다. 오른쪽 목차를 누르면 그 절로 갑니다. **F1** 은 사용설명서, **Ctrl+/** 는 단축키 표입니다.

## 이 프로젝트의 산출물

| 파일 | 무엇 |
|---|---|
| [구리 시장 동향](research/구리-시장-동향.md) | 리서치 문서 — 표, 그림, 박스글, 각주, CSV 를 읽는 차트 |
| [주간 보고서](reports/주간-보고서.html) | HTML 보고서 — 자기 스타일 그대로 보인다 (스크립트는 돌지 않는다) |
| [구현 계획](plans/구현-계획.md) | frontmatter 가 있는 계획, 흐름도 |
| [우선순위](plans/2-우선순위.md) · [후속 과제](plans/10-후속-과제.md) | 숫자로 정렬되는 파일 이름, 체크리스트 |
| `src/collect.py` · `src/report.py` | 코드 — 왼쪽 '코드' 묶음에서 한 번 누르면 읽기 화면 |
| `data/월별-가격.csv` | 자료 — 왼쪽 '자료' 묶음. 리서치 문서와 차트 문서가 이 파일을 읽는다 |

## AI(Claude Code)에게

[CLAUDE.md](CLAUDE.md) 는 Claude Code 가 이 프로젝트에서 문서를 쓸 때 따르는 규칙입니다 (영어판: [CLAUDE.en.md](CLAUDE.en.md)). 내 프로젝트에도 같은 규칙을 주려면 설정(Ctrl+,)의 **Claude Code 에 Lectern 알려 주기** → **Claude Code용 요청 복사**를 Claude Code 에 붙이세요. Claude Code 가 Lectern 의 작성 안내를 읽고 그 프로젝트의 CLAUDE.md 에 정리합니다.

> [!NOTE]
> 이 예제는 Lectern 설치 폴더에 있습니다. 고쳐도 되지만 Lectern 을 다시 설치하면 처음 모양으로 돌아갑니다. 숫자는 모두 예시입니다. 다시 열 때는 툴바 아래 탭 막대의 **∨**(최근 연 폴더) → **예제 열기**, 또는 시작 화면의 **예제 열기**.

# Lectern 슬라이드 예제

Lectern 슬라이드를 배우는 차례입니다. 위에서부터 봅니다. 쓰는 법 전체는 **F1** 사용설명서의 'Lectern 슬라이드' 장에 있습니다.

처음이면 사용법의 [Lectern 슬라이드](../guide/09-Lectern-슬라이드.md)를 먼저 읽습니다 — 이 예제들의 내용을 보통 md 문서로 자세히 적은 안내입니다 (뼈대·칸·배치·글자 크기·분량·지시어부터 고치기·발표·pptx 전환까지). 그 맨 아래에서 이 예제들로 이어집니다. 사용법 전체 차례는 [예제의 첫 문서](../README.md)에 있습니다.

> [!TIP]
> 설치한 예제는 보기만 하는 폴더입니다. 따라 만들려면 자기 프로젝트에서 **새로 만들기**(Ctrl+N)로 Lectern 슬라이드를 새로 만들거나, 이 폴더를 복사해서 엽니다.

## 2. 상황별 모범 예제

상황에 맞는 예제를 고릅니다. 완성본은 슬라이드 창에서 보고, 과정 문서는 그것을 처음부터 만든 순서를 따라갑니다.

| 상황 | 완성본 | 만드는 과정 | 배우는 것 |
|---|---|---|---|
| 임원에게 한 번에 보고한다 | [01 경영 요약](상황별/01-경영-요약.md) | [과정](상황별/과정/01-경영-요약-과정.md) | 결론 먼저, `kpi`, 결정 요청으로 끝내기 |
| 세 대안 중 고른다 | [02 대안 비교](상황별/02-대안-비교.md) | [과정](상황별/과정/02-대안-비교-과정.md) | 기준을 먼저, `three`, 강조한 표 행 |
| 자료로 시장을 설명한다 | [03 시장 분석](상황별/03-시장-분석.md) | [과정](상황별/과정/03-시장-분석-과정.md) | CSV 차트, `left-stack`, 차트를 말하는 제목 |

| 개발자에게 기술을 설명한다 | [07 기술 세미나](상황별/07-기술-세미나.md) | [과정](상황별/과정/07-기술-세미나-과정.md) | 코드 길이, 수식, 시퀀스 다이어그램 |
| 그림으로 이야기한다 | [08 사진 기록](상황별/08-사진-기록.md) | [과정](상황별/과정/08-사진-기록-과정.md) | 배경과 필터, 그림 위의 글, 점검이 못 보는 곳 |
| 한 해의 일정을 보여 준다 | [09 로드맵](상황별/09-로드맵.md) | [과정](상황별/과정/09-로드맵-과정.md) | 직접 그리는 `grid`, 의존 관계, 체크 칸 |
| 있는 md 문서를 Lectern 슬라이드로 바꾼다 | [10 문서에서 발표로](상황별/10-문서에서-발표로.md) | [과정](상황별/과정/10-문서에서-발표로-과정.md) | 메시지 고르기, 원문 줄이기, 출처 잇기 |

과정 문서는 모두 같은 일곱 단계입니다.

1. **먼저 정한다.** 듣는 사람과 그들이 결정할 것, 장 수를 정한다.
2. **Claude 에게 요청한다.** 터미널에 요청문을 넣는다. 작성 안내(`web/help/slides.md`)대로 쓰라고 한다.
3. **제목만 먼저 세운다.** 제목만 읽어도 이야기가 이어지게 한다.
4. **칸을 채운다.** 내용 양에 맞는 배치를 고른다.
5. **점검을 고친다.** 상태줄의 **점검** 목록을 터미널에 붙여 넣으면 Claude 가 고친다.
6. **사람이 다듬는다.** F2 로 그 자리에서 고친다.
7. **발표하고 전한다.** Shift+F5 로 발표하고, **pptx 로 전환**하거나 우클릭의 **인쇄 / PDF로 저장…** 으로 나눠 준다.

## 3. 복잡한 배치

칸이 많고 비대칭인 장이 필요하면 봅니다. [복잡한 배치 10가지](복잡한-배치/README.md)에 대시보드, 잡지 지면, 프로세스 지도, 간트 차트, 분석 틀이 있습니다.

## 좋은 슬라이드의 약속

- 제목은 주제가 아니라 결론을 쓴다.
- 장마다 말할 것 하나. 긴 설명은 발표자 노트에 쓴다.
- 칸으로 쓴다. HTML 장은 사람이 고칠 수 없다.
- 값이 자주 바뀌면 CSV 로 뺀다.
- 숫자는 장을 넘어서도 맞아야 한다. 합계와 비율을 계산해 본다.
- 점검이 0건이어도 눈으로 본다. 사진 위의 글과 빈 곳은 점검이 모른다.

## 강점은 고객 기반, 위협은 가격 경쟁이다

::: a accent
### 강점 S

- 재구매 고객 비중 64%
- 자체 물류망 전국 12곳
- 결제 전환율 업계 상위
:::

::: b note
### 약점 W

- 공급사 한 곳에 의존
- 해외 매출 비중 6%
- 데이터 인력 부족
:::

::: c card
### 기회 O

- 중소 판매자 수요 증가
- 정부 물류 보조금 신설
- 동남아 결제 규제 완화
:::

::: d dark
### 위협 T

- 대형 플랫폼의 가격 공세
- 개인정보 규제 강화
- 운임 상승세 지속
:::

# 키보드로 만든 격자

마우스 없이 키 97번으로 만든 구성

---

<!-- grid: t t t / a a b / c d b -->

## 격자는 Ctrl+E 로 한 줄만 쓴다

::: a card
### 1. 장을 더한다

Ctrl+M 으로 장을 더하고 제목을 쓴다
:::

::: b dark center
Shift+F10 메뉴의 배치 넣기로 뼈대를 만든다
:::

::: c note
Tab 으로 상태줄의 구조 보기에 간다
:::

::: d accent
F2 와 ↓ 로 칸을 채운다
:::

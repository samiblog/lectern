**무슨 일** 물량은 8.0% 늘었는데 영업이익은 6억 원 줄었다.

**왜** 4월부터 물량이 분류 능력을 넘어 병목 비용이 22억 원 나갔다.

**요청** 대전 허브 자동 분류기 60억 원. 2년 6개월이면 회수한다.
:::

## 4월부터 물량이 분류 능력을 넘었다

::: a
### 월별 물량 (만 건) — 점선은 분류 능력 200

```vega-lite
{
  "width": "container",
  "data": {"url": "data/01-월별-물량.csv"},
  "encoding": {
    "x": {"field": "월", "type": "ordinal", "sort": null, "title": null, "axis": {"labelAngle": 0}}
  },
  "layer": [
    {
      "mark": {"type": "bar", "cornerRadiusEnd": 3},
      "encoding": {
        "y": {"field": "물량", "type": "quantitative", "title": null},
        "color": {"condition": {"test": "datum['물량'] > 200", "value": "#b4533c"}, "value": "#5f7d95"}
      }
    },
    {
      "mark": {"type": "text", "dy": -16, "color": "white", "fontSize": 16, "fontWeight": "bold"},
      "encoding": {"y": {"datum": 0}, "text": {"field": "물량", "type": "quantitative"}}
    },
    {
      "mark": {"type": "rule", "strokeDash": [6, 4], "strokeWidth": 2, "color": "#333333"},
      "encoding": {"x": {}, "y": {"datum": 200}}
    }
  ],
  "config": {"axis": {"labelFontSize": 14}}
}
```
:::

::: b kpi center 28
**96.7%**
1분기 정시 배송
:::

::: c kpi accent center 28
**91.9%**
2분기 정시 배송
:::

<!-- 상반기 물량은 1,188만 건으로 전년 1,100만 건보다 8.0% 늘었다. 분류 능력 월 200만 건을 넘은 물량은 초과근무와 외주로 처리했다. 정시 배송은 물량 가중 평균이다 -->

## 분류 병목 비용 22억 원이 이익을 깎았다

::: a center
| 영업이익 변화 | 억 원 |
|---|---:|
| 전년 상반기 영업이익 | 32 |
| 매출 증가 | +32 |
| 운송·유류비 증가 | -16 |
| 병목: 분류 초과근무 | -9 |
| 병목: 외주 분류 | -8 |
| 병목: 지연 보상 | -5 |
| **올해 상반기 영업이익** | **26** |
:::

::: b kpi accent center 22
**22억 원**
병목 비용

병목이 없었다면
이익은 48억 원이다.
:::

<!-- 매출 증가분 32억 원에서 운송비 16억 원을 빼면 16억 원이 남아야 했다. 병목 비용 22억 원이 그것을 넘겼다 -->

## 60억 원은 2년 6개월이면 회수한다

::: a
| 연간 효과 | 억 원 |
|---|---:|
| 초과근무 절감 | 14 |
| 외주 분류 절감 | 12 |
| 지연 보상 절감 | 4 |
| 유지보수비 | -6 |

    "x": {"field": "연차", "type": "ordinal", "sort": null, "title": null, "axis": {"labelAngle": 0}}
  },
  "layer": [
    {
      "mark": {"type": "bar", "cornerRadiusEnd": 3},
      "encoding": {
        "y": {"field": "누적", "type": "quantitative", "title": null},
        "color": {"condition": {"test": "datum['누적'] < 0", "value": "#b4533c"}, "value": "#2e7d6b"}
      }
    },
    {
      "mark": {"type": "text", "color": "white", "fontSize": 16, "fontWeight": "bold"},

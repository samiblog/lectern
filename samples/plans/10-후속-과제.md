# 후속 과제

- [x] 월별 가격을 CSV 하나로 모으기 (`src/collect.py`)

- [ ] 보고서 초안에 지난주 대비 변화 요약 넣기 (`src/report.py:29` 의 `summary()` 를 늘린다)

- [ ] 재고 자료를 주 단위로 모으기

> [!TIP]
> 이 문서는 Lectern 의 **한 줄 편집**을 시험하기 좋다. 마지막 할 일에서 **Ctrl+Enter** 로 새 줄을 열고 할 일을 쓴 뒤 Enter — 바로 저장된다. 편집 모드로 해 보려면 상태줄의 '편집'(또는 Ctrl+E)을 누르고 한 줄 더한 뒤 Ctrl+S 로 저장한다. 다른 프로그램(Claude Code 등)이 이 파일을 고치면 Lectern 이 1~2초 안에 다시 그리고 바뀐 곳을 잠깐 표시한다.

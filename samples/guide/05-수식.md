# 수식

리서치 문서에는 수식과 달러 금액이 함께 나온다. Lectern 은 KaTeX 로 수식을 그리고, 달러 금액은 수식으로 바꾸지 않는다.

## 문장 안의 수식

`$…$` 또는 `\(…\)` 로 감싼다.

~~~md
가격 변화율은 $\Delta P = \frac{P_1 - P_0}{P_0}$ 이고, 오차항은 $\varepsilon_t$ 다.
~~~

가격 변화율은 $\Delta P = \frac{P_1 - P_0}{P_0}$ 이고, 오차항은 $\varepsilon_t$ 다. \(\alpha + \beta = 1\) 처럼 괄호 표기도 된다.

## 줄을 차지하는 수식

`$$…$$` 또는 `\[…\]` 로 감싼다.

~~~md
$$
P_t = P_0 \left(1 + r\right)^t
$$
~~~

$$
P_t = P_0 \left(1 + r\right)^t
$$

$$
\text{변화율} = \frac{\bar{P}_{\text{최근 3개월}} - \bar{P}_{\text{그 앞 3개월}}}{\bar{P}_{\text{그 앞 3개월}}} \times 100
$$

\[ E[R] = \sum_{i=1}^{n} w_i R_i \]

## 코드 블록에 쓴 수식

`math`·`latex`·`tex` 코드 블록도 수식으로 그린다. AI 가 식을 코드 블록으로 적을 때가 많아서다.

~~~~md
```latex
\ln Z_t = r_0 + r_1 \ln X_t
```
~~~~

```latex
\ln Z_t = r_0 + r_1 \ln X_t
```

## 달러 금액

여는 `$` 바로 뒤나 닫는 `$` 바로 앞이 빈칸이거나, 닫는 `$` 바로 뒤가 숫자이면 수식으로 보지 않는다. 그래서 아래 문장들은 그대로 보인다.

- 구리 가격은 $10,600에서 $11,400 사이에서 움직였다.
- 운임은 $95~$110/t 범위였다.
- 매출은 US$1.2bn, 영업이익은 $350m 이었다.
- 가격이 $5 오르면 마진은 $2 늘어난다.

> [!TIP]
> 수식을 쓰지 않는 프로젝트라면 설정(Ctrl+,)의 '수식 표시'를 끈다. 그러면 `$` 를 모두 글자로 본다.

수식을 우클릭하면 **LaTeX 복사**로 원래 식을 가져간다.

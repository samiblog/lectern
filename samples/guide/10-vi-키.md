# vi 키

vi(vim)에 손이 익은 사람을 위한 키다. 설정에서 고를 때만 켜지고, 켜지 않으면 아무것도 바뀌지 않는다. 두 가지를 따로 고른다.

| 설정 (Ctrl+,) | 무엇이 바뀌나 | 기본 |
|---|---|---|
| **vi 키** (체크 칸) | 읽는 화면 — 문서를 보면서 글자 키로 움직이고 고친다 | 꺼짐 |
| **전체 편집 방식** (기본 방식 / vi 방식) | 편집 버튼(Ctrl+E)으로 여는 전체 편집기 — vim 처럼 쓴다 | 기본 방식 |

읽는 화면의 vi 키는 Lectern 의 기본 키를 대신 눌러 주는 번역표다 (j 는 ↓, V 는 Insert, o 는 Ctrl+Enter, u 는 Ctrl+Z). 그래서 저장·되돌리기·고른 줄의 규칙은 [한 줄 편집](08-한-줄-편집.md)과 똑같다. 전체 편집기의 vi 방식은 편집기 안에서 vim 그대로 움직인다.

> [!IMPORTANT]
> 설치한 예제는 보기만 하는 폴더라 여기서는 고쳐지지 않는다. 따라 해 보려면 `samples` 폴더를 다른 곳에 복사해 **폴더 열기**로 연다 ([한 줄 편집](08-한-줄-편집.md)의 안내와 같다).

## 1. 켜고 끄기

1. **Ctrl+,** 로 설정 창을 연다.
2. 읽는 화면에서 쓰려면 **vi 키**에 체크한다. 켜면 아래 상태줄에 `vi` 가 보인다.
3. 전체 편집기에서 쓰려면 **전체 편집 방식**을 **vi 방식**으로 고른다. 열려 있는 편집기도 그 자리에서 바뀐다.
4. 끄면 글자 키는 다시 아무 일도 하지 않고, 편집기는 Esc 로 닫는 기본 방식으로 돌아간다.

둘은 따로다 — 편집기에서만 vim 을 쓰고 읽는 화면은 기본 키로 둘 수 있고, 그 반대도 된다.

## 2. 읽는 화면 — 모드는 줄의 상태다

vi 의 모드가 Lectern 의 줄의 상태와 하나씩 맞는다. 모드를 따로 바꾸는 키는 없고, 줄의 상태가 곧 모드다.

| vi | Lectern | 화면에서 | 들어가기 |
|---|---|---|---|
| Normal | 현재 줄 | 왼쪽의 작은 삼각형 | 줄을 누르거나 `j`·`k` |
| Visual Line | 고른 줄 | 회색으로 골라진 줄 | `V` |
| Insert | 칸 | 줄 안에 열린 글 칸 | `i`·`a`·`o`·`O` |
| (없음) | 하이라이트 | 나머지가 흐려진 화면 | 고른 줄에서 Shift+Enter — 이때는 vi 키가 듣지 않는다 (보기만) |

글자 키는 문서를 보고 있을 때만 듣는다. 칸 안, 찾기·거르기 칸, 터미널, 메모, 전체 편집기 안에서는 글자가 그대로 들어간다.

## 3. 읽는 화면의 키

### 움직이기

| 키 | 하는 일 |
|---|---|
| `j` · `k` | 아래·위 줄 |
| `gg` · `G` | 첫 줄 · 끝 줄 |
| `12G` | 12행으로 (상태줄의 '현재 줄 12행' 과 같은 원문 줄 번호) |
| `[[` · `]]` | 앞·뒤 제목 |
| `zz` | 현재 줄을 화면 가운데로 |
| `:` | 줄로 가기 (Ctrl+G 와 같다 — 줄 번호를 치고 Enter) |

앞에 숫자를 치면 그만큼 되풀이한다 — `5j` 는 다섯 줄 아래, `3]]` 는 세 번째 뒤 제목. 쪽 넘기기는 vi 의 Ctrl+D·Ctrl+F 대신 **PageUp·PageDown** 을 쓴다.

### 접기와 찾기

| 키 | 하는 일 |
|---|---|
| `zc` · `zo` · `za` | 현재 줄이 든 절 접기 · 펴기 · 바꾸기 |
| `zM` · `zR` | 모두 접기 · 모두 펴기 |
| `/` | 문서에서 찾기 — 찾을 말을 치고 Enter, Esc 로 문서로 돌아온다 |
| `n` · `N` | 마지막에 찾은 말의 다음 · 이전 곳 (찾기 막대가 닫혀 있어도) |

### 쓰기

| 키 | 하는 일 |
|---|---|
| `i` · `I` | 그 줄의 칸을 열고 커서를 줄 처음에 |
| `a` · `A` | 그 줄의 칸을 열고 커서를 줄 끝에 |
| `o` · `O` | 아래 · 위에 새 줄을 연다 (앞 줄의 목록 표시를 물려받는다) |
| 칸에서 **Esc** | **저장하고** 나온다 — vi 키를 끄면 Esc 는 그만두기다 |
| 칸에서 **Enter** | 저장한다 (새 줄이면 저장하고 다음 새 줄로 — 한 줄 편집과 같다) |

칸 안에서는 vi 의 Normal 모드(`hjkl`, `w`, `x`, `cw`)를 쓰지 않는다. 칸은 한 줄이라 화살표와 Home·End 로 충분하고, 모드가 두 겹이 되면 헷갈리기 때문이다.

### 고르고 바꾸기 (Visual Line)

`V` 로 현재 줄을 고른 뒤:

| 키 | 하는 일 |
|---|---|
| `j` · `k` | 고른 줄을 아래 · 위로 넓히고 줄인다 |
| `d` · `x` | 고른 줄을 지운다 (담아 둔다) |
| `y` | 고른 줄의 원문을 복사한다 (담아 둔다) |
| `>` · `<` | 레벨을 안으로 · 밖으로 (목록 항목·제목) |
| `J` | 고른 줄을 한 줄로 합친다 — 한 줄만 골랐으면 다음 줄과. 한 문단 안의 이어진 줄만 |
| `V` · Esc | 고르기를 푼다 |

옮기기는 vi 에 맞는 키가 없어 Lectern 의 **Alt+↑·↓** 를 그대로 쓴다.

### 한 번에 (두 번 누르는 명령)

| 키 | 하는 일 |
|---|---|
| `dd` | 현재 줄을 지운다 (`3dd` 는 세 줄) |
| `yy` | 현재 줄의 원문을 복사한다 (`2yy` 는 두 줄) |
| `>>` · `<<` | 현재 줄의 레벨을 안으로 · 밖으로 |
| `p` · `P` | 담아 둔 줄을 현재 줄 아래 · 위에 넣는다 |
| `u` | 되돌린다 (`3u` 는 세 번). 다시 하기는 **Ctrl+Y** |

- `dd`·`>>`·`<<` 는 '그 줄을 고르고 실행'으로 번역된다. 파일을 바꾸는 키는 고른 줄에서만 듣는다는 Lectern 의 규칙을, 두 번 눌러야 하는 명령으로 지킨다 — 읽다가 잘못 눌러 파일이 바뀌지 않게.
- `dd`·`yy`·`d`·`y` 로 담은 줄은 Lectern 안에 담겨 `p`·`P` 가 넣는다. `yy`·`y` 는 시스템 클립보드에도 원문을 복사하고, `dd`·`d` 는 클립보드를 건드리지 않는다.
- `p` 는 현재 줄이 든 블록(문단·표·목록) 아래에 앞뒤 빈 줄을 두고 넣는다. 목록 항목을 목록 안에 넣으면 빈 줄 없이 항목으로 들어간다.
- 고친 것은 모두 누르는 순간 파일에 저장되고 하나하나 Ctrl+Z(`u`)로 되돌린다.

### 기다리는 글자

`d`·`y`·`g`·`z`·`[`·`]`·`>`·`<` 와 숫자는 다음 글자를 1초 기다린다. 그동안 상태줄에 `vi d…` 처럼 보인다. 1초가 지나거나 맞지 않는 글자를 치면 그 명령은 버려진다.

## 4. 해 보세요 (읽는 화면)

복사한 폴더에서 **vi 키**를 켜고 아래 글로 해 본다.

첫째 문단이다.

둘째 문단이다.

셋째 문단이다.

1. '첫째 문단이다.' 를 누르고 `j` 를 두 번 — 현재 줄이 셋째 문단으로 간다. `gg` 로 문서 맨 위, `G` 로 끝.
2. 둘째 문단에서 `dd` — 지워진다. `u` 로 돌아온다.
3. 첫째 문단에서 `yy`, 셋째 문단으로 가서 `p` — 셋째 문단 아래에 같은 문단이 하나 더 생긴다. `u` 로 되돌린다.
4. 둘째 문단에서 `o` 를 누르고 '새 문단' 을 쓴 뒤 **Esc** — 저장되고 칸이 닫힌다.
5. 둘째 문단에서 `V`, `j` 로 셋째 문단까지 넓히고 `d` — 두 문단이 함께 지워진다. `u` 로 돌아온다.
6. `/` 를 누르고 '문단' 을 쳐서 Enter, Esc 로 문서로 돌아와 `n` 을 몇 번 — 찾은 곳을 차례로 다닌다.

## 5. 전체 편집기의 vi 방식

전체 편집 방식을 **vi 방식**으로 고르면 편집 버튼(또는 Ctrl+E)으로 여는 전체 편집기가 vim 처럼 움직인다. 편집기는 CodeMirror 의 vim 키맵이라 이동, 텍스트 객체, 비주얼 모드, `/` 찾기, `:s` 바꾸기 같은 vim 의 명령을 대부분 쓴다.

| 키 | 하는 일 |
|---|---|
| (열면) | Normal 모드로 시작한다 |
| `i` · `a` · `o` … | Insert 모드 |
| **Esc** | Normal 모드로 — 편집을 닫지 않는다 |
| `:w` | 저장 (Ctrl+S 도 된다) |
| `:q` | 편집 닫기 — 저장하지 않은 것이 있으면 묻는다 |
| `:wq` · `:x` | 저장하고 닫기 |
| Ctrl+E · ✕ | 편집 닫기 (기본 방식과 같다) |
| Ctrl+H · Ctrl+G · F3 | 바꾸기 · 줄로 가기 · 다음 찾기 (기본 방식과 같다) |

| 차이 | 기본 방식 | vi 방식 |
|---|---|---|
| 열었을 때 | 바로 쓴다 | Normal 모드 — `i` 로 쓴다 |
| Esc | 편집 닫기 | Normal 모드로 |
| 닫기 | Esc·Ctrl+E·✕ | `:q`·`:wq`·Ctrl+E·✕ |
| 저장 | Ctrl+S | `:w`·Ctrl+S |

> [!WARNING]
> 전체 편집기의 Normal 모드 키는 한글 입력 상태에서 글자로 들어갈 수 있다. 편집기에서는 한/영 키로 영어 입력으로 바꿔 쓴다. 읽는 화면의 vi 키는 자판 자리로 읽어 한/영 상태와 관계없이 듣는다.

## 6. 하지 않는 것

- **Ctrl 이 붙은 키는 바꾸지 않는다.** vi 의 Ctrl+D·Ctrl+U·Ctrl+F·Ctrl+B·Ctrl+R 은 Lectern 에서 장 복제·찾기·사이드바 같은 다른 일을 한다. 쪽 넘기기는 PageUp·PageDown, 다시 하기는 Ctrl+Y.
- 읽는 화면에서는 반복(`.`), 매크로(`q`), 마크(`m`), 이름 붙인 레지스터(`"a`), 텍스트 객체, `:` 명령(줄 번호 말고)이 없다. 글자 단위 고르기(`v`)는 줄 고르기(`V`)와 같다. 이런 일은 전체 편집기의 vi 방식에서 한다.
- 마우스와 Lectern 의 기본 키(F2, Insert, Alt+↑·↓, Ctrl+Enter …)는 vi 키를 켜도 그대로 쓴다.

| 첫 줄·끝 줄 | — | `gg` · `G` |
| 그 줄 고치기 | F2 | `i` · `a` |
| 아래·위 새 줄 | Ctrl+Enter · Ctrl+Shift+Enter | `o` · `O` |
| 칸 저장하고 나오기 | Enter | Enter · Esc |
| 줄 고르기 | Insert | `V` |
| 줄 지우기 | Insert → Delete | `dd` |
| 원문 복사 | Ctrl+C | `yy` |
| 레벨 | Alt+Shift+→ · ← | `>>` · `<<` |
| 되돌리기 | Ctrl+Z | `u` |
| 절 접기·펴기 | Ctrl+Shift+[ · ] | `zc` · `zo` |
| 찾기·다음 | Ctrl+F · Enter | `/` · `n` |

# Lectern 슬라이드

발표 자료도 Markdown 으로 쓴다. 맨 앞 설정에 `marp: true` 를 적은 문서가 **Lectern 슬라이드**다 — `---` 로 장을 나누고, 칸과 배치로 장을 짜고, 슬라이드 창에서 한 장씩 보고, 그대로 발표하거나 pptx 로 바꾼다. 글은 md 문서처럼 그 자리에서 줄마다 고친다.

> [!TIP]
> 이 문서는 보통 md 문서라 처음부터 끝까지 읽을 수 있다. 같은 내용을 슬라이드로 보려면 맨 아래 **13. 예제**의 기초 예제를 연다. 쓰는 법 전체는 **F1** 사용설명서의 'Lectern 슬라이드' 장, Claude 가 따르는 규칙은 작성 안내 옆의 `slides.md` 에 있다.

## 1. md 문서와 무엇이 다른가

| | md 문서 | Lectern 슬라이드 |
|---|---|---|
| 맨 앞 설정 | 없어도 된다 | `marp: true` |
| 나누기 | 제목(`##`)으로 절 | `---` 로 장 (16:9 는 1280×720) |
| 보는 곳 | 문서 칸 | 따로 뜨는 슬라이드 창 — 스타일도 따로 고른다 |
| 한 장의 분량 | 길어도 된다 | 제목 하나와 짧은 줄 대여섯 — 넘친 글은 잘린다 |
| 배치 | 위에서 아래로 | 칸(`::: a card`)과 배치(`<!-- layout: quad -->`) |
| 왼쪽 목록 | 보통 아이콘 | 주황색 아이콘 |
| 오른쪽 목차 | 제목 | 장 목록 (점검할 장은 표시) |
| 결과물 | 인쇄·PDF | 발표(Shift+F5), PDF(한 장에 한 쪽), pptx |

다른 앱에서는 칸 표시(`:::`)가 글자로 보인다. Marp 에서 출발했지만 Lectern 의 형식이다.

## 2. 만들기

1. 사이드바의 **만들기**(Ctrl+N)에서 제목을 쓰고 종류를 **Lectern 슬라이드**로 고른다.
2. 템플릿 갤러리에서 첫 장을 고른다. 갤러리는 왼쪽에서 묶음을 고르고(PageUp·PageDown), 번호를 치거나 화살표로 옮겨 Enter 를 누른다. 글자를 치면 모든 묶음에서 찾는다.
3. 장의 안내 글을 열면 글 전체가 골라져 있어 바로 치면 바뀐다.
4. **Ctrl+M** 으로 다음 장의 템플릿을 고르며 이어 간다. **Ctrl+D** 는 지금 장을 복제한다.

- 고른 뒤에 배치를 바꾸려면 장을 우클릭해 **템플릿 바꾸기…** — 쓴 글은 새 칸으로 옮겨 담고, 못 담는 글은 맨 아래 칸에 남는다.
- 자주 쓰는 장은 우클릭 **이 장을 템플릿으로 저장…** 으로 '내 템플릿' 묶음에 더한다. 템플릿은 프로젝트가 아니라 Lectern 전체에서 함께 쓴다.
- 있는 md 문서는 사이드바에서 우클릭해 **Lectern 슬라이드로 바꾸기 요청**을 고른다. 터미널에 요청 글이 들어가고, Enter 를 누르면 Claude 가 같은 폴더에 새 파일로 만든다.
- pptx 를 옮기거나 pptx 를 참고해 만드는 일은 아래 **12. Claude Code 와 함께**.

## 3. 뼈대

```markdown
---
marp: true
title: 2026년 구리 시장 전망
paginate: true
footer: 원자재 리서치 · 2026-11
---

<!-- _class: lead -->

# 2026년 구리 시장 전망

수요 둔화와 공급 차질 사이에서

---

<!-- layout: two -->

## 재고는 줄고 가격은 올랐다

::: a card
### 재고

거래소 재고는 **19.2만 t** 이다.
:::

::: b
| 분기 | 가격 |
|---|---:|
| 1Q | 8,650 |
| 2Q | 9,120 |
:::

<!-- 재고 수치는 거래소 주간 자료 기준 -->
```

- **맨 앞 설정**: `marp: true` 가 있어야 슬라이드가 된다. `paginate: true` 는 쪽 번호, `footer`·`header` 는 아래·위의 글, `size: 4:3` 은 4:3 장(960×720)이다.
- **장 나누기**: `---` 줄. 앞뒤에 빈 줄을 둔다.
- **제목**: `#`·`##` 는 칸 밖에, 한 장에 하나만 쓴다.
- **지시어**: 그 장의 맨 앞에 HTML 주석으로 쓴다 (`<!-- layout: two -->`, 아래 **9. 지시어**).
- **발표자 노트**: 지시어가 아닌 주석은 모두 노트다. 발표 중 **N** 으로 보이고 pptx 의 노트로 간다.
- **표지·장 구분**: `<!-- _class: lead -->` 장은 칸 없이 가운데로 쓴다.

## 4. 칸

`::: 이름 낱말…` 줄부터 `:::` 줄까지가 칸이다. 칸 안은 보통 Markdown 이라 표·목록·강조글·그림·수식·다이어그램·차트를 모두 넣는다. 칸을 다른 칸 안에 넣지 않고, 머리 줄과 닫는 줄을 빠뜨리지 않는다. 배치가 있는 장의 글은 제목 말고 모두 칸 안에 쓴다.

칸 이름 뒤에 꾸밈 낱말을 붙인다. 여럿을 함께 써도 된다 (`::: b card center`).

| 낱말 | 모양 |
|---|---|
| `card` | 테두리 있는 카드 |
| `accent` | 강조 색 상자 |
| `dark` | 어두운 상자 |
| `note` | 노란 메모 |
| `kpi` | 큰 숫자 카드 — `**숫자**` 가 크게, 다음 줄이 설명 |
| `center` | 글을 위아래 가운데로 (글이 적은 칸, 짧은 표, 차트) |
| `text-center` · `text-right` | 글을 가로 가운데·오른쪽으로 |
| `cols-2` · `cols-3` | 칸 안의 글을 2단·3단으로 |

```markdown
::: a kpi
**9,120**
LME 가격 ($/t)
:::
```

칸 머리 줄에 수를 쓰면 그 칸의 글자 크기다 (`::: b card 14`). 굵은 글이 문장부호로 끝나면 닫는 `**` 뒤에 글자를 바로 붙이지 않는다 — `**8.0%**로` 는 별표가 보이니 `**8.0%** 로` 나 `**8.0%로**` 로 쓴다.

## 5. 배치

### 틀 고르기

장마다 `<!-- layout: 이름 -->` 을 쓴다. 뒷장으로 이어지지 않는다.

| 이름 | 칸 | 모양 |
|---|---|---|
| `two` | a b | 좌우 반반 |
| `two-left` | a b | 왼쪽 2 : 오른쪽 1 |
| `two-right` | a b | 왼쪽 1 : 오른쪽 2 |
| `three` | a b c | 세 칸 |
| `quad` | a b c d | 2×2 |
| `left-stack` | a b c | 왼쪽 큰 칸 a, 오른쪽에 b 위 c 아래 |
| `right-stack` | a b c | 왼쪽에 a 위 c 아래, 오른쪽 큰 칸 b |
| `kpi` | a b c d e | 위에 작은 칸 넷, 아래에 넓은 칸 e |
| `kpi-two` | a b c d e | 위에 작은 칸 셋, 아래에 넓은 칸 d 와 작은 칸 e |
| `stack` | a b | 위아래 |

마우스로는 슬라이드를 우클릭해 **배치 넣기…** 를 고른다. 칸이 있던 장은 칸 이름만 바뀌고, 칸이 없던 장의 글은 첫 칸으로 들어간다.

### 격자로 그리기

틀에 없는 배치는 칸 이름으로 그림을 그린다. 줄은 `/` 로 나눈다.

```markdown
<!-- grid: t t / a b / c b -->
<!-- cols: 1fr 1.2fr -->
<!-- rows: auto 1fr 1fr -->
```

- `t` 는 제목 자리다. 제목을 쓰는 장은 `t` 를 넣는다.
- `.` 은 빈 자리다 (`<!-- grid: t t t / a . b -->`).
- `cols` 는 열마다, `rows` 는 줄마다 `1fr`·`auto`·`200px` 를 하나씩 적는다. 적지 않으면 같은 폭·같은 높이다.
- 줄과 열의 수에는 제한이 없다 — 13열 간트나 35칸 달력도 된다 (`<!-- cols: 120px repeat(12, 1fr) -->`).

### 자리를 직접 정하기와 선 긋기

```markdown
::: hub note at 460 250 300 120
### 제품 마진

스프레드가 핵심이다
:::

<!-- links: cost>hub, freight>hub, hub<>demand -->
```

- `at x y 너비 높이` 는 칸의 자리(px)다. 왼쪽 위가 0 0 이고, 쓸 수 있는 곳은 x 56~1224, y 110~660 이다 (위는 제목, 아래는 꼬리말 자리). `layout` 없이 쓴다.
- `links` 는 칸 사이에 `a>b` 화살표, `a<>b` 양쪽 화살표, `a--b` 선을 긋는다. 칸의 글은 그대로 한 줄 편집이 된다. 칸을 조금 떨어뜨려 놓아야 선이 보인다.

## 6. 글자 크기

기본은 제목 30pt, 소제목 20pt, 본문 18pt, 표 14pt, 강조글 16pt, 코드 14pt 다 — PowerPoint 의 pt 와 같고, 스타일을 바꿔도 그대로다.

| 범위 | 쓰는 법 |
|---|---|
| 문서 전체 | 맨 앞 설정에 `text: 제목 26, 표 12` |
| 그 장 | `<!-- text: 표 12 -->` — 현재 줄에서 **Ctrl+Shift+>·<** 를 누르면 생긴다 |
| 그 칸 | 칸 머리 줄의 수 (`::: b card 14`) — 그 칸에서 Ctrl+Shift+>·< |

표가 12pt, 본문이 14pt 아래로 내려가면 점검에 나온다. 넘친다고 글자만 줄이지 말고 글을 줄이거나 장을 나눈다. 화면에 띄우지 않고 읽는 자료면 맨 앞 설정에 `reading: true` 를 쓴다 (기준 10pt, 12pt).

## 7. 한 장의 분량

글은 넘치면 줄어들지 않고 잘린다 (빨간 점선이 붙는다). 그림·차트·다이어그램은 칸에 맞게 줄어든다. 18pt 기준으로 어림하면 이 정도다.

| 배치 | 칸 | 본문 줄 | 한 줄 글자 | 표 행 |
|---|---|---:|---:|---:|
| `two` | a b | 15 | 24 | 12 |
| `two-left` | a (넓은 칸) | 15 | 32 | 12 |
| `three` | a b c | 15 | 16 | 12 (3열까지) |
| `quad` | a b c d | 7 | 24 | 5 |
| `left-stack` | b c (작은 칸) | 7 | 19 | 5 |
| `kpi` | e (아래 넓은 칸) | 11 | 50 | 9 |
| `stack` | a b | 7 | 50 | 5 |

- `card`·`accent`·`dark`·`note`·`kpi` 칸은 안쪽 여백만큼 조금 더 적게 들어간다.
- 제목은 한 줄에 약 30자다. 영문은 한글의 약 1.6배가 들어간다.
- 문단보다 짧은 목록이 낫다. 긴 설명은 발표자 노트에 쓴다.

## 8. 차트와 그림

- 차트는 md 문서처럼 코드 블록(```` ```vega-lite ````·```` ```echarts ````·```` ```plotly ````·```` ```dot ````·```` ```mermaid ````)으로 쓴다. 칸 안의 차트는 칸의 폭과 남은 높이에 맞춰 그려진다. Vega-Lite 는 `"width": "container"` 를 쓰고 `height` 는 쓰지 않는다.
- 자료는 문서 안에 적거나 프로젝트의 CSV 를 **이 문서 기준 상대경로**로 가리킨다 (Vega-Lite 의 `data.url`). 인터넷 주소의 자료는 읽지 않는다.
- 차트에서 **F2** 를 누르면 값이 표로 나와 칸마다 고친다. 표를 우클릭해 **이 표를 차트로**를 고르면 pptx 에서 PowerPoint 차트가 된다.
- `![w:300 설명](images/a.png)` 은 그림 크기다. 칸보다 크면 비율을 지켜 줄어든다. 붙여 넣은 그림은 **Ctrl+Shift+>·<** 로 폭을 바꾼다.
- `![bg right:40%](images/a.png)` 는 오른쪽 40% 의 배경 그림, `![bg](a.png)` 는 장 전체, `![bg brightness:.5](a.png)` 처럼 필터도 쓴다. 사진 위의 글은 점검이 대비를 재지 못하니 눈으로 본다.

## 9. 지시어

| 지시어 | 뜻 |
|---|---|
| `<!-- layout: two -->` · `<!-- grid: … -->` | 이 장의 배치 |
| `<!-- _class: lead -->` | 표지처럼 가운데로 (장 구분에도) |
| `<!-- _class: invert -->` | 어두운 장 |
| `<!-- _backgroundColor: #17293d -->` · `<!-- _color: #ffd27f -->` | 이 장의 바탕색·글자색 |
| `<!-- _paginate: false -->` · `<!-- _footer: '' -->` | 이 장의 쪽 번호·꼬리말 빼기 |
| `<!-- eyebrow: 시장 요약 -->` | 제목 위의 작은 머리글 |
| `<!-- text: 표 12 -->` | 이 장의 글자 크기 |
| `<!-- hidden: true -->` | 숨긴 장 — 화면에 흐리게, 발표와 PDF 에서 빠진다 |

`_` 를 붙이면 그 장만이고, 붙이지 않은 `class`·`backgroundColor` 는 뒷장으로 이어진다. `layout`·`grid`·`text`·`eyebrow`·`hidden` 은 늘 그 장만이다. 장의 CSS 는 `<style scoped>`, 문서 전체의 CSS 는 맨 앞 설정의 `style: |` 로 쓴다.

## 10. 고치기와 점검

[한 줄 편집](08-한-줄-편집.md)과 같은 키를 쓴다 — **F2** 로 열고 **Enter** 로 저장, **Insert** 로 고르고 **Alt+↑·↓** 로 옮기고, **Ctrl+Z** 로 되돌린다. 칸 끝에서 Ctrl+Enter 로 더한 줄도 칸 안에 들어가고, 줄을 옮기거나 지워도 칸과 장은 깨지지 않는다. 칸의 빈 줄에서 **/** 를 누르면 넣기 창이 뜬다 — 주·표 주·첨부·부록·구분선과 목차·쪽 나눔·상호 참조·본문 인용은 md 문서에만 있다.

| 하는 일 | 키·메뉴 |
|---|---|
| 장 더하기·복제 | **Ctrl+M**·**Ctrl+D** |
| 장 옮기기 | **Ctrl+Shift+PageUp·PageDown**, 또는 장 제목 줄을 고르고 **Alt+↑·↓** |
| 장 지우기 | 슬라이드를 우클릭 |
| 칸 꾸밈·맞바꾸기·비우기 | 칸의 글을 우클릭 → **칸 꾸밈…**·**이 칸을 앞으로·뒤로**·**칸 비우기** |
| 넘친 칸 | 우클릭 → **넘친 줄을 다음 장으로**, **이 칸 줄이기 요청** |
| 수식·다이어그램 원문 | **F2** — 화면 옆 패널에서 줄마다, **Esc** 로 접기 |
| 발표자 노트 | 우클릭 → **발표자 노트 쓰기…** |
| 숨은 줄(칸 머리·지시어·노트) | 상태줄의 **구조 보기**를 켜고 꼬리표에서 **F2** |

**점검**: 상태줄의 **점검**이 넘친 칸, 문법 실수(칸 이름, 빠뜨린 `:::`, 지시어 오타, 잘못된 격자, 닫지 않은 주석), 바탕과 비슷한 글자, 옆으로 잘린 표·코드, 없는 그림, 그리지 못한 차트를 모아 보인다. 고르면 그 줄로 가고, **목록을 터미널에 붙여 넣기**로 Claude 에게 고쳐 달라고 할 수 있다. 점검이 0건이어도 사진 위의 글과 빈 곳은 눈으로 본다.

## 11. 보기, 발표, pptx 로 전환

- Lectern 슬라이드를 누르면 **슬라이드 창**이 따로 열린다. 그 창의 스타일은 메인 창과 따로 고른다 (기본은 '발표'). 화면 스타일을 바꿔도 pptx 스타일은 그대로다.
- 상태줄의 **발표**(Shift+F5)로 지금 장부터 창 전체에 한 장씩 보인다. → ← Space·PageDown·PageUp 으로 넘기고, **N** 은 발표자 노트, **F** 는 전체 화면, **Esc** 는 끝내기다.
- 상태줄의 **문서로 보기**는 칸을 풀어 보통 문서처럼 이어서 보인다. 인쇄·PDF 는 한 장에 한 쪽, 화면과 같은 색이다.
- 상태줄의 **pptx 로 전환**으로 pptx 스타일을 골라 PowerPoint 파일을 만든다. 문서 옆에 새 파일로 만들고 덮어쓰지 않는다. Claude 나 Python 은 없어도 된다.
  - pptx 스타일은 Lectern 전체에서 함께 쓰는 양식이다. 회사 양식 pptx 를 보관소 폴더에 넣으면 목록에 나온다.
  - 칸의 자리는 Lectern 슬라이드를, 색·글꼴·로고·꼬리말은 pptx 스타일을 따른다. 글은 글, 표는 표, 차트는 값을 고칠 수 있는 차트로 들어간다.
  - 고른 스타일은 맨 앞 설정에 `pptxStyle: 이름` 으로 적혀 다음에 먼저 고른다.
- 상태줄의 **html 로 전환**은 impress.js 발표 html 파일 하나를 만든다. 받은 사람이 브라우저로 열어 발표하고, 장이 한 캔버스 위에 놓여 화면이 장 사이를 옮겨 다닌다. 그림·글꼴이 파일 안에 들어가 인터넷 없이 열린다.
  - 배치는 격자(장 구분에서, 없으면 4장마다 줄 바꿈)나 가로 한 줄이다. 장에 `<!-- impress: x=0 y=2400 rotate=90 -->` 를 쓰면 그 장만 그 자리에 놓인다. **Claude 에게 배치 요청**으로 이야기 흐름에 맞춘 자리를 Claude 에게 맡긴다.
  - P 는 발표자 콘솔이다. Lectern 에서 열면 스크립트가 돌지 않아 장이 위에서 아래로 놓인 문서로 보인다.
  - 예제 [html 발표](../slides/기초/07-html-발표.md) 옆의 `07-html-발표.html` 이 그 결과다. 사이드바에서 우클릭 → **탐색기에서 보기**로 찾아 브라우저로 연다.

## 12. Claude Code 와 함께 — 스킬 설치와 사용

Lectern 은 Claude 를 실행하지 않는다. 오른쪽 터미널(**Ctrl+\`** — 숫자 1 왼쪽 키)에서 사람이 `claude` 를 실행하고 직접 말한다. Lectern 의 '…요청' 메뉴는 요청 글을 터미널에 넣기만 하고 **Enter 는 누르지 않는다** — 읽어 보고 사람이 누른다. 그래서 요청 메뉴를 쓰기 전에 터미널에서 Claude Code 를 실행해 둔다. 문서 쪽 연동(위치 복사, 바뀐 곳 표시, 코드 읽기)은 [Claude Code 와 함께](03-Claude-Code와-함께.md)에 있다.

### 처음 한 번: Claude 에게 Lectern 알려 주기

설정(Ctrl+,)의 **Claude Code 에 Lectern 알려 주기** → **Claude Code용 요청 복사**(또는 옆의 터미널 버튼)로 요청 글을 넣는다. Claude 가 Lectern 의 작성 안내를 읽고 그 프로젝트의 `CLAUDE.md` 에 규칙을 정리한다. 슬라이드 규칙(`slides.md`)을 먼저 읽으라는 줄도 들어가서, 그 뒤로 Claude 는 분량 기준과 배치 규칙을 지켜 넘치지 않게 쓴다.

### 스킬 설치

pptx 와 Lectern 슬라이드를 오가는 일은 Lectern 에 든 Claude Code 스킬 두 개가 한다.

| 스킬 | 하는 일 |
|---|---|
| `pptx-to-lectern` | pptx(.pptx·.ppt)나 PowerPoint 에 띄워 둔 발표를 Lectern 슬라이드로 옮긴다. pptx 를 양식으로 참고해 md 문서를 슬라이드로 만든다. pptx 스타일과 템플릿 묶음을 만든다 |
| `lectern-to-pptx` | Lectern 슬라이드를 pptx 로 만든다 — 회사 양식으로, 또는 pptx 에서 옮겨 온 문서면 원본 장을 살려 고친 장만 반영해서 |

1. 설정(Ctrl+,)의 **PowerPoint 스킬** → **Claude Code용 요청 복사**, 또는 옆의 터미널 버튼으로 요청 글을 넣고 Enter 를 누른다.
2. Claude 가 두 스킬이 무엇을 하는지 짧게 알려 주고 설치할지 묻는다. 그렇다고 하면 개인 스킬 폴더(`~/.claude/skills/`)에 복사한다.
3. 새 판의 Lectern 을 설치한 뒤에는 같은 요청을 한 번 더 한다. 이미 있으면 바꿀지 묻는다.

Lectern 이 스킬을 설치하지는 않는다 — Claude 가 묻고 사람이 허락할 때만 들어간다.

### 무엇이 필요한가

- Python 은 없어도 된다. 스킬은 프로그램 폴더의 `lectern-skill.exe` 로 돈다.
- PowerPoint 가 없어도 `.pptx` 파일은 옮기고 내보낸다. 띄워 둔 발표, `.ppt`, DRM 이 걸린 파일은 PowerPoint 가 있어야 한다.
- 암호가 걸린 파일은 먼저 푼다. DRM 이 걸린 파일은 PowerPoint 로 열어 띄워 두고 "지금 띄워 둔 발표를 옮겨 줘" 라고 한다.
- 원본 pptx 는 고치지 않는다. 띄워 둔 발표도 저장하거나 닫지 않는다.
- 옮길 때는 글을 빠뜨리지 않고 장을 그대로 지킨다. 글이 중심인 장은 칸으로 다시 짜고, 지도처럼 자리가 뜻인 도식은 그림으로 남기며 글은 노트에 둔다. 애니메이션과 정확한 글꼴은 옮기지 않는다.

### 요청 예

`@문서.md` 는 트리에서 우클릭한 **@경로 복사**다.

**pptx 를 Lectern 슬라이드로**

```text
이 pptx 를 Lectern 슬라이드로 옮겨 줘: D:\자료\보고서.pptx
지금 PowerPoint 에 띄워 둔 발표를 Lectern 슬라이드로 옮겨 줘. 결과는 D:\프로젝트\발표 폴더에 둬.
D:\자료\보고서.pptx 를 일단 빨리 md 로만 뽑아 줘. 다듬는 건 나중에 할게.
```

**pptx 를 참고해서 md 문서를 Lectern 슬라이드로**

```text
D:\양식\회사보고.pptx 를 참고해서 @시장-분석.md 내용을 Lectern 슬라이드로 만들어 줘.
D:\양식\회사보고.pptx 의 색과 표지만 참고해서 @주간보고.md 를 10장 안으로 Lectern 슬라이드로 만들어 줘. 숫자는 그대로 써.
```

**pptx 스타일과 템플릿 만들기**

```text
D:\양식\회사보고.pptx 로 '회사 보고' pptx 스타일과 템플릿 묶음을 만들어 줘.
'회사 보고' 묶음에 표와 강조글이 있는 템플릿을 하나 더 만들어 줘.
```

**Lectern 슬라이드를 pptx 로**

```text
@발표.md 를 D:\양식\회사보고.pptx 양식으로 pptx 를 만들어 줘.
pptx 에서 옮겨 온 @보고서.md 를 고쳤어. 고친 장만 반영해서 다시 pptx 로 만들어 줘.
```

양식 없이 Lectern 의 모양 그대로면 Claude 없이 상태줄의 **pptx 로 전환**으로 된다 (11절). 요청 예는 프로그램 폴더의 `skills\README.md` 에 더 있다.

### Lectern 의 요청 메뉴

요청 글을 쓰지 않아도 되는 일은 메뉴가 요청 글을 만들어 터미널에 넣는다.

| 메뉴 | 어디서 | Claude 에게 맡기는 일 |
|---|---|---|
| **Lectern 슬라이드로 바꾸기 요청** | 사이드바에서 md 문서를 우클릭 | 그 문서를 같은 폴더의 새 Lectern 슬라이드로 |
| **이 칸 줄이기 요청** | 넘친 칸을 우클릭 | 그 칸의 글을 칸에 맞게 줄이기 |
| **목록을 터미널에 붙여 넣기** | 상태줄의 **점검** | 점검에 나온 곳을 고치기 |
| **Claude 에게 템플릿 요청** | 템플릿 갤러리 | 원하는 모양을 이어 적어 템플릿 만들기 |
| **Claude 에게 스타일 요청** | pptx 로 전환 창 | pptx 경로를 이어 적어 pptx 스타일 만들기 |

### 함께 다듬는 차례

1. Claude 에게 슬라이드를 만들게 한다 — md 문서에서(우클릭 요청), 또는 pptx 에서(스킬).
2. 슬라이드 창에서 보고 상태줄의 **점검**을 연다. 고칠 곳이 많으면 **목록을 터미널에 붙여 넣기**로 Claude 에게 맡긴다.
3. 남은 글은 사람이 한 줄 편집으로 고친다. 넘친 칸은 **넘친 줄을 다음 장으로**, 또는 **이 칸 줄이기 요청**.
4. 마지막에 **pptx 로 전환**(Claude 없이)한다. 원본 pptx 의 디자인을 살려야 하면 Claude 에게 "고친 장만 반영해서 다시 pptx 로" 라고 한다.

# Lectern 슬라이드

발표 자료도 Markdown 으로 쓴다. 맨 앞 설정에 `marp: true` 를 적은 문서가 **Lectern 슬라이드**다 — `---` 로 장을 나누고, 슬라이드 창에서 한 장씩 보고, 그대로 발표하거나 pptx 로 바꾼다. 글은 md 문서처럼 그 자리에서 줄마다 고친다.

> [!TIP]
> 이 문서는 슬라이드 예제 앞에 읽는 짧은 안내다. 예제는 [Lectern 슬라이드 예제](../slides/README.md)에 기초 → 상황별 → 복잡한 배치 차례로 있고, 쓰는 법 전체는 **F1** 사용설명서의 'Lectern 슬라이드' 장에 있다.

## md 문서와 무엇이 다른가

| | md 문서 | Lectern 슬라이드 |
|---|---|---|
| 맨 앞 설정 | 없어도 된다 | `marp: true` |
| 나누기 | 제목(`##`)으로 절 | `---` 로 장 (1280×720) |
| 보는 곳 | 문서 칸 | 따로 뜨는 슬라이드 창 — 스타일도 따로 고른다 |
| 한 장의 분량 | 길어도 된다 | 제목 하나와 짧은 줄 대여섯 — 넘친 글은 잘린다 |
| 배치 | 위에서 아래로 | 칸(`::: a card`)과 배치(`<!-- layout: quad -->`) |
| 왼쪽 목록 | 보통 아이콘 | 주황색 아이콘 |
| 결과물 | 인쇄·PDF | 발표(Shift+F5), PDF(한 장에 한 쪽), pptx |

## 만들기

1. 사이드바의 **만들기**(Ctrl+N)에서 제목을 쓰고 종류를 **Lectern 슬라이드**로 고른다.
2. 템플릿 갤러리에서 첫 장을 고른다. 안내 글이 골라져 있으니 바로 친다.
3. **Ctrl+M** 으로 다음 장의 템플릿을 고르며 이어 간다. **Ctrl+D** 는 지금 장을 복제한다.

있는 md 문서는 사이드바에서 우클릭해 **Lectern 슬라이드로 바꾸기 요청**을 고르면 Claude 가 같은 폴더에 새 파일로 만든다. 자세한 순서는 [템플릿으로 만들기](../slides/기초/03-템플릿으로-만들기.md).

## 고치기

[한 줄 편집](08-한-줄-편집.md)과 같은 키를 쓴다 — **F2** 로 열고 **Enter** 로 저장, **Insert** 로 고르고 **Alt+↑·↓** 로 옮기고, **Ctrl+Z** 로 되돌린다. 줄을 옮기거나 지워도 칸과 장은 깨지지 않는다. 슬라이드에만 있는 것은 이렇다.

| 하는 일 | 키·메뉴 |
|---|---|
| 장 옮기기 | **Ctrl+Shift+PageUp·PageDown**, 또는 장 제목 줄을 고르고 **Alt+↑·↓** |
| 칸 꾸밈·맞바꾸기·비우기 | 칸의 글을 우클릭 |
| 배치 바꾸기 | 슬라이드를 우클릭 → **배치 넣기…**, **템플릿 바꾸기…** |
| 차트 값 고치기 | 차트에서 **F2** — 값이 표로 나온다 |
| 넘친 칸 | 우클릭 → **넘친 줄을 다음 장으로** |
| 구성 요소의 글자 크기 | 현재 줄에서 **Ctrl+Shift+>·<** |
| 숨은 줄(배치·칸 머리·노트) | 상태줄의 **구조 보기**를 켜고 꼬리표에서 **F2** |
| 발표자 노트 | 우클릭 → **발표자 노트 쓰기…** |

키는 [키 연습장](../slides/기초/04-키-연습장.md)에서 손에 익힌다. 칸과 배치는 [칸과 배치](../slides/기초/02-칸과-배치.md)에 있다.

## 발표와 전환

- 상태줄의 **발표**(Shift+F5)로 지금 장부터 창 전체에 한 장씩 보인다. **N** 은 발표자 노트, **Esc** 는 끝내기.
- 상태줄의 **점검**은 넘치거나 잘못 쓴 곳을 모아 보인다. 고르면 그 줄로 간다.
- 상태줄의 **pptx 로 전환**으로 pptx 스타일을 골라 PowerPoint 파일을 만든다. 문서 옆에 새 파일로 만들고 덮어쓰지 않는다.
- pptx 를 Lectern 슬라이드로 옮기거나 회사 양식으로 내보내는 일은 Claude Code 의 스킬에게 시킨다 — 사용설명서의 'Claude 에게 시키기'.

# 업무 관리

폴더마다 `WORK.md` 하나를 두면, Lectern 이 여러 폴더의 상태·마감·할 일·일정을 **업무 현황** 한 곳에 모아 보이고 일정을 알린다. 폴더 안의 폴더에도 둘 수 있어서 프로젝트의 WORK.md 가 하위 업무들을 총괄한다 (7~10절). WORK.md 는 Claude 없이도 쓰고 고칠 수 있는 보통 Markdown 이고, Claude 가 읽고 써도 같은 규칙으로 돌아간다.

> [!IMPORTANT]
> 설치한 예제는 보기만 하는 폴더라 업무 현황에 들어가지 않고 여기서는 고쳐지지 않는다. 따라 해 보려면 `samples` 폴더를 다른 곳에 복사해 **폴더 열기**로 연다. 그러면 맨 위의 [WORK.md](../WORK.md) 가 업무 카드로 기억된다.
>
> 복사본 안의 `guide/업무-나무-예제` 에도 WORK.md 가 여섯 개 있다. 복사본을 열면 그것들도 이 과제의 하위 업무로 들어가, 업무 현황의 주의할 것에 '02 리튬 공급'의 막힘과 '하위 마감이 더 늦음'이 보인다. 1~6절만 해 볼 때는 열기 전에 복사본의 `guide/업무-나무-예제` 폴더를 지운다.

## 1. 견본 보기

이 예제 프로젝트의 맨 위에 [WORK.md](../WORK.md) 가 있다. 열어서 모양을 본다.

| 부분 | 견본의 줄 | 업무 현황이 읽나 |
|---|---|---|
| 머리 설정 | `status: 진행`, `priority: 상`, `due: 2026-12-15` | 읽는다 — 상태·우선·마감 |
| 제목 | `# 구리 시장 리서치 자동화` | 읽는다 — 과제 이름 |
| 할 일 | `- [ ] 재고 자료 이어 붙이기 (2026-11-14)` | 읽는다 — 체크 칸과 끝의 기한 |
| 일정 | `- 2026-11-12 14:00-15:00 팀장 1차 보고` | 읽는다 — 오늘 일정과 10분 전 알림 |
| 기획 메모 | `- 장기 전망은 … 11/25 쯤 초안 회의를 잡으면 좋겠다` — 생각나는 대로 | 읽지 않는다 — 체크 칸·날짜를 써도 할 일·일정이 되지 않는다 |
| 현재 상태·결정·기록·자료 | 자유롭게 | 읽지 않는다 — 사람과 Claude 용 |

- 상태 값은 예정·진행·지연위험·막힘·보류·완료·중단 일곱 가지다.
- 기한은 `(11/14)` 처럼 연도를 빼도 된다. 오늘에서 가장 가까운 해로 읽는다.
- 견본의 날짜는 고정이라, 날이 지나면 업무 현황에 '마감 지남'으로 보인다. 그것도 업무 현황이 하는 일이다.
- 날짜는 `2026-11-14` 로 쓰는 것이 기본이지만 `2026.11.14`·`2026/11/14` 도 읽는다.

## 1-1. 오타를 내면 — 확인할 줄

복사한 예제의 WORK.md 에서 일부러 틀려 본다. 줄은 사라지지 않고, 업무 현황 아래의 **확인할 줄**에 모인다. 누르면 그 줄로 간다.

| 이렇게 틀리면 | 업무 현황에서 |
|---|---|
| `status: 진핸` | 상태 칸에 '진핸'이 기울여 보이고 확인할 줄에 '정해진 상태 값이 아닙니다' |
| `stauts: 진행` | 확인할 줄에 '키 이름이 틀린 것 같습니다 (status)' |
| 할 일 끝의 `(11/31)`·`(11/14` | 할 일은 남고 기한만 빠진다. 확인할 줄에 '할 일의 기한을 읽지 못했습니다' |
| `- [] 할 일` | 할 일로 세지 않고 확인할 줄에 '체크 칸 모양이 아닙니다' |
| `- 2026-11-12 25:00 회의` | 시각 없는 일정으로 남고 확인할 줄에 '시각을 읽지 못해…' |
| 맨 앞 `---` 의 짝을 지움 | 상태·마감이 '값 없음'이 되고 확인할 줄에 '머리 설정이 닫히지 않았습니다' |

## 2. 업무 카드 만들기

1. 복사한 예제를 연 뒤, 맨 위의 `WORK.md` 를 지우거나 이름을 바꿔 둔다 (없을 때만 만든다).
2. 프로젝트 탭을 우클릭해 **업무 카드 만들기…** 를 고른다.
3. 제목·마감·우선을 정하고 **만들기**. 기본 틀로 `WORK.md` 가 생기고 열린다.
4. 머리 설정을 우클릭해 **문서 정보 고치기**로 상태를 `진행` 으로 바꾼다.

## 3. 업무 현황

1. 툴바의 **업무** 버튼이나 **Alt+W** 를 누른다.
2. 처음이면 **공통 폴더**를 고른다. 과제 밖의 일정·할 일을 적는 WORK.md 와 정리 문서를 두는 보통 폴더다 (예: `문서\Lectern 업무`).
3. 공통 폴더가 탭으로 열리고, 폴더 개요 맨 위에 업무 현황이 보인다. **공통 WORK.md 만들기**를 눌러 공통 WORK.md 를 만든다.
4. 과제 표의 줄을 누르면 그 폴더를 탭으로 열고 WORK.md 를 연다. 탭을 닫아도 업무 현황에는 남는다.

| 무리 | 들어가는 과제 |
|---|---|
| 주의할 것 | 막힘·지연위험, 마감이 지났거나 3일 안, 진행인데 14일 넘게 WORK.md 가 안 바뀐 것 |
| 진행·예정 | 마감이 빠른 차례 |
| 보류 | |
| 완료·중단 | 접혀 있다 |

## 4. 일정 더하기

1. **Alt+S** (업무 현황의 **일정 더하기**).
2. 날짜(오늘·내일·요일 단추), 시각, 내용, 넣을 곳(공통 또는 과제)을 정한다. 아래에 넣을 줄이 미리 보인다.
3. **넣기**(Enter). 고른 WORK.md 의 '일정' 절 끝에 한 줄이 들어간다. 오른쪽 아래의 **되돌리기**로 뺄 수 있다 — 그 뒤에 파일을 고쳤으면 고친 글을 지키려고 되돌리지 않는다.
4. 내용을 비우거나 끝나는 시각을 시작보다 앞으로 하면 넣지 않고 까닭을 보인다.

WORK.md 에서 직접 써도 된다 — '일정' 절의 마지막 줄에서 Ctrl+Enter 로 새 줄을 열고 `- 2026-11-14 10:00 팀 회의` 를 쓴다.

## 5. 알림

Lectern 이 켜져 있는 동안 창 오른쪽 아래에 뜨고, 닫을 때까지 남는다.

- 켤 때 **오늘의 업무** — 마감 지남·오늘·3일 안, 기한이 지났거나 오늘인 할 일, 오늘 일정, 확인할 줄. 알릴 것이 없으면 띄우지 않는다.
- 시각이 있는 일정의 **10분 전**, 한 번. 이미 시작한 일정은 알리지 않는다 (절전에서 깨어나도 지난 알림이 몰리지 않는다).
- 17:30 이 지나면 **오늘 기록이 없는 진행 중 과제**.

설정 창(Ctrl+,)의 **업무 알림**으로 끈다. Windows 알림은 쓰지 않으므로 Lectern 을 끄면 알림도 없다.

## 6. Claude 와 함께

설정 창의 **Claude Code 에 Lectern 알려 주기**로 작성 안내를 주면 Claude 가 같은 형식으로 WORK.md 를 쓴다. 터미널의 Claude Code 에 이렇게 말한다.

- "이 폴더의 WORK.md 를 만들어 줘"
- "회의 메모에서 할 일을 뽑아 WORK.md 의 할 일에 넣어 줘"
- "오늘 한 일을 WORK.md 의 기록 절에 적어 줘"

### 6-1. 기획 메모를 반영해 달라고 하기

WORK.md 의 **기획 메모** 절에는 정리하지 않은 생각을 그대로 적는다. 견본의 기획 메모에 세 줄이 있다 — 체크 칸 줄도 메모 안이라 업무 현황의 할 일로 세지 않는다.

1. 복사한 예제에서 WORK.md 를 열고 기획 메모에 한 줄을 더 쓴다 — 예: `- 다음 주 월요일 오전 10시에 팀장 2차 보고`.
2. 문서 여백을 우클릭해 **기획 메모 반영 요청**을 고른다. 요청 글이 터미널에 들어간다 (Enter 는 누르지 않는다).
3. Enter 를 누르면 Claude 가 작성 안내대로 옮긴다 — 날짜가 정해진 보고는 '일정'에, 할 일은 '할 일'에. '11/25 쯤'처럼 분명하지 않은 날짜는 짐작하지 않고 묻는다.
4. 기록 절에 '기획 메모에서 … 반영' 한 줄이 남는다. 메모 글은 그대로 있으니, 옮긴 줄은 직접 지운다.

표 1. 기획 메모를 옮기는 곳

| 메모에 적은 것 | 옮겨 가는 곳 |
|---|---|
| 해야 할 일 | 할 일 — `- [ ] 내용 (기한)` |
| 날짜·시각이 정해진 약속 | 일정 — `- YYYY-MM-DD HH:MM 내용` |
| 정한 것 | 결정 |
| 지금 형편 | 현재 상태 |
| 아직 생각 중인 것 | 메모에 그대로 |

## 7. 업무 나무 — 폴더 안의 폴더

프로젝트 폴더의 WORK.md 는 전체를 총괄하고, 하위 폴더의 WORK.md 는 그 안의 일 하나를 맡는다. 그 사이에 하위 업무 여러 개를 하나처럼 묶는 폴더를 둘 수 있다. 이 가이드 옆의 [업무 나무 예제](업무-나무-예제/README.md) 가 그 모양이다.

```text
2026 원자재 리서치/        WORK.md   총괄 — 상태를 비워 하위에서 셈
├─ 이슈리포트/             WORK.md   묶음 — 상태를 비워 하위에서 셈
│  ├─ 01-구리-관세/        WORK.md   완료
│  ├─ 02-리튬-공급/        WORK.md   막힘
│  └─ 03-니켈-재고/        WORK.md   진행 (마감이 묶음보다 늦다)
└─ 정기보고/               WORK.md 없음 — 건너뜀
   └─ 주간/                WORK.md   진행 — 총괄 바로 아래
```

그림 1. 예제의 업무 나무

- **부모는 가장 가까운 위 폴더의 WORK.md** 다. 위의 '주간'은 '정기보고'에 WORK.md 가 없어 총괄 바로 아래에 붙는다.
- **상위에서 모아 본다.** 하위의 내용은 상위 파일에 옮겨 적지 않는다. Lectern 이 업무 현황, 총괄·묶음 폴더의 폴더 개요('이 폴더의 업무'), 상위 WORK.md 아래의 **하위 업무** 칸(파일에는 없다)에 모아 보인다.
- **상태를 비워 두면(`status:`) 하위에서 셈한다.** 예제의 이슈리포트 묶음은 02 가 막혀 '막힘*', 총괄도 '막힘*' 이 된다 (`*` 는 셈한 값). 적어 두면 적은 값을 따른다.
- **주의할 것**은 나무의 어느 깊이에 있든 업무 현황 맨 위에 경로와 함께 모인다 — '2026 원자재 리서치 › 하반기 이슈리포트 › 02 리튬 공급'. 03 의 마감이 묶음 마감보다 늦어 묶음에 '하위 마감이 더 늦음'도 붙는다.
- 하위 폴더에 업무 카드를 만들려면 사이드바에서 그 폴더를 우클릭해 **이 폴더에 업무 카드 만들기…**. 종류는 '작은 업무'(할 일·일정·기록만)가 기본이고, 묶음이면 '묶음·총괄'(상태를 비움)을 고른다.

## 8. 상위에서 고치기

업무 현황이나 묶음의 폴더 개요, 상위 WORK.md 아래의 하위 업무 칸에서 고르면 **그 업무의 WORK.md 한 줄**이 고쳐진다. 하위 파일을 일일이 열지 않아도 된다.

표 2. 상위에서 고치기

| 하고 싶은 것 | 누르는 곳 | 바뀌는 줄 |
|---|---|---|
| 02 리튬을 '진행'으로 | 02 줄의 상태 칸 → 진행 | 02 의 `status: 진행` |
| 02 의 마감을 하루 늦추기 | 마감 칸 → 달력에서 → 한 번, Enter | 02 의 `due:` |
| '공급사 자료 받기'를 했다고 | 할 일 칸(2 / 2) → 펼친 목록의 체크 칸 | 그 줄의 `[x]` |
| 할 일 하나 더하기 | 펼친 목록 아래 '할 일 더하기' 칸 → 쓰고 Enter | 02 의 '할 일' 절 끝에 한 줄 |
| 묶음을 다시 하위에서 셈하게 | 묶음 줄의 상태 칸 → 비우기 — 하위에서 셈 | 묶음의 `status:` |

- 고치기 전에 그 파일을 다시 읽는다. 그사이 그 줄을 다른 데서(Claude 가) 고쳤으면 쓰지 않고 알린다.
- 할 일의 글이나 기록 같은 글은 펼친 목록의 'n행' 단추로 그 WORK.md 의 그 줄을 열어 고친다.

## 9. 칸반

나무 위의 **목록 · 칸반**에서 칸반을 고른다. 하위가 없는 업무(01·02·03·주간)가 상태 다섯 칸에 카드로 놓이고, 묶음은 카드 위의 경로로 보인다.

1. 03 니켈 카드를 '보류' 칸으로 끌어 놓는다 → 03 의 WORK.md 가 `status: 보류` 가 된다.
2. 주간 카드를 '주의' 칸에 놓으면 막힘·지연위험 가운데 고르라고 묻는다.
3. 카드를 누르면 그 WORK.md 가 열린다 — 하위 폴더를 따로 열지 않고 총괄 프로젝트의 탭에서.

## 10. 달력 입력

날짜를 넣는 곳(업무 카드의 마감, 일정 더하기의 날짜, 나무의 마감·기한)에서 달력이 뜬다. 날짜 칸에서는 옆의 달력 단추나 **Ctrl+;**.

- ←→ 하루, ↑↓ 한 주, PageUp·PageDown 한 달, T 오늘, Enter 고르기, Esc 는 달력만 닫는다.
- '오늘·내일·이번 주 금요일·다음 주 월요일' 단추가 있고, 마감·기한·일정이 있는 날에는 점이 찍힌다.
- 문서를 고치는 중에도 **Ctrl+;** — 한 줄 편집 칸이나 편집 모드에서 커서 자리에 `2026-12-18` 처럼 들어간다. 할 일 줄 끝의 기한 `(…)` 을 쓸 때 쓴다. 넣기 창(/)의 **날짜** 도 같다.

## 11. 예제로 해 보기

1. `samples` 복사본을 그대로 열어 두었다면 이 예제는 이미 그 과제의 하위 업무로 들어가 있다 ('구리 시장 리서치 자동화' 아래). 그 탭에서 4번부터 한다.
2. 따로 해 보려면 이 가이드 옆의 `업무-나무-예제` 폴더만 내 문서 폴더 같은 곳에 복사한다 (설치한 예제는 보기만 하는 곳이다). 두 곳을 함께 열면 같은 나무가 두 벌 보인다.
3. 복사한 곳의 `2026 원자재 리서치` 폴더를 **폴더 열기**로 연다 — 하위 폴더의 WORK.md 다섯 개도 업무 폴더 목록에 들어간다.
4. **Alt+W** — 업무 현황의 나무에서 그림 1 의 모양과 '막힘*' 을 본다.
5. 표 2 의 고치기를 해 보고, 그 하위 WORK.md 를 열어 그 줄만 바뀐 것을 본다.
6. `이슈리포트/WORK.md` 를 연다 — 문서 아래에 하위 업무 칸이 있다. 칸반으로 바꿔 카드를 옮겨 본다.

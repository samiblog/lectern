# 업무 관리

폴더마다 맨 위에 `WORK.md` 하나를 두면, Lectern 이 여러 폴더의 상태·마감·할 일·일정을 **업무 현황** 한 곳에 모아 보이고 일정을 알린다. WORK.md 는 Claude 없이도 쓰고 고칠 수 있는 보통 Markdown 이고, Claude 가 읽고 써도 같은 규칙으로 돌아간다.

> [!IMPORTANT]
> 설치한 예제는 보기만 하는 폴더라 업무 현황에 들어가지 않고 여기서는 고쳐지지 않는다. 따라 해 보려면 `samples` 폴더를 다른 곳에 복사해 **폴더 열기**로 연다. 그러면 맨 위의 [WORK.md](../WORK.md) 가 업무 카드로 기억된다.

## 1. 견본 보기

이 예제 프로젝트의 맨 위에 [WORK.md](../WORK.md) 가 있다. 열어서 모양을 본다.

| 부분 | 견본의 줄 | 업무 현황이 읽나 |
|---|---|---|
| 머리 설정 | `status: 진행`, `priority: 상`, `due: 2026-12-15` | 읽는다 — 상태·우선·마감 |
| 제목 | `# 구리 시장 리서치 자동화` | 읽는다 — 과제 이름 |
| 할 일 | `- [ ] 재고 자료 이어 붙이기 (2026-11-14)` | 읽는다 — 체크 칸과 끝의 기한 |
| 일정 | `- 2026-11-12 14:00-15:00 팀장 1차 보고` | 읽는다 — 오늘 일정과 10분 전 알림 |
| 현재 상태·결정·기록·자료 | 자유롭게 | 읽지 않는다 — 사람과 Claude 용 |

- 상태 값은 예정·진행·지연위험·막힘·보류·완료·중단 일곱 가지다.
- 기한은 `(11/14)` 처럼 연도를 빼도 된다. 오늘에서 가장 가까운 해로 읽는다.
- 견본의 날짜는 고정이라, 날이 지나면 업무 현황에 '마감 지남'으로 보인다. 그것도 업무 현황이 하는 일이다.

## 2. 업무 카드 만들기

1. 복사한 예제를 연 뒤, 맨 위의 `WORK.md` 를 지우거나 이름을 바꿔 둔다 (없을 때만 만든다).
2. 프로젝트 탭을 우클릭해 **업무 카드 만들기…** 를 고른다.
3. 제목·마감·우선을 정하고 **만들기**. 기본 틀로 `WORK.md` 가 생기고 열린다.
4. 머리 설정을 우클릭해 **문서 정보 고치기**로 상태를 `진행` 으로 바꾼다.

## 3. 업무 현황

1. 툴바의 **업무** 버튼이나 **Alt+W** 를 누른다.
2. 처음이면 **공통 폴더**를 고른다. 과제 밖의 일정·할 일을 적는 WORK.md 와 정리 문서를 두는 보통 폴더다 (예: `문서\Lectern 업무`).
3. 공통 폴더가 탭으로 열리고, 폴더 개요 맨 위에 업무 현황이 보인다. **공통 WORK.md 만들기**를 눌러 공통 WORK.md 를 만든다.
4. 과제 표의 줄을 누르면 그 폴더를 탭으로 열고 WORK.md 를 연다. 탭을 닫아도 업무 현황에는 남는다.

| 무리 | 들어가는 과제 |
|---|---|
| 주의할 것 | 막힘·지연위험, 마감이 지났거나 3일 안, 진행인데 14일 넘게 WORK.md 가 안 바뀐 것 |
| 진행·예정 | 마감이 빠른 차례 |
| 보류 | |
| 완료·중단 | 접혀 있다 |

## 4. 일정 더하기

1. **Alt+S** (업무 현황의 **일정 더하기**).
2. 날짜(오늘·내일·요일 단추), 시각, 내용, 넣을 곳(공통 또는 과제)을 정한다. 아래에 넣을 줄이 미리 보인다.
3. **넣기**. 고른 WORK.md 의 '일정' 절 끝에 한 줄이 들어간다. 오른쪽 아래의 **되돌리기**로 뺄 수 있다.

WORK.md 에서 직접 써도 된다 — '일정' 절의 마지막 줄에서 Ctrl+Enter 로 새 줄을 열고 `- 2026-11-14 10:00 팀 회의` 를 쓴다.

## 5. 알림

Lectern 이 켜져 있는 동안 창 오른쪽 아래에 뜨고, 닫을 때까지 남는다.

- 켤 때 **오늘의 업무** — 마감 지남·오늘·3일 안, 기한이 지났거나 오늘인 할 일, 오늘 일정.
- 시각이 있는 일정의 **10분 전**.
- 17:30 이 지나면 **오늘 기록이 없는 진행 중 과제**.

설정 창(Ctrl+,)의 **업무 알림**으로 끈다. Windows 알림은 쓰지 않으므로 Lectern 을 끄면 알림도 없다.

## 6. Claude 와 함께

설정 창의 **Claude Code 에 Lectern 알려 주기**로 작성 안내를 주면 Claude 가 같은 형식으로 WORK.md 를 쓴다. 터미널의 Claude Code 에 이렇게 말한다.

- "이 폴더의 WORK.md 를 만들어 줘"
- "회의 메모에서 할 일을 뽑아 WORK.md 의 할 일에 넣어 줘"
- "오늘 한 일을 WORK.md 의 기록 절에 적어 줘"

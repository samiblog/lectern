# 처음 둘러보기

Lectern 은 프로젝트 폴더의 Markdown·HTML 문서를 **읽기 좋게** 보여 주는 앱이다. Claude Code 가 만든 문서를 사람이 한눈에 훑어보는 데 맞춰져 있다. 이 문서를 따라 화면을 한 바퀴 돌아보자.

## 화면 구성

| 자리 | 하는 일 |
|---|---|
| 툴바 (맨 위) | 사이드바 보이기·숨기기, 뒤로·앞으로, **문서 열기**(Ctrl+P), 글자 크기 − 100% +, 스타일, 장 하이라이트, 설정, 단축키, 터미널 모음 |
| 탭 막대 | 프로젝트 폴더마다 탭 하나. **+** 로 다른 폴더를 새 탭으로, 오른쪽 끝에 **편집**·**목차**·**터미널** 버튼 |
| 사이드바 (왼쪽) | **파일**(문서·코드·자료 묶음) · **최근 변경** · **검색** · **모아 보기** |
| 문서 (가운데) | 고른 문서·코드·폴더 개요 |
| 목차 (오른쪽) | 제목과 그 절의 표·그림·박스글·다이어그램. 지금 읽는 절이 강조된다 |
| 상태줄 (맨 아래) | 파일 경로, **편집** 버튼, 수정 시각, 바뀐 곳, 변경 감시 |

## 해 보세요

- [ ] 왼쪽 트리에서 `plans` 폴더 **이름**을 누른다 — 폴더 개요(문서마다 제목·요약·수정 시각)가 나온다
- [ ] **Ctrl+P** 를 누르고 `동향` 을 친 뒤 Enter — 이름·제목·경로로 문서를 바로 연다
- [ ] **Alt+←** 로 이 문서로 돌아온다 (마우스의 뒤로 버튼도 된다)
- [ ] 오른쪽 목차에서 '단축키'를 누른다 — 그 절로 간다
- [ ] 사이드바 위의 **제목** 버튼 — 트리가 파일 이름 대신 문서 제목으로 바뀐다
- [ ] 사이드바의 **코드** 묶음에서 `src/report.py` 를 한 번 누른다 — 줄 번호·언어 색의 읽기 화면, 오른쪽 목차에는 함수가 나온다
- [ ] **F1** — 사용설명서, **Ctrl+/** — 단축키 표

> [!TIP]
> 위 체크 칸은 표시만 한다(누를 수 없다). Lectern 은 문서를 고치지 않는 **보기 앱**이다 — 고칠 때만 [편집 모드](03-Claude-Code와-함께.md#편집-모드)를 연다.

## 사이드바의 세 묶음

**파일** 탭은 위에서부터 세 묶음이다.

1. **문서** — Markdown·HTML 문서의 트리. 한 번 누르면 연다.
2. **코드** — `.py`·`.js`·`.json` 같은 소스·설정 파일. 한 번 누르면 읽기 화면, 두 번 누르면 편집기(VS Code 등).
3. **자료** — 그 밖의 파일(`data/월별-가격.csv`, PDF, 엑셀 …). csv·txt 는 한 번 누르면 Lectern 에서 본다 — csv 는 표로, 열마다 거르기·정렬·통계. 두 번 누르면 기본 앱으로 연다. 실행 파일은 실행하지 않고 탐색기에서 선택만 한다.

**폴더** 버튼을 켜면 세 묶음 대신 폴더 구조 그대로 한 트리로 본다.

## 보이지 않는 것

이름이 `.` 으로 시작하는 파일·폴더, Windows 숨김 파일, `node_modules`·`dist`·`build` 같은 폴더, 문서가 없는 폴더는 문서 트리에 나오지 않는다. `src`·`web` 같은 앱 소스 폴더의 html 도 문서로 보지 않는다.

## 단축키

| 키 | 하는 일 |
|---|---|
| Ctrl+P | 문서·코드 빠르게 열기 |
| Ctrl+F | 지금 화면에서 찾기 |
| Ctrl+Shift+F | 모든 문서·코드에서 찾기 (사이드바 '검색') |
| Alt+← / Alt+→ | 뒤로 / 앞으로 |
| Ctrl+B | 사이드바 보이기·숨기기 |
| Ctrl+E | 편집 모드 열기·닫기 |
| Ctrl+` | 터미널 열기·닫기 |
| F5 | 다시 불러오기 |
| F1 / Ctrl+/ | 사용설명서 / 단축키 표 |

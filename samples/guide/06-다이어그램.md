# 다이어그램

코드 블록의 언어를 `mermaid` 로 적으면 그림으로 바뀐다 (Mermaid). 색은 문서 스타일을 따르고, 누르면 크게 보며, 우클릭 '그림 복사'로 PNG 를 워드·PPT 에 붙인다. 목차와 모아 보기에는 '다이어그램'으로 나온다.

~~~~md
```mermaid
flowchart LR
    A[자료 수집] --> B[요약 작성] --> C{검토}
```
~~~~

## 흐름도

```mermaid
flowchart LR
    A[자료 수집<br/>collect.py] --> B[(월별-가격.csv)]
    B --> C[요약·차트<br/>report.py]
    C --> D{사람 검토}
    D -->|승인| E[배포]
    D -->|수정| C
```

## 시퀀스

```mermaid
sequenceDiagram
    participant U as 사람
    participant C as Claude Code
    participant F as 프로젝트 폴더
    U->>C: 2분기 보고서를 만들어 줘
    C->>F: research/구리-시장-동향.md 저장
    F-->>U: Lectern 이 바로 다시 그림
    U->>C: 표 단위를 바꿔 줘
```

## 일정 (간트)

```mermaid
gantt
    title 리서치 자동화 일정
    dateFormat YYYY-MM-DD
    section 수집
    스크립트 정리      :done,    a1, 2026-05-04, 10d
    재고 주 단위        :active,  a2, 2026-07-06, 14d
    section 보고서
    요약 자동 작성      :         b1, 2026-06-01, 21d
    배포 절차           :         b2, after b1, 7d
```

## 상태

```mermaid
stateDiagram-v2
    [*] --> 초안
    초안 --> 검토: 작성 끝
    검토 --> 초안: 수정 요청
    검토 --> 배포: 승인
    배포 --> [*]
```

## 마인드맵

```mermaid
mindmap
  root((구리 수요))
    전력
      송배전
      발전
    건설
      주거
      상업
    운송
      전기차
```

## 타임라인

```mermaid
timeline
    title 2026년 상반기
    1월 : 수집 스크립트 시작
    3월 : 월별 CSV 완성
    5월 : 리서치 문서에 차트
    6월 : 주간 보고서 초안
```

## Mermaid 의 차트

간단한 막대·꺾은선(`xychart-beta`), 원형(`pie`), 흐름량(`sankey-beta`)도 Mermaid 로 된다. 한글 축 이름은 따옴표로 감싼다. 데이터가 많거나 모양을 자세히 정하려면 [차트](07-차트.md)의 Vega-Lite·ECharts·Plotly 를 쓴다.

```mermaid
xychart-beta
  title "월평균 가격 (USD/t)"
  x-axis ["1월", "2월", "3월", "4월", "5월", "6월"]
  y-axis "USD/t" 10000 --> 11500
  bar [10620, 10290, 10870, 11040, 10760, 11220]
  line [10620, 10290, 10870, 11040, 10760, 11220]
```

```mermaid
pie title 용도별 구리 수요 (%)
    "전력" : 42
    "건설" : 26
    "운송" : 20
    "기타" : 12
```

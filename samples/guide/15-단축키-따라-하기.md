# 단축키 따라 하기

키보드로 문서를 열고, 읽고, 고르고, 고치고, Claude 에 보내는 흐름을 차례로 해 본다. 절마다 5분쯤 걸린다. 키를 누르는 문서는 [단축키 연습](단축키-연습/연습-문서.md)이다. 모든 키는 **Ctrl+/** 의 단축키 표에 있다.

> [!IMPORTANT]
> 1~4절은 설치한 예제에서 그대로 된다. 5절부터는 문서를 고치므로 `samples` 폴더를 다른 곳에 복사해 **폴더 열기**로 연 뒤 한다 (설치한 예제는 보기만 하는 폴더라 고쳐지지 않고 터미널도 열리지 않는다).

> [!TIP]
> 글자 키가 듣지 않으면 문서의 글을 한 번 누른다. 초점이 사이드바나 입력 칸에 있으면 문서의 키가 듣지 않는다. 한글 입력 상태여도 글자 키는 듣는다.

## 1. 열기와 오가기

1. **Ctrl+P** 를 누르고 `연습` 을 친 뒤 **Enter**. 연습 문서가 열린다.
2. **Ctrl+P** 로 `처음` 을 쳐서 [처음 둘러보기](01-처음-둘러보기.md)도 연다. 문서 칸 위의 문서 탭 줄에 새 탭으로 더해진다.
3. **Ctrl+Shift+Tab** 으로 앞 문서 탭(연습 문서)으로, **Ctrl+Tab** 으로 다음 문서 탭으로 간다. **Alt+1** 은 첫 탭, **Alt+9** 는 마지막 탭이다.
4. 연습 문서에서 **Ctrl+W** 로 그 탭을 닫고, **Ctrl+Shift+T** 로 다시 연다.
5. 연습 문서 첫 줄의 '단축키 따라 하기' 링크를 누른다. 이 가이드로 왔다. **Alt+←** 로 연습 문서로 돌아가고, **Alt+→** 로 다시 온다.
6. **Ctrl+B** 로 사이드바를 숨기고, 한 번 더 눌러 다시 보인다.

| 키 | 하는 일 |
|---|---|
| Ctrl+P | 이름·제목으로 문서 열기 |
| Ctrl+Tab · Alt+1~9 | 문서 탭 오가기 |
| Ctrl+W · Ctrl+Shift+T | 탭 닫기 · 닫은 탭 다시 열기 |
| Alt+← · Alt+→ | 뒤로 · 앞으로 |

## 2. 읽기

1. 연습 문서의 '구리 가격은 3분기에…' 문단을 누른다. 왼쪽에 작은 삼각형이 생긴다 — **현재 줄**이다.
2. **↓** · **↑** 로 현재 줄을 옮긴다. 화면이 따라 내려간다.
3. **Ctrl+F** 를 누르고 `구리` 를 친다. **Enter** 는 다음 곳, **Shift+Enter** 는 앞 곳이다. **Esc** 로 닫는다.
4. **Ctrl+G** 를 누르고 `31` 을 친 뒤 **Enter**. 원문 31행 '- 칠레' 로 간다.
5. **Ctrl+Shift+[** 로 현재 줄이 든 절을 접고, **Ctrl+Shift+]** 로 편다.
6. **Ctrl+=** 를 두 번 눌러 글자를 키우고, **Ctrl+-** 로 줄이고, **Ctrl+0** 으로 100% 로 돌린다.
7. **Alt+L** 로 줄 번호를 보이고, 한 번 더 눌러 감춘다.

## 3. 고르기

1. '구리 재고는…' 문단에서 **Shift+Enter** 를 누른다. 그 줄만 또렷하고 나머지는 흐려진다 — **하이라이트**다. 한 번 더 누르면 꺼진다.
2. 같은 문단에서 **Shift+↓** 를 두 번 누른다. 세 문단이 회색으로 골라진다 — **고른 줄**이다. **Shift+↑** 로 하나 줄인다.
3. **Esc** 로 고르기를 푼다.
4. '9,400달러까지' 를 두 번 눌러 낱말을 고른다. **→** 는 오른쪽 낱말로, **Shift+→** 는 고르기를 넓힌다. **Esc** 로 푼다.
5. 현재 줄에서 **→** 를 누르면 그 줄의 첫 낱말이, **←** 는 마지막 낱말이 골라진다.

## 4. 복사하기

1. '구리 가격은…' 에서 **Shift+↓** 를 한 번 눌러 두 문단을 고른다.
2. **Shift+←** — 위치 `@guide/단축키-연습/연습-문서.md 7~9행` 이 복사된다. 화면 아래에 '복사했습니다' 가 잠깐 뜬다.
3. **Ctrl+C** — 고른 줄의 원문이 복사된다.
4. **Esc** 로 풀고, 낱말 하나를 두 번 눌러 고른 뒤 **Ctrl+C** — 그 낱말이 복사된다.

위치는 Claude Code 같은 AI 도구에 '이 부분'을 가리킬 때 붙여 넣는다 (5절).

## 5. 터미널과 Claude

여기부터는 복사한 `samples` 를 연 탭에서 한다.

1. **Ctrl+\`** 로 오른쪽 터미널을 연다 (\` 는 숫자 1 왼쪽 키). Claude Code 를 쓰면 `claude` 를 쳐서 띄워 둔다.
2. **F6** 으로 문서와 터미널 사이를 오간다.
3. 연습 문서의 '4분기에는…' 문단에서 **Shift+→** 를 누른다. 터미널에 `@guide/단축키-연습/연습-문서.md 11행 ` 이 들어가고 초점이 터미널로 간다. Enter 는 누르지 않았으니 요청을 이어서 쓴다 — 예: "이 문장을 결론 먼저로 고쳐 줘".
4. 여러 곳을 이어서 넣으려면 **Ctrl+Shift+→** — 초점이 문서에 남는다.
5. **Ctrl+\`** 로 터미널을 닫는다. 셸은 계속 돈다.

## 6. 한 줄 편집

1. '이 문장 끝에 낱말을 더해 본다.' 에서 **F2** 를 누른다. 그 자리에 글 칸이 열린다.
2. 글 끝에 ` 더했다` 를 치고 **Enter**. 원문 파일에 바로 저장된다.
3. '이 문장은 아래 줄과…' 에서 **F2**, 글을 조금 고치고 **↓** — 저장하고 아래 줄을 이어서 연다. **Esc** 로 그만둔다.
4. '이 줄 아래에 새 줄을…' 에서 **Ctrl+Enter**. 아래에 새 줄이 열린다. `새 줄이다` 를 치고 **Enter** 하면 저장하고 다음 새 줄이 열린다. 빈 채로 **Enter** 를 누르면 끝난다.
5. **Ctrl+Z** 로 방금 넣은 줄을 되돌리고, **Ctrl+Y** 로 다시 넣는다.
6. 같은 줄에서 **/** 를 누른다 (탭 막대의 **넣기** 단추도 같다). 넣기 창에 다섯 묶음이 열로 보인다 — **→** 로 옆 열, **↓** 로 아래. 다시 **Esc** 로 닫고 **/** 를 눌러 `표` 를 치고 **Enter**, 크기 `3x3` 에서 **Enter** — 캡션 '표 1. 제목' 과 빈 표가 들어가고, 아래에 있던 표는 표 2 가 된다. **Ctrl+Z** 로 뺀다.

> [!NOTE]
> 칸 안에서 **Ctrl+;** 는 달력에서 고른 날짜를, **Ctrl+K** 는 링크를 넣는다. 칸을 연 채 **Alt+↑·↓** 는 그 줄을 옮기고, **Ctrl+Shift+D** 는 복제, **Ctrl+Shift+K** 는 지운다.

## 7. 줄 구조 — 두 번 누르는 키

현재 줄 하나에서 파일을 바꾸는 키는 **두 번** 눌러야 한다. 처음 누르면 그 줄에 띠가 생기고 '한 번 더 누르면 이 줄을 바꿉니다' 가 뜬다. 한 번 더 누르면 바뀐다. **Esc** 는 그만두기다. 읽다가 잘못 누른 키로 파일이 바뀌지 않게 한 규칙이다. 여러 줄을 골랐거나 하이라이트한 줄에서는 한 번에 듣는다.

1. '옮길 줄 하나' 에서 **Alt+↓** 를 두 번 누른다. '옮길 줄 둘' 아래로 내려간다. **Alt+↑** 로 되돌린다.
2. '제목으로 바꿀 줄' 에서 **2** 를 두 번 누른다. 제목 2 가 되고 오른쪽 목차에도 생긴다. **Ctrl+Z** 로 되돌린다.
3. 목록의 '페루' 에서 **Alt+Shift+→** 를 두 번 누른다. '칠레' 의 하위 항목이 된다. **Alt+Shift+←** 로 되돌린다.
4. '중국' 에서 **Shift+Enter** 로 하이라이트하고 **Tab** — 한 번에 한 단계 안으로 간다. **Shift+Tab** 으로 되돌리고 **Shift+Enter** 로 끈다.
5. '이 줄은 지워 본다.' 에서 **Delete** 를 두 번 누른다. 지워진다. **Ctrl+Z** 로 되살린다.
6. '구리 가격은…' 에서 **Shift+↓** 를 두 번 눌러 세 문단을 고르고 **L** — 목록이 된다. **N** 은 번호 목록, **T** 는 할 일, **Q** 는 인용, **C** 는 강조글이다. 같은 키를 다시 누르면 문단으로 돌아간다. **Ctrl+Z** 로 처음으로 되돌린다.

| 키 | 하는 일 |
|---|---|
| Alt+↑ · Alt+↓ | 줄 옮기기 (목록은 하위와 함께) |
| 1~6 · 0 | 제목 1~6 · 문단 |
| L · N · T · Q · C | 목록 · 번호 · 할 일 · 인용 · 강조글 |
| Alt+Shift+→ · ← | 레벨 안 · 밖 (제목은 하위 절까지) |
| Tab · Shift+Tab | 고른 줄의 목록 레벨 (제목은 바꾸지 않음) |
| Delete · Ctrl+X | 지우기 · 원문을 복사하고 지우기 |

## 8. 서식

1. '구리 수요의 절반은…' 에서 '절반은' 을 두 번 눌러 고르고 **B** — 굵게 된다. 다시 **B** 면 풀린다.
2. 그대로 **M** — 형광펜이다. 거듭 누르면 색이 바뀌고 마지막에 풀린다. **F** 는 글자색이다.
3. **Esc** 로 풀고 **F8** — 문서의 다음 형광펜으로 간다. **Shift+F8** 은 앞 형광펜이다.
4. 칸 안에서는 글을 고르고 **Ctrl+B** · **Ctrl+I** · **Ctrl+\`** (코드) 를 쓴다.

아무것도 고르지 않은 현재 줄에서는 B · M 을 눌러도 아무 일이 없다. **Ctrl+B** 는 고른 것이 없으면 사이드바를 감춘다.

## 9. 전체 편집과 도움말

1. **Ctrl+E** 로 연습 문서를 전체 편집으로 연다. 원문이 편집기에 보인다.
2. 편집기에서 **Ctrl+F** 로 찾고, 고친 뒤 **Ctrl+S** 로 저장한다. **Esc** 로 닫는다.
3. **Ctrl+/** 는 단축키 표, **F1** 은 사용설명서, **Shift+F1** 은 예제 프로젝트, **Ctrl+,** 는 설정이다.

## 잘 안 될 때

| 이럴 때 | 이렇게 |
|---|---|
| 글자 키를 눌러도 아무 일이 없다 | 문서의 글을 한 번 눌러 초점을 문서로 옮긴다 |
| '한 번 더 누르면 이 줄을 바꿉니다' 가 뜬다 | 두 번 누르는 키다 — 한 번 더 누르거나 Esc |
| F2 · Ctrl+Enter · / 가 듣지 않는다 | 여러 줄을 고른 동안이다 — Esc 로 풀고 누른다 |
| 고쳐지지 않고 '보기만 합니다' 가 뜬다 | 설치한 예제다 — `samples` 를 복사해 연다 |
| / 를 누르면 찾기가 열린다 | vi 키를 켰다 — 넣기 창은 Ctrl+Shift+/ ([vi 키](10-vi-키.md)) |
| Alt · Ctrl 조합이 듣지 않는다 | 오른쪽 Alt · Ctrl 은 한/영 · 한자 키일 수 있다 — 왼쪽 키로 누른다 |
| Tab 을 누르면 초점이 다른 단추로 간다 | 현재 줄 하나에서는 Tab 이 듣지 않는다 — Shift+Enter 로 하이라이트하거나 Alt+Shift+→ 를 두 번 |

다음: 한 줄 편집의 여러 경우는 [한 줄 편집](08-한-줄-편집.md), vi 에 손이 익었으면 [vi 키](10-vi-키.md).

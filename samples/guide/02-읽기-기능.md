# 읽기 기능

긴 문서를 편하게 읽는 기능들이다. 이 문서는 절이 여럿이라 직접 해 보기 좋다.

## 절 접기

제목(`##`) 왼쪽의 화살표를 누르거나 **Ctrl+Shift+[** 를 누르면 그 절이 접히고, 다시 누르거나 **Ctrl+Shift+]** 를 누르면 펴진다. 제목을 우클릭하면 '같은 수준 모두 접기·펴기'가 있다. 목차에서 접힌 절을 누르면 펴면서 그리로 간다.

> [!TIP]
> 해 보세요: 이 절의 제목 '절 접기' 에 마우스를 올리면 왼쪽에 화살표가 나온다. 화살표를 눌러 접었다가 다시 편다. 제목을 누르고 **Ctrl+Shift+[** · **]** 를 눌러도 된다.

## 장 하이라이트

툴바의 **하이라이트** 버튼을 켜면 한 장(`##` 절)만 또렷하고 나머지는 흐려진다. **↑·↓**(또는 PageUp·PageDown)로 앞뒤 장으로 옮기고, Esc 로 끈다. 발표하듯 한 장씩 읽을 때 좋다.

## 읽으며 표시하기

나중에 다시 볼 곳은 형광펜으로 칠해 둔다. 낱말을 두 번 눌러 고르고 **Shift+→** 로 낱말 단위로 넓힌 뒤 **M** 을 누르면 칠해지고 바로 저장된다. M 을 거듭 누르면 노랑 → 초록 → 분홍 → 하늘 → 풀림이다. '바로 확인할 것'은 노랑, '근거를 더 찾을 것'은 초록처럼 색에 뜻을 정해 두면 다시 볼 때 편하다.

칠한 곳은 사이드바에 모인다. **파일** 탭의 **문서** 아래 **형광펜** 하위 묶음을 펼치면 (처음에는 꺼져 있다 — 하위 묶음의 머리줄을 우클릭해 켠다) 문서마다 칠한 글이 색과 함께 한 줄씩 나오고, 누르면 그 자리로 간다. 문서 안에서는 **F8** 이 다음, **Shift+F8** 이 앞의 칠한 곳이다.

> [!TIP]
> 해 보세요: 예제는 보기만 하므로 여기에 미리 칠해 두었다 — <mark>구리 재고는 3주 연속 줄었다</mark>, <mark class="green">칠레 생산 회복은 4분기 이후로 본다</mark>. 사이드바 **문서** → **형광펜** 을 펼쳐 이 문서의 두 줄을 차례로 누른다. 이 절의 제목을 누르고 **F8** 을 두 번, **Shift+F8** 을 한 번 눌러 본다. 끝나면 **전체**를 눌러 트리로 돌아온다.

칠한 곳(사이드바의 줄이나 F8 로 고른 글)을 우클릭하면 **메모 달기**와 **이 형광펜 지우기**가 있다. 메모 달기는 칠한 글을 제목으로 메모를 만들고, 메모에서 그 자리로 돌아온다 — 그사이 Claude 가 위에 글을 더해 줄이 밀려도 그 글로 찾아간다. 사이드바의 문서 행을 우클릭하면 그 문서의 형광펜을 모두 지운다 (글은 그대로). 칠하기·메모·지우기는 내 프로젝트나 복사한 예제 폴더에서 된다.

## 글자 크기와 스타일

- 툴바의 **− 100% +** 는 문서 글자만 키우고 줄인다 (Ctrl+휠은 앱 화면 전체).
- **스타일** 목록에는 24가지가 있다 — 기본·보고서·사내 문서·논문·잡지·GitHub·다크·Nord 등. 다이어그램과 차트의 색도 따라 바뀐다.
- 설정(Ctrl+,)의 **내 스타일**로 CSS 파일 하나를 직접 만들어 쓸 수도 있다 — 'Claude Code용 요청 복사'를 Claude Code 에 붙이면 만들어 준다.

## 찾기와 검색

| 하고 싶은 것 | 방법 |
|---|---|
| 지금 문서에서 찾기 | **Ctrl+F** — Enter / Shift+Enter 로 다음·이전 |
| 모든 문서·코드에서 찾기 | **Ctrl+Shift+F** 또는 사이드바 **검색** — 결과를 누르면 그 줄로 (초점도 문서로 — 바로 / 로 그 줄 아래에 넣는다) |
| 이름·제목으로 문서 열기 | **Ctrl+P** |
| 트리 거르기 | 사이드바 위 '이름·제목으로 거르기' 칸 |

> [!NOTE]
> 해 보세요: 사이드바 **검색**에 `재고` 를 친다. 리서치 문서·보고서·계획에서 그 말이 든 줄이 모두 나온다.

## 모아 보기

**모아 보기**는 프로젝트(또는 폴더) 전체의 표·그림·차트·박스글·강조글·다이어그램·코드·수식을 종류마다 문서 탭 하나에 실제 모습으로 펼쳐 놓는다. 여러 문서의 표를 문서를 오가지 않고 견준다. 탭 막대의 **모아 보기** 버튼(네모 셋과 줄)을 누르면 열린다 — 폴더 하나만 보려면 그 폴더를 우클릭한다.

| 하려는 일 | 방법 |
|---|---|
| 내용으로 좁히기 | 거르기 칸에 낱말 — 표의 칸·캡션·자료 줄에 그 말이 든 것만 남고, 맞은 낱말이 표시된다 |
| 그 문서로 가기 | 덩어리 위의 출처 줄(절 › 이름 … 줄 번호)을 누른다 — **Alt+←** 로 돌아온다 |
| 거른 것을 넘기기 | **새 문서로**(새 Markdown 문서 하나에) · **Claude Code 에**(위치 목록을 터미널에, Enter 없이) |
| 할 일·링크·출처 | 한 줄씩 — 할 일은 안 한 것부터, 링크는 가리키는 파일이 없으면 '깨짐' |
| 문서 정보·파일 종류 | 위의 단추 — 맨 앞 설정(`status`·`owner` 등)으로 문서를 묶고, CSV·PDF·그림·코드를 형식별로 모은다 |

> 해 보세요: 탭 막대의 **모아 보기** 를 누르고 **표** 를 고른 뒤 거르기 칸에 `구리` 를 친다. 구리가 든 표만 남는다.

## 최근 변경

사이드바 **최근 변경**은 최근에 바뀐 문서·코드·자료를 새것부터 보여 준다. Claude Code 가 방금 무엇을 만들고 고쳤는지 한눈에 본다. 열어 보기 전에 바뀐 문서는 트리에 점이 붙는다.

## 인쇄와 PDF

문서 여백(글이 없는 곳)을 우클릭해 **PDF로 저장…** 이나 **인쇄…** 를 고른다. 탭 막대의 **내보내기** 버튼(위로 향한 화살표)에서 고르는 것도 같다. **내보내기** 창이 뜨고, 화면 스타일과 상관없이 A4 보고서 양식으로 미리 본 뒤 저장하거나 인쇄한다. 접어 둔 절도 펴서 싣는다. 자세한 것은 [보고서와 PDF](12-보고서와-PDF.md)에 있다.

html 문서는 우클릭 메뉴가 **인쇄 / PDF로 저장…** 하나다. PDF 는 프린터에서 'Microsoft Print to PDF'를 고른다.

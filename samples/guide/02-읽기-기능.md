# 읽기 기능

긴 문서를 편하게 읽는 기능들이다. 이 문서는 절이 여럿이라 직접 해 보기 좋다.

## 절 접기

제목(`##`)을 누르면 그 절이 접히고, 다시 누르면 펴진다. 제목을 우클릭하면 '같은 수준 모두 접기·펴기'가 있다. 목차에서 접힌 절을 누르면 펴면서 그리로 간다.

> [!TIP]
> 해 보세요: 이 절의 제목 '절 접기'를 눌러 접었다가 다시 편다.

## 장 하이라이트

툴바의 **하이라이트** 버튼을 켜면 한 장(`##` 절)만 또렷하고 나머지는 흐려진다. **↑·↓**(또는 PageUp·PageDown)로 앞뒤 장으로 옮기고, Esc 로 끈다. 발표하듯 한 장씩 읽을 때 좋다.

## 글자 크기와 스타일

- 툴바의 **− 100% +** 는 문서 글자만 키우고 줄인다 (Ctrl+휠은 앱 화면 전체).
- **스타일** 목록에는 24가지가 있다 — 기본·보고서·사내 문서·논문·잡지·GitHub·다크·Nord 등. 다이어그램과 차트의 색도 따라 바뀐다.
- 설정(Ctrl+,)의 **내 스타일**로 CSS 파일 하나를 직접 만들어 쓸 수도 있다 — 'Claude Code용 요청 복사'를 Claude Code 에 붙이면 만들어 준다.

## 찾기와 검색

| 하고 싶은 것 | 방법 |
|---|---|
| 지금 문서에서 찾기 | **Ctrl+F** — Enter / Shift+Enter 로 다음·이전 |
| 모든 문서·코드에서 찾기 | **Ctrl+Shift+F** 또는 사이드바 **검색** — 결과를 누르면 그 줄로 |
| 이름·제목으로 문서 열기 | **Ctrl+P** |
| 트리 거르기 | 사이드바 위 '이름·제목으로 거르기' 칸 |

> [!NOTE]
> 해 보세요: 사이드바 **검색**에 `재고` 를 친다. 리서치 문서·보고서·계획에서 그 말이 든 줄이 모두 나온다.

## 모아 보기

사이드바 **모아 보기**는 프로젝트(또는 폴더) 전체의 표·그림·박스글·다이어그램·코드·수식을 종류마다 모아 보여 준다. 누르면 그 문서의 그 자리로 간다. 위의 '파일 종류'로 바꾸면 CSV·PDF·그림·코드를 형식별로 모아 본다.

## 최근 변경

사이드바 **최근 변경**은 최근에 바뀐 문서·코드·자료를 새것부터 보여 준다. Claude Code 가 방금 무엇을 만들고 고쳤는지 한눈에 본다. 열어 보기 전에 바뀐 문서는 트리에 점이 붙는다.

## 인쇄와 PDF

문서에서 글이 없는 빈 곳을 우클릭 → **인쇄 / PDF로 저장…**. 화면 장식(사이드바·목차 등)은 빼고, 접어 둔 절도 펴서 인쇄한다. 프린터에서 'Microsoft Print to PDF'를 고르면 PDF 로 저장된다.

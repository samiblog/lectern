      언어 · Language바꾸면 화면을 다시 불러옵니다 (열린 탭·터미널은 그대로)
      스타일 목록 묶기툴바의 스타일 목록을 나누는 방식입니다
      Claude Code 에 Lectern 알려 주기Lectern 에서 잘 보이는 문서를 쓰는 규칙을 적은 작성 안내가 있습니다. 요청 글을 Claude Code 에 붙이면 안내를 읽고 그 프로젝트의 CLAUDE.md 에 규칙을 정리합니다
      내 스타일CSS 파일 하나가 스타일 하나입니다. 스타일 폴더에 저장하면 툴바 스타일 목록 맨 아래 '내 스타일'에 나오고, 고치면 바로 반영됩니다
      터미널 자리터미널 머리줄의 버튼으로도 바꿉니다 (그러면 자동이 아니게 됩니다)
      편집기 경로(editor)·제외 폴더(exclude_dirs)·터미널 셸(terminal_shell)처럼 여기 없는 설정은 파일에서 고칩니다. 저장하면 반영되고, 트리는 F5 를 누르면 다시 불러옵니다.

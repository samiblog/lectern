# 줄 더하기·옮기기·지우기

> 줄을 더하고, 나누고 합치고, 옮기고, 지우고, 복제한다. 누르는 순간 저장되고 Ctrl+Z 한 번으로 되돌아온다.

## 한눈에

| 하려는 일 | 읽는 화면 (현재 줄 · 고른 줄) | 칸 안 |
|---|---|---|
| 아래에 새 줄 | **Shift+Enter** | **Shift+Enter** |
| 위에 새 줄 | **Ctrl+Shift+Enter** | **Ctrl+Shift+Enter** |
| 두 줄로 나누기 | — | 글 가운데서 **Shift+Enter** |
| 윗줄 끝에 잇기 | — | 줄 맨 앞에서 **Backspace** |
| 위 · 아래로 옮기기 | **Alt+↑** · **Alt+↓** | **Alt+↑** · **Alt+↓** |
| 지우기 | **Delete** · 우클릭 **줄 지우기** | **Ctrl+Shift+K** |
| 원문을 복사하고 지우기 | **Ctrl+X** | — |
| 복제 | — | **Ctrl+Shift+D** |
| 목록 레벨 안 · 밖 | **Tab** · **Shift+Tab** (고른 줄) | **Tab** · **Shift+Tab** |

칸에 고친 글이 있으면 먼저 저장하고 바꾼다 — 그래서 되돌리기는 두 걸음이다. 되지 않는 것은 그대로 두고 까닭을 알린다.

## 현재 줄에서는 두 번

파일을 바꾸는 키는 여러 줄을 골랐으면 한 번, 현재 줄 하나면 두 번 누른다. 읽다가 누른 키로 파일이 바뀌지 않게 하려는 것이다.

| 상황 | 동작 |
|---|---|
| 여러 줄을 고른 동안 (하이라이트 포함) · 칸 안 | 한 번에 바꾼다 |
| 현재 줄에서 처음 누름 | 그 줄에 띠가 생기고 상태줄에 `현재 줄 12행 · 바꾸기` — 파일은 그대로 |
| 한 번 더 누름 | 바꾼다 |
| 띠가 있는 동안 | 이어 누르는 키(**Alt+↑** 를 거듭, **Tab**)가 바로 듣는다 |
| **↑** · **↓** · **Esc** · 바깥 누르기 | 그만둔다 |
| 키를 누르고 있기 | 한 번으로 센다 |

이 규칙을 따르는 키는 지우기(**Delete** · **Ctrl+X**), 옮기기(**Alt+↑** · **Alt+↓**), 줄 종류(한 글자 키 · **Ctrl+Alt+숫자**), 레벨(**Alt+Shift+←** · **Alt+Shift+→**)이다. 화면 아래 알림은 Lectern 을 켠 뒤 처음 한 번만 뜬다. 복사 · 위치 복사 · 터미널로 보내기처럼 파일을 바꾸지 않는 키는 바로 한다.

## 새 줄

**Shift+Enter** 는 읽는 화면에서도 칸 안에서도, 문서 중간에서도 끝에서도 같다. **↓** 는 줄을 옮기기만 하고 마지막 줄에서 멈추며, 그때 줄을 더하는 키를 알려 준다. 빈 문서는 **F2** 나 **↓** 로 첫 줄을 연다. 여러 줄을 고른 동안에는 더하지 않는다.

새 줄은 앞 줄의 양식을 물려받는다.

| 어디서 | 새 줄의 양식 |
|---|---|
| 목록 아래 | 같은 표시 — 하위 항목이 있으면 그 뒤에 |
| 번호 목록 아래 | 다음 번호 |
| 인용 · 강조글 아래 | 그 안 |
| 문단 · 제목 아래 | 문단 |
| 표 | 새 행 |
| 차트 · 수식 | 그 앞뒤의 문단 |
| 문단 · 제목 위, 바로 위가 목록 · 인용 · 강조글 | 위 블록을 이어 그 끝에 — 문단이 필요하면 새 줄에서 **Shift+Tab** |
| 목록 항목 · 인용 줄 위 | 그 줄과 같은 양식 — 첫 항목 위면 새 첫 항목 |
| 빈 새 줄에서 넣기 창으로 목록 · 번호 목록 · 할 일 | 바로 위 · 아래의 같은 종류 목록에 붙는다 (번호 목록 아래면 다음 번호) |
| 각주가 있는 문서의 본문 마지막 줄 | 각주 앞에 |
| 표 · 코드 블록 뒤의 문단 | 그 블록에서 **/** — 넣기 창이 블록 뒤에 열린다 (그 블록의 Shift+Enter 는 새 행 · 새 코드 줄) |

새 줄은 글을 쓸 때 파일에 들어간다. 빈 새 줄에서 **Enter** · **Ctrl+Enter** 는 아무것도 넣지 않고 닫는다.

## 목록 끝내기

| 빈 새 항목에서 | 동작 |
|---|---|
| **↓** · **Shift+Tab** | 한 레벨 밖으로 — 맨 바깥이면 문단이 되어 목록이 끝난다 |
| **Tab** | 윗 항목의 하위로 |
| 강조글 안의 빈 새 줄에서 **↓** | 강조글 밖으로 |

## 나누기와 합치기

| 하려는 일 | 키 | 조건 |
|---|---|---|
| 두 줄로 나누기 | 글 가운데서 **Shift+Enter** | 그 자리에서 나눈다 |
| 윗줄 끝에 잇기 | 줄 맨 앞에서 **Backspace** | 문단은 문단끼리, 목록은 목록끼리, 코드는 그 블록 안에서만. 제목과 문단처럼 종류가 다르면 합치지 않는다 |

## 옮기기

| 옮기는 것 | 어디까지 |
|---|---|
| 목록 항목 | 하위 항목과 함께, 같은 목록 안에서 |
| 문단 | 앞뒤 블록과 맞바꾼다 |
| 여러 줄로 나눠 쓴 문단의 한 줄 | 그 문단 안에서 |
| 코드 | 그 블록 안에서 |
| 표의 행 | 머리행 아래에서 |
| 제목 한 줄 | 같은 수준의 앞뒤 절과 본문까지 맞바꾼다 |
| 각주 | 본문과 문서 끝의 각주는 서로 넘어가지 않는다 — 마지막 절을 옮겨도 각주는 그대로 |

옮긴 뒤에도 고른 줄이 따라가서 거듭 옮길 수 있다.

## 지우기와 복제

| 상황 | 동작 |
|---|---|
| 10줄이 넘거나 제목이 들어 있음 | 먼저 묻는다 |
| 지운 뒤 빈 줄이 겹침 | 하나로 줄인다 |
| 지운 항목의 하위 항목 | 지운 항목의 자리로 올린다 |
| 표의 머리행 · 구분 줄만 | 막는다 — 표 전체를 고르면 표째 지운다 |
| 코드 블록 일부와 그 밖의 줄을 함께 | 막는다 — 코드 줄을 모두 고르면 블록째 지운다 |
| 제목 우클릭 **절 지우기** | 본문과 하위 절까지 — 문서 끝의 각주는 남는다 |
| 칸에서 **Ctrl+Shift+D** | 아래에 같은 줄을 만들고 그 줄을 이어서 고친다 — 표의 행은 복제하지 않는다 |
| 전체 편집에서 | **Ctrl+Shift+D** 복제 · **Ctrl+Shift+K** 줄 지우기 — 같은 키 |

## 번호 목록

| 상황 | 동작 |
|---|---|
| 항목을 더하기 · 옮기기 · 지우기 | 뒤 번호를 다시 매긴다 |
| 모두 `1.` 로 쓴 목록 | 그대로 둔다 |
| **Ctrl+Z** | 번호까지 한 번에 돌아온다 |

줄 구조는 코드 화면과 Lectern 슬라이드에서도 된다. HTML 문서 · 자료 파일(CSV · 텍스트 · 엑셀)과 보기만 하는 프로젝트에서는 하지 않는다 — CSV · 텍스트는 편집 모드로 고친다.

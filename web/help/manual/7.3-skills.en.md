# Skills

> Lectern comes with three skills that move between pptx and Lectern slides and make Word files from md documents. They are installed only when you ask, and the AI tool asks first.

A skill is a bundle of work instructions and scripts that an AI tool reads. It uses the SKILL.md format shared by four tools (Claude Code · Codex · Antigravity · OpenCode), so it installs as it is in any of them.

## Included skills

| Skill | What it does |
|---|---|
| `pptx-to-lectern` | Moves a pptx or ppt, or a presentation open in PowerPoint, into Lectern slides. Makes a md document into Lectern slides using a pptx as a model. Makes a pptx style and a template set from a pptx |
| `lectern-to-pptx` | Makes Lectern slides into a pptx — keeping the style, applying only the slides you changed, in a company template |
| `lectern-to-docx` | Makes a md document into Word (docx). The app's **Save as Word…** works without installing the skill |

## Installing

| Step | To do |
|---|---|
| 1 | Under **PowerPoint and Word skills** in the settings window (**Ctrl+,**), choose where to put them — **All folders (personal)** (default) · **Only this folder** |
| 2 | Check the full paths and what happens to each (Create · Change · Unchanged) under **Files that change** below |
| 3 | Paste it with **Copy request for Claude Code**, or put it into the terminal with the **▣** next to it, and press Enter |
| 4 | The AI tool tells you what the skills do and asks whether to install them — say yes and it installs only what is missing or different. The three skills are installed together |
| 5 | When writing in your personal folder (`~/.claude`) or a folder's `.claude`, Claude Code asks for permission once more — allow it if it matches what you saw in Files that change |

| Tool | All folders (personal) | Only this folder |
|---|---|---|
| Claude Code | `~/.claude/skills` | `.claude/skills` |
| Codex | `~/.agents/skills` — `~/.codex/skills`, which requests named up to 0.89, is the old place | `.agents/skills` |
| Antigravity | `~/.gemini/config/skills` | `.agents/skills` |
| OpenCode | `~/.config/opencode/skills` — it also reads `~/.claude/skills`, so skills installed for Claude Code show up without installing again | `.agents/skills` |

Antigravity and Codex may ask before reading a skills folder outside the working folder — allow it and they carry on. **View source** in the settings window shows an installed skill's SKILL.md and the files in its folder exactly as they are.

## How to ask

Lectern does not run the AI tool. You talk to the AI tool in the terminal yourself. `@document.md` is **Copy @path** from a right-click in the tree.

| To do | Example request |
|---|---|
| pptx to Lectern slides | `Move this pptx into Lectern slides: D:\materials\report.pptx` |
| Move an open presentation | `Move the presentation open in PowerPoint into Lectern slides. Put the result in the D:\project\slides folder.` |
| Just md, quickly | `Quickly pull D:\materials\report.pptx into md for now. I'll polish it later.` |
| A md document into slides, using a pptx as a model | `Use D:\templates\company.pptx as a model and make the content of @market-analysis.md into Lectern slides.` |
| Using the pptx on screen as a model | `Use the pptx open on screen as a model and make @market-analysis.md into Lectern slides.` |
| Using only the colors and cover | `Use only the colors and cover of D:\templates\company.pptx and make @weekly.md into at most 10 Lectern slides. Keep the numbers.` |
| A pptx style and template set | `Make a 'Company report' pptx style and template set from D:\templates\company.pptx.` |
| An open presentation as a pptx style | `Add the presentation open in PowerPoint as the 'Company report' pptx style.` |
| One more template | `Add a template with a table and a callout to the 'Company report' set.` |
| Lectern slides to pptx | `Make @deck.md into a pptx, keeping the style as much as you can.` |
| Only the changed slides back to pptx | `I edited @report.md, which came from a pptx. Make the pptx again with just the slides I changed.` |
| In a company template | `Make @deck.md into a pptx using the D:\templates\company.pptx template.` |

More prompt examples are in `_internal\skills\README.md` in the program folder. The Lectern slides writing guide that the AI tool reads is `_internal\web\help\slides.en.md`.

## When moving

| What | How |
|---|---|
| Text | Nothing is left out, and the slides stay as they are |
| Text-centered slides | Rebuilt as cells |
| Diagrams where position carries meaning, like a map | Kept as pictures, with the text in the notes |
| Animations · exact fonts | Not moved |
| The original pptx | Not changed. An open presentation is not saved or closed either |

## What you need

| Case | What happens |
|---|---|
| Python | No need to install it — the skills run on `lectern-skill.exe` in the program folder |
| Without PowerPoint | `.pptx` files can still be moved and exported |
| An open presentation · `.ppt` · DRM files | PowerPoint is needed |
| A password-protected file | Remove the password first |
| A DRM-protected file | Open it in PowerPoint, keep it open and move it from there |

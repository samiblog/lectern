# 모아 보기

> 프로젝트(또는 고른 폴더)의 표·그림·차트를 문서 탭 하나에 실제 모습으로 펼쳐 놓고 견준다. 내용으로 거르고, 거른 것을 새 문서나 AI 도구로 넘긴다.

모아 보기는 **문서 탭 하나**로 열린다. 보던 문서는 그 탭에 그대로 남는다. 처음 열 때는 문서를 읽느라 잠깐 걸린다.

## 여는 길

| 하려는 일 | 방법 |
|---|---|
| 프로젝트 전체 | 탭 막대의 **모아 보기** 단추 — 마지막에 고른 종류로 열린다. 이미 열려 있으면 그 탭으로 간다 |
| 종류를 정해서 | 폴더 개요(탭 막대의 **개요**)의 **모아 보기** 줄에서 종류 (표 · 그림 …) |
| 폴더 하나만 | 그 폴더의 개요에서 같은 줄 · 트리에서 폴더 우클릭 **이 폴더의 표·그림 등 모아 보기** |
| 폴더의 파일을 종류별로 | '코드' · '자료' 목록에서 폴더 우클릭 **이 폴더의 파일을 종류별로 모아 보기** |
| 이름으로 | **Ctrl+Shift+P** (명령 찾기)에서 `모아 보기` |

| 상황 | 열리는 곳 |
|---|---|
| 문서 · 코드를 보던 탭에서 | 새 문서 탭 — 보던 것은 그대로 |
| 폴더 개요에서 | 그 자리 — **Alt+←** 로 개요에 돌아온다 |
| 모아 보기 탭이 이미 열려 있을 때 | 그 탭에서 범위 · 종류만 바뀐다 (프로젝트에 탭 하나) |

## 화면

| 자리 | 무엇 |
|---|---|
| 머리 | 범위(프로젝트 전체 · 폴더 — **전체**를 누르면 프로젝트 전체), 모을 것, 종류 단추 |
| 붙어 있는 줄 | 거르기 칸 · **트리 순서** · **새 문서로** · **Claude Code 에** · 개수 — 스크롤해도 위에 남는다 |
| 목록 | 문서마다 묶음 — 문서 이름 아래에 그 문서의 것 |
| 목차 패널 (오른쪽) | 모은 것의 차례 — 문서와 그 아래 구성 요소. 누르면 그 덩어리로 |

| 모을 것 | 모으는 것 | 고르는 단추 |
|---|---|---|
| **문서 속 요소** | 표 · 그림 · 차트 · 박스글 · 강조글 · 다이어그램 · 코드 · 수식 · 할 일 · 링크 · 출처 | 종류 ('표 7' 처럼) |
| **문서 정보** | 문서 맨 앞 설정(frontmatter)의 값으로 묶은 문서 | 키 |
| **파일 종류** | 문서 · 코드 · 자료 파일을 형식마다 | 형식 ('PDF 2' · '엑셀 3' · 'PNG 10' 처럼) |

## 문서 속 요소

| 종류 | 화면에서 | 아래 단추 |
|---|---|---|
| 표 · 박스글 · 강조글 · 코드 · 수식 | 실제 모습으로 한 줄에 하나 — 캡션과 '주:' · '자료:' 줄도 함께 | — |
| 그림 · 차트 · 다이어그램 | 두세 칸 격자에 실제로 그려서 — 같은 그림을 여러 문서가 쓰면 처음 것 하나에 **+N곳** | — |
| 할 일 | 한 줄씩 — 문서의 체크리스트 (`- [ ]` · `- [x]`) | **안 한 것**(처음) · **한 것** · **모두** |
| 링크 | 한 줄씩 — 대상(문서 · 코드 · 자료 · 폴더 · 인터넷)과 함께. 가리키는 파일이 없으면 붉은 **깨짐** | **깨진 것** · **인터넷** · **프로젝트 안** |
| 출처 | 한 줄씩 — 표 · 그림 아래의 '자료: …' · '출처: …' 줄과 각주 | **출처** · **각주** |

덩어리마다 위에 **출처 줄**이 있다 — 절 이름, '표 3 · 6행 2열' 같은 번호와 크기, 원문 줄 번호. 요소는 묶음이 화면에 가까워질 때 그린다. 이 화면에서는 고치지 않는다 — 고치려면 출처 줄로 그 문서에 간다.

할 일 · 링크 · 출처는 목차에는 나오지 않고 모아 보기에서만 보인다. html 문서의 요소도 펼치지만 그 문서의 스타일은 따라오지 않는다.

## 거르기

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 내용으로 좁히기 | 거르기 칸에 낱말 (`구리`) | 이름 · 절 · 문서와 함께 **표의 칸 · 캡션 · 주·자료 줄 · 코드의 글**에 그 낱말이 든 것만. 맞은 낱말을 표시한다 |
| 낱말 둘 | 띄어 쓴다 (`LME 알루미늄`) | 둘 다 든 것만 |
| 거르기 칸으로 | **Ctrl+F** | 이 화면에서는 찾기 대신 거르기 칸 |
| 첫 덩어리로 | 거르기 칸에서 **Enter** | 초점만 옮긴다 — 한 번 더 누르면 그 문서로 |
| 지우기 | 거르기 칸에서 **Esc** | 모두 다시 보인다 |
| 순서 바꾸기 | **트리 순서** 단추 | 누르면 최근 수정 순 |

그림 · 차트 · 다이어그램은 캡션 · 절 · 대체 글로만 걸린다 (그림 속 글자는 읽지 못한다). 800개가 넘으면 처음 800개만 보인다.

## 그 문서로 가기

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 그 자리로 | 출처 줄 누르기 · 덩어리에서 **Enter** · 한 줄 행 누르기 | 이 탭에서 그 문서의 그 자리로 — 잠깐 테두리로 표시 |
| 모아 보기로 돌아오기 | **Alt+←** | 거르기 · 종류 · 읽던 자리 그대로 |
| 보던 화면을 두고 열기 | **Ctrl+누르기** · 가운데 버튼 | 뒤에서 새 문서 탭에 |
| 그 문서가 다른 탭에 열려 있으면 | 출처 줄 누르기 | 그 탭으로 가서 그 자리로 — 그 탭의 **Alt+←** 는 읽던 곳 |
| 문서와 나란히 보기 | 문서 탭 줄의 **모두 펼치기** | 모아 보기 탭과 문서를 한 화면에 |

## 넘기기

| 단추 | 하는 일 |
|---|---|
| **새 문서로** | 보이는 것을 문서 차례대로 새 Markdown 문서 하나에 — 경로를 정하면 만든다. html 문서의 것은 원문이 없어 빠진다 |
| **Claude Code 에** | 보이는 것의 위치(`@문서 12~19행 ('캡션'), …`)를 터미널에 한 줄로 넣는다 — Enter 는 누르지 않는다. 이어서 '숫자가 다른 곳을 찾아 줘'처럼 할 말을 적는다 |

거른 그대로 넘어간다. 단추 이름은 설정 창 **쓰는 AI 도구**를 따른다 ('Codex 에'). 위치는 100개까지 — 넘으면 거르기로 좁힌다. 넣는 터미널은 최근에 쓴 터미널이다 — [보내기와 요청 글](7.2-보내기와-요청-글.md).

## 우클릭 메뉴

| 항목 | 하는 일 |
|---|---|
| **문서에서 보기** | 그 자리로 (**Enter**) |
| **원문 복사** | md 문서의 그 부분 원문 |
| **위치 복사** | `@문서 12~17행 ('캡션')` |
| **링크 주소 복사** | 링크 항목의 대상 |
| **담기** (**Alt+C**) · **다른 담기함에 담기…** · **문서로 보내기…** | 그 하나를 지금 담기함에 · 고른 담기함에 · 열린 문서 탭이나 새 문서로 바로 — [형광펜·메모·담기](3.5-형광펜-메모-담기.md#담기) |
| **새 메모로 보내기** | 이 프로젝트의 메모에 — 어디서 왔는지도 함께 |
| **보이는 것 모두 담기** | 지금 목록의 것을 문서 차례대로 — 거르기 · 단추로 좁힌 그대로 |
| **@경로 복사** · **전체 경로 복사** | 그 문서의 경로 (**외부 편집기로 열기** · **탐색기에서 보기**도) |

복사 항목 옆의 **▣ 터미널**을 누르면 그 글이 터미널에 들어간다 (Enter 는 누르지 않는다).

## 캡션

| 캡션으로 읽는 것 | 예 |
|---|---|
| 표 · 그림 · 차트 · 다이어그램 바로 위의 한 줄 (그림 아래에 쓴 예전 문서는 아래) | `표 1. …` · `<표 2>` · `[그림 1]` · `〈표 Ⅱ-15〉` |
| 통째로 굵게 쓴 짧은 한 줄 | 바로 위에 |
| html 문서 | `<caption>` · `<figcaption>` |

캡션은 요소와 함께 펼쳐지고, 목차 패널과 AI 도구에 넘기는 위치에도 붙는다.

## 문서 정보

문서 맨 앞 설정(frontmatter — `status: 검토 중` · `owner: 리서치팀` · `tags: [a, b]` 같은 것)으로 문서를 묶는다.

| 상황 | 동작 |
|---|---|
| 키 단추 | 맨 앞 설정의 키마다 하나 |
| 키를 고르면 | 그 키의 값마다 문서를 묶는다 — 날짜는 최근 것부터 |
| 들여 쓴 하위 키 | `author.name` 처럼 점으로 이어 나온다 |
| 그 키가 없는 문서 | 끝의 '값 없음'에 |
| 문서를 누르면 · 우클릭하면 | 연다 · `@경로` 복사와 터미널 |

## 파일 종류

| 상황 | 동작 |
|---|---|
| 형식 단추 | 문서 · 코드 · 자료마다 형식별로 — 고른 형식의 파일이 모인다 |
| 엑셀 · 파워포인트 · 워드 · 한글 | 확장자가 달라도 한 이름으로 센다 |
| 그림 파일 | 작은 그림으로 보인다 |
| 순서 | **트리 순서** 단추 — 누르면 최근 수정한 파일부터 |

## 닫기와 다시 열기

| 상황 | 동작 |
|---|---|
| **Ctrl+W** · 탭의 × | 모아 보기 탭을 닫는다 |
| 다시 열면 | 마지막에 고른 모을 것 · 종류 · 순서로 시작한다 |
| 범위 안의 문서가 밖에서 바뀌면 | 그 문서의 것만 다시 읽어 그린다 — 거르기는 그대로 |
| Lectern 을 다시 실행하면 | 모아 보기 탭은 되살리지 않는다 |

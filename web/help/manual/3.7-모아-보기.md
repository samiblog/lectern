# 모아 보기

> 프로젝트(또는 고른 폴더)의 표·그림·할 일·링크, 문서 정보, 파일을 종류마다 한곳에 모아 보고 누르면 그 자리로 간다.

사이드바 **모아 보기** 탭이다. 맨 위에서 무엇을 모을지 고른다. 처음 열 때는 문서를 읽느라 잠깐 걸린다.

| 보기 | 모으는 것 | 고르는 단추 |
|---|---|---|
| **문서 속 요소** | 표 · 그림 · 차트 · 박스글 · 강조글 · 다이어그램 · 코드 · 수식 · 할 일 · 링크 · 출처 — 종류마다 문서별로 | 종류 ('표 7' 처럼) |
| **문서 정보** | 문서 맨 앞 설정(frontmatter)의 값으로 묶은 문서 | 키 |
| **파일 종류** | 문서 · 코드 · 자료 파일을 형식마다 | 형식 ('PDF 2' · '엑셀 3' · 'PNG 10' · 'PY 12' · 'IPYNB 2' 처럼) |

## 문서 속 요소

| 종류 | 무엇 | 아래 단추 |
|---|---|---|
| 표 · 그림 · 다이어그램 | 캡션이 이름 — 그 아래 '표 3 · 6행 2열' 처럼 번호와 크기 (아래 '캡션') | — |
| 차트 | Vega-Lite · ECharts · Plotly 를 작은 그림으로 — 목록에서 보일 때 그린다 (Graphviz · Mermaid 는 다이어그램) | — |
| 할 일 | 문서의 체크리스트 (`- [ ]` · `- [x]`) | **안 한 것**(처음) · **한 것** · **모두** |
| 링크 | 문서 속 링크와 `src/x.py:42` 같은 경로 표기 — 대상(문서 · 코드 · 자료 · 폴더 · 인터넷)과 함께. 가리키는 파일이 없으면 붉은 **깨짐** | **깨진 것** |
| 출처 | 표 · 그림 아래의 '자료: …' · '출처: …' 같은 줄과 각주 | — |

할 일 · 링크 · 출처는 목차에는 나오지 않고 모아 보기에서만 보인다.

## 캡션

| 캡션으로 읽는 것 | 예 |
|---|---|
| 표 · 그림 · 차트 · 다이어그램 바로 위의 한 줄 (그림 아래에 쓴 예전 문서는 아래) | `표 1. …` · `<표 2>` · `[그림 1]` · `〈표 Ⅱ-15〉` |
| 통째로 굵게 쓴 짧은 한 줄 | 바로 위에 |
| html 문서 | `<caption>` · `<figcaption>` |
| 캡션이 없으면 | 표는 머리행, 그림은 대체 글이 이름 |

## 고르고 가기

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 그 자리로 | 항목 누르기 | 그 문서의 그 자리로 가서 잠깐 테두리로 표시 |
| 보던 문서를 두고 열기 | **Ctrl+누르기** · 가운데 버튼 | 뒤에서 새 문서 탭에 |
| 목록 좁히기 | 거르기 칸 (이름 · 절 · 문서) | 거른 것만 — 800개가 넘으면 처음 800개만 보인다 |
| 순서 바꾸기 | **트리 순서** 단추 | 누르면 최근 수정 순 |
| 폴더 하나만 | 폴더 개요의 **모아 보기** · 트리에서 폴더 우클릭 **이 폴더의 표·그림 등 모아 보기** | 그 폴더와 하위 폴더만 — **전체**를 누르면 프로젝트 전체 |
| 폴더의 파일을 종류별로 | '코드' · '자료' 목록에서 폴더 우클릭 **이 폴더의 파일을 종류별로 모아 보기** | 그 폴더만 |

## 우클릭 메뉴

| 항목 | 하는 일 |
|---|---|
| **문서에서 보기** | 그 자리로 (**Enter**) |
| **원문 복사** | md 문서의 그 부분 원문 |
| **위치 복사** | `@문서 12~17행 ('캡션')` |
| **링크 주소 복사** | 링크 항목의 대상 |
| **담기** · **문서로 보내기…** | 그 하나를 담기 탭에 · 열린 문서 탭이나 새 문서로 바로 — [형광펜·메모·담기](3.5-형광펜-메모-담기.md#담기) |
| **새 메모로 보내기** | 이 프로젝트의 메모에 — 어디서 왔는지도 함께 |
| **보이는 것 모두 담기** | 지금 목록의 것을 문서 차례대로 — 거르기 · 단추로 좁힌 그대로 |
| **@경로 복사** · **전체 경로 복사** | 그 문서의 경로 (**외부 편집기로 열기** · **탐색기에서 보기**도) |

복사 항목 옆의 **▣ 터미널**을 누르면 그 글이 터미널에 들어간다 (Enter 는 누르지 않는다). html 문서의 항목은 원문이 없어 담지 않는다.

## 문서 정보

문서 맨 앞 설정(frontmatter — `status: 검토 중` · `owner: 리서치팀` · `tags: [a, b]` 같은 것)으로 문서를 묶는다.

| 상황 | 동작 |
|---|---|
| 키 단추 | 맨 앞 설정의 키마다 하나 |
| 키를 고르면 | 그 키의 값마다 문서를 묶는다 — 날짜는 최근 것부터 |
| 들여 쓴 하위 키 | `author.name` 처럼 점으로 이어 나온다 |
| 그 키가 없는 문서 | 끝의 '값 없음'에 |
| 문서를 누르면 · 우클릭하면 | 연다 · `@경로` 복사와 터미널 |

## 파일 종류

| 상황 | 동작 |
|---|---|
| 형식 단추 | 문서 · 코드 · 자료마다 형식별로 — 고른 형식의 파일이 모인다 |
| 엑셀 · 파워포인트 · 워드 · 한글 | 확장자가 달라도 한 이름으로 센다 |
| 그림 파일 | 작은 그림으로 보인다 |
| 순서 | **트리 순서** 단추 — 누르면 최근 수정한 파일부터 |

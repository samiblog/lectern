# Document check

> Shows broken structure and places that stray from report structure in an md document as **Check N** in the status bar. Pick one to go to its line; fix the sure ones with **Fix**.

## Where you see it

| Place | What it looks like |
|---|---|
| Status bar | **Check 3** when there is something to check — nothing otherwise |
| Click it | A line number and a one-line note per place, grouped. Pick one to make that line the current line (folded sections and the front matter open) |
| Fix | Only where the change is certain, at the right of the item — it saves, and one **Ctrl+Z** brings it back |
| Below the list | **Paste the list into the terminal** (Enter isn't pressed) · **Copy the list** — to ask an AI tool to fix them |
| Contents | ● beside the heading of a section with something to check |
| Command finder | **Document check** in **Ctrl+Shift+P** |

It checks again every time the document is drawn. The file changes only when you click **Fix**. Lectern slides have their own check — [Presenting and checking](5.2-presenting-and-checking.en.md).

## Broken structure

Places where what is drawn is not what was meant.

| Check | Why | Fix |
|---|---|---|
| An unclosed code block · math block | Everything after it becomes code · math | A closing line before the next heading (or at the end) |
| The front matter has no closing `---` | The front matter shows as body text | `---` after the key lines |
| Rows with different cell counts · a divider row that differs | Cells drop or shift · it is not a table | — |
| A list or text indented 4 spaces or more | It shows as a code block | — |
| A number other than 1 (like `2.`) right under a paragraph | It is not a list and joins the line above | A blank line above (from 1 inside a list) |
| `-` and `*` mixed in one list | The list splits in two | The bullet of the item above |
| `---` right under the text | It becomes a heading, not a rule | A blank line to make it a rule |
| A callout type typo `[!NOTES]` | It shows as a plain quote | The nearest type |
| A footnote with no content · content never used | The number stays as text · the content doesn't show | — |
| A link to a missing section or caption, a missing image file | Clicking goes nowhere · the image is empty | — |

## Report structure

| Check | When | Fix |
|---|---|---|
| A skipped heading level (`####` after `##`) · more than one heading 1 | Always | — |
| A section with no text | Always — task cards (`WORK.md`) are skipped | — |
| The same heading twice | Always — links to it go to the earlier section | — |
| Heading numbers out of order | When the document uses a numbered heading style — unnumbered headings are not counted | Only the numbers of numbered headings |
| Caption numbers out of order | Always | In order — the reference links too |
| A table · figure with no caption | When most tables · figures in the document have captions | An empty caption line |
| A table · figure with no 'Source:' line | When most tables · figures in the document have one | An empty 'Source:' line |
| A list with only a few items separated by blank lines | When separated gaps are not the majority — the whole list shows spaced out | — |

## Writing habits

Seen only when **Writing habits in the document check** is on under 'View' in Settings (**Ctrl+,**) — off by default.

| Check | Limit | Fix |
|---|---|---|
| A long paragraph · sentence · table cell | 600 · 150 · 60 characters | — |
| Two spaces at the end of a line | A hidden line break | Remove |
| A tab indent | Its width differs between editors | Spaces of the same width |
| A period · colon at the end of a heading | | Remove |

## Settings

| Setting (Settings, 'View') | Default |
|---|---|
| **Document check** | On — when off, there is no status bar item or contents mark |
| **Writing habits in the document check** | Off |

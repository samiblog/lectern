# 템플릿

> 템플릿은 제목·글·강조글·차트 자리를 갖춘 장의 뼈대다. 갤러리에서 미리 보며 골라 새 장을 만들고, 지금 장을 내 템플릿으로 남긴다.

## 묶음과 템플릿

템플릿은 프로젝트가 아니라 Lectern 전체에서 함께 쓴다.

| 말 | 무엇 |
|---|---|
| 템플릿 | 제목 · 글 · 강조글 · 차트 자리를 갖춘 장 하나 |
| 묶음 | Lectern 슬라이드 파일 하나 — 그 안의 장 하나가 템플릿 |
| 기본 묶음 | Lectern 에 든 묶음 — 템플릿 12개 |
| 내 템플릿 | **이 장을 템플릿으로 저장…** 으로 더한 장이 모이는 묶음 |
| 최근 쓴 것 | 최근에 쓴 템플릿이 모이는 곳 |
| 템플릿 폴더 | `%APPDATA%\Lectern\templates` |

## 갤러리가 뜨는 때

| 언제 | 방법 | 고른 템플릿은 |
|---|---|---|
| 새로 만들 때 | **Ctrl+N** → 종류 **Lectern 슬라이드** | 새 문서의 첫 장 |
| 새 장 | **Ctrl+M** · 슬라이드 우클릭 **새 장…** | 지금 장 뒤에 들어가고 제목이 바로 열린다 |
| 템플릿 바꾸기 | 장 우클릭 **템플릿 바꾸기…** | 쓴 글은 새 칸으로 옮겨 담고, 못 담는 글은 맨 아래 칸에 남는다. 고치지 않은 안내 글은 옮기지 않는다 (**Ctrl+Z**) |

## 갤러리에서 고르기

| 하려는 일 | 마우스 | 키 |
|---|---|---|
| 묶음 고르기 | 왼쪽 묶음 목록 누르기 | **PageUp** · **PageDown** |
| 템플릿 고르기 | 누르기 | 번호 (묶음 안의 장 차례) · 화살표로 옮겨 **Enter** |
| 모든 묶음에서 찾기 | 위의 **템플릿 찾기** 칸 | 글자를 친다 |
| 그만두기 | **취소** | — |

## 내 템플릿과 묶음 고치기

| 하려는 일 | 방법 | 메모 |
|---|---|---|
| 지금 장을 템플릿으로 | 장 우클릭 **이 장을 템플릿으로 저장…** → 이름 | **내 템플릿** 묶음에 더해진다. 장의 글이 그대로 저장되니 내용은 안내 글로 고쳐 둔다 |
| 묶음 고치기 | 갤러리 **템플릿 폴더 열기** | 템플릿 폴더가 Lectern 탭으로 열린다 — 평소처럼 한 줄 편집과 점검으로 고친다 |
| 템플릿의 번호 · 이름 | 묶음 파일의 원문 | 장 차례가 번호, 장 이름은 `<!-- template: 이름 -->` |
| AI 도구(Claude Code 등)에 요청 | 갤러리 **Claude 에게 템플릿 요청** | 터미널에 요청 글 — 원하는 모양을 이어 적고 **Enter** |
| 묶음 기억 | 내가 만든 묶음으로 시작한 문서 | 맨 앞 설정에 `templates: 회사 보고` 가 적혀, 다음 장도 그 묶음이 먼저 열린다 |

단추의 'Claude' 는 설정 **쓰는 AI 도구** 의 이름을 따른다. 그림이 든 장을 템플릿으로 저장하면 그림의 경로도 그대로 저장되므로, 다른 폴더의 문서에서는 그림을 못 찾을 수 있다.

# 슬라이드 쓰기

> Lectern 슬라이드를 만들고, 칸 안의 글을 그 자리에서 고치고, 장과 칸을 다루고, 배치와 글자 크기를 정한다. pptx 를 옮기는 일은 AI 도구(Claude Code 등)에 맡긴다.

## 만들기

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 새 Lectern 슬라이드 | **Ctrl+N** (사이드바 '문서' 묶음의 **만들기** 도) → 제목을 쓰고 종류 **Lectern 슬라이드** → 템플릿 갤러리에서 첫 장 | 고른 템플릿이 첫 장인 새 문서 |
| 있는 md 문서를 슬라이드로 | 사이드바에서 문서 우클릭 **Lectern 슬라이드로 바꾸기 요청** | 터미널에 요청 글 — **Enter** 를 누르면 AI 도구가 같은 폴더에 새 파일로 만든다 |
| pptx 를 슬라이드로 | 터미널의 AI 도구에 시킨다 | 아래 [AI 도구에 시키기](#ai-도구에-시키기) |

## 칸 안의 글

글은 md 문서처럼 한 줄 편집으로 고치고, 누르는 순간 원문에 저장된다. 칸 끝에서 **Shift+Enter** 로 더한 줄도 칸 안에 들어가고, 줄을 옮기거나 지워도 칸과 장은 깨지지 않는다.

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 글 고치기 | **F2** · **Enter** | 칸에서 **Enter** 로 저장, **Ctrl+Z** 로 되돌린다 |
| 안내 글 바꾸기 | 템플릿의 안내 글을 연다 | 글 전체가 골라져 있어 바로 치면 바뀐다 |
| 구성 요소 넣기 | 칸의 빈 줄에서 **/** | 제목 · 목록 · 강조글 · 표 · 그림 · 차트 · 다이어그램 · 수식 · 코드 · 출처 줄 · 발표자 노트 (주 · 첨부 · 부록 · 구분선은 없다) |
| 서식 | **Ctrl+B** · **Ctrl+I** · **Ctrl+K** · **Ctrl+\`** | md 문서와 같고 칸 안에 든다 |
| 붙여 넣기 · 표 · 강조글 | 여러 줄 · 엑셀 범위 붙여 넣기, 표의 행과 열, 강조글 메뉴 | md 문서와 같고 칸 안에 든다 |
| 그림 | 붙여 넣기 | 칸에 들어간다 — **Ctrl+Shift+>** · **Ctrl+Shift+<** 로 폭 |
| 수식 · 다이어그램의 원문 | 그 위에서 **F2** | 화면 옆 패널에서 줄마다 고친다. 칸의 그림은 저장할 때마다 바뀐다. **Esc** 로 접는다 |
| 차트 값 | 차트에서 **F2** | 값이 표로 나온다 — 칸마다 고치고, **Shift+Enter** 로 행 더하기, **Ctrl+Shift+K** 로 지우기, 아래 버튼으로 막대 · 선 · 영역 · 원. 값이 다른 파일에 있거나 복잡한 차트는 원문으로 열린다 |
| 표를 차트로 | 표 우클릭 **이 표를 차트로** | 첫 열이 항목, 다음 열들이 값. pptx 에서 PowerPoint 차트가 되어 거기서도 값을 고친다 |
| 발표자 노트 | 우클릭 **발표자 노트 쓰기…** | 장 끝에 주석 한 줄 — pptx 의 노트로 간다 |
| 체크 칸 | 누르기 | 원문의 `[ ]` · `[x]` 가 바뀐다 (발표 중에는 바뀌지 않는다) |

## 장과 칸 다루기

| 하려는 일 | 우클릭 | 키 |
|---|---|---|
| 템플릿을 골라 이 장 뒤에 새 장 | 슬라이드 **새 장…** | **Ctrl+M** |
| 장 복제 | 슬라이드 **장 복제** | **Ctrl+D** |
| 장을 앞 · 뒤로 | 슬라이드 **장 앞으로 옮기기** · **장 뒤로 옮기기** | **Ctrl+Shift+PageUp** · **Ctrl+Shift+PageDown** (장 제목 줄에서 **Alt+↑** · **Alt+↓** 도) |
| 장 지우기 · 템플릿 바꾸기 | 슬라이드 **장 지우기** · **템플릿 바꾸기…** | — |
| 칸의 뼈대 넣기 | 슬라이드 **배치 넣기…** — 칸이 있던 장은 칸 이름만 바뀌고, 칸이 없던 장의 글은 첫 칸으로 | 그다음 **F2** 로 채운다 |
| 칸 모양 | 칸의 글 **칸 꾸밈…** — 상자 · 강조 · 메모 같은 모양 | — |
| 칸의 글을 맞바꾸기 | 칸의 글 **이 칸을 앞으로** · **이 칸을 뒤로** | — |
| 칸 비우기 | 칸의 글 **칸 비우기** | — |
| 넘친 칸 나누기 | 넘친 칸 **넘친 줄을 다음 장으로** — 같은 배치의 새 장으로 | — |
| 넘친 칸 줄이기 | 넘친 칸 **이 칸 줄이기 요청** — 터미널에 요청 글 (앱이 저절로 줄이지는 않는다) | — |

모두 **Ctrl+Z** 로 돌아온다. 오른쪽 목차는 장 목록이고 점검할 장이 표시된다.

## 칸과 배치의 원문

템플릿으로 모자라면 원문으로 칸을 짠다. 숨은 줄은 [구조 보기](5.2-발표와-점검.md#구조-보기)에서 꼬리표로 보고 고친다.

| 원문 | 결과 |
|---|---|
| `---` | 장 나누기 — 한 장은 1280×720 |
| `::: a card` … `:::` | 칸 하나 — 안에 글 · 표 · 차트 · 그림 |
| `<!-- layout: quad -->` | 정해진 배치 고르기 |
| `<!-- grid: a a b / c d b -->` | 배치를 직접 그리기 |
| `::: a at 100 200 300 120` | 칸의 자리를 직접 정하기 |
| `<!-- links: a>b, c--d -->` | 칸 사이에 화살표(`a>b`)와 선(`c--d`) — 칸의 글은 그대로 고친다 |
| `<!-- hidden: true -->` | 숨긴 장 — 화면에 흐리게 나오고 발표와 PDF 에서 빠진다 |

Marp 의 `paginate` · `header` · `footer` · `class: lead` · `invert` · 배경색, `![bg right:40%](그림)` 같은 배경 그림과 필터, `style:` 과 `<style scoped>` 의 CSS 를 읽는다. `theme`(gaia 등)은 읽지 않는다.

## 글자 크기

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 이 장의 한 구성 요소 | 현재 줄에서 **Ctrl+Shift+>** · **Ctrl+Shift+<** | 그 장의 표 · 강조글 · 제목 같은 구성 요소가 1pt 커지고 작아진다 — 원문에 `<!-- text: 표 14 -->` 한 줄 (**Ctrl+Z**) |
| 한 칸 | 크기가 적힌 칸(`::: b 16`)에서 같은 키 | 그 칸의 크기가 바뀐다 |
| 문서 전체 | 맨 앞 설정 `text: 제목 26, 표 12` | 문서 전체의 크기 |
| 띄우지 않고 읽는 자료 | 맨 앞 설정 `reading: true` | 점검 기준이 표 10pt · 본문 12pt 로 |

기본은 제목 30 · 소제목 20 · 본문 18 · 표 14 · 강조글 16 이다. 스타일을 바꿔도 크기는 그대로이고, 차트와 다이어그램 안의 글자는 칸 크기를 따른다. 표가 12pt, 본문이 14pt 아래로 내려가면 점검에 나온다.

## AI 도구에 시키기

pptx 를 Lectern 슬라이드로 옮기거나 pptx 를 참고해 만드는 일은 AI 도구의 스킬이 한다. 설치는 설정 창 **PowerPoint·Word 스킬** → **Claude Code용 요청 복사**(또는 옆의 터미널 버튼)로, 사용자가 시킬 때만 한다 — AI 도구가 무엇을 하는 스킬인지 알리고 설치할지 묻는다. Lectern 은 AI 도구를 실행하지 않는다. 터미널의 AI 도구에 직접 말하고, `@문서.md` 는 트리 우클릭 **@경로 복사** 로 얻는다.

| 하려는 일 | 요청 예 |
|---|---|
| pptx 를 Lectern 슬라이드로 | `이 pptx 를 Lectern 슬라이드로 옮겨 줘: D:\자료\보고서.pptx` |
| 띄워 둔 발표를 옮기기 | `지금 PowerPoint 에 띄워 둔 발표를 Lectern 슬라이드로 옮겨 줘. 결과는 D:\프로젝트\발표 폴더에 둬.` |
| 빨리 md 로만 | `D:\자료\보고서.pptx 를 일단 빨리 md 로만 뽑아 줘. 다듬는 건 나중에 할게.` |
| pptx 를 참고해 md 를 슬라이드로 | `D:\양식\회사보고.pptx 를 참고해서 @시장-분석.md 내용을 Lectern 슬라이드로 만들어 줘.` |
| 화면의 pptx 를 참고해 | `화면에 떠 있는 pptx 를 참고해서 @시장-분석.md 를 Lectern 슬라이드로 만들어 줘.` |
| 색과 표지만 참고해 | `D:\양식\회사보고.pptx 의 색과 표지만 참고해서 @주간보고.md 를 10장 안으로 Lectern 슬라이드로 만들어 줘. 숫자는 그대로 써.` |
| pptx 스타일과 템플릿 묶음 | `D:\양식\회사보고.pptx 로 '회사 보고' pptx 스타일과 템플릿 묶음을 만들어 줘.` |
| 띄워 둔 발표를 스타일로 | `지금 PowerPoint 에 띄워 둔 발표를 '회사 보고' pptx 스타일로 등록해 줘.` |
| 묶음에 템플릿 더하기 | `'회사 보고' 묶음에 표와 강조글이 있는 템플릿을 하나 더 만들어 줘.` |
| Lectern 슬라이드를 pptx 로 | `@발표.md 를 스타일을 최대한 유지해서 pptx 로 만들어 줘.` |
| 고친 장만 다시 pptx 로 | `pptx 에서 옮겨 온 @보고서.md 를 고쳤어. 고친 장만 반영해서 다시 pptx 로 만들어 줘.` |
| 회사 양식으로 pptx | `@발표.md 를 D:\양식\회사보고.pptx 양식으로 pptx 를 만들어 줘.` |

| 상황 | 동작 |
|---|---|
| 옮길 때 | 글을 빠뜨리지 않고 장을 그대로 지킨다. 글이 중심인 장은 칸으로 다시 짜고, 지도처럼 자리가 뜻인 도식은 그림으로 남기며 글은 노트에 둔다. 애니메이션과 정확한 글꼴은 옮기지 않는다 |
| 원본 | 원본 pptx 는 고치지 않는다. 띄워 둔 발표도 저장하거나 닫지 않는다 |
| Python 이 없을 때 | 된다 — 스킬은 프로그램 폴더의 `lectern-skill.exe` 로 돈다 |
| PowerPoint 가 없을 때 | `.pptx` 파일은 옮기고 내보낸다. 띄워 둔 발표 · `.ppt` · DRM 파일은 PowerPoint 가 있어야 한다 |
| 암호 · DRM | 암호는 먼저 푼다. DRM 이 걸린 파일은 PowerPoint 로 열어 띄워 두고 옮긴다 |

요청 예는 프로그램 폴더의 `_internal\skills\README.md` 에 더 있다. AI 도구가 읽는 작성 안내는 프로그램 폴더의 `_internal\web\help\slides.md` 다.

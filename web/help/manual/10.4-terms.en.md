# Terms

> Lectern's words used in this guide — what each means and the document that covers it.

## Screen and windows

| Term | Meaning | More |
|---|---|---|
| Project | One folder opened with Lectern — one project tab (up to 10) | [Project tabs](2.2-project-tabs.en.md) |
| Project tab | Below the toolbar, one tab per open project | [Project tabs](2.2-project-tabs.en.md) |
| Document tab | Just above the body — the documents open in one project (up to 40) | [Document tabs](2.3-document-tabs.en.md) |
| Spread all | **▦** in the document tab row — a project's document tabs and terminals in a grid over the whole window | [Document tabs](2.3-document-tabs.en.md) |
| Folder overview | What you see first when you open a folder — recently changed documents, subfolders, and each document's title · summary · modified time | [Reading](3-reading.en.md) |
| Sidebar | On the left — the Files · Recent · Search · Elements · Clip tabs | [Sidebar](2.4-sidebar.en.md) |
| 'Other files' list | Files on the sidebar's 'Files' tab that are neither documents nor code — PDF · Office · images · data and so on | [Sidebar](2.4-sidebar.en.md) |
| Excluded folder | Folders such as `node_modules` · `dist` — not in the document tree or search, shown only in 'Other files' as faint collapsed folders | [Sidebar](2.4-sidebar.en.md) |
| Contents | On the right — the current document's headings and parts such as tables and images | [Contents](2.5-contents.en.md) |
| Status bar | At the bottom — document path · modified time · changes · change watching | [Status bar](2.6-status-bar.en.md) |
| Main window | Lectern's main window, with the project tabs · terminal · notes · settings | [Separate windows](2.7-separate-windows.en.md) |
| Own window | A window apart from the main window — a separate window · slide window · User guide window · Example guide window | [Separate windows](2.7-separate-windows.en.md) |
| Separate window | A window you move documents into to read side by side — it belongs to its project (up to 8) | [Separate windows](2.7-separate-windows.en.md) |
| Slide window | The window Lectern slides open in with 'Open in new window' — its style is chosen separately | [Separate windows](2.7-separate-windows.en.md) |
| User guide window | The window of this guide, opened with **F1** — only one, view-only | [Separate windows](2.7-separate-windows.en.md) |
| Example guide window | The window that shows documents of the sample project, opened with **Shift+F1** — only one, view-only | [Separate windows](2.7-separate-windows.en.md) |
| All terminals | The toolbar button · **Ctrl+Shift+\`** — the terminals of the open projects in a grid on one screen | [Terminal](7.1-terminal.en.md) |

## Reading and picking

| Term | Meaning | More |
|---|---|---|
| Line | A line of the source file — a paragraph written on one line, a list item, a heading or a table row is one whole line | [Current line and picking](3.1-current-line-and-picking.en.md) |
| Current line | The line you are on — the small triangle on the left. Where you read, and where you write and insert | [Current line and picking](3.1-current-line-and-picking.en.md) |
| Picked lines | Several lines widened from the current line with **Shift+↑·↓** — lines to delete, move or change together | [Current line and picking](3.1-current-line-and-picking.en.md) |
| Select lines (focus) | **Ctrl+Enter** — only the current line or the picked lines stay sharp, the rest is dimmed | [Current line and picking](3.1-current-line-and-picking.en.md) |
| Section | A top-level section of a document. In Lectern slides, one slide | [Folding and focus](3.3-folding-and-focus.en.md) |
| Section focus | **Alt+H** — only the section with the current line stays sharp. Turning it off is Clear focus | [Folding and focus](3.3-folding-and-focus.en.md) |
| Click | One press of the left mouse button | — |
| Filter | Keeping only what matches the text you type in a list or table | [Sidebar](2.4-sidebar.en.md) |
| Quick open | **Ctrl+P** — open by name · title · path | [Find and search](3.2-find-and-search.en.md) |
| Find in document | **Ctrl+F** — within the current document | [Find and search](3.2-find-and-search.en.md) |
| Search | **Ctrl+Shift+F** — in the body text of all documents and code | [Find and search](3.2-find-and-search.en.md) |
| Find a command | **Ctrl+Shift+P** — type a feature's name and do it at once | [Shortcuts](10.1-shortcuts.en.md) |
| Changes | Blocks changed from outside (by an AI tool and the like) and redrawn — go through them with **F7** · **Shift+F7** | [Find and search](3.2-find-and-search.en.md) |
| Highlight | Text you colored — also a mark for places to come back to (**F8**) | [Highlights, notes and clip](3.5-highlights-notes-clip.en.md) |
| Notes | Notes for each project, written in the right-hand panel (**Alt+M**) | [Highlights, notes and clip](3.5-highlights-notes-clip.en.md) |
| Clip | Gathering pieces of documents and sending them to another document — the sidebar's 'Clip' tab | [Highlights, notes and clip](3.5-highlights-notes-clip.en.md) |
| Elements | A project's parts such as tables · images · charts, or its files, gathered in one place by kind | [Elements](3.7-elements.en.md) |

## Writing and documents

| Term | Meaning | More |
|---|---|---|
| Line edit | Changing a line right where it is on screen — **F2** · **Enter**, and **Enter** saves too | [Line edit](4.2-line-edit.en.md) |
| Cell | The text box in which line edit changes that line. In Lectern slides, a place within a slide (`::: a`) | [Line edit](4.2-line-edit.en.md) |
| Line structure | Adding, splitting, joining, moving and deleting lines | [Adding, moving and deleting lines](4.3-adding-moving-deleting-lines.en.md) |
| Change window | **.** — the window that turns the current line or picked lines into a heading · list · table · code | [Line kinds and formatting](4.4-line-kinds-and-formatting.en.md) |
| Insert window | **/** — the window that inserts parts such as a table · callout · image below the current line | [Insert](4.5-insert.en.md) |
| Full editor (edit mode) | **Ctrl+E** — the whole file in an editor, saved with **Ctrl+S** | [Full editor](4.7-full-editor.en.md) |
| md document | An ordinary Markdown document (`.md`) | [Writing](4-writing.en.md) |
| Lectern slides | An md with `marp: true` in its front matter — shown as slides, each slide with its own layout | [Lectern slides](5-lectern-slides.en.md) |
| pptx | A PowerPoint file | [pptx and html presentations](6.4-pptx-and-html-presentations.en.md) |
| HTML document | An `.html` document — its styles are kept, its scripts are not run | [Reading](3-reading.en.md) |
| Front matter | The `key: value` lines between `---` at the very top of a document (frontmatter) | [Elements](3.7-elements.en.md) |
| Callout | A callout such as `> [!NOTE]` — Note · Tip · Important · Warning · Caution | [Insert](4.5-insert.en.md) |
| Box | Between `<!-- box -->` and `<!-- /box -->` — a text box read apart from the body | [Insert](4.5-insert.en.md) |
| Named box | `<!-- box: 요약 -->` — moved into that slot (here `요약`, 'summary') of a page layout or Word template | [Print and PDF](6.1-print-and-pdf.en.md) |
| Image | An image in a document — a web image is one at an https address | [Insert](4.5-insert.en.md) |
| Caption | The one line 'Table 1. …' just above a table, or 'Figure 1. …' just below an image | [Numbers, references, contents and styles](4.6-numbers-references-contents-styles.en.md) |
| Cross-reference | A link to a caption or section, such as `[Table 3](#table-3)` | [Numbers, references, contents and styles](4.6-numbers-references-contents-styles.en.md) |
| md document style | The document mode (Prose · Outline) and the heading look (numbers · symbols) | [Numbers, references, contents and styles](4.6-numbers-references-contents-styles.en.md) |
| My styles | One CSS file in the style folder — at the bottom of the toolbar style list | [Settings](9-settings.en.md) |
| Template | A slide skeleton with places for a title · text · callout · chart — one slides file is one set | [Templates](5.3-templates.en.md) |
| Page layout | The output format for PDF · html (government report · research report and others) | [Print and PDF](6.1-print-and-pdf.en.md) |
| Word template | The template used when saving as Word — 18 Lectern templates and your own | [Word](6.3-word.en.md) |
| pptx style | The color · font · logo format of 'Convert to pptx' | [pptx and html presentations](6.4-pptx-and-html-presentations.en.md) |

## AI tools and work

| Term | Meaning | More |
|---|---|---|
| AI tool | Claude Code · Codex · Antigravity · OpenCode, started in the terminal — Lectern does not run them | [Working with AI tools](7-working-with-ai-tools.en.md) |
| Terminal | The button in the tab bar · **Ctrl+\`** — a PowerShell that starts in the current project folder | [Terminal](7.1-terminal.en.md) |
| First terminal | The terminal with the lowest number (usually terminal 1) — where sending goes | [Sending and requests](7.2-sending-and-requests.en.md) |
| Location | Text of the form `@docs/report.md lines 40-52` — points the AI tool to that part | [Sending and requests](7.2-sending-and-requests.en.md) |
| Send | **Shift+→** — puts the location into the terminal (Enter is not pressed) | [Sending and requests](7.2-sending-and-requests.en.md) |
| Request | Text for the AI tool that Lectern puts into the terminal or copies — you press Enter yourself | [Sending and requests](7.2-sending-and-requests.en.md) |
| Writing guide | The rules for writing documents that read well in Lectern — handed to the AI tool with 'Teach … about Lectern' in Settings | [Settings](9-settings.en.md) |
| Skills | AI tool features for working with PowerPoint · Word (SKILL.md format) | [Skills](7.3-skills.en.md) |
| Writing style | A style that makes the AI tool write like a practitioner writing a report — there are four | [Writing styles and polish](7.4-writing-styles-and-polish.en.md) |
| Polish check | Having the AI tool first show, as a table, wrong words and hard-to-read places in something a person wrote, and change only the ones you choose | [Writing styles and polish](7.4-writing-styles-and-polish.en.md) |
| My voice | A note, drawn from what you wrote, of what to keep and which habits not to copy | [Writing styles and polish](7.4-writing-styles-and-polish.en.md) |
| Work card | The `WORK.md` at the top of a folder — status · due · to-dos · schedule | [Work cards](8.1-work-cards.en.md) |
| Planning notes | The 'Planning notes' section of a work card — a place to jot things down as they come; Lectern does not read it | [Work cards](8.1-work-cards.en.md) |
| Work board | **Alt+W** — the work of several folders gathered at the top of the common folder's folder overview | [Work management](8-work-management.en.md) |
| Common folder | The folder for the WORK.md that holds events and to-dos outside any task, and for review documents | [Work management](8-work-management.en.md) |
| Work tree | A tree that gathers WORK.md files up and down, including those of subfolders — overview · group · small task | [Work tree, kanban and Gantt](8.2-work-tree-kanban-gantt.en.md) |

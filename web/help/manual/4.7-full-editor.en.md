# Full editor

> Open the whole file in the editor to rework many places at once or to edit an HTML document. This is the only way where nothing is saved until you press Ctrl+S.

Most work is done with [Line edit](4.2-line-edit.en.md). Use this editor (edit mode) for what line edit cannot do.

## At a glance

| To | Mouse | Keys |
|---|---|---|
| Open · close the document or code you are viewing | **Edit** on the tab bar (press again to close) · **Edit** in the status bar · **Edit** in the code view header · right-click the document margin **Edit this document** | **Ctrl+E** |
| Open at that block · line | Right-click a line **Open in the full editor** (**Edit here** in the code and data views) | **Ctrl+E** |
| Open CSV · TSV · text at that line | — | **F2** · **Enter** |
| Save | — | **Ctrl+S** |
| Close | **✕** | **Esc** · **Ctrl+E** |

The **Edit** button on the tab bar shows the accent color and an underline while it is on. The editor opens with the source of where you were reading at the same height.

## Keys in the editor

| To | Keys |
|---|---|
| Find · replace | **Ctrl+F** · **Ctrl+H** |
| Find next · previous | **F3** · **Shift+F3** |
| Go to line | **Ctrl+G** |
| Delete line · duplicate line | **Ctrl+Shift+K** · **Ctrl+Shift+D** — the same keys as in a cell (Ctrl+D is not used) |
| Date · special character | **Ctrl+;** · **Ctrl+Shift+;** |
| Indent | **Tab** — indents with spaces (a tab character in CSV · TSV · text) |

It has line numbers and language colors.

## It stays with your reading position

| Situation | What happens |
|---|---|
| The contents on the right while editing | Marks the section the cursor is in — if the cursor is off screen, the section at the top of the screen |
| Clicking a place in this file in the contents · Elements · search results | The editor goes to that line |
| Closing the editor | The document view is where you were editing — a folded section is unfolded |
| HTML documents | Follows by headings |

## Saving

| Situation | What happens |
|---|---|
| **Ctrl+S** | Saves keeping the file's line endings (CRLF · LF — the more common one if they are mixed) · BOM · file attributes |
| After saving | The document view underneath is redrawn with your changes and shows when you close the editor |
| Another program (an AI tool and so on) changed the same file meanwhile | Asks whether to overwrite — cancel to keep editing without saving |
| Closing · going to another document · closing the tab or window with unsaved edits | Asks first |
| Read-only files | Not saved |
| CSV · TSV · text | Saved in their original encoding (UTF-8 · UTF-16 · CP949) — [Code and data files](3.6-code-and-data-files.en.md) |

## What it does not edit

| File · task | Instead |
|---|---|
| Documents · code that are not UTF-8 | View only — data files are edited in their original encoding |
| Files over 2MB | An external editor |
| Data such as PDF · Excel · logs | Not edited |
| New files · new folders | [Creating](4.8-creating.en.md) — new documents · empty code files · empty data files · folders |
| Renaming files | Pick the file in the sidebar and press **F2** — [Sidebar](2.4-sidebar.en.md) |

## Source lines

A way to edit every line of an md document, line by line, without opening the full editor.

| To | How |
|---|---|
| Show an md document as a code view with line numbers | **Source lines** in the status bar |
| Edit blank lines · comments · HTML too | Line by line in cells in that view (the same keys as [Line edit](4.2-line-edit.en.md)) |
| Go back | **View as md document** in the status bar |

## vi mode

Choose **vi** under **Full editor keys** in Settings (**Ctrl+,**) to use the editor like vim. The default is **Default**, and it is set separately from the vi keys of the reading view.

| To | Keys |
|---|---|
| To Normal mode | **Esc** — does not close the editor |
| Save | `:w` |
| Close | `:q` · **Ctrl+E** · **✕** |
| Save and close | `:wq` · `:x` |

With Korean input on, Normal-mode keys may be typed as characters, so switch to English input.

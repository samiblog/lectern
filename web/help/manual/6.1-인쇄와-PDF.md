# 인쇄와 PDF

> md 문서를 화면 스타일과 상관없이 늘 같은 보고서 양식이나 고른 지면 틀로 인쇄하고 PDF 로 저장한다. 미리보기가 저장·인쇄될 그대로다.

## 여는 법

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 내보내기 창 열기 | 탭 막대 오른쪽 끝 **내보내기** → **PDF로 저장…** 이나 **인쇄…** | 형식 **PDF·인쇄** 로 열린다 |
| PDF 로 저장 | 본문 여백 우클릭 **PDF로 저장…** | 같은 창 — **PDF로 저장…** 단추가 먼저 |
| 인쇄 | 본문 여백 우클릭 **인쇄…** | 같은 창 — **인쇄…** 단추가 먼저 |
| 이름으로 찾기 | **Ctrl+Shift+P** → '인쇄·PDF' | 같은 창 |

## 내보내기 창

왼쪽에서 옵션을 고르면 오른쪽 미리보기가 그 옵션으로 다시 만들어진다. 목차·확대·쪽 넘기기는 미리보기 위 막대로 한다. 옵션은 다음에도 그대로다.

| 옵션 | 고르는 것 |
|---|---|
| 형식 | **PDF·인쇄** · **html 한 파일** · **Word** |
| 틀 | **보고서 (기본 양식)** · 지면 틀 18가지 · 내 틀 |
| 글꼴 | 명조 (함초롬바탕, 없으면 바탕 — 제목은 고딕) · 고딕 (맑은 고딕) |
| 여백 | 보통 (위 25 · 아래 22 · 좌우 22mm) · 좁게 (사방 15mm) · 넓게 (위 30 · 아래 25 · 좌우 30mm) |
| 쪽 머리 | 2쪽부터 머리에 문서 제목과 날짜 |
| 쪽 번호 | 바닥 가운데 '- 1 -' |

글꼴·여백·쪽 머리·쪽 번호는 **보고서 (기본 양식)** 일 때만 보인다 — 지면 틀을 고르면 틀이 정한다.

| 단추 | 하는 일 |
|---|---|
| **PDF로 저장…** | 미리 본 PDF 를 저장 대화상자에서 고른 곳에 쓴다 — 문서 옆, 문서 이름으로 열린다. 제목이 PDF 책갈피가 된다 |
| **인쇄…** | 미리 본 PDF 를 인쇄 창으로 보낸다 — 프린터 · 매수 · 쪽 · 색은 인쇄 창에서 |
| **글꼴·틀 설정…** | 설정 창의 인쇄·PDF 글꼴과 지면 틀 |
| **닫기** · **Esc** | 창을 닫는다 — 미리보기 안을 누른 뒤에는 마우스를 미리보기 밖으로 |

PDF 를 저장하고 PDF 를 인쇄하는 것이라 브라우저가 붙이는 날짜·주소 머리글이 없다.

## 보고서 양식

| 자리 | 모양 |
|---|---|
| 쪽 | A4 · 여백 위 25 · 아래 22 · 좌우 22mm |
| 첫 쪽 | 가운데 제목 |
| 쪽 머리 | 2쪽부터 문서 제목과 날짜 — 맨 앞 설정의 `date`, 없으면 오늘 |
| 쪽 번호 | 바닥 가운데 |
| 본문 글꼴 | 설정 창 **인쇄·PDF 글꼴** — 명조(기본) · 고딕 |
| 표 | 위아래 굵은 줄. 12행이 넘으면 쪽을 나눠 싣고 머리행을 쪽마다 되풀이 |
| 캡션 · 주 · 자료 | 표 · 그림과 같은 쪽에 붙는다 — 캡션은 가운데 11pt, 주 · 자료는 왼쪽 작은 글 |
| 그림 | 쪽보다 크면 한 쪽 높이로 줄인다 |
| 링크 | 검은 글자 — 주소는 '출처' · '참고문헌' · '자료' 절의 목록에만 붙는다 |
| 맨 앞 설정 표 | 싣지 않는다 |
| 쪽 나눔 줄 | 그 자리에서 다음 쪽으로 (넣기 창의 **쪽 나눔**) |
| `[목차]` 줄 | 그 자리에 목차로 인쇄된다 |

화면의 글자 크기·문서 폭·줄 번호·찾기 표시·하이라이트·스타일은 종이에 들어가지 않는다.

## 지면 틀

**틀** 에서 출력 양식을 고른다. 글은 그대로이고 표지·머리·쪽 크기·글꼴·색이 바뀐다. PDF 와 html 이 같은 꼴로 나온다.

| 묶음 | 틀 (맨 앞 설정 `layout:` 에 쓰는 id) |
|---|---|
| 업무·공공 | 정부 보고서 `gov-report` · 한 장 보고서 `one-page` · 공문 (기안문) `official-letter` · 보도자료 `press-release` · 회의록 `minutes` |
| 연구 | 연구보고서 `research-report` · 이슈 브리프 `issue-brief` · 학술 논문 (2단) `paper-2col` · 투고 원고 `manuscript` · 백서 `white-paper` |
| 금융·컨설팅 | 증권사 리포트 `equity-research` · 컨설팅 보고서 `consulting` · 제안서 `proposal` |
| 매체·출판 | 잡지 `magazine` · 뉴스레터 `newsletter` · 책 `book` · 웹 장문 `longform` |
| 안내 | 매뉴얼·가이드 `manual` |
| 내 틀 | 목록 맨 아래 — 설정 창에서 만든 틀 |

| 하려는 일 | 방법 |
|---|---|
| 표지 · 머리 채우기 | 맨 앞 설정 `title` · `subtitle` · `author` · `date` · `org`(기관) · `dept`(부서) 등 — 한국어 키 `기관:` · `부서:` 도 된다 |
| 비어 있는 키 채우기 | 틀을 고르면 그 틀이 쓰는데 비어 있는 키를 알린다 → **맨 앞 설정 견본 복사** 로 복사해 문서 맨 앞에 붙여 채운다 |
| 요약 · 핵심 · 초록을 제자리에 | 이름 있는 박스글 `<!-- box: 요약 -->` 로 연다 — 그 틀의 요약 자리로 옮겨진다. 자리가 없으면 본문의 보통 박스글로 남는다. 창에 그 틀의 박스글 자리가 보인다 |
| 틀을 문서에 기억 | 맨 앞 설정 `layout: research-report` (이름도 된다) — 창을 열 때 그 틀이 골라져 있다 |
| 내 틀 만들기 | 설정 창 **지면 틀** 에서 틀 폴더를 열고 **Claude Code용 요청 복사** → AI 도구(Claude Code 등)에 붙이고 원하는 양식(예: '우리 회사 주간 보고 양식, 첫 쪽에 로고 띠')을 이어 적는다 → AI 도구가 작성 안내를 읽고 틀 폴더에 html 하나를 만든다 |

## 이럴 때는

| 상황 | 동작 |
|---|---|
| Lectern 슬라이드 | 슬라이드 크기의 쪽에 한 장씩, 화면 색 그대로 — 글꼴 · 여백 · 쪽 머리 · 쪽 번호 · 틀은 쓰지 않는다. 숨긴 장과 발표자 노트는 빠진다 |
| html 문서 | 그 문서의 스타일로 인쇄 창 하나 (**인쇄 / PDF로 저장…**) — PDF 는 프린터에서 'Microsoft Print to PDF' 를 고른다 |
| 편집 중 | 저장하고 편집을 닫은 뒤 만든다 — PDF 는 저장한 내용으로 |
| 모두 펼치기 | 우클릭한 칸의 문서가 PDF 가 된다 |
| 같은 이름의 PDF 가 있을 때 | Windows 가 덮어쓸지 묻는다 |
| PDF 보기 프로그램이 그 파일을 열고 있을 때 | 그 프로그램을 닫고 다시 저장한다 |

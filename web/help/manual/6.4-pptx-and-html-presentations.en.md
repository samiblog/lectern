# pptx and html presentations

> Turn Lectern slides into a pptx file or an impress.js presentation html file from the status bar. Both make one new file next to the document and never overwrite.

## Comparing the two

| What | **Convert to pptx** | **Convert to html** |
|---|---|---|
| Result | A new pptx next to the document | One impress.js presentation html next to the document |
| The reader | Opens and edits it in PowerPoint | Opens it in a browser to present — the slides sit on one canvas and the view moves between them |
| Look | Cell positions from the Lectern slides; colors · fonts · logo · footer from the pptx style | Colors · fonts from the style picked now, as they are |
| If the name exists | A new name such as `Report 2.pptx` | A new name such as `Report 2.html` |

## Convert to pptx

| What to do | How | Result |
|---|---|---|
| Convert | **Convert to pptx** on the status bar → pick a pptx style → **Convert** | A pptx next to the document — no AI tool (Claude Code and others) or Python needed |
| After making it | **Open pptx** · **Show in Explorer** | — |
| Add a style | **Open library folder** in the window (`%APPDATA%\Lectern\pptx-styles`) → put your company's pptx there | It shows in the list — shared by all of Lectern |
| Leave the style to an AI tool | **Ask Claude for a style** → write the pptx path | The AI tool makes the style, a template set of the same name and preview images together |
| Set the default style | Turn on **Make this the default** and convert | Documents with no style set use that style |

If there are unsaved edits, save them first, then convert.

## The order styles are used in

| Order | Style | Notes |
|---|---|---|
| 1 | The style picked this time | The picked name is written in the front matter as `pptxStyle: Company report` and is picked first next time |
| 2 | The document's style | The one in `pptxStyle:`, or its paired style — a document made from the 'Company report' set uses the 'Company report' style |
| 3 | The original pptx | For documents moved from a pptx |
| 4 | Default style | The one set with **Make this the default** |
| 5 | Lectern style | When there is none of these |

A template set and a pptx style with the same name are a pair. If you move only the document to another PC, the style may be missing — Lectern then tells you and lets you pick again.

## What goes into the pptx

| Lectern slides | In the pptx |
|---|---|
| Cell positions | Follow the Lectern slides |
| Colors · fonts · logo · footer | Follow the pptx style |
| Text · tables | Text · tables |
| Charts | Charts whose values you can edit |
| Lines between cells | Connectors |
| Complex charts · Mermaid | Images |
| Speaker notes | pptx notes |
| Highlights · text colors | As they are |
| The model pptx's slides · images | Do not go in — its slide titles and cover thumbnail are removed from the file properties too |
| Logo · footer in the model's layouts | Part of the model, so they go in |

## Documents moved from a pptx

Convert again without picking a style and the original slides are kept. For that, do not delete `document-변환기록.json` (the conversion record) or the `.pptx-work` folder.

| Slide | When converted again |
|---|---|
| Slides you did not change | The original slide as it is — design and animations stay |
| Slides where you edited only text | Only that text changes in the original slide |
| Slides whose cells or layout changed | Made anew |

## Convert to html

**Convert to html** on the status bar → pick an arrangement and **Create**. The md is the source, so convert again after editing.

| Option | What it does |
|---|---|
| **Grid** | Starts a new row at the cover · section slides (`lead` slides), and wraps when a row passes 4 slides |
| **One row** | All slides in one row |
| Arrangement map | Shows each slide number in its place |
| **Overview at the end** | Adds a last slide that shows all slides on one screen |
| **Ask Claude to arrange** | A request to place the slides along the story goes into the terminal (**Enter** is not pressed) |
| First choice | With `impress: line` in the front matter, One row |
| Placing a slide yourself | `<!-- impress: x=0 y=2400 rotate=90 scale=2 -->` on the slide — only the axes you write change, and the look on screen stays the same |

After making it, **Open in browser** opens only the file Lectern just made, in your default browser. **Show in Explorer** is there too.

| Presenting (in the reader's browser) | Keys |
|---|---|
| Next slide · previous slide | **→** · **Space** · **PageDown** / **←** · **PageUp** |
| First slide · last slide | **Home** · **End** |
| Presenter console (notes · next slide · clock) in a new window | **P** |

| Situation | What happens |
|---|---|
| One file | Images · styles · math fonts · impress.js all go inside — it opens without the internet and requests nothing from anywhere. You can send it by mail · messenger. Only internet images stay as addresses, loaded by the reader's browser |
| What is left out | Hidden slides, videos · sounds. Links to other documents in the project stay as text. `class="step"` · `notes` · `substep` written in HTML slides are removed, because impress reads those names as slides · notes |
| Safety | Only impress.js and its start line run in the file — scripts in the document do not run in the reader's browser |
| Opened in Lectern | It shows in the document list on the left as an html document — Lectern does not run its scripts, so the slides appear top to bottom like a document, and the notes show too |

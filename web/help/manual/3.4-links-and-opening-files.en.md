# Links and opening files

> Links and file paths in the body open in Lectern, the default app, the editor or the browser, depending on the target. Programs and scripts are never run, anywhere.

## By target

| Link target | Opens in |
|---|---|
| md · html documents shown in the tree | Lectern — in the current tab (with `#section`, at that section) |
| Section links · footnotes in the same document | That place — **Alt+←** brings you back |
| Folder | That folder's overview |
| Code file | The code view — add `#L42` for that line |
| CSV · text files | Lectern — [Code and data files](3.6-code-and-data-files.en.md) |
| The project's PDFs | Inside Lectern — with `#page=12`, that page ([Viewing PDFs](3.8-pdf.en.md)) |
| Images · Office files | The default app |
| Other text files | The editor (if there is no editor, Explorer with the file selected) |
| Web address | The default browser |
| Outside the project folder | Not opened — shown struck through |

Paths of files that really exist, such as `src/app.py:42` or `data/x.csv:5` in the body, become links that go to that line when clicked. Absolute paths in documents (`C:\...\chart.png`) open too when they point inside the project.

## How to open

| What you want to do | Mouse | Key |
|---|---|---|
| Opening in the current tab | Click | **Alt+Enter** (on a line with a link · a link reached with **Tab**) |
| Opening behind, keeping the document you were reading | **Ctrl+click** · middle button · right-click **Open in new tab** | — |
| Opening in a new window | Right-click **Open in new window** (documents · code) | — |
| Going back | The mouse's back button | **Alt+←** |
| Copying the link address | Right-click **Copy link address** — **▣ Terminal** beside it puts it into the terminal | — |
| Copying an internet image's address | Right-click **Copy image address** | — |

## Picking links from the keyboard

| Key · situation | Behavior |
|---|---|
| **Tab** · **Shift+Tab** | Moves focus to the next · previous link from the current line — after the last link it wraps to the first |
| **Alt+Enter** | Opens the focused link · button. With several links on the current line, a menu to pick from |
| **Enter** | Edits that line, not the link |
| Without links | Cycles the buttons in the document (such as the code view header) |
| Leaving the document | **Tab** doesn't go out to the terminal or sidebar — press **F6** to leave |
| Folder overview · html documents | Stays inside them |
| Find bar boxes | Cycles only the bar and the document |
| With several lines picked | **Tab** changes the level — [Adding, moving and deleting lines](4.3-adding-moving-deleting-lines.en.md) |

# 툴바

> 창 맨 위 한 줄 — 글자 크기·문서 폭·줄 번호·스타일·하이라이트로 화면을 맞추고, 문서 열기·설정·단축키·업무·터미널 모음을 연다.

## 단추 (왼쪽부터)

| 단추 | 하는 일 | 키 |
|---|---|---|
| 사이드바 | 왼쪽 사이드바 보이기·감추기 | **Ctrl+B** |
| ‹ · › | 뒤로 · 앞으로 — 같은 문서 안에서 뛴 자리도 | **Alt+←** · **Alt+→** (마우스의 뒤로·앞으로 버튼도) |
| 문서 열기 | 이름·제목·경로로 문서·코드 열기 — `>` 로 시작하면 명령 찾기 | **Ctrl+P** · **Ctrl+Shift+P** |
| − · 100% · + | 문서 글자 크기 | **Ctrl+=** · **Ctrl+-** · **Ctrl+0** |
| 좁게 · 폭 100% · 넓게 | md 문서 본문의 좌우 폭 | — |
| 줄 번호 | md 문서 왼쪽 여백에 원문 줄 번호 | **Alt+L** |
| 스타일 · ∧ · ∨ | 본문과 툴바·사이드바의 색과 글꼴 | — |
| 하이라이트 · ∧ · ∨ | 현재 줄이 있는 장만 또렷하게, 옆 ∧·∨ 로 앞뒤 장 | **Alt+H** |
| ⚙ | 설정 창 | **Ctrl+,** |
| ? | 단축키 표 (사용설명서는 **F1**) | **Ctrl+/** |
| 업무 | 업무 현황 — WORK.md 가 있는 폴더들의 상태·마감·할 일·일정 | **Alt+W** |
| 터미널 모음 | 열린 프로젝트들의 터미널을 한 화면에 | **Ctrl+Shift+\`** |

하이라이트는 고른 줄이 있으면 그 줄을 또렷하게 하고, 장으로 나뉘지 않은 문서와 코드 화면에서는 **Ctrl+Enter**(줄 선택)와 같다.

## 글자 크기와 문서 폭

| | 글자 크기 | 문서 폭 |
|---|---|---|
| 바꾸는 것 | 문서의 글자 | md 문서 본문의 좌우 폭 — 글자는 그대로, 한 줄이 길어지거나 짧아진다 |
| 범위 | 80%~200% (100% 도 읽기 좋게 조금 크게 잡혀 있다) | 80%~200%, 끝까지 넓히면 **가득**(문서 칸 폭 전체) |
| 처음으로 | 가운데 **100%** 누르기 · **Ctrl+0** | 가운데 **폭 100%** 누르기 |
| 창이 좁으면 | — | 문서 칸 폭까지만 넓어진다 |
| 그대로인 것 | 앱 화면 (앱 전체를 키우려면 **Ctrl+휠**) | 코드 화면 · Lectern 슬라이드 · 자기 스타일이 있는 HTML 문서 |
| 다음 실행 | 고른 크기 그대로 | 고른 폭 그대로 |
| 인쇄 · PDF | 들어가지 않는다 | 들어가지 않는다 |

## 폭이 바뀌면 표는

표의 열 너비는 저절로 맞춘다. 창·사이드바 폭이나 글자 크기·문서 폭을 바꾸면 다시 맞춘다.

| 경우 | 동작 |
|---|---|
| 열마다 | 가장 긴 낱말이 들어가는 폭부터 — 글이 적은 열이 한두 글자 폭으로 좁아져 행이 길어지지 않게 |
| 남는 폭 | 몇 가지로 나눠 실제로 그려 보고 나은 것을 쓴다 — 표가 가장 낮게, 열마다 든 글 양에 맞춰, 한 줄에 낱말이 둘은 들어가게 |
| 맨 왼쪽 열 때문에 행이 높으면 | 그 열을 넓히는 것도 함께 대어 본다 |
| 머리행 · 맨 왼쪽 열 | 낱말 가운데서 끊지 않고 띄어쓰기에서 감는다 (긴 낱말로 표가 옆으로 넘치면 그 표만 끊는다) |
| 옆으로 스크롤 | 마지막 수단 — 열이 아주 많아 글이 세로로 감길 때, 줄바꿈하지 않는 숫자가 들어가지 않을 때만 표 안에서 |
| 파일 · 인쇄 | 보이는 폭만 바뀌고 파일은 그대로. 인쇄·PDF 는 쪽 폭에 맞춰 다시 나눈다 |

그래도 칸이 길면 표를 나누거나 긴 설명을 표 밖으로 옮긴다. AI 도구(Claude Code 등)에 문서를 맡기면 Lectern 작성 안내가 그렇게 쓰게 한다.

## 줄 번호

| 경우 | 동작 |
|---|---|
| 번호 | 원문 파일의 줄 — AI 도구에 보내는 `@경로 12행` 과 같은 줄 |
| 빈 줄처럼 화면에 없는 줄 | 번호를 건너뛴다 |
| 화면에서 꺾인 글 | 첫 줄에만 붙는다 |
| 코드 화면 | 늘 번호가 있다 |
| 인쇄 | 나오지 않는다 |

## 스타일

| 하려는 일 | 방법 |
|---|---|
| 스타일 고르기 | 목록에서 25가지 가운데 — 본문과 툴바·사이드바 색이 함께 바뀐다 |
| 차례로 견주어 보기 | 목록 옆 **∧** · **∨** — 위·아래 스타일로 |
| Windows 다크 모드 따르기 | 목록 맨 위 **자동 (시스템)** |
| 목록 묶는 방식 바꾸기 | 설정 창 — 용도별 · 분위기별 · 밝기별 |
| 설정 창으로 | 목록 맨 아래 **스타일 설정…** |
| 내 스타일 만들기 | 목록 아래쪽 **내 스타일 만들기…** — 아래 |
| 내가 만든 스타일 | 목록 맨 아래 **내 스타일** 묶음 |

스타일은 화면에만 듣는다 (내 스타일도). 종이와 PDF 는 늘 같은 보고서 양식이고, 종이의 모양을 바꾸려면 [지면 틀](6.1-인쇄와-PDF.md)을 고른다.

## 내 스타일 만들기

| 무엇 | 어떻게 |
|---|---|
| 스타일 하나 | CSS 파일 하나 — `%APPDATA%\Lectern\styles` 폴더에 두면 **내 스타일**에 나온다 |
| 화면에서 만들기 | 스타일 목록의 **내 스타일 만들기…** (설정 창 **화면에서 만들기…** · 명령 찾기도) — 지금 스타일을 바탕으로 글꼴(본문 · 제목) · 크기(글자 · 줄 간격 · 폭) · 색(글자 · 제목 · 링크 · 표 머리) · 목록(맨 위 항목의 굵기 · 크기)을 고르면 문서에 바로 입혀 보인다. 이름을 적고 **저장** — 바꾼 칸만 담긴 CSS 하나가 생기고 그 스타일로 바뀐다 |
| 화면에서 다시 고치기 | 그 창으로 만든 스타일을 고른 채 다시 열면 값을 불러온다. **저장**하면 묻고 그 파일을 바꾼다 — **새 스타일로 저장**도. 그사이 파일이 바뀌었으면 바꾸지 않는다 |
| 손으로 쓴 스타일 위에 | 그 스타일을 고른 채 열면 그 규칙을 새 파일에 옮겨 담고 값을 얹는다 — 원래 파일은 그대로 |
| 그만두기 | **취소** · Esc — 입혀 본 것을 걷는다. 다른 스타일을 골라도 걷힌다 |
| 글꼴 · 색 | 글꼴은 이 PC 에 있는 것 가운데서 (직접 적어도 된다). 글자색이 바탕과 대비가 낮으면 (4.5:1 아래) 알린다 |
| AI 도구에 맡기기 | 설정 창 **Claude Code용 요청 복사**를 AI 도구에 붙여 넣고 원하는 모양을 이어 적는다 (예: '남색 제목, 표 머리행은 짙은 남색에 흰 글자, 본문은 명조'). 요청 글에 앱에 든 스타일 설명서와 저장할 폴더가 들어 있다. 옆 **▣** 은 터미널에 바로 |
| 보면서 다듬기 | 그 스타일을 고른 채 파일이 고쳐지면 몇 초 안에 다시 입혀진다 — '제목을 더 크게' 처럼 이어서 부탁한다 |
| 폴더 열기 · 빼기 | 설정 창 **스타일 폴더 열기** — 파일을 지우면 목록에서 빠진다 |
| 인터넷 글꼴 · 그림 | 앱이 지운다 — 글꼴은 PC 에 있는 것만 쓰인다 |

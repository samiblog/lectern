# 설정

> 설정 창(Ctrl+,)의 분류마다 무엇을 고르는지, 창에 없는 설정은 어디서 고치는지, 설정이 어디에 저장되는지.

## 설정 창

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 설정 창 열기 | 툴바의 톱니 · **Ctrl+,** | 마지막에 고른 분류에서 열린다 |
| 분류로 가기 | 왼쪽 분류 누르기 | 오른쪽이 그 절로 간다. 내리면 지금 절이 강조된다 |
| 여럿 가운데 고르기 | 한 줄 단추 | 고른 것의 설명이 아래에 |
| 켜고 끄기 | 오른쪽 끝의 스위치 | 고른 즉시 반영된다 — 저장 단추는 없다 |
| 관련 화면에서 바로 열기 | 터미널 머리줄 우클릭 **터미널 설정…** · 툴바 스타일 목록 맨 아래 **스타일 설정…** · 업무 현황의 **업무 설정…** · 상태줄의 **vi** 표시 · 내보내기 창의 **글꼴·틀 설정…** | 그 분류(터미널 · 보기 · 업무 · 편집 · 인쇄·내보내기)로 열린다 |

## 설정이 듣는 곳

| 설정 | 듣는 곳 |
|---|---|
| 설정 창의 설정 | Lectern 전체 — 모든 폴더와 창. 폴더마다 따로 두지 않는다 |
| 다른 창 | 열린 독립창 · 슬라이드 창도 1~2초 안에 따라 바뀐다. 설정 파일을 편집기로 고쳐 저장해도 같다 |
| 독립창에서만 바꾼 화면 설정 (글자 크기 등) | 그 창에만 남는다. 다른 창에서 그 설정을 바꾸면 따라간다 |
| md 문서 스타일 · 메모 · 업무 카드 · 마지막에 보던 위치 | 그 폴더 · 문서의 것 |
| 'AI 도구'의 **AI 도구에 건네는 것** | Lectern 설정이 아니라 AI 도구(Claude Code 등)의 파일 |

## 일반

| 설정 | 고르는 것 |
|---|---|
| 언어 · Language | 자동(Windows 표시 언어) · 한국어 · English. 바꾸면 화면을 다시 불러온다 (열린 탭 · 터미널은 그대로) |
| 마지막 위치에서 시작 | 폴더를 열면 마지막에 보던 문서와 위치로 |
| 첫 단계 폴더 펼치기 | 폴더를 열 때 트리의 첫 단계 폴더를 펼쳐 둔다 |
| 목록에 문서 제목 보이기 | 끄면(기본) md 문서를 파일 이름으로 보이고 마우스를 올리면 제목. 사이드바 '제목' 단추와 같고, 문서 탭 · 문서 열기 · 최근 변경 · 검색 · 폴더 개요도 따른다 |
| 사이드바 '문서'의 하위 묶음 | Word · PowerPoint · Excel·CSV · 한글(HWP) · 업무 · 형광펜 · 할 일 가운데 보일 것 — 처음에는 오피스 넷만 ([사이드바](2.4-사이드바.md)) |

## 보기

| 설정 | 고르는 것 |
|---|---|
| 스타일 목록 묶기 | 툴바 스타일 목록을 용도별 · 분위기별 · 밝기별로 |
| 내 스타일 | **스타일 폴더 열기** · **Claude Code용 요청 복사** · ▣(그 요청 글을 터미널에). CSS 파일 하나가 스타일 하나이고, 스타일 목록 맨 아래 '내 스타일'에 나온다 |
| 표 칸 맞춤 | 기본(글 왼쪽 · 숫자 오른쪽 · 칸의 위) · 보고서식(머리행과 짧은 열 가운데, 숫자 오른쪽, 긴 글 왼쪽, 세로 가운데). 원문에 맞춤 표시(`:---:`)가 있는 열은 그 표시대로 |
| 수식 표시 | `$…$` · `$$…$$` · math · latex 코드 블록을 수식으로 |
| 문단 안의 줄바꿈 보이기 | 원문에서 Enter 로 바꾼 줄이 화면에서도 바뀐다 (Word 의 Shift+Enter 처럼). 끄면 표준 Markdown 처럼 이어서 |
| 인터넷 그림 표시 | 문서 속 https 그림을 불러온다. 끄면 링크로만 보이고 인터넷에 요청하지 않는다. 바꾸면 화면을 다시 불러온다 |

## 편집

| 설정 | 고르는 것 |
|---|---|
| vi 키 | 문서에서 글자 키로 움직이고 고친다 — j·k 줄 옮기기, V 고르기, dd 지우기, i 쓰기, u 되돌리기. 기본은 꺼짐, 켜면 상태줄에 `vi` |
| 전체 편집 방식 | 기본 방식(Esc 로 닫기, Ctrl+S 저장) · vi 방식(vim 처럼 — Esc 는 Normal 모드로, `:w` 저장, `:q` 닫기). 읽는 화면의 vi 키와 따로 고른다 |

## 인쇄·내보내기

| 설정 | 고르는 것 |
|---|---|
| 인쇄·PDF 글꼴 | 'PDF로 저장…' · '인쇄…' 의 본문 글꼴 — 명조(함초롬바탕, 없으면 바탕 · 제목은 고딕) · 고딕(맑은 고딕) |
| 지면 틀 | **틀 폴더 열기** · **Claude Code용 요청 복사** · ▣. html 파일 하나가 틀 하나이고, 내보내기 창 '틀'의 '내 틀'에 나온다 |

종이와 PDF 는 화면 스타일과 상관없이 보고서 양식으로 나온다. 여백 · 쪽 머리 · 쪽 번호는 내보내기 창에서 고르고, 다음에도 그대로다.

## 터미널

| 설정 | 고르는 것 |
|---|---|
| 터미널 자리 | 자동(창이 세로로 길면 문서 아래, 아니면 오른쪽) · 오른쪽 · 아래. 터미널 머리줄의 자리 버튼으로 바꾸면 그 자리로 고정되고, 여기서 다시 자동으로 |
| 터미널 색을 스타일에 맞춤 | 바탕 · 글자 색을 문서 스타일에 맞춘다. 끄면 늘 어두운 색 |
| 터미널 글자 크기 | 10~24 (기본 14) — **−** · **+** · **기본 크기** · 숫자. 열린 터미널과 터미널 모음에 바로 |

## AI 도구

위 칸 **Lectern 설정**은 Lectern 의 것이고, 아래 칸 **AI 도구에 건네는 것**은 AI 도구의 파일이다. 버튼과 요청 글의 이름은 쓰는 AI 도구를 따른다.

| 설정 | 고르는 것 | 자세히 |
|---|---|---|
| 쓰는 AI 도구 | Claude Code(기본) · Codex · Antigravity · OpenCode · 여럿. 화면의 이름('Codex로 보내기')과 요청 글이 말하는 지시 파일 · 스킬 폴더가 따른다. Lectern 이 도구를 실행하지는 않는다 | [AI 도구와 함께](7-AI-도구와-함께.md) |
| Claude Code 에 Lectern 알려 주기 | 넣을 곳(모든 폴더 (개인) · ○○ 폴더만) → 작성 안내를 읽고 정리하라는 요청 글 복사 · ▣ · **예제 열기** | [보내기와 요청 글](7.2-보내기와-요청-글.md) |
| PowerPoint·Word 스킬 | 넣을 곳 → 없는 것과 다른 것만 설치하라는 요청 글 | [스킬](7.3-스킬.md) |
| 글쓰기 스타일 | **스타일 고르기…** → 켤 곳(○○ 폴더에서 켜기 · 모든 폴더에서 켜기 · ○○ 폴더에서 끄기) → 설치하고 켜라는 요청 글. Codex · Antigravity · OpenCode 는 개인 지시 파일이나 그 폴더의 AGENTS.md 에 '글쓰기' 절로 | [글쓰기 스타일과 다듬기](7.4-글쓰기-스타일과-다듬기.md) |
| 내 문체 | 내가 직접 쓴 글로 내 문체 노트(개인 폴더에 하나)를 만들라는 요청 글 — 견본은 끝에 `@경로` 로 | [글쓰기 스타일과 다듬기](7.4-글쓰기-스타일과-다듬기.md) |

| AI 도구에 건네는 것 | 동작 |
|---|---|
| 넣을 곳을 고르면 | 아래 **바뀌는 파일**에 전체 경로와 할 일(새로 만듦 · 바꿈 · 그대로 · 절 넣기 · 한 값 적기 · 옮김) |
| 지금 상태 | Lectern 이 개인 폴더(`~/.claude` 등)와 열린 폴더의 정해진 파일 몇 개를 읽기만 한다 — 설정 파일에서는 `outputStyle` 값 하나만 |
| 파일을 쓰는 것 | 요청 글을 받은 AI 도구가 지금 상태를 알리고 물은 뒤 |
| `.claude` 안에 쓸 때 | Claude Code 가 허락을 한 번 더 묻는다 — 바뀌는 파일에서 본 것과 같으면 허락한다 |

## 고급 — 설정 파일에서만 고치는 것

**설정 파일 열기**는 `%APPDATA%\Lectern\config.json` 을 편집기로 연다. 저장하면 반영되고, 트리에 영향을 주는 설정은 **F5** 를 누르면 다시 불러온다. 고급 칸 아래에 편집기 경로 · 제외 폴더 · 터미널 셸의 지금 값이 보인다.

| 키 | 하는 일 |
|---|---|
| `editor` | 코드 파일을 열 편집기의 전체 경로. 비워 두면 VS Code(`code`) |
| `exclude_dirs` | 트리에서 뺄 폴더 이름 (예: `["data", "output"]`) — 기본 제외 폴더(`node_modules` · `dist` · `build` · `venv` 등)에 더한다. '자료' 목록에는 접혀 나온다 |
| `html_exclude_dirs` | 이 이름의 폴더 안 html 은 문서로 보지 않는다 — 기본(`src` · `public` · `web` 등)에 더한다 |
| `terminal_shell` | 터미널 셸의 전체 경로 (예: PowerShell 7). 비워 두면 Windows PowerShell. 바꾼 뒤 터미널의 ↻ 로 다시 시작하면 듣는다 |
| `ref_windows` | 사용설명서 · 예제 가이드를 따로 창에서 — `auto`(기본) · `on` · `off`(메인 창을 덮어서) |

경로의 역슬래시는 `\\` 로 두 번 쓴다. 파일에 문법 오류가 있으면 기본 설정으로 열리고 오류 위치를 알린다.

## 설정 원문 보기

고급의 **설정 원문 보기**와 'AI 도구' 항목마다의 **원문 보기**는 파일을 고치지 않고 원문 그대로 보인다 — Lectern 설정, 작성 안내 요약, 내 문체 노트, Claude Code 설정(개인 · 이 폴더), 글쓰기 스타일(설치한 것과 Lectern 에 든 것), 스킬(SKILL.md 와 그 폴더의 파일).

| 보이는 것 | 뜻 |
|---|---|
| 번호가 있는 줄 | 파일의 원문 |
| 번호 없는 흐린 `//` 줄 | Lectern 이 단 설명 — 파일에는 없다. 열쇠마다 뜻, 기본 값, 바꾸는 곳(설정 창의 어느 분류 · 'Lectern 이 기록' · '이 파일에서만') |
| 알림 | 형식이 틀린 값, Lectern 이 쓰지 않는 열쇠 |

Claude Code 개인 설정에는 비밀 값이 있을 수 있으니 화면을 나눌 때 조심한다.

## 설정 폴더

설정은 `%APPDATA%\Lectern` 에 있다. Lectern 을 지워도 남아서, 다시 설치하면 최근 폴더 · 스타일이 그대로다.

| 이름 | 무엇 | 여는 곳 |
|---|---|---|
| `config.json` | Lectern 의 설정 — 설정 창 · 툴바에서 바꾸면 Lectern 이 쓴다 | 고급 **설정 파일 열기** |
| `cache` | 제목 기억 — 프로젝트마다 문서의 제목과 슬라이드 여부 | 지워도 다시 만든다 |
| `styles` | 내 스타일 (CSS) | 보기 **스타일 폴더 열기** |
| `md-styles` | md 문서의 내 스타일 | md 문서 스타일 창 **스타일 폴더 열기** |
| `templates` | Lectern 슬라이드의 내 템플릿 묶음 | 템플릿 갤러리 **템플릿 폴더 열기** — Lectern 탭으로 |
| `pptx-styles` | pptx 스타일 | 'pptx 로 전환' 창 **보관소 폴더 열기** |
| `layouts` | 내 지면 틀 | 인쇄·내보내기 **틀 폴더 열기** |
| `docx-styles` | 내 Word 양식 | 내보내기 창 **양식 폴더 열기** |

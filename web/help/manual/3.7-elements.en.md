# Elements

> Lay out the tables, images and charts of the project (or a chosen folder) in one document tab, as they really look, and compare them. Filter by content, and hand what is left to a new document or your AI tool.

Elements opens as **one document tab**. The document you were reading stays in its own tab. The first time it opens, it takes a moment to read the documents.

## Opening it

| What you want to do | How |
|---|---|
| The whole project | The **Elements** button on the tab bar — opens with the kind you last chose. If it is already open, goes to that tab |
| With a kind | A kind (Tables · Images …) on the **Elements** line of the folder overview (**Overview** on the tab bar) |
| Just one folder | The same line in that folder's overview · right-click the folder in the tree: **Elements in this folder (tables, figures…)** |
| A folder's files by type | Right-click a folder in the 'Code' · 'Other files' list: **Collect the files in this folder by type** |
| By name | `Elements` in **Ctrl+Shift+P** (the command list) |

| Situation | Where it opens |
|---|---|
| From a tab showing a document · code | A new document tab — what you were reading stays |
| From a folder overview | In place — **Alt+←** goes back to the overview |
| When an Elements tab is already open | That tab changes its scope · kind (one tab per project) |

## The screen

| Place | What |
|---|---|
| Head | Scope (the whole project · a folder — **All** goes back to the whole project), what to collect, kind buttons |
| Sticky line | Filter box · **Tree order** · **To new document** · **To Claude Code** · the count — it stays at the top while you scroll |
| List | One group per document — the document name, then what that document has |
| Contents panel (right) | The outline of what is collected — documents and the elements under them. Click one to go to that block |

| What to collect | What it collects | Buttons to choose |
|---|---|---|
| **In documents** | Tables · images · charts · boxes · callouts · diagrams · code · math · to-dos · links · sources | Kind (such as 'Tables 7') |
| **Doc info** | Documents grouped by the values in their front matter | Key |
| **File types** | Document · code · other files by format | Format (such as 'PDF 2' · 'Excel 3' · 'PNG 10') |

## In documents

| Kind | On the screen | Buttons below |
|---|---|---|
| Tables · boxes · callouts · code · math | As they really look, one per row — with the caption and the 'Note:' · 'Source:' lines | — |
| Images · charts · diagrams | Really drawn, in a grid two or three across — when several documents use the same image, only the first shows, with **+N more** | — |
| To-dos | One line each — the documents' checklists (`- [ ]` · `- [x]`) | **Open** (default) · **Done** · **All** |
| Links | One line each — with their target (document · code · other file · folder · web). If the file it points to doesn't exist, **Broken** in red | **Broken** · **Web** · **In the project** |
| Sources | One line each — lines such as 'Source: …' under tables and images, and footnotes | **Sources** · **Footnote** |

Each block has a **source line** above it — the section name, a number and size such as 'Table 3 · 6 × 2', and the source line numbers. An element is drawn when its group comes near the screen. Nothing is edited here — to change something, go to its document from the source line.

To-dos, links and sources don't appear in the contents; they show only in Elements. Elements from html documents are laid out too, but that document's own styling does not come along.

## Filtering

| What you want to do | How | Result |
|---|---|---|
| Narrowing by content | A word in the filter box (`copper`) | Only what has that word in its name · section · document or in **its table cells · caption · note and source lines · code**. The matched words are marked |
| Two words | Put a space between them (`LME aluminium`) | Only what has both |
| To the filter box | **Ctrl+F** | On this screen it goes to the filter box instead of Find |
| To the first block | **Enter** in the filter box | Only moves the focus — press it again to go to that document |
| Clearing | **Esc** in the filter box | Everything shows again |
| Changing the order | **Tree order** button | Click it for most recently changed first |

Images · charts · diagrams match only by caption · section · alt text (text inside a picture is not read). Over 800, only the first 800 show.

## Going to the document

| What you want to do | How | Result |
|---|---|---|
| To that place | Click the source line · **Enter** on a block · click a one-line row | This tab goes to that place in the document — outlined briefly |
| Back to Elements | **Alt+←** | The filter · kind · where you were, all as they were |
| Opening while keeping this screen | **Ctrl+click** · middle button | In a new document tab, behind |
| If that document is open in another tab | Click the source line | Goes to that tab and that place — **Alt+←** there returns to where you were reading |
| Side by side with a document | **Spread all** on the document tab strip | The Elements tab and the document on one screen |

## Handing over

| Button | What it does |
|---|---|
| **To new document** | Puts what is shown into one new Markdown document, in document order — it is created once you set the path. Items from html documents have no source and are left out |
| **To Claude Code** | Puts the locations of what is shown (`@document lines 12-19 ('caption'), …`) into the terminal on one line — Enter is not pressed. Then type what you want, such as 'find where the numbers differ' |

What goes over is exactly what the filter left. The button is named after **Your AI tool** in Settings ('To Codex'). It takes up to 100 locations — narrow it with the filter if there are more. The text goes to the terminal you used last — [Sending and requests](7.2-sending-and-requests.en.md).

## Right-click menu

| Item | What it does |
|---|---|
| **Show in document** | Goes to that place (**Enter**) |
| **Copy source** | The source of that part of an md document |
| **Copy location** | `@document lines 12-17 ('caption')` |
| **Copy link address** | The target of a link item |
| **Clip** · **Send to a document…** | That one to the Clip tab · straight to an open document tab or a new document — [Highlights, notes and clip](3.5-highlights-notes-clip.en.md#clip) |
| **Send to new note** | To this project's notes — with where it came from |
| **Clip all shown** | Everything in the list now, in document order — as narrowed by the filter · buttons |
| **Copy @path** · **Copy full path** | The document's path (**Open in external editor** · **Show in Explorer** too) |

Click **▣ Terminal** next to a copy item to put that text into the terminal (Enter is not pressed).

## Captions

| What is read as a caption | Example |
|---|---|
| The line right above a table · image · chart · diagram (below the image in older documents that put it there) | `Table 1. …` · `<Table 2>` · `[Figure 1]` · `〈Table Ⅱ-15〉` (the Korean words work too) |
| A short line written all in bold | Right above it |
| html documents | `<caption>` · `<figcaption>` |

The caption is laid out with its element, and it is also attached in the contents panel and in the locations handed to your AI tool.

## Doc info

Groups documents by their front matter (the settings at the very top of a document — such as `status: review` · `owner: research team` · `tags: [a, b]`).

| Situation | Behavior |
|---|---|
| Key buttons | One for each key in the front matter |
| Choosing a key | Documents are grouped by that key's values — dates newest first |
| Indented sub-keys | Shown joined with a dot, like `author.name` |
| Documents without that key | Under 'No value' at the end |
| Clicking · right-clicking a document | Opens it · copy `@path` and the terminal |

## File types

| Situation | Behavior |
|---|---|
| Format buttons | For documents · code · other files, by format — the files of the chosen format are collected |
| Excel · PowerPoint · Word · Hangul (HWP) | Counted under one name, whatever the extension |
| Image files | Shown as thumbnails |
| Order | **Tree order** button — click it for most recently changed files first |

## Closing and reopening

| Situation | Behavior |
|---|---|
| **Ctrl+W** · the × on the tab | Closes the Elements tab |
| Opening it again | Starts with what you last chose to collect · the kind · the order |
| A document in scope changes outside | Only that document's elements are read and drawn again — the filter stays |
| Starting Lectern again | The Elements tab is not restored |

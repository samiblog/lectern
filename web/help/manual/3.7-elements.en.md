# Elements

> Collect the tables, images, to-dos and links, document info and files of the project (or a chosen folder) by kind in one place, and click one to go there.

This is the **Elements** tab in the sidebar. Choose what to collect at the top. The first time it opens, it takes a moment to read the documents.

| View | What it collects | Buttons to choose |
|---|---|---|
| **In documents** | Tables · images · charts · boxes · callouts · diagrams · code · math · to-dos · links · sources — by kind and by document | Kind (such as 'Tables 7') |
| **Doc info** | Documents grouped by the values in their front matter | Key |
| **File types** | Document · code · other files by format | Format (such as 'PDF 2' · 'Excel 3' · 'PNG 10' · 'PY 12' · 'IPYNB 2') |

## In documents

| Kind | What | Buttons below |
|---|---|---|
| Tables · images · diagrams | The caption is the name — with the number and size below it, such as 'Table 3 · 6 × 2' (see 'Captions' below) | — |
| Charts | Vega-Lite · ECharts · Plotly as thumbnails — each is drawn when it comes into view in the list (Graphviz · Mermaid are diagrams) | — |
| To-dos | The documents' checklists (`- [ ]` · `- [x]`) | **Open** (default) · **Done** · **All** |
| Links | Links in documents and path notation such as `src/x.py:42` — with their target (document · code · other file · folder · internet). If the file it points to doesn't exist, **Broken** in red | **Broken** |
| Sources | Lines such as 'Source: …' under tables and images, and footnotes | — |

To-dos, links and sources don't appear in the contents; they show only in Elements.

## Captions

| What is read as a caption | Example |
|---|---|
| The line right above a table · right below an image | `Table 1. …` · `<Table 2>` · `[Figure 1]` · `〈Table Ⅱ-15〉` (the Korean words work too) |
| A short line written all in bold | Right above a table · right below an image |
| html documents | `<caption>` · `<figcaption>` |
| Without a caption | Tables are named by the header row, images by their alt text |

## Picking and going

| What you want to do | How | Result |
|---|---|---|
| To that place | Click an item | Goes to that place in the document and outlines it briefly |
| Opening while keeping the document you were reading | **Ctrl+click** · middle button | In a new document tab, behind |
| Narrowing the list | Filter box (name · section · document) | Only what matches — over 800, only the first 800 show |
| Changing the order | **Tree order** button | Click it for most recently changed first |
| Just one folder | **Elements** in the folder overview · right-click a folder in the tree: **Elements in this folder (tables, figures…)** | That folder and its subfolders only — **All** goes back to the whole project |
| A folder's files by type | Right-click a folder in the 'Code' · 'Other files' list: **Collect the files in this folder by type** | That folder only |

## Right-click menu

| Item | What it does |
|---|---|
| **Show in document** | Goes to that place (**Enter**) |
| **Copy source** | The source of that part of an md document |
| **Copy location** | `@document lines 12-17 ('caption')` |
| **Copy link address** | The target of a link item |
| **Clip** · **Send to a document…** | That one to the Clip tab · straight to an open document tab or a new document — [Highlights, notes and clip](3.5-highlights-notes-clip.en.md#clip) |
| **Send to new note** | To this project's notes — with where it came from |
| **Clip all shown** | Everything in the list now, in document order — as narrowed by the filter · buttons |
| **Copy @path** · **Copy full path** | The document's path (**Open in external editor** · **Show in Explorer** too) |

Click **▣ Terminal** next to a copy item to put that text into the terminal (Enter is not pressed). Items from html documents have no source, so they are not clipped.

## Doc info

Groups documents by their front matter (the settings at the very top of a document — such as `status: review` · `owner: research team` · `tags: [a, b]`).

| Situation | Behavior |
|---|---|
| Key buttons | One for each key in the front matter |
| Choosing a key | Documents are grouped by that key's values — dates newest first |
| Indented sub-keys | Shown joined with a dot, like `author.name` |
| Documents without that key | Under 'No value' at the end |
| Clicking · right-clicking a document | Opens it · copy `@path` and the terminal |

## File types

| Situation | Behavior |
|---|---|
| Format buttons | For documents · code · other files, by format — the files of the chosen format are collected |
| Excel · PowerPoint · Word · Hangul (HWP) | Counted under one name, whatever the extension |
| Image files | Shown as thumbnails |
| Order | **Tree order** button — click it for most recently changed files first |

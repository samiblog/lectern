# 업무 카드

> 폴더에 `WORK.md` 를 기본 틀로 만들고, 머리 설정·할 일·일정을 정해진 줄 모양으로 적는다. 읽지 못한 줄은 '확인할 줄'에 모인다.

## 만들기

| 하려는 일 | 방법 |
|---|---|
| 프로젝트 맨 위에 | 프로젝트 탭이나 문서 트리의 빈 곳 우클릭 **업무 카드 만들기…** |
| 하위 폴더에 | 사이드바에서 그 폴더 우클릭 **이 폴더에 업무 카드 만들기…** — 문서가 없는 폴더는 문서 트리에 나오지 않으니 '자료' · '코드' 목록의 폴더를 우클릭 |
| 이미 있으면 | 메뉴가 **업무 카드 열기** |
| 열지 않은 폴더에 | 업무 현황의 **폴더 더하기** — WORK.md 가 없으면 열고 만들지 묻는다 |

창에서 종류 · 제목(처음엔 폴더 이름) · 마감 · 우선을 정하고 **만들기**를 누르면 기본 틀로 `WORK.md` 를 만들어 연다. 만든 폴더는 업무 폴더 목록에 들어간다. 마감 칸은 `YYYY-MM-DD` 로 쓰거나(`2026.11.20` 도 읽는다) 옆의 달력 단추 · **Ctrl+;** 로 고른다.

| 종류 | 틀 | 기본으로 골라지는 곳 |
|---|---|---|
| 업무 | 기획 메모 · 현재 상태 · 할 일 · 일정 · 결정 · 기록 · 자료, 상태 '예정' | 프로젝트 맨 위 |
| 묶음·총괄 | 같은 절, 상태는 비움 — 하위 업무에서 셈 | (고를 때) |
| 작은 업무 | 기획 메모 · 할 일 · 일정 · 기록만, 상태 '예정' — 이슈리포트 하나 같은 일 | 하위 폴더 |

## WORK.md 의 칸

| 부분 | 쓰는 것 | 업무 현황이 읽나 |
|---|---|---|
| 머리 설정 | `status`(예정 · 진행 · 지연위험 · 막힘 · 보류 · 완료 · 중단), `priority`(상 · 중 · 하), `due`(YYYY-MM-DD), `start`(YYYY-MM-DD — 간트 · 달력의 시작) | 읽음 — 상태 · 우선 · 마감 · 시작 |
| `# 제목` | 업무 이름 | 읽음 |
| 할 일 | `- [ ] 초안 3장 작성 (11/14)` — 끝의 괄호가 기한 | 읽음 — 체크 칸과 기한 |
| 일정 | `- 2026-11-12 14:00-15:00 팀장 보고`, `- 2026-11-20 종일 워크숍` | 읽음 — 오늘 일정과 알림 |
| 기획 메모 | 생각나는 대로 — 할 일 · 날짜를 써도 | 읽지 않음 — 정리할 때 옮김 |
| 현재 상태 · 결정 · 기록 · 자료 | 자유롭게 | 읽지 않음 |

## 읽는 규칙

Lectern 은 머리 설정과 할 일 · 일정의 줄 모양만 본다. 절 이름과 차례는 자유다.

| 쓴 것 | 읽는 법 |
|---|---|
| 연도를 뺀 기한 `(11/14)` | 오늘에서 가장 가까운 해 |
| 날짜 | `2026-11-14` 가 기본. `2026.11.14` · `2026/11/14` · `2026-11-5` 도 |
| 영어 값 | `active` · `done` 등도 |
| 키 이름 | 대문자(`Status`) · 콜론 앞 빈칸도 |
| 하위 폴더의 `WORK.md` | 그 안의 일 하나 — [업무 나무](8.2-업무-나무-칸반-간트.md#업무-나무) |

## 고치기

| 고칠 것 | 방법 |
|---|---|
| 상태 · 마감 | 머리 설정 우클릭 **문서 정보 고치기** |
| 할 일 | 체크 칸 누르기 |
| 기록 같은 글 | 한 줄 편집 |
| 다른 WORK.md 를 열지 않고 | 업무 나무 · 칸반 · 간트에서 — [상위에서 고치기](8.2-업무-나무-칸반-간트.md#상위에서-고치기) |
| 정리되지 않은 기획 메모 | [기획 메모](8-업무-관리.md#기획-메모) |

## 확인할 줄

오타나 지운 곳 때문에 읽지 못한 줄은 버리지 않고 업무 현황의 **확인할 줄**에 모은다. 누르면 그 WORK.md 의 그 줄로 간다. 업무 나무의 그 업무 줄에 '확인할 줄 n' 이 붙고, 켤 때의 요약(오늘의 업무 알림)에도 나온다.

| 읽지 못한 것 | 예 |
|---|---|
| 정해진 값이 아닌 상태 | `진핸` |
| 키 이름 오타 | `stauts` — 맞는 키를 알려 준다 |
| 읽지 못한 마감 · 할 일 기한 | `(11/31)`, 괄호 빠짐 |
| 체크 칸 오타 | `- []` · `-[ ]` |
| 없는 날의 일정 | `2026-11-31` |
| 읽지 못한 시각 | `25:00`, `14:00-1500` — 시각 없는 일정으로 남긴다 |
| 내용 없는 일정 | — |
| 머리 설정 | 닫는 `---` 가 없음 |
| 시작 | `start:` 를 읽지 못하거나 시작이 마감보다 늦음 |

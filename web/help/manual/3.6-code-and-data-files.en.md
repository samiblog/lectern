# Code and data files

> See code with line numbers and language colors, CSV and Excel as tables you can filter, sort and count, and tables as charts right where they are. Image files open in Lectern too.

## By file

| File | One click | Double-click | Editing |
|---|---|---|---|
| Code ('Code' list) | The code view — line numbers and language colors (**Enter** too) | The editor | **F2** line edit · **Ctrl+E** full editor |
| `txt` · `log` ('Other files' list) | With line numbers | The default app (Notepad) | txt in edit mode · log is view only |
| `csv` · `tsv` ('Other files' list) | A table | The default app (Excel) | Edit mode |
| `xlsx` · `xlsm` ('Other files' list, or right-click **Open in new tab**) | A table with sheet tabs | Excel | View only — edit it in Excel |
| Old formats `xls` · `xlsb` | Not viewed in Lectern | Excel | — |
| Images `png` · `jpg` · `gif` · `webp` · `bmp` · `svg` · `ico` · `avif` (**Images** in the 'Other files' list) | The image view — fitted to the pane, click the image or **Actual size** for full size. Resolution and size in the status bar | The default app | View only — edit it in the default app |
| Images such as `tif` · `heic` | Not viewed in Lectern (the screen cannot draw them) | The default app | — |

Data files open in Lectern when clicked in Recent, in file names in Search and in Elements, and from links or paths such as `data/x.csv:5` in documents too. Code is never run.

## Code view

| What you want to do · situation | How · behavior |
|---|---|
| Seeing the structure | The contents on the right — classes · functions · methods and divider comments such as `# ---- drawing ----` (keys · sections in config files). Click one to go to that line |
| Buttons · line menu | **Open in external editor** · **Copy all** at the top. Right-click a line — **Copy line** · **Copy location** · **Open in the full editor** · **Open this line in external editor** |
| Arriving from a path · link in a document | At that line — **Alt+←** returns to the document |
| When the code you are viewing changes | Redrawn within two seconds, with the changed lines marked briefly |
| Files over 4 MB or not text | A note says to open them in an editor |

## CSV tables

The separator (comma · semicolon · tab) and the header row are detected automatically; change the header with **First row is the header** in the bar. CSV saved by Excel (CP949, the Korean Windows encoding) and 'Unicode text' (UTF-16) are read too (the encoding shows in the status bar).

| What you want to do | How | Result |
|---|---|---|
| Filtering | Type in the box under the header row | Only rows containing that text. `!text` excludes · `=text` matches exactly · numbers take `>100` · `<=5` · `10..20`. Filter several columns together, and **Clear filters** resets them |
| Sorting | Click the header row | Ascending → descending → original order |
| Stats | The row above the table · the **Stats** checkbox in the bar (all columns at once) | Number columns: count · sum · mean · min · max · median; text columns: count · distinct values · most common value. When you filter, from the remaining rows |
| Copying a row | Right-click a row: **Copy line** (the source) · **Copy location** | Row numbers are the source's line numbers |

Up to 2,000 rows are shown; filter to narrow larger files (counts and stats use all rows). The **Stats** checkbox stays as you set it for other CSV and Excel tables and for the next run.

## Editing CSV and text

`csv` · `tsv` · `txt` files are edited in edit mode (**Edit** on the tab bar · **Ctrl+E**), as source. Press **F2** or **Enter** in the table or text to open it at that line.

| Situation | Behavior |
|---|---|
| Saving (**Ctrl+S**) | The table is redrawn — filters and sorting stay |
| Encoding | Kept as it was — CP949 stays CP949, UTF-16 stays UTF-16 (shown in the editor header). Excel still opens it without broken characters. If you add characters CP949 can't hold (such as emoji), the file is not saved and Lectern names those characters |
| **Tab** | Types a tab character — tabs show as → (TSV columns) |
| Table cells | Not edited in place as in Excel — you edit the source line (commas and quotes as they are) |
| `log` · files over 2 MB | Not edited (a log is a file that programs keep appending to) |

## Excel

Filter, sort, stats and First row is the header work as in CSV. Switch sheets with the **sheet tabs** under the header (hidden sheets in italics).

| What | Behavior |
|---|---|
| Columns · rows | Excel's column letter (A · B · C…) before each column name; row numbers are Excel's row numbers. Rows without values are left out |
| Cell values | What Excel shows — thousands separators · percentages · dates · decimal places. Formula cells show the calculated value (hover for the formula). Colors · fonts · merged cells are not shown |
| Right-clicking a cell | **Copy this cell** (with its name, such as B3) · **Copy this row** · **Copy location** (`@data/prices.xlsx sheet 'Q1' line 3`) |
| **Copy all** | The current sheet as tab-separated text — pasted into Excel, it fills the cells |
| Sending to AI tools (Claude Code and others) | Focus the rows and press **Shift+→** |
| Limits | 50,000 rows · 1,000,000 cells per sheet — beyond that, the bar says so |

## Sheets with several tables

If a sheet has a title row on top, several header rows or several tables, it is split into tables, the largest one is shown, and buttons appear above it. Clean sheets have no buttons. CSV works the same way.

| What you want to do · situation | Behavior |
|---|---|
| Picking a table | **Table 1** · **Table 2** … — **Whole sheet** (**Whole file** for CSV) shows it as received. Row numbers stay the original ones |
| Where it splits | Blank rows · blank columns (a spacer column inside a table and blank rows inside the body stay in the same table) |
| A single-cell row above a table · `Source:` · `Note:` rows below it | Becomes the title (`Unit: kt` becomes the chart's unit) · left out of the table |
| Header rows | The rows above where the numbers start. Several rows are joined, like `Imports · Copper` — merged cells carry the left value across the merged range |
| If the guess is wrong | Change the number of rows with **Header rows −** · **+**, or pick rows in the whole sheet and right-click **Use this range as a table** |
| Remembering | The chosen table and number of header rows are kept until you quit the app. The file doesn't change |

## Data analysis

| What you want to do | How | Result |
|---|---|---|
| Seeing a summary | The summary line above the table | `Monthly · 2015-01 ~ 2026-09 · 6 numeric columns · 2 blanks` — when you filter, from the remaining rows |
| Adding · removing calculated columns | Right-click a number column header · **×** in a calculated column header | % vs previous period · % vs same period last year (12 back for months, 4 for quarters) · difference · cumulative · moving average · index with first value = 100. They have their own color, and filters · sorting · stats · charts work on them |
| Copying the shown table | **Copy shown table** | With filtered rows and calculated columns — pasted into Excel, it fills the cells |
| As a table in another document | **Send to a document…** | As a Markdown table (up to 500 rows) |

Calculated columns exist on screen only — they are never written to the file. They stay when the file changes and is redrawn, but are gone when you open the file again. Calculations use the filtered rows. A table stacked by item has several rows for the same period, so it isn't calculated and a note says so — filter by item first, then calculate, and you get that item's time series. After a missing month, the % vs previous period of the following month is blank.

## Viewing a table as a chart

See a table as a line or bar chart right where it is. It only views — documents and files don't change.

| What you want to do | How |
|---|---|
| Opening | Right-click a table in a document: **View as chart** (only those rows, if you picked table rows) · **View as chart** in the CSV · Excel view (the filtered rows as they are) · right-click a column header |
| Shape · axes | **Auto** (levels as bars, rates as lines — levels become lines past 36 points) · **Line** · **Bar**. When levels and growth rates are mixed, **Level** · **Growth rate** · **Both** (two axes at most) |
| Series | Turn them on and off in the list on the left — up to 6 at first |
| Fixing a wrong guess | **Rows↔Columns** · choosing series |
| Values · zoom | Hover for values; with many points, zoom with the bar below |
| Closing | **Esc** |

## What the chart guesses

| What it guesses | Rule |
|---|---|
| Time | `2026` · `2026-03` · `2026.3` · `202603` · `2026M03` · `2026-03-15` · `2026. 3. 15.` · `3/31/2026` · `2026Q1` · `1Q26` · `2026년 1분기` · `2026년 1/4분기` · `2026년 3월` (Korean quarter and month forms) · `Mar-26` · `2026H1` · `FY2026` · `2026E` and so on |
| Order · direction | Oldest first, even in tables with the latest row on top. If the header row is periods (`2024` · `2025` · `2026`), rows and columns are swapped. Text columns before the periods (item · unit in tables from ECOS, the Bank of Korea's statistics service) become series names and units |
| Units · growth rates | The unit comes from brackets in the header (`Price (USD/t)`), otherwise from the table caption (`Unit: kt`). `%` · `YoY` and similar words (Korean ones too) mark growth rates — mixed with levels, they go on two axes |
| Gaps | Blank · `-` · `n.a.` · `x` · `#DIV/0!` — not zero |
| Negatives · marks | `(1,234)` · `△3.5` are negative; the provisional mark in `1,234p` is dropped. `▲` has more than one meaning, so it is not read as a number |
| Total · average rows | Left out unless the axis is time (they would flatten the bars) — a note above says what was left out |

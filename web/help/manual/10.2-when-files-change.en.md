# When files change

> Lectern never creates, edits or deletes files on its own — a file changes only when you choose, and only that file. What you choose and which file changes.

## Who changes files

| Who | What changes |
|---|---|
| You, choosing something in Lectern | Only the file you chose — see the tables below |
| Lectern on its own | Only the settings and remembered titles in the settings folder (`%APPDATA%\Lectern`) |
| Commands typed in the terminal | Whatever the command does — it is an ordinary PowerShell. Lectern did not do it |
| AI tools (Claude Code and others) | The AI tool writes. Lectern only puts the request into the terminal, and you press Enter |

## Editing in the reading view

Changes are saved to the document the moment you make them, and **Ctrl+Z** undoes them one by one. Moving the current line, picking lines, focus and folding do not change the file.

| What you do | Where it changes |
|---|---|
| Line edit — **Enter** in the cell | That line. A new line goes in when you write in it, and **Esc** in a cell drops your change |
| Adding · splitting · joining · moving · deleting · duplicating lines · level | The picked lines — and the following numbers in a numbered list |
| Line kind and format keys | The picked lines · the selected text |
| Clicking a checkbox | The `[ ]` · `[x]` of that to-do line |
| Find and replace | The matching places in that document |
| Adding, moving or deleting a table or image | Also the caption numbers and the cross-reference links that point to them — only in documents whose numbers were in order |
| Adding, moving or deleting a numbered heading | Also the heading numbers and the section links inside this document |
| Applying an md document style | That document's headings and section links |
| Clipping · editing a clip box | One md per box in the project's `.lectern/clips/` — made when you first clip. Deleting a box sends it to the Recycle Bin |
| Send from Clip | The receiving document — a document open in a document tab, or a new document |
| **Put data into the document** on a chart | That chart's source |
| New slide · duplicate · move · change template in Lectern slides | That slides document |

On a single current line, change keys (delete · move · line kind · level) take two presses — so a key pressed while reading does not change the file.

## Saving in the full editor

| File | Saving (**Ctrl+S**) |
|---|---|
| md · html documents · code | UTF-8 text files only, up to 2MB |
| CSV · TSV · text | In the original encoding (UTF-8 · UTF-16 · CP949) |
| All files | Line endings (CRLF · LF), BOM and file attributes stay as they are. Read-only files are not saved |
| A file another program changed in the meantime | Lectern asks whether to overwrite |
| Logs · Excel | View only |

## Creating, renaming and deleting

| What you do | What appears or changes | Safeguard |
|---|---|---|
| New md document | One document in the chosen folder — one `# Title` line (plus two sample headings if the style is numbered) | Not created if the name is taken |
| New Lectern slides | One document — the front matter and the first slide of the chosen template | The same |
| New code · data file | One empty file — a header row line for CSV · TSV, and a UTF-8 BOM for CSV too | The same. Lectern only creates it and never runs it |
| New folder | One folder with the name you gave | The same |
| Rename (**F2**) | The one file you chose — within the same folder | Never overwrites. Links in other documents are not updated |
| Delete document | The one document you chose — Lectern asks first and sends it to the Recycle Bin | Code and data files are not deleted. Nothing is deleted on a drive without a Recycle Bin |
| Pasting or dragging in an image | One image in the `name-images` folder next to the document, and the image line in the document | Never overwrites |

There is no moving. Folders are not renamed either.

## Notes and work

| What you do | File that changes |
|---|---|
| Writing notes | The project's `.lectern/notes.md` only — created when you first write a note |
| Make work card | One `WORK.md` in the chosen folder — only if there is none, from the default template |
| Add event (**Alt+S**) | One line at the end of the 'Schedule' section of the chosen WORK.md — if there is no such section, it is made at the end of the document |
| Changing things in the work tree · kanban · Gantt | One line of that task's WORK.md — status · due · start · priority · to-do check · deadline · adding a to-do |

On the work side, Lectern reads the file again before writing, and if that line or the file changed in the meantime it does not write and tells you.

## Export and save

| What you do | File created | If the name is taken |
|---|---|---|
| **Save as PDF…** · **Save as html…** · **Save as Word…** | One file where you chose in the save dialog | Windows asks whether to overwrite |
| Preview in the export window · **Print…** | None — the preview stays in memory, and printing goes to the print dialog | — |
| **Convert to pptx** | One pptx next to the Lectern slides | Never overwrites — uses a new name such as `Report 2.pptx` |
| **Convert to html** | One presentation html next to the Lectern slides | The same |
| **Save this slide as a template…** | One slide in the 'My templates' set in the settings folder's `templates` | Existing slides are not changed |
| **Make a style from this document** | One new file in the settings folder's `md-styles` | Never overwrites |
| **Save** in **Make my style** | One new CSS file in the settings folder's `styles` (not made if the name exists) | Only files made by that window are replaced — after asking, and not if the file changed in the meantime. Hand-written styles are never changed |

Nothing is written inside the Lectern program folder (the installed samples and so on) by any route — when you open it, it is view-only and the terminal does not open either.

## What Lectern writes and reads on its own

| Where | What |
|---|---|
| `%APPDATA%\Lectern\config.json` | Values chosen in Settings and the toolbar, open tabs, recently opened folders, window size, and the last document and position for each project |
| `%APPDATA%\Lectern\cache` | Remembered titles — only the titles of documents and whether each is slides, per project. No body text or summaries, and rebuilt if deleted |
| `styles` · `templates` and the like in the settings folder | Made as empty folders, if missing, when you click the button that opens them — the files inside are only read (apart from the saves above and 'Make my style') |
| The open project folder | Only that folder and below are read — hidden items (`.git` · `.claude` and the like) are not looked at |
| Folders in the work folder list | Only that folder's `WORK.md` — even after you close the tab |
| Personal folder (`~/.claude` and the like) | A few fixed files are only read, to show how things stand under 'AI tool' in Settings |

## Internet

Lectern never connects to the internet on its own — there are no update checks, analytics or web fonts.

| What | Does it go to the internet |
|---|---|
| Web (https) images in documents | Only while **Show web images** under 'View' in Settings is on (on by default) — the site is not told which document the image is in. If an image cannot be loaded or takes more than 15 seconds, it becomes a link |
| html documents | Scripts, web CSS and fonts are blocked — only images follow the setting above |
| My styles · page layouts | The parts that load fonts or images from the internet are removed — only fonts on the PC are used |
| Charts | Only data in the document or in the project — web addresses are not read |
| **Save as Word…** | Charts are drawn with Windows' Edge — nothing goes to the internet |
| The file made by **Convert to html** | Images, fonts and impress.js are put inside the file — only web images stay as addresses, loaded by the browser of whoever receives it |

## Terminal

| What | What happens |
|---|---|
| Commands typed in the terminal | Run exactly as typed — a command that changes files changes them |
| **▣ Terminal** · **Shift+→** · requests | Only put text in — Enter is not pressed. For several lines Lectern asks first (at a PowerShell prompt each line may become a command — while an AI tool is running, it goes into the input box as is, without asking) |
| Links in documents · other features | Never send commands to the shell. Executables and scripts are never run from anywhere |

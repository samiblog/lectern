# Schedule and alerts

> Add one event line at the end of the 'Schedule' section of the WORK.md you choose, and while Lectern is running it shows Today's work, Starting soon and Today's record alerts inside the window.

## Adding events

| To do | Mouse | Keys |
|---|---|---|
| Open the window | **Add event** on the work board · a date number in the calendar | **Alt+S** |
| Date | Today · Tomorrow · weekday buttons, the calendar button | **Ctrl+;** |
| Time | Start and end time, **All day** | — |
| Add it | **Insert** | **Enter** |
| Cancel | — | **Esc** |
| Take back what you added | **Undo** at the bottom right of the window | — |

Set the date · time · description · where it goes in the window and press **Insert**: one line goes in at the end of the 'Schedule' section of the chosen WORK.md.

## Where it goes

| Situation | What happens |
|---|---|
| What you can choose | Common, or a task that is not finished — in tree order, sub-tasks with the path of the tasks above |
| Chosen at first | The deepest task containing the document or folder you are looking at — a sub-task when you are reading a document in its subfolder |
| Opened from a date number in the calendar | In a group folder's overview or the Sub-tasks panel, that task |
| Where the line goes | The end of the 'Schedule' section. If there is no such section, one is made at the end of the document |
| Headings taken as the 'Schedule' section | `## Schedule` · `### Schedule`. Something after it in parentheses or after a colon is fine, as in `## Schedule (November)`. A task title such as `# Schedule cleanup` is not |

## When nothing is added

| Situation | What happens |
|---|---|
| The description is empty, or the end time is before the start | Not added; the reason is shown |
| The same event twice | Not prevented |
| The file changed or was deleted while the window was open | Not added; you are told |
| You are editing the same WORK.md in edit mode | Saving in the editor tells you it changed and asks |
| You edited the file after adding | **Undo** does not undo, to keep your edit, and tells you |

## Writing it yourself

You can also write it in WORK.md yourself. On the last line of the 'Schedule' section, open a new line with **Shift+Enter** and write it in the shape below.

| Event | How to write it |
|---|---|
| With a time | `- 2026-11-14 10:00 Team meeting` |
| With an end time | `- 2026-11-12 14:00-15:00 Report to the lead` |
| All day | `- 2026-11-20 all-day Workshop` |
| Repeating (every Monday) | Not there yet — write one line for each date |

## Alerts

Shown at the bottom right of the window while Lectern is running, and they stay until you close them.

| Alert | When |
|---|---|
| Today's work | Once at start (again when the date changes) — overdue · due today · due within 3 days, to-dos overdue or due today, today's events, lines to check. Nothing is shown when there is nothing to report |
| Starting soon | Once, 10 minutes before an event with a time — events that already started are not announced (waking from sleep does not bring a pile of old alerts) |
| Today's record | Once after 17:30 — active tasks whose WORK.md did not change today |

| Situation | What happens |
|---|---|
| Windows notifications · notification area | Not used |
| If the window is hidden | The alerts are waiting when you come back |
| With Lectern closed | No alerts either |
| Turning them off | **Work alerts** in the settings window (on by default) |
| Starting Lectern again | Shown alerts are not remembered, so Today's work appears again |

# Print and PDF

> Print md documents and save them as PDF in the same report layout every time, whatever the screen style, or in a page layout you pick. The preview is exactly what is saved or printed.

## Opening it

| What to do | How | Result |
|---|---|---|
| Open the Export window | **Print** at the right end of the tab bar (between Contents and Notes) | Opens with the format **PDF and print** |
| Save as PDF | Right-click the body margin → **Save as PDF…** | The same window — with **Save as PDF…** as the main button |
| Print | Right-click the body margin → **Print…** | The same window — with **Print…** as the main button |
| Find by name | **Ctrl+Shift+P** → 'Print & PDF' | The same window |

## The Export window

Pick options on the left and the preview on the right is made again with them. Use the bar above the preview for the contents, zoom and turning pages. The options are kept for next time.

| Option | Choices |
|---|---|
| Format | **PDF and print** · **One html file** · **Word** |
| Layout | **Report (default layout)** · 18 page layouts · My layouts |
| Font | Serif (Cambria; Korean text in HCR Batang, else Batang — sans-serif headings) · Sans-serif (Calibri; Korean text in Malgun Gothic) |
| Margins | Normal (top 25 · bottom 22 · sides 22 mm) · Narrow (15 mm all round) · Wide (top 30 · bottom 25 · sides 30 mm) · **Custom** — top · right · bottom · left as numbers in mm (0–80). Typing a number switches to Custom. Under 12 mm, the page header (top) or page numbers (bottom) are left out |
| Page header | Document title and date in the header from page 2 |
| Page numbers | '- 1 -' at the bottom center |

Font, margins, page header and page numbers show only with **Report (default layout)** — pick a page layout and the layout decides them. Set margins in this window — **Print…** prints pages already laid out (a PDF), so margin numbers in the dialog where you choose the printer have no effect.

| Button | What it does |
|---|---|
| **Save as PDF…** | Writes the previewed PDF where you choose in the save dialog — it opens next to the document, with the document's name. Headings become PDF bookmarks |
| **Print…** | Sends the previewed PDF to the print dialog — choose the printer · copies · pages · color there |
| **Font and layout settings…** | The print and PDF font and the page layouts in Settings |
| **Close** · **Esc** | Closes the window — after clicking inside the preview, move the mouse out of the preview first |

Lectern saves a PDF and prints that PDF, so there is no date and address header that a browser would add.

## The report layout

| Part | Look |
|---|---|
| Page | A4 · margins top 25 · bottom 22 · sides 22 mm |
| First page | Title centered |
| Page header | Document title and date from page 2 — `date` in the front matter, or today |
| Page numbers | Bottom center |
| Body font | Settings **Print and PDF font** — Serif (default) · Sans-serif |
| Tables | Heavy rules at the top and bottom. Over 12 rows, split across pages with the header row repeated on each page |
| Captions · notes · sources | Stay on the same page as their table · figure — captions centered in 11 pt, notes · sources small and on the left |
| Images | Scaled down to one page's height when taller than a page |
| Links | Black text — addresses are added only in the lists of a 'Sources' · 'References' section (or the Korean `출처` · `참고문헌` · `자료`) |
| Front matter table | Left out |
| Page break line | Moves on to the next page at that spot (**Page break** in the Insert window) |
| `[TOC]` line | Prints as a table of contents in its place |

Text size, document width, line numbers, find marks, section focus and the screen style do not reach the paper.

## Page layouts

Pick an output layout under **Layout**. The text stays the same; the cover, header, page size, fonts and colors change. PDF and html come out alike.

| Group | Layouts (the id to write in the front matter `layout:`) |
|---|---|
| Office and public sector | Government report `gov-report` · One-page brief `one-page` · Official letter (Korean) `official-letter` · Press release `press-release` · Meeting minutes `minutes` |
| Research | Research report `research-report` · Issue brief `issue-brief` · Journal paper (two columns) `paper-2col` · Manuscript (double-spaced) `manuscript` · White paper `white-paper` |
| Finance and consulting | Equity research `equity-research` · Consulting report `consulting` · Proposal `proposal` |
| Media and publishing | Magazine feature `magazine` · Newsletter `newsletter` · Book chapter `book` · Long-form web article `longform` |
| Guides | Manual or guide `manual` |
| My layouts | At the bottom of the list — layouts made from Settings |

| What to do | How |
|---|---|
| Fill the cover · header | Front matter `title` · `subtitle` · `author` · `date` · `org` (organization) · `dept` (department) and so on — the Korean keys `기관:` · `부서:` work too |
| Fill empty keys | When you pick a layout, it tells you the keys it uses that are empty → copy them with **Copy front matter sample**, paste them at the top of the document and fill them in |
| Put a summary · key points · abstract in its place | Open it as a named box `<!-- box: 요약 -->` (slot names are Korean — `요약` summary, `핵심` key points, `초록` abstract) — it moves to the layout's summary slot. If there is no slot, it stays an ordinary box in the body. The window shows the layout's box slots |
| Remember the layout in the document | Front matter `layout: research-report` (the name works too) — the window opens with that layout picked |
| Make your own layout | In Settings **Page layouts**, open the layouts folder and **Copy request for Claude Code** → paste it into the AI tool (Claude Code and others) and add the layout you want (for example 'our company's weekly report, a logo band on the first page') → the AI tool reads the writing guide and makes one html file in the layouts folder |

## In these cases

| Situation | What happens |
|---|---|
| Lectern slides | One slide per slide-sized page, in the screen colors — font · margins · page header · page numbers · layout do not apply. Hidden slides and speaker notes are left out |
| html documents | One print dialog in that document's own style (**Print / Save as PDF…**) — for a PDF, choose 'Microsoft Print to PDF' as the printer |
| While editing | Save and close the editor first — the PDF is made from the saved text |
| Spread all | The document in the pane you right-clicked becomes the PDF |
| A PDF of the same name exists | Windows asks whether to replace it |
| A PDF viewer has the file open | Close that program and save again |

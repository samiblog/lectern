# One html file

> Save an md document as one html file with all its images, charts and math inside. Send just that one file and the reader opens it safely in a browser.

## Opening it

| What to do | How | Result |
|---|---|---|
| Save as html | Right-click the body margin → **Save as html…** | The Export window opens with the format **One html file** |
| Switch the format in the window | Export window **Format** → **One html file** | The preview is made again as html |
| Save | **Save as html…** in the window | Exactly as previewed, where you choose in the save dialog — it opens next to the document, with the document's name |

## What goes in

| In the document | In the html |
|---|---|
| Look | The current screen style as it is, on one long page — pick a page layout under **Layout** and it takes that layout's look |
| Images · charts · diagrams · math | Go inside the file — just mail the one file |
| Folded sections · boxes | Unfolded |
| Contents · footnotes · cross-reference links | Still work |
| Links to other documents | Stay as text |
| App marks such as copy buttons · line numbers | Left out |
| Front matter table | Left out |
| Scripts | None — it opens safely in the reader's browser |
| When the reader prints it | The same report layout as the PDF — the layout's look if you picked one |

## Save as html and Convert to html

The two similar names work on different documents.

| What | **Save as html…** | **Convert to html** |
|---|---|---|
| Works on | md documents | Lectern slides |
| Where to open it | Right-click the body margin · Export window | Status bar |
| Result | A document read from top to bottom | An impress.js presentation — the view moves between the slides |
| Saved to | Where you choose in the save dialog | Next to the document — if the name exists, a new name such as `Report 2.html` |

In Lectern slides the html format in the Export window is turned off. html documents are already html, so they do not have this menu.

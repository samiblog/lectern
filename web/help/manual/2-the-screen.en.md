# The screen

> The seven areas of the Lectern window — where everything is and what it does.

| Area | Position | What it does |
|---|---|---|
| Toolbar | Top | Adjusting the view and opening frequently used windows |
| Project tabs | Below the toolbar | One tab per open folder |
| Document tabs | Just above the text | The documents open in one project |
| Sidebar | Left | File lists · Recent · Search · Elements · Clip |
| Contents | Right | The current document's headings and elements |
| Status bar | Bottom | Path · time · changes |
| Separate windows | Their own windows | Documents, slides, the user guide and the example guide in other windows |

# 사이드바

> 왼쪽의 네 탭 — 파일·최근 변경·검색·담기. '파일' 탭은 프로젝트의 파일을 문서·자료·코드·작업·폴더 다섯 묶음으로 보인다.

## 네 탭

| 탭 | 보이는 것 | 키 | 자세히 |
|---|---|---|---|
| 파일 | 문서 · 자료 · 코드 · 작업 · 폴더 다섯 묶음 | **Ctrl+Shift+E** | 아래 |
| 최근 변경 | 고친 차례의 파일 — 위 **문서**·**코드**·**자료** 단추로 보일 것을 고른다 (모두 켜면 섞어서 최근 것부터). 자료는 두 번 누르기나 **Enter** 로 열고, 우클릭은 '코드'·'자료' 목록과 같다. 탭 옆 숫자는 아직 열어 보지 않은 바뀐 문서 수 | — | — |
| 검색 | 모든 문서·코드의 본문과 파일 이름에서 찾기 | **Ctrl+Shift+F** | [찾기와 검색](3.2-찾기와-검색.md) |
| 담기 | 담기함들 — 문서 목록처럼 눌러 문서 탭에 펼쳐 보고, 열린 문서나 새 문서로 보낸다 (탭 옆에 지금 담기함의 개수) | **Alt+C** (담기) | [형광펜·메모·담기](3.5-형광펜-메모-담기.md) |

모아 보기는 사이드바 탭이 아니라 문서 탭 하나로 열린다 — 탭 막대의 **모아 보기** 단추나 폴더 우클릭에서. [모아 보기](3.7-모아-보기.md)

사이드바는 툴바 첫 단추나 **Ctrl+B** 로 보이고 감춘다. 경계를 끌어 폭을 바꾸고, 경계를 두 번 누르면 기본 폭이다.

## 파일 — 다섯 묶음

| 묶음 | 들어가는 것 | 누르면 |
|---|---|---|
| 문서 | Markdown · HTML 문서 (폴더 트리). PDF · 오피스 파일은 설정에서 켜면 여기로 — 아래 | 한 번 — 본문에 연다. 폴더 이름은 그 폴더의 개요 |
| 자료 | 문서도 코드도 아닌 파일 — PDF · 오피스 · 그림 · 데이터 · 압축 · 실행 파일 (PDF 는 한 번 누르면 [PDF 보기](3.8-PDF-보기.md)) | 한 번 — csv·tsv·txt·log·xlsx 는 Lectern 에서 보기, 두 번 — 기본 앱 (실행·압축 파일은 실행하지 않고 탐색기에서 선택만) |
| 코드 | 소스(py·js·ts 등) · 스크립트(ps1·bat·EViews 의 prg) · 웹(css) · 설정(json·yaml·toml) | 한 번 — 코드 읽기 화면, 두 번 — 외부 편집기 |
| 작업 | 업무 카드(폴더마다의 `WORK.md`) · 형광펜 · 할 일 — 아래 | 줄을 누르면 그 문서의 그 자리 |
| 폴더 | 문서 · 자료 · 코드를 나누지 않고 실제 폴더 구조 그대로 한 트리 — **숨긴 것까지 모두** (아래) | 파일은 위와 같다 (숨긴 파일은 보기만). 폴더 개요는 폴더 우클릭 |

묶음은 머리줄로 고른다.

| 무엇 | 동작 |
|---|---|
| 머리줄 누르기 | 그 묶음만 펼친다 (한 번에 한 묶음) — 남은 높이를 모두 쓰고 나머지는 머리줄만. 펼친 묶음은 프로젝트 탭마다 기억한다 |
| 머리줄의 수 ('문서 10'·'코드 3') | 그 묶음의 파일 수 — 거르기 칸에 글을 치면 맞는 수 ('폴더'는 위 셋을 더한 것이라 수가 없다) |
| **만들기** | 펼친 묶음의 머리줄에만 보인다 — 아래 '만들기' |
| **Ctrl+Shift+E** | 펼친 묶음의 지금 보는 문서 행으로 초점 (사이드바를 감췄으면 보이면서) — 그 안에서 또 누르면 다음 묶음 (문서 → 자료 → 코드 → 작업 → 폴더 → 문서) |
| 호박색 점 | 아직 열어 보지 않은 바뀐 문서 |

## '문서' 안의 하위 묶음

'문서'를 펼치면 그 아래에 하위 묶음이 한 단 들여 쌓인다. 이것도 한 번에 하나만 펼치고, 펼친 것 바로 아래에 트리가 온다.

| 하위 묶음 | 보이는 것 |
|---|---|
| 전체 | 모든 문서 |
| 문서 | Markdown 문서 (슬라이드 뺌) |
| 슬라이드 | Lectern 슬라이드 |
| HTML | html 문서 |
| PDF | PDF — 누르면 [PDF 보기](3.8-PDF-보기.md), 두 번 누르면 기본 앱 |
| Word | docx · doc 등 — 두 번 누르면 Word |
| PowerPoint | pptx · ppt 등 — 두 번 누르면 PowerPoint |
| Excel·CSV | xlsx · xls · csv · tsv — 한 번 누르면 Lectern 의 표(xls 는 빼고), 두 번 누르면 엑셀 |
| 한글(HWP) | hwp · hwpx — 두 번 누르면 한글 |

**고르는 하위 묶음** — PDF · Word · PowerPoint · Excel·CSV · 한글(HWP) 은 처음에는 '문서'에 없고 '자료' 목록에 있다. 설정 창 '일반'의 **사이드바 '문서'의 하위 묶음**이나 하위 묶음 머리줄의 우클릭으로 켠 종류는 '문서' 아래 하위 묶음으로 옮겨 가고 **'자료' 에서는 빠진다** — 한 파일은 한 곳에. 끄면 '자료'로 돌아온다.

'문서'로 옮긴 오피스 파일도 누르기 · 우클릭 · **Enter** · **F2** · **Shift+→** 는 '자료' 목록과 같다. 폴더는 늘 펼쳐 있고, 제외 폴더(`node_modules` 등) 안의 것은 넣지 않는다.

문서가 없는 종류와 '전체'와 같은 종류는 보이지 않는다.

## '작업' 묶음 — 업무 카드 · 형광펜 · 할 일

'작업'을 펼치면 '문서'처럼 하위 묶음이 한 단 들여 쌓이고, 펼친 것 바로 아래에 트리가 온다 (폴더는 늘 펼쳐 있다).

| 하위 묶음 | 보이는 것 |
|---|---|
| 업무 카드 | 폴더마다의 `WORK.md` — [업무 카드](8.1-업무-카드.md) |
| 형광펜 | 칠한 곳이 있는 문서 — 아래에 칠한 글이 색 표시와 함께 한 줄씩 |
| 할 일 | 끝내지 않은 할 일이 있는 문서 — 아래에 할 일이 한 줄씩 (처음 펼치면 이것) |

업무 카드는 `WORK.md` 가 있을 때, 형광펜 · 할 일은 md 문서가 있으면 0개여도 보인다. 형광펜 · 할 일은 본문을 읽어 찾으므로 '작업'을 처음 펼칠 때 잠깐 걸리고 개수도 그때 채워진다 — 접혀 있으면 읽지 않는다. 그 뒤로는 바뀐 문서만 다시 읽고, 코드 블록 안은 보지 않는다. 줄을 누르면 그 문서의 그 자리로 가고, 우클릭하면 메모 달기 · 지우기다.

## 목록 위 칸과 단추

| 칸 · 단추 | 하는 일 |
|---|---|
| 거르기 칸 | 이름·제목으로 거른다 ('작업'의 형광펜 · 할 일은 그 글로도). 폴더 개요에서 **Ctrl+F** 도 이 칸 |
| 제목 | 켜면 파일 이름 대신 문서 제목, 끄면 파일 이름(마우스를 올리면 제목) — 문서 열기·검색 결과·모아 보기·최근 변경·문서 탭도 따른다 |
| 차례 | 이름순 · 시간순 · 형식순 — 늘 폴더가 먼저. 시간순은 새것이 위(폴더는 그 안의 가장 새 파일), 형식순은 확장자 차례 |
| ↕ | 폴더 모두 펼치기 · 폴더 모두 접기 · 첫 단계 폴더만 펼치기 — 제외 폴더는 펼치지 않는다 |
| 가르는 말 | 한 목록에 같은 글이 둘 이상이면 흐리게 붙는다 — 같은 제목이면 파일 이름(`같은 제목 · 노트.md`), 폴더가 보이지 않는 문서 탭에서 같은 이름이면 폴더(`README.md · a`). 폴더가 이미 보이는 목록(트리·검색 결과 등)에는 폴더를 붙이지 않는다 |

## 키보드

다섯 묶음 모두 탐색기처럼 다룬다. **Tab** 은 목록마다 한 번만 들르고, 목록 안은 화살표로 옮긴다.

| 키 | 하는 일 |
|---|---|
| **↑** · **↓** · **Home** · **End** | 위·아래 항목 · 처음·끝 |
| **→** · **←** | 폴더 펼치기(펼쳐 있으면 첫 항목) · 접기(접혀 있으면 위 폴더) |
| **Enter** | 열기 — 볼 수 있는 파일은 한 번 누르기와 같고 그 밖의 자료는 기본 앱 ('문서'의 폴더는 폴더 개요) |
| 글자 | 그 글자로 시작하는 항목 — 거듭 치면 다음 항목 |
| **F2** | 고른 파일의 이름 바꾸기 |
| **Shift+→** | 고른 문서 · 폴더의 `@경로` 를 최근에 쓴 터미널에 — 초점도 터미널로 (Enter 는 누르지 않는다). 우클릭 **@경로 복사** 옆의 **▣ 터미널**과 같다. 담기 탭에서는 담기함 파일, 조각에서는 담은 곳의 줄 |
| **Ctrl+Shift+→** | 같은 글을 넣고 초점은 목록에 — **↓** 로 옮겨 가며 여러 파일을 이어 넣는다 |
| **Shift+1~5** · **Shift+←** | 그 번호의 터미널에 · `@경로` 복사 (형광펜 · 할 일 줄은 `@경로 N행`) |

## 제외 폴더

`node_modules`·`dist`·`build`·`venv`·`__pycache__` 같은 폴더다. 문서 트리와 검색에는 나오지 않고 '자료'에만 흐린 접힌 폴더로 나오며, 머리줄 수와 거르기에는 들어가지 않는다.

| 경우 | 동작 |
|---|---|
| 펼칠 때 | 그때 안을 읽는다 (파일이 아주 많을 수 있어서) — 안의 파일은 종류와 상관없이 모두 여기, 코드는 한 번 누르면 읽기 화면 |
| 안이 바뀌면 | 저절로 따라오지 않는다 — 접었다 다시 펼치거나 **F5** |

## '폴더' 묶음 — 모든 것과 복사 · 붙여 넣기

'폴더' 묶음만 숨긴 것까지 모두 보인다. 문서 · 코드 · 자료 묶음과 검색 · 최근 변경에는 여전히 나오지 않는다.

| 보이는 것 | 모양 · 동작 |
|---|---|
| 점으로 시작하는 것(`.git` · `.env` 등) · Windows 숨김 속성 | 흐린 기울임 글씨. 숨긴 파일은 누르면 코드 화면에서 **보기만** (편집은 막힌다 — 고치려면 외부 편집기), 숨긴 폴더는 펼칠 때 안을 읽는다 |
| 빈 폴더 · 숨긴 것만 든 폴더 | 그대로 — 펼치면 '빈 폴더' |
| 바로가기 폴더(심볼릭 링크 · 정션) | ↪ 표시로 보이기만 — 펼치거나 따라가지 않는다 (프로젝트 밖으로 나가거나 끝없이 돌 수 있어서) |
| 제외 폴더 | 펼칠 때 안을 읽는다 — 그 안의 숨긴 것도 |

복사 · 붙여 넣기도 '폴더' 묶음에서만 된다. Windows 탐색기와 서로 주고받는다.

| 하려는 일 | 방법 |
|---|---|
| 여럿 고르기 | **Ctrl+누르기** (하나씩 더하고 빼기) · **Shift+누르기** (사이 모두). 그냥 누르면 하나로 — 새 문서 탭에 열기는 가운데 버튼으로 |
| 복사 | **Ctrl+C** · 우클릭 **복사** — 탐색기에서 **Ctrl+V** 하면 붙는다 |
| 붙여 넣기 | **Ctrl+V** · 우클릭 **붙여 넣기** — 폴더 행이면 그 안, 파일 행이면 그 파일의 폴더, 목록의 빈 곳 우클릭이면 프로젝트 맨 위. 탐색기에서 복사한 것도 |
| 이름이 겹치면 | 탐색기처럼 `이름 - 복사본` · `이름 - 복사본 (2)` — **덮어쓰지 않는다** |
| 탐색기에서 잘라내기 한 것 | 복사만 한다 — 원본은 그대로 (Lectern 에는 옮기기가 없다) |
| 하지 않는 것 | 폴더를 그 폴더 안으로 · 바로가기 폴더 · 예제처럼 보기만 하는 프로젝트 |

실제 복사는 Windows 가 한다 — 오래 걸리면 Windows 의 진행 창(취소)이 뜨고, 붙여 넣은 것은 탐색기의 **Ctrl+Z** 로 되돌릴 수 있다. 다른 묶음의 **Ctrl+C** · **Ctrl+V** 는 파일을 다루지 않는다.

## 만들기

묶음 머리줄의 **만들기**는 그 묶음의 것만 만든다. **폴더는 '폴더' 묶음에서만** 만든다. 만들기 창은 [만들기](4.8-만들기.md)에 있다.

| 연 곳 | 만드는 것 | 처음 위치 |
|---|---|---|
| '문서'의 만들기 | md 문서 · Lectern 슬라이드 | 지금 보는 문서나 폴더 개요의 폴더 |
| **Ctrl+N** | 폴더를 뺀 넷 — md 문서 · Lectern 슬라이드 · 코드 파일 · 자료 파일 | 〃 |
| '코드'의 만들기 | 코드 파일 | 그 목록에서 고른 폴더 (파일을 골랐으면 그 폴더, 없으면 프로젝트 맨 위) |
| '자료'의 만들기 | 자료 파일(CSV·TSV·텍스트) | 〃 |
| '폴더'의 만들기 | 다섯 모두 — 폴더도 | 〃 |

| '폴더' 묶음의 파일 · 빈 곳 | 복사 · 붙여 넣기 · (빈 곳) 새로 만들기… · 새 폴더 만들기… | 위 '폴더' 묶음 |

## 이름 바꾸기와 문서 삭제

| | 이름 바꾸기 | 문서 삭제 |
|---|---|---|
| 여는 법 | 파일 우클릭 **이름 바꾸기…** · 행을 고른 채 **F2** (문서 트리·'코드'·'자료'·최근 변경·검색 결과) | 문서 트리에서 문서 우클릭 **문서 삭제…** |
| 하는 일 | 같은 폴더 안에서 이름만 — 확장자 앞까지 골라져 있으니 고쳐 쓰고 **Enter** (**Esc** 는 그대로 두기) | 늘 먼저 묻고 휴지통으로 보낸다 — 휴지통에서 되살린다 |
| 하지 않을 때 | 같은 이름이 있거나 쓸 수 없는 이름(점으로 시작, `\`·`/`·`:`·`*`·`?`·`"`·`<`·`>`·`\|` 등)이면 까닭을 알린다. 확장자를 바꾸면 한 번 더 묻는다. 저장하지 않은 편집이 있으면 먼저 저장하거나 편집을 닫는다 | 코드와 자료는 지우지 않는다. 휴지통이 없는 곳(네트워크 드라이브 등)은 까닭을 알린다. 저장하지 않은 편집이 있으면 지우지 않는다 |
| 따라가는 것 | 보던 문서 탭(편집 중이면 편집도) · 뒤로 가기 기록 · 담은 조각 | — |
| 그대로인 것 | 다른 문서 속 이 문서로 가는 링크 · 폴더 이름 · 제외 폴더 안의 파일 — 옮기기는 없다 | — |

# 문서 점검

> md 문서의 깨진 틀과 보고서의 틀에서 벗어난 곳을 상태줄의 **점검 N곳** 으로 알린다. 고르면 그 줄로 가고, 확실한 것은 **고치기** 로 고친다.

## 보는 곳

| 자리 | 모양 |
|---|---|
| 상태줄 | 점검할 곳이 있으면 **점검 3곳** — 없으면 나오지 않는다 |
| 누르면 | 묶음마다 줄 번호와 한 줄 설명. 고르면 그 줄이 현재 줄 (접힌 절·머리 설정은 편다) |
| 고치기 | 계산이 확실한 곳만 항목 오른쪽에 — 누르면 저장하고, **Ctrl+Z** 한 번으로 돌아온다 |
| 목록 아래 | **목록을 터미널에 붙여 넣기** (Enter 는 누르지 않음) · **목록 복사** — AI 도구에 고쳐 달라고 할 때 |
| 목차 | 점검할 곳이 든 절의 제목 옆에 ● |
| 명령 찾기 | **Ctrl+Shift+P** 의 **문서 점검** |

문서를 그릴 때마다 다시 본다. 파일은 **고치기** 를 누를 때만 바뀐다. Lectern 슬라이드는 따로 점검이 있다 — [발표와 점검](5.2-발표와-점검.md).

## 깨진 틀

그려진 것이 쓴 뜻과 다른 곳이다.

| 점검 | 왜 | 고치기 |
|---|---|---|
| 닫지 않은 코드 블록 · 수식 블록 | 뒤의 글이 모두 코드 · 수식이 된다 | 다음 제목 앞(없으면 문서 끝)에 닫는 줄 |
| 머리 설정의 닫는 `---` 가 없음 | 머리 설정이 본문으로 보인다 | 키 줄 뒤에 `---` |
| 표의 칸 수가 행마다 다름 · 구분 줄과 다름 | 칸이 빠지거나 밀린다 · 표가 되지 않는다 | — |
| 4칸 넘게 들여 쓴 목록 · 글 | 코드 블록으로 보인다 | — |
| `2.` 처럼 1 이 아닌 번호가 문단 바로 아래 | 목록이 되지 않고 윗줄의 글이 된다 | 윗줄과 띄운다 (목록 안이면 1 부터) |
| 한 목록에 `-` 와 `*` 가 섞임 | 목록이 둘로 갈린다 | 앞 항목의 글머리표로 |
| 글 바로 아래의 `---` | 가로줄이 아니라 제목이 된다 | 빈 줄을 넣어 가로줄로 |
| 강조글 종류 오타 `[!NOTES]` | 일반 인용으로 보인다 | 가까운 종류로 |
| 각주의 내용이 없음 · 쓰지 않는 내용 | 번호가 글자로 남는다 · 내용이 보이지 않는다 | — |
| 없는 절 · 캡션으로 가는 링크, 없는 그림 파일 | 눌러도 가지 않는다 · 그림이 빈다 | — |

## 보고서의 틀

| 점검 | 언제 | 고치기 |
|---|---|---|
| 제목 수준 건너뜀 (`##` 다음 `####`) · 제목 1 이 둘 이상 | 늘 | — |
| 글이 없는 절 | 늘 — 업무 카드(`WORK.md`)는 보지 않는다 | — |
| 같은 제목 | 늘 — 그 절로 가는 링크는 앞 절로 간다 | — |
| 제목 번호가 차례와 다름 | 문서가 번호를 단 머리글 모양일 때 — 번호 없는 제목은 세지 않는다 | 번호가 있는 제목의 번호만 다시 |
| 캡션 번호의 차례 | 늘 | 차례대로 — 참조 링크도 |
| 캡션이 없는 표 · 그림 | 그 문서의 표 · 그림이 대부분 캡션을 쓸 때 | 빈 캡션 줄 |
| '자료:' 줄이 없는 표 · 그림 | 그 문서의 표 · 그림이 대부분 '자료:' 줄을 쓸 때 | 빈 '자료:' 줄 |
| 몇 곳만 빈 줄로 띄운 목록 | 띄운 사이가 많지 않을 때 — 목록 전체가 띄워 보인다 | — |

## 글버릇

설정 창(**Ctrl+,**) '보기'의 **문서 점검에 글버릇도** 를 켜야 본다 — 기본은 꺼져 있다.

| 점검 | 기준 | 고치기 |
|---|---|---|
| 긴 문단 · 긴 문장 · 긴 표의 칸 | 600자 · 150자 · 60자 | — |
| 줄 끝의 공백 두 칸 | 보이지 않는 줄바꿈 | 걷기 |
| 탭 들여쓰기 | 편집기마다 폭이 다르다 | 같은 폭의 칸으로 |
| 제목 끝의 마침표 · 쌍점 | | 걷기 |

## 설정

| 설정 (설정 창 '보기') | 기본 |
|---|---|
| **문서 점검** | 켬 — 끄면 상태줄과 목차의 표시가 없다 |
| **문서 점검에 글버릇도** | 끔 |

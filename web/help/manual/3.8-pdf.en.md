# Viewing PDFs

> View the project's PDFs in a document tab — turn pages, find, select text and clip it, and point an AI tool at the page you are on. View only.

## Opening

| What you want to do | How |
|---|---|
| View in Lectern | Click a PDF once in the sidebar's 'Documents' group (they are gathered under **PDF**) · type its name in **Ctrl+P** |
| In the default app (Edge, Acrobat and so on) | Double-click · right-click **Open in default app** · **Open in default app** on the bar |
| From a link in a document | `[report](data/report.pdf)` opens in Lectern; `data/report.pdf#page=12` goes to that page |

## The view

| Place | What |
|---|---|
| Bar at the top | Page box (type and press **Enter**) · **−** · zoom (click to fit the width) · **+** · notices · **Open in default app** |
| Body | Pages one after another — only the pages near the screen are drawn, so even hundreds of pages stay light |
| Contents panel | The PDF's bookmarks (two levels) — empty if it has none |
| Status bar | `PDF · p. 12/300` and when it was changed |

| What you want to do | Key |
|---|---|
| Turn pages | **PageDown** · **PageUp** · **Space** · wheel |
| First · last page | **Home** · **End** |
| Larger · smaller · fit width | **Ctrl+=** · **Ctrl+-** · **Ctrl+0**, **Ctrl+wheel** |
| Find — in every page | **Ctrl+F**, then **Enter** for the next and **Shift+Enter** for the previous |
| Put the page you are on into the terminal (`@data/report.pdf p. 12`) | **Shift+→** — Enter is not pressed. **Shift+←** copies it |
| Clip selected text · to another box | Drag to select, then **Alt+C** · **Alt+Shift+C** |

With fit width, the zoom follows when you open or close the sidebar or contents. If the file changes outside, it is read again at the page you were on.

## Right-click

| Item | What it does |
|---|---|
| **Copy selected text** · **Clip selected text** · **Clip to another box…** | When text is selected — the clip's source is that page |
| **Copy location** | `@data/report.pdf p. 12` — **▣ Terminal** next to it puts it into the terminal |
| **Open in default app** | Print, annotate and fill forms there |
| **Copy @path** · **Show in File Explorer** · **Rename…** | As for other files |

## With clips

| What | How |
|---|---|
| Source | `data/report.pdf p. 12` — click the source line in a laid-out box to go to that page |
| Send to a document | `<!-- from: data/report.pdf p. 12 -->` before the clip |
| Hand to an AI tool | The location goes as `@data/report.pdf p. 12 ('…')` |
| Checking the source | For PDFs only whether the file is there — you are told if it is deleted or renamed |

## What it does not do

| What | Why · what to do |
|---|---|
| Edit · delete · highlight · add notes | View only — use the default app |
| Find a PDF's text with sidebar **Search** | Use **Ctrl+F** with the PDF open — Search shows PDFs only when the name matches |
| Select or find text in a scanned PDF | It is an image without text — the bar says so. Make text with the default app or OCR first |
| Password-protected PDFs | Open them in the default app |
| Scripts and forms in a PDF | Not run. Internet links open in the default browser when clicked |

# 전체 편집

> 여러 곳을 한꺼번에 손보거나 HTML 문서를 고칠 때 파일 전체를 편집기로 연다. Ctrl+S 를 눌러야 저장되는 것은 이 길뿐이다.

대부분의 일은 [한 줄 편집](4.2-한-줄-편집.md)으로 된다. 한 줄 편집으로 되지 않는 일에 이 편집기(편집 모드)를 쓴다.

## 한눈에

| 하려는 일 | 마우스 | 키 |
|---|---|---|
| 보고 있는 문서 · 코드를 열기 · 닫기 | 탭 막대 **편집** (다시 누르면 닫힌다) · 상태줄 **편집** · 코드 화면 머리줄 **편집** · 문서 여백 우클릭 **이 문서 편집** | **Ctrl+E** |
| 그 블록 · 줄에서 열기 | 줄 우클릭 **전체 편집으로 열기** (코드 · 자료 화면은 **여기서 편집**) | **Ctrl+E** |
| CSV · TSV · 텍스트의 그 줄에서 열기 | — | **F2** · **Enter** |
| 저장 | — | **Ctrl+S** |
| 닫기 | **✕** | **Esc** · **Ctrl+E** |

탭 막대의 **편집** 은 켜져 있으면 강조색과 밑줄로 보인다. 열면 읽던 곳의 원문이 같은 높이에 온다.

## 편집기 안의 키

| 하려는 일 | 키 |
|---|---|
| 찾기 · 바꾸기 | **Ctrl+F** · **Ctrl+H** |
| 다음 · 이전 찾기 | **F3** · **Shift+F3** |
| 줄로 가기 | **Ctrl+G** |
| 줄 지우기 · 줄 복제 | **Ctrl+Shift+K** · **Ctrl+Shift+D** — 칸 안과 같은 키 (Ctrl+D 는 쓰지 않는다) |
| 날짜 · 특수 문자 | **Ctrl+;** · **Ctrl+Shift+;** |
| 들여쓰기 | **Tab** — 빈칸으로 들인다 (CSV · TSV · 텍스트는 탭 글자) |

줄 번호와 언어 색이 있다.

## 읽는 위치와 이어진다

| 상황 | 동작 |
|---|---|
| 편집하는 동안 오른쪽 목차 | 커서가 있는 절을 표시한다 — 커서가 화면 밖이면 화면 위쪽의 절 |
| 목차 · 모아 보기 · 검색 결과에서 이 파일의 곳을 누름 | 편집기가 그 줄로 간다 |
| 편집을 닫음 | 문서 화면이 편집하던 곳에 있다 — 접힌 절이면 편다 |
| HTML 문서 | 제목 단위로 이어진다 |

## 저장

| 상황 | 동작 |
|---|---|
| **Ctrl+S** | 원래 파일의 줄바꿈(CRLF · LF — 섞여 있으면 많은 쪽) · BOM · 파일 속성을 그대로 두고 저장 |
| 저장한 뒤 | 아래의 문서 화면이 고친 내용으로 다시 그려지고, 닫으면 보인다 |
| 그사이 다른 프로그램(AI 도구 등)이 같은 파일을 고침 | 덮어쓸지 묻는다 — 취소하면 저장하지 않고 편집을 이어 간다 |
| 저장하지 않은 편집이 있는데 닫기 · 다른 문서로 · 탭이나 창 닫기 | 먼저 묻는다 |
| 읽기 전용 파일 | 저장하지 않는다 |
| CSV · TSV · 텍스트 | 원래 인코딩(UTF-8 · UTF-16 · CP949) 그대로 — [코드와 자료 보기](3.6-코드와-자료-보기.md) |

## 고치지 않는 것

| 파일 · 일 | 대신 |
|---|---|
| UTF-8 이 아닌 문서 · 코드 | 보기만 — 자료 파일은 원래 인코딩으로 고친다 |
| 2MB 가 넘는 파일 | 외부 편집기 |
| PDF · 엑셀 같은 자료 · 로그 | 편집하지 않는다 |
| 새 파일 · 새 폴더 | [만들기](4.8-만들기.md) — 새 문서 · 빈 코드 파일 · 빈 자료 파일 · 폴더 |
| 파일 이름 바꾸기 | 사이드바에서 고르고 **F2** — [사이드바](2.4-사이드바.md) |

## 원문 줄 보기

전체 편집기를 열지 않고 md 문서의 모든 줄을 줄마다 고치는 길이다.

| 하려는 일 | 방법 |
|---|---|
| md 문서를 줄 번호와 함께 코드 화면으로 | 상태줄 **원문 줄 보기** |
| 빈 줄 · 주석 · HTML 까지 고치기 | 그 화면에서 줄마다 칸으로 ([한 줄 편집](4.2-한-줄-편집.md) 과 같은 키) |
| 돌아오기 | 상태줄 **md 문서로 보기** |

## vi 방식

설정(**Ctrl+,**)의 **전체 편집 방식** 에서 **vi 방식** 을 고르면 편집기를 vim 처럼 쓴다. 기본은 **기본 방식** 이고, 읽는 화면의 vi 키와는 따로 고른다.

| 하려는 일 | 키 |
|---|---|
| Normal 모드로 | **Esc** — 편집을 닫지 않는다 |
| 저장 | `:w` |
| 닫기 | `:q` · **Ctrl+E** · **✕** |
| 저장하고 닫기 | `:wq` · `:x` |

한글 입력 상태에서는 Normal 모드 키가 글자로 들어갈 수 있으니 영어 입력으로 쓴다.

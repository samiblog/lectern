# 형광펜·메모·담기

> 다시 볼 곳은 형광펜으로 칠하고, 떠오른 것은 메모로 적고, 여러 문서의 조각은 담아 두었다가 한 문서로 보낸다.

## 형광펜

형광펜은 모양만이 아니라 '나중에 다시 볼 곳' 표시로 쓴다. 칠하는 법은 낱말을 두 번 눌러 고르고 **M** — [줄 종류와 서식](4.4-줄-종류와-서식.md).

| 하려는 일 | 마우스 | 키 |
|---|---|---|
| 칠한 곳 모아 보기 | 사이드바 '문서'의 **형광펜** 묶음 — 문서별, 누르면 그 줄로 | — |
| 칠한 글로 거르기 | 사이드바의 거르기 칸에 글 치기 | — |
| 다음 · 앞의 형광펜 — 칠한 글을 고른다 | — | **F8** · **Shift+F8** |
| 색 바꾸기 | — | 고른 채 **M** (거듭 누르면 다음 색) |
| 메모 달기 | 형광펜 줄 · 칠한 글(**F8** 이나 두 번 누르기로 고른 채) 우클릭 **메모 달기** | — |
| 하나 지우기 | 형광펜 줄 · 칠한 글 우클릭 **이 형광펜 지우기** | — |
| 문서의 것 모두 지우기 | 사이드바 문서 행 우클릭 **이 문서의 형광펜 모두 지우기…** (색이 여럿이면 색마다도) | — |

지우면 글은 그대로 두고 칠한 것만 걷는다. **Ctrl+Z** 한 번으로 되돌린다. 모두 지울 때는 몇 곳인지 묻고, 다른 문서의 형광펜이면 그 문서를 먼저 열어 보여 준 뒤 지운다. 여러 문서를 한꺼번에 지우는 길은 없다.

## 메모

프로젝트마다 메모를 둔다. 탭 막대의 **메모**나 **Alt+M** 으로 오른쪽 패널을 열고 닫는다 (**Esc** 로도 닫는다). 문서 위를 덮어 문서를 보며 쓴다.

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 새 메모 | **새 메모**를 누르고 쓰기 | 저절로 저장한다 |
| 꾸미기 | 제목 · 색 · 고정 | 고정한 메모는 맨 위 |
| 메모 거르기 | 위 칸에 글자 | 맞는 메모만 |
| 할 일 목록으로 | **할 일로** | 줄마다 체크 칸 — 끝낸 항목은 아래로, 맨 아래 칸에서 더한다 (본문에 `- [ ] 할 일` 로 적어도) |
| 복사 · 터미널에 · 문서로 | **복사** · **터미널** · **문서로** | Markdown 글로 · 터미널에 붙여 넣기 (Enter 는 누르지 않는다) · 문서 탭의 문서나 새 문서로 |
| 지우기 | **지우기** | 위에 **되돌리기**가 잠깐 |
| 문서의 글을 메모로 | 본문 · 고른 글 · 모아 보기 항목 우클릭 **새 메모로 보내기** | 그 글이 메모가 되고 `@경로 12~20행` 이 아래에 — 누르면 그 자리로 |
| 형광펜에 메모 | 칠한 글 우클릭 **메모 달기** | 칠한 글을 제목으로 한 메모 — 바로 내용을 쓴다 |

## 메모가 남는 곳

| 상황 | 동작 |
|---|---|
| 파일 | 프로젝트 폴더의 `.lectern/notes.md` 하나에 Markdown 으로. 메모를 처음 쓸 때 만든다 |
| 트리 · 검색 | 나오지 않는다 |
| 폴더를 옮기면 | 메모도 따라간다 |
| AI 도구(Claude Code 등)에 읽히기 | `@.lectern/notes.md` |
| git 저장소 | 올리지 않으려면 `.gitignore` 에 `.lectern/` |
| 그사이 다른 곳에서 고쳤으면 | 다시 읽어 합친다 |
| 보기만 하는 프로젝트(예제 등) | 메모를 쓰지 않는다 |
| 되찾아 가기 | 고른 글 · 형광펜에서 만든 메모는 문서가 바뀌어 줄이 밀려도 그 글로, 블록에서 보낸 메모는 그 줄 번호로 ('그 자리로 가기') |

## 담기

문서의 조각을 **담기함**에 쌓는다. 담기함은 프로젝트마다 여럿 만들 수 있고 앱을 꺼도 남는다 — 질문이나 주제마다 하나씩 두고 근거를 모은다.

| 담을 것 | 우클릭 위치 | 항목 | 키 |
|---|---|---|---|
| 절 — 제목과 아래 내용 전부 | 제목 | **이 절 담기** | 제목 줄에서 **Alt+C** |
| 표 · 그림 · 차트 (캡션과 바로 아래의 '자료:' 줄까지) · 다이어그램 · 수식 · 코드 · 단락 | 그 블록 | **담기** | 그 줄에서 **Alt+C** |
| 고른 글 | 고른 글 | **고른 글 담기** | **Alt+C** |
| 고른 줄 | 고른 줄 안 | **담기** | **Alt+C** |
| 모아 보기의 항목 하나 | 그 항목 | **담기** | 초점을 두고 **Alt+C** |
| 모아 보기에 보이는 것 모두 — 거르기 · 단추로 좁힌 그대로 (프로젝트의 모든 표 등) | 아무 항목 | **보이는 것 모두 담기** | — |

| 어디에 담기나 | 방법 |
|---|---|
| **지금 담기함**에 | 담기 · **Alt+C** — 알림에 담기함의 이름과 개수가 뜬다 |
| 다른 담기함에 하나만 | 우클릭 **다른 담기함에 담기…** — 담기함을 고르거나 **새 담기함…** (지금 담기함은 그대로) |
| 담기함이 하나도 없을 때 | '담기함' 하나가 저절로 생긴다 |

담는 순간의 내용이라 원래 문서가 나중에 바뀌어도 그대로다. 코드 화면의 줄과 html 문서의 블록은 담지 않는다 (원문 줄이 없다).

## 담기함

사이드바 **담기** 탭에 담기함들이 보이고, **지금 담기함** 하나만 펼쳐져 담은 것이 차례대로 나온다 (탭 옆 숫자는 지금 담기함의 개수).

| 하려는 일 | 마우스 | 키 |
|---|---|---|
| 새 담기함 | 탭 위 **+** → 이름을 적고 Enter | — |
| 지금 담기함 바꾸기 | 담기함의 머리줄 누르기 | **Enter** |
| 담은 것을 펼쳐 보기 (아래) | 탭 위 **펼쳐 보기** · 머리줄 오른쪽의 단추 · 지금 담기함의 머리줄 또 누르기 | **Enter** |
| 제목 · 설명 고치기, 비우기, 지우기 | 머리줄 우클릭 — 지우면 휴지통으로 간다 | — |
| 차례 바꾸기 | 항목의 **↑** · **↓** | **Alt+↑** · **Alt+↓** |
| 빼기 — 문서는 그대로 | 항목의 **✕** | **Delete** |
| 뺀 것 되돌리기 (마지막에 뺀 것) | 탭 위 **되돌리기** | — |
| 다른 담기함으로 옮기기 · 복사 | 항목 우클릭 | — |
| 원래 자리로 | 항목 누르기 | **Enter** |
| 모두 보내기 — 담은 차례대로 | 탭 위 **문서로 보내기…** | — |
| 편집 중인 문서의 커서 자리에 | 항목의 **보내기** — 커서가 든 블록 뒤에 | — |
| AI 도구에 맡기기 | 탭 위 **Claude 에 맡기기** (이름은 설정 '쓰는 AI 도구'를 따른다) | — |

맡기기는 담은 것들의 위치(`@문서 12~19행 ('이름')`)를 묶어 새 문서로 만들어 달라는 요청 글이다. 제목이나 메모를 달았으면 담기함 파일도 함께 가리킨다. 복사하거나 **▣ 터미널**로 넣는다 (Enter 는 누르지 않는다).

## 담기함 펼쳐 보기

담기함을 문서 탭 하나에 펼친다 — 담은 표 · 그림 · 차트 · 글이 실제 모습으로 차례대로 놓이고, 조각마다 제목과 메모를 적는다. 쓰는 대로 저장된다.

| 자리 | 무엇 |
|---|---|
| 머리 | 담기함의 제목과 설명 (질문 등) — 비워 두어도 된다 |
| 붙어 있는 줄 | **문서로 보내기…** · **Claude Code 에** · **더 보기** · 되돌리기 · 개수 |
| 카드의 제목 | 비워 두면 캡션이나 첫 글이 흐리게 보인다 |
| 출처 줄 | 담은 문서와 줄, 담은 날 — 누르면 그 자리로 (**Alt+←** 로 돌아온다) |
| 메모 | 왜 담았는지 |
| 목차 패널 (오른쪽) | 담은 것의 차례 |

| 하려는 일 | 키 (카드에 초점) |
|---|---|
| 앞 · 뒤 카드로 | **↑** · **↓** |
| 차례 바꾸기 | **Alt+↑** · **Alt+↓** |
| 빼기 | **Delete** |
| 원래 자리로 | **Enter** |
| 제목 쓰기 | **F2** — Enter 는 메모로, Esc 는 카드로 |

| 출처 줄의 알림 | 뜻 |
|---|---|
| 원래 문서가 바뀌었습니다 | 담은 글이 그 문서에 그대로 있지 않다 — 카드에 보이는 것은 담은 때의 내용이다. 줄이 밀리기만 했으면 알리지 않는다 |
| 원래 문서가 없습니다 | 지워졌거나 밖에서 이름이 바뀌었다 (Lectern 에서 이름을 바꾸면 따라간다) |

담은 내용은 여기서 고치지 않는다 — 원래 문서나 보낸 문서에서 고친다.

## 담기함의 파일

| 물음 | 답 |
|---|---|
| 어디에 | 프로젝트의 `.lectern/clips/` — 담기함마다 md 파일 하나. 트리 · 검색 · 모아 보기에는 나오지 않는다 |
| 언제 생기나 | 처음 담거나 담기함을 만들 때 |
| AI 도구가 읽나 | 읽는다 — 머리줄 우클릭의 **@경로 복사**로 가리킨다. 밖에서 고치면 창으로 돌아올 때 보이고, 쓰던 것과 합쳐진다 |
| 보기만 하는 프로젝트 (설치된 예제 등) | 담기는 되지만 저장하지 않는다 — 앱을 끄면 비워진다 |

## 보내기

담기 탭 위의 **문서로 보내기…** 는 지금 담기함의 것 모두를, 우클릭 메뉴의 **문서로 보내기…** 는 그 조각 하나를 바로 보낸다.

| 받는 곳 | 자리 | 저장 |
|---|---|---|
| 편집 중인 곳 | 커서 자리 | 편집기에 넣는다 — 저장은 **Ctrl+S** |
| 문서 탭에 열린 문서 | **맨 끝** · **맨 앞** · **'…' 절 끝** | 바로 저장한다 — **Ctrl+Z** 한 번으로 되돌린다 |
| **새 문서…** | 경로를 적고 Enter (처음 값은 담기함의 제목) — 제목 한 줄로 바로 만들고 새 문서 탭에서 맨 끝에 | 바로 저장한다 |

받는 곳은 문서 탭에 열어 둔 md 문서와 새 문서뿐이다. 다른 문서로 보내려면 먼저 그 문서를 문서 탭으로 연다 (트리에서 **Ctrl+누르기**).

| 보낼 때 맞춰 주는 것 | 어떻게 |
|---|---|
| 그림 · 링크 · 차트 데이터의 상대경로 | 받는 문서 기준으로 |
| 각주 | 정의도 함께 — 이름이 겹치면 바꾼다 |
| 제목 수준 | 받는 자리에 맞게 (절 끝이면 그 절 아래) |
| 조각의 제목 · 메모 | 제목은 조각 위의 제목으로, 메모는 아래에 `> 메모: …` 로 |
| 출처 | 화면에 보이지 않는 `<!-- 담은 곳: research/a.md 12~19행 -->` 주석 — 나중에 AI 도구가 출처를 안다 |

# pptx 와 html 발표

> Lectern 슬라이드를 상태줄에서 pptx 파일이나 impress.js 발표 html 파일로 바꾼다. 둘 다 문서 옆에 새 파일 하나를 만들고 덮어쓰지 않는다.

## 둘 견주기

| 무엇 | **pptx 로 전환** | **html 로 전환** |
|---|---|---|
| 결과 | 문서 옆에 새 pptx | 문서 옆에 impress.js 발표 html 하나 |
| 받은 사람 | PowerPoint 로 열고 고친다 | 브라우저로 열어 발표한다 — 장이 한 캔버스 위에 놓이고 화면이 장 사이를 옮겨 다닌다 |
| 모양 | 칸의 자리는 Lectern 슬라이드, 색 · 글꼴 · 로고 · 꼬리말은 pptx 스타일 | 색 · 글꼴은 지금 고른 스타일 그대로 |
| 같은 이름이 있으면 | `보고서 2.pptx` 처럼 새 이름 | `보고서 2.html` 처럼 새 이름 |

## pptx 로 전환

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 전환 | 상태줄 **pptx 로 전환** → pptx 스타일 고르기 → **전환** | 문서 옆에 pptx — AI 도구(Claude Code 등)나 Python 은 없어도 된다 |
| 만든 뒤 | **pptx 열기** · **탐색기에서 보기** | — |
| 스타일 더하기 | 창의 **보관소 폴더 열기** (`%APPDATA%\Lectern\pptx-styles`) → 회사 양식 pptx 를 넣는다 | 목록에 나온다 — Lectern 전체에서 함께 쓴다 |
| AI 도구에 스타일 맡기기 | **Claude 에게 스타일 요청** → pptx 경로를 적는다 | AI 도구가 스타일 · 같은 이름의 템플릿 묶음 · 미리보기 그림을 함께 만든다 |
| 기본 스타일 정하기 | **기본 스타일로** 를 켜고 전환 | 스타일을 정하지 않은 문서에 그 스타일이 쓰인다 |

저장하지 않은 편집이 있으면 저장한 뒤 전환한다.

## 쓰이는 스타일의 차례

| 차례 | 스타일 | 메모 |
|---|---|---|
| 1 | 이번에 고른 스타일 | 고른 이름은 맨 앞 설정에 `pptxStyle: 회사보고` 로 적혀 다음에 먼저 골라진다 |
| 2 | 문서의 스타일 | `pptxStyle:` 의 것, 또는 짝인 스타일 — '회사 보고' 묶음으로 만든 문서는 '회사 보고' 스타일 |
| 3 | 원본 pptx | pptx 에서 옮겨 온 문서 |
| 4 | 기본 스타일 | **기본 스타일로** 로 정한 것 |
| 5 | Lectern 스타일 | 아무것도 없을 때 |

템플릿 묶음과 이름이 같은 pptx 스타일이 짝이다. 문서만 다른 PC 로 옮기면 스타일이 없을 수 있다 — 그때는 알려 주고 다시 고르게 한다.

## pptx 에 들어가는 것

| Lectern 슬라이드 | pptx 에서 |
|---|---|
| 칸의 자리 | Lectern 슬라이드를 따른다 |
| 색 · 글꼴 · 로고 · 꼬리말 | pptx 스타일을 따른다 |
| 글 · 표 | 글 · 표 |
| 차트 | 값을 고칠 수 있는 차트 |
| 칸 사이의 선 | 연결선 |
| 복잡한 차트 · Mermaid | 그림 |
| 발표자 노트 | pptx 의 노트 |
| 형광펜 · 글자색 | 그대로 |
| 양식 pptx 의 장 · 그림 | 들어가지 않는다 — 장 제목과 표지 그림도 파일 속성에서 지운다 |
| 양식 레이아웃의 로고 · 꼬리말 | 양식의 일부라 들어간다 |

## pptx 에서 옮겨 온 문서

스타일을 고르지 않고 다시 전환하면 원본 장을 살린다. 그러려면 `문서-변환기록.json` 과 `.pptx-work` 폴더를 지우지 않는다.

| 장 | 다시 전환하면 |
|---|---|
| 고치지 않은 장 | 원본 장 그대로 — 디자인과 애니메이션이 살아 있다 |
| 글만 고친 장 | 원본 장에서 그 글만 바뀐다 |
| 칸이나 배치를 바꾼 장 | 새로 만든다 |

## html 로 전환

상태줄 **html 로 전환** → 배치를 고르고 **만들기**. md 가 원본이므로 고친 뒤 다시 전환한다.

| 옵션 | 하는 일 |
|---|---|
| **격자** | 표지 · 간지(`lead` 장)에서 줄을 바꾸고, 한 줄이 4장을 넘으면 접는다 |
| **가로 한 줄** | 모든 장을 한 줄로 |
| 배치 지도 | 장 번호가 그 자리에 보인다 |
| **맨 끝에 전체 보기** | 맨 끝에 모든 장이 한 화면에 보이는 장을 붙인다 |
| **Claude 에게 배치 요청** | 이야기 흐름에 맞게 자리를 적어 달라는 요청 글이 터미널에 (**Enter** 는 누르지 않음) |
| 처음 값 | 맨 앞 설정 `impress: line` 이면 가로 한 줄 |
| 장의 자리를 직접 | 장에 `<!-- impress: x=0 y=2400 rotate=90 scale=2 -->` — 적은 축만 바뀌고 화면의 모양은 그대로 |

만든 뒤 **브라우저로 열기** 는 이번에 Lectern 이 만든 그 파일만 기본 브라우저로 연다. **탐색기에서 보기** 도 있다.

| 발표 (받은 사람의 브라우저) | 키 |
|---|---|
| 다음 장 · 이전 장 | **→** · **Space** · **PageDown** / **←** · **PageUp** |
| 첫 장 · 마지막 장 | **Home** · **End** |
| 발표자 콘솔 (노트 · 다음 장 · 시계) 을 새 창에 | **P** |

| 상황 | 동작 |
|---|---|
| 파일 하나 | 그림 · 스타일 · 수식 글꼴 · impress.js 가 모두 안에 든다 — 인터넷 없이 열리고 아무 데도 요청하지 않는다. 메일 · 메신저로 보내도 된다. 인터넷 그림만 주소로 남아 받은 사람의 브라우저가 불러온다 |
| 넣지 않는 것 | 숨긴 장, 동영상 · 소리. 프로젝트 안의 다른 문서로 가는 링크는 글로 남는다. HTML 장에 쓴 `class="step"` · `notes` · `substep` 은 impress 가 장 · 노트로 읽는 이름이라 뗀다 |
| 안전 | 파일 안에서는 impress.js 와 시작 줄만 돈다 — 문서에 스크립트가 들어 있어도 받은 사람의 브라우저에서 돌지 않는다 |
| Lectern 에서 열면 | 왼쪽 문서 목록에 html 문서로 나온다 — 스크립트를 돌리지 않으므로 장이 위에서 아래로 놓인 문서로 보이고 노트도 보인다 |

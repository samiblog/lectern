# Word

> Save an md document as a docx to keep editing in Word. Text, tables, footnotes and caption numbers go in as Word's own, and you can borrow your company's or organization's Word template.

## Opening it

| What to do | How | Result |
|---|---|---|
| Save as Word | Right-click the body margin → **Save as Word…** | The Export window opens with the format **Word** and makes the file |
| Switch the format in the window | Export window **Format** → **Word** | Makes it again from the same document |
| Pick a template | **Word template** in the window | Makes it again with that template |
| Save | **Save as Word…** in the window | Where you choose in the save dialog |

There is no preview; the window shows what was made (number of images, size, things to note). Making it takes a few seconds (more with many charts). Charts are drawn with Windows' Edge — nothing goes to the internet.

## What carries over

| md document | In Word |
|---|---|
| Text | Text |
| Tables | Word tables — the header row on each page |
| Lists | Word lists — top items of a list with sub-items are bold and slightly larger (as on screen) |
| Bullet-mark lists (`□` · `○` · `-` · `·`) | One paragraph per item — the mark stays as text, each level is indented and wrapped lines align after the mark. In a group that has `○`, the `□` items are bold |
| Footnotes | Word footnotes |
| `Table 1.` · `Figure 1.` captions | Word numbering fields |
| Cross-references such as `[Table 1](#table-1)` | Links to that caption |
| Highlights · text colors · callouts · boxes | Carried over as they are |
| Charts · diagrams · display math | Images |
| Inline math | Text |
| `[TOC]` line | When Word opens the file it asks whether to update the fields — click **Yes** and the contents and page numbers are filled in |
| Pages | Word lays them out |

## Word templates

| Template | What |
|---|---|
| Lectern default template | A4 · serif body · title in the header from page 2 · page numbers at the bottom center |
| 18 Lectern templates | The same names · groups as the page layouts — Office and public sector · Research · Finance and consulting · Media and publishing · Guides |
| My Word templates | Your company's · organization's Word templates (.dotx · .docx) — at the bottom of the list |

Export the same document to PDF · html with a page layout and to Word with the template of the same name, and the cover, summary box, sign-off boxes and running heads come out alike.

| What to do | Front matter · source | Result |
|---|---|---|
| Cover and information table | `title` · `subtitle` · `author` · `org` · `date` · `number` … (the Korean keys `기관` · `부제` · `연구진` too) | Filled in — lines whose keys are empty are left out |
| Summary box | A named box `<!-- box: 요약 -->` | Goes to that slot in the template |
| Sign-off boxes | `결재: [Staff, Manager, Director]` (the key is Korean, `결재` = approval) | Sign-off boxes |
| Labels in English | `lang: en` | Summary · Contents … come out in English |
| Find the empty keys | Pick a template | Below appear the description · pages · box slots · empty front matter — **Copy front matter sample** copies only the empty keys (it writes nothing to the document — you paste and fill them in) |

## The template picked when the window opens

| Order | If the document has | Template picked |
|---|---|---|
| 1 | Front matter `docxStyle: template name` | That template |
| 2 | One of My Word templates with the same name as `layout:` (the page layout) | That template of yours |
| 3 | A Lectern template with the same name as `layout:` | That Lectern template |
| 4 | Neither | Lectern default template |

Layouts and templates share their names, so the one line `layout: research-report` pairs PDF, html and Word.

## My Word templates

| What to do | How |
|---|---|
| Add a template | **Open Word templates folder** in the window → put .dotx · .docx files in that folder → **My Word templates** at the bottom of the list |
| What is borrowed | The template's styles · page size · margins · headers · footers — only the body is written anew |
| When a template uses its own style names (such as '1.Heading' · 'Body2') | Next to the template, `template-name.styles.json` — `{"heading 1": "1.Heading", "Normal": "Body2"}` |
| Giving it a cover | In Word, put placeholders such as `{{title}}` · `{{author}}` · `{{date:ko}}` in the template's text, and one `{{body}}` line where the body goes — the full list of placeholders is in the skill's SKILL.md |

## The small ▪ left of section headings

| Question | Answer |
|---|---|
| What is it | Not a character but the mark Word shows on a paragraph set to 'Keep with next' — it appears when Word's **paragraph marks** are shown |
| Why is it there | So section headings · captions are not separated from the text that follows when the page changes. The document title · subtitle at the top of the first page do not have it |
| Does it print | It does not appear in print · PDF — Word's own heading styles show the same mark |
| To hide it | Turn off 'Paragraph marks' under **File > Options > Display** in Word |

# 넣기

> 현재 줄에서 / 를 누르면 그 줄 아래에 넣기 창이 뜬다. 표·그림·차트·수식·강조글·박스글·주·특수 문자를 표시를 외우지 않고 넣는다.

## 여는 법

| 하려는 일 | 마우스 | 키 |
|---|---|---|
| 현재 줄 아래에 넣기 창 | 탭 막대 **넣기** · 우클릭 **여기에 넣기…** | **/** |
| 칸 안에서 | — | 빈 줄 **/** · 글이 있는 줄 **Ctrl+Shift+/** |
| 표 · 코드 블록 뒤에 | 표 우클릭 **여기에 넣기…** (표 아래에) | 그 블록에서 **/** |
| 날짜 · 특수 문자 | 칸 안 우클릭 **특수 문자…** | **Ctrl+;** · **Ctrl+Shift+;** |

그 줄 아래에 새 줄이 열리고 창이 뜬다. 여러 줄을 고른 동안에는 넣지 않는다. vi 키를 켰으면 `/` 가 찾기라서 **Ctrl+Shift+/** 를 쓴다.

## 넣기 창

| 하려는 일 | 키 |
|---|---|
| 열 안에서 · 옆 열로 | **↑** · **↓** · **←** · **→** |
| 거르기 | 글자를 친다 — `표` · `박스` · `주`. 자음만 치면 첫소리로 (`ㅍ` 표, `ㅉㄴ` 쪽 나눔) |
| 같은 것을 거듭 넣기 | **/** · **Enter** — 맨 앞 열 '최근'(최근 넣은 다섯)의 첫 항목이 골라져 있다 |
| 넣기 · 그만두기 | **Enter** · **Esc** |

창이 넓으면 묶음이 열로 한 번에 보인다.

| 묶음 | 항목 |
|---|---|
| 글 | 제목 1~4 · 문단 · 목록 · 번호 목록 · 할 일 · 인용 · 날짜 · 특수 문자 |
| 강조글 | 참고 · 팁 · 중요 · 경고 · 주의 |
| 자료 | 표 · 그림 · 차트 · 다이어그램 · 수식 · 코드 · 박스글 |
| 주·참조 | 주 · 출처 줄 · 표 주 · 링크 · 상호 참조 · 본문 인용 · 첨부 · 부록 |
| 쪽 | 구분선 · 쪽 나눔 · 목차 · 표 목차 · 그림 목차 |

글 묶음의 줄은 글을 쓸 때 파일에 들어간다 — `## ` · `- ` 를 직접 쳐도 된다. 상호 참조 · 본문 인용 · 목차는 [번호·참조·목차·스타일](4.6-번호-참조-목차-스타일.md) 에 있다. Lectern 슬라이드의 넣기는 [슬라이드 쓰기](5.1-슬라이드-쓰기.md) 에 있다.

## 무엇이 들어가나

| 항목 | 들어가는 것 |
|---|---|
| 주 (칸 안 **Ctrl+Alt+F**) | 글 가운데 그 자리에 표시를 넣고 내용을 묻는다 — 본문과 함께 저장. 표시 위에서 누르면 그 주를 고친다. 번호는 나온 차례로, 내용은 문서 끝에 모인다. 표시를 지우면 내용도 지울지 묻는다 |
| 출처 줄 · 표 주 | `자료: ` · `주: ` 로 시작하는 줄 — 표 바로 아래면 작은 글자 |
| 링크 (칸 안 **Ctrl+K**) | 프로젝트의 파일을 고르거나 주소를 쓴다 — 고른 글이 있으면 그 글에 |
| 첨부 | 문서 끝(각주 앞) `## 붙임` 절에 번호와 링크 — 절이 없으면 만든다. 파일을 복사하지는 않는다 |
| 부록 | `## 부록 A. 제목` 을 다음 글자로 — 본문 번호에 들지 않는다 |
| 구분선 · 쪽 나눔 | 구분선은 `---` 한 줄. 쪽 나눔은 화면에 점선과 '쪽 나눔', 인쇄에서는 다음 쪽 — 다른 뷰어에서는 보이지 않는다 |
| 날짜 | 달력에서 고른 날을 `YYYY-MM-DD` 로 커서 자리에 |

## 표

| 하려는 일 | 방법 |
|---|---|
| 넣기 | 크기를 `3x4`(열 x 행)로 정한다 — 위에 `표 1. 제목` 캡션을 다음 번호로, 아래에 빈 `자료: ` 줄을 함께 넣고 '제목'을 골라 둔다 (슬라이드에서는 표만) |
| 칸 채우기 · 새 행 | **↓** 로 표에 들어가 **Tab** — 마지막 칸의 **Tab** · **Shift+Enter** 는 새 행, **Ctrl+Shift+Enter** 는 위에 새 행 |
| 열 · 맞춤 · 차트 · 지우기 | 칸 우클릭 — 열 더하기 · 옮기기 · 지우기, 이 열 왼쪽 · 가운데 · 오른쪽 맞춤, **이 표를 차트로**, **표 지우기** |

## 그림

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 프로젝트의 그림 넣기 | 넣기 창 **그림** — 파일을 고른다 | 위에 `그림 1. 제목` 캡션, 그림 줄, 아래에 빈 `자료: ` 줄 (슬라이드에서는 그림 줄만) |
| 복사한 그림 · 그림 파일 | **Ctrl+V** · 끌어 놓기 | 문서 옆 `문서이름-그림` 폴더에 `그림 1.png` 같은 새 파일, 현재 줄 뒤에 캡션 · 그림 줄 · 자료 줄 |
| 원문 고치기 | **F2** | 그림의 원문 줄 |

붙여 넣는 순간 저장되고, 있는 파일을 덮어쓰지 않는다. PNG · JPEG · GIF · WebP 를 20MB 까지 받는다. 여러 줄을 고른 동안에는 넣지 않는다.

## 차트·다이어그램·수식

| 원문 | 그려지는 것 |
|---|---|
| `$x^2$` | 문장 속 수식 |
| `$$` 로 감싼 줄 · 언어가 `math` · `latex` 인 코드 블록 | 블록 수식 |
| 언어가 `mermaid` 인 코드 블록 | Mermaid 다이어그램 |
| 언어가 `dot` · `graphviz` 인 코드 블록 | 구성도 · 의존 관계 |
| 언어가 `vega-lite` 인 코드 블록 | 데이터 차트 |
| 언어가 `echarts` 인 코드 블록 | 도넛 · 캔들 같은 여러 차트 |
| 언어가 `plotly` 인 코드 블록 | 상자 그림 · 선버스트 같은 분석용 차트 (Python 의 `fig.to_json()` 결과도) |

`$105` 같은 달러 표기는 수식으로 바꾸지 않는다. 차트 설정은 JSON 이고 함수는 쓸 수 없다. 데이터는 문서 안에 적거나 프로젝트 안의 CSV · JSON 파일을 상대경로로 가리킨다 (인터넷 주소는 읽지 않는다).

| 하려는 일 | 키 | 결과 |
|---|---|---|
| 넣기 | 넣기 창 **차트** · **다이어그램** · **수식** | 보기를 넣고 화면 옆 패널을 연다 — 차트 · 다이어그램은 위에 `그림 n. 제목` 캡션, 아래에 빈 `자료: ` 줄도 (슬라이드에서는 보기만) |
| 있는 것 고치기 · 접기 | **F2** · **Esc** | 패널에 원문 — 수식 · 다이어그램은 줄마다 칸으로. 그린 결과는 그 자리에 보인다 |
| 값이 문서 안에 있는 차트 | **F2** | 값을 표로 — **Shift+Enter** 행 더하기, **Ctrl+Shift+K** 행 지우기, 아래 단추로 막대 · 선 · 영역 · 원, **원문 보기** (값이 다른 파일에 있거나 복잡하면 원문으로 열린다) |

## 강조글과 박스글

| 비교 | 강조글 | 박스글 |
|---|---|---|
| 원문 | `> [!NOTE]` · `[!TIP]` · `[!IMPORTANT]` · `[!WARNING]` · `[!CAUTION]` | `<!-- box -->` 줄과 `<!-- /box -->` 줄 사이 |
| 무엇 | 참고 · 팁 · 중요 · 경고 · 주의 — 종류마다 색 | 본문과 따로 읽는 글 상자 — 본문 흐름에서 떨어진 주제 |
| 번호 | 없다 | `박스 1. 제목` 이면 번호 — `[박스 1](#박스-1)` 로 가리킨다 |
| 넣으면 | 빈 새 줄에서 **↓** 는 강조글 밖으로 | 여는 줄 · `박스 1. 제목` · 내용 한 줄 · 닫는 줄을 넣고 제목 줄을 연다 |
| 쓴 글을 감싸기 | 줄을 고르고 **C** | 줄을 고르고(한 줄이면 그 줄에서) 우클릭 **박스글로 묶기** — 제목 줄에 걸치면 묶지 않는다 |
| 우클릭 | 종류 바꾸기 · 풀기 · **박스글로 바꾸기** · 지우기 | **강조글로 바꾸기** · **박스글 풀기** (두 표시 줄만 빼고 글은 그대로) · **박스글 지우기** |

박스글 안의 줄은 보통 줄처럼 고치고, 박스글을 더하거나 옮기면 번호와 링크를 함께 고친다. 첫 줄을 한 줄로 쓰면 제목이 된다. 안에 제목(`#`)과 다른 박스글은 넣지 않는다. 닫는 줄을 빠뜨리면 다음 제목 앞에서 끝난 것으로 본다. 다른 뷰어에서는 두 표시 줄이 보이지 않아 보통 글로 읽힌다.

AI 도구(Claude Code 등)와 나눈 대화를 문서에 남기려면 줄에서(또는 줄을 고른 뒤) 우클릭 **Claude 에 박스글 요청** 을 누른다 (이름은 쓰는 AI 도구를 따른다). 터미널에 '지금까지의 대화를 정리해 `@문서 12행` 바로 뒤에 박스글로 넣어 줘' 같은 요청 글이 들어가고, 고쳐 쓴 뒤 Enter 를 누르면 AI 도구가 그 자리에 쓴다 — 그 줄이 든 블록의 뒤, 고른 줄이면 끝 줄의 뒤. Lectern 은 요청 글만 넣고 파일은 AI 도구가 고친다.

## 특수 문자

| 하려는 일 | 방법 |
|---|---|
| 칸 · 편집 모드에서 넣기 | **Ctrl+Shift+;** · 칸 안 우클릭 **특수 문자…** — 커서 자리에 |
| 읽는 화면에서 넣기 | **Ctrl+Shift+;** · 넣기 창 **특수 문자** — 현재 줄의 칸을 열고 그 끝에 (새 줄은 만들지 않는다) |
| 거르기 | 이름 — '화살표' · '원 숫자' · '섭씨', 첫소리 'ㅅㅆ', 영어 이름도 |
| 고르기 | **←** · **↑** · **↓** · **→** — 아래 줄에 그 문자의 이름. **Enter** 넣기, **Esc** 그만두기, 마우스로 눌러도 |

묶음은 문장 부호(· — 「」 ※) · 화살표(→ ⇒) · 도형(○ ● □ ■ ★) · 수학(± × ≤ ≒) · 단위·통화(℃ ㎡ ㎏ ₩ €) · 번호(① ㉠ ㉮ Ⅰ) · 첨자(² ₂) · 그리스 문자(α Σ) · 기타이고, 맨 위 줄은 최근 넣은 열둘이다. 넣은 뒤 칸은 열린 채 이어 쓴다. 문서를 깨는 글자는 뺐다 — Markdown 표시로 읽히는 `*` · `_` · `|` · `#` 같은 글자, 목록 · 할 일처럼 보이는 • ☐ ☑ (목록은 `-`, 할 일은 `- [ ]`), 표의 숫자로 읽히지 않는 빼기 기호 − (음수는 `-`), 맑은 고딕 · 바탕에 없어 다른 컴퓨터 · PDF · Word 에서 모양이 바뀌거나 이모지가 되는 ✓ ✗ ⑯~⑳ ⁵~⁹ ☀ ✉ 같은 글자.

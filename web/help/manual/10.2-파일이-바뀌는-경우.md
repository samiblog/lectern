# 파일이 바뀌는 경우

> Lectern 은 스스로 파일을 만들거나 고치거나 지우지 않는다 — 사용자가 고를 때 그 파일만 바뀐다. 무엇을 고르면 어느 파일이 바뀌는지.

## 누가 바꾸나

| 누가 | 바뀌는 것 |
|---|---|
| 사용자가 Lectern 에서 고를 때 | 고른 그 파일만 — 아래 표들 |
| Lectern 스스로 | 설정 폴더(`%APPDATA%\Lectern`)의 설정과 제목 기억뿐 |
| 터미널에서 친 명령 | 명령이 하는 그대로 — 보통의 PowerShell 이다. Lectern 이 한 것이 아니다 |
| AI 도구(Claude Code 등) | AI 도구가 쓴다. Lectern 은 요청 글을 터미널에 넣을 뿐이고 Enter 는 사용자가 누른다 |

## 읽는 화면에서 고칠 때

누르는 순간 그 문서에 저장되고, 하나하나 **Ctrl+Z** 로 되돌린다. 현재 줄을 옮기거나 줄을 고르거나 하이라이트 · 접기를 하는 것은 파일을 바꾸지 않는다.

| 하는 일 | 바뀌는 곳 |
|---|---|
| 한 줄 편집 — 칸의 **Enter** | 그 줄. 새 줄은 글을 쓸 때 들어가고, 칸에서 **Esc** 는 고친 것을 버린다 |
| 줄 더하기 · 나누기 · 합치기 · 옮기기 · 지우기 · 복제 · 레벨 | 고른 줄 — 번호 목록이면 뒤 번호도 |
| 줄 종류 · 서식 키 | 고른 줄 · 고른 글 |
| 체크 칸 누르기 | 그 할 일 줄의 `[ ]` · `[x]` |
| 찾아 바꾸기 | 그 문서의 맞는 곳 |
| 표 · 그림을 더하고 옮기고 지우기 | 캡션 번호와 그것을 가리키는 상호 참조 링크도 — 번호가 차례대로였던 문서만 |
| 번호가 있는 제목을 더하고 옮기고 지우기 | 제목 번호와 이 문서 안의 절 링크도 |
| md 문서 스타일 적용 | 그 문서의 머리글과 절 링크 |
| 담기 · 담기함 고치기 | 프로젝트의 `.lectern/clips/` 에 담기함마다 md 하나 — 처음 담을 때 생긴다. 담기함 지우기는 휴지통으로 |
| 담기의 보내기 | 받는 문서 — 문서 탭에 연 문서나 새 문서 |
| 차트의 **데이터를 문서 안으로 넣기** | 그 차트의 원문 |
| Lectern 슬라이드의 새 장 · 복제 · 옮기기 · 템플릿 바꾸기 | 그 슬라이드 문서 |

현재 줄 하나에서 바꾸는 키(지우기 · 옮기기 · 줄 종류 · 레벨)는 두 번 눌러야 바뀐다 — 읽다가 누른 키로 파일이 바뀌지 않게.

## 전체 편집에서 저장할 때

| 파일 | 저장 (**Ctrl+S**) |
|---|---|
| md · html 문서 · 코드 | UTF-8 글 파일만, 2MB 까지 |
| CSV · TSV · 텍스트 | 원래 인코딩(UTF-8 · UTF-16 · CP949) 그대로 |
| 모든 파일 | 줄바꿈(CRLF · LF) · BOM · 파일 속성 그대로. 읽기 전용 파일은 저장하지 않는다 |
| 그사이 다른 프로그램이 고친 파일 | 덮어쓸지 묻는다 |
| 로그 · 엑셀 | 보기만 |

## 만들고 이름을 바꾸고 지울 때

| 하는 일 | 생기거나 바뀌는 것 | 지키는 것 |
|---|---|---|
| 새 md 문서 | 고른 폴더에 문서 하나 — `# 제목` 한 줄 (번호가 있는 스타일이면 보기 머리글 두 줄도) | 같은 이름이 있으면 만들지 않는다 |
| 새 Lectern 슬라이드 | 문서 하나 — 머리 설정과 고른 템플릿의 첫 장 | 같음 |
| 새 코드 · 자료 파일 | 빈 파일 하나 — CSV · TSV 는 머리행 한 줄, CSV 는 UTF-8 BOM 도 | 같음. 만들기만 하고 실행하지 않는다 |
| 새 폴더 | 이름을 정한 폴더 하나 | 같음 |
| 이름 바꾸기 (**F2**) | 고른 파일 하나 — 같은 폴더 안에서 | 덮어쓰지 않는다. 다른 문서 속 링크는 고치지 않는다 |
| 문서 삭제 | 고른 문서 하나 — 먼저 묻고 휴지통으로 | 코드 · 자료는 지우지 않는다. 휴지통이 없는 드라이브에서는 지우지 않는다 |
| 그림 붙여 넣기 · 끌어 넣기 | 문서 옆 `문서이름-그림` 폴더에 그림 하나와 문서의 그림 줄 | 덮어쓰지 않는다 |

옮기기는 없다. 폴더 이름도 바꾸지 않는다.

## 메모와 업무

| 하는 일 | 바뀌는 파일 |
|---|---|
| 메모 쓰기 | 그 프로젝트의 `.lectern/notes.md` 하나 — 메모를 처음 쓸 때 만든다 |
| 업무 카드 만들기 | 고른 폴더의 `WORK.md` 하나 — 없을 때만, 기본 틀로 |
| 일정 더하기 (**Alt+S**) | 고른 WORK.md 의 '일정' 절 끝에 한 줄 — 절이 없으면 문서 끝에 만든다 |
| 업무 나무 · 칸반 · 간트에서 고치기 | 그 업무의 WORK.md 한 줄 — 상태 · 마감 · 시작 · 우선 · 할 일 체크 · 기한 · 할 일 더하기 |

업무 쪽은 쓰기 전에 그 파일을 다시 읽고, 그사이 그 줄이나 파일이 바뀌었으면 쓰지 않고 알린다.

## 내보내기와 저장

| 하는 일 | 생기는 파일 | 같은 이름이 있으면 |
|---|---|---|
| **PDF로 저장…** · **html로 저장…** · **Word로 저장…** | 저장 대화상자에서 고른 곳에 파일 하나 | Windows 가 덮어쓸지 묻는다 |
| 내보내기 창의 미리보기 · **인쇄…** | 없음 — 미리보기는 메모리에만, 인쇄는 인쇄 창으로 | — |
| **pptx 로 전환** | Lectern 슬라이드 옆에 pptx 하나 | 덮어쓰지 않고 `보고서 2.pptx` 처럼 새 이름 |
| **html 로 전환** | Lectern 슬라이드 옆에 발표 html 하나 | 같음 |
| **이 장을 템플릿으로 저장…** | 설정 폴더 `templates` 의 '내 템플릿' 묶음에 장 하나 | 있는 장은 고치지 않는다 |
| **이 문서를 스타일로 만들기** | 설정 폴더 `md-styles` 에 새 파일 하나 | 덮어쓰지 않는다 |

Lectern 프로그램 폴더 안(설치된 예제 등)에는 어떤 길로도 쓰지 않는다 — 그 안을 열면 보기만 하고 터미널도 열리지 않는다.

## Lectern 이 스스로 쓰고 읽는 곳

| 곳 | 무엇 |
|---|---|
| `%APPDATA%\Lectern\config.json` | 설정 창 · 툴바에서 고른 값, 열어 둔 탭, 최근 연 폴더, 창 크기, 프로젝트마다 마지막 문서와 위치 |
| `%APPDATA%\Lectern\cache` | 제목 기억 — 프로젝트마다 문서의 제목과 슬라이드 여부만. 본문 · 요약은 적지 않고, 지워도 다시 만든다 |
| 설정 폴더의 `styles` · `templates` 등 | 그 폴더를 여는 단추를 누를 때 없으면 빈 폴더로 만든다 — 안의 파일은 읽기만 |
| 연 프로젝트 폴더 | 그 폴더와 하위만 읽는다 — 숨김(`.git` · `.claude` 등)은 보지 않는다 |
| 업무 폴더 목록의 폴더 | 그 폴더의 `WORK.md` 한 파일만 — 탭을 닫아도 |
| 개인 폴더(`~/.claude` 등) | 설정 창 'AI 도구'의 지금 상태를 보이려고 정해진 파일 몇 개를 읽기만 |

## 인터넷

Lectern 은 스스로 인터넷에 연결하지 않는다 — 업데이트 확인 · 분석 · 웹 글꼴이 없다.

| 무엇 | 인터넷에 나가나 |
|---|---|
| 문서 속 인터넷(https) 그림 | 설정 창 '보기'의 **인터넷 그림 표시**가 켜져 있을 때만 (기본 켜짐) — 어느 문서에서 부르는지 알리지 않는다. 못 불러오거나 15초가 넘으면 링크로 |
| html 문서 | 스크립트 · 인터넷 CSS · 글꼴을 막는다 — 그림만 위 설정을 따른다 |
| 내 스타일 · 지면 틀 | 인터넷에서 글꼴 · 그림을 부르는 부분을 지운다 — 글꼴은 PC 에 있는 것만 |
| 차트 | 문서 안이나 프로젝트 안의 데이터만 — 인터넷 주소는 읽지 않는다 |
| **Word로 저장…** | 차트를 Windows 의 Edge 로 그린다 — 인터넷에 나가지 않는다 |
| **html 로 전환**의 결과 파일 | 그림 · 글꼴 · impress.js 가 파일 안에 든다 — 인터넷 그림만 주소로 남아 받은 사람의 브라우저가 부른다 |

## 터미널

| 무엇 | 하는 일 |
|---|---|
| 터미널에서 친 명령 | 친 그대로 실행된다 — 파일을 바꾸는 명령이면 바뀐다 |
| **▣ 터미널** · **Shift+→** · 요청 글 | 글만 넣는다 — Enter 는 누르지 않는다. 여러 줄이면 먼저 묻는다 (PowerShell 프롬프트에서는 줄마다 명령이 될 수 있다 — AI 도구가 떠 있으면 묻지 않고 입력 칸에 그대로) |
| 문서 속 링크 · 다른 기능 | 셸로 명령을 보내지 않는다. 실행 파일 · 스크립트는 어디서도 실행하지 않는다 |

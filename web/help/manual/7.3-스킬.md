# 스킬

> pptx 와 Lectern 슬라이드를 오가고 md 문서를 Word 로 만드는 스킬 셋이 Lectern 에 들어 있다. 설치는 사용자가 시킬 때 AI 도구가 묻고 한다.

스킬은 AI 도구가 읽는 작업 안내와 스크립트의 묶음이다. 네 도구(Claude Code · Codex · Antigravity · OpenCode)가 함께 쓰는 SKILL.md 형식이라 어느 도구에나 그대로 설치된다.

## 들어 있는 스킬

| 스킬 | 하는 일 |
|---|---|
| `pptx-to-lectern` | pptx·ppt 나 PowerPoint 에 띄워 둔 발표를 Lectern 슬라이드로 옮긴다. pptx 를 양식으로 참고해 md 문서를 Lectern 슬라이드로 만든다. pptx 로 pptx 스타일과 템플릿 묶음을 만든다 |
| `lectern-to-pptx` | Lectern 슬라이드를 pptx 로 만든다 — 스타일 유지, 고친 장만 반영, 회사 양식으로 |
| `lectern-to-docx` | md 문서를 Word(docx)로 만든다. 앱의 **Word로 저장…** 은 스킬을 설치하지 않아도 된다 |

## 설치

| 차례 | 할 일 |
|---|---|
| 1 | 설정 창(**Ctrl+,**)의 **PowerPoint·Word 스킬**에서 넣을 곳을 고른다 — **모든 폴더(개인)**(기본) · **이 폴더만** |
| 2 | 아래 **바뀌는 파일**에서 전체 경로와 할 일(새로 만듦 · 바꿈 · 그대로)을 본다 |
| 3 | **Claude Code용 요청 복사**로 붙여 넣거나 옆의 **▣** 로 터미널에 넣고 Enter 를 누른다 |
| 4 | AI 도구가 무엇을 하는 스킬인지 알리고 설치할지 묻는다 — 그렇다고 하면 없는 것과 다른 것만 설치한다. 세 스킬이 함께 설치된다 |
| 5 | 개인 폴더(`~/.claude`)나 폴더의 `.claude` 안에 쓸 때 Claude Code 가 허락을 한 번 더 묻는다 — 바뀌는 파일에서 본 것과 같으면 허락한다 |

| 도구 | 모든 폴더(개인) | 이 폴더만 |
|---|---|---|
| Claude Code | `~/.claude/skills` | `.claude/skills` |
| Codex | `~/.agents/skills` — 0.89 까지 요청 글이 말하던 `~/.codex/skills` 는 옛 자리 | `.agents/skills` |
| Antigravity | `~/.gemini/config/skills` | `.agents/skills` |
| OpenCode | `~/.config/opencode/skills` — `~/.claude/skills` 도 읽어서, Claude Code 용으로 설치했으면 따로 설치하지 않아도 보인다 | `.agents/skills` |

Antigravity·Codex 는 작업 폴더 밖의 스킬 폴더를 읽을 때 허용할지 물을 수 있다 — 허용하면 이어서 한다. 설치된 스킬은 설정 창의 **원문 보기**로 SKILL.md 와 그 폴더의 파일을 원문 그대로 본다.

## 이렇게 말한다

Lectern 이 AI 도구를 실행하지는 않는다. 터미널의 AI 도구에게 직접 말한다. `@문서.md` 는 트리에서 우클릭한 **@경로 복사**다.

| 하려는 일 | 요청 예 |
|---|---|
| pptx 를 Lectern 슬라이드로 | `이 pptx 를 Lectern 슬라이드로 옮겨 줘: D:\자료\보고서.pptx` |
| 띄워 둔 발표를 옮기기 | `지금 PowerPoint 에 띄워 둔 발표를 Lectern 슬라이드로 옮겨 줘. 결과는 D:\프로젝트\발표 폴더에 둬.` |
| 빨리 md 로만 | `D:\자료\보고서.pptx 를 일단 빨리 md 로만 뽑아 줘. 다듬는 건 나중에 할게.` |
| pptx 를 참고해 md 문서를 슬라이드로 | `D:\양식\회사보고.pptx 를 참고해서 @시장-분석.md 내용을 Lectern 슬라이드로 만들어 줘.` |
| 화면의 pptx 를 참고해 | `화면에 떠 있는 pptx 를 참고해서 @시장-분석.md 를 Lectern 슬라이드로 만들어 줘.` |
| 색과 표지만 참고해 | `D:\양식\회사보고.pptx 의 색과 표지만 참고해서 @주간보고.md 를 10장 안으로 Lectern 슬라이드로 만들어 줘. 숫자는 그대로 써.` |
| pptx 스타일과 템플릿 묶음 | `D:\양식\회사보고.pptx 로 '회사 보고' pptx 스타일과 템플릿 묶음을 만들어 줘.` |
| 띄워 둔 발표를 pptx 스타일로 | `지금 PowerPoint 에 띄워 둔 발표를 '회사 보고' pptx 스타일로 등록해 줘.` |
| 템플릿 하나 더 | `'회사 보고' 묶음에 표와 강조글이 있는 템플릿을 하나 더 만들어 줘.` |
| Lectern 슬라이드를 pptx 로 | `@발표.md 를 스타일을 최대한 유지해서 pptx 로 만들어 줘.` |
| 고친 장만 다시 pptx 로 | `pptx 에서 옮겨 온 @보고서.md 를 고쳤어. 고친 장만 반영해서 다시 pptx 로 만들어 줘.` |
| 회사 양식의 pptx 로 | `@발표.md 를 D:\양식\회사보고.pptx 양식으로 pptx 를 만들어 줘.` |

프롬프트 예제는 프로그램 폴더의 `_internal\skills\README.md` 에 더 있다. AI 도구가 읽는 Lectern 슬라이드 작성 안내는 `_internal\web\help\slides.md` 다.

## 옮길 때

| 무엇 | 어떻게 |
|---|---|
| 글 | 빠뜨리지 않고 장을 그대로 지킨다 |
| 글이 중심인 장 | 칸으로 다시 짠다 |
| 지도처럼 자리가 뜻인 도식 | 그림으로 남기고 글은 노트에 둔다 |
| 애니메이션 · 정확한 글꼴 | 옮기지 않는다 |
| 원본 pptx | 고치지 않는다. 띄워 둔 발표도 저장하거나 닫지 않는다 |

## 필요한 것

| 경우 | 동작 |
|---|---|
| Python | 설치하지 않아도 된다 — 스킬은 프로그램 폴더의 `lectern-skill.exe` 로 돈다 |
| PowerPoint 가 없으면 | `.pptx` 파일은 옮기고 내보낼 수 있다 |
| 띄워 둔 발표 · `.ppt` · DRM 파일 | PowerPoint 가 있어야 한다 |
| 암호가 걸린 파일 | 먼저 푼다 |
| DRM 이 걸린 파일 | PowerPoint 로 열어 띄워 두고 옮긴다 |

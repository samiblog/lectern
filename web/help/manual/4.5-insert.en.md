# Insert

> Press / on the current line and the Insert window opens below that line. Insert tables, images, charts, math, callouts, boxes, footnotes and special characters without remembering their markup.

## Opening it

| To | Mouse | Keys |
|---|---|---|
| Insert window below the current line | **Insert** on the tab bar · right-click **Insert here…** | **/** |
| In a cell | — | **/** on an empty line · **Ctrl+Shift+/** on a line with text |
| After a table · code block | Right-click a table **Insert here…** (below the table) | **/** on that block |
| Date · special character | Right-click in a cell **Special character…** | **Ctrl+;** · **Ctrl+Shift+;** |

A new line opens below that line and the window appears. Nothing is inserted while several lines are picked. With vi keys on, `/` is find, so use **Ctrl+Shift+/**.

## The Insert window

| To | Keys |
|---|---|
| Within a column · to the next column | **↑** · **↓** · **←** · **→** |
| Filter | Type — `table` · `box` · `note`. Typing only Korean initial consonants matches by first sounds (`ㅍ` for `표` table, `ㅉㄴ` for `쪽 나눔` page break) |
| Insert the same thing again | **/** · **Enter** — the first item of the first column, 'Recent' (the last five inserted), is already picked |
| Insert · cancel | **Enter** · **Esc** |

In a wide window the groups show as columns all at once.

| Group | Items |
|---|---|
| Text | Heading 1–4 · paragraph · list · numbered list · to-do · quote · date · special character |
| Callout | Note · tip · important · warning · caution |
| Tables and figures | Table · figure · chart · diagram · math · code · box |
| Notes and references | Note (footnote) · source line · table note · link · cross-reference · citation · attachment · appendix |
| Page | Divider · page break · contents · list of tables · list of figures |

Lines from the Text group go into the file when you write in them — typing `## ` · `- ` yourself works too. Cross-references · citations · contents are in [Numbers, references, contents and styles](4.6-numbers-references-contents-styles.en.md). Inserting in Lectern slides is in [Writing slides](5.1-writing-slides.en.md).

## What goes in

| Item | What goes in |
|---|---|
| Note (**Ctrl+Alt+F** in a cell) | Puts a mark at that spot in the text and asks for the note — saved with the body. Pressing it on a mark edits that note. Numbers follow the order of appearance, and the notes gather at the end of the document. Deleting a mark asks whether to delete the note too |
| Source line · table note | A line starting with `Source: ` · `Note: ` — in small type right under a table |
| Link (**Ctrl+K** in a cell) | Pick a project file or type an address — on the selected text if there is one |
| Attachment | A number and a link in the `## Attachments` section at the end of the document (before the footnotes) — the section is created if missing. The file is not copied |
| Appendix | `## Appendix A. Title` with the next letter — left out of the body numbering |
| Divider · page break | A divider is one `---` line. A page break shows on screen as a dashed line with 'Page break' and starts a new page when printed — other viewers don't show it |
| Date | The day picked in the calendar, as `YYYY-MM-DD` at the cursor |

## Tables

| To | How |
|---|---|
| Insert | Set the size as `3x4` (columns x rows) — a `Table 1. Title` caption with the next number comes above it and an empty `Source: ` line below it, with 'Title' selected (only the table in slides) |
| Fill cells · new row | Go into the table with **↓** and press **Tab** — **Tab** in the last cell and **Shift+Enter** add a row, **Ctrl+Shift+Enter** adds one above |
| Columns · alignment · chart · delete | Right-click a cell — add · move · delete columns, align this column left · center · right, **Turn this table into a chart**, **Delete table** |

## Images

| To | How | Result |
|---|---|---|
| Insert an image from the project | **Figure** in the Insert window — pick the file | A `Figure 1. Title` caption above, the image line, and an empty `Source: ` line below (only the image line in slides) |
| A copied image · an image file | **Ctrl+V** · drag and drop | A new file such as `image 1.png` in the `<name>-images` folder next to the document, and a caption · image line · source line after the current line |
| Edit the source | **F2** | The image's source line |

It is saved the moment you paste, and existing files are never overwritten. PNG · JPEG · GIF · WebP up to 20MB are accepted. Nothing is inserted while several lines are picked.

## Charts, diagrams and math

| Source | What is drawn |
|---|---|
| `$x^2$` | Math inside a sentence |
| Lines wrapped in `$$` · a code block in `math` · `latex` | Block math |
| A code block in `mermaid` | A Mermaid diagram |
| A code block in `dot` · `graphviz` | Structure diagrams · dependencies |
| A code block in `vega-lite` | Data charts |
| A code block in `echarts` | Many kinds of charts such as doughnut and candlestick |
| A code block in `plotly` | Analysis charts such as box plots and sunbursts (the output of Python's `fig.to_json()` too) |

Dollar amounts like `$105` are not turned into math. Chart settings are JSON and cannot use functions. The data is written in the document or points to a CSV · JSON file in the project by a relative path (internet addresses are not read).

| To | Keys | Result |
|---|---|---|
| Insert | **Chart** · **Diagram** · **Math** in the Insert window | Inserts a sample and opens the panel beside the view — charts · diagrams also get a `Figure n. Title` caption above and an empty `Source: ` line below (only the sample in slides) |
| Edit · fold an existing one | **F2** · **Esc** | The source in the panel — math and diagrams line by line in cells. The drawn result stays visible in place |
| A chart with its values in the document | **F2** | The values as a table — **Shift+Enter** adds a row, **Ctrl+Shift+K** deletes one, buttons below for bar · line · area · pie, **View source** (charts whose values are in another file, or complex ones, open as source) |

## Callouts and boxes

| Compare | Callout | Box |
|---|---|---|
| Source | `> [!NOTE]` · `[!TIP]` · `[!IMPORTANT]` · `[!WARNING]` · `[!CAUTION]` | Between a `<!-- box -->` line and a `<!-- /box -->` line |
| What | Note · tip · important · warning · caution — a color for each kind | A text box read apart from the body — a topic set off from the main flow |
| Numbers | None | Numbered when it is `Box 1. Title` — point to it with `[Box 1](#box-1)` |
| When inserted | **↓** on an empty new line leaves the callout | Inserts the opening line, `Box 1. Title`, one line of text and the closing line, and opens the title line |
| Wrapping text you wrote | Pick the lines and press **C** | Pick the lines (for one line, on that line) and right-click **Wrap in a box** — not wrapped if a heading line is included |
| Right-click | Change kind · remove · **Change to a box** · delete | **Change to a callout** · **Unwrap box** (removes only the two marker lines, the text stays) · **Delete box** |

Lines in a box are edited like ordinary lines, and adding or moving a box fixes the numbers and links too. A first line written as a single line becomes the title. Don't put headings (`#`) or other boxes inside. If the closing line is missing, the box is taken to end before the next heading. Other viewers don't show the two marker lines, so the text reads as ordinary text.

To keep a conversation with an AI tool (Claude Code and others) in the document, right-click a line (or picked lines) and choose **Ask Claude for a box** (the name follows the AI tool you use). A request such as 'summarize the conversation so far and insert it as a box right after `@doc line 12`' goes into the terminal; edit it and press Enter, and the AI tool writes the box there — after the block that holds the line, or after the last picked line. Lectern only puts the request in; the AI tool edits the file.

## Special characters

| To | How |
|---|---|
| Insert in a cell · edit mode | **Ctrl+Shift+;** · right-click in a cell **Special character…** — at the cursor |
| Insert in the reading view | **Ctrl+Shift+;** · **Special character** in the Insert window — opens the current line's cell and inserts at its end (no new line is made) |
| Filter | By name — 'arrow' · 'circled' · 'Celsius'; Korean names and initial consonants work too (`ㅅㅆ` for `섭씨`, Celsius) |
| Choose | **←** · **↑** · **↓** · **→** — the character's name shows on the bottom line. **Enter** inserts, **Esc** cancels, clicking works too |

The groups are punctuation (· — 「」 ※) · arrows (→ ⇒) · shapes (○ ● □ ■ ★) · math (± × ≤ ≒) · units and currency (℃ ㎡ ㎏ ₩ €) · numbers (① ㉠ ㉮ Ⅰ) · super- and subscripts (² ₂) · Greek (α Σ) · other, and the top row is the last twelve you inserted. The cell stays open after inserting, so you keep writing. Characters that break documents are left out — characters Markdown reads as markup, such as `*` · `_` · `|` · `#`; characters that look like a list or to-do, such as • ☐ ☑ (lists are `-`, to-dos `- [ ]`); the minus sign − that a table does not read as a number (negatives are `-`); and characters missing from Malgun Gothic · Batang (standard Korean Windows fonts) that change shape or turn into emoji on other PCs, in PDF or in Word, such as ✓ ✗ ⑯~⑳ ⁵~⁹ ☀ ✉.

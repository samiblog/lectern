# Writing slides

> Create Lectern slides, edit the text in cells in place, handle slides and cells, and set layouts and text size. Moving a pptx over is left to AI tools (Claude Code and others).

## Creating

| To | How | Result |
|---|---|---|
| New Lectern slides | **Ctrl+N** (or **Create** on the sidebar's 'Documents' group) → type a title and pick the kind **Lectern slides** → the first slide in the template gallery | A new document whose first slide is the template you picked |
| Turn an existing md document into slides | Right-click the document in the sidebar **Ask to make Lectern slides** | A request in the terminal — press **Enter** and the AI tool makes it as a new file in the same folder |
| Turn a pptx into slides | Ask the AI tool in the terminal | See [Asking an AI tool](#asking-an-ai-tool) below |

## Text in cells

Text is edited with line edit, as in md documents, and saved to the source the moment you press. A line added with **Shift+Enter** at the end of a cell stays in the cell, and moving or deleting lines does not break cells or slides.

| To | How | Result |
|---|---|---|
| Edit text | **F2** · **Enter** | **Enter** in the cell saves, **Ctrl+Z** undoes |
| Replace placeholder text | Open a template's placeholder text | All of it is selected, so typing replaces it |
| Insert components | **/** on an empty line in a cell | Heading · list · callout · table · figure · chart · diagram · math · code · source line · speaker notes (no footnotes · attachments · appendices · dividers) |
| Formatting | **Ctrl+B** · **Ctrl+I** · **Ctrl+K** · **Ctrl+\`** | As in md documents, and it stays in the cell |
| Pasting · tables · callouts | Pasting lines · Excel ranges, table rows and columns, the callout menu | As in md documents, and it stays in the cell |
| Images | Paste | Goes into the cell — **Ctrl+Shift+>** · **Ctrl+Shift+<** change the width |
| Source of math · diagrams | **F2** on it | Edit line by line in the panel beside the slide. The cell's picture updates on each save. **Esc** folds it |
| Chart values | **F2** on a chart | The values show as a table — edit cell by cell, add a row with **Shift+Enter**, delete one with **Ctrl+Shift+K**, buttons below for bar · line · area · pie. Charts whose values are in another file, or complex ones, open as source |
| Table to chart | Right-click a table **Turn this table into a chart** | The first column is the items, the next columns the values. In pptx it becomes a PowerPoint chart whose values can be edited there too |
| Speaker notes | Right-click **Write speaker note…** | One comment line at the end of the slide — it becomes the pptx notes |
| Checkbox | Click | Switches `[ ]` · `[x]` in the source (not during a presentation) |

## Handling slides and cells

| To | Right-click | Keys |
|---|---|---|
| New slide after this one, from a template | Slide **New slide…** | **Ctrl+M** |
| Duplicate a slide | Slide **Duplicate slide** | **Ctrl+D** |
| Move a slide earlier · later | Slide **Move slide earlier** · **Move slide later** | **Ctrl+Shift+PageUp** · **Ctrl+Shift+PageDown** (also **Alt+↑** · **Alt+↓** on the slide title line) |
| Delete a slide · change its template | Slide **Delete slide** · **Change template…** | — |
| Add a cell skeleton | Slide **Set layout…** — on a slide with cells only the cell names change, on a slide without cells its text goes into the first cell | Then fill it with **F2** |
| Cell look | Cell text **Cell look…** — looks such as box · accent · note | — |
| Swap the text of cells | Cell text **Move this cell back** · **Move this cell forward** | — |
| Empty a cell | Cell text **Empty this cell** | — |
| Split an overflowing cell | Overflowing cell **Move overflow to a new slide** — to a new slide with the same layout | — |
| Shorten an overflowing cell | Overflowing cell **Ask to shorten this cell** — a request in the terminal (the app never shortens text on its own) | — |

All of these come back with **Ctrl+Z**. The contents on the right is the slide list, and slides to check are marked.

## Source of cells and layouts

When templates are not enough, build cells in the source. Hidden lines show as tags in [Structure view](5.2-presenting-and-checking.en.md#structure-view), where you edit them.

| Source | Result |
|---|---|
| `---` | Slide break — one slide is 1280×720 |
| `::: a card` … `:::` | One cell — text · tables · charts · images inside |
| `<!-- layout: quad -->` | Picks a set layout |
| `<!-- grid: a a b / c d b -->` | Draws a layout yourself |
| `::: a at 100 200 300 120` | Sets a cell's position yourself |
| `<!-- links: a>b, c--d -->` | Arrows (`a>b`) and lines (`c--d`) between cells — the cell text is still edited as usual |
| `<!-- hidden: true -->` | Hidden slide — shown faded on screen and left out of presentations and PDF |

Lectern reads Marp's `paginate` · `header` · `footer` · `class: lead` · `invert` · background color, background images like `![bg right:40%](image)` and their filters, and CSS in `style:` and `<style scoped>`. It does not read `theme` (gaia and so on).

## Text size

| To | How | Result |
|---|---|---|
| One component on this slide | **Ctrl+Shift+>** · **Ctrl+Shift+<** on the current line | That slide's component, such as a table · callout · title, grows or shrinks by 1pt — one `<!-- text: table 14 -->` line in the source (**Ctrl+Z**) |
| One cell | The same keys on a cell with a size (`::: b 16`) | That cell's size changes |
| Whole document | Front matter `text: title 26, table 12` | Sizes for the whole document |
| Material read rather than shown | Front matter `reading: true` | Check limits become table 10pt · body 12pt |

The defaults are title 30 · subtitle 20 · body 18 · table 14 · callout 16. Changing the style keeps the sizes, and text inside charts and diagrams follows the cell size. Tables below 12pt and body text below 14pt show up in Check.

## Asking an AI tool

Moving a pptx into Lectern slides, or making slides with a pptx as a model, is done by the AI tool's skills. Install them from **PowerPoint and Word skills** → **Copy request for Claude Code** (or the terminal button beside it) in the Settings window, and only when you ask — the AI tool tells you what the skills do and asks whether to install them. Lectern does not run AI tools. Talk to the AI tool in the terminal yourself; get `@document.md` with **Copy @path** from a right-click in the tree.

| To | Example request |
|---|---|
| pptx to Lectern slides | `Move this pptx into Lectern slides: D:\data\report.pptx` |
| Move an open presentation | `Move the presentation open in PowerPoint into Lectern slides. Put the result in the D:\project\slides folder.` |
| Just md, quickly | `Quickly pull D:\data\report.pptx into md for now. I'll polish it later.` |
| md to slides with a pptx as a model | `Use D:\templates\company-report.pptx as a model and make @market-analysis.md into Lectern slides.` |
| With the pptx on screen as a model | `Use the pptx open on screen as a model and make @market-analysis.md into Lectern slides.` |
| Only its colors and cover as a model | `Use only the colors and cover of D:\templates\company-report.pptx and make @weekly-report.md into at most 10 Lectern slides. Keep the numbers as they are.` |
| A pptx style and template set | `Make a 'Company report' pptx style and template set from D:\templates\company-report.pptx.` |
| An open presentation as a style | `Add the presentation open in PowerPoint as the 'Company report' pptx style.` |
| Add a template to a set | `Add one more template with a table and a callout to the 'Company report' set.` |
| Lectern slides to pptx | `Make @deck.md into a pptx, keeping the style as much as you can.` |
| Only edited slides back to pptx | `I edited @report.md, which came from a pptx. Make the pptx again with only the slides I changed.` |
| pptx in a company template | `Make @deck.md into a pptx using the D:\templates\company-report.pptx template.` |

| Situation | What happens |
|---|---|
| When moving | No text is left out and the slides are kept as they are. Text-centered slides are rebuilt as cells, and diagrams where position carries meaning, like maps, stay as pictures with their text in the notes. Animations and exact fonts are not moved |
| The original | The original pptx is not changed. An open presentation is not saved or closed either |
| Without Python | It works — the skills run on `lectern-skill.exe` in the program folder |
| Without PowerPoint | `.pptx` files are moved and exported. Open presentations · `.ppt` · DRM files need PowerPoint |
| Password · DRM | Remove the password first. Open a DRM-protected file in PowerPoint, keep it open and move it from there |

More example requests are in `_internal\skills\README.md` in the program folder. The writing guide the AI tool reads is `_internal\web\help\slides.en.md` in the program folder.

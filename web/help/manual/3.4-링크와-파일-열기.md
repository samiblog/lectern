# 링크와 파일 열기

> 본문의 링크와 파일 경로는 대상에 따라 Lectern 안, 기본 앱, 편집기, 브라우저에서 열린다. 실행 파일과 스크립트는 어디서도 실행하지 않는다.

## 대상마다

| 링크 대상 | 열리는 곳 |
|---|---|
| 트리에 보이는 md · html 문서 | Lectern 안 — 지금 탭에서 (`#절` 이 붙으면 그 절로) |
| 같은 문서의 절 링크 · 각주 | 그 자리로 — **Alt+←** 로 돌아온다 |
| 폴더 | 그 폴더의 개요 |
| 코드 파일 | 코드 화면 — `#L42` 를 붙이면 그 줄 |
| CSV · 텍스트 파일 | Lectern 안 — [코드와 자료 보기](3.6-코드와-자료-보기.md) |
| 프로젝트의 PDF | Lectern 안 — `#page=12` 가 붙으면 그 쪽으로 ([PDF 보기](3.8-PDF-보기.md)) |
| 그림 · 오피스 파일 | 기본 앱 |
| 그 밖의 글 파일 | 편집기 (편집기가 없으면 탐색기에서 그 파일을 고른 채) |
| 웹 주소 | 기본 브라우저 |
| 프로젝트 폴더 밖 | 열리지 않는다 — 취소선으로 표시 |

본문의 `src/app.py:42` · `data/x.csv:5` 처럼 실제로 있는 파일의 경로는 링크가 되고, 누르면 그 줄로 간다. 문서 속 절대경로(`C:\...\chart.png`)도 프로젝트 안을 가리키면 열린다.

## 여는 법

| 하려는 일 | 마우스 | 키 |
|---|---|---|
| 지금 탭에서 열기 | 누르기 | **Alt+Enter** (링크가 있는 줄 · **Tab** 으로 간 링크) |
| 보던 문서를 두고 뒤에서 열기 | **Ctrl+누르기** · 가운데 버튼 · 우클릭 **새 문서 탭에서 열기** | — |
| 새 창에서 열기 | 우클릭 **새 창에서 열기** (문서 · 코드) | — |
| 돌아오기 | 마우스의 뒤로 버튼 | **Alt+←** |
| 링크 주소 복사 | 우클릭 **링크 주소 복사** — 옆의 **▣ 터미널**은 터미널에 | — |
| 인터넷 그림의 주소 복사 | 우클릭 **그림 주소 복사** | — |

## 키보드로 링크 고르기

| 키 · 상황 | 동작 |
|---|---|
| **Tab** · **Shift+Tab** | 현재 줄 뒤 · 앞의 링크로 초점을 옮긴다 — 마지막 링크 다음은 첫 링크로 돈다 |
| **Alt+Enter** | 초점이 간 링크 · 단추를 연다. 현재 줄에 링크가 여럿이면 고르는 메뉴 |
| **Enter** | 링크가 아니라 그 줄의 편집 |
| 링크가 없으면 | 문서 안의 단추(코드 화면 머리줄 등)를 돈다 |
| 문서 밖 | **Tab** 은 터미널 · 사이드바로 나가지 않는다 — 떠나려면 **F6** |
| 폴더 개요 · html 문서 | 그 안에서만 돈다 |
| 찾기 막대의 칸 | 막대와 문서 안만 돈다 |
| 여러 줄을 골랐으면 | **Tab** 은 레벨 바꾸기 — [줄 더하기·옮기기·지우기](4.3-줄-더하기-옮기기-지우기.md) |

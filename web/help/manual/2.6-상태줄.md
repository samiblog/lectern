# 상태줄

> 창 맨 아래 한 줄 — 지금 문서의 경로와 정보, 그 문서에서 쓰는 단추, 현재 줄과 고른 줄, 바뀐 곳, 변경 감시를 보인다.

## 왼쪽부터

| 자리 | 보이는 것 |
|---|---|
| 경로 | 지금 문서·코드의 경로 — 폴더 개요면 `폴더/` 나 '(프로젝트 루트)' |
| 단추 | 지금 문서에서 쓸 수 있는 것만 (아래 '단추') |
| 정보 | 수정 시각, 코드·자료는 형식·크기·인코딩 (아래 '정보') |
| 줄 | `현재 줄 12행` · `고른 줄 3~5행 · 3줄` 같은 줄 상태 (아래 '줄') |
| 바뀐 곳 | `바뀐 곳 3곳 ↓` — 밖에서 바뀐 곳이 화면 밖에 있을 때 |
| 오른쪽 끝 | 변경 감시 상태와 마지막 반영 시각 |

모두 펼치기에서는 고른 칸(테두리 강조)의 것이 보인다.

## 정보

| 화면 | 보이는 정보 |
|---|---|
| md 문서 | `수정` 시각 — 저장할 때마다 바뀐다 (저장할 때마다 알림을 띄우지 않는다) |
| HTML 문서 | `HTML` · 수정 시각 |
| 코드 · 텍스트 | 언어 · 줄 수 · 크기 · 수정 시각 |
| CSV · TSV | 형식 · 행 · 열 · 구분자 · 크기 · 수정 시각 |
| 엑셀 | `엑셀` · 시트 이름 · 행 · 열 · 크기 · 수정 시각 |
| 폴더 개요 | `문서 N개` |

코드·자료가 UTF-8 이 아니면 인코딩(CP949·UTF-16)도 보인다 — 엑셀이 저장한 CSV 와 '유니코드 텍스트' 같은 것이다.

## 줄

줄 표시는 md 문서와 코드 화면에서, `vi` 는 vi 키를 켠 동안 보인다. 표시에 마우스를 올리면 그때 쓰는 키가 나온다.

| 표시 | 뜻 |
|---|---|
| `현재 줄 12행` | 현재 줄 — 문서 탭마다 따로 남는다 |
| `고른 줄 3~5행 · 3줄` | **Shift+↑·↓** 등으로 고른 줄 |
| `현재 줄 12행 · 바꾸기` | 바꾸는 키(지우기·옮기기·줄 종류·레벨)를 한 번 누른 상태 — 파일은 그대로, 한 번 더 누르면 바꾼다 |
| `하이라이트 3~5행 · 3줄` | 줄 선택(**Ctrl+Enter**)으로 또렷하게 켠 줄 |
| `한 줄 편집 12행` | 칸을 연 줄 |
| `vi` · `vi d…` | vi 키를 켰다 · 두 글자 명령의 다음 글자를 기다린다 — 누르면 설정 창의 '편집' |

## 바뀐 곳과 변경 감시

AI 도구(Claude Code 등)가 문서를 쓰는 동안 1초 안에 화면에 반영되고, 바뀐 문단·표는 잠깐 배경색으로 표시된다.

| 표시 | 뜻 | 하는 일 |
|---|---|---|
| `바뀐 곳 N곳 ↓` | 다시 그린 블록 가운데 화면 밖에 있는 것이 있다 | 누르면 차례로 간다 — **F7** · **Shift+F7** 은 단추가 없어도 되고 현재 줄도 그리로 |
| 변경 감시 중 | 폴더의 파일 변경을 바로 받는다 | — |
| 변경 감시 중 (주기 확인) | 파일 알림을 받지 못해 주기적으로 살핀다 | — |
| 마지막 반영 시각 | 마지막으로 화면에 반영한 때 | 감시가 놓친 변경은 **F5** 로 다시 불러온다 |

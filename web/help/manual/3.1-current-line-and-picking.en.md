# Current line and picking

> Where you read is one current line. Widen it with Shift and it becomes picked lines; copy their location or source, or send them to an AI tool.

md documents and the code view (including csv and txt) count lines as lines of the source file — a paragraph, list item, heading or table row written on one line is one line as a whole, a paragraph split over several lines counts each source line, and code goes line by line. So the `@path lines 12-20` you send to AI tools (Claude Code and others) matches what you picked on screen.

## Four states of a line

| State | What it is | Get there | Leave |
|---|---|---|---|
| Current line | One line — where you read, write and insert. A small triangle on the left | Click · right-click · **↑**·**↓** and so on (below) | — |
| Picked lines | Several lines — copy · send · delete · move them together | **Shift+↑**·**Shift+↓** · Shift+click · Shift+drag · **Ctrl+A** | **Esc** · **↑**·**↓** · a click elsewhere · shrinking to one line |
| Focus | Only the current line or the picked lines stay sharp (select lines) | **Ctrl+Enter** | **Ctrl+Enter** · **Esc** · a click on a dimmed area — [Folding and focus](3.3-folding-and-focus.en.md) |
| Cell | A text box that edits the line right where it is on screen | **Enter** · **F2** | **Enter** saves · **Esc** cancels — [Line edit](4.2-line-edit.en.md) |

Moving the current line and picking lines don't change the file. The status bar shows `Current line 12` or `Picked lines 3-5 · 3 lines`, and each document tab keeps its own current line.

## Moving the current line

| What you want to do | Mouse | Key |
|---|---|---|
| To that line | Click · right-click the body | — |
| One line at a time — the view follows, and it stops at the last line | — | **↑** · **↓** |
| First · last line of the document | — | **Home** · **End** (**Ctrl+Home** · **Ctrl+End** too) |
| A screen at a time — the current line keeps its height on screen | — | **PageUp** · **PageDown** (**Shift+Space** · **Space** too) |
| Previous · next heading | — | **Ctrl+↑** · **Ctrl+↓** |
| By line number | — | **Ctrl+G** |

If you scroll with the wheel and the current line goes off screen, it follows to the nearest line on screen. Going somewhere with the contents, Find or Search moves it to that line.

## Picking several lines

| What you want to do | Mouse | Key |
|---|---|---|
| Widening · shrinking one line at a time | — | **Shift+↑** · **Shift+↓** |
| From the current line to that line | **Shift+click** | — |
| From the line you press to the line you drag to | **Shift+drag** | — |
| To the start · end of the document | — | **Shift+Home** · **Shift+End** |
| A screen's worth | — | **Shift+PageUp** · **Shift+PageDown** |
| To the section heading · section end (press again to reach the previous · next section) | — | **Ctrl+Shift+↑** · **Ctrl+Shift+↓** |
| All lines — the view stays | — | **Ctrl+A** |
| Releasing | A click elsewhere | **Esc** · **↑** · **↓** |

There is one selection. The first line stays and the last line moves, so it grows or shrinks, and when it shrinks to one line it is the current line again. For Shift+click, the current line is the line you last clicked or moved to (even if you scrolled afterwards). While several lines are picked, writing and inserting (new lines · the Insert window · pasting images) don't work — release them with **Esc**, then press the key. For selecting words, see [Line kinds and formatting](4.4-line-kinds-and-formatting.en.md).

## Copying and sending

| What you want to do | Key | Result |
|---|---|---|
| Copying the location | **Shift+←** | `@docs/report.md lines 40-52` — pasted into an AI tool's prompt, it points to that part |
| Copying the source | **Ctrl+C** | The source of those lines (or the text you dragged to select, if any) |
| Sending to an AI tool | **Shift+→** | The location goes into the first terminal (usually number 1) — Enter is not pressed, and focus goes to the terminal |
| Sending several places in a row | **Ctrl+Shift+→** | The same, with focus staying in the document (it sends even while words are selected) |
| To the terminal with that number | **Shift+1~5** · **Ctrl+Shift+1~5** | Focus goes to the terminal · stays in the document |

These keys don't change the file, so they act at once on the current line or the picked lines. After copying, 'Copied: …' shows briefly at the bottom of the screen. While words are selected, **Shift+→** widens the word selection instead of sending.

## Right-click menus

| Where you right-click | Item | What it does |
|---|---|---|
| Anywhere in the body | — | That line becomes the current line, and its heading · paragraph · table · image gets an outline |
| Paragraph | **Copy text** · **Copy source** | Text only · Markdown source |
| Heading | **Copy this section's source** · **Copy section link** · **Copy heading text** | The whole section · a link to that section · the heading only |
| Table · image | **Copy table** · **Copy image** | A table that pastes into Excel and Word · PNG |
| Any block | **Copy location** | `@path lines 40-52` |
| Selected text | **Copy selected text** (at the top) | Within one line, formats · Clip · Send too. The block's own menu is **Menu for this block…** at the bottom |
| Inside picked lines | A selection box for that range | What only that block can do · **Send to Claude** · copy · Clip · Send · **Change picked lines…** · release · delete lines |
| Outside picked lines | That line's menu | Releases the picked lines |

Menus keep the same order everywhere — what only that item can do → AI tools → copying → Clip and Send → edit and open → view → delete. Only shortcuts appear on the right; hover over an item for its description. From the keyboard, **Shift+F10** opens the current line's menu. **▣ Terminal** to the right of a copy item (selected text · location · source · code · `@path` · full path and so on) puts the same text into the terminal (Enter is not pressed). It is also in the right-click menus of the tree and the 'Code' and 'Other files' lists — [Terminal](7.1-terminal.en.md).

## Enter on the current line

| Key | What it does |
|---|---|
| **Enter** · **F2** | Opens the line edit cell — editing comes first, on a heading or a line with a link too. **Enter** in the cell saves and goes to the next line, so Enter, Enter goes through the lines as you fix them |
| **Alt+Enter** | On a heading, folds or unfolds the section; on a line with a link, opens the link (a menu to pick from if there are several) |
| **Ctrl+Enter** · **Shift+Enter** · **Ctrl+Shift+Enter** | Select lines (focus) · new line below · new line above — [Adding, moving and deleting lines](4.3-adding-moving-deleting-lines.en.md) |

## vi keys

Turn on **vi keys** in the 'Edit' part of the Settings window (**Ctrl+,**) to move and edit with letter keys. They are off by default; when on, `vi` shows in the status bar. The line states match vi's modes — the current line is Normal, picked lines are Visual and a cell is Insert. The mouse and the usual keys keep working.

| Key | What it does |
|---|---|
| **j** · **k** | Line below · above (type a number first to repeat — **3j**) |
| **gg** · **G** | First · last line (**12G** goes to line 12) |
| **[[** · **]]** | Previous · next heading |
| **zz** | Current line to the middle of the screen |
| **zc** · **zo** · **za** · **zM** · **zR** | Fold · unfold · toggle the section · fold all · unfold all |
| **/** · **n** · **N** · **:** | Find · next · previous match · go to line |
| **i** · **a** | Open the cell — caret at the start · end of the line |
| **o** · **O** | New line below · above |
| **V** | Hold the current line (the same as the first press of a change key) → **j**·**k** widen · **d** delete · **y** copy the source · **>**·**<** level · **J** join into one line · **V**·**Esc** release |
| **dd** · **yy** (**Y**) | Delete the line · copy its source |
| **p** · **P** | Put lines you deleted or copied below · above the current line (**yyp** · **Yp** duplicate a line) |
| **>>** · **<<** | Level — only that line for a heading (with its subsections, **Alt+Shift+←** · **Alt+Shift+→**) |
| **u** | Undo (redo is **Ctrl+Y**) |
| **Esc** (in a cell) | Save and leave (with vi keys off, cancel) |

| Situation | Behavior |
|---|---|
| Two-letter commands | Type the next letter within one second — meanwhile the status bar shows `vi d…` |
| **.** · Insert window | **.** opens the Change window as usual (it is not vi's repeat) · the Insert window is **Ctrl+Shift+/** (**/** is find) |
| One-letter line kind keys (L · N · T · Q · C and so on) | After holding the line with **V** — a double press on the current line doesn't hold it |
| Numbers on picked lines | Counts — for headings, use **H** or **Ctrl+Alt+1~6** |
| Lines put with **p** · **P** | What is kept inside the app (separate from the clipboard). Table rows go inside the table, and numbered lists are renumbered |
| Keys with Ctrl · Korean/English input | Ctrl keys stay as they are (**Ctrl+D** duplicates a slide, **Ctrl+F** finds); page with **PageUp** · **PageDown**. The keys work whatever the Korean/English input mode |
| Full editor | Set separately — **Full editor keys** in Settings ([Full editor](4.7-full-editor.en.md)) |

# 따로 창

> 문서·Lectern 슬라이드·사용설명서·예제 가이드를 메인 창 밖의 별도 창에 띄워 나란히 본다. 모니터가 둘이면 한쪽에 보고서, 다른 쪽에 자료를 둔다.

## 창의 종류

| 창 | 여는 법 | 몇 개 | 고치기 | 다른 프로젝트를 고르면 |
|---|---|---|---|---|
| 문서 창 (독립창) | 문서 탭 우클릭 **새 창으로 옮기기** · **Ctrl+Shift+N**, 목록·링크 우클릭 **새 창에서 열기** | 여럿 | 된다 | 숨는다 — 돌아오면 탭·스크롤 그대로 |
| 슬라이드 창 | Lectern 슬라이드를 **새 창에서 열기** · **새 창으로 옮기기** | 슬라이드마다 하나 — 있으면 그 창이 앞으로 | 된다 | 숨는다 |
| 사용설명서 창 | **F1** (명령 찾기·단축키 표의 '사용설명서'도) | 하나 — 또 누르면 떠 있는 창이 앞으로 | 보기만 | 숨지 않는다 |
| 예제 가이드 창 | **Shift+F1** · 예제 열기 · 설명서의 예제 링크 | 하나 — 다른 예제는 그 창의 새 문서 탭 | 보기만 | 숨지 않는다 |

창은 모두 합쳐 8개까지 띄운다. 어느 창이든 연 프로젝트 탭을 닫으면 함께 닫히고, 메인 창을 닫으면 모두 닫힌다. 다음 실행에는 다시 열리지 않는다.

## 문서 창

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 지금 문서를 옮기기 | 문서 탭 우클릭 **새 창으로 옮기기** · **Ctrl+Shift+N** | 원래 창의 탭은 사라지고 독립창에 같은 위치로 열린다 |
| 탭은 두고 열기 | 사이드바의 문서나 본문의 링크 우클릭 **새 창에서 열기** | 지금 탭은 그대로 |
| 메인 창으로 보내기 | 독립창의 문서 탭 우클릭 **메인 창으로 보내기** | 1초쯤 뒤 받는 창의 새 문서 탭에 같은 위치로 열리고 그 창이 앞으로 |
| 다른 독립창으로 보내기 | 어느 창에서든 문서 탭 우클릭 **(문서 이름) 창으로 보내기** | 〃 |
| 문서 더 열기 | **Ctrl+T** · **Ctrl+P** — 사이드바는 감춰져 있고 **Ctrl+B** 로 꺼낸다 | 문서 탭을 여럿 둔다 |
| 창 닫기 | **Ctrl+W** 로 마지막 문서 탭을 닫기 · 마지막 문서를 다른 창으로 보내기 | 창이 닫힌다 |

메인 창의 **열린 문서 모두 닫기**는 독립창의 문서를 건드리지 않는다.

## 메인 창에만 있는 것

프로젝트 탭·터미널·메모·설정·스타일 목록은 메인 창에 있다. 독립창에서 터미널과 메모로 보내는 것은 메인 창으로 간다.

| 독립창에서 | 가는 곳 | 메모 |
|---|---|---|
| **Claude로 보내기** · 터미널 단추 · **새 메모로 보내기** | 메인 창의 터미널 · 메모 | Enter 는 누르지 않고 메인 창이 앞으로 나온다 |
| **Shift+→** | 메인 창의 맨 앞 터미널 | 독립창에 머문 채 넣는다 |
| **Shift+숫자** · 메뉴의 숫자+누르기 | 메인 창의 그 번호 터미널 | — |
| **F6** | 문서와 사이드바만 오간다 | 독립창에는 터미널이 없다 |
| 글자 크기 같은 화면 조정 | 그 창에서만 — 저장되지 않는다 | 메인 창이나 설정 파일에서 바꾼 설정은 1~2초 안에 따라온다 (그 창에서만 바꾼 것은 다른 창이 그 설정을 바꿀 때까지 그대로) |

## 슬라이드 창

| 무엇 | 동작 |
|---|---|
| 여는 법 | 왼쪽 목록에서 Lectern 슬라이드 우클릭 **새 창에서 열기** · 열린 문서 탭에서 **새 창으로 옮기기**(**Ctrl+Shift+N**) |
| 이미 떠 있으면 | 그 창이 앞으로 온다 |
| 스타일 | 메인 창과 따로 고른다 — 기본은 **발표** 스타일. 메인 창의 문서 칸에서 볼 때는 메인 창의 스타일 |
| pptx 스타일 | 화면 스타일을 바꿔도 바뀌지 않는다 |
| 터미널 | 메인 창의 것을 쓴다 |

## 사용설명서 창과 예제 가이드 창

옆에 두고 따라 하는 보기 창이다. 그래서 다른 프로젝트 탭을 골라도 숨지 않는다.

| | 사용설명서 창 | 예제 가이드 창 |
|---|---|---|
| 보이는 것 | 이 설명서 | 예제 프로젝트의 문서 |
| 또 열면 | 떠 있는 창이 앞으로 | 그 창의 새 문서 탭으로 |
| 메인 창 | 그대로 | 보던 프로젝트 그대로 — 예제 탭은 뒤에 열린다 |
| 고치기 | 안 된다 | 안 된다 — 고쳐 보려면 예제 폴더를 다른 곳에 복사해 연다 |
| 왼쪽 보이기·감추기 | **Ctrl+B** — 설명서의 차례 (머리줄의 **▯** 로 감추고, 감추면 본문 왼쪽 위의 단추로 다시 보인다). 메인 창을 덮어 보일 때도 같다 | **Ctrl+B** — 사이드바 |
| 닫기 | **F1** · **Esc** · **✕** | **✕** · 마지막 문서 탭에서 **Ctrl+W** |
| 창의 예제 링크 | 메인 창에 맡긴다 — 예제 가이드 창에 열린다 | — |
| 창을 띄우지 못하면 | 메인 창을 덮어 보인다 (열린 프로젝트가 없을 때도) | 메인 창에 예제 탭으로 연다 |

설명서가 메인 창을 덮어 보일 때는 왼쪽 위 **사용설명서** 머리줄이나 차례의 문서를 우클릭한 **새 창에서 열기**(**Ctrl+Shift+N**)로 그 자리에서 창을 띄운다. 창은 프로젝트에 속하므로 먼저 폴더를 연다.

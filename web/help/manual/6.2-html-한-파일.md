# html 한 파일

> md 문서를 그림·차트·수식이 모두 든 html 파일 하나로 저장한다. 그 파일 하나만 보내면 받은 사람이 브라우저로 안전하게 연다.

## 여는 법

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| html 로 저장 | 본문 여백 우클릭 **html로 저장…** | 내보내기 창이 형식 **html 한 파일** 로 열린다 |
| 창에서 형식 바꾸기 | 내보내기 창 **형식** → **html 한 파일** | 미리보기가 html 로 다시 만들어진다 |
| 저장 | 창의 **html로 저장…** | 미리 본 그대로 저장 대화상자에서 고른 곳에 — 문서 옆, 문서 이름으로 열린다 |

## 담기는 것

| 문서의 것 | html 에서 |
|---|---|
| 모양 | 지금 화면 스타일 그대로 한 쪽에 길게 — **틀** 에서 지면 틀을 고르면 그 틀의 모양 |
| 그림 · 차트 · 다이어그램 · 수식 | 파일 안에 들어간다 — 파일 하나만 메일로 보내면 된다 |
| 접어 둔 절 · 박스글 | 펴서 담는다 |
| 목차 · 각주 · 상호 참조 링크 | 그대로 된다 |
| 다른 문서로 가는 링크 | 글로 남는다 |
| 복사 단추 · 줄 번호 같은 앱 표시 | 뺀다 |
| 맨 앞 설정 표 | 뺀다 |
| 스크립트 | 없다 — 받은 사람의 브라우저에서 안전하게 열린다 |
| 받은 사람이 인쇄하면 | PDF 와 같은 보고서 양식 — 틀을 골랐으면 그 틀의 꼴 |

## html로 저장과 html 로 전환

이름이 비슷한 두 길은 쓰는 문서가 다르다.

| 무엇 | **html로 저장…** | **html 로 전환** |
|---|---|---|
| 쓰는 문서 | md 문서 | Lectern 슬라이드 |
| 여는 곳 | 본문 여백 우클릭 · 내보내기 창 | 상태줄 |
| 결과 | 위에서 아래로 읽는 문서 | impress.js 발표 — 화면이 장 사이를 옮겨 다닌다 |
| 저장 | 저장 대화상자에서 고른 곳 | 문서 옆 — 같은 이름이 있으면 `보고서 2.html` 처럼 새 이름 |

Lectern 슬라이드에서는 내보내기 창의 html 형식이 꺼져 있다. html 문서는 이미 html 이라 이 메뉴가 없다.

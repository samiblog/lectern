# Highlights, notes and clip

> Highlight places to come back to, write down what comes to mind as notes, and clip pieces of several documents to send them to one document.

## Highlights

Use a highlight not only as a look but as a mark for 'a place to look at again later'. To highlight, double-click a word to select it and press **M** — [Line kinds and formatting](4.4-line-kinds-and-formatting.en.md).

| What you want to do | Mouse | Key |
|---|---|---|
| Seeing all highlights | The **Highlights** sub-group of 'Documents' in the sidebar — by document; click one to go to that line | — |
| Filtering by highlighted text | Type in the sidebar's filter box | — |
| Next · previous highlight — selects the highlighted text | — | **F8** · **Shift+F8** |
| Changing the color | — | **M** while it is selected (press again for the next color) |
| Adding a note | Right-click a highlight line · highlighted text (selected with **F8** or a double-click): **Add a note** | — |
| Removing one | Right-click a highlight line · highlighted text: **Remove this highlight** | — |
| Removing all in a document | Right-click a document row in the sidebar: **Remove all highlights in this document…** (per color too, when there are several) | — |

Removing leaves the text as it is and takes off only the highlight. One **Ctrl+Z** undoes it. Removing all asks first how many places, and a highlight in another document opens that document first to show you, then removes it. There is no way to remove highlights from many documents at once.

## Notes

Each project has its own notes. **Notes** in the tab bar or **Alt+M** opens and closes the panel on the right (**Esc** closes it too). It covers the document, so you can write while you look at the document.

| What you want to do | How | Result |
|---|---|---|
| A new note | Click **New note** and write | Saves itself |
| Decorating | Title · color · pin | Pinned notes come first |
| Filtering notes | Type in the box at the top | Only matching notes |
| As a to-do list | **To to-do** | A checkbox on each line — finished items move down; add items in the box at the bottom (or write `- [ ] item` in the text) |
| Copy · to the terminal · to a document | **Copy** · **Terminal** · **To document** | As Markdown text · pasted into the terminal (Enter is not pressed) · to a document in a document tab or a new document |
| Deleting | **Delete** | **Undo** appears at the top for a moment |
| Turning document text into a note | Right-click the body · selected text · an Elements item: **Send to new note** | That text becomes a note with `@path lines 12-20` below it — click that to go back there |
| A note on a highlight | Right-click highlighted text: **Add a note** | A note titled with the highlighted text — type its content right away |

## Where notes are kept

| Situation | Behavior |
|---|---|
| File | One file in the project folder, `.lectern/notes.md`, as Markdown. Created when you first write a note |
| Tree · search | Not shown |
| Moving the folder | The notes go with it |
| Letting AI tools (Claude Code and others) read them | `@.lectern/notes.md` |
| git repository | To keep them out, add `.lectern/` to `.gitignore` |
| Changed elsewhere in the meantime | Read again and merged |
| View-only projects (the samples and so on) | Notes are off |
| Going back | Notes made from selected text or a highlight find that text even if the document changes and lines move; notes sent from a block go to that line number ('Go to that place') |

## Clip

Pile up pieces of documents in **clip boxes**. A project can have several, and they stay when you quit the app — keep one per question or topic and gather the evidence there.

| What to clip | Where to right-click | Item | Key |
|---|---|---|---|
| A section — the heading and everything below it | The heading | **Clip this section** | **Alt+C** on the heading line |
| Table · image · chart (with the caption and the 'Source:' line right below) · diagram · math · code · paragraph | That block | **Clip** | **Alt+C** on that line |
| Selected text | The selected text | **Clip selected text** | **Alt+C** |
| Selected text in a PDF — the source is that page | The selected text | **Clip selected text** | **Alt+C** — [Viewing PDFs](3.8-pdf.en.md) |
| Picked lines | Inside the picked lines | **Clip** | **Alt+C** |
| One Elements item | That item | **Clip** | **Alt+C** with the focus on it |
| Everything shown in Elements — as narrowed by the filter · buttons (all the project's tables and so on) | Any item | **Clip all shown** | — |

| Where it goes | How |
|---|---|
| Into the **current box** | Clip · **Alt+C** — the message shows the box's name and count. With several boxes, the right-click menu says where it goes: **Clip — 'name'** |
| One piece into another box | **Alt+Shift+C** · right-click **Clip to another box…** — recent boxes come first. Type to filter, choose with **↑** · **↓** and **Enter** (the current box stays the same) |
| Into a new box | Type a new name in the same window and choose **New clip box 'name'** — it becomes the current box |
| When there is no box yet | One called 'Clip box' is made for you |

A clip holds the content as it was when clipped, so it stays the same even if the original document changes later. Lines in the code view and blocks of html documents are not clipped (they have no source lines).

## Clip boxes

The sidebar **Clip** tab lists the clip boxes one per line, like the document list. Clicking one lays it out in a document tab (below); its outline is in the contents panel on the right.

| Mark | Meaning |
|---|---|
| **●** | The current box — what you clip goes here. The number next to the tab is its count. Opening another box or restarting the app does not change it |
| **○** (on hover) | Click to make that box the current one |
| The number on the right | How many clips |
| A clip's ✎ · ⚠ | It has a note · its source document changed or is gone. Hover for its kind · source · note |

| What you want to do | Mouse | Key (focus in the list) |
|---|---|---|
| Laying a box out in a document tab | Click the box (**Ctrl+click** opens a new tab behind) | **Enter** |
| Seeing just the clips in the list | The box's arrow | **→** expand · **←** collapse |
| To that clip in the laid-out view | Click the clip | **Enter** |
| A new box | **+** at the top of the tab → type a name and press Enter | — |
| Changing the current box | **○** · right-click **Clip here** · **Clip here** in the laid-out view | — |
| Filtering — box names · clip titles · captions · notes · paths | The field at the top | **↓** in the field goes to the list |
| Order — by name · recent (last edited first) | The order button at the top of the tab | — |
| Editing a title | Right-click a box, **Edit title and description** | **F2** (box · clip) |
| Reordering clips | In the laid-out view | **Alt+↑** · **Alt+↓** |
| Removing a clip (documents stay as they are) · deleting a box (Recycle Bin) | Right-click | **Delete** |
| Undoing the last removal | **Undo** at the top of the tab | — |
| Moving · copying to another box | Right-click a clip | — |
| To the original place | Right-click a clip, **Show in document** · the source line in the laid-out view | — |
| `@path` to the terminal · copying it | Right-click a box | **Shift+→** · **Shift+←** |
| Sending all — in clipped order | Right-click a box, **Send to a document…** | — |
| At the cursor in the document being edited | A clip's **Send** (shown only while editing) | — |
| Handing to an AI tool | Right-click a box, **Ask Claude** (the name follows the 'AI tool' setting) | — |

Asking makes a request that lists the clips' locations (`@doc lines 12-19 ('name')`) and asks for a new document made from them. If you gave titles or notes, it points to the box's file too. Copy it or put it in with **▣ Terminal** (Enter is not pressed).

## Laying out a clip box

Lays out a clip box in one document tab — the clipped tables · images · charts · text as they really look, in order, with a title and a note for each. What you type is saved as you type.

| Place | What |
|---|---|
| Head | The box's title and description (a question, for example) — may be left empty |
| Sticky line | **Clip here** (**● current box** when it is) · **Send to a document…** · **To Claude Code** · **More** · Undo · the count |
| A card's title | Left empty, the caption or first words show dimmed |
| Source line | The document and lines it came from and the date — click it to go there (**Alt+←** comes back) |
| Note | Why you clipped it |
| Contents panel (right) | The outline of the clips — ✎ with a note, ⚠ when the source document changed or is gone |

| What you want to do | Key (focus on a card) |
|---|---|
| Previous · next card | **↑** · **↓** |
| Reordering | **Alt+↑** · **Alt+↓** |
| Removing | **Delete** |
| To the original place | **Enter** |
| Writing the title | **F2** — Enter goes to the note, Esc to the card |

| Mark on the source line | Meaning |
|---|---|
| Source changed | The clipped text is no longer in that document as it was — the card shows the content when it was clipped. Lines that only moved are not marked |
| Source is gone | Deleted, or renamed outside (renaming in Lectern is followed) |

The clipped content is not edited here — edit the original document, or the one you sent it to. Laid-out tabs are not reopened when you restart Lectern (the clips stay).

## The clip box file

| Question | Answer |
|---|---|
| Where | The project's `.lectern/clips/` — one md file per box. Not shown in the tree · search · Elements |
| When is it made | When you first clip, or make a box |
| Can AI tools read it | Yes — point to it with **Copy @path** in the box's right-click menu. Changes made outside show when you come back to the window and are merged with what you were writing. You can also ask it to add clips (the file format is in the writing guide for AI) |
| View-only projects (the installed samples and so on) | You can clip, but nothing is saved — it is gone when you quit the app |

## Sending

**Send to a document…** in a box's right-click menu and in the laid-out view sends all its clips; the one in a clip's right-click menu sends just that piece, right away.

| Receiver | Place | Saving |
|---|---|---|
| Where you are editing | At the cursor | Goes into the editor — save with **Ctrl+S** |
| A document open in a document tab | **At the end** · **At the beginning** · **End of section '…'** | Saved at once — one **Ctrl+Z** undoes it |
| **New document…** | Type a path and press Enter (it starts with the box's title) — created right away with a title line, and the pieces go to its end in a new document tab | Saved at once |

Only md documents open in document tabs and new documents can receive. To send to another document, open it in a document tab first (**Ctrl+click** it in the tree).

| What is fitted when sending | How |
|---|---|
| Relative paths of images · links · chart data | Rewritten for the receiving document |
| Footnotes | Definitions come along — renamed if names clash |
| Heading levels | Fitted to the place (under that section, for a section end) |
| A clip's title · note | The title becomes a heading above the piece, the note a `> Note: …` below it |
| Source | A `<!-- from: research/a.md lines 12-19 -->` comment that doesn't show on screen — so AI tools later know where it came from |

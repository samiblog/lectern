# Highlights, notes and clip

> Highlight places to come back to, write down what comes to mind as notes, and clip pieces of several documents to send them to one document.

## Highlights

Use a highlight not only as a look but as a mark for 'a place to look at again later'. To highlight, double-click a word to select it and press **M** — [Line kinds and formatting](4.4-line-kinds-and-formatting.en.md).

| What you want to do | Mouse | Key |
|---|---|---|
| Seeing all highlights | The **Highlights** sub-group of 'Documents' in the sidebar — by document; click one to go to that line | — |
| Filtering by highlighted text | Type in the sidebar's filter box | — |
| Next · previous highlight — selects the highlighted text | — | **F8** · **Shift+F8** |
| Changing the color | — | **M** while it is selected (press again for the next color) |
| Adding a note | Right-click a highlight line · highlighted text (selected with **F8** or a double-click): **Add a note** | — |
| Removing one | Right-click a highlight line · highlighted text: **Remove this highlight** | — |
| Removing all in a document | Right-click a document row in the sidebar: **Remove all highlights in this document…** (per color too, when there are several) | — |

Removing leaves the text as it is and takes off only the highlight. One **Ctrl+Z** undoes it. Removing all asks first how many places, and a highlight in another document opens that document first to show you, then removes it. There is no way to remove highlights from many documents at once.

## Notes

Each project has its own notes. **Notes** in the tab bar or **Alt+M** opens and closes the panel on the right (**Esc** closes it too). It covers the document, so you can write while you look at the document.

| What you want to do | How | Result |
|---|---|---|
| A new note | Click **New note** and write | Saves itself |
| Decorating | Title · color · pin | Pinned notes come first |
| Filtering notes | Type in the box at the top | Only matching notes |
| As a to-do list | **To to-do** | A checkbox on each line — finished items move down; add items in the box at the bottom (or write `- [ ] item` in the text) |
| Copy · to the terminal · to a document | **Copy** · **Terminal** · **To document** | As Markdown text · pasted into the terminal (Enter is not pressed) · to a document in a document tab or a new document |
| Deleting | **Delete** | **Undo** appears at the top for a moment |
| Turning document text into a note | Right-click the body · selected text · an Elements item: **Send to new note** | That text becomes a note with `@path lines 12-20` below it — click that to go back there |
| A note on a highlight | Right-click highlighted text: **Add a note** | A note titled with the highlighted text — type its content right away |

## Where notes are kept

| Situation | Behavior |
|---|---|
| File | One file in the project folder, `.lectern/notes.md`, as Markdown. Created when you first write a note |
| Tree · search | Not shown |
| Moving the folder | The notes go with it |
| Letting AI tools (Claude Code and others) read them | `@.lectern/notes.md` |
| git repository | To keep them out, add `.lectern/` to `.gitignore` |
| Changed elsewhere in the meantime | Read again and merged |
| View-only projects (the samples and so on) | Notes are off |
| Going back | Notes made from selected text or a highlight find that text even if the document changes and lines move; notes sent from a block go to that line number ('Go to that place') |

## Clip

Collect pieces of documents and send them to a document open in a document tab or to a new document.

| What to clip | Where to right-click | Item |
|---|---|---|
| A section — the heading and everything below it | The heading | **Clip this section** |
| Table · image · chart (with the caption and the 'Source:' line right below) · diagram · math · code · paragraph | That block | **Clip** |
| Selected text | The selected text | **Clip selected text** |
| One Elements item | That item | **Clip** |
| Everything shown in Elements — as narrowed by the filter · buttons (all the project's tables and so on) | Any item | **Clip all shown** |

Clips pile up in order in the sidebar **Clip** tab (with a count next to the tab). A clip holds the content as it was when clipped, so it stays the same even if the original document changes later. Each project tab has its own clips, and they are cleared when you quit the app. Lines in the code view and blocks of html documents are not clipped (they have no source lines).

## Clip tab

| What you want to do | Mouse | Key |
|---|---|---|
| Reordering | An item's **↑** · **↓** | **Alt+↑** · **Alt+↓** |
| Removing | An item's **✕** | **Delete** |
| Removing all — documents stay as they are | **Clear** at the top of the tab | — |
| To the original place | Click an item | — |
| Sending all — in clipped order | **Send to a document…** at the top of the tab | — |
| At the cursor in the document being edited | An item's **Send** — after the block the cursor is in | — |
| Handing to an AI tool | **Ask Claude** at the top of the tab (the name follows the 'AI tool' setting) | — |

Asking makes a request that lists the clips' locations (`@doc lines 12-19 ('name')`) and asks for a new document made from them. Copy it or put it in with **▣ Terminal** (Enter is not pressed).

## Sending

**Send to a document…** at the top of the Clip tab sends all the clips; **Send to a document…** in a right-click menu sends just that piece, right away.

| Receiver | Place | Saving |
|---|---|---|
| Where you are editing | At the cursor | Goes into the editor — save with **Ctrl+S** |
| A document open in a document tab | **At the end** · **At the beginning** · **End of section '…'** | Saved at once — one **Ctrl+Z** undoes it |
| **New document…** | Type a path and press Enter — created right away with a title line, and the pieces go to its end in a new document tab | Saved at once |

Only md documents open in document tabs and new documents can receive. To send to another document, open it in a document tab first (**Ctrl+click** it in the tree).

| What is fitted when sending | How |
|---|---|
| Relative paths of images · links · chart data | Rewritten for the receiving document |
| Footnotes | Definitions come along — renamed if names clash |
| Heading levels | Fitted to the place (under that section, for a section end) |
| Source | A `<!-- from: research/a.md lines 12-19 -->` comment that doesn't show on screen — so AI tools later know where it came from |

# Templates

> A template is a slide skeleton with spots for a title, text, callouts and charts. Preview and pick one in the gallery to make a new slide, and keep the current slide as your own template.

## Sets and templates

Templates are shared by all of Lectern, not kept per project.

| Term | What it is |
|---|---|
| Template | One slide with spots for a title · text · callouts · charts |
| Set | One Lectern slides file — each slide in it is a template |
| Basic set | The set that comes with Lectern — 12 templates |
| My templates | The set that collects slides added with **Save this slide as a template…** |
| Recently used | Where the templates you used lately collect |
| Templates folder | `%APPDATA%\Lectern\templates` |

## When the gallery opens

| When | How | The picked template becomes |
|---|---|---|
| Creating a new document | **Ctrl+N** → Type **Lectern slides** | The first slide of the new document |
| New slide | **Ctrl+M** · slide right-click **New slide…** | It goes after the current slide, and its title opens for typing |
| Change template | Slide right-click **Change template…** | Your text moves into the new cells, and text that does not fit stays in the last cell. Placeholder text you did not change does not move (**Ctrl+Z**) |

## Picking in the gallery

| What to do | Mouse | Keys |
|---|---|---|
| Pick a set | Click the set list on the left | **PageUp** · **PageDown** |
| Pick a template | Click | Number (slide order in the set) · move with the arrows and press **Enter** |
| Search all sets | The **Find a template** box at the top | Type letters |
| Stop | **Cancel** | — |

## My templates and editing sets

| What to do | How | Notes |
|---|---|---|
| Make the current slide a template | Slide right-click **Save this slide as a template…** → name | Added to the **My templates** set. The slide's text is saved as it is, so turn the content into placeholder text first |
| Edit sets | **Open templates folder** in the gallery | The templates folder opens in a Lectern tab — edit as usual with line edit and Check |
| A template's number · name | The source of the set file | Slide order is the number; the slide's name is `<!-- template: name -->` |
| Ask an AI tool (Claude Code and others) | **Ask Claude for a template** in the gallery | A request goes into the terminal — add the look you want and press **Enter** |
| Remembering the set | A document started from a set you made | The front matter gets `templates: Company report`, and that set opens first for the next slide too |

The 'Claude' in the button follows the name in the **AI tool** setting. If you save a slide with an image as a template, the image's path is saved as it is, so a document in another folder may not find the image.

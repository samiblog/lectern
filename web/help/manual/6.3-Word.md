# Word

> md 문서를 Word 에서 고쳐 쓸 docx 로 저장한다. 글·표·각주·캡션 번호는 Word 의 것으로 들어가고, 회사·기관의 Word 양식을 빌릴 수 있다.

## 여는 법

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| Word 로 저장 | 본문 여백 우클릭 **Word로 저장…** | 내보내기 창이 형식 **Word** 로 열리고 파일을 만든다 |
| 창에서 형식 바꾸기 | 내보내기 창 **형식** → **Word** | 같은 문서로 다시 만든다 |
| 양식 고르기 | 창의 **Word 양식** | 그 양식으로 다시 만든다 |
| 저장 | 창의 **Word로 저장…** | 저장 대화상자에서 고른 곳에 |

미리보기는 없고 만든 결과(그림 수·크기·알릴 것)가 보인다. 만드는 데 몇 초 걸린다 (차트가 많으면 더). 차트는 Windows 의 Edge 로 그린다 — 인터넷에 나가지 않는다.

## 옮겨지는 것

| md 문서 | Word 에서 |
|---|---|
| 글 | 글 |
| 표 | Word 표 — 머리행은 쪽마다 |
| 목록 | Word 목록 — 하위 항목이 있는 목록의 맨 위는 진하게 · 조금 크게 (화면과 같다) |
| 글머리 글자 목록 (`□` · `○` · `-` · `·`) | 항목마다 단락 — 글머리 글자는 그대로, 수준마다 들여 쓰고 꺾인 줄은 글자 뒤에. `○` 가 있는 묶음의 `□` 는 진하게 |
| 각주 | Word 각주 |
| `표 1.` · `그림 1.` 캡션 | Word 의 번호 필드 |
| `[표 1](#표-1)` 같은 상호 참조 | 그 캡션으로 가는 링크 |
| 형광펜 · 글자색 · 강조글 · 박스글 | 그대로 옮긴다 |
| 차트 · 다이어그램 · 블록 수식 | 그림 |
| 문장 속 수식 | 글 |
| `[목차]` 줄 | Word 가 열 때 '필드를 업데이트할까요?' 를 묻는다 — **예** 를 누르면 목차와 쪽 번호가 채워진다 |
| 쪽 | Word 가 나눈다 |

## Word 양식

| 양식 | 무엇 |
|---|---|
| Lectern 기본 양식 | A4 · 명조 본문 · 2쪽부터 머리에 제목 · 바닥 가운데 쪽 번호 |
| Lectern 양식 18가지 | 지면 틀과 같은 이름 · 묶음 — 업무·공공 · 연구 · 금융·컨설팅 · 매체·출판 · 안내 |
| 내 양식 | 회사 · 기관의 Word 양식 (.dotx · .docx) — 목록 맨 아래 |

같은 문서를 지면 틀로 PDF·html 을, 같은 이름의 양식으로 Word 를 내면 표지·요약 상자·결재란·쪽 머리가 같은 꼴로 나온다.

| 하려는 일 | 맨 앞 설정 · 원문 | 결과 |
|---|---|---|
| 표지와 정보 표 | `title` · `subtitle` · `author` · `org` · `date` · `number` … (한국어 키 `기관` · `부제` · `연구진` 도) | 채운다 — 비어 있는 키의 줄은 뺀다 |
| 요약 상자 | 이름 있는 박스글 `<!-- box: 요약 -->` | 양식의 그 자리로 |
| 결재란 | `결재: [담당, 팀장, 원장]` | 결재란 |
| 이름표를 영어로 | `lang: en` | 요약 · 차례 … 가 영어로 |
| 비어 있는 키 알기 | 양식을 고른다 | 아래에 설명 · 쪽 · 박스글 자리 · 비어 있는 맨 앞 설정이 보인다 — **맨 앞 설정 견본 복사** 가 비어 있는 키만 복사한다 (문서에는 쓰지 않는다 — 붙여 넣고 채우는 것은 사용자) |

## 창을 열 때 골라지는 양식

| 차례 | 문서에 있으면 | 골라지는 양식 |
|---|---|---|
| 1 | 맨 앞 설정 `docxStyle: 양식 이름` | 그 양식 |
| 2 | `layout:` (지면 틀) 과 같은 이름의 내 양식 | 그 내 양식 |
| 3 | `layout:` 과 같은 이름의 Lectern 양식 | 그 Lectern 양식 |
| 4 | 둘 다 없으면 | Lectern 기본 양식 |

틀과 양식이 같은 이름이라 `layout: 연구보고서` 한 줄이면 PDF·html·Word 가 짝지어진다.

## 내 양식

| 하려는 일 | 방법 |
|---|---|
| 양식 넣기 | 창의 **양식 폴더 열기** → 그 폴더에 .dotx · .docx 를 넣는다 → 목록 맨 아래 **내 양식** |
| 빌리는 것 | 양식의 스타일 · 쪽 크기 · 여백 · 머리글 · 바닥글 — 본문만 새로 쓴다 |
| 양식이 자기 이름의 스타일을 쓸 때 ('1.제목' · '본문2' 처럼) | 양식 옆에 `양식이름.styles.json` — `{"heading 1": "1.제목", "Normal": "본문2"}` |
| 표지 두기 | Word 에서 양식의 글 속에 `{{title}}` · `{{author}}` · `{{date:ko}}` 같은 자리를, 본문이 들어갈 곳에 `{{body}}` 한 줄을 둔다 — 자리의 전체 목록은 스킬의 SKILL.md |

## 절 제목 왼쪽의 작은 ▪

| 물음 | 답 |
|---|---|
| 무엇인가 | 글자가 아니라 Word 가 '다음 단락과 함께' 가 걸린 문단에 보이는 표시 — Word 의 **단락 기호** 를 보이게 해 두면 나온다 |
| 왜 있나 | 절 제목 · 캡션이 쪽이 바뀔 때 다음 글과 떨어지지 않게. 첫 쪽 맨 위의 문서 제목 · 부제에는 두지 않는다 |
| 인쇄되나 | 인쇄 · PDF 에는 나오지 않는다 — Word 기본 제목 스타일에도 같은 표시가 붙는다 |
| 안 보려면 | Word 의 **파일 > 옵션 > 표시** 에서 '단락 기호' 를 끈다 |

## 앱의 Word로 저장과 Word 스킬

| 길 | 설치 | 쓰는 때 |
|---|---|---|
| 앱의 **Word로 저장…** | 없어도 된다 | 내보내기 창에서 양식을 골라 바로 |
| 스킬 `lectern-to-docx` | 설정 창 **PowerPoint·Word 스킬** 의 요청 글로 PowerPoint 스킬과 함께 — 사용자가 시킬 때만 | 터미널의 AI 도구(Claude Code 등)에게 Word 로 만들어 달라고 할 때 |

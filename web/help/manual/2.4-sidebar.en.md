# Sidebar

> The four tabs on the left — Files, Recent, Search and Clip. The 'Files' tab shows the project's files in four groups: Documents, Code, Other files and Folders.

## Four tabs

| Tab | What it shows | Keys | More |
|---|---|---|---|
| Files | Four groups: Documents · Code · Other files · Folders | **Ctrl+Shift+E** | Below |
| Recent | Files in the order they were changed — the **Documents**, **Code** and **Other files** buttons at the top choose what to show (with all on, mixed, newest first). Other files open with a double-click or **Enter**, and the right-click menu is the same as in the 'Code' and 'Other files' lists. The number next to the tab is how many changed documents you have not opened yet | — | — |
| Search | Find in the text and file names of all documents and code | **Ctrl+Shift+F** | [Find and search](3.2-find-and-search.en.md) |
| Clip | Clip boxes — click one like a document to lay it out, send them to an open or new document (the current box's count next to the tab) | **Alt+C** (clip) | [Highlights, notes and clip](3.5-highlights-notes-clip.en.md) |

Elements is not a sidebar tab — it opens as one document tab, from the **Elements** button on the tab bar or by right-clicking a folder. [Elements](3.7-elements.en.md)

Show and hide the sidebar with the first toolbar button or **Ctrl+B**. Drag its edge to change the width; double-click the edge for the default width.

## Files — four groups

| Group | What it holds | Clicking |
|---|---|---|
| Documents | Markdown and HTML documents and PDFs (a folder tree — PDFs are view only) | Once — opens in the main area. A folder name shows that folder's overview |
| Code | Source (py, js, ts…) · scripts (ps1, bat, EViews prg) · web (css) · config (json, yaml, toml) | Once — the code reading view; twice — the external editor |
| Other files | Files that are neither documents nor code — Office, images, data, archives, programs | Once — csv, tsv, txt, log and xlsx are shown in Lectern; twice — the default app (programs and archives are never run, only selected in Explorer) |
| Folders | The real folder structure as one tree, without splitting the other three | Files as above. For a folder overview, right-click the folder |

Pick a group with its header.

| What | Behavior |
|---|---|
| Clicking a header | Opens only that group (one at a time) — it takes all the remaining height and the others shrink to their headers. Each project tab remembers the open group |
| Number in the header ('Documents 10', 'Code 3') | How many files the group has — while you type in the filter box, how many match ('Folders' has no number, since it is the other three together) |
| **Create** | Shown only on the open group's header — see 'Create' below |
| **Ctrl+Shift+E** | Focus goes to the row of the document you are viewing in the open group (showing the sidebar if it was hidden) — press it again inside to go to the next group (Documents → Code → Other files → Folders → Documents) |
| Amber dot | A changed document you have not opened yet |

## Sub-groups inside 'Documents'

When 'Documents' is open, its sub-groups are stacked under it, indented one step. These too open one at a time, and the tree appears right below the open one.

| Sub-group | Shows |
|---|---|
| All | Every document |
| Documents | Markdown documents (without slides) |
| Slides | Lectern slides |
| HTML | HTML documents |
| PDF | PDFs — click to [view](3.8-pdf.en.md), double-click for the default app |
| Work | The `WORK.md` of each folder |
| Highlights | Documents with highlighted text — the highlighted text below each, one line per highlight, with its color |
| To-dos | Documents with open to-dos — the to-dos below each, one per line |

Kinds with no documents, and kinds that are the same as 'All', are hidden (Highlights and To-dos show whenever there are md documents, even at 0). Highlights and To-dos are found by reading the documents' text, so they take a moment the first time you open them, and their counts fill in then. After that only changed documents are read again, and code blocks are skipped. Click a line to go to that place in the document; right-click it to add a note or remove it.

## The box and buttons above the list

| Box · button | What it does |
|---|---|
| Filter box | Filters by name or title (the Highlights group by highlighted text too). On a folder overview, **Ctrl+F** also goes to this box |
| Titles | On: document titles instead of file names. Off: file names (the title shows on hover) — Quick open, search results, Elements, Recent and document tabs follow it too |
| Sort | By name · By time · By type — folders always come first. By time puts the newest on top (a folder goes by its newest file); by type goes by extension |
| ↕ | Expand all folders · Collapse all folders · Expand first-level folders only — excluded folders are not expanded |
| Telling apart | When the same text appears more than once in a list, a dimmed hint is added — the file name for the same title (`Same title · notes.md`), the folder for the same name in document tabs, which show no folder (`README.md · a`). Lists that already show the folder (the tree, search results and so on) get no folder |

## Keyboard

All four groups work like Explorer. **Tab** stops once per list; move inside a list with the arrow keys.

| Key | What it does |
|---|---|
| **↑** · **↓** · **Home** · **End** | Item above or below · first or last |
| **→** · **←** | Expand a folder (if it is open, go to its first item) · collapse (if it is closed, go to the parent folder) |
| **Enter** | Open — files you can view open as with one click, other files in the default app (a folder in 'Documents' shows its overview) |
| A letter | The item starting with that letter — type it again for the next one |
| **F2** | Rename the selected file |
| **Shift+→** | Puts the `@path` of the picked document · folder into the terminal you used last — focus moves to the terminal (Enter is not pressed). The same as **▣ Terminal** next to **Copy @path** in the right-click menu. In the Clip tab: the box's file, and for a clip the lines it came from |
| **Ctrl+Shift+→** | Puts the same text and keeps the focus in the list — move with **↓** and send several files in a row |
| **Shift+1~5** · **Shift+←** | To the terminal with that number · copy the `@path` (highlight · to-do rows use `@path line N`) |

## Excluded folders

Folders such as `node_modules`, `dist`, `build`, `venv` and `__pycache__`. They stay out of the document tree and search, appear dimmed and collapsed only in 'Other files', and are not counted in the header numbers or matched by the filter.

| Case | Behavior |
|---|---|
| When expanded | The contents are read then (there can be a great many files) — everything inside is listed here whatever its kind; code opens in the reading view with one click |
| When the contents change | Not followed automatically — collapse and expand it again, or press **F5** |

## Create

What **Create** on a group header can make depends on where you open it. The Create window is described in [Creating](4.8-creating.en.md).

| Opened from | What it makes | Starting location |
|---|---|---|
| Create in 'Documents' | md document · Lectern slides · folder | The folder of the document you are viewing, or of the folder overview |
| **Ctrl+N** | All five — md document · Lectern slides · code file · data file · folder | Same as above |
| Create in 'Code' | Code file · folder | The folder selected in that list (if a file is selected, its folder; if nothing is, the project's top folder) |
| Create in 'Other files' | Data file (CSV, TSV, text) · folder | Same as above |
| Create in 'Folders' | All five | Same as above |

## Renaming and deleting documents

| | Rename | Delete document |
|---|---|---|
| How to open | Right-click a file, **Rename…** · select its row and press **F2** (document tree, 'Code', 'Other files', Recent, search results) | Right-click a document in the document tree, **Delete document…** |
| What it does | Only the name, within the same folder — the name is selected up to the extension, so type over it and press **Enter** (**Esc** leaves it as is) | Always asks first and sends it to the Recycle Bin — restore it from there |
| When it doesn't | If a file with that name exists or the name can't be used (starting with a dot, `\`, `/`, `:`, `*`, `?`, `"`, `<`, `>`, `\|` and so on), the reason is shown. Changing the extension asks once more. With unsaved edits, save or close the editor first | Code and other files are not deleted. Places without a Recycle Bin (network drives and so on) get a message saying why. Documents with unsaved edits are not deleted |
| What follows | The document tab showing it (and edit mode, if it was open) · back history · clipped pieces | — |
| What stays | Links to this document in other documents · folder names · files in excluded folders — there is no move | — |

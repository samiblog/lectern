# 단축키

> 단축키를 찾는 길과 Lectern 의 모든 단축키 — 아래 표는 단축키 표(Ctrl+/)와 같은 목록으로 만들어진다.

## 찾는 길

| 하려는 일 | 방법 | 결과 |
|---|---|---|
| 키를 빨리 보기 | **Ctrl+/** · 툴바 **?** | 단축키 표 — 탭 여덟, 열 때마다 첫 탭 **자주 쓰는 것**에서 시작 |
| 단축키 표의 탭 옮기기 | 탭 누르기 · **Ctrl+Tab** | 옆 탭 |
| 하는 일이나 키로 찾기 | 단축키 표 위 찾기 칸에 `표` · `Ctrl+K` 처럼 | 모든 탭에서 맞는 줄만 |
| 이름으로 찾아 바로 하기 | **Ctrl+Shift+P** (명령 찾기) · **Ctrl+P** 칸에서 `>` | 맞는 명령과 오른쪽에 그 단축키 — **Enter** 로 바로 한다 |
| 키가 없는 일 | 명령 찾기 | 인쇄 · PDF, 모두 펼치기, 열린 문서 모두 닫기, 설정 원문 보기 등 |
| 이 문서에서 찾기 | **Ctrl+F** | 아래 표에서 |

## 단축키 표의 탭

| 탭 | 들어 있는 것 |
|---|---|
| 자주 쓰는 것 | 처음 익힐 스무 가지 — 읽고 고르기 열, 쓰고 고치기 열 |
| 열기·화면 | 열기 · 찾기, 프로젝트 탭, 문서 탭, 화면, 찾기 막대, 사이드바, 도움말 · 설정 |
| 고르기·복사 | 현재 줄 · 고르기 · 복사, 고른 글의 서식 |
| 쓰기·바꾸기 | md 문서의 새 줄 · 넣기 · 바꾸기 · 옮기기 · 지우기 · 되돌리기 |
| 한 줄 편집 | 칸 안의 키 (**F2**) |
| 터미널 | 터미널, 터미널로 보내기 |
| 편집 모드·슬라이드 | 전체 편집, Lectern 슬라이드와 발표 |
| vi 키 | 설정 창 '편집'에서 켤 때 |

## 키가 듣는 곳

| 곳 | 동작 |
|---|---|
| 터미널 안 | 키는 셸로 간다. 앱 키(**Ctrl+P** · **Ctrl+F** · **F1**)는 본문을 누른 뒤에 쓴다. **Ctrl+Tab** 은 터미널 안에서도 다음 탭 |
| 한 줄 편집 칸 안 | **F1** · **Ctrl+/** · **Ctrl+W** · **Ctrl+Tab** · **Alt+1~9** · **Ctrl+P** 같은 앱 키가 듣는다 — 칸을 저장하고 닫은 뒤 그 일을 한다 |
| 한/영 | 줄 종류의 한 글자 키(**1~6** · **L** · **N** · **T** · **Q** · **C**)와 vi 키는 한/영을 바꾸지 않아도 듣는다 |
| 현재 줄 하나 | 바꾸는 키(지우기 · 옮기기 · 줄 종류 · 레벨)는 두 번 — 처음은 그 줄을 잡기만 한다 |
| 표의 ` / ` | 키와 하는 일이 같은 차례로 짝 — **Ctrl+Tab** / **Ctrl+Shift+Tab** 은 다음 / 이전 |

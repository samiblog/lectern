# 용어

> 이 설명서에 나오는 Lectern 의 말 — 뜻과 그 말을 자세히 다루는 문서.

## 화면과 창

| 말 | 뜻 | 자세히 |
|---|---|---|
| 프로젝트 | Lectern 으로 연 폴더 하나 — 프로젝트 탭 하나 (10개까지) | [프로젝트 탭](2.2-프로젝트-탭.md) |
| 프로젝트 탭 | 툴바 아래, 열린 프로젝트마다 탭 하나 | [프로젝트 탭](2.2-프로젝트-탭.md) |
| 문서 탭 | 본문 바로 위 — 한 프로젝트에서 열어 둔 문서들 (40개까지) | [문서 탭](2.3-문서-탭.md) |
| 모두 펼치기 | 문서 탭 줄의 **▦** — 한 프로젝트의 문서 탭들과 터미널을 창 전체 격자에 | [문서 탭](2.3-문서-탭.md) |
| 폴더 개요 | 폴더를 열면 처음 보이는 화면 — 방금 바뀐 문서, 하위 폴더, 문서마다 제목 · 요약 · 수정 시각 | [읽기](3-읽기.md) |
| 사이드바 | 왼쪽 — 파일 · 최근 변경 · 검색 · 담기 탭 | [사이드바](2.4-사이드바.md) |
| '자료' 목록 | 사이드바 '파일' 탭에서 문서도 코드도 아닌 파일 — 오피스 · 그림 · 데이터 등 | [사이드바](2.4-사이드바.md) |
| 제외 폴더 | `node_modules` · `dist` 같은 폴더 — 문서 트리와 검색에 나오지 않고 '자료'에만 흐린 접힌 폴더로 | [사이드바](2.4-사이드바.md) |
| 목차 | 오른쪽 — 지금 문서의 제목과 표 · 그림 같은 구성 요소 | [목차](2.5-목차.md) |
| 상태줄 | 맨 아래 — 문서 경로 · 수정 시각 · 바뀐 곳 · 변경 감시 | [상태줄](2.6-상태줄.md) |
| 메인 창 | 프로젝트 탭 · 터미널 · 메모 · 설정이 있는 Lectern 의 본 창 | [따로 창](2.7-따로-창.md) |
| 따로 창 | 메인 창 밖의 별도 창 — 독립창 · 슬라이드 창 · 사용설명서 창 · 예제 가이드 창 | [따로 창](2.7-따로-창.md) |
| 독립창 | 문서를 옮겨 나란히 보는 따로 창 — 그 프로젝트에 속한다 (8개까지) | [따로 창](2.7-따로-창.md) |
| 슬라이드 창 | Lectern 슬라이드를 '새 창에서 열기'로 띄운 창 — 스타일을 따로 고른다 | [따로 창](2.7-따로-창.md) |
| 사용설명서 창 | **F1** 로 뜨는 이 설명서의 창 — 하나뿐, 보기만 | [따로 창](2.7-따로-창.md) |
| 예제 가이드 창 | **Shift+F1** 로 예제 프로젝트의 문서를 보는 창 — 하나뿐, 보기만 | [따로 창](2.7-따로-창.md) |
| 터미널 모음 | 툴바의 버튼 · **Ctrl+Shift+\`** — 열린 프로젝트들의 터미널을 한 화면 격자에 | [터미널](7.1-터미널.md) |

## 읽기와 고르기

| 말 | 뜻 | 자세히 |
|---|---|---|
| 줄 | 원문 파일의 줄 — 한 줄로 쓴 문단 · 목록 항목 · 제목 · 표의 행은 통째로 한 줄 | [현재 줄과 고르기](3.1-현재-줄과-고르기.md) |
| 현재 줄 | 지금 보는 줄 — 왼쪽의 작은 삼각형. 읽는 자리이고 쓰고 넣는 자리 | [현재 줄과 고르기](3.1-현재-줄과-고르기.md) |
| 고른 줄 | 현재 줄에서 **Shift+↑·↓** 로 넓힌 여러 줄 — 한꺼번에 지우고 옮기고 바꿀 줄 | [현재 줄과 고르기](3.1-현재-줄과-고르기.md) |
| 줄 선택 (하이라이트) | **Ctrl+Enter** — 현재 줄이나 고른 줄만 또렷하게, 나머지는 흐리게 | [현재 줄과 고르기](3.1-현재-줄과-고르기.md) |
| 장 | 문서의 맨 위 수준 절. Lectern 슬라이드에서는 슬라이드 한 장 | [접기와 하이라이트](3.3-접기와-하이라이트.md) |
| 장 하이라이트 | **Alt+H** — 현재 줄이 있는 장만 또렷하게. 끄는 것은 하이라이트 해제 | [접기와 하이라이트](3.3-접기와-하이라이트.md) |
| 누르기 | 마우스 왼쪽 단추로 한 번 — 이 설명서는 '클릭'이라 하지 않는다 | — |
| 거르기 | 목록 · 표에서 친 글에 맞는 것만 남기기 | [사이드바](2.4-사이드바.md) |
| 문서 열기 | **Ctrl+P** — 이름 · 제목 · 경로로 열기 | [찾기와 검색](3.2-찾기와-검색.md) |
| 문서에서 찾기 | **Ctrl+F** — 지금 문서 안에서 | [찾기와 검색](3.2-찾기와-검색.md) |
| 검색 | **Ctrl+Shift+F** — 모든 문서 · 코드의 본문에서 | [찾기와 검색](3.2-찾기와-검색.md) |
| 명령 찾기 | **Ctrl+Shift+P** — 기능 이름을 쳐서 바로 하기 | [단축키](10.1-단축키.md) |
| 바뀐 곳 | 밖에서(AI 도구 등) 고쳐져 다시 그려진 블록 — **F7** · **Shift+F7** 로 차례로 | [찾기와 검색](3.2-찾기와-검색.md) |
| 형광펜 | 칠해 둔 글 — 다시 볼 곳 표시로도 (**F8**) | [형광펜·메모·담기](3.5-형광펜-메모-담기.md) |
| 메모 | 프로젝트마다 오른쪽 패널에 쓰는 메모 (**Alt+M**) | [형광펜·메모·담기](3.5-형광펜-메모-담기.md) |
| 담기 · 담기함 | 문서의 조각을 담기함에 쌓아 두고(**Alt+C**) 제목·메모를 달아 펼쳐 보고 다른 문서로 보내기 — 사이드바 '담기' 탭 | [형광펜·메모·담기](3.5-형광펜-메모-담기.md) |
| 모아 보기 | 프로젝트의 표 · 그림 · 차트 같은 요소를 문서 탭 하나에 실제 모습으로 펼쳐 놓는 화면 (파일을 종류마다 모으기도) | [모아 보기](3.7-모아-보기.md) |

# Status bar

> The row at the very bottom of the window — shows the current document's path and information, the buttons for that document, the current and picked lines, changes and change watching.

## From the left

| Area | What it shows |
|---|---|
| Path | The path of the current document or code — for a folder overview, `folder/` or '(project root)' |
| Buttons | Only those you can use in the current document (see 'Buttons' below) |
| Information | Modified time; for code and data files, format, size and encoding (see 'Information' below) |
| Lines | Line state such as `Current line 12` · `Picked lines 3-5 · 3 lines` (see 'Lines' below) |
| Changes | `3 changes ↓` — when places changed elsewhere are off screen |
| Right end | Change watching status and the last refresh time |

In Spread all, it shows what belongs to the selected cell (the one with the highlighted border).

## Buttons

| Button | Shown for | What it does | Keys |
|---|---|---|---|
| Source lines · View as md document | md documents (except in view-only projects) | Shows the md document in the code view with line numbers — you can edit every line in a box, blank lines, comments and HTML included. Go back with **View as md document** | — |
| Edit | Documents · code · CSV, TSV and text (when not already editing, except in view-only projects) | Opens the whole file in the editor | **Ctrl+E** |
| View as slides · View as document | Lectern slides | Unwrap the cells and read on like an ordinary document · back to slides | — |
| Present | Lectern slides (when viewed as slides) | From the slide in view, one slide at a time in the whole window | **Shift+F5** |
| md document style | md documents you can edit (not slides) | Pick the document type and heading shape | — |
| Convert to pptx | Lectern slides (when viewed as slides) | Pick a pptx style and make a pptx file next to the document | — |
| Convert to html | Same as above | An impress.js presentation html file next to the document | — |
| Structure | Same as above | Shows cell header lines and directive and note lines as tags — click a tag and press **F2** to edit it | — |
| Check N | When slides overflow or are written wrong | A list — pick one to go to its line; **Paste the list into the terminal** · **Copy the list** | — |
| Shrunk text N | When nothing needs fixing but some slides had their text shrunk to fit | A list — pick one to go to its line | — |

## Information

| View | Information shown |
|---|---|
| md document | `Modified` time — changes every time you save (there is no alert on each save) |
| HTML document | `HTML` · modified time |
| Code · text | Language · line count · size · modified time |
| CSV · TSV | Format · rows · columns · delimiter · size · modified time |
| Excel | `Excel` · sheet name · rows · columns · size · modified time |
| Folder overview | `N documents` |

When code or a data file is not UTF-8, the encoding (CP949, the Korean Windows encoding, or UTF-16) shows too — such as a CSV saved by Excel or 'Unicode Text'.

## Lines

Line indicators show in md documents and the code view, and `vi` while vi keys are on. Hover over an indicator to see the keys you can use at that moment.

| Indicator | Meaning |
|---|---|
| `Current line 12` | The current line — each document tab keeps its own |
| `Picked lines 3-5 · 3 lines` | Lines picked with **Shift+↑·↓** and so on |
| `Current line 12 · change` | A change key (delete, move, line kind, level) was pressed once — the file is unchanged; press it again to change |
| `Focus lines 3-5 · 3 lines` | Lines made sharp with select lines (**Ctrl+Enter**) |
| `Line edit line 12` | The line with its box open |
| `vi` · `vi d…` | vi keys are on · waiting for the second letter of a two-letter command — click to open 'Edit' in the settings window |

## Changes and change watching

While AI tools (Claude Code and others) write a document, the changes appear on screen within a second, and changed paragraphs and tables are briefly marked with a background color.

| Indicator | Meaning | What it does |
|---|---|---|
| `N changes ↓` | Some of the redrawn blocks are off screen | Click to go through them — **F7** · **Shift+F7** work without the button too and move the current line there |
| Watching for changes | File changes in the folder arrive at once | — |
| Watching for changes (polling) | File notifications don't arrive, so it checks regularly | — |
| Last refresh time | When the screen was last refreshed | Reload changes the watcher missed with **F5** |

# PDF 보기

> 프로젝트의 PDF 를 문서 탭에서 본다 — 쪽을 넘기고, 찾고, 글을 골라 담고, 보던 쪽을 AI 도구에 가리킨다. 보기만 한다.

## 여는 법

| 하려는 일 | 방법 |
|---|---|
| Lectern 에서 보기 | 사이드바 **자료** 묶음의 PDF 를 한 번 누르기 (설정에서 PDF 를 '문서'로 옮겼으면 '문서'의 하위 묶음 **PDF**) · **Ctrl+P** 로 이름을 쳐서 |
| 기본 앱(Edge · Acrobat 등)으로 | 두 번 누르기 · 우클릭 **기본 앱으로 열기** · 막대의 **기본 앱으로 열기** |
| 문서의 링크에서 | `[보고서](자료/보고서.pdf)` 는 Lectern 안에서, `자료/보고서.pdf#page=12` 는 그 쪽으로 |

## 화면

| 자리 | 무엇 |
|---|---|
| 위 막대 | 쪽 칸 (적고 **Enter**) · **−** · 배율(누르면 폭 맞춤) · **+** · 알림 · **기본 앱으로 열기** |
| 본문 | 쪽을 세로로 잇는다 — 화면 가까이의 쪽만 그려 수백 쪽도 가볍다 |
| 목차 패널 | PDF 의 책갈피 (두 단계까지) — 없으면 비어 있다 |
| 상태줄 | `PDF · 12/300쪽` 과 고친 시각 |

| 하려는 일 | 키 |
|---|---|
| 넘기기 | **PageDown** · **PageUp** · **Space** · 휠 |
| 첫 쪽 · 마지막 쪽 | **Home** · **End** |
| 크게 · 작게 · 폭 맞춤 | **Ctrl+=** · **Ctrl+-** · **Ctrl+0**, **Ctrl+휠** |
| 찾기 — 모든 쪽에서 | **Ctrl+F** 다음은 **Enter**, 앞은 **Shift+Enter** |
| 보던 쪽의 위치를 터미널에 (`@자료/보고서.pdf 12쪽`) | **Shift+→** — Enter 는 누르지 않는다. 복사는 **Shift+←** |
| 고른 글 담기 · 다른 담기함에 | 글을 끌어 고르고 **Alt+C** · **Alt+Shift+C** |

폭 맞춤이면 사이드바 · 목차를 열고 닫을 때 폭을 따라간다. 밖에서 파일이 바뀌면 보던 쪽에서 다시 읽는다.

## 우클릭

| 항목 | 하는 일 |
|---|---|
| **고른 글 복사** · **고른 글 담기** · **다른 담기함에 담기…** | 글을 골랐을 때 — 담은 곳은 그 쪽 |
| **위치 복사** | `@자료/보고서.pdf 12쪽` — 옆의 **▣ 터미널** 로 터미널에 |
| **기본 앱으로 열기** | 인쇄 · 주석 · 양식 채우기는 그 앱에서 |
| **@경로 복사** · **탐색기에서 보기** · **이름 바꾸기…** | 다른 파일과 같다 |

## 담기와의 관계

| 무엇 | 어떻게 |
|---|---|
| 담은 곳 | `자료/보고서.pdf 12쪽` — 펼친 담기함의 출처 줄을 누르면 그 쪽으로 |
| 문서로 보내기 | 조각 앞에 `<!-- 담은 곳: 자료/보고서.pdf 12쪽 -->` |
| AI 도구에 맡기기 | 위치가 `@자료/보고서.pdf 12쪽 ('…')` 로 간다 |
| 원래 문서와의 대조 | PDF 는 있는지만 본다 — 지워지거나 이름이 바뀌면 알린다 |

## 되지 않는 것

| 무엇 | 까닭 · 할 일 |
|---|---|
| 고치기 · 지우기 · 형광펜 · 메모 달기 | 보기만 한다 — 기본 앱에서 |
| 사이드바 **검색**에서 PDF 의 글 찾기 | PDF 의 글은 열었을 때 **Ctrl+F** 로 — 검색은 이름이 맞는 PDF 만 보인다 |
| 스캔한 PDF 의 글 고르기 · 찾기 | 글자가 없는 그림이다 — 막대에 알린다. 기본 앱이나 OCR 로 글을 만든 뒤에 |
| 암호가 걸린 PDF | 기본 앱으로 연다 |
| PDF 안의 스크립트 · 양식 | 돌리지 않는다. 인터넷 링크는 누르면 기본 브라우저로 |

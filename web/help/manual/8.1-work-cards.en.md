# Work cards

> Make a `WORK.md` in a folder from a template, and write its front matter, to-dos and events in set line shapes. Lines that cannot be read gather under 'Lines to check'.

## Creating

| To do | How |
|---|---|
| At the top of a project | Right-click a project tab or an empty spot of the document tree, **Make work card…** |
| In a subfolder | Right-click that folder in the sidebar, **Make a work card in this folder…** — a folder without documents is not in the document tree, so right-click the folder in the 'Other files' or 'Code' list |
| If one already exists | The menu says **Open work card** |
| In a folder you have not opened | **Add folder** on the work board — if it has no WORK.md, Lectern asks whether to open it and make one |

In the window, set the kind · title (the folder name at first) · due date · priority and press **Create**: `WORK.md` is made from the template and opened. The folder joins the work folder list. Write the due date as `YYYY-MM-DD` (`2026.11.20` is read too) or pick it with the calendar button next to it or **Ctrl+;**.

| Kind | Template | Chosen by default |
|---|---|---|
| Task | Planning notes · current state · to-dos · schedule · decisions · log · materials, status 'planned' | Top of a project |
| Group · overview | The same sections, status left empty — worked out from the sub-tasks | (when you pick it) |
| Small task | Only planning notes · to-dos · schedule · log, status 'planned' — something like one issue report | Subfolders |

## Parts of WORK.md

| Part | What goes there | Read by the work board |
|---|---|---|
| Front matter | `status` (planned · active · at-risk · blocked · on-hold · done · dropped), `priority` (high · medium · low), `due` (YYYY-MM-DD), `start` (YYYY-MM-DD — the start in the Gantt chart and calendar) | Yes — status · priority · due date · start |
| `# Title` | The task name | Yes |
| To-dos | `- [ ] Draft chapter 3 (11/14)` — the parentheses at the end are the due date | Yes — checkbox and due date |
| Events | `- 2026-11-12 14:00-15:00 Report to the lead`, `- 2026-11-20 all-day Workshop` | Yes — today's events and alerts |
| Planning notes | Whatever comes to mind — to-dos and dates too | No — moved out when you tidy up |
| Current state · decisions · log · materials | Anything | No |

## Reading rules

Lectern looks only at the front matter and the shape of to-do and event lines. Section names and order are up to you.

| Written | How it is read |
|---|---|
| A due date without a year, `(11/14)` | The year nearest to today |
| Dates | `2026-11-14` is the norm. `2026.11.14` · `2026/11/14` · `2026-11-5` too |
| Korean values | `진행` (active) · `완료` (done) and the like too |
| Key names | Upper case (`Status`) · a space before the colon too |
| A `WORK.md` in a subfolder | One piece of work inside it — [Work tree](8.2-work-tree-kanban-gantt.en.md#work-tree) |

## Changing

| To change | How |
|---|---|
| Status · due date | Right-click the front matter, **Edit document info** |
| To-dos | Click the checkbox |
| Text such as the log | Line edit |
| Without opening another WORK.md | From the work tree · kanban · Gantt — [Changing from the top](8.2-work-tree-kanban-gantt.en.md#changing-from-the-top) |
| Planning notes not yet tidied up | [Planning notes](8-work-management.en.md#planning-notes) |

## Lines to check

Lines that could not be read because of a typo or something deleted are not dropped but gathered under **Lines to check** on the work board. Click one to go to that line of that WORK.md. The task's row in the work tree gets 'n lines to check', and the summary at start (the Today's work alert) mentions them too.

| What could not be read | Example |
|---|---|
| A status that is not a known value | `actve` |
| A misspelled key name | `stauts` — the right key is shown |
| A due date or to-do date that cannot be read | `(11/31)`, a missing parenthesis |
| A mistyped checkbox | `- []` · `-[ ]` |
| An event on a day that does not exist | `2026-11-31` |
| A time that cannot be read | `25:00`, `14:00-1500` — kept as an event without a time |
| An event without a description | — |
| Front matter | The closing `---` is missing |
| Start | `start:` cannot be read, or the start is after the due date |

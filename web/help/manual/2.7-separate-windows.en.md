# Separate windows

> Show documents, Lectern slides, the user guide and the example guide in their own windows outside the main window and read them side by side. With two monitors, keep the report on one and the source material on the other.

## Kinds of windows

| Window | How to open | How many | Editing | When you pick another project |
|---|---|---|---|---|
| Document window (separate window) | Right-click a document tab, **Move to new window** · **Ctrl+Shift+N**; right-click a list item or link, **Open in new window** | Several | Yes | Hides — when you come back, tabs and scroll are as they were |
| Slide window | **Open in new window** · **Move to new window** on Lectern slides | One per slide deck — if one is open, it comes to the front | Yes | Hides |
| User guide window | **F1** (also 'User guide' in Find a command and the keyboard shortcuts) | One — pressing again brings the open window to the front | View only | Stays |
| Example guide window | **Shift+F1** · Open samples · example links in the guide | One — other examples open as new document tabs in it | View only | Stays |

You can open up to 8 windows in all. Any window closes with the project tab it was opened from, and closing the main window closes them all. They do not reopen on the next start.

## Document windows

| To do | How | Result |
|---|---|---|
| Move the current document | Right-click a document tab, **Move to new window** · **Ctrl+Shift+N** | The tab leaves the original window and opens at the same position in a separate window |
| Open and keep the tab | Right-click a document in the sidebar or a link in the text, **Open in new window** | The current tab stays |
| Send to the main window | Right-click a document tab in a separate window, **Send to main window** | About a second later it opens at the same position in a new document tab of the receiving window, and that window comes to the front |
| Send to another separate window | Right-click a document tab in any window, **Send to window: (document name)** | Same as above |
| Open more documents | **Ctrl+T** · **Ctrl+P** — the sidebar is hidden; show it with **Ctrl+B** | Keep several document tabs |
| Close the window | Close the last document tab with **Ctrl+W** · send the last document to another window | The window closes |

**Close all open documents** in the main window leaves the documents in separate windows alone.

## Only in the main window

Project tabs, the terminal, notes, settings and the style list are in the main window. What you send to the terminal or notes from a separate window goes to the main window.

| From a separate window | Goes to | Note |
|---|---|---|
| **Send to Claude** · Terminal buttons · **Send to new note** | The main window's terminal · notes | Enter is not pressed, and the main window comes to the front |
| **Shift+→** | The first terminal in the main window | Puts it in while you stay in the separate window |
| **Shift+number** · number+click in a menu | The main window's terminal with that number | — |
| **F6** | Moves only between the document and the sidebar | Separate windows have no terminal |
| Display changes such as text size | Only in that window — not saved | Settings changed in the main window or the settings file follow within 1–2 seconds (what you changed only in that window stays until another window changes that setting) |

## Slide windows

| What | Behavior |
|---|---|
| How to open | Right-click Lectern slides in the list on the left, **Open in new window** · on their open document tab, **Move to new window** (**Ctrl+Shift+N**) |
| If one is already open | That window comes to the front |
| Style | Chosen separately from the main window — the **Presentation** style by default. In the main window's document pane, slides use the main window's style |
| pptx style | Doesn't change when you change the screen style |
| Terminal | Uses the main window's |

## User guide and example guide windows

These are viewing windows you keep beside you while you follow along. So they stay visible when you pick another project tab.

| | User guide window | Example guide window |
|---|---|---|
| What it shows | This guide | Documents of the sample project |
| Opening again | The open window comes to the front | A new document tab in that window |
| Main window | Unchanged | Stays on the project you were viewing — the samples tab opens in the background |
| Editing | Not possible | Not possible — to try changes, copy the samples folder elsewhere and open the copy |
| Showing and hiding the left side | **Ctrl+B** — the guide's contents (hide them with **▯** in the header; when hidden, the button at the top left of the text shows them again). The same when the guide covers the main window | **Ctrl+B** — the sidebar |
| Closing | **F1** · **Esc** · **✕** | **✕** · **Ctrl+W** on the last document tab |
| Example links in the window | Handed to the main window — they open in the example guide window | — |
| If the window can't open | Covers the main window instead (also when no project is open) | Opens as a samples tab in the main window |

When the guide covers the main window, right-click the **User guide** header at the top left or a document in its contents and choose **Open in new window** (**Ctrl+Shift+N**) to open the window from there. Windows belong to a project, so open a folder first.

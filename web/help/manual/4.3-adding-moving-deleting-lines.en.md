# Adding, moving and deleting lines

> Add, split and join, move, delete and duplicate lines. Each change is saved the moment you press, and one Ctrl+Z brings it back.

## At a glance

| To | Reading view (current line · picked lines) | In a cell |
|---|---|---|
| New line below | **Shift+Enter** | **Shift+Enter** |
| New line above | **Ctrl+Shift+Enter** | **Ctrl+Shift+Enter** |
| Split into two lines | — | **Shift+Enter** in the middle of the text |
| Join to the end of the line above | — | **Backspace** at the start of the line |
| Move up · down | **Alt+↑** · **Alt+↓** | **Alt+↑** · **Alt+↓** |
| Delete | **Delete** · right-click **Delete lines** | **Ctrl+Shift+K** |
| Copy the source and delete | **Ctrl+X** | — |
| Duplicate | — | **Ctrl+Shift+D** |
| List level in · out | **Tab** · **Shift+Tab** (picked lines) | **Tab** · **Shift+Tab** |

If the cell has edited text, it is saved first and then changed — so undoing takes two steps. If something cannot be done, nothing changes and you are told why.

## Two presses on the current line

Keys that change the file take one press when several lines are picked, and two presses on the current line alone. This keeps a key pressed while reading from changing the file.

| Situation | What happens |
|---|---|
| While several lines are picked (focus included) · in a cell | Changes at once |
| Text you dragged to select across several lines | Delete and move act on every line the text touches, at once — a line the text only partly covers goes whole |
| First press on the current line | A band appears on the line and the status bar shows `Current line 12 · change` — the file is untouched |
| One more press | Changes it |
| While the band is there | Further keys (**Alt+↑** again, **Tab**) act at once |
| **↑** · **↓** · **Esc** · a click elsewhere | Cancel |
| Holding a key down | Counts as one press |

The keys that follow this rule are delete (**Delete** · **Ctrl+X**), move (**Alt+↑** · **Alt+↓**), line kind (one-letter keys · **Ctrl+Alt+number**) and level (**Alt+Shift+←** · **Alt+Shift+→**). The notice at the bottom of the screen appears only the first time after Lectern starts. Keys that do not change the file — copy, copy location, send to the terminal — act at once.

## New lines

**Shift+Enter** is the same in the reading view and in a cell, in the middle of a document and at its end. **↓** only moves the current line; it stops on the last line and then tells you the key that adds a line. In an empty document, **F2** or **↓** opens the first line. Nothing is added while several lines are picked.

A new line takes after the line before it.

| Where | Form of the new line |
|---|---|
| Below a list | The same marker — after any sub-items |
| Below a bullet-mark list | The same mark is already in the box — after any sub-items. **Tab** · **Shift+Tab** switch `□` → `○` → `-` → `·`. Leaving only the mark adds nothing |
| Below a numbered list | The next number |
| Below a quote · callout | Inside it |
| Below a paragraph · heading | Paragraph |
| Table | New row |
| Chart · math | A paragraph before or after it |
| Above a paragraph · heading with a list · quote · callout right above it | Continues the block above, at its end — for a paragraph, press **Shift+Tab** in the new line |
| Above a list item · quote line | The same form as that line — above the first item, a new first item |
| List · numbered list · to-do from the Insert window on an empty new line | Joins a list of the same kind right above or below (the next number under a numbered list) |
| Last line of the body in a document with footnotes | Before the footnotes |
| Paragraph after a table · code block | **/** on that block — the Insert window opens after the block (Shift+Enter in that block adds a row · a code line) |

A new line goes into the file when you write in it. **Enter** · **Ctrl+Enter** on an empty new line close it without adding anything.

## Ending a list

| On an empty new item | What happens |
|---|---|
| **↓** · **Shift+Tab** | Out one level — at the outermost level it becomes a paragraph and the list ends |
| **Tab** | Under the item above |
| **↓** on an empty new line in a callout | Out of the callout |

## Splitting and joining

| To | Keys | Conditions |
|---|---|---|
| Split into two lines | **Shift+Enter** in the middle of the text | Splits right there. In a bullet-mark list the second half becomes an item with the same mark |
| Join to the end of the line above | **Backspace** at the start of the line | Paragraphs with paragraphs, lists with lists, code only within its block. Lines of different kinds, such as a heading and a paragraph, are not joined. In a bullet-mark list, onto the item above in the same list — this line's mark is dropped |

## Moving

| What moves | How far |
|---|---|
| List item | With its sub-items, within the same list |
| Bullet-mark list item | With its deeper items, past the item of the same level before or after — within the list |
| Paragraph | Swaps with the block before or after |
| One line of a paragraph written over several lines | Within that paragraph |
| Code | Within its block |
| Table row | Below the header row |
| One heading line | Swaps with the section of the same level before or after, body included |
| Footnotes | The body and the footnotes at the end of the document never cross — moving the last section leaves the footnotes in place |

The picked lines follow after a move, so you can keep moving them.

## Deleting and duplicating

| Situation | What happens |
|---|---|
| More than 10 lines, or a heading included | Asks first |
| Blank lines doubled after deleting | Reduced to one |
| Sub-items of a deleted item | Keep their level under the item before — for the first item of a list they move up to its place |
| A deleted item's second paragraph or continued line | Its first line takes over the item's marker (number, task box) — the items below stay as they are |
| The first line of a callout | The header line (`> [!NOTE]`) stays — it is still a callout |
| An item of a bullet-mark list | That line only — lines starting with `-` · `2.` are not tidied like a Markdown list |
| A paragraph between two lists | The two lists become one — a tight list if both were tight, numbered on |
| Only a table's header row · divider row | Blocked — picking the whole table deletes the table |
| Part of a code block together with lines outside it | Blocked — picking every code line (with lines around it or not) deletes the block |
| Right-click a heading **Delete section** | With its body and subsections — the footnotes at the end of the document stay |
| **Ctrl+Shift+D** in a cell | Makes the same line below and goes on editing it — table rows are not duplicated |
| In the full editor | **Ctrl+Shift+D** duplicate · **Ctrl+Shift+K** delete line — the same keys |

## Numbered lists

| Situation | What happens |
|---|---|
| Adding · moving · deleting items | Renumbers the following items |
| A list written with `1.` throughout | Left as it is |
| **Ctrl+Z** | The numbers come back too, in one step |

Line structure also works in the code view and in Lectern slides. It is not available in HTML documents, data files (CSV · text · Excel) and view-only projects — CSV and text are edited in edit mode.

# Shortcuts

> Ways to find a shortcut, and every shortcut in Lectern — the tables below are made from the same list as the shortcut table (Ctrl+/).

## Ways to find

| To do this | How | Result |
|---|---|---|
| See the keys quickly | **Ctrl+/** · **?** in the toolbar | The shortcut table — eight tabs, opening each time on the first tab, **Most used** |
| Switch tabs in the shortcut table | Click a tab · **Ctrl+Tab** | The next tab |
| Find by action or key | In the search box at the top of the shortcut table, type something like `table` or `Ctrl+K` | Only the matching rows, from every tab |
| Find by name and do it at once | **Ctrl+Shift+P** (Find a command) · `>` in the **Ctrl+P** box | Matching commands with their shortcuts on the right — press **Enter** to run one |
| Actions without a key | Find a command | Print & PDF, Spread all, Close all open documents, View settings source and more |
| Find in this document | **Ctrl+F** | In the tables below |

## Tabs of the shortcut table

| Tab | What it holds |
|---|---|
| Most used | The twenty to learn first — a Read and pick column and a Write and edit column |
| Open and view | Open & find, Project tabs, Document tabs, View, Find bar, Sidebar, Help & settings |
| Pick and copy | Current line, picking and copying; formatting selected text |
| Write and change | New lines, inserting, changing, moving, deleting and undoing in md documents |
| Line edit | Keys inside a cell (**F2**) |
| Terminal | The terminal, sending to the terminal |
| Editor and slides | Full editor, Lectern slides and presenting |
| vi keys | When you turn them on under 'Edit' in Settings |

## Where keys work

| Where | What happens |
|---|---|
| Inside the terminal | Keys go to the shell. Use app keys (**Ctrl+P** · **Ctrl+F** · **F1**) after clicking the main area. **Ctrl+Tab** moves to the next tab even inside the terminal |
| Inside a line edit cell | App keys such as **F1** · **Ctrl+/** · **Ctrl+W** · **Ctrl+Tab** · **Alt+1~9** · **Ctrl+P** work — the cell is saved and closed, then the action runs |
| Korean/English key | One-letter line kind keys (**1~6** · **L** · **N** · **T** · **Q** · **C**) and vi keys work without switching the Korean/English input mode |
| A single current line | Change keys (delete · move · line kind · level) take two presses — the first only marks the line |
| ` / ` in the tables | Keys and actions pair up in the same order — **Ctrl+Tab** / **Ctrl+Shift+Tab** are next / previous |

# Lectern 내 도해 스타일·내 색 조합 — AI 용 안내

사람이 Lectern 에서 그림을 우클릭해 **'이 모양으로 내 도해 스타일 만들기…'**(차트는 **'이 색으로 내 색 조합 만들기…'**)를 고르면, 그 그림의 자리(`@경로 3~9행`)와 번호, 저장할 폴더를 담은 요청이 온다. 그 그림의 모양을 Lectern 이 아는 값으로 옮겨 **파일 하나**를 쓴다. Lectern 은 그 폴더를 읽기만 하고, 3초 안에 고르기 창·설정 창에 그 번호로 보인다. 번호와 이름 쓰는 법은 같은 폴더의 `diagrams.md`.

## 1. 차례

1. 요청의 그림 블록을 읽는다. 모양을 정하는 것을 찾는다 — `classDef`·`style` 줄의 `fill`·`stroke`·`stroke-width`·`stroke-dasharray`·`rx`, `%%{init: …}%%` 의 `curve`·`nodeSpacing`, `linkStyle` 의 굵기, 상자 글의 줄바꿈(제목과 내용), 묶음(`subgraph`). 표시 줄(`%% 스타일: 8 …`)이 있으면 그 번호가 바탕이다.
2. 기본 번호 1~10 가운데 가장 가까운 것을 `base` 로 고르고, 다른 것만 값으로 적는다 (아래 2). 같은 값은 적지 않는다.
3. 저장하기 전에 이름과 값을 표로 보이고 묻는다 — 무엇이 그대로 옮겨지고 무엇이 옮겨지지 않는지(색·글꼴·화살표 모양 등) 한 줄로 함께.
4. 허락하면 요청의 폴더에 `이름.json` 하나를 쓴다. 폴더가 없으면 만든다. 같은 이름의 파일이 있으면 덮어쓰지 않고 묻는다. 번호는 요청의 번호를 쓴다 (다른 파일이 쓰는 번호는 쓰지 않는다 — 폴더의 다른 파일을 먼저 본다).
5. 쓴 뒤 사람에게 알린다: 고르기 창·설정 창에 그 번호로 나온다, 그림에 쓰려면 블록에 `%% 스타일: 11 우리 회사` 한 줄. 사람이 원하면 그 그림의 블록을 그 줄로 바꾸고 이제 필요 없는 `classDef`·`style` 줄을 뺀다 — 묻기 전에는 문서를 고치지 않는다.

## 2. 모양 파일

```json
{
  "kind": "style",
  "number": 11,
  "name": "우리 회사",
  "tip": "남색 제목 띠, 직각 선 — 주간 보고",
  "base": 8,
  "corner": 4,
  "line": "step",
  "bold": true
}
```

| 열쇠 | 값 | 뜻 |
|---|---|---|
| `kind` | `"style"` | 모양 파일 (꼭) |
| `number` | 11~99 정수 | 번호 (꼭 — 요청의 번호) |
| `name` | 24자까지 | 이름 (꼭). 숫자로 시작하지 않고 `·` `,` `;` `:` 를 쓰지 않는다. 기본 이름(카드·제목 띠 등)과 같은 이름은 쓰지 않는다 |
| `tip` | 80자까지 | 고르기 창의 설명 한 줄 — 무엇이 다르고 언제 쓰는지 |
| `base` | 1~10 | 바탕 번호 (없으면 1). 아래 값이 없으면 그 번호의 것 그대로 |
| `corner` | 0~24 | 상자 모서리 둥글기 (px). Graphviz 는 0 이면 네모, 아니면 둥근 네모 |
| `border` | 0~4 | 상자 테두리 굵기 (px) |
| `line` | `"curve"`·`"step"`·`"straight"` | 선 모양 — 곡선·직각으로 꺾기·곧은 선 |
| `line_width` | 0.5~4 | 선 굵기 (px) |
| `dash` | `true`·`false` | 선을 점선으로 |
| `shadow` | `true`·`false` | 상자 그림자 |
| `fill` | `"none"`·`"light"`·`"solid"` | 상자 채움 — 바탕색·옅게·진하게(밝은 글자) |
| `spacing` | `"tight"`·`"normal"`·`"wide"` | 상자 사이 간격 |
| `bold` | `true`·`false` | 상자 글자 굵게 |
| `title` | `"none"`·`"band"`·`"tint"`·`"rule"` | 제목 상자 — 없음·진한 띠·옅은 띠·제목 아래 줄. 줄을 바꾼 상자의 첫 줄이 제목 |
| `zones` | `true`·`false` | 묶음마다 옅은 색을 돌려 쓰기 |
| `sketch` | `true`·`false` | 손그림 선 (Mermaid 만) |

- 색은 모양 파일에 적지 않는다. 상자·강조·띠의 색은 문서 스타일과 색 조합 번호가 정한다 — 색까지 옮기려면 아래 3 의 색 조합 파일을 함께 만든다 (사람에게 묻고).
- 강조 표시 `:::key`(핵심)·`:::warn`(주의)·`:::muted`(보조)의 칠은 바탕 번호를 따른다 (`fill: "solid"` 이면 4 진한 채움의 것, 제목 상자면 띠 색).
- Mermaid 는 classic 모양 위에 그린다 (`sketch` 면 손그림). 1 기본의 둥근 neo 모양은 아니다.

## 3. 색 조합 파일

```json
{
  "kind": "colors",
  "number": 9,
  "name": "회사 색",
  "tip": "회사 로고의 남색과 주황",
  "series": ["#17304f", "#2f5d8a", "#5b8db8", "#c2410c", "#6b7280"],
  "strong": "#17304f",
  "accent": "#c2410c"
}
```

| 열쇠 | 값 | 뜻 |
|---|---|---|
| `kind` | `"colors"` | 색 조합 파일 (꼭) |
| `number` | 9~99 정수 | 번호 (꼭) |
| `name`·`tip` | 위와 같다 | |
| `series` | `"#rrggbb"` 2~12개 | 차트의 계열 색 (차례대로). 꼭 |
| `strong` | `"#rrggbb"` | 도해의 기본 상자 색 (없으면 series 의 첫 색) |
| `accent` | `"#rrggbb"` | 핵심(`key`) 강조색 (없으면 series 의 둘째 색) |
| `zones` | `"#rrggbb"` 1~12개 | 단계 색(묶음마다)의 색 (없으면 series) |

- 그림이 `classDef`·`style` 로 정한 색, 차트가 `"scale": {"range": …}`·ECharts `color` 로 정한 색을 차례대로 옮긴다. 어두운 문서 스타일에서는 Lectern 이 진한 색을 밝게 바꿔 그린다.
- 글자와 바탕이 잘 구분되도록, 계열 색끼리는 서로 잘 갈리도록 고른다.

## 4. 하지 않을 것

- 위 표에 없는 열쇠(CSS, Mermaid 설정, 글꼴, 그림 주소)를 적지 않는다 — Lectern 은 모르는 열쇠를 빼고 설정 창에 '고칠 것'으로 보인다.
- 숫자를 범위 밖으로, 색을 `#rrggbb` 가 아닌 것(`red`, `rgb(…)`)으로 적지 않는다 — 그 값은 빠진다.
- 한 파일에 둘 이상을 적지 않는다 (파일 하나가 스타일 하나). 기본 번호(모양 1~10, 색 1~8)를 쓰지 않는다.
- 사람의 다른 파일(다른 스타일, Lectern 설정 `config.json`)을 고치지 않는다.

## 5. 쓰는 법 (사람에게 알릴 것)

- 그림 하나: 블록에 `%% 스타일: 11 우리 회사` (Graphviz·차트는 `//`), 색은 `%% 색: 9 회사 색`. 우클릭 '도해 스타일…' 창에도 11번 칸이 나온다.
- 문서 하나: `<!-- 도해: 스타일 11 우리 회사 · 색 9 회사 색 -->`. 표시 줄이 없는 그림 모두: 설정 창 '도해 스타일 · 색 조합'의 '내 것'.
- 그 파일이 없는 PC(동료에게 보낸 문서 등)에서는 그 번호를 모르므로 기본 모양·색으로 그린다 — 파일을 함께 건네면 같은 모양이 된다.

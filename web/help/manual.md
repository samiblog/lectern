# Lectern 사용설명서

Lectern(렉턴, 독서대)은 Markdown 문서를 중심으로 사람과 AI가 함께 리서치하는 작업 환경입니다. Claude Code나 Claude가 프로젝트 폴더에 만든 문서와 자료를 사람이 읽고 살피고 그 자리에서 고칩니다. Markdown(`.md`)·HTML(`.html`) 문서를 읽기 좋게 보여 주고, 코드는 읽기 화면으로 보여 줍니다.

- **파일은 고를 때만 바꿉니다.** 앱이 스스로 문서를 만들거나 고치거나 지우지 않습니다. 디스크에 쓰는 것은 설정 폴더(설정 파일·제목 기억)와, 사용자가 고른 일로 바뀌거나 생기는 파일뿐입니다 (아래 '알아 둘 점'). 오른쪽 터미널에서 직접 친 명령도 예외입니다.
- **스스로 인터넷에 연결하지 않습니다.** 문서 속 인터넷 그림만 불러오고, 이것도 설정 창에서 끌 수 있습니다.
- **고른 폴더 안만 봅니다.** 숨김 파일·폴더(`.git`, `.claude` 등)는 보이지 않습니다. `node_modules`·`dist` 같은 제외 폴더는 문서 트리와 검색에 나오지 않고, '자료' 목록에만 흐리게 나옵니다.

> [!TIP]
> 이 설명서는 F1 로 열고 닫습니다 (Esc 로도 닫힘). 왼쪽 차례를 누르면 그 장으로 가고, Ctrl+F 로 설명서 안에서 찾습니다. 단축키만 빨리 보려면 툴바의 **?** 버튼이나 Ctrl+/ 를 누르세요.
>
> 설명서를 옆에 띄워 두고 문서를 보려면 왼쪽 위 **사용설명서** 머리줄을 우클릭해 **새 창에서 열기**를 고릅니다 (설명서를 보는 중의 **Ctrl+Shift+N**, 명령 찾기의 **사용설명서를 새 창에서 열기**도). 차례의 장을 우클릭하면 그 장에서 엽니다. 이 창은 문서의 새 창처럼 지금 프로젝트에 속해, 다른 프로젝트 탭을 고르면 숨고 돌아오면 다시 보입니다. 그 창에서 F1·Esc·✕ 는 창을 닫고, 예제 링크는 메인 창이 예제 탭에서 엽니다.

## 시작하기

처음이면 **Shift+F1** 로 예제 프로젝트를 열어 사용법을 차례대로 따라 해 봅니다 — [예제의 첫 문서](../../samples/README.md). 이 설명서의 장마다 맞는 예제가 '예제 —' 로 이어져 있고, 누르면 예제 탭에서 그 문서가 열립니다.

### 폴더 열기

- 탭 막대의 **+** 버튼(Ctrl+O)을 누르고 프로젝트 폴더를 고르면 새 탭으로 열립니다. 이미 열린 폴더면 그 탭으로 갑니다.
- **+** 옆 화살표에는 최근 연 폴더와 **예제 열기**가 있습니다.
- **예제 열기**(시작 화면에도 있음)는 Lectern 둘러보기와 문서 쓰는 법을 담은 예제 프로젝트를 엽니다. Claude Code 와 함께 하는 리서치 프로젝트처럼 꾸며져 있어 트리·코드·자료·차트를 바로 시험해 볼 수 있습니다. 예제는 Lectern 프로그램 폴더 안에 있어 **보기만** 합니다 — 그 탭에서는 터미널·편집 모드·새 문서·이름 바꾸기가 없습니다 (프로그램 파일 옆에서 명령이 돌거나 파일이 바뀌지 않게). 예제로 편집이나 Claude Code 를 써 보려면 예제 폴더를 다른 곳(문서 폴더 등)에 복사해 그 복사본을 엽니다 — 터미널 자리의 '탐색기에서 이 폴더 보기'로 폴더를 찾을 수 있습니다.
- 탐색기에서 폴더를 우클릭해 **Lectern으로 열기**를 골라도 됩니다. Lectern 이 이미 떠 있으면 새 창 대신 그 창에 탭으로 열립니다.
- Lectern 을 다시 실행하면 지난번에 열어 둔 탭들이 보던 문서·위치 그대로 열립니다.

### 화면 구성

예제 — [01 처음 둘러보기](../../samples/guide/01-처음-둘러보기.md): 화면 구성, 트리와 폴더 개요, 문서 열기, 뒤로 가기.

| 자리 | 하는 일 |
|---|---|
| 툴바 (맨 위) | 사이드바·뒤로·앞으로, **문서 열기**(Ctrl+P), 글자 크기 − 100% +, 문서 폭, **줄 번호**, 스타일, 하이라이트, 설정, **?**(단축키), **업무**(Alt+W), 터미널 모음 |
| 탭 막대 | 열린 프로젝트마다 탭 하나, 폴더 열기(+), 오른쪽 끝에 **편집**·**목차**·**인쇄**·**메모**·**터미널** 버튼 |
| 문서 탭 줄 | 본문 바로 위 — 이 프로젝트에서 열어 둔 문서들 (40개까지), 새 탭에 문서 열기(+), 오른쪽 끝에 열린 문서 탭 목록(∨)과 모두 펼치기(▦) |
| 사이드바 (왼쪽) | **파일**·**최근 변경**·**검색**·**모아 보기**·**담기** 탭. 경계를 끌어 폭을 바꿈 (두 번 누르면 기본 폭) |
| 본문 (가운데) | 문서, 폴더 개요, 코드 읽기 화면 |
| 목차 (오른쪽) | 지금 문서의 제목과 표·그림 같은 구성 요소. 터미널을 열면 그 자리에 터미널 |
| 상태줄 (맨 아래) | 문서 경로와 수정 시각, '바뀐 곳' 버튼, 변경 감시 상태 |

## 프로젝트 탭

- 폴더마다 탭이 하나씩 생깁니다 (10개까지). 탭을 누르면 사이드바와 본문이 그 프로젝트의 것으로 바뀌고, 탭마다 보던 문서와 스크롤 위치가 그대로 남습니다.
- 이미 고른 탭을 또 누르면 그 프로젝트의 개요가 나옵니다. 탭을 우클릭하면 프로젝트 개요, 맨 위 폴더에 새 문서, 프로젝트의 모아 보기도 있습니다.
- 뒤에 있는 탭의 문서가 바뀌면 탭 이름 옆에 점이 붙습니다.
- 이름이 같은 폴더는 상위 폴더 이름이 함께 보입니다.
- 닫기: 탭의 ×, 마우스 가운데 버튼, Ctrl+Shift+W. 탭을 우클릭하면 다른 탭 모두 닫기·전체 경로 복사·탐색기에서 보기도 있습니다. 프로젝트는 그대로 두고 그 안에 열린 문서만 정리하려면 탭을 우클릭해 **열린 문서 모두 닫기**를 고릅니다 (아래 '문서 탭').
- 옮겨 다니기: Ctrl+1~8(그 순번의 탭), Ctrl+9(마지막 탭), Alt+PageDown / Alt+PageUp(다음 / 이전 탭).
- **차례 바꾸기**: 탭을 옆으로 끌어 놓으면 그 자리로 옮겨집니다. 끄는 동안 놓일 자리에 세로 막대가 보이고, Esc 를 누르면 그만둡니다. 옮긴 차례는 다음 실행에도 남고 Ctrl+1~9 도 그 차례를 따릅니다. 마우스로만 옮깁니다 — 단축키는 없습니다.

## 문서 탭

한 프로젝트에서 문서를 40개까지 탭으로 열어 두고 오갑니다. 본문 바로 위의 문서 탭 줄에 보입니다.

- 사이드바의 문서를 **누르면 새 문서 탭**에서 열리고 보던 문서는 그대로 남습니다 — 트리·'코드'·'자료'·'폴더' 목록·최근 변경·검색 결과·모아 보기·문서 열기(Ctrl+P)가 같습니다. 지금 탭이 폴더 개요면 그 자리에서 엽니다.
- **Ctrl+누르기**·**마우스 가운데 버튼**은 보던 문서를 두고 뒤에서 새 문서 탭을 엽니다 (브라우저처럼 — 탭은 누를 때 그립니다). **Alt+누르기**는 지금 탭에서 엽니다. 빠른 열기는 Enter·Ctrl+Enter·Alt+Enter 가 같습니다.
- 본문의 링크·경로 표기는 지금 탭에서 열립니다 (Alt+← 로 돌아옵니다). Ctrl+누르기·가운데 버튼·우클릭 **새 문서 탭에서 열기**로 새 문서 탭에 열 수 있습니다.
- 이미 다른 탭에 열려 있는 문서를 누르면 그 탭으로 갑니다 (같은 문서를 두 번 열지 않습니다).
- 40개가 차 있으면 가장 오래 안 본 탭에서 엽니다 (저장하지 않은 편집이 있는 탭은 건드리지 않습니다).
- **뒤로·앞으로**(Alt+←·→, 마우스의 뒤로·앞으로 버튼)는 다른 문서로 간 것뿐 아니라 같은 문서 안에서 뛴 것도 되돌립니다 — 목차, 절 링크, 각주, 찾기, 모아 보기·검색 결과로 간 뒤 누르면 읽던 자리(스크롤과 현재 위치)로 돌아오고, 그 자리가 접힌 절 안이면 펴 줍니다. 찾기는 결과를 몇 번 옮겨 다녀도 한 번이면 찾기 전 자리입니다. 스크롤이나 ↑·↓ 로 옮긴 것은 남지 않습니다.
- 탭마다 읽던 위치, 뒤로·앞으로 기록, 편집 모드에서 고치던 내용이 따로 남습니다. 저장하지 않은 편집이 있는 탭에는 **●** 가 붙습니다. 그래서 한 탭에서 문서를 고치면서 다른 탭에서 자료를 읽을 수 있고, 사이드바 '담기'의 보내기도 받는 문서를 그 문서의 탭에서 엽니다.
- 고르기: 탭을 누르거나 **Alt+1~8**(그 순번), **Alt+9**(마지막 탭). 탭이 많아 줄에 다 보이지 않으면 휠로 줄을 옆으로 넘기거나, 줄 오른쪽 끝의 **∨**(옆의 숫자는 열린 문서 탭 수)를 눌러 열린 문서 탭 목록에서 고릅니다. **Ctrl+Tab**·**Ctrl+Shift+Tab**(Ctrl+PageDown·PageUp 도)은 다음·이전 문서 탭입니다. 닫기: 탭의 ×, 마우스 가운데 버튼, **Ctrl+W**(Ctrl+F4 도 — 탭이 하나뿐이면 닫지 않습니다), **Ctrl+Shift+T** 는 닫은 문서 탭을 다시 엽니다. **Ctrl+T** 는 새 문서 탭에 문서를 엽니다. 탭을 우클릭하면 다른 문서 탭 모두 닫기와 경로 복사가 있습니다.
- **차례 바꾸기**: 문서 탭을 줄 안에서 옆으로 끌어 놓습니다 (프로젝트 탭과 같습니다 — 놓일 자리에 세로 막대, Esc 로 그만두기). 줄이 넘치면 줄 끝으로 끌 때 줄이 넘어갑니다. 고른 탭은 그대로이고, Alt+1~9 와 다음 실행에 되살리는 차례도 옮긴 차례를 따릅니다.
- **열린 문서 모두 닫기**: 문서 탭이나 프로젝트 탭을 우클릭(또는 문서 탭 줄의 **∨**)해 고르면 그 프로젝트의 문서 탭이 모두 닫히고 폴더 개요만 남습니다. 저장하지 않은 편집이 있으면 한 번 묻고, 그만두면 아무것도 닫지 않습니다. 닫은 문서는 **Ctrl+Shift+T** 로 하나씩 다시 엽니다. 독립창의 문서는 그대로입니다 (독립창은 창을 닫습니다).
- 문서 탭을 모두 닫으면 폴더 개요가 나옵니다 — 프로젝트를 처음 열었을 때의 화면입니다. 하나 남은 문서 탭도 **×**·**Ctrl+W**·가운데 버튼으로 닫습니다. 폴더 개요만 남았을 때 프로젝트를 닫으려면 **Ctrl+Shift+W** 를 누릅니다.
- 다음에 Lectern 을 열면 열어 두었던 문서 탭들이 그대로 돌아옵니다 (설정 '마지막 위치에서 시작'이 켜져 있을 때 — 고른 탭만 바로 그리고 나머지는 누를 때 그립니다). 문서 탭을 모두 닫아 폴더 개요만 남겼으면 다음에도 폴더 개요로 엽니다.

### 모두 펼치기

문서 탭 줄 오른쪽 끝, ∨ 옆의 **▦** 를 누르면 이 프로젝트의 문서 탭들을 창 전체에 격자로 펼칩니다 — 터미널 모음처럼. 다시 누르면 원래 화면으로 돌아옵니다.

- 칸 하나에 문서 탭 하나 (탭 차례대로), **오른쪽 아래 칸은 이 프로젝트의 터미널**입니다 — Claude Code 에 일을 맡기면서 여러 문서가 바뀌는 것을 한눈에 봅니다. 터미널이 닫혀 있었으면 열고(셸이 없으면 시작), 끝낼 때 다시 감춥니다 (셸은 그대로 돕니다).
- 칸 수가 격자에 맞지 않으면 옆이나 위의 문서 칸이 넓어져 빈 자리를 채웁니다. 사이드바와 목차는 감춥니다.
- 칸을 누르면 그 문서 탭이 골라집니다 (테두리 강조) — 상태줄·문서에서 찾기(Ctrl+F)·우클릭 메뉴·Alt+1~9 는 고른 칸의 것입니다. 바뀐 문서는 어느 칸이든 바로 다시 그립니다.
- 칸 머리의 **⤢**(또는 머리를 두 번 누르기)는 그 문서만 보도록 펼치기를 끝냅니다. 사이드바·목차 버튼(Ctrl+B)을 눌러도 끝나고 그것이 보입니다.
- 펼친 채 다른 프로젝트 탭을 고르면 그 프로젝트의 문서 탭들이 펼쳐집니다. 보기만 하는 프로젝트(예제)에는 터미널 칸이 없습니다.

### 독립창

문서를 별도 창으로 옮겨 나란히 볼 수 있습니다. 모니터가 둘이면 한쪽에 보고서, 다른 쪽에 자료를 두기 좋습니다.

- 옮기기: 문서 탭을 우클릭해 **새 창으로 옮기기**, 또는 **Ctrl+Shift+N**. 원래 창의 탭은 사라지고 독립창에 같은 위치로 열립니다.
- 탭은 두고 열기: 사이드바의 문서나 본문의 링크를 우클릭해 **새 창에서 열기**.
- 창 사이로 보내기: 독립창의 문서 탭을 우클릭해 **메인 창으로 보내기**. 다른 독립창이 떠 있으면 어느 창에서든 **(문서 이름) 창으로 보내기**가 나옵니다. 1초쯤 뒤에 받는 창의 새 문서 탭에 같은 위치로 열리고 그 창이 앞으로 나옵니다.
- 독립창의 마지막 문서를 보내면 그 창은 닫힙니다.
- 독립창에도 문서 탭을 여럿 둘 수 있습니다. 사이드바는 감춰져 있고 **Ctrl+B** 로 꺼냅니다. **Ctrl+T**·**Ctrl+P** 로도 문서를 엽니다.
- 독립창은 그 프로젝트에 속합니다. 메인 창에서 다른 프로젝트를 고르면 숨고, 돌아오면 탭과 스크롤 그대로 다시 보입니다. 프로젝트 탭을 닫으면 함께 닫힙니다.
- 독립창에서 **Claude 로 보내기**·**터미널** 버튼·**새 메모로 보내기**를 고르면 메인 창의 터미널·메모로 갑니다. Enter 는 누르지 않고, 메인 창이 앞으로 나옵니다. **Shift+→** 는 독립창에 머문 채 넣습니다. **Shift+숫자**와 메뉴의 숫자+누르기(아래 '터미널')도 메인 창의 그 번호 터미널로 갑니다.
- 프로젝트 탭·터미널·메모·설정·스타일은 메인 창에 있습니다. 메인 창에서 바꾼 스타일은 독립창을 다시 열 때 따릅니다.
- 글자 크기 같은 화면 조정은 그 창에서만 쓰이고 저장되지 않습니다.
- **Ctrl+W** 로 마지막 문서 탭을 닫으면 창이 닫힙니다. 메인 창을 닫으면 모두 닫힙니다. 독립창은 다음 실행에 다시 열리지 않습니다.
- 창은 8개까지 띄울 수 있습니다.

## 사이드바

### 파일 — 문서·코드·자료·폴더

'파일' 탭은 네 묶음으로 나뉩니다. 위의 셋은 파일을 종류로 나눈 것이고, 맨 아래 **폴더**는 모두를 실제 폴더 구조 그대로 한 트리에 보입니다.

| 묶음 | 들어가는 것 | 누르면 |
|---|---|---|
| 문서 | Markdown·HTML 문서 (폴더 트리) | 한 번 눌러 본문에 열기 |
| 코드 | 소스(py·js·ts 등)·스크립트(ps1·bat·EViews 의 prg)·웹(css)·설정(json·yaml·toml) | 한 번 누르면 코드 읽기 화면, 두 번 누르면 편집기 |
| 자료 | 문서도 코드도 아닌 파일 — PDF·오피스·그림·데이터·압축·실행 파일 등 | 두 번 눌러 기본 앱으로 (실행·압축 파일은 실행하지 않고 탐색기에서 선택만) |
| 폴더 | 문서·코드·자료를 나누지 않고 폴더 구조 그대로 | 문서는 한 번 눌러 열기, 코드·자료는 위와 같음, 폴더 개요는 폴더를 우클릭 |

- **한 번에 한 묶음만 펼칩니다.** 머리줄('문서 10', '코드 3', '자료 4', '폴더')을 누르면 그 묶음이 펼쳐지고 나머지는 머리줄만 남습니다. 펼친 묶음이 남은 높이를 모두 씁니다. 접힌 머리줄에도 개수가 보이고, 거르기 칸에 글을 치면 그 묶음에서 맞는 수가 보입니다 ('폴더'는 위 셋을 더한 것이라 숫자가 없습니다). 펼친 묶음은 프로젝트 탭마다 기억합니다.
- **Ctrl+Shift+E** 는 펼친 묶음으로 초점을 옮깁니다 (지금 보는 문서의 행으로 — 사이드바를 감췄으면 보이면서). 그 안에서 한 번 더 누르면 다음 묶음을 펼치고 그리로 갑니다 (문서 → 코드 → 자료 → 폴더 → 문서).
- **'문서' 안의 하위 묶음**: '문서'를 펼치면 그 아래에 하위 묶음이 한 단 들여 쌓입니다. 이것도 한 번에 하나만 펼치고, 펼친 것 바로 아래에 트리가 옵니다. 문서가 없는 종류와 '전체'와 같은 종류는 보이지 않습니다 (형광펜·할 일은 md 문서가 있으면 0개여도 보입니다).

  | 하위 묶음 | 보이는 것 |
  |---|---|
  | 전체 | 모든 문서 |
  | 문서 | Markdown 문서 (슬라이드 뺌) |
  | 슬라이드 | Lectern 슬라이드 |
  | HTML | html 문서 |
  | 업무 | 폴더마다의 `WORK.md` |
  | 형광펜 | 칠한 곳이 있는 문서 — 문서 아래에 칠한 글이 한 줄씩 (색 표시와 함께) |
  | 할 일 | 끝내지 않은 할 일이 있는 문서 — 문서 아래에 할 일이 한 줄씩 |

  형광펜·할 일은 문서 본문을 읽어 찾으므로 처음 펼칠 때 잠깐 걸립니다 (그 뒤로는 바뀐 문서만 다시 읽습니다). 개수도 그때 채워집니다. 코드 블록 안은 보지 않습니다. 줄을 누르면 그 문서의 그 자리로 가고, 우클릭하면 메모 달기·지우기가 나옵니다 (아래 '형광펜으로 표시하고 다시 보기').
- 위 입력칸으로 이름·제목을 거릅니다. **제목** 버튼을 켜면 파일 이름 대신 문서 제목으로 보입니다 (끄면 파일 이름, 마우스를 올리면 제목). 문서 열기(Ctrl+P)·검색 결과·모아 보기·최근 변경·문서 탭도 이 설정을 따릅니다.
- 한 목록에 같은 글이 둘 이상이면 가르는 말이 흐리게 붙습니다 — 같은 제목이면 파일 이름(`같은 제목 · 노트.md`), 폴더가 보이지 않는 문서 탭에서 같은 이름이면 폴더(`README.md · a`). 폴더가 이미 보이는 목록(트리·검색 결과 등)에서는 폴더를 붙이지 않습니다.
- **차례** 버튼으로 목록의 차례를 이름순·시간순·형식순으로 고릅니다. 언제나 폴더가 먼저이고 파일이 다음입니다. 시간순은 새것이 위로 오고, 폴더는 그 안의 가장 새 파일을 따릅니다. 형식순은 확장자 차례입니다.
- **↕** 버튼(폴더 모두 펼치기·접기)으로 문서·코드·자료·폴더 목록의 폴더를 한 번에 **폴더 모두 펼치기**·**폴더 모두 접기**·**첫 단계 폴더만 펼치기**를 합니다. 제외 폴더(흐린 폴더)는 펼치지 않습니다 — 펼치면 안을 읽기 때문입니다.
- 아직 열어 보지 않은 바뀐 문서에는 호박색 점이 붙습니다.
- 네 목록 모두 탐색기처럼 키보드로 다룹니다: **↑·↓** 위·아래 항목, **Home·End** 처음·끝, **→** 폴더 펼치기(펼쳐 있으면 첫 항목), **←** 접기(접혀 있으면 위 폴더), **Enter** 열기, 글자를 치면 그 글자로 시작하는 항목. Tab 은 목록마다 한 번만 들르고, 목록 안은 화살표로 옮깁니다.
- `node_modules`·`dist`·`build`·`venv`·`__pycache__` 같은 **제외 폴더**는 '자료'에 흐린 접힌 폴더로 나옵니다. 파일이 아주 많을 수 있어 펼칠 때 안을 읽고, 안의 파일은 종류와 상관없이 모두 여기 보입니다 (코드는 한 번 누르면 읽기 화면). 안이 바뀌어도 저절로 따라오지 않으니, 접었다 다시 펼치거나 F5 를 누르면 새로 읽습니다. 머리줄 개수와 거르기에는 들어가지 않습니다.
- 우클릭 메뉴: `@경로 복사`(Claude Code 프롬프트에 붙이기), 전체 경로 복사, 외부 편집기로 열기, 탐색기에서 보기, **이름 바꾸기…**. 폴더를 우클릭하면 그 폴더만 모아 보기도 있습니다.
- **이름 바꾸기**: 문서 트리·'코드'·'자료' 목록(최근 변경·검색 결과도)에서 파일을 우클릭해 **이름 바꾸기…**, 또는 행을 고른 채 **F2**. 지금 이름이 확장자 앞까지 골라져 있으니 고쳐 쓰고 Enter (Esc 는 그대로 두기). 같은 폴더 안에서 이름만 바뀝니다.
  - 같은 이름의 파일이 있거나 쓸 수 없는 이름(점으로 시작, `\ / : * ? " < > |` 등)이면 까닭이 나오고 바꾸지 않습니다. 확장자를 바꾸면 한 번 더 묻습니다.
  - 보고 있던 문서 탭은 새 이름으로 이어지고(편집 중이었으면 편집도), 뒤로 가기 기록과 담은 조각도 따라갑니다. 저장하지 않은 편집이 있는 파일은 먼저 저장하거나 편집을 닫아야 합니다.
  - 다른 문서 속 이 문서를 가리키는 링크는 고치지 않습니다. 폴더 이름과 제외 폴더 안의 파일은 바꾸지 않고, 옮기기는 없습니다.
- **문서 삭제**: 문서 트리에서 문서를 우클릭해 **문서 삭제…** 를 고릅니다. 늘 먼저 묻고 **휴지통으로 보냅니다**. 휴지통에서 되살립니다. 코드와 자료는 지우지 않습니다. 네트워크 드라이브처럼 휴지통이 없는 곳은 지우지 않고 까닭을 알립니다. 저장하지 않은 편집이 있으면 지우지 않습니다.

### 최근 변경

- 고친 순서로 파일이 나옵니다. 위의 **문서**·**코드**·**자료** 버튼으로 보일 것을 고릅니다 (모두 켜면 섞어서 최근 것부터).
- 문서·코드는 한 번 누르면 열리고, 자료는 두 번 누르거나 Enter 로 엽니다. 우클릭하면 '코드'·'자료' 목록과 같은 메뉴가 나옵니다.
- '최근 변경' 탭 이름 옆의 숫자는 아직 열어 보지 않은 바뀐 문서 수입니다.

### 검색

- 모든 문서와 코드의 본문, 그리고 파일 이름에서 찾습니다 (Ctrl+Shift+F). 대소문자는 가리지 않습니다.
- 검색 칸 아래 **문서**·**코드**·**자료** 버튼으로 찾을 곳을 고릅니다. 맨 위에 **이름이 맞는 파일**(문서는 제목도)이 나오고, 그 아래 본문 결과가 문서 먼저, 그다음 '코드' 묶음으로 나옵니다. 자료(PDF·엑셀 등)는 이름으로만 찾습니다.
- 결과 줄을 누르면(검색 칸에서 Enter 면 첫 결과) 그 문서(코드)의 그 줄로 가서 검색어를 표시합니다. 현재 줄이 그 줄이 되고 초점도 문서로 가므로, 바로 **/**(아래에 넣기)·**F2**(한 줄 편집)·**F3**(다음 찾은 곳)를 누릅니다. 검색어를 고치려면 **Ctrl+Shift+F** 로 검색 칸에 돌아갑니다.
- 이름·제목으로 여는 것은 툴바의 **문서 열기**(Ctrl+P)가 더 빠릅니다. 맞는 문서가 먼저, 그다음 코드가 나옵니다.
- **명령 찾기(Ctrl+Shift+P)**: 문서 열기 칸에 `>` 를 넣은 채 열립니다. 하고 싶은 일의 이름(인쇄, 모두 접기, 목차 …)을 치면 맞는 명령이 나오고 오른쪽에 그 단축키가 보입니다 — Enter 로 바로 합니다. 키가 없는 일(인쇄·PDF, 모두 펼치기, 열린 문서 모두 닫기, 설정 원문 보기 등)도 여기서 찾고, 자주 쓰는 것은 옆의 키를 익혀 두면 됩니다. Ctrl+P 칸에서 `>` 를 쳐도 같습니다.

### 모아 보기

- 맨 위에서 **문서 속 요소**·**문서 정보**·**파일 종류** 가운데 고릅니다.
- 문서 속 요소: 프로젝트의 표·그림·차트·박스글·강조글·다이어그램·코드·수식·할 일·링크·출처를 종류마다 문서별로 모아 봅니다. 종류 버튼('표 7'처럼)으로 고릅니다.
  - **차트**(Vega-Lite·ECharts·Plotly)는 그림처럼 작은 그림으로 모입니다 — 목록에서 보일 때 그립니다. Graphviz·Mermaid 는 다이어그램입니다.
  - **할 일**은 문서의 체크리스트(`- [ ]`·`- [x]`)입니다. 아래 단추로 **안 한 것**(처음)·한 것·모두를 고릅니다.
  - **링크**는 문서 속 링크와 `src/x.py:42` 같은 경로 표기를 대상(문서·코드·자료·폴더·인터넷)과 함께 보입니다. 가리키는 파일이 없으면 붉은 **깨짐** — 아래 단추 **깨진 것**으로 그것만 봅니다.
  - **출처**는 표·그림 아래의 '자료: …'·'출처: …' 같은 줄과 각주입니다.
  - 할 일·링크·출처는 목차에는 나오지 않습니다 (모아 보기에서만).
- 표·그림·다이어그램에 **캡션**이 있으면 캡션이 이름으로 보이고, 그 아래에 '표 3 · 6행 2열' 처럼 번호와 크기가 나옵니다. 캡션은 표 바로 위·그림 바로 아래의 '표 1. …'·'<표 2>'·'[그림 1]'·'〈표 Ⅱ-15〉' 같은 한 줄이나 통째로 굵게 쓴 짧은 한 줄, html 의 `<caption>`·`<figcaption>` 입니다. 없으면 표는 머리행, 그림은 대체 글로 보입니다.
- 누르면 그 문서의 그 자리로 가서 잠깐 테두리로 표시합니다.
- **우클릭**하면 문서에서 보기, **위치 복사**(`@문서 12~17행 ('캡션')`), **원문 복사**(md 문서), **담기**·**문서로 보내기…**·**보이는 것 모두 담기**(아래 '담기'), 문서 경로 복사가 나옵니다. 복사 항목 옆의 **▣ 터미널**을 누르면 그 글이 터미널에 들어갑니다 (Enter 는 누르지 않음).
- 폴더 개요의 '모아 보기' 버튼이나 트리에서 폴더를 우클릭하면 그 폴더만 모읍니다 ('전체'를 누르면 프로젝트 전체).
- 처음 열 때는 문서를 읽느라 잠깐 걸립니다.
- 문서 정보: 문서 맨 앞 설정(frontmatter — `status: 검토 중`, `owner: 리서치팀`, `tags: [a, b]` 같은 것)의 키마다 단추가 나오고, 고른 키의 값마다 문서가 묶입니다 (날짜는 최근 것부터). 들여 쓴 하위 키는 `author.name` 처럼 점으로 이어 나옵니다. 그 키가 없는 문서는 끝의 '값 없음'에. 문서를 누르면 열고, 우클릭하면 `@경로` 복사·터미널.
- 파일 종류: 문서·코드·자료마다 'PDF 2'·'엑셀 3'·'PNG 10'·'PY 12'·'IPYNB 2' 처럼 형식 버튼이 나오고, 고른 형식의 파일이 모입니다. 엑셀·파워포인트·워드·한글은 확장자가 달라도 한 이름으로 셉니다. 그림 파일은 작은 그림으로 보입니다. '트리 순서' 버튼으로 최근 수정한 파일부터 볼 수 있습니다.
- '코드'·'자료' 목록에서 폴더를 우클릭해 **이 폴더의 파일을 종류별로 모아 보기**를 고르면 그 폴더만 모읍니다.

### 담기

문서의 조각을 모아 문서 탭에 열린 문서나 새 문서로 보냅니다.

- **담는 법**: 본문에서 제목을 우클릭하면 **이 절 담기**(그 제목과 아래 내용 전부), 표·그림·차트·다이어그램·수식·코드·단락을 우클릭하면 **담기** — 표·그림·차트는 캡션과 바로 아래의 '자료:' 줄까지 함께 담습니다. 글을 고른 채 우클릭하면 **고른 글 담기**. 모아 보기에서는 항목 우클릭의 **담기**, 또는 **보이는 것 모두 담기**(거르기·단추로 좁힌 목록 그대로 — 예를 들어 프로젝트의 모든 표).
- 담은 것은 사이드바 **담기** 탭에 차례대로 쌓입니다 (탭 옆에 개수). ↑·↓ 로 순서를 바꾸고 ✕ 로 빼며, 누르면 원래 문서의 그 자리로 갑니다. 담는 순간의 내용이라 원래 문서가 나중에 바뀌어도 그대로입니다. 프로젝트 탭마다 따로이고, 앱을 끄면 비워집니다.
- **문서로 보내기…**(담기 탭 위 — 담은 것 모두, 차례대로) 또는 우클릭 메뉴의 **문서로 보내기…**(그 조각 하나만 바로)를 누르면 보낼 곳을 고릅니다: 편집 중인 곳(커서 자리), **새 문서…**, 또는 **문서 탭에 열린 문서** → **맨 끝**·**맨 앞**·**'…' 절 끝**.
- 받는 곳은 문서 탭에 열어 둔 문서와 새 문서뿐입니다. 다른 문서로 보내려면 먼저 그 문서를 문서 탭으로 엽니다 (트리에서 Ctrl+누르기 — 위 '문서 탭').
- 그 문서에 바로 들어가 저장됩니다. **Ctrl+Z** 한 번으로 되돌립니다. 받는 문서를 편집 모드로 고치고 있으면 편집기에 넣고, 저장은 **Ctrl+S** 로 합니다.
- **새 문서…**는 경로를 적고 Enter 를 누르면 그 자리에 제목 한 줄로 바로 만들고(아래 '새 문서 만들기'), 새 문서 탭에서 맨 끝으로 보냅니다.
- 보낼 때 맞춰 주는 것: 그림·링크·차트 데이터의 상대경로를 받는 문서 기준으로, 각주의 정의도 함께(이름이 겹치면 바꿈), 제목 수준을 받는 자리에(절 끝이면 그 절 아래). 조각마다 화면에 보이지 않는 `<!-- 담은 곳: research/a.md 12~19행 -->` 주석이 붙어, 나중에 Claude Code 가 출처를 알 수 있습니다.
- 다른 문서를 편집 모드로 열어 둔 채 담기 탭 항목의 **보내기**를 누르면 그 커서가 든 블록 뒤에 바로 들어갑니다.
- **Claude 에 맡기기**는 담은 것들의 위치(`@문서 12~19행 ('이름')`)를 묶어 새 문서로 만들어 달라는 Claude Code 요청 글입니다 — 복사하거나 ▣ 터미널로 넣습니다 (Enter 는 누르지 않음).
- 코드 화면의 줄과 html 문서의 블록은 담지 않습니다 (원문 줄이 없음). 받는 곳도 md 문서만입니다.

폴더를 열면 처음 보이는 화면입니다. 방금 바뀐 문서, 하위 폴더, 문서마다 제목·요약·수정 시각이 나옵니다. 트리에서 폴더 이름을 누르면 그 폴더의 개요가, 고른 프로젝트 탭을 또 누르면 프로젝트의 개요가 나옵니다.

### 본문

예제 — [04 문서 쓰는 법](../../samples/guide/04-문서-쓰는-법.md)(표·강조글·각주·링크·그림의 원문과 결과), [05 수식](../../samples/guide/05-수식.md), [06 다이어그램](../../samples/guide/06-다이어그램.md), [07 차트](../../samples/guide/07-차트.md).

- 표는 숫자 열을 오른쪽에 맞추고, 머리행이 위에 붙어 따라옵니다. 표에 마우스를 올리면 오른쪽 위에 **복사** 단추가 보입니다 — 우클릭 '표 복사'와 같이 엑셀에 붙이면 칸이 나뉘고, 워드·메일에는 표로 붙습니다.
- **표 칸 맞춤**: 기본은 글은 왼쪽, 숫자는 오른쪽, 칸의 위에 맞춥니다. 설정 창 '보기'의 **표 칸 맞춤**에서 **보고서식**을 고르면 한글 보고서의 표처럼 머리행과 짧은 열(칸의 글이 모두 열 글자 안인 열 — 구분·상태·○× 같은 것)은 가운데, 숫자는 오른쪽, 긴 글은 왼쪽에 두고 칸은 세로 가운데에 맞춥니다. 보이는 것만 바뀌고 파일은 그대로이며, 인쇄·PDF·html 로 저장에도 그대로 갑니다. 한 열만 다르게 하려면 표의 칸을 우클릭해 **이 열 왼쪽 맞춤**·**가운데 맞춤**·**오른쪽 맞춤**을 고릅니다 — 원문의 구분 줄에 맞춤 표시(`:---`·`:---:`·`---:`)를 쓰고, 이 표시가 있는 열은 설정보다 앞섭니다. 표시를 지우려면 그 열에서 **이 열 맞춤 표시 지우기**를 고릅니다.
- 코드 블록은 언어 색으로 칠하고, 오른쪽 위 '복사' 버튼으로 복사합니다.
- 강조글(`> [!NOTE]` 같은 콜아웃 — 제목 줄 없이 종류의 색으로만), 각주, 체크리스트, 수식(`$…$`, `$$…$$`, math·latex 코드 블록), Mermaid 다이어그램을 그립니다. `$105` 같은 달러 표기는 수식으로 바꾸지 않습니다.
- **박스글**: 본문과 따로 읽는 글 상자입니다. 보고서에서 본문의 흐름과 떨어진 주제를 가볍게 다룰 때 씁니다. 원문에서 `<!-- box -->` 줄과 `<!-- /box -->` 줄 사이에 보통 글·표·그림을 쓰면, Lectern 은 테두리와 제목 띠가 있는 상자로 그립니다. 다른 뷰어에서는 두 줄이 보이지 않아 보통 글로 읽힙니다. 첫 줄을 한 줄로 쓰면 제목이 되고, `박스 1. 제목` 으로 쓰면 표·그림처럼 번호가 매겨져 `[박스 1](#박스-1)` 로 가리킵니다. 제목 띠 오른쪽의 화살표를 누르면 접고 폅니다 (접어 두어도 인쇄에는 모두 나옵니다). 닫는 줄을 빠뜨리면 다음 제목 앞에서 끝난 것으로 봅니다. 박스글 안에 제목(`#`)과 다른 박스글은 넣지 않습니다. 전에 '박스글'이라 부르던 `> [!NOTE]` 종류는 **강조글**로 이름을 바꾸었습니다.
- **차트**: 코드 블록의 언어를 `vega-lite`(데이터 차트), `echarts`(도넛·캔들 등 여러 차트), `plotly`(상자 그림·선버스트 등 분석용 차트 — Python 의 `fig.to_json()` 결과도), `dot` 또는 `graphviz`(구성도·의존 관계)로 적으면 그림으로 그립니다. 색은 문서 스타일을 따르고, 누르면 크게 보며, 우클릭 '그림 복사'로 PNG 를 붙입니다. 설정은 JSON 이고 함수는 쓸 수 없습니다. 데이터는 문서 안에 적거나 프로젝트 안의 CSV·JSON 파일을 상대경로로 가리킵니다 (인터넷 주소는 읽지 않습니다). 마우스를 올려 값 보기 같은 움직임은 없고, Plotly 의 지도 차트는 인터넷의 지도 자료가 있어야 해서 그리지 않습니다. 예제(**예제 열기**)의 `guide/07-차트.md` 에 종류마다 예가 있습니다.
- **차트의 데이터**: 차트에 마우스를 올리면 오른쪽 위에 **표**·**복사** 단추가 보입니다. **표**는 차트를 그린 데이터를 차트 아래에 표로 펼치고, 다시 누르면 접습니다. 30행이 넘으면 처음·끝과 일정한 간격의 30행만 보이고 **모두 보기**로 5,000행까지 펼칩니다. **복사**는 데이터 전부를 엑셀(칸이 나뉨)·워드(표)에 붙일 수 있게 복사합니다. 데이터는 차트의 원문에서 읽습니다 — 차트가 값을 거르거나 합쳐 그리면(변환·집계) 표는 그 전의 값입니다. 데이터가 CSV 파일에 있는 차트는 표 대신 파일 이름을 알리고 **데이터를 문서 안으로 넣기**를 보입니다. 누르면 그 CSV 를 읽어 차트의 원문에 값으로 넣습니다 — 문서만 보내도 다른 PC 에서 차트와 표가 보입니다 (Ctrl+Z 로 되돌립니다). Lectern 슬라이드의 차트와 Graphviz 에는 단추가 없고, 단추와 표는 인쇄·PDF 에 나오지 않습니다.
- 문단 안에서 Enter 로 바꾼 줄은 화면에서도 줄이 바뀝니다 (Word 의 Shift+Enter 처럼 — 개조식 글이 그대로 보입니다). 줄 끝 공백 두 개와 `<br>` 도 같습니다. 표준 Markdown 처럼 이어서 보려면 설정에서 끕니다.
- 그림을 누르면 크게 보입니다.
- 본문의 `src/app.py:42` 처럼 실제로 있는 파일 경로는 링크가 됩니다.

### 목차

- 오른쪽 목차를 누르면 그 제목으로 가고, 지금 읽는 곳이 표시됩니다.
- 제목 아래에는 그 절의 표·그림·박스글·강조글·다이어그램·코드·수식이 '표 1 · 가격 비교 · 6행 4열'처럼 나옵니다. 누르면 그 자리로 갑니다.
- 목차 위의 '표 2'·'코드 5' 같은 버튼을 누르면 그 종류를 목차에서 감추고, 다시 누르면 보입니다.
- 탭 막대 오른쪽 끝의 **목차** 버튼이나 **Alt+O** 로 목차를 보이고 감춥니다.
- 문서와 목차 사이 경계를 끌어 목차 폭을 바꿉니다. 두 번 누르면 기본 폭으로 돌아갑니다.
- **절 옮기기**: 고칠 수 있는 md 문서에서는 목차의 제목을 끌어 다른 제목 위에 놓으면 그 절을 본문·하위 절과 함께 그 앞으로 옮깁니다. 마지막 제목의 아래쪽에 놓으면 문서 끝으로 갑니다. 수준은 그대로이고 Ctrl+Z 로 되돌립니다.

### 절 접기

제목 왼쪽 여백의 화살표를 누르면 그 절이 접히고, 다시 누르면 펼쳐집니다 (화살표는 제목 위에 마우스를 올리면 보입니다). 키보드는 **Ctrl+Shift+[** 로 현재 줄이 든 절을 접고 **Ctrl+Shift+]** 로 폅니다 — 이미 접혔으면 Ctrl+Shift+[ 는 바깥 절을 접고, 펴져 있으면 Ctrl+Shift+] 는 그 안의 접힌 하위 절을 폅니다. 제목 글자를 누르면 접히지 않고 그 줄이 현재 줄이 됩니다. 본문을 우클릭하면 같은 수준 제목 모두 접기, 모두 접기·펴기도 있습니다. 모두 접기·펴기는 **Ctrl+Alt+[**·**Ctrl+Alt+]** 로도 합니다 — 모두 접으면 현재 줄은 그 줄이 든 절의 제목으로 갑니다. 접어 둔 절은 앱을 다시 실행하면 펼쳐집니다.

### 글자 크기와 스타일

- 툴바의 − / + 로 문서 글자를 80%~200%로 바꿉니다 (100% 도 읽기 좋게 조금 크게 잡혀 있습니다). 가운데 '100%'를 누르면 처음 크기로 돌아갑니다. 키보드로는 **Ctrl+=**·**Ctrl+-**·**Ctrl+0**(100%)입니다. 앱 화면 전체를 키우려면 Ctrl+휠을 씁니다.
- 그 옆의 **문서 폭** 버튼(좁게 · 폭 100% · 넓게)으로 md 문서 본문의 좌우 폭을 80%~200%로, 끝까지 넓히면 **가득**(문서 칸 폭 전체)으로 바꿉니다. 글자 크기는 그대로이고 한 줄이 길어지거나 짧아집니다. 가운데를 누르면 처음 폭으로 돌아가고, 고른 폭은 다음 실행에도 그대로입니다. 창이 좁아 문서 칸이 본문보다 좁으면 칸 폭까지만 넓어집니다. 코드 화면·Lectern 슬라이드·자기 스타일이 있는 HTML 문서는 그대로입니다.
- 표의 머리행과 맨 왼쪽 열은 낱말 가운데서 끊지 않습니다 (띄어쓰기에서 감깁니다. 긴 낱말 때문에 표가 옆으로 넘치면 그 표만 예전처럼 끊습니다).
- 툴바의 **줄 번호** 버튼이나 **Alt+L** 로 Markdown 문서 왼쪽 여백에 원문 줄 번호를 보이고 감춥니다. 번호는 Claude 에 보내는 `@경로 12행` 과 같은 줄입니다. 빈 줄처럼 화면에 없는 줄의 번호는 건너뛰고, 화면에서 꺾인 글은 첫 줄에만 붙습니다. 코드 화면에는 늘 번호가 있습니다. 인쇄에는 나오지 않습니다.
- **표의 열 너비는 저절로 맞춥니다.** 글이 적은 열이 한두 글자 폭으로 좁아져 행이 길어지지 않게, 열마다 가장 긴 낱말이 들어가는 폭부터 줍니다. 남는 폭은 몇 가지로 나눠 실제로 그려 보고 나은 것을 씁니다 — 표가 가장 낮아지게, 열마다 든 글 양에 맞춰, 한 줄에 낱말이 둘은 들어가게. 맨 왼쪽 열 때문에 행이 높으면 그 열을 넓히는 것도 함께 대어 봅니다. 옆으로 스크롤은 마지막 수단입니다 — 열이 아주 많아 좁혀 넣으면 글이 세로로 감길 때나, 줄바꿈하지 않는 숫자가 들어가지 않을 때만 표 안에서 옆으로 스크롤합니다. 그래도 칸이 길면 표를 나누거나 긴 설명을 표 밖으로 옮기는 것이 좋습니다 — AI 에게 문서를 맡기면 Lectern 작성 안내가 그렇게 쓰게 합니다. 창·사이드바 폭이나 글자 크기·문서 폭을 바꾸면 다시 맞춥니다. 보이는 폭만 바꾸고 파일은 그대로이며, 인쇄·PDF 는 쪽 폭에 맞춰 다시 나눕니다.
- **스타일** 목록에서 24종 중 고르면 본문과 툴바·사이드바 색이 함께 바뀝니다. 목록 옆 ∧·∨ 로 위·아래 스타일을 차례로 견주어 볼 수 있습니다. '자동'은 Windows 다크 모드를 따릅니다.
- 스타일 목록을 용도별·분위기별·밝기별 중 어떻게 묶을지는 설정 창에서 고릅니다.

### 내 스타일

- 원하는 모양의 스타일을 직접 만들 수 있습니다. CSS 파일 하나가 스타일 하나이고, `%APPDATA%\Lectern\styles` 폴더에 두면 스타일 목록 맨 아래 **내 스타일**에 나옵니다.
- 직접 쓰지 않아도 됩니다. 설정 창의 **Claude Code용 요청 복사**를 누르고 Claude Code 에 붙여 넣은 뒤 원하는 모양(예: '남색 제목, 표 머리행은 짙은 남색에 흰 글자, 본문은 명조')을 이어서 적으세요. 요청 글에는 앱에 든 스타일 설명서와 저장할 폴더의 위치가 들어 있어, AI 가 설명서를 읽고 파일을 만듭니다. 옆의 터미널 버튼을 누르면 그 글이 터미널에 바로 들어갑니다.
- 그 스타일을 고른 채 파일이 고쳐지면 몇 초 안에 다시 입혀집니다 — '제목을 더 크게' 처럼 이어서 부탁하며 바로 보면서 다듬을 수 있습니다.
- 설정 창의 **스타일 폴더 열기**로 폴더를 엽니다. 파일을 지우면 목록에서 빠집니다.
- 인터넷에서 글꼴·그림을 불러오는 부분은 앱이 지웁니다. 글꼴은 PC 에 있는 것만 쓰입니다.

### 현재 줄

Markdown 문서와 코드 화면(csv·txt 포함)에서는 줄을 원문 파일의 줄로 셉니다 — 한 줄로 쓴 문단·목록 항목·제목·표의 행은 통째로 한 줄, 여러 줄로 나눠 쓴 문단은 줄마다, 코드는 줄마다입니다. 그래서 Claude 에 보내는 `@경로 12~20행` 이 화면에서 고른 곳과 같습니다.

- **현재 줄**: 지금 보는 줄 왼쪽의 작은 삼각형입니다. 본문을 누르거나 우클릭하면 그 줄로, **↑·↓** 로 한 줄씩 옮기고 화면이 따라갑니다. **Home·End** 는 문서의 첫 줄·끝 줄로, **PageUp·PageDown**(Space·Shift+Space)은 한 화면씩 옮기며 현재 줄은 화면에서 같은 높이에 둡니다. **Ctrl+↑·↓** 는 앞·뒤 제목으로 갑니다. 휠로 스크롤해 화면 밖으로 나가면 화면 안의 가장 가까운 줄로 따라옵니다. 목차·찾기·검색으로 가면 그 줄로 옮깁니다. 상태줄에 `현재 줄 12행` 처럼 보이고, 문서 탭마다 따로 남습니다.
- **Claude로 보내기**: **Shift+→** 를 누르면 현재 줄(고른 줄이 있으면 그 범위 — 낱말을 고른 동안은 보내지 않고 낱말 넓히기)의 위치 `@경로 12~20행` 이 맨 앞 터미널(보통 1번 — Claude Code 를 돌리는 곳)에 들어갑니다. Enter 는 누르지 않고 초점이 터미널로 가서 바로 요청을 적을 수 있습니다. 여러 곳을 이어서 넣으려면 **Ctrl+Shift+→** 를 누르세요 — 초점이 문서에 남습니다. 터미널이 여럿이면 **Shift+숫자**(Ctrl+Shift+숫자)로 그 번호의 터미널에 넣습니다. **Shift+←** 는 그 위치를, **Ctrl+C** 는 그 줄들의 원문을 복사합니다 (글자를 끌어 고른 것이 있으면 Ctrl+C 는 그 글). 복사하면 화면 아래에 '복사했습니다: …' 가 잠시 뜹니다.
- **장 하이라이트**: 툴바의 **하이라이트** 버튼이나 **Alt+H** 를 누르면 현재 줄이 있는 장만 또렷해집니다. ↑·↓, PageUp·PageDown, 버튼 옆 ∧·∨ 로 앞뒤 장으로 갑니다. 흐린 곳을 누르면 그 장으로 옮깁니다. Shift+↑·↓ 를 누르면 그 장이 고른 줄이 됩니다. Esc·버튼으로 끄고, 본문을 우클릭해 '이 장 하이라이트'를 골라도 됩니다. 장으로 나뉘지 않은 문서와 코드 화면에서는 버튼이 Ctrl+Enter 와 같습니다.
- **그 줄에서 Enter**: 현재 줄을 한 줄 편집으로 엽니다 — F2 와 같습니다. 제목 줄·링크가 있는 줄에서도 편집이 먼저입니다. 칸에서 Enter 를 다시 누르면 저장하고 닫고 현재 줄은 다음 줄로 옮겨 가니(바꾸지 않았으면 파일은 그대로), Enter·Enter 로 줄을 차례로 훑으며 고칩니다.
- **그 줄에서 Alt+Enter**: 제목 줄이면 그 절을 접고 펴고(Ctrl+Shift+[·] 도), 링크가 있는 줄이면 그 링크를 엽니다 (여럿이면 고르는 메뉴). **Tab·Shift+Tab** 은 현재 줄 뒤·앞의 링크로 초점을 옮기고, 거기서 **Alt+Enter** 로 엽니다 (Enter 는 그 줄의 편집). 마지막 링크 다음은 첫 링크로 돌고, 링크가 없으면 문서 안의 단추(코드 화면 머리줄 등)를 돕니다 — **Tab 은 문서 밖(터미널·사이드바)으로 나가지 않습니다.** 폴더 개요와 html 문서도 그 안에서만 돌고, 찾기 막대의 칸에서도 막대와 문서 안만 돕니다. 문서를 떠나려면 **F6** 을 누릅니다. **F3·Shift+F3** 은 마지막에 찾은 말의 다음·앞 곳입니다 (찾기 막대를 닫은 뒤에도).
- 줄을 고르고 고치는 일은 '문서 쓰고 고치기' 장에 있습니다.

### 문서에서 찾기

- Ctrl+F 는 지금 보는 문서나 코드에서 찾습니다. 굵게·코드 같은 서식이 섞여도 찾습니다.
- Enter 는 다음, Shift+Enter 는 이전 결과, Esc 는 닫기입니다.
- **찾아 바꾸기**(md 문서): 찾기 막대의 **바꾸기** 단추나 **Ctrl+H**(찾는 말 칸에서도)로 바꿀 글 줄을 엽니다 — 단추로 열면 바로 바꿀 글을 칩니다. 다시 누르면 닫힙니다. **바꾸기**(Enter)는 현재 줄 뒤의 첫 곳을, **모두 바꾸기**(Ctrl+Enter)는 문서 전체를 바꿔 바로 저장합니다. **Ctrl+Z** 로 되돌립니다. 코드 화면·html 문서·보기만 하는 폴더에서는 단추가 보이지 않습니다 (찾기만).
- **Ctrl+G** 는 줄로 가기입니다 — 줄 번호를 치고 Enter.

### HTML 문서

Claude 가 만든 html 보고서는 트리에 `HTML` 표시와 함께 나옵니다. 문서의 스타일은 그대로 보이고, 스크립트와 인터넷 CSS 는 막습니다 (스크립트로 그리는 차트는 보이지 않습니다). `src`·`public`·`web` 같은 앱 소스 폴더의 html 은 문서로 보지 않습니다.

### 자동 새로고침

- Claude 가 문서를 쓰는 동안 1초 안에 반영되고, 보던 위치는 그대로입니다.
- 바뀐 문단·표는 잠깐 배경색으로 표시됩니다. 화면 밖에서 바뀌었으면 상태줄의 **바뀐 곳** 버튼으로 차례로 갑니다. **F7**·**Shift+F7** 은 바뀐 곳의 다음·앞으로 갑니다 — 모두 화면 안이라 버튼이 없어도 되고, 현재 줄도 그 블록으로 옮겨 가니 바로 F2 로 고치거나 Shift+→ 로 보낼 수 있습니다.
- 글이 그대로면 화면을 다시 그리지 않아 고른 글이 남습니다. 글을 끌어 고르는 동안에는 마우스를 놓을 때까지 기다립니다.
- 글이 실제로 바뀌면 화면을 다시 그리므로 고른 글은 풀립니다.
- 감시가 놓친 변경은 F5 를 누르면 다시 불러옵니다.

### 인쇄·PDF·html·Word

탭 막대 오른쪽 끝의 **인쇄** 버튼(목차와 메모 사이)을 누르거나, 본문 여백을 우클릭해 **PDF로 저장…**·**인쇄…**·**html로 저장…**·**Word로 저장…** 을 고릅니다. 종이와 PDF 는 화면 스타일과 상관없이 늘 같은 **보고서 양식**입니다 — A4, 여백 위 25·아래 22·좌우 22mm, 첫 쪽 가운데 제목, 2쪽부터 머리에 문서 제목과 날짜(맨 앞 설정의 `date`, 없으면 오늘), 바닥 가운데 쪽 번호. 표는 위아래 굵은 줄, 링크는 검은 글자로 나오고 주소는 '출처'·'참고문헌'·'자료' 절의 목록에만 붙습니다. 맨 앞 설정 표는 싣지 않습니다. 본문 글꼴은 설정 창의 **인쇄·PDF 글꼴**에서 명조(기본)·고딕을 고릅니다.

모두 **내보내기** 창을 엽니다. 맨 위 **형식**에서 PDF·인쇄, html 한 파일, Word 를 고릅니다. 왼쪽에서 옵션을 고르면 오른쪽 미리보기가 그 옵션으로 다시 만들어집니다 — 미리보기가 저장·인쇄될 PDF 그대로입니다 (목차·확대·쪽 넘기기는 미리보기 위 막대로).

| 옵션 | 고르는 것 |
|---|---|
| 글꼴 | 명조(함초롬바탕, 없으면 바탕 — 제목은 고딕)·고딕(맑은 고딕) |
| 여백 | 보통(위 25·아래 22·좌우 22mm)·좁게(사방 15mm)·넓게(위 30·아래 25·좌우 30mm) |
| 쪽 머리 | 2쪽부터 머리에 문서 제목과 날짜 |
| 쪽 번호 | 바닥 가운데 '- 1 -' |

옵션은 다음에도 그대로입니다.

- **PDF로 저장…**: 미리 본 PDF 를 저장 대화상자에서 고른 곳에 씁니다 (문서 옆, 문서 이름으로 열립니다). 브라우저가 붙이는 날짜·주소 머리글이 없고, 제목이 PDF 책갈피가 됩니다. 같은 이름이 있으면 Windows 가 덮어쓸지 묻습니다. PDF 보기 프로그램이 그 파일을 열고 있으면 닫고 다시 저장합니다.
- **인쇄…**: 미리 본 PDF 를 인쇄 창으로 보냅니다. 프린터·매수·쪽·색은 인쇄 창에서 고릅니다. PDF 를 인쇄하는 것이라 날짜·주소 머리글이 붙지 않습니다.
- Esc 나 **닫기**로 창을 닫습니다 (미리보기 안을 누른 뒤에는 마우스를 미리보기 밖으로).
- html 문서는 그 문서 자체의 스타일로 인쇄 창 하나(**인쇄 / PDF로 저장…**)만 있습니다 — PDF 는 프린터에서 'Microsoft Print to PDF'를 고릅니다.
- **틀**: 형식 아래 **틀**에서 출력 양식을 고릅니다 — 정부 보고서·한 장 보고서·공문·보도자료·회의록, 연구보고서·이슈 브리프·학술 논문(2단)·투고 원고·백서, 증권사 리포트·컨설팅 보고서·제안서, 잡지·뉴스레터·책·웹 장문, 매뉴얼. 글은 그대로이고 표지·머리·쪽 크기·글꼴·색이 바뀝니다. PDF 와 html 이 같은 꼴로 나옵니다. 맨 위 **보고서 (기본 양식)** 은 위의 보고서 양식(글꼴·여백 옵션)입니다.
  - 틀은 맨 앞 설정의 값을 표지·머리에 씁니다 (`title`·`subtitle`·`author`·`date`·`org` 기관·`dept` 부서 등 — 한국어 키 `기관:`·`부서:` 도 됩니다). 틀을 고르면 그 틀이 쓰는데 비어 있는 키를 알리고, **맨 앞 설정 견본 복사**로 그 키들을 복사해 문서 맨 앞에 붙여 채웁니다.
  - 요약·핵심·초록처럼 따로 놓일 글은 **이름 있는 박스글**로 씁니다 — `<!-- box: 요약 -->` 줄로 열면 그 틀의 요약 자리로 옮겨집니다. 틀에 그 자리가 없으면 본문의 보통 박스글로 남습니다. 창에 그 틀의 박스글 자리가 보입니다.
  - 문서 맨 앞 설정에 `layout: 틀 id`(예: `layout: research-report`)를 적어 두면 창을 열 때 그 틀이 골라져 있습니다.
  - 내 틀: 설정 창의 **지면 틀**에서 틀 폴더를 열고, **Claude Code용 요청 복사**를 Claude Code 에 붙여 원하는 양식(예: '우리 회사 주간 보고 양식, 첫 쪽에 로고 띠')을 이어 적으면 Claude 가 작성 안내를 읽고 틀 폴더에 html 하나를 만듭니다. 목록 맨 아래 **내 틀**에 나옵니다.
- **html로 저장…**: md 문서를 html 파일 하나로 저장합니다. 지금 화면 스타일 그대로 한 쪽에 길게 담고, 그림·차트·다이어그램·수식이 파일 안에 들어가 그 파일 하나만 메일로 보내면 됩니다. 접어 둔 절과 박스글도 펴서 담고, 복사 단추·줄 번호 같은 앱 표시와 맨 앞 설정 표는 빼며, 목차·각주·상호 참조 링크는 그대로 됩니다. 다른 문서로 가는 링크는 글로 남습니다. 스크립트가 없어 받은 사람의 브라우저에서 안전하게 열리고, 받은 사람이 인쇄하면 PDF 와 같은 보고서 양식입니다. 미리 본 그대로 저장 대화상자에서 고른 곳에 씁니다 (문서 옆, 문서 이름으로 열립니다). Lectern 슬라이드는 상태줄의 **html 로 전환**을 씁니다.
- **Word로 저장…**: md 문서를 Word 에서 고쳐 쓸 docx 로 저장합니다. 글은 글로, 표는 Word 표로(머리행은 쪽마다), 각주는 Word 각주로, `표 1.`·`그림 1.` 캡션은 Word 의 번호 필드로 들어가고 `[표 1](#표-1)` 같은 상호 참조는 그 캡션으로 가는 링크가 됩니다. 형광펜·글자색·강조글·박스글도 옮기고, 차트·다이어그램·블록 수식은 그림으로 넣습니다 (문장 속 수식은 글). 미리보기는 없고 만든 결과(그림 수·크기·알릴 것)가 보입니다 — 쪽은 Word 가 나눕니다. `[목차]` 줄이 있으면 Word 가 열 때 '필드를 업데이트할까요?' 를 묻습니다 — **예**를 누르면 목차와 쪽 번호가 채워집니다.
  - **Word 양식**: 기본은 Lectern 기본 양식(A4, 명조 본문, 2쪽부터 머리에 제목, 바닥 가운데 쪽 번호)입니다. 그 아래 **Lectern 양식 18가지**가 지면 틀과 같은 이름·묶음으로 있습니다 — 정부 보고서·한 장 보고서·공문·보도자료·회의록, 연구보고서·이슈 브리프·학술 논문(2단)·투고 원고·백서, 증권사 리포트·컨설팅 보고서·제안서, 잡지·뉴스레터·책·웹 장문, 매뉴얼. 같은 문서를 틀로 PDF·html 을, 같은 이름의 양식으로 Word 를 내면 표지·요약 상자·결재란·쪽 머리가 같은 꼴로 나옵니다. 양식은 맨 앞 설정(`title`·`subtitle`·`author`·`org`·`date`·`number` …, 한국어 키 `기관`·`부제`·`연구진` 도)으로 표지와 정보 표를 채우고, 비어 있는 키의 줄은 뺍니다. 이름 있는 박스글(`<!-- box: 요약 -->`)은 양식의 그 자리로, 결재란은 `결재: [담당, 팀장, 원장]` 으로, 이름표(요약·차례 …)는 `lang: en` 이면 영어로 나옵니다. 양식을 고르면 아래에 설명·쪽·박스글 자리와 비어 있는 맨 앞 설정이 보이고, **맨 앞 설정 견본 복사**가 비어 있는 키만 복사합니다 (문서에는 쓰지 않습니다 — 붙여 넣고 채우는 것은 사용자가).
  - **절 제목 왼쪽의 작은 ▪**: 글자가 아니라 Word 가 '다음 단락과 함께'가 걸린 문단에 보이는 표시입니다 — Word 의 **단락 기호**를 보이게 해 두면 나옵니다 (인쇄·PDF 에는 나오지 않고, Word 기본 제목 스타일에도 같은 표시가 붙습니다). 절 제목·캡션은 쪽이 바뀔 때 다음 글과 떨어지지 않게 이 설정을 두고, 첫 쪽 맨 위의 문서 제목·부제에는 두지 않습니다. 안 보려면 Word 의 **파일 > 옵션 > 표시** 에서 '단락 기호'를 끕니다.
  - **내 양식**: 회사·기관의 Word 양식(.dotx·.docx)을 **양식 폴더 열기**로 연 폴더에 넣으면 목록 맨 아래 '내 양식'에 나오고, 고르면 그 양식의 스타일·쪽 크기·여백·머리글·바닥글을 빌려 본문만 새로 씁니다. 양식이 자기 이름의 스타일('1.제목'·'본문2'처럼)을 쓰면 양식 옆에 `양식이름.styles.json`(`{"heading 1": "1.제목", "Normal": "본문2"}`)을 둡니다. 내 양식에 표지를 두려면 Word 에서 양식의 글 속에 `{{title}}`·`{{author}}`·`{{date:ko}}` 같은 자리를 쓰고 본문이 들어갈 곳에 `{{body}}` 한 줄을 둡니다 (자리의 전체 목록은 스킬의 SKILL.md 와 예제 가이드 13).
  - 문서 맨 앞 설정에 `docxStyle: 양식 이름`을 적어 두면 창을 열 때 그 양식이 골라져 있습니다. 없으면 `layout:`(지면 틀)과 같은 이름의 양식 — 내 양식을 먼저, 다음은 Lectern 양식입니다. 틀과 양식이 같은 이름이라 `layout: 연구보고서` 한 줄이면 PDF·html·Word 가 짝지어집니다.
  - 만드는 데 몇 초 걸립니다 (차트가 많으면 더). 차트는 Windows 의 Edge 로 그립니다 — 인터넷에 나가지 않습니다.

Lectern 슬라이드는 슬라이드 크기의 쪽에 한 장씩 나옵니다 (아래 'Lectern 슬라이드'). 넣기 창의 **쪽 나눔** 줄에서 쪽이 바뀌고, **목차** 줄은 그 자리에 목차로 인쇄됩니다 (아래 '구성 요소 넣기').

- 화면의 글자 크기·문서 폭·줄 번호·찾기 표시·하이라이트·스타일은 종이에 들어가지 않습니다. 12행이 넘는 표는 쪽을 나눠 싣고 머리행을 쪽마다 되풀이하며, 캡션은 표·그림과 같은 쪽에 붙고, 쪽보다 큰 그림은 한 쪽 높이로 줄입니다.
- 편집 중이면 저장하고 편집을 닫은 뒤 저장합니다 (PDF 는 저장한 내용으로). 모두 펼치기에서는 우클릭한 칸의 문서가 PDF 가 됩니다.

예제 — [12 보고서와 PDF](../../samples/guide/12-보고서와-PDF.md): 글쓰기 스타일로 보고서를 쓰게 하는 요청의 예, PDF 에 잘 나오게 쓰는 법, Claude 가 쓴 견본 보고서로 해 보기. [13 내보내기 — html·지면 틀·Word](../../samples/guide/13-내보내기-html-틀-Word.md): 틀 18가지와 맨 앞 설정·이름 있는 박스글, 회사 Word 양식 쓰기, 바로 해 볼 예제 문서 세 개.

## 문서 쓰고 고치기

전체 편집을 열지 않고 md 문서를 처음부터 끝까지 쓰고 고칩니다.

예제 — [08 한 줄 편집](../../samples/guide/08-한-줄-편집.md): 줄 고르기와 사례 스물두 가지를 따라 해 봅니다.

**저장은 따로 하지 않습니다.** 칸의 Enter, 줄 옮기기·지우기, 줄 종류·레벨 바꾸기, 표의 행·열, 체크 칸, 그림 붙여 넣기는 누르는 순간 원문 파일에 저장되고, 하나하나 **Ctrl+Z** 로 되돌립니다 (고른 줄·하이라이트는 되돌린 줄들에 그대로 남습니다). 새 줄은 글을 쓸 때 저장되고, 칸에서 Esc 를 누르면 고친 것을 버립니다. Lectern 슬라이드도 같습니다. Ctrl+S 를 눌러야 저장되는 것은 전체 편집뿐입니다 (칸 안의 Ctrl+S 는 Enter 와 같습니다). 현재 줄을 옮기거나 줄을 고르거나 하이라이트·접기를 하는 것은 파일을 바꾸지 않습니다.

**알림은 보지 못한 변경에만 뜹니다.** 저장할 때마다 알리지 않습니다 — 상태줄의 '수정' 시각이 바뀝니다. 화면 아래 알림은 지운 것, 고른 줄 밖이 함께 바뀐 것(뒤 항목의 번호 같은), 여러 곳을 한 번에 바꾼 것(찾아 바꾸기), 되지 않은 일과 그 까닭처럼 화면에서 보지 못했을 수 있는 것만 띄웁니다. 되돌리기도 그 줄이 화면 밖이어서 옮겨 갔을 때만 알립니다.

### 줄의 네 상태

| 상태 | 무엇인가 | 들어가기 | 나오기 |
|---|---|---|---|
| **현재 줄** | 한 줄 — 읽는 자리이고, 쓰고 넣는 자리입니다 | 누르기, 우클릭, ↑·↓, Home·End, PageUp·PageDown, Ctrl+↑·↓ | — |
| **고른 줄** | 여러 줄 — 한꺼번에 지우고 옮기고 바꿀 줄입니다 | 현재 줄에서 **Shift+↑·↓**, Shift+누르기·끌기, Ctrl+A(모든 줄) | Esc, ↑·↓, 바깥 누르기, 한 줄로 줄이기 |
| **하이라이트** | 현재 줄이나 고른 줄의 라이트(줄 선택) — 나머지를 흐리게 합니다 | **Ctrl+Enter** | Ctrl+Enter·Esc·흐린 곳 누르기 |
| **칸** | 그 줄을 화면의 그 자리에서 고치는 글 칸 | **Enter**·**F2**, Shift+Enter(새 줄) | Enter 저장하고 닫고 다음 줄로(열지는 않음), Ctrl+S 저장하고 닫기(그 줄에), Shift+Enter 저장하고 아래에 새 줄, Ctrl+Enter 저장하고 그 줄 선택, Esc 그만두기 |

- **선택은 하나입니다**: 한 줄이면 현재 줄이고, Shift+↑·↓ 나 Shift+누르기로 넓혀 여러 줄이 되면 고른 줄입니다. 처음 줄은 그대로 두고 끝 줄을 옮기므로 넓어지거나 줄어들고, 한 줄로 줄면 현재 줄로 돌아옵니다. Shift+누르기는 현재 줄(마지막으로 누르거나 옮긴 줄 — 그 뒤에 스크롤해도 같습니다)부터 누른 줄까지, Shift+끌기는 누른 줄부터 끈 줄까지 고릅니다. 고른 동안 상태줄에 `고른 줄 3~5행 · 3줄` 이 보입니다.
- **크게 고르기**: **Shift+Home·End** 는 현재 줄부터 문서 처음·끝까지, **Shift+PageUp·PageDown** 은 한 화면만큼, **Ctrl+Shift+↑·↓** 는 그 절의 제목·끝까지 고릅니다. **Ctrl+A** 는 문서의 모든 줄을 고르고 화면은 옮기지 않습니다 — 그대로 Ctrl+C 로 원문을 복사하거나 Shift+→ 로 Claude 에 보냅니다.
- **Enter 키는 어디서나 같은 뜻입니다**: **Shift+Enter** 는 아래에 새 줄(읽는 화면이든 칸 안이든), **Ctrl+Enter** 는 줄 선택(하이라이트 — 칸 안이면 저장하고 그 줄을), **Enter** 는 편집 — 읽는 화면에서는 현재 줄의 칸을 열고(F2 와 같다), 칸 안에서는 저장하고 닫은 뒤 현재 줄을 다음 줄로 옮깁니다(마지막 줄이면 그대로). 제목 접기·링크 열기는 **Alt+Enter** 입니다. 위에 새 줄은 **Ctrl+Shift+Enter**.
- **쓰고 넣는 것은 현재 줄에서 합니다**: 그 줄 쓰기(F2), 아래·위에 새 줄(Shift+Enter·Ctrl+Shift+Enter), 아래에 넣기 창(`/`), 그림 붙여 넣기. 여러 줄을 고른 동안에는 되지 않고 'Esc 로 풀고 누르세요'라고 알립니다.
- **바꾸는 키는 한 줄이면 두 번, 여러 줄이면 한 번입니다**: 지우기(Delete·Ctrl+X), 옮기기(Alt+↑·↓), 줄 종류(한 글자 키·Ctrl+Alt+숫자), 레벨(Alt+Shift+←·→)이 그렇습니다. 현재 줄에서 처음 누르면 그 줄에 띠가 생기고 상태줄에 `현재 줄 12행 · 바꾸기` 가 보일 뿐 파일은 그대로입니다 — 읽다가 누른 키로 파일이 바뀌지 않게 (화면 아래 알림은 Lectern 을 켠 뒤 처음 한 번만 뜹니다). 한 번 더 누르면 바꾸고, 띠가 있는 동안은 이어 누르는 키(Alt+↑ 를 거듭, Tab)가 바로 듣습니다. ↑·↓·Esc·바깥 누르기로 그만둡니다. 키를 누르고 있어도 한 번으로 셉니다. 복사·위치 복사·터미널로 보내기처럼 파일을 바꾸지 않는 키는 현재 줄이든 고른 줄이든 바로 합니다.
- **쓰기를 시작하면 고르기는 끝납니다**: 칸을 열면 띠와 한 줄의 하이라이트가 풀립니다.
- **하이라이트(줄 선택)는 언제든 켜고 끕니다**: **Ctrl+Enter** 는 현재 줄이면 그 한 줄을, 고른 줄이면 그 줄들을 또렷하게 하고 나머지를 흐리게 합니다. 켠 줄은 고른 줄과 같습니다 — 지우기·옮기기·줄 종류·복사·보내기가 그대로 되고(한 줄이어도 한 번에), Shift+↑·↓ 로 넓히고 줄입니다. 다른 것은 ↑·↓ 뿐입니다 — 풀지 않고 화면만 스크롤합니다. 끄면 고른 줄로(한 줄이면 현재 줄로) 돌아옵니다. 흐린 곳은 누르면 끄고, 우클릭하면 끄기만 나옵니다.
- **우클릭**: 우클릭한 줄이 현재 줄이 됩니다. 고른 줄 안에서 우클릭하면 그 범위의 선택 상자가 나옵니다 — 그 블록에서만 하는 일(표 복사 등), **Claude로 보내기**, 복사, 담기·보내기, **고른 줄 바꾸기…**, 풀기, 맨 아래 줄 지우기. 고른 줄 밖을 우클릭하면 고르기를 풀고 그 줄의 메뉴가 나옵니다. 메뉴 항목의 설명은 마우스를 올리면 보입니다.

### 글 고르기와 서식

읽는 화면에서도 낱말을 골라 바로 서식을 줍니다. 칸을 열지 않아도 됩니다.

예제 — [08 한 줄 편집](../../samples/guide/08-한-줄-편집.md)의 사례 21·22: 중요한 말에 굵게·형광펜, 한 줄 통째에 서식. 문장 속 서식의 원문은 [04 문서 쓰는 법](../../samples/guide/04-문서-쓰는-법.md)의 '문장 속 서식'.

| 키 | 하는 일 |
|---|---|
| 본문을 **두 번 누르기** | 그 낱말을 고릅니다 (한 줄 편집 칸은 열리지 않습니다) |
| 현재 줄에서 **→** / **←** | 그 줄의 첫 낱말 / 마지막 낱말을 고릅니다 |
| 고른 채 **→** / **←** | 오른쪽 / 왼쪽 낱말로 옮깁니다 |
| 고른 채 **Shift+→** / **Shift+←** | 낱말 단위로 넓히고 줄입니다 |
| 고른 채 **Home** / **End** | 첫 낱말 / 마지막 낱말 (Shift 와 함께면 거기까지 넓힘) |
| **B** · **I** · **S** · **M** · **F** | 고른 글을 굵게 · 기울임 · 취소선 · 형광펜 · 글자색 (Ctrl+B · Ctrl+I · Ctrl+Shift+X · Ctrl+Shift+H · Ctrl+Shift+C 도 — 맨 H·C 는 줄 종류 키입니다) |
| **F2** · **Enter** | 그 줄의 칸을 열고 같은 글을 골라 둡니다 |
| **Esc**, **↑·↓** | 고르기를 풉니다 (↑·↓ 는 현재 줄도 옮깁니다) |

- 낱말은 띄어쓰기로 나눕니다. 그 줄(원문 한 줄) 안에서만 움직이고, 끝 낱말에서 → 를 눌러도 다음 줄로 넘어가지 않습니다. 마우스로 끌어 고른 것도 같은 키로 넓힙니다.
- 서식은 누르는 순간 저장되고 화면에 그 모양으로 보입니다. 고른 글은 그대로 남습니다. 굵게·기울임·취소선은 다시 누르면 풀립니다. 형광펜·글자색은 거듭 누르면 다음 색으로 바뀌고 마지막 색 다음에 풀립니다 (형광펜은 노랑 → 초록 → 분홍 → 하늘 → 풀림). 색을 바로 걷으려면 우클릭해 같은 색을 다시 고르거나 **서식 풀기**를 고릅니다. **Ctrl+Z** 로 되돌립니다.
- **B·I·S·M·F 는 글이나 줄을 고른 동안에만 듣습니다.** 아무것도 고르지 않은 현재 줄에서는 두 번 눌러도 아무 일도 하지 않습니다 — 읽다가 누른 글자로 파일이 바뀌지 않게. Shift 는 누르지 않습니다. **Ctrl+B** 도 고른 것이 없으면 늘 하던 대로 사이드바를 감추고 보입니다.
- **한 줄 통째에**: 그 줄을 **세 번 누르면** 줄의 글이 모두 골라지고, 이어서 B·M 같은 키를 누르면 그 줄 통째에 서식이 들어갑니다 (목록·제목의 표시는 그대로). 여러 줄은 Shift+↑·↓ 로 고른 뒤 누릅니다.
- 고른 글을 우클릭하면 그 글의 선택 상자가 나옵니다 — 고른 글 복사(옆의 터미널 버튼은 터미널에 넣기), 서식과 색, 서식 풀기, 여기서 편집, 고른 글 담기·문서로 보내기, 새 메모로 보내기. 고른 글이 형광펜 안이면 **메모 달기**·**이 형광펜 지우기**가 나옵니다 (아래). 그 블록의 보통 메뉴(표 복사 등)는 맨 아래 **이 블록의 메뉴…** 입니다.
- 고르는 동안 Shift+→ 는 터미널로 보내지 않고 넓히기입니다. 터미널로 보내려면 Esc 로 풀고 누릅니다.
- 되지 않는 경우는 알립니다: 여러 줄에 걸쳐 고른 것(줄을 골라 줄 전체에 하세요), 표의 칸을 넘어 고른 것, 굵게 같은 서식의 가운데부터 밖까지 걸쳐 고른 것, 수식·각주가 든 줄(F2 로 열어 칸 안에서 하세요).

### 형광펜으로 표시하고 다시 보기

형광펜은 모양만이 아니라 '나중에 다시 볼 곳' 표시로도 씁니다. 칠하는 법은 위 '글 고르기와 서식' — 낱말을 두 번 눌러 고르고 **M** 입니다.

예제 — [02 읽기 기능](../../samples/guide/02-읽기-기능.md)의 '읽으며 표시하기': 칠해 둔 곳을 사이드바와 F8 로 다시 봅니다.

- **돌아가기**: 사이드바 '문서'의 **형광펜** 하위 묶음에 칠한 곳이 문서별로 나옵니다. 누르면 그 문서의 그 줄로 갑니다. 거르기 칸에 글을 치면 칠한 글로도 거릅니다. 문서 안에서는 **F8** 이 다음 형광펜, **Shift+F8** 이 앞의 형광펜으로 가서 그 칠한 글을 고릅니다 — 이어서 M 으로 색을 바꾸거나, 우클릭해 메모를 달거나 지웁니다.
- **메모 달기**: 사이드바의 형광펜 줄이나 문서 안의 칠한 글(F8 로 고르거나 그 안의 낱말을 두 번 눌러 고른 채)을 우클릭해 **메모 달기**를 고르면 메모 패널에 칠한 글을 제목으로 한 메모가 생기고 바로 내용을 씁니다. 메모의 '그 자리로 가기'로 돌아오고, 문서가 바뀌어 줄이 밀려도 그 글로 찾아갑니다.
- **지우기**: 사이드바의 형광펜 줄이나 문서 안의 칠한 글을 우클릭해 **이 형광펜 지우기**, 사이드바의 문서 행을 우클릭해 **이 문서의 형광펜 모두 지우기…** (색이 여럿이면 색마다도). 모두 지울 때는 몇 곳인지 묻습니다. 글은 그대로 두고 칠한 것만 걷고, **Ctrl+Z** 한 번으로 되돌립니다. 다른 문서의 형광펜이면 그 문서를 먼저 열어 보여 준 뒤 지웁니다. 여러 문서를 한꺼번에 지우는 길은 두지 않았습니다.

### 새 문서 만들기

- 여는 법: 사이드바 '파일' 탭의 묶음 머리줄에 있는 **만들기**(펼친 묶음에만 보입니다), **Ctrl+N**, 문서 탭 줄의 **+**, 트리의 문서·폴더·빈 곳을 우클릭한 **새 문서 만들기…**. 처음 위치는 그 폴더입니다. Ctrl+N 과 **문서**의 **만들기**는 지금 보는 문서나 폴더 개요의 폴더, **코드**·**자료**·**폴더**의 **만들기**는 그 목록에서 고른 폴더(파일을 골랐으면 그 폴더, 고른 것이 없으면 프로젝트 맨 위)입니다.
- **종류**는 연 곳에 따라 다릅니다. **문서**의 만들기는 md 문서·Lectern 슬라이드·폴더, **코드**는 코드 파일·폴더, **자료**는 자료 파일·폴더이고, **폴더**의 만들기와 Ctrl+N 은 다섯 모두입니다. 코드·자료 목록의 폴더를 우클릭한 **새 코드 파일 만들기…**·**새 자료 파일 만들기…** 와 명령 찾기(Ctrl+Shift+P)의 같은 이름도 됩니다.
- **제목**이 파일 이름이 됩니다. 처음 값은 '새 문서' 입니다. **스타일**은 최근에 쓴 것이 골라져 있고 ↑·↓ 로 바꿉니다. 종류에서 **Lectern 슬라이드**를 고르면 첫 장의 템플릿을 고릅니다.
- **위치**에서 프로젝트 맨 위나 다른 폴더를 고릅니다. 비어 있는 폴더도 나옵니다. **새 폴더…** 는 고른 위치 안에 폴더를 만들고 그 폴더를 고릅니다. 트리·프로젝트 탭의 우클릭 **새 폴더 만들기…** 도 같습니다. 빈 폴더는 트리에 나오지 않으므로 바로 새 문서 창이 열립니다.
- `# 제목` 한 줄로 만들고 새 문서 탭에서 제목 아래 칸이 열려 바로 씁니다. 번호가 있는 스타일이면 보기 머리글 두 줄을 넣고 첫 머리글을 골라 두니, 치면 번호는 두고 글만 바뀝니다.
- **코드 파일**은 **이름**에 확장자까지 적습니다 (`정리.py`, `설정.json`). 처음 값의 확장자는 그 프로젝트에 가장 많은 것이고, 확장자를 빼고 적으면 그것이 붙습니다. 만들 수 있는 것은 사이드바 '코드' 목록에 나오는 형식입니다(html·ipynb 는 빼고). 빈 파일을 만들어 새 문서 탭의 편집 모드로 엽니다. 만들기만 하고 실행하지 않습니다.
- **자료 파일**은 `.csv`·`.tsv`·`.txt` 입니다. CSV·TSV 는 **머리행**에 열 이름을 쉼표로 적으면(예: `날짜, 품목, 금액`) 첫 줄이 되고, 비워 두면 빈 파일입니다. CSV 에는 한국어 엑셀이 바로 열어도 한글이 깨지지 않게 UTF-8 BOM 을 붙이고, 편집 모드로 고쳐 저장해도 그대로 둡니다. 새 문서 탭의 편집 모드로 엽니다.
- **폴더**는 이름만 적습니다. 빈 폴더는 목록에 나오지 않으므로 만든 뒤 창을 닫지 않고, 그 폴더를 위치로 해서 그 안에 만들 것을 고르게 합니다. 그만두려면 Esc.
- 종류를 바꾸면 쓴 이름은 그대로 두고 확장자만 그 종류의 것으로 바꿉니다 (`분석 메모` → 코드 파일 `분석 메모.js`).
- 같은 이름이 없을 때만 만듭니다. 안 되면 까닭이 나오니 제목을 고칩니다. Esc 는 닫기.
- 쓰기 전에 닫아도 파일은 남습니다. 필요 없으면 트리에서 우클릭해 **문서 삭제…** 합니다.

### 한 줄 편집

줄을 화면의 그 자리에서 고칩니다. 현재 줄에서 **Enter** 나 **F2** 를 누르면 그 줄이 열립니다. 두 번 누르기는 낱말을 고를 뿐 칸을 열지 않습니다 — 낱말을 고른 채 F2 를 누르면(우클릭 **여기서 편집**도 같습니다) 그 낱말을 고른 채 열립니다. 보통 줄의 우클릭 메뉴에 있는 **전체 편집으로 열기**(Ctrl+E)는 전체 편집기를 그 줄에서 엽니다 (아래 '전체 편집'). 제목은 제목 크기, 목록은 글머리표, 강조글은 강조글 안 그대로이고, `#`·`-`·`>`·`1.`·`[ ]` 같은 표시는 잠겨 글만 고칩니다. 굵게·링크 같은 문장 속 서식은 `**굵게**`·`[링크](주소)` 처럼 원문 글자로 보입니다.

- **Enter** 로 원문 파일에 바로 저장하고 닫으며 현재 줄은 다음 줄로 옮겨 갑니다 (마지막 줄이면 그대로). **Esc** 는 그만둡니다. 칸 밖을 누르면 고친 것이 있을 때 저장합니다. 저장하면 화면이 다시 그려지고 바뀐 곳이 잠깐 강조됩니다.
- **↑·↓** 는 저장하고 위·아래 줄을 이어서 고칩니다. 글이 화면에서 여러 줄로 꺾여 있으면 먼저 그 안에서 움직이고, 맨 윗줄·맨 아랫줄에서 넘어갑니다. 그 줄을 Claude 에 보내려면 Enter(또는 Esc)로 칸을 닫고 **Shift+→** 를 누릅니다.
- **표**: 행에서 F2 를 누르면 첫 칸이, 칸의 낱말을 두 번 눌러 고르고 F2 를 누르면 그 칸이 열려 칸마다 고칩니다. **Tab**·Shift+Tab 으로 옆 칸 — 행의 끝 칸에서 Tab 은 다음 행 첫 칸, 첫 칸에서 Shift+Tab 은 앞 행 끝 칸이라 표를 줄줄이 채웁니다. ↑·↓ 는 위·아래 행의 같은 칸. 칸 글의 `|` 는 `\|` 로 저장되어 칸이 나뉘지 않습니다.
- 여러 줄로 나눠 쓴 문단은 그 줄만, 코드 블록과 코드 화면은 그 줄을 고칩니다. 그림은 F2 로 원문 줄을 엽니다. 수식·다이어그램·차트는 F2 로 원문을 펼쳐 줄마다 고칩니다. HTML 과 주석은 상태줄의 **원문 줄 보기**로 고칩니다. CSV·텍스트 같은 자료 파일은 F2·Enter 가 그 줄에서 **편집 모드**를 엽니다 (아래 'CSV·텍스트 파일'). 엑셀과 로그(`log`)는 볼 수만 있습니다.
- 칸 안에서 고친 것 없이 칸 밖을 누르면 저장하지 않고 끝납니다.
- 장 하이라이트 중에 고치면 회색이 걷혀 위아래 글이 그대로 보이고, 끝내면 다시 회색이 됩니다.
- **할 일**: 본문의 체크 칸을 누르면 원문의 `[ ]`·`[x]` 가 바뀌어 바로 저장됩니다. 예제처럼 보기만 하는 프로젝트에서는 바뀌지 않습니다.
- 저장한 뒤 **Ctrl+Z** 를 누르면 그 줄을 고치기 전으로 되돌려 저장합니다. 거듭 누르면 그 앞 것도. 되돌린 것은 **Ctrl+Y** 로 다시 합니다. 되돌리기는 파일마다 따로라 다른 문서를 고친 뒤에도 앞 문서로 돌아가 되돌릴 수 있습니다. 되돌린 뒤 새로 고치면 다시 하기는 없어집니다.

### 줄 더하기·옮기기·지우기

칸에서나 고른 줄에서(현재 줄 하나면 키를 두 번 눌러) 줄의 구조를 바꿉니다. 칸에 고친 글이 있으면 먼저 저장하고 바꾸므로 되돌리기는 두 걸음입니다. 되지 않는 것은 그대로 두고 까닭을 알립니다.

- **새 줄**: **Shift+Enter** 는 아래에, **Ctrl+Shift+Enter** 는 위에 새 줄을 엽니다. 칸을 열지 않아도 현재 줄에서 같은 키가 됩니다 (여러 줄을 고른 동안에는 되지 않습니다). 앞 줄의 형식을 물려받습니다 — 목록은 같은 표시(하위 항목이 있으면 그 뒤에), 번호 목록은 다음 번호, 인용·강조글은 그 안, 문단·제목 아래는 문단입니다. **위에 넣을 때는 위 블록을 따릅니다** — 문단·제목 위인데 바로 위가 목록·인용·강조글이면 그것을 이어 그 끝에 열립니다 (문단이 필요하면 새 줄에서 Shift+Tab). 목록 항목·인용 줄 위에서는 그 줄과 같은 양식입니다 (첫 항목 위면 새 첫 항목). 빈 새 줄에서 넣기 창(/)으로 목록·번호 목록·할 일을 고르면 바로 위·아래의 같은 종류 목록에 붙습니다 (번호 목록 아래면 다음 번호). 표에서는 새 행, 차트·수식에서는 그 앞뒤 문단입니다. 글을 쓰기 전에는 파일이 바뀌지 않습니다.
- **줄 더하기는 어디서나 같은 키입니다**: 읽는 화면에서도 칸 안에서도 **Shift+Enter**(위에는 Ctrl+Shift+Enter), 문서 중간에서도 끝에서도 같습니다. **↓** 는 줄을 옮기기만 하고 마지막 줄에서 멈추며, 그때 줄을 더하는 키를 알려 줍니다. 빈 문서는 F2 나 ↓ 로 첫 줄을 엽니다. **Enter** 는 새 줄이든 있던 줄이든 저장하고 닫으며, 현재 줄은 다음 줄로 옮겨 갑니다 (다음 줄을 열지는 않습니다 — 마지막 줄이면 그 줄에 그대로, **Ctrl+S** 는 그 줄에 머뭅니다). 그래서 Enter·Enter 로 줄을 차례로 열고 닫으며 훑어 고칩니다. 이어서 아래에 쓰려면 **Shift+Enter** — 저장하고 아래에 새 줄을 엽니다. **Ctrl+Enter** 는 저장하고 닫은 뒤 그 줄을 선택(하이라이트)해, 바로 옮기거나 서식을 입힙니다. 빈 새 줄의 Enter·Ctrl+Enter 는 아무것도 넣지 않고 닫습니다. 표·코드 블록 뒤에 문단을 더하려면 그 블록에서 **/** 를 누릅니다 — 넣기 창이 블록 뒤에 열립니다 (그 블록의 Shift+Enter 는 새 행·새 코드 줄). 각주가 있으면 본문 마지막 줄에서 더한 줄은 각주 앞에 들어갑니다.
- **목록 끝내기**: 빈 새 항목에서 **↓** 나 **Shift+Tab** 은 한 레벨 밖으로 나가고, 맨 바깥이면 문단이 되어 목록이 끝납니다. **Tab** 은 윗 항목의 하위로 들어갑니다.
- **나누기·합치기**: 글 가운데서 **Shift+Enter** 를 누르면 그 자리에서 두 줄로 나눕니다. 줄 맨 앞에서 **Backspace** 를 누르면 윗줄 끝에 잇습니다 — 문단은 문단끼리, 목록은 목록끼리, 코드는 그 블록 안에서만입니다. 제목과 문단처럼 종류가 다르면 합치지 않습니다.
- **옮기기**: **Alt+↑·↓** 로 줄을 옮깁니다. 목록 항목은 하위 항목과 함께 같은 목록 안에서, 문단은 앞뒤 블록과 맞바꾸고, 여러 줄로 나눠 쓴 문단의 한 줄은 그 문단 안에서, 코드는 그 블록 안에서, 표의 행은 머리행 아래에서 옮깁니다. 옮긴 뒤에도 고른 줄이 따라가 거듭 옮길 수 있습니다. 문서 끝의 각주와 본문은 서로 넘어가지 않습니다.
- **지우기**: 줄을 고르고 **Delete**(또는 우클릭 '줄 지우기'), 칸에서는 **Ctrl+Shift+K** 입니다. **Ctrl+X** 는 원문을 복사하고 지웁니다. 10줄이 넘거나 제목이 들어 있으면 먼저 묻습니다. 지운 뒤 빈 줄이 겹치면 하나로 줄이고, 남는 하위 항목은 지운 항목의 자리로 올립니다.
- 표의 머리행이나 구분 줄만 지우면 표가 깨지므로 막습니다 (표 전체를 고르면 표째 지웁니다). 코드 블록의 일부와 그 밖의 줄을 함께 지우는 것도 막고, 코드 줄을 모두 고르면 블록째 지웁니다.
- **복제**: 칸에서 **Ctrl+Shift+D** 를 누르면 아래에 같은 줄을 만들고 그 줄을 이어서 고칩니다. 표의 행은 복제하지 않습니다. 전체 편집에서도 **Ctrl+Shift+D** 는 복제, **Ctrl+Shift+K** 는 줄 지우기입니다.
- 칸 안에서도 **F1**·**Ctrl+/**·**Ctrl+W**·**Ctrl+Tab**·**Alt+1~9**·**Ctrl+P** 같은 앱 키가 듣습니다 — 칸을 저장하고 닫은 뒤 그 일을 합니다.
- 번호 목록은 더하고 옮기고 지울 때 뒤 번호를 다시 매깁니다. 모두 `1.` 로 쓴 목록은 그대로 둡니다. 번호까지 **Ctrl+Z** 한 번으로 돌아옵니다.
- 코드 화면과 슬라이드에서도 됩니다. HTML 문서·자료 파일(CSV·텍스트·엑셀 — CSV·텍스트는 편집 모드로 고칩니다)과 보기만 하는 프로젝트에서는 하지 않습니다.
- UTF-8 이 아닌 파일은 볼 수만 있습니다. EViews 프로그램(`prg`)처럼 Windows 인코딩으로 쓴 파일은 코드 화면과 검색에서 한글이 그대로 보이지만, 한 줄 편집과 편집 모드로는 고치지 않습니다. 글이 모두 영문인 `prg` 는 고칠 수 있고, 한글을 넣으면 파일이 UTF-8 로 바뀌어 EViews 에서 깨지므로 저장하지 않습니다.

### 줄 종류와 제목 수준

표시(`#`, `-`, `>`)는 잠겨 있으니 키와 메뉴로 바꿉니다. 키는 칸이나 고른 줄에서 듣고, 현재 줄 하나면 두 번 누릅니다 (서식 키 B·I·S·M·F 는 다릅니다 — 아래).

- **한 글자 키**: 줄을 고른 뒤(Shift+↑·↓·Shift+누르기) 글자 하나만 누릅니다. 현재 줄 하나면 두 번 누릅니다 — **1~6** 제목, **0**·**P** 문단, **H** 제목 수준을 차례로(제목 2 → 3 → 1 → 문단), **L**·**-** 목록, **N** 번호 목록, **T** 할 일, **Q** 인용, **C** 강조글(강조글이면 다음 종류 — 참고 → 팁 → 중요 → 경고 → 주의). 같은 키를 다시 누르면 문단으로 돌아갑니다(할 일은 목록으로). 바꾼 뒤에도 고른 채 남아 **Tab** 으로 레벨을 이어 바꿀 수 있습니다. 한/영을 바꾸지 않아도 되고, Lectern 모바일과 같은 키입니다. 현재 줄에서 처음 누른 키는 그 줄을 잡기만 합니다 — 읽다가 잘못 눌러 파일이 바뀌지 않게.
- **서식 키**: **B** 글을 통째로 굵게, **I** 기울임, **S** 취소선, **M** 형광펜, **F** 글자색 (형광펜·글자색은 거듭 누르면 다음 색, B 를 다시 누르면 굵게를 풂). 이 다섯은 고른 줄(한 줄이면 Ctrl+Enter 나 세 번 누르기)과 고른 글에서만 듣고, 현재 줄에서는 두 번 눌러도 하지 않습니다 — 위 '글 고르기와 서식'.
- 칸 안에서는 글자가 들어가므로 **Ctrl+Alt+1~6**(제목)·**Ctrl+Alt+0**(문단)을 씁니다. 고른 줄에서도 되고, 숫자 키처럼 같은 수준을 다시 누르면 문단으로 돌아갑니다. 칸 밖에서는 우클릭 **이 줄 바꾸기…**(키는 **.**)로 목록, 번호 목록, 할 일, 인용, 강조글로도 바꿉니다.
- **바꾸기 창**: 칸 밖의 현재 줄이나 고른 줄에서 **.**(마침표)를 누르거나 우클릭 **이 줄 바꾸기…** 를 고르면 넣기 창과 같은 판이 뜹니다 (표·강조글·코드 블록은 우클릭 메뉴에 없으니 **.** 으로 엽니다). 지금 종류에 '지금' 표시가 있고 거기서 시작합니다. 맨 앞 열 **이 줄에 맞는 것**에는 그 자리에 맞는 바꾸기가 있습니다 — 목록이면 **이 목록 전체를 번호 목록으로**(글머리 목록으로·할 일로)와 **목록을 표로**, 표면 **표를 목록으로**·**이 표를 차트로**, 강조글이면 **강조글 풀기**, 코드 블록이면 **코드 풀기**, 표·코드 블록이 아니면 **코드로 감싸기**, 그리고 **바꿔 쓰기 요청**. 바꿀 수 없는 것은 흐리게 보이고, 누르면 까닭을 알려 줍니다.
- **목록을 표로**는 항목마다 한 행이고, 항목 글에 탭·' — '·': ' 이 있으면 거기서 칸을 나눕니다 (머리행은 '항목·값' — 고쳐 쓰면 됩니다). 하위 항목이 있는 목록은 바꾸지 않습니다. **표를 목록으로**는 본문 행마다 한 항목이고 칸을 ' — ' 로 잇습니다 (머리행은 뺍니다). 표에 캡션이 있으면 함께 지울지 묻습니다. 코드로 감싸고 풀 때는 글을 표시까지 그대로 둡니다.
- **바꿔 쓰기 요청**은 '이 문단 셋을 표로', '표를 글로 풀어'처럼 글을 다시 써야 하는 바꾸기를 AI 에게 맡깁니다. 줄 위치를 담은 요청 글이 터미널에 들어가고(Enter 는 누르지 않음), 끝의 '바꿀 모양:' 뒤에 원하는 모양을 적고 Enter 를 누릅니다.
- **Alt+Shift+←·→** 는 레벨을 바꿉니다. 제목은 하위 절까지 함께, 목록은 하위 항목까지 함께 옮깁니다. 목록 줄에서는 **Tab**·**Shift+Tab** 도 같습니다. 제목은 **Tab** 으로 바꾸지 않습니다 (누르면 키를 알려 줍니다). 제목 한 줄의 수준만 바꾸려면 숫자 키나 vi 키의 `>>`·`<<` 를 씁니다.
- 여러 줄을 골라 레벨을 바꾸면 위에서부터 옮기되, 앞 줄과 함께 옮겨진 하위 항목·하위 절 제목은 다시 옮기지 않습니다.
- **이웃은 뜻이 깨질 때만 따라 고칩니다.** 번호 목록에서 줄을 문단·제목·다른 목록으로 바꾸면 뒤 항목의 번호를 앞 항목에 잇습니다 (모두 `1.` 로 쓴 목록은 그대로). 목록으로 바꾸는 줄의 바로 위·아래가 같은 종류의 목록이면 거기에 붙습니다 — 그 목록의 표시와 다음 번호로 (할 일은 글머리 목록에도 붙습니다). 강조글·인용 안의 줄은 안에서 바뀌고 강조글의 머리 줄은 그대로입니다. 하위 항목을 문단으로 바꾸면 부모 항목 안의 문단이 됩니다. 캡션 줄(`표 1. …`)은 종류를 바꾸지 않습니다. 인용 글을 문단으로 바꾸면 인용 밖으로 나옵니다 (Q 를 다시 누른 것과 같습니다). 인용·강조글 안과 밖의 줄을 함께 고르면 바꾸지 않고 까닭을 알립니다.
- 고른 줄 밖이 함께 바뀌면 알려 줍니다 — '하위 절 제목 2개도 함께 옮겼습니다', '뒤 항목 3개의 번호를 다시 매겼습니다', 번호를 단 제목 문서에서는 '제목 번호 4곳을 다시 매겼습니다', 제목을 문단으로 바꿔 그 제목을 가리키던 링크가 남으면 '없어진 제목을 가리키는 링크 1곳이 남았습니다'. Ctrl+Z 한 번으로 모두 되돌립니다.
- 목록 항목끼리 종류를 바꾸면(N·L·T) 들여쓰기를 지킵니다. 하위가 있는 항목을 제목·문단으로 바꾸면 하위 항목이 그 자리로 올라옵니다.
- 여러 줄을 고른 뒤 누르면 한 번에 바꿉니다. 문단 여러 개를 고르고 **L** 을 누르면 목록 하나, **C** 를 누르면 강조글 하나가 됩니다. 메뉴로는 우클릭 **고른 줄 바꾸기…** 입니다 — 창의 각 항목 옆에 그 키가 보입니다.
- **번호가 있는 제목**: 문서가 번호를 쓰면 제목을 더하고 옮기고 지울 때 번호를 다시 맞춥니다. 번호까지 **Ctrl+Z** 한 번으로 돌아오고, 이 문서 안의 절 링크도 함께 고칩니다. 칸에서는 번호가 잠깁니다. `참고문헌`, `부록`, `붙임`, `요약` 같은 절에는 번호를 달지 않습니다.
- **절 다루기**: 제목 한 줄을 고르고 **Alt+↑·↓** 를 누르면 같은 수준의 앞뒤 절과 본문까지 바꿉니다. 제목을 우클릭해 **절 지우기**를 고르면 본문과 하위 절까지 지웁니다. 마지막 절을 옮기거나 지워도 문서 끝의 각주는 그대로 남습니다.

### 구성 요소 넣기

현재 줄에서 **/** 를 누르거나 탭 막대 오른쪽 끝의 **넣기** 단추를 누르면 그 줄 아래에 새 줄이 열리고 넣기 창이 뜹니다. 창이 넓으면 글·강조글·자료·주·참조·쪽 다섯 묶음이 열로 한 번에 보입니다 — ↑↓ 는 열 안에서, ←→ 는 옆 열로. '글' 묶음의 **날짜**·**특수 문자**는 글 속에 넣는 것입니다 — 특수 문자는 아래 새 줄이 아니라 현재 줄 끝에 들어갑니다 (아래 '특수 문자'). 맨 앞 열 **최근**에는 최근 넣은 다섯 가지가 있고 그 첫 항목이 골라져 있어, 같은 것을 거듭 넣을 때는 `/` 와 Enter 두 번이면 됩니다. 글자를 치면 거릅니다 (`표`, `박스`, `주`) — 자음만 쳐도 첫소리로 거릅니다 (`ㅍ` 표, `ㅉㄴ` 쪽 나눔). 칸 안에서는 빈 줄이면 **/**, 글이 있는 줄이면 **Ctrl+Shift+/** 입니다 (현재 줄에서도 되고, vi 키를 켰으면 `/` 가 찾기라 이 키를 씁니다). 마우스는 우클릭 **여기에 넣기…** 입니다 — 표에서는 표 아래에 넣습니다. 여러 줄을 고른 동안에는 넣지 않습니다.

- **글**: 제목, 문단, 목록, 번호 목록, 할 일, 인용. 고른 뒤 글을 쓸 때 파일에 들어갑니다. `## `, `- ` 를 직접 쳐도 됩니다.
- **표**: 크기를 `3x4`(열 x 행)처럼 정합니다. `표 1. 제목` 캡션을 다음 번호로 함께 넣고 '제목'을 골라 두니 바로 칩니다. ↓ 로 표에 들어가 **Tab** 으로 칸을 채웁니다. 마지막 칸의 Tab 과 **Shift+Enter** 는 새 행, **Ctrl+Shift+Enter** 는 위에 새 행입니다. 열은 칸을 우클릭해 더하고 지우고 옮기고 맞춥니다.
- **강조글**: 참고, 팁, 중요, 경고, 주의. 빈 새 줄에서 **↓** 를 누르면 강조글 밖으로 나갑니다. 우클릭으로 종류를 바꾸고, 풀고, 지웁니다.
- **박스글**: 넣기 창에서 **박스글**을 고르면 여는 줄, 제목(`박스 1. 제목`), 내용 한 줄, 닫는 줄을 넣고 제목 줄을 엽니다. 이미 쓴 글은 줄을 고른 뒤(한 줄이면 고르지 않고 그 줄에서) 우클릭 **박스글로 묶기** 로 감쌉니다 — 제목 줄에 걸치면 묶지 않습니다. 안의 줄은 보통 줄처럼 고치고, 박스글을 더하거나 옮기면 번호와 `[박스 1](#박스-1)` 링크를 함께 고칩니다. 박스글 안에서 우클릭하면 **박스글 풀기**(두 표시 줄만 빼고 글은 그대로)와 **박스글 지우기**가 있습니다. Claude Code 와 나눈 대화를 문서에 남기려면 줄에서(또는 줄을 고른 뒤) 우클릭 **Claude 에 박스글 요청** 을 누릅니다. 터미널에 '지금까지의 대화를 정리해 `@문서 12행` 바로 뒤에 박스글로 넣어 줘'라는 요청 글이 들어가고, Enter 를 누르면 Claude 가 그 자리에 박스글을 씁니다 — 자리는 그 줄이 든 블록의 뒤, 고른 줄이면 끝 줄의 뒤입니다. Lectern 은 요청 글만 넣고 파일은 Claude 가 고칩니다. 요청 글은 보내기 전에 고쳐 쓸 수 있습니다.
- **주**: 글 가운데서 **Ctrl+Alt+F** 를 누르면 그 자리에 표시를 넣고 주 내용을 묻습니다. 본문과 내용을 함께 저장합니다. 주 표시 위에서 누르면 그 주를 고칩니다. 번호는 나온 차례로 저절로 매겨지고 내용은 문서 끝에 모입니다. 표시를 지우면 내용도 지울지 묻습니다.
- **그림**: 프로젝트의 그림 파일을 고릅니다. `그림 1. 제목` 캡션을 함께 넣습니다. 그림을 복사해 **Ctrl+V** 로 붙이거나 끌어 넣으면 문서 옆 `문서이름-그림` 폴더에 PNG 로 저장합니다 (현재 줄 뒤에 — 여러 줄을 고른 동안에는 넣지 않습니다). 덮어쓰지 않습니다.
- **수식·다이어그램·차트**: 보기를 넣고 화면 옆 패널을 엽니다. 있는 것은 **F2** 로 엽니다. 수식·다이어그램은 줄마다 칸으로 고치고, 값이 문서 안에 있는 차트는 값을 표로 고칩니다. 그린 결과는 그 자리에 보입니다. **Esc** 로 접습니다.
- **출처 줄·표 주**: `자료: `, `주: ` 로 시작하는 줄을 엽니다. 표 바로 아래의 이런 줄은 작은 글자로 보입니다.
- **링크**: **Ctrl+K** 로 프로젝트의 파일을 고르거나 주소를 씁니다. 고른 글이 있으면 그 글에 겁니다.
- **첨부**: 프로젝트의 파일을 고르면 문서 끝(각주 앞)의 `## 붙임` 절에 번호와 링크를 더합니다. 절이 없으면 만듭니다. 파일을 복사하지는 않습니다.
- **부록**: `## 부록 A. 제목` 을 다음 글자로 넣습니다. 본문 번호에 들지 않습니다.
- **상호 참조**: 표·그림의 캡션이나 절을 골라 `[표 3](#표-3)` 같은 링크를 넣습니다. 누르면 그 자리로 갑니다. 문장 가운데서는 **Ctrl+Shift+/** 로 엽니다.
- **본문 인용**: `## 참고문헌`(또는 `## References`) 절의 목록에서 문헌을 골라 `(김영삼, 2026)` 을 넣습니다. 창에 문헌마다 본문에 인용한 수가 나오고, 아직 쓰지 않은 문헌이 몇 개인지 알려 줍니다. APA 같은 서식 맞추기는 Claude 에게 요청합니다.
- **목차·표 목차·그림 목차**: `[목차]` 한 줄을 넣으면 그 자리에 제목 목차가 그려집니다 (문서 제목은 빼고 세 단계까지). 표 목차·그림 목차는 번호가 붙은 캡션을 모읍니다. 인쇄·PDF 를 위한 것이고 오른쪽 목차는 그대로입니다.
- **쪽 나눔**: 화면에는 점선과 '쪽 나눔' 으로, 인쇄에서는 다음 쪽으로 넘어갑니다. 다른 뷰어에서는 보이지 않습니다.

**캡션 번호**: 표·그림 캡션의 번호가 1, 2, 3… 차례대로인 문서에서 표·그림을 넣거나 옮기거나 지우면 번호를 다시 매기고, 그 표를 가리키는 상호 참조 링크도 함께 고칩니다. 같은 저장이라 Ctrl+Z 한 번으로 되돌립니다. 링크가 아닌 '표 3' 같은 글자는 다른 문서를 가리킬 수 있어 고치지 않고 몇 곳인지 알려 줍니다 — Ctrl+F 로 찾아 확인하세요. 캡션 하나의 번호만 손으로 고친 것과 '표 2-1' 처럼 장 번호가 든 캡션은 그대로 둡니다.
- **머리 설정**: 맨 위의 문서 정보를 우클릭해 **문서 정보 고치기**를 고르면 키는 잠그고 값만 고칩니다.

### 서식과 붙여 넣기

- **문장 속 서식**: 칸 안에서 글을 고르고 키를 누릅니다. 같은 키를 다시 누르면 풉니다. 표의 칸에서도 됩니다.

  | 서식 | 칸 안의 키 | 줄 전체 (칸 밖) | 원문 |
  |---|---|---|---|
  | 굵게 | **Ctrl+B** | **B** | `**글**` |
  | 기울임 | **Ctrl+I** | **I** | `*글*` |
  | 취소선 | **Ctrl+Shift+X** | **S** | `~~글~~` |
  | 코드 | **Ctrl+\`** | — | `` `글` `` |
  | 형광펜 | **Ctrl+Shift+H** | **M** | `<mark>글</mark>` |
  | 글자색 | **Ctrl+Shift+C** | **F** | `<span style="color:red">글</span>` |

- **형광펜과 글자색은 같은 키를 거듭 누르면 색이 차례로 바뀌고 마지막에 풀립니다.** 형광펜은 노랑 → 초록 → 분홍 → 하늘, 글자색은 빨강 → 파랑 → 초록 → 노랑입니다. 색은 이 몇 가지뿐이고, 스타일에 맞는 농도로 보입니다(어두운 스타일에서도 읽힙니다).
- **칸 안에서도 서식이 보입니다.** 글자는 원문 그대로 두고 모양만 입힙니다 — 굵게 한 글은 굵게, 색을 준 글은 그 색으로, 형광펜은 바탕색으로, 취소선은 줄이 그어져 보이고, `**`·`<mark>` 같은 표시 글자는 흐립니다. 기울임만은 기울여 보이지 않고 물결 밑줄로 보입니다 (저장하면 기울어집니다).
- **고른 글이 없을 때**: 키를 누르면 빈 표시 사이에 커서가 놓여 이어서 씁니다. 커서가 이미 그 서식 안에 있으면 풉니다.
- **우클릭**: 칸 안에서 우클릭하면 서식의 선택 상자가 뜹니다 — 서식과 색, 링크·주, **서식 풀기**. 항목 옆에 키가 보입니다. 고른 글에 하고, 고른 글이 없으면 그 줄의 글 통째에 합니다. 고르면 상자가 닫히고 고른 글이 그대로 남아 이어서 씁니다.
- **줄 전체에 한 번에**: 칸을 열지 않고 줄을 고른 뒤(Shift+↑·↓, 한 줄은 Ctrl+Enter 나 세 번 누르기) **B**·**I**·**S**·**M**·**F** 를 누릅니다. 아무것도 고르지 않은 현재 줄에서는 듣지 않습니다. 목록·제목의 표시는 그대로 두고 글만 감쌉니다. 우클릭 **이 줄 바꾸기…**·**고른 줄 바꾸기…** 창의 '줄 전체의 서식'에서 골라도 됩니다.
- 형광펜과 글자색은 PDF·인쇄와 pptx 전환에도 그대로 나옵니다.
- 여러 줄을 붙여 넣으면 줄마다 나눠 넣습니다. 목록에서는 항목이 됩니다. 되돌리기 한 번으로 돌아옵니다.
- 엑셀 범위를 붙여 넣으면 표로 넣습니다.

### 특수 문자

가운뎃점(·)·줄표(—)·낫표(「」)·참고표(※), 화살표(→ ⇒), 도형(○ ● □ ■ ★), 수학(± × ≤ ≈), 단위·통화(℃ ㎡ ㎏ ₩ €), 원 숫자(① ㉠ ㉮)·로마 숫자(Ⅰ), 첨자(² ₂), 그리스 문자(α Σ) 같은 문자를 자판 없이 넣습니다.

- **여는 곳**: 한 줄 편집 칸·편집 모드에서 **Ctrl+Shift+;**(날짜 넣기 Ctrl+; 옆) — 커서 자리에 넣습니다. 칸 안의 우클릭 메뉴 **특수 문자…** 도 같습니다. 읽는 화면에서는 **Ctrl+Shift+;** 나 넣기 창(`/`)의 **특수 문자** — 현재 줄의 칸을 열고 그 끝에 넣습니다 (아래에 새 줄을 만들지 않습니다).
- **고르기**: 묶음마다 칸으로 나옵니다. 맨 위 줄은 최근 넣은 것(열둘)입니다. 이름으로 거릅니다 — '화살표', '원 숫자', '섭씨', 초성 'ㅅㅆ'(섭씨), 영어 이름도 됩니다. **← ↑ ↓ →** 로 옮기면 아래 줄에 그 문자의 이름이 보이고, **Enter** 로 넣고 **Esc** 로 그만둡니다. 마우스로 눌러도 됩니다.
- 넣은 뒤 칸은 그대로 열려 있어 이어서 씁니다.
- **문서를 깨지 않는 글자만 둡니다**: Markdown 표시로 읽히는 글자(`*` `_` `|` `#` 등)는 넣은 문자가 서식이 되지 않게 뺐습니다. 목록·할 일처럼 보이지만 아닌 글자(• ☐ ☑)와 표의 숫자로 읽히지 않는 빼기 기호(−)도 뺐습니다 — 목록은 `-`, 할 일은 `- [ ]`, 음수는 `-` 로 씁니다. 맑은 고딕·바탕에 없는 글자(✓ ✗ ⑯~⑳ ⁵~⁹ ☀ ✉ 등)도 뺐습니다 — 다른 컴퓨터·PDF·Word 에서 모양이 달라지거나 이모지로 바뀔 수 있습니다.

### Claude 와 함께 고칠 때

Claude Code 가 같은 문서를 고치는 동안에도 사람이 고친 것과 Claude 가 고친 것이 서로를 덮지 않습니다.

- **칸에 쓰던 글**은 그사이 파일이 바뀌어도 사라지지 않습니다. 위쪽에 줄이 더해져 줄 번호만 밀렸으면 같은 줄을 찾아 그 자리에 저장합니다. 그 줄 자체가 바뀌었거나 같은 줄이 둘 이상이면 저장하지 않고, 고친 줄을 클립보드에 복사해 둡니다.
- **고른 줄**은 글을 따라갑니다. 위쪽에 줄이 더해져도 같은 글이 고른 줄로 남고, 그 글이 바뀌거나 없어지면 고르기를 풉니다 — 다른 줄을 지우지 않게.
- **되돌리기**: 그사이 파일이 바뀌었으면 Ctrl+Z 는 되돌리지 않고 알립니다. 남이 고친 것을 덮어쓰지 않게.
- 화면은 1초 안에 다시 그려지고 보던 자리는 그대로입니다 ('자동 새로고침').

### 원문 줄 보기

상태줄의 **원문 줄 보기**는 md 문서를 줄 번호와 함께 코드 화면으로 봅니다. 빈 줄, 주석, HTML 까지 모든 줄을 칸으로 고칩니다. **md 문서로 보기**로 돌아옵니다.

### md 문서 스타일

상태줄의 **md 문서 스타일**이나 우클릭 메뉴에서 엽니다. **문서 방식**과 **머리글 모양**을 고릅니다.

- **문서 방식**은 본문을 쓰는 방식입니다. 서술식은 문장으로 쓰고, 개조식은 짧은 항목으로 씁니다. 지금 방식은 본문을 보고 알려 줍니다.
- **머리글 모양**은 번호와 기호입니다. 고르면 미리보기가 나오고, 적용하면 md 파일의 제목 줄이 실제로 바뀝니다.

| 문서 방식 | 머리글 모양 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|---|
| 서술식 | 번호 없음 (기고문·칼럼) | 개요 | 시장 현황 | 가격 |
| 서술식 | 논문형 (인문·사회 논문) | Ⅰ. 개요 | 1. 시장 현황 | 1) 가격 |
| 서술식 | 숫자형 (이공계 논문·기술 문서) | 1. 개요 | 1.1 시장 현황 | 1.1.1 가격 |
| 서술식 | 장·절형 (학위 논문·단행본) | 제1장 개요 | 제1절 시장 현황 | 1. 가격 |
| 서술식 | 규정형 (규정·지침) | 제1장 개요 | 제1조 시장 현황 | ① 가격 |
| 개조식 | 보고서형 (보고서) | Ⅰ. 개요 | 1. 시장 현황 | 가. 가격 |
| 개조식 | 숫자형 (기획안·계획서) | 1. 개요 | 1.1 시장 현황 | 1.1.1 가격 |
| 개조식 | 기호형 (공문·요약) | □ 개요 | ○ 시장 현황 | - 가격 |
| 개조식 | 번호 없음 (회의록·메모) | 개요 | 시장 현황 | 가격 |

- 같은 방식 안의 머리글 모양은 바로 바뀝니다. Ctrl+Z 로 되돌립니다.
- **문서 방식을 바꾸면 꼭 묻습니다.** 머리글은 앱이 바꾸지만 본문은 내용을 판단해야 하기 때문입니다. **머리글을 바꾸고 본문은 Claude 에게 요청**을 고르면 터미널에 요청 글이 들어가고 Enter 는 직접 누릅니다. **머리글만 바꾸기**를 고르면 본문은 그대로이니 방식은 바뀌지 않습니다.
- 문서 제목(`#` 하나)에는 번호를 달지 않습니다. 본문과 코드 블록은 그대로입니다.
- 이미 붙은 번호는 떼고 새로 매깁니다. `2026년 전망` 같은 제목의 숫자는 번호로 보지 않습니다.
- 이 문서 안의 절 링크는 함께 고칩니다. 다른 문서에서 이 절로 오는 링크는 그대로입니다.
- **이 문서를 스타일로 만들기:** 머리글에 번호를 단 문서에서 누르면 그 번호 모양을 **내 스타일**로 저장합니다. 지금 고르고 있는 방식(서술식·개조식)의 스타일이 됩니다. 프로젝트가 아니라 Lectern 전체에서 씁니다. 파일은 `%APPDATA%\Lectern\md-styles` 에 있고, **스타일 폴더 열기**로 열어 지웁니다.
- 번호 모양이 복잡해서 잘 뽑히지 않으면 **Claude 에게 스타일 요청**을 누릅니다. 터미널에 요청 글이 들어가고, 이름을 적어 Enter 를 누르면 Claude 가 문서를 보고 만듭니다.
- 스타일이 많으면 찾기 칸에 이름, 용도(`논문`), 번호 글자를 칩니다. 최근에 쓴 스타일은 맨 위에 모입니다.

### 전체 편집 (편집 모드)

한 줄 편집으로 되지 않는 일 — 여러 곳을 한꺼번에 손보거나 HTML 문서를 고칠 때 — 은 파일 전체를 편집기로 엽니다. 대부분의 일은 위의 한 줄 편집으로 됩니다.

- 여는 법: 탭 막대 오른쪽 끝의 **편집** 버튼(목차·터미널 버튼 왼쪽 — 다시 누르면 닫힘, 켜져 있으면 강조색과 밑줄), 아래 상태줄의 **편집**, 코드 화면 머리줄의 **편집**, 본문 우클릭 **이 문서 편집**·**전체 편집으로 열기**(그 블록이나 줄에서), 또는 Ctrl+E. 편집기 안에서 **Ctrl+Shift+K** 는 줄 지우기, **Ctrl+Shift+D** 는 줄 복제입니다 (칸 안과 같은 키 — Ctrl+D 는 쓰지 않습니다). 읽던 곳의 원문이 같은 높이에 오게 열립니다.
- **읽는 위치와 이어집니다**: 편집하는 동안 오른쪽 목차는 커서가 있는 절을 표시합니다 (커서가 화면 밖이면 화면 위쪽의 절). 목차·모아 보기·검색 결과에서 이 파일의 곳을 누르면 편집기가 그 줄로 갑니다. 편집을 닫으면 문서 화면이 편집하던 곳에 있습니다 (접힌 절이면 폅니다). HTML 문서는 제목 단위로 이어집니다.
- 줄 번호와 언어 색이 있고, Ctrl+F 찾기, Ctrl+H 바꾸기, Ctrl+G 줄로 가기, F3·Shift+F3 다음·이전 찾기를 씁니다. Tab 은 빈칸으로 들입니다.
- **Ctrl+S** 로 저장합니다. 원래 파일의 줄바꿈(CRLF/LF — 섞여 있으면 많은 쪽)과 BOM, 파일 속성은 그대로 둡니다. 읽기 전용 파일은 저장하지 않습니다. 저장하면 아래의 문서 화면이 고친 내용으로 다시 그려지고, Esc(또는 ✕·Ctrl+E)로 닫으면 보입니다.
- 편집하는 동안 Claude Code 같은 다른 프로그램이 같은 파일을 고쳤으면, 저장할 때 덮어쓸지 묻습니다. 취소하면 저장하지 않고 편집을 이어 갑니다.
- 저장하지 않은 편집이 있으면 편집을 닫거나, 다른 문서로 가거나, 탭이나 창을 닫기 전에 묻습니다.
- UTF-8 글 파일만, 2MB 까지 고칩니다. 새로 만드는 것은 새 문서와 빈 코드·자료 파일, 폴더뿐이고(위 '새 문서 만들기'), 파일 이름은 사이드바에서 바꿉니다(위 '파일'). 자료(PDF·엑셀 등)는 편집하지 않습니다.
- 설정의 **전체 편집 방식**을 **vi 방식**으로 고르면 편집기를 vim 처럼 씁니다. Esc 는 편집을 닫지 않고 Normal 모드로 가며, `:w` 저장, `:q` 닫기, `:wq`·`:x` 저장하고 닫기입니다. 닫기는 Ctrl+E 와 ✕ 도 됩니다. 기본은 **기본 방식**이고, 읽는 화면의 vi 키(아래)와 따로 고릅니다. 한글 입력 상태에서는 Normal 모드 키가 글자로 들어갈 수 있으니 영어 입력으로 씁니다.

### vi 키

설정 창(Ctrl+,)에서 **vi 키**를 켜면 문서에서 글자 키로 움직이고 고칩니다. 기본은 꺼져 있고, 켜면 상태줄에 `vi` 가 보입니다. 줄의 상태가 vi 의 모드와 맞습니다 — 현재 줄은 Normal, 고른 줄은 Visual(V), 칸은 Insert 입니다. 마우스와 기본 키는 그대로 씁니다.

- **움직이기**: `j`·`k` 아래·위 줄, `gg`·`G` 첫 줄·끝 줄, `[[`·`]]` 앞·뒤 제목, `zz` 현재 줄을 가운데로. 앞에 숫자를 치면 그만큼 (`3j`, `12G` 는 12행).
- **접기·찾기**: `zc`·`zo`·`za` 절 접기·펴기·바꾸기, `zM`·`zR` 모두 접기·펴기, `/` 찾기, `n`·`N` 다음·이전, `:` 줄로 가기.
- **쓰기**: `i`·`a` 칸 열기 (커서는 줄 처음·끝), `o`·`O` 아래·위에 새 줄. 칸에서 **Esc** 는 저장하고 나옵니다 (vi 키를 끄면 Esc 는 그만두기).
- **.** 은 vi 키를 켜도 바꾸기 창입니다 (vi 의 반복이 아닙니다).
- **고르고 바꾸기**: `V` 로 현재 줄을 잡고(바꾸는 키의 첫 누름과 같습니다) `j`·`k` 로 넓힙니다. 고른 줄에서 `d` 지우기, `y` 원문 복사, `>`·`<` 레벨, `J` 한 줄로 합치기, `V`·Esc 풀기.
- **한 번에**: `dd` 줄 지우기, `yy`(또는 `Y`) 원문 복사, `>>`·`<<` 레벨 — 그 줄을 고르고 하는 것과 같습니다. `>>`·`<<` 는 제목도 그 줄의 수준만 바꿉니다 (하위 절까지는 Alt+Shift+←·→). 지우거나 복사한 줄은 `p`·`P` 로 현재 줄 아래·위에 넣습니다 (앱 안에 담아 둔 것이라 클립보드와 따로입니다). 표의 행은 표 안에 들어가고, 번호 목록에 넣으면 번호를 다시 매깁니다. 줄 복제는 `yyp`·`Yp`. `u` 되돌리기, 다시 하기는 Ctrl+Y.
- 두 글자 명령은 1초 안에 다음 글자를 칩니다. 그동안 상태줄에 `vi d…` 처럼 보입니다.
- 줄 종류의 한 글자 키(L·N·T·Q·C 등)는 `V` 로 줄을 잡은 뒤 누릅니다 — 현재 줄에서 두 번 눌러 잡지 않습니다. 고른 줄에서 숫자는 횟수라 1~6 으로 제목을 바꾸지 않습니다 — **H** 나 **Ctrl+Alt+1~6** 을 씁니다.
- Ctrl 이 붙은 키는 바꾸지 않습니다 (Ctrl+D 는 여전히 장 복제, Ctrl+F 는 찾기). 쪽 넘기기는 PageUp·PageDown 입니다.
- 한/영 상태와 관계없이 듣습니다.
- 전체 편집기는 따로 고릅니다 — 설정의 **전체 편집 방식**(위 '전체 편집').
- 예제 — [10 vi 키](../../samples/guide/10-vi-키.md): 해 보기와 기본 키와 나란히 본 표, 전체 편집기의 vi 방식.

## Lectern 슬라이드

예제 — [09 Lectern 슬라이드](../../samples/guide/09-Lectern-슬라이드.md)(이 장의 내용을 md 문서로 자세히 적은 안내)와 [슬라이드 예제](../../samples/slides/README.md)(기초·상황별·복잡한 배치).

Lectern 은 세 가지를 구분합니다.

| 말 | 무엇 |
|---|---|
| **md 문서** | 보통 Markdown 문서입니다 |
| **Lectern 슬라이드** | 맨 앞 설정에 `marp: true` 가 있는 md 입니다. 장마다 배치가 다른 슬라이드로 보입니다. 왼쪽 목록에서 주황색 아이콘으로 나옵니다 |
| **pptx** | PowerPoint 파일입니다 |

작업은 이 순서로 합니다.

1. **새로 만들기**에서 템플릿을 골라 첫 장을 만듭니다.
2. 자리의 안내 글을 내용으로 바꾸고, **Ctrl+M** 으로 다음 장의 템플릿을 고르며 이어 갑니다.
3. 발표하거나, pptx 스타일을 골라 **pptx 로 전환**합니다.

### 만들기

- **새 문서 만들기**(Ctrl+N)에서 제목을 쓰고 종류를 **Lectern 슬라이드**로 고릅니다. 템플릿 갤러리에서 첫 장을 고르면 문서가 만들어집니다.
- 있는 md 문서는 사이드바에서 우클릭해 **Lectern 슬라이드로 바꾸기 요청**을 고릅니다. 터미널에 요청 글이 들어가고, Enter 를 누르면 Claude 가 같은 폴더에 새 파일로 만듭니다.
- pptx 를 Lectern 슬라이드로 옮기는 일은 [Claude 에게 시키기](#claude-에게-시키기)에 있습니다.

### 템플릿

템플릿은 제목, 글, 강조글, 차트 자리를 갖춘 장의 뼈대입니다. 프로젝트가 아니라 Lectern 전체에서 함께 씁니다. Lectern 슬라이드 파일 하나가 **묶음**이고 그 안의 장 하나가 템플릿입니다.

- **갤러리:** 템플릿을 미리 보며 고릅니다. 왼쪽에서 묶음을 고르고(PageUp·PageDown), 누르거나, 번호를 치거나, 화살표로 옮겨 Enter 를 누릅니다. 번호는 묶음 안의 장 차례입니다. 글자를 치면 모든 묶음에서 찾습니다. 최근에 쓴 템플릿은 **최근 쓴 것**에 모입니다. 기본 묶음에 템플릿 12개가 들어 있습니다.
- **새 장:** **Ctrl+M** 을 누르면 갤러리가 뜨고, 고른 템플릿이 지금 장 뒤에 들어갑니다. 제목이 바로 열립니다.
- **템플릿 바꾸기:** 장을 우클릭해 **템플릿 바꾸기…** 를 고릅니다. 쓴 글은 새 칸으로 옮겨 담고, 못 담는 글은 맨 아래 칸에 남습니다. 고치지 않은 안내 글은 옮기지 않습니다. Ctrl+Z 로 되돌립니다.
- **내 템플릿 만들기:** 장을 우클릭해 **이 장을 템플릿으로 저장…** 을 고르고 이름을 적습니다. **내 템플릿** 묶음에 더해집니다. 장의 글이 그대로 저장되니 내용은 안내 글로 고쳐 두면 좋습니다.
- **묶음 고치기:** 갤러리의 **템플릿 폴더 열기**를 누르면 템플릿 폴더(`%APPDATA%\Lectern\templates`)가 Lectern 탭으로 열립니다. 묶음을 평소처럼 한 줄 편집과 점검으로 고칩니다. 장 차례가 번호이고, 장 이름은 `<!-- template: 이름 -->` 입니다.
- **Claude 에게 요청:** **Claude 에게 템플릿 요청**을 누르면 터미널에 요청 글이 들어갑니다. 원하는 모양을 이어서 적고 Enter 를 누릅니다.
- **묶음 기억:** 내가 만든 묶음으로 시작한 문서는 맨 앞 설정에 `templates: 회사 보고` 가 적혀, 다음 장도 그 묶음이 먼저 열립니다.

그림이 든 장을 템플릿으로 저장하면 그림의 경로도 그대로 저장됩니다. 다른 폴더의 문서에서는 그림을 못 찾을 수 있습니다.

### 글 쓰기와 장 다루기

- 슬라이드 안의 글은 **한 줄 편집**으로 고칩니다. 칸 끝에서 Shift+Enter 로 더한 줄도 칸 안에 들어가고, 줄을 옮기거나 지워도 칸과 장은 깨지지 않습니다.
- **안내 글**: 템플릿의 안내 글을 열면 글 전체가 골라져 있어 바로 치면 바뀝니다.
- **넣기**: 칸의 빈 줄에서 **/** 를 누르면 제목, 목록, 강조글, 표, 그림, 차트, 다이어그램, 수식, 코드, 출처 줄, 발표자 노트를 고릅니다. 주, 첨부, 부록, 구분선은 슬라이드에 없습니다.
- **서식과 붙여 넣기**: Ctrl+B·I·K·\`, 여러 줄과 엑셀 범위 붙여 넣기, 표의 행과 열, 강조글 메뉴는 md 문서와 같고 모두 칸 안에 들어갑니다. 그림을 붙여 넣으면 칸에 들어가고 **Ctrl+Shift+>·<** 로 폭을 바꿉니다.
- **원문**: 수식·다이어그램은 **F2** 를 누르면 화면 옆 패널에서 줄마다 고칩니다. 칸의 그림은 그대로 보이고 저장할 때마다 바뀝니다. **Esc** 로 접습니다.
- **차트 값**: 차트에서 **F2** 를 누르면 값이 표로 나옵니다. 칸마다 고치고, **Shift+Enter** 로 행을 더하고, **Ctrl+Shift+K** 로 지웁니다. 아래 버튼으로 막대, 선, 영역, 원을 바꿉니다. 값이 다른 파일에 있거나 복잡한 차트는 원문으로 열립니다.
- **표를 차트로**: 표를 우클릭해 **이 표를 차트로**를 고릅니다. 첫 열이 항목, 다음 열들이 값입니다. 이렇게 만든 차트는 pptx 에서 PowerPoint 차트가 되어 거기서도 값을 고칩니다.
- **칸**: 칸의 글을 우클릭해 **칸 꾸밈…**(상자, 강조, 메모 등), **이 칸을 앞으로·뒤로**(글을 맞바꿈), **칸 비우기**를 고릅니다.
- **넘쳤을 때**: 넘친 칸을 우클릭하면 **넘친 줄을 다음 장으로**(같은 배치의 새 장으로 옮김)와 **이 칸 줄이기 요청**(터미널에 요청 글)이 나옵니다. 앱이 저절로 줄이지는 않습니다.
- **발표자 노트**: 우클릭 **발표자 노트 쓰기…**. 장 끝에 주석 한 줄로 들어가고 pptx 의 노트로 갑니다.
- 슬라이드를 우클릭하면 새 장·복제·옮기기·지우기가 있습니다. 키는 Ctrl+M, Ctrl+D, Ctrl+Shift+PageUp·PageDown 입니다. 장 제목 줄의 **Alt+↑·↓** 도 그 장을 옮깁니다. 모두 Ctrl+Z 로 돌아옵니다.
- 오른쪽 목차는 장 목록입니다. 점검할 장은 표시됩니다.
- 슬라이드의 체크 칸을 누르면 원문의 `[ ]`·`[x]` 가 바뀝니다. 발표 중에는 바뀌지 않습니다.
- `<!-- hidden: true -->` 를 쓴 장은 숨긴 장입니다. 화면에 흐리게 나오고 발표와 PDF 에서 빠집니다.

### 칸과 배치

템플릿으로 모자라면 칸을 직접 짭니다.

- `---` 마다 한 장입니다. 크기는 1280×720 입니다.
- `::: a card` 부터 `:::` 까지가 칸입니다. 칸 안에 글·표·차트·그림을 넣습니다.
- `<!-- layout: quad -->` 처럼 배치를 고르거나 `<!-- grid: a a b / c d b -->` 로 직접 그립니다. `::: a at 100 200 300 120` 은 자리를 직접 정합니다.
- 슬라이드를 우클릭해 **배치 넣기…** 를 고르면 그 배치의 빈 칸이 들어갑니다. 칸이 있던 장은 칸 이름만 바뀌고, 칸이 없던 장의 글은 첫 칸으로 들어갑니다. F2 로 글을 채웁니다.
- `<!-- links: a>b, c--d -->` 를 쓰면 칸 사이에 화살표와 선을 긋습니다. 칸의 글은 그대로 고칠 수 있습니다.
- Marp 의 `paginate`·`header`·`footer`·`class: lead`·`invert`·배경색, `![bg right:40%](그림)` 같은 배경 그림과 필터, `style:` 과 `<style scoped>` 의 CSS 를 읽습니다. `theme`(gaia 등)은 읽지 않습니다.

### 글자 크기

- 현재 줄에서 **Ctrl+Shift+>** · **Ctrl+Shift+<** 를 누르면 그 장의 표·강조글·제목 같은 구성 요소가 1pt 커지고 작아집니다. 원문에 `<!-- text: 표 14 -->` 한 줄이 생기고 Ctrl+Z 로 돌아옵니다.
- 크기가 적힌 칸(`::: b 16`)에서는 그 칸의 크기가 바뀝니다. 문서 전체는 맨 앞 설정의 `text: 제목 26, 표 12` 로 정합니다.
- 기본은 제목 30, 소제목 20, 본문 18, 표 14, 강조글 16 입니다. 스타일을 바꿔도 크기는 그대로입니다. 차트와 다이어그램 안의 글자는 칸 크기를 따릅니다.
- 표가 12pt, 본문이 14pt 아래로 내려가면 점검에 나옵니다. 화면에 띄우지 않고 읽는 자료면 맨 앞 설정에 `reading: true` 를 씁니다 (기준 10pt, 12pt).

### 구조 보기와 점검

- 상태줄의 **구조 보기**를 켜면 칸 머리 줄과 지시어·노트 줄이 꼬리표로 나옵니다. 꼬리표를 누르고 F2 로 그 줄을 고칩니다. 칸 꾸밈이나 배치를 이렇게 바꿉니다.
- 넘치면 그림·차트는 칸에 맞춰 줄어듭니다. 글은 줄어들지 않고 잘리며 빨간 점선이 붙습니다.
- 문법 실수도 표시합니다. 칸 이름, 빠뜨린 `:::`, 지시어와 낱말의 오타, 잘못된 격자, 닫지 않은 주석·코드 블록, `---` 바로 위의 글, 풀리지 않은 `**` 입니다.
- 화면에서 재는 것도 있습니다. 바탕과 비슷한 글자, 옆으로 잘린 코드·표, 없는 그림, 그리지 못한 차트입니다. 사진 위의 글은 재지 못하니 눈으로 봅니다.
- 상태줄의 **점검**을 누르면 목록이 나오고, 고르면 그 줄로 갑니다. **목록을 터미널에 붙여 넣기**로 Claude 에게 고쳐 달라고 할 수 있습니다.

### 보기와 발표

- Lectern 슬라이드를 누르면 md 문서처럼 지금 창의 문서 칸에 열립니다. 발표·점검·구조 보기·pptx 로 전환·html 로 전환 같은 슬라이드 도구는 상태줄에 그대로 있습니다.
- 따로 띄워 보려면 왼쪽 목록에서 우클릭 **새 창에서 열기**를 고르거나, 열린 문서 탭에서 **새 창으로 옮기기**(Ctrl+Shift+N)를 고릅니다. 그러면 슬라이드 창이 열립니다 (이미 열려 있으면 그 창이 앞으로 옵니다). 터미널은 메인 창의 것을 씁니다.
- 슬라이드 창의 스타일은 메인 창과 따로 고릅니다. 기본은 **발표** 스타일입니다. 지금 창에서 볼 때는 메인 창의 스타일로 보입니다. 화면 스타일을 바꿔도 pptx 스타일은 바뀌지 않습니다.
- 상태줄의 **발표**(Shift+F5) 나 슬라이드의 ▶ 를 누르면 창 전체에 한 장씩 보입니다. → ← Space·PageDown·PageUp 이나 누르기·휠로 넘기고, **N** 은 발표자 노트, **F** 는 전체 화면, **Esc** 는 끝내기입니다.
- 상태줄의 **문서로 보기**를 누르면 칸을 풀어 보통 문서처럼 이어서 봅니다.
- Lectern 슬라이드에서 본문 여백을 우클릭해 **PDF로 저장…** 을 고르면 슬라이드 크기의 쪽에 한 장씩, 화면과 같은 색으로 PDF 를 만듭니다 (숨긴 장과 발표자 노트는 빠집니다). **인쇄…** 도 한 장에 한 쪽입니다.

### pptx 로 전환

상태줄의 **pptx 로 전환**을 누르고 pptx 스타일을 고르면 문서 옆에 pptx 파일이 만들어집니다. Claude 나 Python 은 없어도 됩니다.

- **pptx 스타일:** Lectern 전체에서 함께 쓰는 양식입니다. 창의 **보관소 폴더 열기**로 폴더(`%APPDATA%\Lectern\pptx-styles`)를 열어 회사 양식 pptx 를 넣으면 목록에 나옵니다. **Claude 에게 스타일 요청**을 누르고 pptx 경로를 적으면 Claude 가 스타일, 같은 이름의 템플릿 묶음, 미리보기 그림을 함께 만듭니다.
- **짝:** 템플릿 묶음과 이름이 같은 pptx 스타일은 짝입니다. '회사 보고' 묶음으로 만든 문서는 '회사 보고' 스타일을 먼저 고릅니다.
- **기억:** 고른 스타일의 이름은 문서의 맨 앞 설정에 `pptxStyle: 회사보고` 로 적힙니다. 다음에는 그 스타일을 먼저 고릅니다. 문서만 다른 PC 로 옮기면 스타일이 없을 수 있습니다. 그때는 알려 주고 다시 고르게 합니다.
- **기본 스타일:** **기본 스타일로**를 켜고 전환하면 스타일을 정하지 않은 문서에 그 스타일이 쓰입니다.
- **적용 차례:** 이번에 고른 스타일, 문서의 스타일(짝 포함), 원본 pptx, 기본 스타일, Lectern 스타일 순서입니다.
- **양식의 내용:** 양식 pptx 의 장과 그림은 결과에 들어가지 않습니다. 장 제목과 표지 그림도 파일 속성에서 지웁니다. 레이아웃에 있는 로고와 꼬리말은 양식의 일부라서 들어갑니다.
- **결과:** 칸의 자리는 Lectern 슬라이드를 따르고, 색·글꼴·로고·꼬리말은 pptx 스타일을 따릅니다. 글은 글, 표는 표, 차트는 값을 고칠 수 있는 차트, 선은 연결선으로 들어갑니다. 복잡한 차트와 Mermaid 는 그림으로 들어갑니다.
- **pptx 에서 옮겨 온 문서:** 스타일을 고르지 않으면 고치지 않은 장은 원본 장이 그대로 쓰이고, 글만 고친 장은 원본 장에서 그 글만 바뀝니다. 디자인과 애니메이션이 살아 있습니다. 칸이나 배치를 바꾼 장만 새로 만듭니다. 그러려면 `문서-변환기록.json` 과 `.pptx-work` 폴더를 지우지 않습니다.
- 같은 이름의 pptx 가 있으면 덮어쓰지 않고 `보고서 2.pptx` 처럼 새 이름으로 만듭니다.

### html 로 전환

상태줄의 **html 로 전환**을 누르면 문서 옆에 impress.js 발표 html 파일이 만들어집니다. 받은 사람은 브라우저로 열어 발표합니다. 장이 한 캔버스 위에 놓이고 화면이 장 사이를 옮겨 다닙니다.

- **배치:** **격자**는 표지·간지(`lead` 장)에서 줄을 바꾸고, 한 줄이 4장을 넘으면 접습니다. **가로 한 줄**도 고를 수 있습니다. 창의 배치 지도에 장 번호가 그 자리에 보입니다. 맨 앞 설정에 `impress: line` 을 적으면 그것이 처음 값입니다.
- **장의 자리 직접 적기:** 장에 `<!-- impress: x=0 y=2400 rotate=90 scale=2 -->` 를 쓰면 그 장이 그 자리에 놓입니다. 적은 축만 바뀝니다. 화면의 모양은 바뀌지 않습니다. **Claude 에게 배치 요청**을 누르면 이야기 흐름에 맞게 자리를 적어 달라는 요청 글이 터미널에 들어갑니다 (Enter 는 누르지 않음).
- **전체 보기:** 켜 두면 맨 끝에 모든 장이 한 화면에 보이는 장이 붙습니다.
- **발표:** → ← Space·PageDown·PageUp 으로 넘기고, **Home**·**End** 는 첫 장·마지막 장입니다. **P** 는 발표자 콘솔(노트·다음 장·시계)을 새 창에 엽니다.
- **파일 하나:** 그림, 스타일, 수식 글꼴, impress.js 가 모두 파일 안에 들어갑니다. 인터넷 없이 열리고 아무 데도 요청하지 않습니다. 메일·메신저로 보내도 됩니다. 인터넷 그림만 주소로 남아 받은 사람의 브라우저가 불러옵니다.
- **넣지 않는 것:** 숨긴 장, 동영상·소리. 프로젝트 안의 다른 문서로 가는 링크는 글로 남습니다. HTML 장에 쓴 `class="step"`·`notes`·`substep` 은 impress 가 장·노트로 읽는 이름이라 결과 파일에서 뗍니다.
- **안전:** 파일 안에서는 impress.js 와 시작 줄만 돌도록 막아 둡니다. 문서에 스크립트가 들어 있어도 받은 사람의 브라우저에서 돌지 않습니다.
- **브라우저로 열기:** 만든 뒤의 **브라우저로 열기**는 이번에 Lectern 이 만든 그 파일만 기본 브라우저로 엽니다.
- **Lectern 에서 열면:** 왼쪽 문서 목록에 html 문서로 나옵니다. Lectern 은 문서의 스크립트를 돌리지 않으므로 장이 위에서 아래로 놓인 문서로 보이고 노트도 보입니다.
- 색·글꼴은 지금 고른 스타일 그대로입니다. 같은 이름의 html 이 있으면 덮어쓰지 않고 `보고서 2.html` 처럼 새 이름으로 만듭니다. md 가 원본이므로 고친 뒤 다시 전환합니다.

### Claude 에게 시키기

예제 — [09 Lectern 슬라이드](../../samples/guide/09-Lectern-슬라이드.md)의 12절 'Claude Code 와 함께': 스킬 설치 순서, 요청 예, 요청 메뉴, 함께 다듬는 차례.

pptx 를 Lectern 슬라이드로 옮기거나 pptx 를 참고해 만드는 일은 Claude Code 스킬이 합니다. 스킬은 Lectern 에 들어 있고, 설치는 사용자가 시킬 때만 합니다. 설정 창의 **PowerPoint·Word 스킬** → **Claude Code용 요청 복사**(또는 옆의 터미널 버튼)로 요청 글을 Claude Code 에 넣으면, Claude 가 무엇을 하는 스킬인지 알려 주고 설치할지 묻습니다. 같은 요청으로 md 문서를 Word 로 만드는 스킬(`lectern-to-docx`)도 함께 설치됩니다 — 앱의 **Word로 저장…** 은 스킬을 설치하지 않아도 됩니다.

Lectern 이 Claude 를 실행하지는 않습니다. 터미널의 Claude Code 에게 직접 말합니다. 쓰는 말은 이렇습니다. `@문서.md` 는 트리에서 우클릭한 `@경로 복사`입니다.

**pptx 를 Lectern 슬라이드로**

```text
이 pptx 를 Lectern 슬라이드로 옮겨 줘: D:\자료\보고서.pptx
지금 PowerPoint 에 띄워 둔 발표를 Lectern 슬라이드로 옮겨 줘. 결과는 D:\프로젝트\발표 폴더에 둬.
D:\자료\보고서.pptx 를 일단 빨리 md 로만 뽑아 줘. 다듬는 건 나중에 할게.
```

**pptx 를 참고해서 md 문서를 Lectern 슬라이드로**

```text
D:\양식\회사보고.pptx 를 참고해서 @시장-분석.md 내용을 Lectern 슬라이드로 만들어 줘.
화면에 떠 있는 pptx 를 참고해서 @시장-분석.md 를 Lectern 슬라이드로 만들어 줘.
D:\양식\회사보고.pptx 의 색과 표지만 참고해서 @주간보고.md 를 10장 안으로 Lectern 슬라이드로 만들어 줘. 숫자는 그대로 써.
```

**pptx 스타일과 템플릿 만들기**

```text
D:\양식\회사보고.pptx 로 '회사 보고' pptx 스타일과 템플릿 묶음을 만들어 줘.
지금 PowerPoint 에 띄워 둔 발표를 '회사 보고' pptx 스타일로 등록해 줘.
'회사 보고' 묶음에 표와 강조글이 있는 템플릿을 하나 더 만들어 줘.
```

**Lectern 슬라이드를 pptx 로**

```text
@발표.md 를 스타일을 최대한 유지해서 pptx 로 만들어 줘.
pptx 에서 옮겨 온 @보고서.md 를 고쳤어. 고친 장만 반영해서 다시 pptx 로 만들어 줘.
@발표.md 를 D:\양식\회사보고.pptx 양식으로 pptx 를 만들어 줘.
```

- 옮길 때는 글을 빠뜨리지 않고 장을 그대로 지킵니다. 글이 중심인 장은 칸으로 다시 짜고, 지도처럼 자리가 뜻인 도식은 그림으로 남기며 글은 노트에 둡니다. 애니메이션과 정확한 글꼴은 옮기지 않습니다.
- 원본 pptx 는 고치지 않습니다. 띄워 둔 발표도 저장하거나 닫지 않습니다.
- Python 을 설치하지 않아도 됩니다. 스킬은 프로그램 폴더의 `lectern-skill.exe` 로 실행됩니다.
- PowerPoint 가 없어도 `.pptx` 파일을 옮기고 내보낼 수 있습니다. 띄워 둔 발표, `.ppt`, DRM 파일은 PowerPoint 가 있어야 합니다.
- 암호가 걸린 파일은 먼저 풀어 주세요. DRM 이 걸린 파일은 PowerPoint 로 열어 띄워 두고 옮기세요.

프롬프트 예제를 더 보려면 프로그램 폴더의 `_internal\skills\README.md` 를 보세요. Claude 가 읽는 작성 안내는 프로그램 폴더의 `_internal\web\help\slides.md` 입니다.

## 코드 읽기

- '코드' 목록에서 파일을 한 번 누르면(또는 Enter) 본문 자리에 줄 번호와 언어 색으로 보입니다. 실행하지는 않습니다. 고치려면 F2(한 줄 편집)나 Ctrl+E(전체 편집)를 씁니다.
- 오른쪽 목차에 클래스·함수·메서드와 `# ---- 그리기 ----` 같은 구분 주석이 나오고, 누르면 그 줄로 갑니다. 설정 파일은 키·섹션이 나옵니다.
- 화면 위 **외부 편집기로 열기**·**전체 복사** 버튼이 있고, 줄을 우클릭하면 이 줄 복사·위치 복사·전체 편집으로 열기·외부 편집기로 이 줄 열기가 나옵니다.
- 보고 있는 코드가 바뀌면 2초 안에 다시 그리고 바뀐 줄을 잠깐 표시합니다.
- 문서 속 `src/app.py:42` 같은 경로나 코드 파일 링크를 누르면 그 줄로 갑니다. 뒤로 가기(Alt+←)로 문서에 돌아옵니다.
- 4MB 가 넘거나 글자가 아닌 파일은 편집기로 열라고 알려 줍니다.

### CSV·텍스트 파일

'자료' 목록(최근 변경·검색의 이름·모아 보기도)에서 `csv`·`tsv`·`txt`·`log` 파일을 한 번 누르면 Lectern 에서 봅니다. 두 번 누르면 지금처럼 기본 앱(엑셀·메모장)으로 엽니다. 문서 속 링크나 `data/x.csv:5` 같은 경로도 Lectern 에서 엽니다.

- **텍스트**(`txt`·`log`)는 코드처럼 줄 번호와 함께 보입니다.
- **CSV**(`csv`·`tsv`)는 표로 보입니다. 구분자(쉼표·세미콜론·탭)와 머리행은 저절로 알아보고, 막대의 **첫 줄은 머리행**으로 바꿀 수 있습니다.
- **거르기**: 머리행 아래 칸에 글자를 치면 그것을 포함하는 행만 남습니다. `!글자` 는 빼기, `=글자` 는 같은 것, 숫자는 `>100`·`<=5`·`10..20`. 여러 열을 함께 거르고, **거르기 지우기**로 되돌립니다.
- **정렬**: 머리행을 누르면 오름차순 → 내림차순 → 원래 순서.
- **통계**: 표 위 줄에 열마다 — 숫자 열은 개수·합계·평균·최소·최대·중앙값, 글자 열은 개수·고유값·가장 많은 값. 거르면 남은 행으로 다시 셉니다. 막대의 **통계** 체크 칸으로 모든 열의 통계를 한꺼번에 보이고 감춥니다 — 고른 것은 다른 CSV·엑셀 표와 다음 실행에도 남습니다.
- 행 번호는 원문의 줄 번호입니다. 행을 우클릭하면 이 줄(원문) 복사·위치 복사가 나옵니다.
- 엑셀이 저장한 CSV(CP949)와 '유니코드 텍스트'(UTF-16)도 읽습니다 (상태줄에 인코딩 표시).
- **고치기**: `csv`·`tsv`·`txt` 는 **편집 모드**(탭 막대의 **편집**·Ctrl+E)로 원문을 고칩니다. 표나 글에서 **F2**·**Enter** 를 누르면 그 줄에서 편집 모드가 열립니다. 저장(Ctrl+S)하면 표가 다시 그려지고 거르기·정렬은 그대로입니다.
  - **원래 인코딩 그대로 저장합니다** — 엑셀이 저장한 CP949 CSV 는 CP949 로, UTF-16 은 UTF-16 으로 (편집기 머리에 인코딩이 보입니다). 그래서 엑셀에서 다시 열어도 글자가 깨지지 않습니다. CP949 에 없는 글자(이모지 등)를 넣으면 저장하지 않고 그 글자를 알립니다.
  - `tsv`·`txt`·`csv` 에서 **Tab** 은 탭 글자를 넣고, 탭은 → 로 보입니다 (TSV 의 열).
  - 표의 칸을 엑셀처럼 바로 고치지는 않습니다 — 원문 줄(쉼표·따옴표 그대로)을 고칩니다.
  - 로그(`log`)는 프로그램이 계속 덧붙이는 파일이라 볼 수만 있습니다. 2MB 가 넘는 파일은 편집하지 않습니다.
- 2,000행까지 보이고, 그보다 많으면 거르기로 좁힙니다 (개수·통계는 모든 행으로 셉니다).

### 엑셀 파일

'자료' 목록에서 엑셀 파일(`xlsx`·`xlsm`)을 한 번 누르거나, 우클릭해 **새 문서 탭에서 열기**를 고르면 Lectern 에서 봅니다. 두 번 누르면 지금처럼 엑셀로 엽니다.

- CSV 와 같은 표로 보입니다 — 거르기·정렬·통계·첫 줄은 머리행이 그대로 되고, 머리줄 아래 **시트 탭**으로 시트를 바꿉니다 (숨긴 시트는 기울임꼴).
- 열 이름 앞에 엑셀의 열 글자(A·B·C…), 행 번호는 엑셀의 행 번호입니다. 값이 없는 행은 빠집니다.
- 칸에는 엑셀에 보이는 값이 나옵니다 — 자리 쉼표·백분율·날짜·소수 자리 같은 표시 형식을 따르고, 수식 칸은 계산된 값(마우스를 올리면 수식). 색·글꼴·셀 병합 같은 서식은 보이지 않습니다.
- 칸을 우클릭하면 **이 칸 복사**(B3 처럼 이름과 함께)·**이 행 복사**·**위치 복사**(`@data/가격.xlsx '1분기' 시트 3행`). **전체 복사**는 지금 시트를 탭으로 나눈 글로 복사해 엑셀에 붙이면 칸이 나뉩니다. 행을 하이라이트하고 Shift+→ 로 Claude 에 보낼 수도 있습니다.
- 보기만 합니다 — 고치려면 엑셀로 여세요. 옛 형식 `xls`·`xlsb` 는 엑셀로 엽니다. 시트마다 5만 행·100만 칸까지 보이고, 넘으면 막대에 알립니다.

### 표를 차트로 보기

표를 그 자리에서 선·막대 차트로 봅니다. 보기만 하고 문서나 파일은 바뀌지 않습니다.

- **여는 곳**: 문서의 표를 우클릭해 **차트로 보기**, 표의 행을 고른 곳을 우클릭하면 그 행만, CSV·엑셀 화면의 **차트로 보기** 버튼(거른 행 그대로)과 열 머리 우클릭.
- 시간을 저절로 알아봅니다 — `2026`, `2026-03`, `2026.3`, `202603`, `2026M03`, `2026-03-15`, `2026. 3. 15.`, `3/31/2026`, `2026Q1`, `1Q26`, `2026년 1분기`, `2026년 1/4분기`, `2026년 3월`, `Mar-26`, `2026H1`, `FY2026`, `2026E` 등. 최근 것이 위에 있는 표도 오래된 것부터 놓고, 머리행이 시점(`2024 | 2025 | 2026`)이면 행과 열을 저절로 바꿉니다. 시점 앞의 글 열(ECOS 의 항목·단위)은 계열 이름과 단위가 됩니다.
- 단위는 머리행의 괄호(`가격 (USD/t)`)에서, 없으면 표의 캡션(`단위: 천톤`)에서 읽습니다. 레벨과 증가율(`%`, `YoY`, `전년비` 등)이 섞이면 양쪽 축으로 나누고 **레벨·증가율·둘 다** 로 고릅니다. 축은 둘까지입니다.
- 빈칸, `-`, `n.a.`, `x`, `#DIV/0!` 는 0 이 아니라 끊긴 곳입니다. `(1,234)` 와 `△3.5` 는 음수이고, `1,234p` 의 잠정 표시는 뗍니다. `▲` 는 뜻이 갈려 숫자로 읽지 않습니다.
- 시간 축이 아니면 `합계`·`평균` 행은 차트에서 뺍니다 (막대의 눈금을 뭉갭니다). 뺀 것은 위에 알려 줍니다.
- **자동** 은 레벨을 막대로, 비율을 선으로 그립니다 (점이 36개를 넘으면 레벨도 선). **선**·**막대** 로 바꾸고, 왼쪽 목록에서 계열을 켜고 끕니다. 처음에는 6개까지 켜 둡니다.
- 어림이 틀리면 **행↔열** 과 계열 고르기로 바로잡습니다. 마우스를 올리면 값이 보이고, 점이 많으면 아래 막대로 확대합니다. **Esc** 로 닫습니다.

### 데이터 분석 (CSV·엑셀)

- **요약 줄**: 표 위에 `월별 · 2015-01 ~ 2026-09 · 숫자 열 6 · 빈칸 2` 처럼 나옵니다. 거르면 남은 행으로 다시 셉니다.
- **계산 열**: 숫자 열 머리를 우클릭해 전기 대비 %, 전년 동기 대비 %(월은 12, 분기는 4를 뺍니다), 차분, 누적, 이동평균, 첫 값=100 지수를 더합니다. 색이 다르고, 거르기·정렬·통계·차트가 그대로 됩니다.
- 계산 열은 화면에만 있습니다. 파일에는 쓰지 않고, 파일이 바뀌어 다시 그려도 남지만 파일을 다시 열면 없습니다. 머리의 **×** 로 뺍니다.
- 계산은 거른 행으로 합니다. 품목별로 쌓은 표는 같은 시점이 여러 행이라 그대로는 계산하지 않고 알려 주니, 품목으로 거른 뒤 계산하면 그 품목의 시계열이 됩니다. 빠진 달이 있으면 그 뒤 달의 전기 대비는 비어 있습니다.
- **보이는 표 복사**: 거른 행과 계산 열까지 복사합니다 (엑셀에 붙이면 칸이 나뉩니다). **문서로 보내기…** 는 Markdown 표로 다른 문서에 넣습니다 (500행까지).

### 여러 표가 든 시트

엑셀에서 온 표는 위에 제목 줄이 있거나, 머리행이 여러 줄이거나, 한 시트에 표가 여럿인 경우가 많습니다. 그런 시트는 표로 나눠 가장 큰 표를 보이고, 위에 단추가 나옵니다. 깔끔한 시트에는 단추가 없고 전과 같습니다. CSV 도 같습니다.

- **표 1**·**표 2** 단추로 표를 고르고, **시트 전체**(CSV 는 **파일 전체**)로 받은 그대로를 봅니다. 행 번호는 원래 번호 그대로입니다.
- 빈 행·빈 열로 표를 나눕니다. 표 안의 간격용 빈 열과 몸통 사이의 빈 줄은 같은 표로 봅니다.
- 표 위의 한 칸짜리 줄은 제목입니다 (`단위: 천톤` 은 차트의 단위로). 표 아래의 `자료:`·`주:` 줄은 표에서 뺍니다.
- 숫자가 시작되는 행 위가 머리행입니다. 여러 줄이면 `수입 · 구리` 처럼 합칩니다 — 병합 칸은 병합한 범위까지 왼쪽 값을 씁니다.
- 어림이 틀리면 **머리행 − · +** 로 줄 수를 고치거나, 시트 전체에서 행을 골라 우클릭 **이 범위를 표로** 를 고릅니다.
- 고른 표와 머리행 줄 수는 앱을 끌 때까지 기억합니다. 파일은 바꾸지 않습니다.

## 우클릭 메뉴와 복사

- 본문을 우클릭하면 그 제목·단락·표·그림에 테두리가 생기고 복사 메뉴가 나옵니다.
- 텍스트·Markdown 원문 복사, 제목은 절 전체와 절 링크, 표는 엑셀·워드에 붙일 수 있는 모양으로, 그림은 PNG 로 복사합니다.
- **위치 복사**는 `@docs/보고서.md 40~52행` 처럼 복사됩니다. Claude Code 프롬프트에 붙이면 그 부분을 짚어 줄 수 있습니다.
- 글을 고른 채 우클릭하면 '고른 글 복사'가 맨 위에 나옵니다. 한 줄 안에서 골랐으면 서식과 담기·보내기가 함께 나오고(위 '글 고르기와 서식'), 그 블록의 보통 메뉴는 맨 아래 **이 블록의 메뉴…** 입니다.
- 메뉴는 어디서나 같은 차례입니다: 그 대상에서만 하는 일 → Claude → 복사 → 담기·보내기 → 편집·열기 → 보기 → 지우기. 오른쪽에는 단축키만 보이고, 설명은 마우스를 올리면 보입니다.
- 키보드로는 **Shift+F10** 이 초점이 있는 곳이나 현재 줄의 메뉴를 엽니다.
- 블록·제목 메뉴의 **담기**·**문서로 보내기…**는 그 조각을 문서 탭에 열린 문서나 새 문서로 보냅니다 (위 '담기').
- 복사 항목 오른쪽의 **터미널 버튼**을 누르면 같은 글이 터미널에 들어갑니다 (Enter 는 누르지 않음). 고른 글·위치·원문·코드·`@경로`·전체 경로 등에 있고, 트리·'코드'·'자료' 목록의 우클릭 메뉴에도 있습니다. 자세한 것은 아래 '터미널'.

## 메모

프로젝트마다 메모를 둡니다. 탭 막대의 **메모** 버튼이나 **Alt+M** 으로 오른쪽 패널을 열고 닫습니다 (Esc 로도 닫습니다). 문서 위를 덮으므로 문서를 보면서 쓸 수 있습니다.

- **새 메모**를 누르고 쓰면 저절로 저장됩니다. 제목·색·고정을 줄 수 있고, 고정한 메모는 맨 위에 옵니다. 위 칸에 글자를 적으면 맞는 메모만 보입니다.
- **할 일로**를 누르면 줄마다 체크 칸이 생깁니다. 끝낸 항목은 아래로 내려가고, 맨 아래 칸에서 항목을 더합니다. 본문에 `- [ ] 할 일` 로 적어도 됩니다.
- **복사**는 Markdown 글로, **터미널**은 터미널에 붙여 넣기로 (Enter 는 누르지 않음), **문서로**는 문서 탭의 문서나 새 문서로 보냅니다.
- **지우기**를 누르면 위에 **되돌리기**가 잠깐 나옵니다.
- 문서를 우클릭해 **새 메모로 보내기**를 고르면 그 글이 메모가 되고, 어디서 왔는지(`@경로 12~20행`)가 아래에 붙습니다. 누르면 그 자리로 갑니다. 고른 글에서 보낸 메모와 형광펜의 **메모 달기**(위 '형광펜으로 표시하고 다시 보기')는 문서가 바뀌어 줄이 밀려도 그 글로 찾아가고, 블록에서 보낸 메모는 그 줄 번호로 갑니다.
- 메모는 프로젝트 폴더의 `.lectern/notes.md` 하나에 Markdown 으로 저장합니다. 메모를 처음 쓸 때 만들고, 트리와 검색에는 나오지 않습니다. 폴더를 옮기면 메모도 따라가고, Claude Code 에 `@.lectern/notes.md` 로 읽힐 수 있습니다.
- git 으로 관리하는 폴더, 특히 공개 저장소에 메모가 올라가지 않게 하려면 `.gitignore` 에 `.lectern/` 을 적으세요.
- 그사이 다른 곳에서 파일을 고쳤으면 다시 읽어 합칩니다. 예제처럼 보기만 하는 프로젝트에서는 메모를 쓰지 않습니다.

## 업무 관리

폴더마다 맨 위에 `WORK.md` 하나를 두면, Lectern 이 그 폴더를 기억하고 여러 폴더의 상태·마감·할 일·일정을 **업무 현황** 한 곳에 모아 보여 줍니다. Lectern 이 켜져 있는 동안 창 안에 알림도 띄웁니다. WORK.md 는 Claude 없이도 쓰고 고칠 수 있는 보통 Markdown 이고, Claude 가 읽고 써도 됩니다.

예제 — [11 업무 관리](../../samples/guide/11-업무-관리.md): 예제 맨 위의 WORK.md 견본과 따라 하기, 기획 메모 반영 요청(6-1절), 업무 나무·상위에서 고치기·칸반·달력 입력(7~10절)과 업무 나무 예제로 해 보기(11절).

### WORK.md

| 부분 | 쓰는 것 | 업무 현황이 읽나 |
|---|---|---|
| 머리 설정 | `status`(예정·진행·지연위험·막힘·보류·완료·중단), `priority`(상·중·하), `due`(YYYY-MM-DD), `start`(YYYY-MM-DD — 간트·달력의 시작) | 읽음 — 상태·우선·마감·시작 |
| `# 제목` | 업무 이름 | 읽음 |
| 할 일 | `- [ ] 초안 3장 작성 (11/14)` — 끝의 괄호가 기한 | 읽음 — 체크 칸과 기한 |
| 일정 | `- 2026-11-12 14:00-15:00 팀장 보고`, `- 2026-11-20 종일 워크숍` | 읽음 — 오늘 일정과 알림 |
| 기획 메모 | 생각나는 대로 — 할 일·날짜를 써도 | 읽지 않음 — 정리할 때 옮김 |
| 현재 상태·결정·기록·자료 | 자유롭게 | 읽지 않음 |

- 절 이름과 차례는 자유입니다. Lectern 은 머리 설정과 할 일·일정의 줄 모양만 봅니다.
- 연도를 뺀 기한 `(11/14)` 은 오늘에서 가장 가까운 해로 읽습니다. 영어 값(`active`·`done` 등)도 됩니다.
- 날짜는 `2026-11-14` 로 쓰는 것이 기본이고, `2026.11.14`·`2026/11/14`·`2026-11-5` 처럼 써도 읽습니다. 키 이름의 대문자(`Status`)·콜론 앞 빈칸도 됩니다.
- 상태·마감은 머리 설정을 우클릭해 **문서 정보 고치기**로, 할 일은 체크 칸을 눌러, 기록은 한 줄 편집으로 고칩니다.
- 하위 폴더에도 `WORK.md` 를 둘 수 있습니다. 아래 '업무 나무'를 보세요.

### 기획 메모

업무 카드의 `## 기획 메모` 절은 생각나는 대로 적는 곳입니다. 기본 틀에는 한 줄 요약 바로 아래에 있습니다. Lectern 은 이 절을 읽지 않아서, 메모에 `- [ ] …` 이나 `- 2026-11-25 초안 회의?` 를 적어도 업무 현황·알림·확인할 줄에 나오지 않습니다. 절은 같거나 높은 수준의 다음 제목(`## 할 일` 같은)까지입니다. 영어 이름 `## Planning notes` 와 `## 자유 서술` 도 같습니다.

정리하는 길은 둘입니다.

- **직접**: 메모를 읽고 할 일·일정·결정 절로 옮깁니다. 옮긴 메모는 지웁니다.
- **AI 에게**: WORK.md 를 열고 여백을 우클릭해 **기획 메모 반영 요청**을 고르면 요청 글이 맨 앞 터미널에 들어갑니다 (Enter 는 누르지 않습니다). AI 는 작성 안내대로 할 일·일정·결정·현재 상태에 옮기고, 이미 있는 줄은 넣지 않고, 날짜가 분명하지 않으면 묻고, 기록 절에 무엇을 반영했는지 한 줄 남깁니다. 메모 글은 고치거나 지우지 않습니다 — 반영한 메모를 지우는 것은 사람이 합니다.

### 업무 카드 만들기

프로젝트 탭이나 문서 트리의 빈 곳을 우클릭해 **업무 카드 만들기…** 를 고릅니다. 하위 폴더에 만들려면 사이드바에서 그 폴더를 우클릭해 **이 폴더에 업무 카드 만들기…** 를 고릅니다. 문서가 없는 폴더는 문서 트리에 나오지 않으니 '자료'·'코드' 목록의 폴더를 우클릭합니다. 종류(아래 표)·제목(처음엔 폴더 이름)·마감·우선을 정하고 **만들기**를 누르면 기본 틀로 `WORK.md` 를 만들어 엽니다. 이미 있으면 메뉴가 **업무 카드 열기**입니다. 만든 폴더는 업무 폴더 목록에 들어갑니다.

| 종류 | 틀 | 기본으로 골라지는 곳 |
|---|---|---|
| 업무 | 기획 메모·현재 상태·할 일·일정·결정·기록·자료, 상태 '예정' | 프로젝트 맨 위 |
| 묶음·총괄 | 같은 절, 상태는 비움 — 하위 업무에서 셈 | (고를 때) |
| 작은 업무 | 기획 메모·할 일·일정·기록만, 상태 '예정' — 이슈리포트 하나 같은 일 | 하위 폴더 |

마감 칸은 `YYYY-MM-DD` 로 쓰거나(`2026.11.20` 도 읽습니다) 옆의 달력 단추·**Ctrl+;** 로 고릅니다.

### 업무 나무 — 폴더 안의 폴더

프로젝트 폴더의 WORK.md 는 전체를 총괄하고, 하위 폴더의 WORK.md 는 그 안의 일 하나(예: 이슈리포트 하나)를 맡습니다. 그 사이에 묶음 폴더(예: '이슈리포트' — 하위 업무 여러 개를 하나처럼)를 둘 수 있습니다.

```text
2026 원자재 리서치/        WORK.md   총괄
├─ 이슈리포트/             WORK.md   묶음
│  ├─ 01-구리/             WORK.md   작은 업무
│  └─ 02-리튬/             WORK.md   작은 업무
└─ 정기보고/               (WORK.md 없음 — 건너뜀)
   └─ 주간/                WORK.md   총괄 바로 아래
```

- **부모는 가장 가까운 위 폴더의 WORK.md** 입니다. WORK.md 가 없는 폴더는 건너뜁니다.
- **상위에서 모아 봅니다.** 파일에는 저마다 자기 일만 적고, Lectern 이 세 곳에서 모아 보입니다 — 업무 현황, 총괄·묶음 폴더의 폴더 개요('이 폴더의 업무'), 상위 WORK.md 를 열면 문서 아래의 **하위 업무** 칸(파일에는 없는 칸, 인쇄·PDF 에도 나오지 않음).
- **상태를 비워 두면 하위에서 셈합니다.** 하위에 막힘이 하나라도 있으면 막힘이고, 그다음 지연위험·진행·예정·보류 차례이며, 모두 끝났으면 완료입니다. 셈한 값에는 `*` 가 붙습니다. 상태를 적어 두면 적은 값을 따릅니다.
- **위로 올라오는 것**: 줄에 '하위 5 · 진행 3 · 막힘 1' 같은 요약과 열린 하위 가운데 가장 이른 마감('다음 11-20'). 하위의 할 일·일정·알림은 '총괄 › 이슈리포트 › 02 리튬'처럼 경로와 함께 나옵니다.
- **주의할 것**: 업무 현황 맨 위에 나무의 어느 깊이에 있든 주의할 업무를 모읍니다. 나무에서 생긴 어긋남도 여기 나옵니다 — 상위가 완료인데 하위가 열림('하위가 아직 열림'), 하위 마감이 상위 마감보다 늦음('하위 마감이 더 늦음').
- **펼치기**: 처음엔 세 단계가 보이고 ▸ 로 펼치고 접습니다. 끝난 하위는 '완료·중단 n건 보이기'로 접혀 있습니다.
- **하위 업무를 누르면** 그 폴더를 따로 열지 않고 품은 프로젝트 탭에서 그 WORK.md 를 엽니다.
- **기억하기**: 프로젝트를 열면 하위 폴더의 WORK.md 를 찾아 업무 폴더 목록에 더합니다 (숨김·제외 폴더 안은 빼고). 탭을 닫아도 업무 현황에 남고, 닫힌 동안에도 그 WORK.md 한 파일씩만 읽습니다. 프로젝트가 열린 채 하위 폴더의 이름을 바꾸거나 옮기면 다시 읽을 때 새 자리로 바뀝니다.

### 상위에서 고치기

나무의 줄(업무 현황·폴더 개요·하위 업무 칸)에서 고르면 **그 업무의 WORK.md 한 줄**이 고쳐집니다. 고친 파일은 트리에 호박색 점이 붙습니다.

| 고르는 곳 | 바뀌는 줄 |
|---|---|
| 상태 칸 → 상태 메뉴 (묶음은 '비우기 — 하위에서 셈'도) | 머리 설정의 `status:` |
| 마감 칸 → 달력 | 머리 설정의 `due:` |
| 우선 칸 → 메뉴 | 머리 설정의 `priority:` |
| 할 일 칸(2 / 5) → 펼친 목록의 체크 칸 | 그 할 일 줄의 `[ ]` ↔ `[x]` |
| 펼친 목록의 기한 단추 → 달력 | 그 할 일 줄 끝의 `(YYYY-MM-DD)` |
| 펼친 목록의 '할 일 더하기' 칸 → Enter | '할 일' 절 끝에 `- [ ] 글 (기한)` 한 줄 |

- 줄을 우클릭하면 **이 업무 열기·상태 바꾸기·마감 바꾸기·우선 바꾸기** 메뉴가 나옵니다.
- 할 일의 글이나 기록 같은 글 자체는 그 WORK.md 를 열어 고칩니다 (펼친 목록의 'n행' 단추).
- 고치기 전에 그 파일을 다시 읽습니다. 그사이 그 줄이 바뀌었거나(다른 데서·Claude 가 고침) 파일이 바뀌었으면 쓰지 않고 다시 그린 뒤 알립니다 — 한 번 더 고르면 됩니다.
- 상태 값은 그 파일이 쓰는 말로 씁니다 — `status: active` 처럼 영어 값을 쓰는 파일은 영어로.

### 칸반

나무 위의 **목록 · 칸반**에서 칸반을 고르면, 끝 업무(하위가 없는 업무)가 상태 다섯 칸에 카드로 놓입니다: 예정 · 진행 · 주의(막힘·지연위험) · 보류 · 완료·중단. 상태를 비웠거나 읽지 못한 끝 업무가 있으면 '상태 없음' 칸이 하나 더 생깁니다. 묶음은 카드가 아니라 카드 위의 경로로 보입니다.

- 카드에는 위 업무의 경로, 제목, 상태, 마감(D-n), 우선, 할 일 진척(3/5), 다음 할 일이 있습니다.
- **카드를 다른 칸으로 끌어 놓으면** 그 업무의 WORK.md 상태가 바뀝니다. 주의 칸은 막힘·지연위험, 완료 칸은 완료·중단 가운데 고릅니다.
- 카드를 누르면 그 WORK.md 를 엽니다. 키보드로는 카드에서 Enter·Space(열기), 메뉴 키(이 업무 열기·상태·마감·우선 바꾸기 메뉴).
- 한 칸에 40장까지 보이고 나머지는 개수로 알립니다.

### 간트와 달력

나무 위의 **목록 · 칸반 · 간트 · 달력**에서 고릅니다. 날짜는 WORK.md 머리 설정의 `start:`(시작)와 `due:`(마감)에서 옵니다.

- **간트**: 행은 목록과 같은 업무 나무입니다(같은 펼침·접힘). 오른쪽에 날짜 막대 — 시작~마감이 있으면 막대, 하나만 있으면 그날의 점(◆), 묶음은 하위의 가장 이른 날 ~ 가장 늦은 날의 가는 막대입니다. 색은 칸반의 칸과 같고, 붉은 세로선이 오늘입니다. 눈금은 기간이 70일 안이면 주마다, 넘으면 달마다입니다.
- 막대나 이름을 누르면 그 WORK.md 를 엽니다. **시작**·**마감** 칸을 누르면 달력이 뜨고, 고른 날이 그 업무의 머리 설정에 들어갑니다. 끌어서 날짜를 바꾸지는 않습니다 — 잘못 끌어도 파일이 바로 바뀌기 때문입니다.
- **Mermaid 간트로 복사**: 지금 보이는 업무를 Mermaid 간트 글로 복사합니다. md 문서에 붙여 넣으면 그 자리에 일정표 그림이 그려집니다 — 보고서에 일정을 넣을 때 씁니다. 맨 위 업무마다 한 묶음이고, 완료는 흐리게, 막힘·지연위험은 붉게, 진행은 강조해 그립니다. 날짜가 없는 업무는 빼고 몇 개를 뺐는지 알려 줍니다.
- **달력**: 달 격자(일요일 시작)에 시작~마감이 이틀 넘는 업무를 여러 날 막대로, 그 아래 날마다 마감(■)·시작(▶)·할 일 기한(☐)·일정(•, 시각과 함께)을 보입니다. 끝난 업무는 일정만 보이고, 업무 현황의 달력에는 공통 WORK.md 의 일정·할 일도 나옵니다. ‹ · 이번 달 · › 로 달을 옮깁니다.
- 달력의 **날짜 숫자를 누르면** 그날로 일정 더하기 창이 뜹니다. 묶음 폴더의 개요나 하위 업무 칸에서는 그 업무가 넣을 곳으로 골라집니다. 항목을 누르면 그 WORK.md 의 그 줄로 갑니다.
- `start:` 를 읽지 못하거나 시작이 마감보다 늦으면 확인할 줄에 나옵니다.

### 달력 입력

날짜를 넣는 곳 — 업무 카드의 마감, 일정 더하기의 날짜, 나무의 마감·기한 — 에서 달력이 뜹니다. 문서를 고치는 중(한 줄 편집 칸·편집 모드)에도 **Ctrl+;** 를 누르면 달력에서 고른 날이 커서 자리에 `YYYY-MM-DD` 로 들어갑니다. 넣기 창(/)의 **날짜** 도 같습니다.

| 키 | 하는 일 |
|---|---|
| ← → | 하루 |
| ↑ ↓ | 한 주 |
| PageUp · PageDown | 한 달 |
| Home · End | 그 주의 처음 · 끝 |
| T | 오늘 |
| Enter | 고르기 |
| Esc | 그만두기 (달력만 닫힘) |

'오늘'·'내일'·'이번 주 금요일'·'다음 주 월요일' 단추가 있고, 고칠 때는 **비우기**도 있습니다. 마감·할 일 기한·일정이 있는 날에는 점이 찍힙니다.

### 업무 현황

툴바의 **업무** 버튼이나 **Alt+W**. 공통 폴더를 탭으로 열고, 그 폴더 개요 맨 위에 보입니다.

- **공통 폴더**: 과제 밖의 일정·할 일을 적는 WORK.md 와 주간·월간 정리를 두는 보통 폴더입니다. 처음 업무 현황을 열 때 고릅니다 (예: `문서\Lectern 업무` — 고르는 창에서 새 폴더를 만들 수 있습니다). 공통 WORK.md 는 업무 현황의 **공통 WORK.md 만들기**로 만듭니다.
- **주의할 것**: 막힘·지연위험, 마감이 지났거나 3일 안, 진행인데 14일 넘게 WORK.md 가 안 바뀜, 그리고 나무의 어긋남 — 나무의 어느 깊이에 있든 맨 위에 경로와 함께 모읍니다.
- **업무 나무**: 기억한 업무마다 한 줄 — 상태, 업무(제목과 폴더 이름, 하위 요약), 우선, 마감(D-n), 안 한 할 일 수, 갱신. 진행·예정(마감이 빠른 차례), 보류, 완료·중단(접힘) 차례이고, 하위는 그 아래에 들여 씁니다. 줄의 상태·마감·우선·할 일 칸을 누르면 그 자리에서 고칩니다 (위 '상위에서 고치기'). 제목을 누르면 WORK.md 를 엽니다. 위의 **목록 · 칸반**으로 칸반을 봅니다.
- **기한 있는 할 일**(지남·오늘·이번 주)과 **오늘 일정**: 공통 WORK.md 의 것은 '공통'으로 표시합니다. 누르면 그 줄로 갑니다.
- **확인할 줄**: 오타나 지운 곳 때문에 읽지 못한 줄을 버리지 않고 모아 보입니다. 누르면 그 WORK.md 의 그 줄로 갑니다. 정해진 값이 아닌 상태(`진핸`), 키 이름 오타(`stauts` — 맞는 키를 알려 줌), 읽지 못한 마감·할 일 기한(`(11/31)`, 괄호 빠짐), 체크 칸 오타(`- []`·`-[ ]`), 없는 날의 일정(`2026-11-31`), 읽지 못한 시각(`25:00`, `14:00-1500` — 시각 없는 일정으로 남김), 내용 없는 일정, 닫는 `---` 가 없는 머리 설정이 그렇습니다. 업무 나무의 그 업무 줄에 '확인할 줄 n'이 붙고, 켤 때의 요약에도 나옵니다.
- **읽지 못한 폴더**: 폴더를 옮겼거나 지웠거나 드라이브가 연결되지 않았으면, 또 WORK.md 가 UTF-8 이 아니거나(옛 메모장의 ANSI 등) 2MB 를 넘으면 여기 나옵니다. **목록에서 빼기**로 뺍니다 (파일은 그대로).
- 공통 폴더를 옮기거나 지우면 업무 현황을 열 때 다시 고르라고 묻습니다. 과제 폴더들의 목록은 그대로입니다.
- 확인할 줄·기한 있는 할 일·오늘 일정은 50개까지 보이고, 나머지는 개수로 알립니다.
- 탭을 닫아도 업무 현황에는 남습니다. Lectern 은 기억한 폴더의 `WORK.md` 한 파일만 읽고, 그 폴더의 다른 파일은 읽지 않습니다.
- WORK.md 가 있는 폴더를 열면 저절로 기억합니다. 열지 않고 더하려면 **폴더 더하기** — 고른 폴더에 WORK.md 가 없으면 열고 만들지 묻습니다. Lectern 프로그램 폴더 안(예제)은 기억하지 않습니다.

### 일정 더하기

업무 현황의 **일정 더하기**나 **Alt+S**. 날짜(오늘·내일·요일 단추, 달력 단추·Ctrl+;), 시각(끝나는 시각, 종일), 내용, 넣을 곳(공통 또는 끝나지 않은 업무 — 나무 차례로, 하위는 위 업무의 경로와 함께)을 정하고 **넣기**를 누릅니다. 고른 WORK.md 의 '일정' 절 끝에 한 줄이 들어갑니다 (절이 없으면 문서 끝에 만듭니다). 넣을 곳은 처음에 지금 보는 문서·폴더가 속한 가장 깊은 업무입니다 — 하위 폴더의 문서를 보고 있으면 그 하위 업무. Enter 로 넣고 Esc 로 그만둡니다.

- 내용이 비었거나 끝나는 시각이 시작보다 앞이면 넣지 않고 까닭을 보입니다. 같은 일정을 두 번 넣는 것은 막지 않습니다.
- 넣은 뒤 오른쪽 아래의 **되돌리기**로 뺍니다. 그 뒤에 파일을 고쳤으면 고친 글을 지키려고 되돌리지 않고 알립니다.
- 창을 연 사이 파일이 바뀌었거나 지워졌으면 넣지 않고 알립니다. 같은 WORK.md 를 편집 모드로 고치는 중이었으면, 편집기에서 저장할 때 바뀐 것을 알리고 묻습니다.
- '일정' 절은 `## 일정` 이나 `### 일정` 제목입니다. `## 일정 (11월)` 처럼 뒤에 괄호·콜론이 붙어도 되고, `# 일정 관리 개선` 같은 업무 제목은 일정 절이 아닙니다.

WORK.md 에서 직접 써도 됩니다 — '일정' 절의 마지막 줄에서 Shift+Enter 로 새 줄을 열고 `- 2026-11-14 10:00 팀 회의`. 반복 일정(매주 월)은 아직 없습니다. 날짜마다 한 줄씩 씁니다.

### 알림

Lectern 이 켜져 있는 동안 창 오른쪽 아래에 띄웁니다. 닫을 때까지 남습니다.

| 알림 | 언제 |
|---|---|
| 오늘의 업무 | 켤 때 한 번(날짜가 바뀌면 다시) — 마감 지남·오늘·3일 안, 기한이 지났거나 오늘인 할 일, 오늘 일정, 확인할 줄. 알릴 것이 없으면 띄우지 않습니다 |
| 곧 시작 | 시각이 있는 일정의 10분 전, 한 번 — 이미 시작한 일정은 알리지 않습니다 (절전에서 깨어나도 지난 알림이 몰리지 않음) |
| 오늘 기록 | 17:30 이 지나면 한 번 — 오늘 WORK.md 가 바뀌지 않은 진행 중 과제 |

- Windows 알림이나 알림 영역은 쓰지 않습니다. 창이 가려져 있으면 다시 볼 때 쌓여 있습니다. Lectern 을 끄면 알림도 없습니다.
- 설정 창의 **업무 알림**으로 끕니다. 띄운 알림은 기억해 두지 않아서, 다시 켜면 오늘의 업무가 또 나옵니다.

### Claude 와 함께

WORK.md 는 Claude 가 읽고 써도 같은 규칙으로 돌아갑니다. 설정 창의 **Claude Code 에 Lectern 알려 주기**로 작성 안내를 주면 Claude 가 같은 형식으로 씁니다. 예: "이 폴더의 WORK.md 를 만들어 줘", "회의 메모에서 할 일을 뽑아 WORK.md 에 넣어 줘", "오늘 한 일을 기록 절에 적어 줘". 기획 메모는 문서 우클릭의 **기획 메모 반영 요청**으로 맡깁니다 (위의 '기획 메모').

## 터미널

- 탭 막대 오른쪽 끝의 **터미널** 버튼이나 Ctrl+\` 로 본문 오른쪽에 터미널이 열립니다. 지금 탭의 프로젝트 폴더에서 Windows PowerShell 이 시작되고, 탭마다 셸이 따로입니다.
- **터미널 여러 개**: 머리줄의 **+** 로 같은 프로젝트에 터미널을 더 엽니다 (프로젝트마다 5개까지 — 예를 들어 1번은 Claude Code, 2번은 다른 명령). 문서 아래에 두었으면 머리줄의 [1 PowerShell] [2 PowerShell] 를 눌러 고르고, 오른쪽에 두었으면 아래 '위아래로 쌓기'처럼 모두 보입니다. 화면을 다시 불러와도 돌던 터미널들은 그대로 이어집니다.
- **위아래로 쌓기**: 터미널이 문서 오른쪽에 있을 때 둘 이상이면 탭 대신 위아래로 쌓여 모두 보입니다. 1번이 맨 아래이고 번호가 클수록 위입니다. 높이는 똑같이 나뉘고, 칸 사이 경계를 끌어 바꿉니다 (경계를 두 번 누르면 다시 똑같이, 터미널을 더하거나 닫아도 똑같이). 칸마다 머리줄에 번호·셸 이름·× 가 있고, 칸을 누르면 그 터미널을 고릅니다 (↻ 다시 시작이 그 터미널에 — F6 은 1번부터 차례로 모두 거칩니다). 터미널이 문서 아래에 있으면 지금처럼 탭입니다.
- **터미널 끝내기**: 다 쓴 터미널은 그 탭의 × (또는 가운데 버튼)로 끝냅니다 — 그 셸과 거기서 띄운 프로그램이 끝나고, 프로그램이 돌고 있으면 먼저 묻습니다. 터미널이 하나뿐이어도 되고, 마지막 터미널을 끝내면 패널이 감춰졌다가 다시 열 때 새 셸로 1번이 시작합니다. 패널이 좁으면 고르지 않은 탭은 이름이 줄고 × 는 마우스를 올릴 때 나옵니다.
- 머리줄 오른쪽 끝의 × (또는 Ctrl+\`)는 패널을 감추기만 합니다 — 셸은 계속 돌아, 다시 열면 이어집니다. 머리줄의 ↻ 는 셸을 새로 시작합니다.
- **화면 다시 붙기**: 터미널 머리줄·터미널 탭·쌓은 칸의 머리줄을 우클릭해 **N번 터미널 화면 다시 붙기**를 고르면(명령 찾기 Ctrl+Shift+P 의 **터미널 화면 다시 붙기**도) 그 터미널의 화면만 새로 만들어 같은 셸에 다시 붙습니다. 셸과 그 안에서 도는 프로그램(Claude Code 등)은 끝나지 않고, 최근 출력(약 52만 글자)을 다시 받아 보입니다. 오래 쓴 터미널에서 한글 입력이 이상해졌을 때 먼저 해 봅니다 — 고쳐지면 화면 쪽 문제였고, 그대로면 한/영 키를 두 번 누르거나, 프로그램을 끝내고 이어 가기(`claude --continue` 등)를 해 보고, 마지막으로 ↻ 다시 시작을 씁니다.
- 터미널 안의 키는 셸로 갑니다. Ctrl+P·Ctrl+F·F1 같은 앱 단축키는 본문을 누른 뒤에 씁니다 (Ctrl+Tab 은 터미널 안에서도 다음 탭).
- **F6** 은 초점을 **문서 → 터미널 1 → 2 → 3 … → 사이드바 → 문서** 차례로 한 곳씩 옮깁니다. **Shift+F6** 은 거꾸로입니다. 터미널 안에서도 됩니다. 문서 안의 **Tab** 은 문서를 떠나지 않으니, 터미널·사이드바로 갈 때는 F6 을 씁니다.
  - 그 프로젝트의 터미널을 번호 차례로 모두 거칩니다 (쌓여 있든 탭이든). 터미널이 닫혀 있으면 열면서 1번으로 갑니다.
  - 사이드바는 그 안에서 마지막에 있던 곳(검색 칸·고른 행)으로 갑니다. 사이드바를 감췄으면(Ctrl+B) 건너뜁니다. 보기만 하는 프로젝트(예제)와 독립창에는 터미널이 없어 문서와 사이드바만 오갑니다.
  - 문서로 돌아오면 보던 자리로 갑니다 — 편집 중이면 편집기, 한 줄 편집 중이면 그 칸의 그 자리로 (칸은 저장하지 않고 그대로 둡니다). 목차·툴바를 누른 뒤에 남은 초점은 문서로 봅니다.
  - 터미널을 연 동안 키가 가는 쪽은 강조색 줄로 보입니다 (터미널은 머리줄, 문서는 문서 탭 줄).
- 글을 끌어 고른 뒤 Ctrl+C 나 우클릭으로 복사하고, Ctrl+V 나 우클릭으로 붙여 넣습니다. 고른 글이 없을 때 Ctrl+C 는 실행 중인 명령을 멈춥니다.
- 경계를 끌어 폭을 바꿉니다 (두 번 누르면 기본 폭).
- **자리**: 창이 가로로 넓으면 문서 오른쪽에, 세로로 길면(세로 모니터, 화면 반쪽에 붙인 창 등) 문서 아래에 열립니다. 아래에 있을 때는 경계를 끌어 높이를 바꿉니다. 터미널 머리줄의 자리 버튼으로 오른쪽·아래를 바꾸면 그 자리로 고정되고, 설정 창의 '터미널 자리'에서 다시 '자동'으로 되돌립니다.
- **터미널에 붙여 넣기**: 우클릭 메뉴에서 복사 항목 오른쪽의 **▣ 터미널** 버튼을 누르면 그 글이 지금 탭의 터미널에 들어가고, '1번 터미널에 넣었습니다'처럼 알림이 뜹니다 (항목 이름 쪽을 누르면 복사만 합니다). 터미널이 닫혀 있으면 열립니다. 터미널이 여럿이면 기본은 맨 앞 터미널(가장 작은 번호 — 보통 처음 연 1번)이고 그 터미널로 바꿔 보이니, Claude Code 는 1번 터미널에서 돌리세요 (다른 번호로 보내는 법은 아래 '번호로 보내기'). Enter 는 누르지 않으니 확인하고 직접 Enter 를 누르세요. 여러 줄이면 먼저 묻습니다 — PowerShell 프롬프트에서는 줄마다 명령으로 실행될 수 있기 때문입니다 (Claude Code·Codex·Antigravity·OpenCode 처럼 붙여넣기 모드를 켠 프로그램에는 묻지 않습니다 — 여러 줄이 보내지지 않고 입력 칸에 그대로 들어갑니다).
- **번호로 보내기**: 다른 터미널에 보내려면 메뉴를 연 뒤 **숫자 키(1~5)를 누른 채** ▣ 터미널이나 'Claude로 보내기'를 누릅니다 — 메뉴 위에 '→ 3번 터미널'이 보입니다. 키보드로는 **Shift+숫자**(초점은 터미널로)·**Ctrl+Shift+숫자**(초점은 문서에)가 현재 줄의 위치를 그 번호의 터미널에 넣습니다. 쌓아 둔 칸은 넣은 터미널의 머리줄이 잠깐 빛납니다. 없는 번호면 넣지 않고 알립니다 (새로 만들지 않습니다). 한 줄 편집 칸과 터미널 안에서 Shift+숫자는 그냥 글자(! @ # …)입니다.
- **설정 창의 터미널 단추**(요청 글 옆의 ▣)는 마지막에 쓴 터미널(누르거나 초점이 간 터미널 — 터미널 탭에서 골라 둔 것)에 넣습니다. 고른 AI 도구가 1번이 아닌 터미널에 떠 있으면 그 터미널을 한 번 누른 뒤 설정 창을 엽니다. **숫자 키(1~5)를 누른 채** 누르면 그 번호의 터미널에 넣고, 누르고 있는 동안 단추에 번호가 뜹니다 (글 칸에 초점이 있으면 숫자는 그 칸의 글입니다).
- 터미널 색은 문서 스타일을 따릅니다. 늘 어두운 터미널을 원하면 설정 창에서 '터미널 색을 스타일에 맞춤'을 끕니다.
- 터미널 글자 크기는 설정 창의 '터미널 글자 크기'에서 바꿉니다 (10~24, 기본 14). 열린 터미널과 터미널 모음에도 바로 듣습니다.
- 탭을 닫으면 그 셸도 끝납니다. 셸에서 띄운 프로그램이 돌고 있으면 먼저 묻습니다. Lectern 을 닫으면 모든 셸이 함께 끝납니다.
- **멈춘 프로그램 알림**: 셸에서 띄운 프로그램이 시작하다 멈추면(회사 PC 의 보안 프로그램(DRM 등)이 프로그램 실행을 막을 때 생깁니다 — Claude Code 가 git 을 부르다 아무 입력도 받지 않게 됨) 10초쯤 뒤에 터미널 머리줄 아래에 붉은 띠가 나오고 ↻ 가 강조됩니다. 이런 프로그램은 Ctrl+C 로 끝나지 않고 작업 관리자로도 끝나지 않을 때가 많으니 띠의 **다시 시작**을 누르세요. 셸과 멈춘 프로그램을 끝내고 새 셸을 엽니다. Claude Code 는 새 셸에서 `claude --continue` 로 하던 대화를 이어 갑니다 (Codex 는 `codex resume --last`, Antigravity 는 `agy --continue`, OpenCode 는 `opencode --continue`). 보이지 않는 탭의 터미널이면 알림이 한 번 뜹니다.

### 터미널 모음

- 툴바의 **터미널 모음** 버튼이나 Ctrl+Shift+\` 로 열린 프로젝트들의 터미널을 한 화면에 격자로 모아 봅니다.
- 칸 머리에 '실행 중'·'대기'가 보여, 여러 프로젝트에서 돌린 Claude Code 를 한눈에 볼 수 있습니다. 터미널이 여럿인 프로젝트는 칸 머리의 번호(1 2 3)로 칸에 보일 터미널을 고릅니다. 프로그램이 시작하다 멈춘 칸은 '멈춤'이 붉게 보이니 그 칸의 ↻ 를 누릅니다.
- 칸 안에서 Ctrl+Tab 은 다음 칸입니다. 칸 머리를 두 번 누르면 그 칸만 크게 봅니다.
- 칸의 → 버튼은 그 프로젝트로 가서 오른쪽 터미널을 엽니다. 프로젝트 탭을 누르면 문서 화면으로 돌아갑니다.

## Claude Code와 함께 쓰기

예제 — [03 Claude Code 와 함께](../../samples/guide/03-Claude-Code와-함께.md): 터미널, 위치 복사, 바뀐 곳 표시, 코드 읽기.

1. Claude Code 로 작업하는 프로젝트 폴더를 Lectern 으로 열어 둡니다.
2. 터미널(Ctrl+\`)에서 `claude` 를 실행하면 문서를 보면서 바로 옆에서 작업할 수 있습니다.
3. Claude 가 문서를 만들거나 고치면 1초 안에 반영되고, 아직 열어 보지 않은 바뀐 문서에는 트리에 호박색 점이 붙습니다.
4. 문서에 대해 물을 때는 트리에서 문서를 우클릭해 `@경로 복사`를 고르고 프롬프트에 붙여 넣습니다. 예: `@docs/보고서.md 의 결론을 세 줄로 줄여 줘`
5. 문서의 한 부분을 짚을 때는 본문을 우클릭해 **위치 복사**를 고릅니다.
6. Claude Code 가 Lectern 에서 잘 보이는 문서를 쓰게 하려면 설정 창의 **Claude Code 에 Lectern 알려 주기** → **Claude Code용 요청 복사**(옆의 터미널 버튼은 지금 탭의 터미널에 바로)를 Claude Code 에 붙입니다. Claude Code 가 Lectern 의 작성 안내(`web/help/writing.md`)를 읽고 고른 곳에 규칙을 정리합니다 — **모든 폴더(개인)**(기본)면 개인 규칙 파일 `~/.claude/rules/lectern.md` 하나에 형식 규칙을, **이 폴더만**이면 그 프로젝트의 `CLAUDE.md` 에 그 폴더의 글을 누가 읽고 무엇에 쓰는지를. 한 번 모든 폴더에 넣어 두고, 읽는 사람이 뚜렷한 폴더에서만 이 폴더만으로 한 번 더 보내면 됩니다. 예제의 `CLAUDE.md` 가 폴더 쪽의 본보기입니다.
7. 보고서·검토 의견처럼 사람이 읽을 글은 아래 **보고서 글쓰기**를 봅니다 — 글쓰기 스타일, 다듬기 점검, 내 문체.

### 보고서 글쓰기 — 글쓰기 스타일·다듬기 점검·내 문체

예제 — [14 보고서 글쓰기](../../samples/guide/14-보고서-글쓰기.md): 같은 요청을 개조식·서술식으로 쓴 견본, 다듬기 점검을 해 볼 연습 보고서, 내 문체 노트를 만드는 법과 실제로 해 본 결과.

Claude Code 의 기본 역할은 개발자입니다. 보고서를 맡겨도 본문에 파일 경로, '**굵은 이름** — 설명' 꼴의 나열, 화살표, '다음과 같습니다:' 같은 개발 문서의 버릇이 섞이기 쉽습니다. Lectern 은 세 가지로 돕습니다.

| 무엇 | 하는 일 | 어디서 |
|---|---|---|
| 글쓰기 스타일 | Claude 가 그 글을 쓰는 실무자처럼 씁니다 — 리서치 글쓰기·업무 보고·학술 글·쉬운 설명 가운데 고름 | 설정 창 **글쓰기 스타일** → **스타일 고르기…** (한 번 설치, 켤 곳을 고름) |
| 다듬기 점검 | 사람이 쓴 글의 틀린 말·읽기 어려운 곳을 표로 먼저 보이고, 고른 것만 고칩니다 | 문서 여백 우클릭 **다듬기 점검 요청** |
| 내 문체 | 내가 직접 쓴 글로 지킬 것과 따라 하지 않을 버릇을 노트로 남깁니다 | 문서 여백 우클릭 **내 문체 견본으로 보내기**, 설정 창 **내 문체** |

셋 모두 Lectern 은 요청 글만 터미널에 넣습니다 (Enter 는 누르지 않음). 파일을 고치거나 설치하는 것은 Claude 가 먼저 보이고 물은 뒤 사람이 그렇다고 할 때입니다.

**글쓰기 스타일 — 고르고, 한 번 설치하고, 켤 곳을 고름**

Lectern 에는 글쓰기 스타일이 넷 들어 있습니다. 넷 모두 개발자·AI 글버릇을 빼고 다 쓴 뒤 다시 읽는 것은 같고, 무엇을 기준으로 쓰는지가 다릅니다.

| 스타일 | 이런 글에 | 다른 점 |
|---|---|---|
| 리서치 글쓰기 | 보고서·검토 의견·분석 메모 | 읽는 사람과 판단할 것을 먼저, 폴더 밖 자료와 웹까지 근거를 넓힘, 글 종류마다 기준 |
| 업무 보고 | 결재·보고용 한 장 보고, 회의 자료 | 개조식이 기본, 맨 위에 결론과 결재권자가 할 일, 숫자는 계획·전년 대비, 누가·언제까지, 붙임 |
| 학술 글 | 논문·연구 보고서·학회 발표문 | 확인한 문헌만 인용(지어내지 않음), 주장의 세기를 근거에 맞춤, 단위·불확실성, 한계 |
| 쉬운 설명 | 설명서·안내문·교육 자료 | 할 수 있게 되는 일을 먼저, 짧은 문장과 쉬운 말, 번호 하나에 동작 하나, 막히는 곳을 미리 |

1. 설정 창(**Ctrl+,**) **글쓰기 스타일**의 **스타일 고르기…** 로 고르기 창을 엽니다. 왼쪽에 Lectern 에 든 넷, **Claude Code 기본**(스타일 없이), **내 글쓰기 스타일**(개인 폴더 `~/.claude/output-styles` 에 있는, Lectern 의 것이 아닌 출력 스타일), **새 스타일 만들기**가 있습니다 — Claude Code 기본과 내 글쓰기 스타일은 쓰는 AI 도구가 Claude Code 일 때만 보입니다. 오른쪽에는 그 스타일이 맞는 글, 바뀌는 것, **견본**(같은 요청을 Claude Code 에 스타일 없이와 그 스타일로 실제로 시킨 결과의 앞부분), 설치 상태, 지금 이 폴더에서 듣는 스타일이 보입니다. **원문 보기**로 스타일 파일 전체를 읽습니다. **이 스타일로**를 누르면 설정 창으로 돌아오고 '고른 스타일'이 바뀝니다. Claude Code 기본의 **이 폴더는 Claude Code 기본으로**는 켤 곳을 '○○ 폴더에서 끄기'로 바꾸고(열린 폴더가 있을 때만), 그 뒤 스타일을 고르면 다시 '켜기'가 됩니다.
2. 보고서를 쓰는 폴더를 연 채로 설정 창(**Ctrl+,**)의 **글쓰기 스타일**에서 켤 곳을 고릅니다 — **○○ 폴더에서 켜기**(기본)·**모든 폴더에서 켜기**·**○○ 폴더에서 끄기** (○○ 자리에는 열린 폴더 이름이 들어갑니다). 아래 **바뀌는 파일**에 고른 스타일의 파일(`~/.claude/output-styles/` 안)과 켜는 값을 적을 설정 파일이 전체 경로로 보이고, 지금 이 폴더에서 듣는 스타일도 보입니다.
3. 터미널 버튼을 누르고 Enter 를 누르면 Claude 가 지금 상태를 알리고, 스타일 파일을 설치(없거나 다를 때)하고 켤지 묻습니다. 그렇다고 하면 설치하고 그 설정 파일에 `"outputStyle"` 한 값만 적습니다. 두 파일 모두 `.claude` 폴더 안이라 Claude Code 가 쓰기 전에 허락을 한 번 더 묻습니다 — 바뀌는 파일에서 본 것과 같으면 허락합니다.
4. 스타일 파일을 새로 설치했으면 Claude Code 를 끝냈다가(`/exit`) 다시 띄웁니다.
5. 코드를 쓰는 폴더에서는 켜지 마세요 — Lectern 의 글쓰기 스타일은 넷 모두 개발 지침(범위 지키기, 고친 뒤 확인하기)을 뺍니다 (내 글쓰기 스타일은 맨 앞 설정에 `keep-coding-instructions: true` 가 없으면 뺍니다). **모든 폴더에서 켜기**를 고르면 이 경고가 보입니다. 그래도 모든 폴더에 켰다면, 코드를 쓰는 폴더를 열고 **○○ 폴더에서 끄기**로 요청하거나 Claude Code 에서 `/output-style` 로 기본을 고릅니다 (폴더의 값이 모든 폴더의 값보다 앞섭니다).
6. Lectern 을 새 판으로 바꾼 뒤 바뀌는 파일에 '바꿈 — Lectern 의 것과 다름'이 보이면 같은 요청 글로 다시 설치합니다.

한 폴더에는 스타일 하나가 듣습니다. 보고서 폴더는 리서치 글쓰기, 결재 문서 폴더는 업무 보고처럼 폴더마다 다르게 켤 수 있습니다 — 스타일 파일은 개인 폴더에 여럿 두고, 켜는 값만 폴더마다 다릅니다. **내 글쓰기 스타일**은 켜기만 합니다(이미 개인 폴더에 있으므로). **새 스타일 만들기**의 요청 복사·터미널 단추는 Claude 가 넷 가운데 가장 가까운 것을 바탕으로 새 스타일을 짓고 초안을 보인 뒤 물어서 개인 폴더에 저장하게 하는 요청 글을 넣습니다 — 끝에 원하는 글을 이어서 적습니다. 저장한 뒤 설정 창을 다시 열면 내 글쓰기 스타일에 나오고, Claude Code 가 쓰려면 다시 시작합니다.

리서치 글쓰기로 쓰면 이렇게 달라집니다 (다른 셋도 개발자·AI 글버릇과 다시 읽기는 같습니다).

- **글 종류에 맞게** 씁니다. 서술식은 문단으로(첫 문장이 주장), 개조식은 위 항목에 결론·아래 항목에 근거로. 개조식을 나쁜 글로 보지 않습니다. 요청에 "개조식으로"·"서술식으로"라고 붙이면 그대로 씁니다.
- **개발자 글버릇을 뺍니다.** 본문에 파일 경로·코드 표기·굵은 이름 나열·화살표·작업 보고 말투를 쓰지 않고, 출처는 끝의 출처 절에 문서 이름으로 적습니다.
- **AI 글버릇을 줄입니다.** '첫째·둘째', '~로 판단됩니다', '한편·또한'의 되풀이, 절마다 붙는 요약 문장, 빈 꾸밈말.
- **소제목을 그 절의 주장으로** 답니다 ('6월 값은 전망 범위의 위쪽에 있다'). 소제목만 훑어도 흐름이 잡힙니다.
- **분량을 지킵니다.** PDF 양식에서 A4 한 쪽은 공백 빼고 서술식 1,000자, 개조식 800자 안팎입니다.
- **자료의 어색한 표현은 고쳐 씁니다** ('230천 t' → '23만 t'). 인용한 문장과 숫자 값은 그대로 둡니다.

요청에 읽는 사람·목적·글 종류·분량을 붙이면 글이 가장 많이 달라집니다. 예: "구매팀장이 3분기에 언제 살지 정할 수 있게, 개조식으로 A4 한 쪽. 개요 확인 없이 바로 써." 긴 글이면 Claude 가 핵심 주장과 쪽 배분을 개요로 먼저 보이고 멈춥니다.

**다듬기 점검 — 내가 쓴 글을 고르게 고치기**

1. 내가 쓴(또는 고친) md 문서의 여백을 우클릭해 **다듬기 점검 요청**을 고릅니다. 몇 줄만이면 그 줄을 고르거나(Shift+↓) 장을 하이라이트(Alt+H)한 뒤 우클릭해 **이 범위 다듬기 점검 요청**을 고릅니다.
2. 터미널에서 Enter 를 누릅니다. Claude 가 파일을 고치기 전에 표를 보입니다 — 번호, 등급, 어디, 원문, 고친 안, 까닭.
3. 고를 것을 말합니다. "틀림만 고쳐 줘", "1·3·7번만", "취향 빼고 모두". 고른 곳만 고치고 나머지 글자는 그대로입니다. 고친 곳은 Lectern 에 바로 보입니다.

| 등급 | 무엇 | 예 |
|---|---|---|
| 틀림 | 고친 안이 하나뿐인 것 | 왠만하면 → 웬만하면, 상승세를 띄고 → 띠고, 지향·지양이 뒤바뀜 |
| 읽기 어려움 | 틀리지 않았지만 읽는 사람이 막히는 곳 | 겹말(남은 잔량), 번역투(~에 대한 검토를 진행하였다), 조건이 얽힌 긴 문장, 풀지 않은 약어 |
| 취향 | 둘 다 맞는 것 | 구매할 만한·구매할만한, 글 종류에 따라 관습인 공문 투 |
| 확인 필요 | 표현이 아니라 내용 | 앞뒤가 맞지 않는 숫자, 근거가 보이지 않는 주장 — 고치지 않고 알리기만 합니다 |

인용(따옴표·인용 상자 안, 규정에서 옮긴 문장), 숫자 값, 기관·법령 이름, 맞게 쓴 말(대금 결제의 '결제', '일절')은 건드리지 않습니다. 같은 버릇이 되풀이되면 끝에 '자주 나온 것'으로 알려 줍니다. 그냥 "다듬어 줘"라고 시키면 Claude 가 묻지 않고 내용까지 고쳐 쓰기 쉽습니다 — 다듬기 점검 요청은 표를 먼저 보이게 합니다.

예제 폴더처럼 보기만 하는 프로젝트(Lectern 프로그램 폴더 안)에서는 터미널이 열리지 않아 요청 글이 들어가지 않습니다. 예제의 연습 보고서는 내 폴더로 복사해서 해 봅니다.

**내 문체 — 내 글에서 지킬 것과 버릇을 노트로**

1. 내가 직접 쓴 글(AI 와 함께 쓴 글은 빼고)의 여백을 우클릭해 **내 문체 견본으로 보내기**를 고릅니다. 여러 편을 한 번에 보내려면 설정 창 **내 문체**의 요청 글 끝에 `@경로` 를 이어 붙입니다 (문서를 우클릭해 **위치 복사**). Word·PDF 로 쓴 예전 보고서도 됩니다.
2. Claude 가 세 칸으로 정리한 노트 초안을 보입니다. 아직 저장하지 않습니다.
   - **지킬 것**: 읽는 사람이 기대하는 규칙 — 말투, 용어, 숫자·단위·날짜 쓰는 법.
   - **참고할 것**: 즐겨 쓰는 방식 — 문장 길이, 결론을 두는 자리. 글 종류와 읽는 사람이 맞을 때만 씁니다.
   - **따라 하지 않을 것**: 읽기 어렵게 하는 버릇 — 겹말, 번역투, 아주 긴 문장. 글을 쓸 때 따라 하지 않고 다듬기 점검 때 먼저 살핍니다.
3. 칸을 옮기거나 지우라고 말한 뒤("이건 내 방식이니 따라 해", "이건 빼") 좋다고 하면 저장합니다. Claude Code 는 개인 규칙 파일 `~/.claude/rules/내-문체.md` 하나에 넣고, 어느 폴더·어느 글쓰기 스타일에서나 같은 노트를 씁니다. 예전 판처럼 글쓰기 스타일 파일 끝에 '내 문체' 절이 있으면 이 파일로 옮길지 묻습니다. 그 파일은 `.claude` 폴더 안이라 Claude Code 가 고쳐도 되는지 한 번 더 묻습니다 — 허락합니다. Claude Code 를 다시 시작해야 읽습니다.
4. 견본을 더할 때마다 노트가 보태집니다. 두 편 넘게 나온 것만 적고, 예문은 견본을 옮기지 않고 새로 지어 씁니다 — 기밀 보고서가 견본이어도 숫자·이름이 노트로 새지 않습니다.
5. 항목마다 '메모:', '서술식 보고서:', '공통:'처럼 어느 글 종류에서 본 것인지 붙습니다. 그래서 메모에서 뽑은 합니다체가 보고서로 번지지 않고, 노트에 없는 종류의 글에는 '공통:' 항목(용어, 숫자·날짜 표기, 출처 쓰는 법)만 쓰입니다.

내 문체는 보고서 글의 기본보다 앞서지 않습니다. 용어·말투 같은 지킬 것은 따르지만, 읽기 어렵게 하는 버릇은 따라 하지 않습니다. 폴더마다 다른 규칙(기관 양식, 존댓말)은 그 폴더의 `CLAUDE.md` 에 둡니다.

### Codex·Antigravity·OpenCode 를 쓸 때

터미널은 어떤 프로그램이든 돌리므로 `claude` 대신 `codex`(OpenAI Codex CLI), `agy`(Google Antigravity CLI), `opencode`(OpenCode)를 띄워도 됩니다. 문서를 보면서 위치를 보내고(Shift+→, Shift+숫자), 고친 것이 바로 보이는 것은 같습니다. 이 설명서는 줄여서 'Claude' 라고 적지만 네 도구 모두에 해당합니다.

- 설정 창의 **쓰는 AI 도구**에서 Claude Code·Codex·Antigravity·OpenCode·여럿을 고릅니다. 화면의 이름이 따라 바뀌고('Codex로 보내기', 'Codex용 요청 복사'), 요청 글이 그 도구의 파일과 폴더를 말합니다. Lectern 이 도구를 실행하지는 않습니다 — 터미널에서 직접 띄웁니다.
- 도구마다 다른 것:

| | Claude Code | Codex | Antigravity | OpenCode |
|---|---|---|---|---|
| 터미널에서 | `claude` | `codex` | `agy` | `opencode` |
| 프로젝트의 지시 파일 | `CLAUDE.md` | `AGENTS.md` | `AGENTS.md` | `AGENTS.md` |
| 개인 스킬 폴더 | `~/.claude/skills` | `~/.agents/skills` | `~/.gemini/config/skills` | `~/.config/opencode/skills` |
| 프로젝트 스킬 폴더 | `.claude/skills` | `.agents/skills` | `.agents/skills` | `.agents/skills` |
| Lectern 요약 (모든 폴더) | `~/.claude/rules/lectern.md` | `~/.codex/AGENTS.md` 의 한 절 | `~/.gemini/AGENTS.md` 의 한 절 | `~/.config/opencode/AGENTS.md` 의 한 절 |
| 글쓰기 스타일 | 출력 스타일 (켤 곳을 고름) | 개인 지시 파일이나 `AGENTS.md` 의 '글쓰기' 절 | 같음 | 같음 |
| 내 문체 노트 | `~/.claude/rules/내-문체.md` | 개인 지시 파일의 '내 문체' 절 | 같음 | 같음 |
| 하던 대화 잇기 | `claude --continue` | `codex resume --last` | `agy --continue` | `opencode --continue` |

- **여럿**을 고르면 이름이 'AI'가 되고, 요청 글이 도구마다의 파일과 폴더를 함께 적습니다. 한 프로젝트에서 여러 도구를 쓰면 규칙은 `AGENTS.md` 에 두고 `CLAUDE.md` 에는 `@AGENTS.md` 한 줄만 두면 한 곳만 고칩니다.
- PowerPoint·Word 스킬 세 개는 네 도구가 함께 쓰는 형식(SKILL.md)이라 그대로 설치됩니다. OpenCode 는 `~/.claude/skills` 도 읽으므로 Claude Code 용으로 설치했으면 따로 설치하지 않아도 보입니다. Codex 의 개인 스킬 폴더는 `~/.agents/skills` 입니다 — 0.89 까지 요청 글이 말하던 `~/.codex/skills` 는 옛 자리입니다.
- Codex 는 `~/.codex/AGENTS.override.md` 가 있으면 개인 지시 파일 `~/.codex/AGENTS.md` 대신 그것만 읽습니다. 바뀌는 파일에 그렇게 알려 줍니다.
- 여러 줄을 터미널에 붙여 넣어도(메뉴의 ▣ 터미널, Ctrl+V) 네 도구 모두 보내지 않고 입력 칸에 그대로 둡니다. Enter 는 직접 누릅니다. 가운뎃점(·)·줄표(—)·말줄임(…) 같은 부호도 그대로 들어갑니다.
- Antigravity·Codex 는 작업 폴더 밖의 파일(Lectern 의 작성 안내·스킬 폴더)을 읽을 때 허용할지 물을 수 있습니다. 허용하면 이어서 합니다.
- OpenCode 처럼 화면 전체를 쓰는 도구는 쌓은 칸이 좁으면 아래쪽만 보입니다. 칸 사이 경계를 끌어 키우거나 터미널을 문서 아래(탭)에 둡니다.
- 터미널을 쌓아 1번은 Claude Code, 2번은 Codex 처럼 나란히 두고 Shift+숫자로 골라 보낼 수 있습니다.

## 설정

툴바의 톱니 버튼(Ctrl+,)으로 설정 창을 엽니다. 여기의 설정은 Lectern 전체에 듣습니다 — 폴더마다 따로 두지 않습니다. 열려 있는 독립창·슬라이드 창도 1~2초 안에 따라 바뀌고, 설정 파일을 편집기로 고쳐 저장해도 그렇습니다 (독립창에서만 바꾼 글자 크기 같은 화면 설정은 그 창에 남고, 다른 창에서 그 설정을 바꾸면 따라갑니다). 폴더나 문서에 딸린 것 — md 문서 스타일(그 문서의 머리글), 메모, 업무 카드, 마지막에 보던 위치 — 은 그대로 그 폴더·문서의 것입니다. 왼쪽 분류(일반·보기·편집·인쇄·내보내기·터미널·AI 도구·업무·고급)를 누르면 오른쪽이 그 절로 가고, 내리면 지금 절이 강조됩니다. 다음에는 마지막에 고른 분류에서 열립니다. 고르는 것은 한 줄 단추(고른 것의 설명이 아래에), 켜고 끄는 것은 오른쪽 끝의 스위치입니다. 고른 즉시 반영되고 저장 단추는 없습니다.

**AI 도구**의 아래쪽 **AI 도구에 건네는 것**(작성 안내 요약·스킬·글쓰기 스타일·내 문체)은 Lectern 의 설정이 아니라 AI 도구의 파일입니다. 항목마다 넣을 곳(기본은 **모든 폴더(개인)** — 이 PC 의 모든 폴더에서 듣는 개인 폴더, 글쓰기 스타일은 켤 곳)을 고르면, 아래 **바뀌는 파일**에 전체 경로와 할 일(새로 만듦·바꿈·그대로·한 값 적기)이 보입니다. 지금 상태를 보이려고 Lectern 이 개인 폴더(`~/.claude` 등)와 열린 폴더의 정해진 파일 몇 개를 읽기만 합니다 — 설정 파일에서는 `outputStyle` 값 하나만. 파일을 쓰는 것은 요청 글을 받은 AI 도구가 지금 상태를 알리고 물은 뒤입니다. 개인 폴더(`~/.claude`)나 폴더의 `.claude` 안에 쓸 때는 Claude Code 가 허락을 한 번 더 묻습니다 — 바뀌는 파일에서 본 것과 같으면 허락합니다.

관련 화면에서 그 분류로 바로 열 수도 있습니다 — 터미널 머리줄 우클릭 **터미널 설정…**, 툴바 스타일 목록 맨 아래 **스타일 설정…**, 업무 현황의 **업무 설정…**, 상태줄의 **vi** 표시, 내보내기 창의 **글꼴·틀 설정…**. **고급**에는 설정 파일에서만 고치는 편집기 경로·제외 폴더·터미널 셸의 지금 값이 보입니다.

| 설정 | 하는 일 |
|---|---|
| 언어 · Language | 자동(Windows 표시 언어)·한국어·English. 바꾸면 화면을 다시 불러옴 |
| 마지막 위치에서 시작 | 폴더를 열면 마지막에 보던 문서와 위치로 |
| 첫 단계 폴더 펼치기 | 폴더를 열 때 트리의 첫 단계 폴더를 펼쳐 둠 |
| 스타일 목록 묶기 | 스타일 목록을 용도별·분위기별·밝기별로 묶음 |

| 표 칸 맞춤 | md 문서 표의 칸 맞춤 — 기본(글 왼쪽·숫자 오른쪽·위)·보고서식(머리행과 짧은 열 가운데, 숫자 오른쪽, 긴 글 왼쪽, 세로 가운데). 원문에 맞춤 표시가 있는 열은 그 표시대로 |
| 수식 표시 | `$…$`·`$$…$$`·math 코드 블록을 수식으로 그림 |
| 문단 안의 줄바꿈 보이기 | 원문에서 Enter 로 바꾼 줄이 화면에서도 바뀜 (Word 의 Shift+Enter 처럼). 끄면 표준 Markdown 처럼 이어서 보임 |
| 인터넷 그림 표시 | 문서 속 https 그림을 불러옴. 끄면 링크로만 보임 |
| vi 키 | 문서에서 글자 키로 움직이고 고침 (위 'vi 키'). 기본은 꺼짐 |
| 전체 편집 방식 | 기본 방식(Esc 로 닫기)·vi 방식(vim 처럼 — `:w`·`:q`). 기본은 기본 방식 |
| 인쇄·PDF 글꼴 | 'PDF로 저장…'·'인쇄…' 의 본문 글꼴 — 명조(기본)·고딕 (위 '인쇄·PDF·html·Word') |

| 업무 관리 | 공통 폴더 고르기·비우기, 업무 폴더 목록에서 빼기 (위 '업무 관리') |
| 업무 알림 | Lectern 이 켜져 있는 동안 창 안의 업무 알림. 기본은 켜짐 |

설정 창에 없는 설정은 **설정 파일 열기**를 눌러 편집기에서 고칩니다 (`%APPDATA%\Lectern\config.json`). 저장하면 반영되고, 트리에 영향을 주는 설정은 F5 를 누르면 다시 불러옵니다.

**설정 원문 보기**(설정 창 '고급', AI 항목마다의 **원문 보기**)는 파일을 고치지 않고 원문 그대로 보입니다 — Lectern 설정, 작성 안내 요약, 내 문체 노트, Claude Code 설정(개인·이 폴더), 글쓰기 스타일(설치한 것과 Lectern 에 든 것), 스킬(SKILL.md 와 그 폴더의 파일). 원문 줄 사이의 **번호 없는 흐린 `//` 줄**은 Lectern 이 단 설명이고 파일에는 없습니다 — 열쇠마다 뜻, 기본 값, 바꾸는 곳(설정 창의 어느 분류인지, 'Lectern 이 기록', '이 파일에서만'). 형식이 틀린 값과 Lectern 이 쓰지 않는 열쇠도 알려 줍니다. Claude Code 개인 설정에는 비밀 값이 있을 수 있으니 화면을 나눌 때 조심합니다.

| 키 | 하는 일 |
|---|---|
| `language` | `auto`·`ko`·`en` |
| `editor` | 코드 파일을 열 편집기의 전체 경로. 비워 두면 VS Code(`code`) |
| `exclude_dirs` | 트리에서 뺄 폴더 이름 (예: `["data", "output"]`) — '자료' 목록에는 접혀 나옵니다 |
| `terminal_shell` | 터미널 셸의 전체 경로 (예: PowerShell 7). 비워 두면 Windows PowerShell |

경로의 역슬래시는 `\\` 로 두 번 씁니다. 파일에 문법 오류가 있으면 기본 설정으로 열리고 오류 위치를 알려 줍니다.

## 단축키

툴바의 **?** 버튼이나 Ctrl+/ 로 언제든 이 표를 띄울 수 있습니다. 표는 탭 여덟으로 나뉘고, 열 때마다 첫 탭 **자주 쓰는 것**(처음 익힐 스무 가지)에서 시작합니다. 탭은 누르거나 Ctrl+Tab 으로 옮기고, 위의 찾기 칸에 `표`·`Ctrl+K` 처럼 하는 일이나 키를 치면 모든 탭에서 찾습니다. **Shift+F1** 은 예제 프로젝트를 엽니다.

## 알아 둘 점

- 앱은 스스로 파일을 고치지 않습니다. 파일이 바뀌는 것은 사용자가 고를 때뿐입니다 — 한 줄 편집·줄 구조·서식 키·체크 칸(누르는 순간 저장), 전체 편집의 저장, 업무 나무·칸반·일정 더하기, 새 문서·새 파일·새 폴더·이름 바꾸기·문서 삭제(휴지통), 그림 붙여 넣기, 메모, 내보내기(PDF·html·Word·pptx). 그 밖에 쓰는 것은 설정 폴더(`%APPDATA%\Lectern`)의 설정과 제목 기억뿐입니다. 단, 오른쪽 터미널은 보통의 PowerShell 이라 거기서 친 명령은 그대로 실행됩니다.
- 터미널은 Windows 10(1809) 이상에서 됩니다. 셸의 화면 기록은 앱을 닫으면 사라집니다.
- 트리의 문서 제목은 문서 앞부분에서 찾습니다. 앞부분이 아주 긴 frontmatter 면 파일 이름으로 나옵니다.
- 인터넷 그림을 불러오지 못하면(사내망에서 막혔거나 15초가 넘으면) 링크로 바뀝니다.
- Lectern 은 MIT 라이선스입니다. 함께 든 오픈소스(Python, pywebview, Markdown·차트·편집기 라이브러리 등)의 저작권 표시와 라이선스 전문은 설치한 프로그램 폴더의 `THIRD-PARTY-NOTICES.md` 에, Lectern 의 라이선스는 `LICENSE.txt` 에 있습니다.

# Lectern 사용설명서

Lectern(렉턴, 독서대)은 Markdown 문서를 중심으로 사람과 AI가 함께 리서치하는 작업 환경입니다. Claude Code나 Claude가 프로젝트 폴더에 만든 문서와 자료를 사람이 읽고 살피고 그 자리에서 고칩니다. Markdown(`.md`)·HTML(`.html`) 문서를 읽기 좋게 보여 주고, 코드는 읽기 화면으로 보여 줍니다.

- **파일은 고를 때만 바꿉니다.** 앱이 스스로 문서를 만들거나 고치거나 지우지 않습니다. 디스크에 쓰는 것은 설정 파일과, 저장·새 문서·이름 바꾸기로 직접 고른 파일뿐입니다. 오른쪽 터미널에서 직접 친 명령도 예외입니다.
- **스스로 인터넷에 연결하지 않습니다.** 문서 속 인터넷 그림만 불러오고, 이것도 설정 창에서 끌 수 있습니다.
- **고른 폴더 안만 봅니다.** 숨김 파일·폴더(`.git`, `.claude` 등)는 보이지 않습니다. `node_modules`·`dist` 같은 제외 폴더는 문서 트리와 검색에 나오지 않고, '자료' 목록에만 흐리게 나옵니다.

> [!TIP]
> 이 설명서는 F1 로 열고 닫습니다 (Esc 로도 닫힘). 왼쪽 차례를 누르면 그 장으로 가고, Ctrl+F 로 설명서 안에서 찾습니다. 단축키만 빨리 보려면 툴바의 **?** 버튼이나 Ctrl+/ 를 누르세요.

## 시작하기

처음이면 **Shift+F1** 로 예제 프로젝트를 열어 사용법을 차례대로 따라 해 봅니다 — [예제의 첫 문서](../../samples/README.md). 이 설명서의 장마다 맞는 예제가 '예제 —' 로 이어져 있고, 누르면 예제 탭에서 그 문서가 열립니다.

### 폴더 열기

- 탭 막대의 **+** 버튼(Ctrl+O)을 누르고 프로젝트 폴더를 고르면 새 탭으로 열립니다. 이미 열린 폴더면 그 탭으로 갑니다.
- **+** 옆 화살표에는 최근 연 폴더와 **예제 열기**가 있습니다.
- **예제 열기**(시작 화면에도 있음)는 Lectern 둘러보기와 문서 쓰는 법을 담은 예제 프로젝트를 엽니다. Claude Code 와 함께 하는 리서치 프로젝트처럼 꾸며져 있어 트리·코드·자료·차트를 바로 시험해 볼 수 있습니다. 예제는 Lectern 프로그램 폴더 안에 있어 **보기만** 합니다 — 그 탭에서는 터미널·편집 모드·새 문서·이름 바꾸기가 없습니다 (프로그램 파일 옆에서 명령이 돌거나 파일이 바뀌지 않게). 예제로 편집이나 Claude Code 를 써 보려면 예제 폴더를 다른 곳(문서 폴더 등)에 복사해 그 복사본을 엽니다 — 터미널 자리의 '탐색기에서 이 폴더 보기'로 폴더를 찾을 수 있습니다.
- 탐색기에서 폴더를 우클릭해 **Lectern으로 열기**를 골라도 됩니다. Lectern 이 이미 떠 있으면 새 창 대신 그 창에 탭으로 열립니다.
- Lectern 을 다시 실행하면 지난번에 열어 둔 탭들이 보던 문서·위치 그대로 열립니다.

### 화면 구성

예제 — [01 처음 둘러보기](../../samples/guide/01-처음-둘러보기.md): 화면 구성, 트리와 폴더 개요, 문서 열기, 뒤로 가기.

| 자리 | 하는 일 |
|---|---|
| 툴바 (맨 위) | 사이드바·뒤로·앞으로, **문서 열기**(Ctrl+P), 글자 크기 − 100% +, 문서 폭, **줄 번호**, 스타일, 하이라이트, 설정, **?**(단축키), 터미널 모음 |
| 탭 막대 | 열린 프로젝트마다 탭 하나, 폴더 열기(+), 오른쪽 끝에 **목차**·**터미널** 버튼 |
| 문서 탭 줄 | 본문 바로 위 — 이 프로젝트에서 열어 둔 문서들 (20개까지), 새 탭에 문서 열기(+), 오른쪽 끝에 열린 문서 탭 목록(∨)과 모두 펼치기(▦) |
| 사이드바 (왼쪽) | **파일**·**최근 변경**·**검색**·**모아 보기**·**담기** 탭. 경계를 끌어 폭을 바꿈 (두 번 누르면 기본 폭) |
| 본문 (가운데) | 문서, 폴더 개요, 코드 읽기 화면 |
| 목차 (오른쪽) | 지금 문서의 제목과 표·그림 같은 구성 요소. 터미널을 열면 그 자리에 터미널 |
| 상태줄 (맨 아래) | 문서 경로와 수정 시각, '바뀐 곳' 버튼, 변경 감시 상태 |

## 프로젝트 탭

- 폴더마다 탭이 하나씩 생깁니다 (10개까지). 탭을 누르면 사이드바와 본문이 그 프로젝트의 것으로 바뀌고, 탭마다 보던 문서와 스크롤 위치가 그대로 남습니다.
- 이미 고른 탭을 또 누르면 그 프로젝트의 개요가 나옵니다. 탭을 우클릭하면 프로젝트 개요, 맨 위 폴더에 새 문서, 프로젝트의 모아 보기도 있습니다.
- 뒤에 있는 탭의 문서가 바뀌면 탭 이름 옆에 점이 붙습니다.
- 이름이 같은 폴더는 상위 폴더 이름이 함께 보입니다.
- 닫기: 탭의 ×, 마우스 가운데 버튼, Ctrl+Shift+W. 탭을 우클릭하면 다른 탭 모두 닫기·전체 경로 복사·탐색기에서 보기도 있습니다. 프로젝트는 그대로 두고 그 안에 열린 문서만 정리하려면 탭을 우클릭해 **열린 문서 모두 닫기**를 고릅니다 (아래 '문서 탭').
- 옮겨 다니기: Ctrl+1~8(그 순번의 탭), Ctrl+9(마지막 탭), Alt+PageDown / Alt+PageUp(다음 / 이전 탭).

## 문서 탭

한 프로젝트에서 문서를 20개까지 탭으로 열어 두고 오갑니다. 본문 바로 위의 문서 탭 줄에 보입니다.

- 사이드바의 문서를 **누르면 새 문서 탭**에서 열리고 보던 문서는 그대로 남습니다 — 트리·'코드'·'자료' 목록·폴더 보기·최근 변경·검색 결과·모아 보기·문서 열기(Ctrl+P)가 같습니다. 지금 탭이 폴더 개요면 그 자리에서 엽니다.
- **Ctrl+누르기**·**마우스 가운데 버튼**은 보던 문서를 두고 뒤에서 새 문서 탭을 엽니다 (브라우저처럼 — 탭은 누를 때 그립니다). **Alt+누르기**는 지금 탭에서 엽니다. 빠른 열기는 Enter·Ctrl+Enter·Alt+Enter 가 같습니다.
- 본문의 링크·경로 표기는 지금 탭에서 열립니다 (Alt+← 로 돌아옵니다). Ctrl+누르기·가운데 버튼·우클릭 **새 문서 탭에서 열기**로 새 문서 탭에 열 수 있습니다.
- 이미 다른 탭에 열려 있는 문서를 누르면 그 탭으로 갑니다 (같은 문서를 두 번 열지 않습니다).
- 20개가 차 있으면 가장 오래 안 본 탭에서 엽니다 (저장하지 않은 편집이 있는 탭은 건드리지 않습니다).
- **뒤로·앞으로**(Alt+←·→, 마우스의 뒤로·앞으로 버튼)는 다른 문서로 간 것뿐 아니라 같은 문서 안에서 뛴 것도 되돌립니다 — 목차, 절 링크, 각주, 찾기, 모아 보기·검색 결과로 간 뒤 누르면 읽던 자리(스크롤과 현재 위치)로 돌아오고, 그 자리가 접힌 절 안이면 펴 줍니다. 찾기는 결과를 몇 번 옮겨 다녀도 한 번이면 찾기 전 자리입니다. 스크롤이나 ↑·↓ 로 옮긴 것은 남지 않습니다.
- 탭마다 읽던 위치, 뒤로·앞으로 기록, 편집 모드에서 고치던 내용이 따로 남습니다. 저장하지 않은 편집이 있는 탭에는 **●** 가 붙습니다. 그래서 한 탭에서 문서를 고치면서 다른 탭에서 자료를 읽을 수 있고, 사이드바 '담기'의 보내기도 받는 문서를 그 문서의 탭에서 엽니다.
- 고르기: 탭을 누르거나 **Alt+1~8**(그 순번), **Alt+9**(마지막 탭). 탭이 많아 줄에 다 보이지 않으면 휠로 줄을 옆으로 넘기거나, 줄 오른쪽 끝의 **∨**(옆의 숫자는 열린 문서 탭 수)를 눌러 열린 문서 탭 목록에서 고릅니다. **Ctrl+Tab**·**Ctrl+Shift+Tab**(Ctrl+PageDown·PageUp 도)은 다음·이전 문서 탭입니다. 닫기: 탭의 ×, 마우스 가운데 버튼, **Ctrl+W**(Ctrl+F4 도 — 탭이 하나뿐이면 닫지 않습니다), **Ctrl+Shift+T** 는 닫은 문서 탭을 다시 엽니다. **Ctrl+T** 는 새 문서 탭에 문서를 엽니다. 탭을 우클릭하면 다른 문서 탭 모두 닫기와 경로 복사가 있습니다.
- **열린 문서 모두 닫기**: 문서 탭이나 프로젝트 탭을 우클릭(또는 문서 탭 줄의 **∨**)해 고르면 그 프로젝트의 문서 탭이 모두 닫히고 폴더 개요만 남습니다. 저장하지 않은 편집이 있으면 한 번 묻고, 그만두면 아무것도 닫지 않습니다. 닫은 문서는 **Ctrl+Shift+T** 로 하나씩 다시 엽니다. 독립창의 문서는 그대로입니다 (독립창은 창을 닫습니다).
- 문서 탭을 모두 닫으면 폴더 개요가 나옵니다 — 프로젝트를 처음 열었을 때의 화면입니다. 하나 남은 문서 탭도 **×**·**Ctrl+W**·가운데 버튼으로 닫습니다. 폴더 개요만 남았을 때 프로젝트를 닫으려면 **Ctrl+Shift+W** 를 누릅니다.
- 다음에 Lectern 을 열면 열어 두었던 문서 탭들이 그대로 돌아옵니다 (설정 '마지막 위치에서 시작'이 켜져 있을 때 — 고른 탭만 바로 그리고 나머지는 누를 때 그립니다). 문서 탭을 모두 닫아 폴더 개요만 남겼으면 다음에도 폴더 개요로 엽니다.

### 모두 펼치기

문서 탭 줄 오른쪽 끝, ∨ 옆의 **▦** 를 누르면 이 프로젝트의 문서 탭들을 창 전체에 격자로 펼칩니다 — 터미널 모음처럼. 다시 누르면 원래 화면으로 돌아옵니다.

- 칸 하나에 문서 탭 하나 (탭 차례대로), **오른쪽 아래 칸은 이 프로젝트의 터미널**입니다 — Claude Code 에 일을 맡기면서 여러 문서가 바뀌는 것을 한눈에 봅니다. 터미널이 닫혀 있었으면 열고(셸이 없으면 시작), 끝낼 때 다시 감춥니다 (셸은 그대로 돕니다).
- 칸 수가 격자에 맞지 않으면 옆이나 위의 문서 칸이 넓어져 빈 자리를 채웁니다. 사이드바와 목차는 감춥니다.
- 칸을 누르면 그 문서 탭이 골라집니다 (테두리 강조) — 상태줄·문서에서 찾기(Ctrl+F)·우클릭 메뉴·Alt+1~9 는 고른 칸의 것입니다. 바뀐 문서는 어느 칸이든 바로 다시 그립니다.
- 칸 머리의 **⤢**(또는 머리를 두 번 누르기)는 그 문서만 보도록 펼치기를 끝냅니다. 사이드바·목차 버튼(Ctrl+B)을 눌러도 끝나고 그것이 보입니다.
- 펼친 채 다른 프로젝트 탭을 고르면 그 프로젝트의 문서 탭들이 펼쳐집니다. 보기만 하는 프로젝트(예제)에는 터미널 칸이 없습니다.

### 독립창

문서를 별도 창으로 옮겨 나란히 볼 수 있습니다. 모니터가 둘이면 한쪽에 보고서, 다른 쪽에 자료를 두기 좋습니다.

- 옮기기: 문서 탭을 우클릭해 **새 창으로 옮기기**, 또는 **Ctrl+Shift+N**. 원래 창의 탭은 사라지고 독립창에 같은 위치로 열립니다.
- 탭은 두고 열기: 사이드바의 문서나 본문의 링크를 우클릭해 **새 창에서 열기**.
- 창 사이로 보내기: 독립창의 문서 탭을 우클릭해 **메인 창으로 보내기**. 다른 독립창이 떠 있으면 어느 창에서든 **(문서 이름) 창으로 보내기**가 나옵니다. 1초쯤 뒤에 받는 창의 새 문서 탭에 같은 위치로 열리고 그 창이 앞으로 나옵니다.
- 독립창의 마지막 문서를 보내면 그 창은 닫힙니다.
- 독립창에도 문서 탭을 여럿 둘 수 있습니다. 사이드바는 감춰져 있고 **Ctrl+B** 로 꺼냅니다. **Ctrl+T**·**Ctrl+P** 로도 문서를 엽니다.
- 독립창은 그 프로젝트에 속합니다. 메인 창에서 다른 프로젝트를 고르면 숨고, 돌아오면 탭과 스크롤 그대로 다시 보입니다. 프로젝트 탭을 닫으면 함께 닫힙니다.
- 독립창에서 **Claude 로 보내기**·**터미널** 버튼·**새 메모로 보내기**를 고르면 메인 창의 터미널·메모로 갑니다. Enter 는 누르지 않고, 메인 창이 앞으로 나옵니다. **Shift+→** 는 독립창에 머문 채 넣습니다. **Shift+숫자**와 메뉴의 숫자+누르기(아래 '터미널')도 메인 창의 그 번호 터미널로 갑니다.
- 프로젝트 탭·터미널·메모·설정·스타일은 메인 창에 있습니다. 메인 창에서 바꾼 스타일은 독립창을 다시 열 때 따릅니다.
- 글자 크기 같은 화면 조정은 그 창에서만 쓰이고 저장되지 않습니다.
- **Ctrl+W** 로 마지막 문서 탭을 닫으면 창이 닫힙니다. 메인 창을 닫으면 모두 닫힙니다. 독립창은 다음 실행에 다시 열리지 않습니다.
- 창은 8개까지 띄울 수 있습니다.

## 사이드바

### 파일 — 문서·코드·자료

'파일' 탭은 세 묶음으로 나뉩니다.

| 묶음 | 들어가는 것 | 누르면 |
|---|---|---|
| 문서 | Markdown·HTML 문서 (폴더 트리) | 한 번 눌러 본문에 열기 |
| 코드 | 소스(py·js·ts 등)·스크립트(ps1·bat·EViews 의 prg)·웹(css)·설정(json·yaml·toml) | 한 번 누르면 코드 읽기 화면, 두 번 누르면 편집기 |
| 자료 | 문서도 코드도 아닌 파일 — PDF·오피스·그림·데이터·압축·실행 파일 등 | 두 번 눌러 기본 앱으로 (실행·압축 파일은 실행하지 않고 탐색기에서 선택만) |

- 머리줄('문서 10', '코드 3', '자료 4')을 누르면 그 묶음이 접힙니다. 묶음 사이 분리선을 끌어 높이를 바꾸고, 두 번 누르면 기본 높이로 돌아갑니다.
- 위 입력칸으로 이름·제목을 거릅니다. **제목** 버튼을 켜면 파일 이름 대신 문서 제목으로 보입니다 (끄면 파일 이름, 마우스를 올리면 제목).
- **차례** 버튼으로 목록의 차례를 이름순·시간순·형식순으로 고릅니다. 언제나 폴더가 먼저이고 파일이 다음입니다. 시간순은 새것이 위로 오고, 폴더는 그 안의 가장 새 파일을 따릅니다. 형식순은 확장자 차례입니다.
- **폴더** 버튼을 켜면 문서·코드·자료를 나누지 않고 실제 폴더 구조 그대로 한 트리에 보입니다.
- **↕** 버튼(폴더 모두 펼치기·접기)으로 문서·코드·자료 목록의 폴더를 한 번에 **폴더 모두 펼치기**·**폴더 모두 접기**·**첫 단계 폴더만 펼치기**를 합니다. 제외 폴더(흐린 폴더)는 펼치지 않습니다 — 펼치면 안을 읽기 때문입니다.
- 아직 열어 보지 않은 바뀐 문서에는 호박색 점이 붙습니다.
- '코드'·'자료' 목록은 탐색기처럼 화살표 키(→ 펼치기, ← 접기)와 Enter 로 다루고, 글자를 치면 그 글자로 시작하는 항목으로 갑니다.
- `node_modules`·`dist`·`build`·`venv`·`__pycache__` 같은 **제외 폴더**는 '자료'에 흐린 접힌 폴더로 나옵니다. 파일이 아주 많을 수 있어 펼칠 때 안을 읽고, 안의 파일은 종류와 상관없이 모두 여기 보입니다 (코드는 한 번 누르면 읽기 화면). 안이 바뀌어도 저절로 따라오지 않으니, 접었다 다시 펼치거나 F5 를 누르면 새로 읽습니다. 머리줄 개수와 거르기에는 들어가지 않습니다.
- 우클릭 메뉴: `@경로 복사`(Claude Code 프롬프트에 붙이기), 전체 경로 복사, 외부 편집기로 열기, 탐색기에서 보기, **이름 바꾸기…**. 폴더를 우클릭하면 그 폴더만 모아 보기도 있습니다.
- **이름 바꾸기**: 문서 트리·'코드'·'자료' 목록(최근 변경·검색 결과도)에서 파일을 우클릭해 **이름 바꾸기…**, 또는 행을 고른 채 **F2**. 지금 이름이 확장자 앞까지 골라져 있으니 고쳐 쓰고 Enter (Esc 는 그대로 두기). 같은 폴더 안에서 이름만 바뀝니다.
  - 같은 이름의 파일이 있거나 쓸 수 없는 이름(점으로 시작, `\ / : * ? " < > |` 등)이면 까닭이 나오고 바꾸지 않습니다. 확장자를 바꾸면 한 번 더 묻습니다.
  - 보고 있던 문서 탭은 새 이름으로 이어지고(편집 중이었으면 편집도), 뒤로 가기 기록과 담은 조각도 따라갑니다. 저장하지 않은 편집이 있는 파일은 먼저 저장하거나 편집을 닫아야 합니다.
  - 다른 문서 속 이 문서를 가리키는 링크는 고치지 않습니다. 폴더 이름과 제외 폴더 안의 파일은 바꾸지 않고, 옮기기는 없습니다.
- **문서 삭제**: 문서 트리에서 문서를 우클릭해 **문서 삭제…** 를 고릅니다. 늘 먼저 묻고 **휴지통으로 보냅니다**. 휴지통에서 되살립니다. 코드와 자료는 지우지 않습니다. 네트워크 드라이브처럼 휴지통이 없는 곳은 지우지 않고 까닭을 알립니다. 저장하지 않은 편집이 있으면 지우지 않습니다.

### 최근 변경

- 고친 순서로 파일이 나옵니다. 위의 **문서**·**코드**·**자료** 버튼으로 보일 것을 고릅니다 (모두 켜면 섞어서 최근 것부터).
- 문서·코드는 한 번 누르면 열리고, 자료는 두 번 누르거나 Enter 로 엽니다. 우클릭하면 '코드'·'자료' 목록과 같은 메뉴가 나옵니다.
- '최근 변경' 탭 이름 옆의 숫자는 아직 열어 보지 않은 바뀐 문서 수입니다.

### 검색

- 모든 문서와 코드의 본문, 그리고 파일 이름에서 찾습니다 (Ctrl+Shift+F). 대소문자는 가리지 않습니다.
- 검색 칸 아래 **문서**·**코드**·**자료** 버튼으로 찾을 곳을 고릅니다. 맨 위에 **이름이 맞는 파일**(문서는 제목도)이 나오고, 그 아래 본문 결과가 문서 먼저, 그다음 '코드' 묶음으로 나옵니다. 자료(PDF·엑셀 등)는 이름으로만 찾습니다.
- 결과 줄을 누르면 그 문서(코드)의 그 줄로 가서 검색어를 표시합니다.
- 이름·제목으로 여는 것은 툴바의 **문서 열기**(Ctrl+P)가 더 빠릅니다. 맞는 문서가 먼저, 그다음 코드가 나옵니다.

### 모아 보기

- 맨 위에서 **문서 속 요소**·**문서 정보**·**파일 종류** 가운데 고릅니다.
- 문서 속 요소: 프로젝트의 표·그림·차트·박스글·강조글·다이어그램·코드·수식·할 일·링크·출처를 종류마다 문서별로 모아 봅니다. 종류 버튼('표 7'처럼)으로 고릅니다.
  - **차트**(Vega-Lite·ECharts·Plotly)는 그림처럼 작은 그림으로 모입니다 — 목록에서 보일 때 그립니다. Graphviz·Mermaid 는 다이어그램입니다.
  - **할 일**은 문서의 체크리스트(`- [ ]`·`- [x]`)입니다. 아래 단추로 **안 한 것**(처음)·한 것·모두를 고릅니다.
  - **링크**는 문서 속 링크와 `src/x.py:42` 같은 경로 표기를 대상(문서·코드·자료·폴더·인터넷)과 함께 보입니다. 가리키는 파일이 없으면 붉은 **깨짐** — 아래 단추 **깨진 것**으로 그것만 봅니다.
  - **출처**는 표·그림 아래의 '자료: …'·'출처: …' 같은 줄과 각주입니다.
  - 할 일·링크·출처는 목차에는 나오지 않습니다 (모아 보기에서만).
- 표·그림·다이어그램에 **캡션**이 있으면 캡션이 이름으로 보이고, 그 아래에 '표 3 · 6행 2열' 처럼 번호와 크기가 나옵니다. 캡션은 표 바로 위·그림 바로 아래의 '표 1. …'·'<표 2>'·'[그림 1]'·'〈표 Ⅱ-15〉' 같은 한 줄이나 통째로 굵게 쓴 짧은 한 줄, html 의 `<caption>`·`<figcaption>` 입니다. 없으면 표는 머리행, 그림은 대체 글로 보입니다.
- 누르면 그 문서의 그 자리로 가서 잠깐 테두리로 표시합니다.
- **우클릭**하면 문서에서 보기, **위치 복사**(`@문서 12~17행 ('캡션')`), **원문 복사**(md 문서), **담기**·**보내기…**·**보이는 것 모두 담기**(아래 '담기'), 문서 경로 복사가 나옵니다. 복사 항목 옆의 **▣ 터미널**을 누르면 그 글이 터미널에 들어갑니다 (Enter 는 누르지 않음).
- 폴더 개요의 '모아 보기' 버튼이나 트리에서 폴더를 우클릭하면 그 폴더만 모읍니다 ('전체'를 누르면 프로젝트 전체).
- 처음 열 때는 문서를 읽느라 잠깐 걸립니다.
- 문서 정보: 문서 맨 앞 설정(frontmatter — `status: 검토 중`, `owner: 리서치팀`, `tags: [a, b]` 같은 것)의 키마다 단추가 나오고, 고른 키의 값마다 문서가 묶입니다 (날짜는 최근 것부터). 들여 쓴 하위 키는 `author.name` 처럼 점으로 이어 나옵니다. 그 키가 없는 문서는 끝의 '값 없음'에. 문서를 누르면 열고, 우클릭하면 `@경로` 복사·터미널.
- 파일 종류: 문서·코드·자료마다 'PDF 2'·'엑셀 3'·'PNG 10'·'PY 12'·'IPYNB 2' 처럼 형식 버튼이 나오고, 고른 형식의 파일이 모입니다. 엑셀·파워포인트·워드·한글은 확장자가 달라도 한 이름으로 셉니다. 그림 파일은 작은 그림으로 보입니다. '트리 순서' 버튼으로 최근 수정한 파일부터 볼 수 있습니다.
- '코드'·'자료' 목록에서 폴더를 우클릭해 **이 폴더의 파일을 종류별로 모아 보기**를 고르면 그 폴더만 모읍니다.

### 담기

문서의 조각을 모아 문서 탭에 열린 문서나 새 문서로 보냅니다.

- **담는 법**: 본문에서 제목을 우클릭하면 **이 절 담기**(그 제목과 아래 내용 전부), 표·그림·차트·다이어그램·수식·코드·단락을 우클릭하면 **담기** — 표·그림·차트는 캡션과 바로 아래의 '자료:' 줄까지 함께 담습니다. 글을 고른 채 우클릭하면 **고른 글 담기**. 모아 보기에서는 항목 우클릭의 **담기**, 또는 **보이는 것 모두 담기**(거르기·단추로 좁힌 목록 그대로 — 예를 들어 프로젝트의 모든 표).
- 담은 것은 사이드바 **담기** 탭에 차례대로 쌓입니다 (탭 옆에 개수). ↑·↓ 로 순서를 바꾸고 ✕ 로 빼며, 누르면 원래 문서의 그 자리로 갑니다. 담는 순간의 내용이라 원래 문서가 나중에 바뀌어도 그대로입니다. 프로젝트 탭마다 따로이고, 앱을 끄면 비워집니다.
- **문서로 보내기…**(담기 탭 위 — 담은 것 모두, 차례대로) 또는 우클릭 메뉴의 **문서로 보내기…**(그 조각 하나만 바로)를 누르면 보낼 곳을 고릅니다: 편집 중인 곳(커서 자리), **새 문서…**, 또는 **문서 탭에 열린 문서** → **맨 끝**·**맨 앞**·**'…' 절 끝**.
- 받는 곳은 문서 탭에 열어 둔 문서와 새 문서뿐입니다. 다른 문서로 보내려면 먼저 그 문서를 문서 탭으로 엽니다 (트리에서 Ctrl+클릭 — 위 '문서 탭').
- 그 문서에 바로 들어가 저장됩니다. **Ctrl+Z** 한 번으로 되돌립니다. 받는 문서를 편집 모드로 고치고 있으면 편집기에 넣고, 저장은 **Ctrl+S** 로 합니다.
- **새 문서…**는 경로를 적고 Enter 를 누르면 그 자리에 제목 한 줄로 바로 만들고(아래 '새 문서 만들기'), 새 문서 탭에서 맨 끝으로 보냅니다.
- 보낼 때 맞춰 주는 것: 그림·링크·차트 데이터의 상대경로를 받는 문서 기준으로, 각주의 정의도 함께(이름이 겹치면 바꿈), 제목 수준을 받는 자리에(절 끝이면 그 절 아래). 조각마다 화면에 보이지 않는 `<!-- 담은 곳: research/a.md 12~19행 -->` 주석이 붙어, 나중에 Claude Code 가 출처를 알 수 있습니다.
- 다른 문서를 편집 모드로 열어 둔 채 담기 탭 항목의 **보내기**를 누르면 그 커서가 든 블록 뒤에 바로 들어갑니다.
- **Claude 에 맡기기**는 담은 것들의 위치(`@문서 12~19행 ('이름')`)를 묶어 새 문서로 만들어 달라는 Claude Code 요청 글입니다 — 복사하거나 ▣ 터미널로 넣습니다 (Enter 는 누르지 않음).
- 코드 화면의 줄과 html 문서의 블록은 담지 않습니다 (원문 줄이 없음). 받는 곳도 md 문서만입니다.

### 폴더 개요

폴더를 열면 처음 보이는 화면입니다. 방금 바뀐 문서, 하위 폴더, 문서마다 제목·요약·수정 시각이 나옵니다. 트리에서 폴더 이름을 누르면 그 폴더의 개요가, 고른 프로젝트 탭을 또 누르면 프로젝트의 개요가 나옵니다.

### 본문

예제 — [04 문서 쓰는 법](../../samples/guide/04-문서-쓰는-법.md)(표·강조글·각주·링크·그림의 원문과 결과), [05 수식](../../samples/guide/05-수식.md), [06 다이어그램](../../samples/guide/06-다이어그램.md), [07 차트](../../samples/guide/07-차트.md).

- 표는 숫자 열을 오른쪽에 맞추고, 머리행이 위에 붙어 따라옵니다. 표에 마우스를 올리면 오른쪽 위에 **복사** 단추가 보입니다 — 우클릭 '표 복사'와 같이 엑셀에 붙이면 칸이 나뉘고, 워드·메일에는 표로 붙습니다.
- 코드 블록은 언어 색으로 칠하고, 오른쪽 위 '복사' 버튼으로 복사합니다.
- 강조글(`> [!NOTE]` 같은 콜아웃 — 제목 줄 없이 종류의 색으로만), 각주, 체크리스트, 수식(`$…$`, `$$…$$`, math·latex 코드 블록), Mermaid 다이어그램을 그립니다. `$105` 같은 달러 표기는 수식으로 바꾸지 않습니다.
- **박스글**: 본문과 따로 읽는 글 상자입니다. 보고서에서 본문의 흐름과 떨어진 주제를 가볍게 다룰 때 씁니다. 원문에서 `<!-- box -->` 줄과 `<!-- /box -->` 줄 사이에 보통 글·표·그림을 쓰면, Lectern 은 테두리와 제목 띠가 있는 상자로 그립니다. 다른 뷰어에서는 두 줄이 보이지 않아 보통 글로 읽힙니다. 첫 줄을 한 줄로 쓰면 제목이 되고, `박스 1. 제목` 으로 쓰면 표·그림처럼 번호가 매겨져 `[박스 1](#박스-1)` 로 가리킵니다. 제목 띠 오른쪽의 화살표를 누르면 접고 폅니다 (접어 두어도 인쇄에는 모두 나옵니다). 닫는 줄을 빠뜨리면 다음 제목 앞에서 끝난 것으로 봅니다. 박스글 안에 제목(`#`)과 다른 박스글은 넣지 않습니다. 전에 '박스글'이라 부르던 `> [!NOTE]` 종류는 **강조글**로 이름을 바꾸었습니다.
- **차트**: 코드 블록의 언어를 `vega-lite`(데이터 차트), `echarts`(도넛·캔들 등 여러 차트), `plotly`(상자 그림·선버스트 등 분석용 차트 — Python 의 `fig.to_json()` 결과도), `dot` 또는 `graphviz`(구성도·의존 관계)로 적으면 그림으로 그립니다. 색은 문서 스타일을 따르고, 누르면 크게 보며, 우클릭 '그림 복사'로 PNG 를 붙입니다. 설정은 JSON 이고 함수는 쓸 수 없습니다. 데이터는 문서 안에 적거나 프로젝트 안의 CSV·JSON 파일을 상대경로로 가리킵니다 (인터넷 주소는 읽지 않습니다). 마우스를 올려 값 보기 같은 움직임은 없고, Plotly 의 지도 차트는 인터넷의 지도 자료가 있어야 해서 그리지 않습니다. 예제(**예제 열기**)의 `guide/07-차트.md` 에 종류마다 예가 있습니다.
- **차트의 데이터**: 차트에 마우스를 올리면 오른쪽 위에 **표**·**복사** 단추가 보입니다. **표**는 차트를 그린 데이터를 차트 아래에 표로 펼치고, 다시 누르면 접습니다. 30행이 넘으면 처음·끝과 일정한 간격의 30행만 보이고 **모두 보기**로 5,000행까지 펼칩니다. **복사**는 데이터 전부를 엑셀(칸이 나뉨)·워드(표)에 붙일 수 있게 복사합니다. 데이터는 차트의 원문에서 읽습니다 — 차트가 값을 거르거나 합쳐 그리면(변환·집계) 표는 그 전의 값입니다. 데이터가 CSV 파일에 있는 차트는 표 대신 파일 이름을 알리고 **데이터를 문서 안으로 넣기**를 보입니다. 누르면 그 CSV 를 읽어 차트의 원문에 값으로 넣습니다 — 문서만 보내도 다른 PC 에서 차트와 표가 보입니다 (Ctrl+Z 로 되돌립니다). Lectern 슬라이드의 차트와 Graphviz 에는 단추가 없고, 단추와 표는 인쇄·PDF 에 나오지 않습니다.
- 문단 안에서 Enter 로 바꾼 줄은 화면에서도 줄이 바뀝니다 (Word 의 Shift+Enter 처럼 — 개조식 글이 그대로 보입니다). 줄 끝 공백 두 개와 `<br>` 도 같습니다. 표준 Markdown 처럼 이어서 보려면 설정에서 끕니다.
- 그림을 누르면 크게 보입니다.
- 본문의 `src/app.py:42` 처럼 실제로 있는 파일 경로는 링크가 됩니다.

### 목차

- 오른쪽 목차를 누르면 그 제목으로 가고, 지금 읽는 곳이 표시됩니다.
- 제목 아래에는 그 절의 표·그림·박스글·강조글·다이어그램·코드·수식이 '표 1 · 가격 비교 · 6행 4열'처럼 나옵니다. 누르면 그 자리로 갑니다.
- 목차 위의 '표 2'·'코드 5' 같은 버튼을 누르면 그 종류를 목차에서 감추고, 다시 누르면 보입니다.
- 탭 막대 오른쪽 끝의 **목차** 버튼으로 목차를 보이고 감춥니다.
- 문서와 목차 사이 경계를 끌어 목차 폭을 바꿉니다. 두 번 누르면 기본 폭으로 돌아갑니다.
- **절 옮기기**: 고칠 수 있는 md 문서에서는 목차의 제목을 끌어 다른 제목 위에 놓으면 그 절을 본문·하위 절과 함께 그 앞으로 옮깁니다. 마지막 제목의 아래쪽에 놓으면 문서 끝으로 갑니다. 수준은 그대로이고 Ctrl+Z 로 되돌립니다.

### 절 접기

제목 왼쪽 여백의 화살표를 누르면 그 절이 접히고, 다시 누르면 펼쳐집니다 (화살표는 제목 위에 마우스를 올리면 보입니다). 키보드는 **Ctrl+Shift+[** 로 현재 줄이 든 절을 접고 **Ctrl+Shift+]** 로 폅니다 — 이미 접혔으면 Ctrl+Shift+[ 는 바깥 절을 접고, 펴져 있으면 Ctrl+Shift+] 는 그 안의 접힌 하위 절을 폅니다. 제목 글자를 누르면 접히지 않고 그 줄이 현재 줄이 됩니다. 본문을 우클릭하면 같은 수준 제목 모두 접기, 모두 접기·펴기도 있습니다. 접어 둔 절은 앱을 다시 실행하면 펼쳐집니다.

### 글자 크기와 스타일

- 툴바의 − / + 로 문서 글자를 80%~200%로 바꿉니다 (100% 도 읽기 좋게 조금 크게 잡혀 있습니다). 가운데 '100%'를 누르면 처음 크기로 돌아갑니다. 앱 화면 전체를 키우려면 Ctrl+휠을 씁니다.
- 그 옆의 **문서 폭** 버튼(좁게 · 폭 100% · 넓게)으로 md 문서 본문의 좌우 폭을 80%~200%로, 끝까지 넓히면 **가득**(문서 칸 폭 전체)으로 바꿉니다. 글자 크기는 그대로이고 한 줄이 길어지거나 짧아집니다. 가운데를 누르면 처음 폭으로 돌아가고, 고른 폭은 다음 실행에도 그대로입니다. 창이 좁아 문서 칸이 본문보다 좁으면 칸 폭까지만 넓어집니다. 코드 화면·Lectern 슬라이드·자기 스타일이 있는 HTML 문서는 그대로입니다.
- 표의 머리행과 맨 왼쪽 열은 낱말 가운데서 끊지 않습니다 (띄어쓰기에서 감깁니다. 긴 낱말 때문에 표가 옆으로 넘치면 그 표만 예전처럼 끊습니다).
- 툴바의 **줄 번호** 버튼이나 **Alt+L** 로 Markdown 문서 왼쪽 여백에 원문 줄 번호를 보이고 감춥니다. 번호는 Claude 에 보내는 `@경로 12행` 과 같은 줄입니다. 빈 줄처럼 화면에 없는 줄의 번호는 건너뛰고, 화면에서 꺾인 글은 첫 줄에만 붙습니다. 코드 화면에는 늘 번호가 있습니다. 인쇄에는 나오지 않습니다.
- 표에서 **맨 왼쪽 열의 글이 다른 열보다 여러 줄로 감겨 행이 높아지면** 첫 열을 저절로 넓힙니다. 넓힐 폭은 가장 넓은 열에서만 가져오고, 넓혀도 표가 높아지면 그대로 둡니다. 창·사이드바 폭이나 글자 크기·문서 폭을 바꾸면 다시 맞춥니다 (파일은 그대로).
- **스타일** 목록에서 24종 중 고르면 본문과 툴바·사이드바 색이 함께 바뀝니다. 목록 옆 ∧·∨ 로 위·아래 스타일을 차례로 견주어 볼 수 있습니다. '자동'은 Windows 다크 모드를 따릅니다.
- 스타일 목록을 용도별·분위기별·밝기별 중 어떻게 묶을지는 설정 창에서 고릅니다.

### 내 스타일

- 원하는 모양의 스타일을 직접 만들 수 있습니다. CSS 파일 하나가 스타일 하나이고, `%APPDATA%\Lectern\styles` 폴더에 두면 스타일 목록 맨 아래 **내 스타일**에 나옵니다.
- 직접 쓰지 않아도 됩니다. 설정 창의 **Claude Code용 요청 복사**를 누르고 Claude Code 에 붙여 넣은 뒤 원하는 모양(예: '남색 제목, 표 머리행은 짙은 남색에 흰 글자, 본문은 명조')을 이어서 적으세요. 요청 글에는 앱에 든 스타일 설명서와 저장할 폴더의 위치가 들어 있어, AI 가 설명서를 읽고 파일을 만듭니다. 옆의 터미널 버튼을 누르면 그 글이 터미널에 바로 들어갑니다.
- 그 스타일을 고른 채 파일이 고쳐지면 몇 초 안에 다시 입혀집니다 — '제목을 더 크게' 처럼 이어서 부탁하며 바로 보면서 다듬을 수 있습니다.
- 설정 창의 **스타일 폴더 열기**로 폴더를 엽니다. 파일을 지우면 목록에서 빠집니다.
- 인터넷에서 글꼴·그림을 불러오는 부분은 앱이 지웁니다. 글꼴은 PC 에 있는 것만 쓰입니다.

### 현재 줄

Markdown 문서와 코드 화면(csv·txt 포함)에서는 줄을 원문 파일의 줄로 셉니다 — 한 줄로 쓴 문단·목록 항목·제목·표의 행은 통째로 한 줄, 여러 줄로 나눠 쓴 문단은 줄마다, 코드는 줄마다입니다. 그래서 Claude 에 보내는 `@경로 12~20행` 이 화면에서 고른 곳과 같습니다.

- **현재 줄**: 지금 보는 줄 왼쪽의 작은 삼각형입니다. 본문을 누르거나 우클릭하면 그 줄로, **↑·↓** 로 한 줄씩 옮기고 화면이 따라갑니다. 휠·PageUp·PageDown 으로 스크롤해 화면 밖으로 나가면 화면 안의 가장 가까운 줄로 따라옵니다. 목차·찾기·검색으로 가면 그 줄로 옮깁니다. 상태줄에 `현재 줄 12행` 처럼 보이고, 문서 탭마다 따로 남습니다.
- **Claude로 보내기**: **Shift+→** 를 누르면 현재 줄(고른 줄이 있으면 그 범위)의 위치 `@경로 12~20행` 이 맨 앞 터미널(보통 1번 — Claude Code 를 돌리는 곳)에 들어갑니다. Enter 는 누르지 않고 초점이 터미널로 가서 바로 요청을 적을 수 있습니다. 여러 곳을 이어서 넣으려면 **Ctrl+Shift+→** 를 누르세요 — 초점이 문서에 남습니다. 터미널이 여럿이면 **Shift+숫자**(Ctrl+Shift+숫자)로 그 번호의 터미널에 넣습니다. **Shift+←** 는 그 위치를, **Ctrl+C** 는 그 줄들의 원문을 복사합니다 (글자를 끌어 고른 것이 있으면 Ctrl+C 는 그 글).
- **장 하이라이트**: 툴바의 **하이라이트** 버튼이나 **Alt+H** 를 누르면 현재 줄이 있는 장만 또렷해집니다. ↑·↓, PageUp·PageDown, 버튼 옆 ∧·∨ 로 앞뒤 장으로 갑니다. 흐린 곳을 누르면 그 장으로 옮깁니다. Shift+↑·↓ 를 누르면 그 장이 고른 줄이 됩니다. Esc·버튼으로 끄고, 본문을 우클릭해 '이 장 하이라이트'를 골라도 됩니다. 장으로 나뉘지 않은 문서와 코드 화면에서는 버튼이 Shift+Enter 와 같습니다.
- 줄을 고르고 고치는 일은 '문서 쓰고 고치기' 장에 있습니다.

### 문서에서 찾기

- Ctrl+F 는 지금 보는 문서나 코드에서 찾습니다. 굵게·코드 같은 서식이 섞여도 찾습니다.
- Enter 는 다음, Shift+Enter 는 이전 결과, Esc 는 닫기입니다.

### HTML 문서

Claude 가 만든 html 보고서는 트리에 `HTML` 표시와 함께 나옵니다. 문서의 스타일은 그대로 보이고, 스크립트와 인터넷 CSS 는 막습니다 (스크립트로 그리는 차트는 보이지 않습니다). `src`·`public`·`web` 같은 앱 소스 폴더의 html 은 문서로 보지 않습니다.

### 자동 새로고침

- Claude 가 문서를 쓰는 동안 1초 안에 반영되고, 보던 위치는 그대로입니다.
- 바뀐 문단·표는 잠깐 배경색으로 표시됩니다. 화면 밖에서 바뀌었으면 상태줄의 **바뀐 곳** 버튼으로 차례로 갑니다.
- 글이 그대로면 화면을 다시 그리지 않아 고른 글이 남습니다. 글을 끌어 고르는 동안에는 마우스를 놓을 때까지 기다립니다.
- 글이 실제로 바뀌면 화면을 다시 그리므로 고른 글은 풀립니다.
- 감시가 놓친 변경은 F5 를 누르면 다시 불러옵니다.

### 인쇄·PDF

탭 막대 오른쪽 끝의 **인쇄** 버튼(목차와 메모 사이)을 누르거나, 본문 여백을 우클릭해 **PDF로 저장…** 이나 **인쇄…** 를 고릅니다. 종이와 PDF 는 화면 스타일과 상관없이 늘 같은 **보고서 양식**입니다 — A4, 여백 위 25·아래 22·좌우 22mm, 첫 쪽 가운데 제목, 2쪽부터 머리에 문서 제목과 날짜(맨 앞 설정의 `date`, 없으면 오늘), 바닥 가운데 쪽 번호. 표는 위아래 굵은 줄, 링크는 검은 글자로 나오고 주소는 '출처'·'참고문헌'·'자료' 절의 목록에만 붙습니다. 맨 앞 설정 표는 싣지 않습니다. 본문 글꼴은 설정 창의 **인쇄·PDF 글꼴**에서 명조(기본)·고딕을 고릅니다.

둘 다 **PDF·인쇄** 창을 엽니다. 왼쪽에서 옵션을 고르면 오른쪽 미리보기가 그 옵션으로 다시 만들어집니다 — 미리보기가 저장·인쇄될 PDF 그대로입니다 (목차·확대·쪽 넘기기는 미리보기 위 막대로).

| 옵션 | 고르는 것 |
|---|---|
| 글꼴 | 명조(함초롬바탕, 없으면 바탕 — 제목은 고딕)·고딕(맑은 고딕) |
| 여백 | 보통(위 25·아래 22·좌우 22mm)·좁게(사방 15mm)·넓게(위 30·아래 25·좌우 30mm) |
| 쪽 머리 | 2쪽부터 머리에 문서 제목과 날짜 |
| 쪽 번호 | 바닥 가운데 '- 1 -' |

옵션은 다음에도 그대로입니다.

- **PDF로 저장…**: 미리 본 PDF 를 저장 대화상자에서 고른 곳에 씁니다 (문서 옆, 문서 이름으로 열립니다). 브라우저가 붙이는 날짜·주소 머리글이 없고, 제목이 PDF 책갈피가 됩니다. 같은 이름이 있으면 Windows 가 덮어쓸지 묻습니다. PDF 보기 프로그램이 그 파일을 열고 있으면 닫고 다시 저장합니다.
- **인쇄…**: 미리 본 PDF 를 인쇄 창으로 보냅니다. 프린터·매수·쪽·색은 인쇄 창에서 고릅니다. PDF 를 인쇄하는 것이라 날짜·주소 머리글이 붙지 않습니다.
- Esc 나 **닫기**로 창을 닫습니다 (미리보기 안을 누른 뒤에는 마우스를 미리보기 밖으로).
- html 문서는 그 문서 자체의 스타일로 인쇄 창 하나(**인쇄 / PDF로 저장…**)만 있습니다 — PDF 는 프린터에서 'Microsoft Print to PDF'를 고릅니다.

Lectern 슬라이드는 슬라이드 크기의 쪽에 한 장씩 나옵니다 (아래 'Lectern 슬라이드'). 넣기 창의 **쪽 나눔** 줄에서 쪽이 바뀌고, **목차** 줄은 그 자리에 목차로 인쇄됩니다 (아래 '구성 요소 넣기').

- 화면의 글자 크기·문서 폭·줄 번호·찾기 표시·하이라이트·스타일은 종이에 들어가지 않습니다. 12행이 넘는 표는 쪽을 나눠 싣고 머리행을 쪽마다 되풀이하며, 캡션은 표·그림과 같은 쪽에 붙고, 쪽보다 큰 그림은 한 쪽 높이로 줄입니다.
- 편집 중이면 저장하고 편집을 닫은 뒤 저장합니다 (PDF 는 저장한 내용으로). 모두 펼치기에서는 우클릭한 칸의 문서가 PDF 가 됩니다.

예제 — [12 보고서와 PDF](../../samples/guide/12-보고서와-PDF.md): 글쓰기 스타일로 보고서를 쓰게 하는 요청의 예, PDF 에 잘 나오게 쓰는 법, Claude 가 쓴 견본 보고서로 해 보기.

## 문서 쓰고 고치기

전체 편집을 열지 않고 md 문서를 처음부터 끝까지 쓰고 고칩니다.

예제 — [08 한 줄 편집](../../samples/guide/08-한-줄-편집.md): 줄 고르기와 사례 스무 가지를 따라 해 봅니다.

**저장은 따로 하지 않습니다.** 칸의 Enter, 줄 옮기기·지우기, 줄 종류·레벨 바꾸기, 표의 행·열, 체크 칸, 그림 붙여 넣기는 누르는 순간 원문 파일에 저장되고, 하나하나 **Ctrl+Z** 로 되돌립니다. 새 줄은 글을 쓸 때 저장되고, 칸에서 Esc 를 누르면 고친 것을 버립니다. Lectern 슬라이드도 같습니다. Ctrl+S 로 저장하는 것은 전체 편집뿐입니다. 현재 줄을 옮기거나 줄을 고르거나 하이라이트·접기를 하는 것은 파일을 바꾸지 않습니다.

### 줄의 네 상태

| 상태 | 무엇인가 | 들어가기 | 나오기 |
|---|---|---|---|
| **현재 줄** | 자리 — 어디에 쓰고 넣을지 | 누르기, 우클릭, ↑·↓ | — |
| **고른 줄** | 대상 — 지우고 옮기고 바꿀 줄. 한 줄도 여러 줄도 됩니다 | **Insert**, **Ctrl+L**, **Shift+Enter**, Shift+↑·↓, Shift+누르기·끌기 | Esc, ↑·↓, 바깥 누르기, 칸 열기 |
| **하이라이트** | 고른 줄의 라이트 — 나머지를 흐리게 하고 보기만 | 고른 줄에서 **Shift+Enter**, 툴바 버튼 | Shift+Enter·Esc·툴바 버튼·흐린 곳 누르기 — 고른 줄로 돌아갑니다 |
| **칸** | 그 줄을 화면의 그 자리에서 고치는 글 칸 | **F2**, 두 번 누르기, Ctrl+Enter | Enter 저장, Esc 그만두기 |

- **현재 줄은 '어디에', 고른 줄은 '무엇을'** 맡습니다. 새 줄·그림·구성 요소는 현재 줄에 들어가고(줄을 골랐으면 끝 줄 아래), 지우기·옮기기·줄 종류·레벨은 고른 줄에 합니다.
- **파일을 바꾸는 키는 칸이나 고른 줄에서만 됩니다**: 현재 줄에서 Delete·Ctrl+X·Alt+↑·↓·Ctrl+Alt+숫자·Alt+Shift+←·→ 를 누르면 '줄을 먼저 고르세요'라고 알립니다 — 읽다가 눌러 파일이 바뀌지 않게. 복사·위치 복사·터미널로 보내기처럼 파일을 바꾸지 않는 키는 고른 줄이 없으면 현재 줄에 합니다.
- **쓰기를 시작하면 고르기는 끝납니다**: 칸을 열면 고른 줄이 풀립니다. 여러 줄을 고른 채 F2 를 누르면 현재 위치(끝 줄)를 엽니다.
- **넓히고 줄이기**: **Shift+↑·↓** 는 고른 줄의 끝 줄을 위·아래로 옮깁니다 — 처음 줄은 그대로라 넓어지거나 줄어듭니다. 고른 줄이 없으면 현재 줄부터 두 줄을 고릅니다. Insert·Ctrl+L 은 거듭 누르면 아래로 넓히고, 고른 줄이 있을 때 Shift+누르기는 거기까지 넓힙니다. 고른 동안 상태줄에 `고른 줄 3~5행 · 3줄` 이 보입니다.
- **하이라이트는 보기만 합니다**: 켜 있는 동안은 고른 줄의 키, 복사·보내기, 칸 열기가 되지 않고, ↑·↓ 는 화면만 스크롤하고, 우클릭 메뉴에는 끄기만 나옵니다. 고치려면 끄세요.
- **우클릭**: 우클릭한 줄이 현재 줄이 됩니다. 고른 줄 안에서 우클릭하면 그 범위의 선택 상자가 나옵니다 — 그 블록에서만 하는 일(표 복사 등), **Claude로 보내기**, 복사, 담기·보내기, **아래에 넣기…**, **고른 줄 바꾸기…**, 여기서 편집(한 줄일 때), 풀기, 맨 아래 줄 지우기. 고른 줄 밖을 우클릭하면 고르기를 풀고 그 줄의 메뉴가 나옵니다. 메뉴 항목의 설명은 마우스를 올리면 보입니다.

### 새 문서 만들기

- 여는 법: 사이드바 **문서** 머리줄의 **만들기**, **Ctrl+N**, 문서 탭 줄의 **+**, 트리의 문서·폴더·빈 곳을 우클릭한 **새 문서 만들기…**. 처음 위치는 그 폴더이고, Ctrl+N 과 **만들기**는 지금 보는 문서나 폴더 개요의 폴더입니다.
- **제목**이 파일 이름이 됩니다. 처음 값은 '새 문서' 입니다. **스타일**은 최근에 쓴 것이 골라져 있고 ↑·↓ 로 바꿉니다. 종류에서 **Lectern 슬라이드**를 고르면 첫 장의 템플릿을 고릅니다.
- **위치**에서 프로젝트 맨 위나 다른 폴더를 고릅니다. 비어 있는 폴더도 나옵니다. **새 폴더…** 는 고른 위치 안에 폴더를 만들고 그 폴더를 고릅니다. 트리·문서 탭 줄의 우클릭 **새 폴더 만들기…** 도 같습니다. 빈 폴더는 트리에 나오지 않으므로 바로 새 문서 창이 열립니다.
- `# 제목` 한 줄로 만들고 새 문서 탭에서 제목 아래 칸이 열려 바로 씁니다. 번호가 있는 스타일이면 보기 머리글 두 줄을 넣고 첫 머리글을 골라 두니, 치면 번호는 두고 글만 바뀝니다.
- 같은 이름이 없을 때만 만듭니다. 안 되면 까닭이 나오니 제목을 고칩니다. Esc 는 닫기.
- 쓰기 전에 닫아도 파일은 남습니다. 필요 없으면 트리에서 우클릭해 **문서 삭제…** 합니다.

### 한 줄 편집

줄을 화면의 그 자리에서 고칩니다. 현재 줄에서 **F2** 를 누르거나, 본문을 **두 번 누르면** 그 줄이 열립니다 (두 번 누르면 누른 자리에 커서가 놓입니다). 제목은 제목 크기, 목록은 글머리표, 강조글은 박스 안 그대로이고, `#`·`-`·`>`·`1.`·`[ ]` 같은 표시는 잠겨 글만 고칩니다. 굵게·링크 같은 문장 속 서식은 `**굵게**`·`[링크](주소)` 처럼 원문 글자로 보입니다.

- **Enter** 로 원문 파일에 바로 저장하고, **Esc** 는 그만둡니다. 칸 밖을 누르면 고친 것이 있을 때 저장합니다. 저장하면 화면이 다시 그려지고 바뀐 곳이 잠깐 강조됩니다.
- **↑·↓** 는 저장하고 위·아래 줄을 이어서 고칩니다. 글이 화면에서 여러 줄로 꺾여 있으면 먼저 그 안에서 움직이고, 맨 윗줄·맨 아랫줄에서 넘어갑니다. 줄 끝에서 **Shift+→** 는 저장하고 그 줄의 위치를 터미널의 Claude Code 에 넣습니다.
- **표**: 행에서 F2 를 누르거나 칸을 두 번 누르면 칸마다 고칩니다. **Tab**·Shift+Tab 으로 옆 칸 — 행의 끝 칸에서 Tab 은 다음 행 첫 칸, 첫 칸에서 Shift+Tab 은 앞 행 끝 칸이라 표를 줄줄이 채웁니다. ↑·↓ 는 위·아래 행의 같은 칸. 칸 글의 `|` 는 `\|` 로 저장되어 칸이 나뉘지 않습니다.
- 여러 줄로 나눠 쓴 문단은 그 줄만, 코드 블록과 코드 화면은 그 줄을 고칩니다. 그림은 F2 로 원문 줄을 엽니다. 수식·다이어그램·차트는 F2 로 원문을 펼쳐 줄마다 고칩니다. HTML 과 주석은 상태줄의 **원문 줄 보기**로 고칩니다. CSV·텍스트·엑셀 같은 자료 파일은 볼 수만 있습니다.
- 링크·그림·다이어그램·차트·수식은 두 번 눌러도 열리지 않습니다. 세 번 눌러 문단을 고르는 것은 그대로입니다. 낱말을 복사하려면 칸 안에서 다시 두 번 누르세요 — 고친 것 없이 칸 밖을 누르면 저장하지 않고 끝납니다.
- 장 하이라이트 중에 고치면 회색이 걷혀 위아래 글이 그대로 보이고, 끝내면 다시 회색이 됩니다.
- **할 일**: 본문의 체크 칸을 누르면 원문의 `[ ]`·`[x]` 가 바뀌어 바로 저장됩니다. 예제처럼 보기만 하는 프로젝트에서는 바뀌지 않습니다.
- 저장한 뒤 **Ctrl+Z** 를 누르면 그 줄을 고치기 전으로 되돌려 저장합니다. 거듭 누르면 그 앞 것도. 되돌린 것은 **Ctrl+Y** 로 다시 합니다. 되돌리기는 파일마다 따로라 다른 문서를 고친 뒤에도 앞 문서로 돌아가 되돌릴 수 있습니다. 되돌린 뒤 새로 고치면 다시 하기는 없어집니다.

### 줄 더하기·옮기기·지우기

칸에서나 고른 줄에서 줄의 구조를 바꿉니다. 칸에 고친 글이 있으면 먼저 저장하고 바꾸므로 되돌리기는 두 걸음입니다. 되지 않는 것은 그대로 두고 까닭을 알립니다.

- **새 줄**: **Ctrl+Enter** 는 아래에, **Ctrl+Shift+Enter** 는 위에 새 줄을 엽니다. 칸을 열지 않아도 현재 줄에서 같은 키가 되고, 줄을 골랐으면 끝 줄 아래·첫 줄 위에 엽니다. 앞 줄의 형식을 물려받습니다 — 목록은 같은 표시(하위 항목이 있으면 그 뒤에), 번호 목록은 다음 번호, 문단·제목 아래는 문단입니다. 표에서는 새 행, 차트·수식에서는 그 앞뒤 문단입니다. 글을 쓰기 전에는 파일이 바뀌지 않습니다.
- **이어 쓰기**: 마지막 줄에서 **↓** 를 누르면 화살표가 내려가고 새 줄이 열립니다. 아무것도 쓰지 않고 **↑** 를 누르면 새 줄을 걷고 읽기로 돌아옵니다 — 끝까지 내려갔다가 다시 올라갈 때 줄마다 칸이 열리지 않습니다. 새 줄에서 **Enter** 는 저장하고 다음 새 줄을 엽니다. 빈 줄에서 Enter 를 누르면 끝납니다. 있던 줄의 Enter 는 저장하고 닫습니다. 표나 코드 블록이 끝이면 그 뒤에 문단을 엽니다. 각주가 있어도 본문 마지막 줄의 ↓ 는 각주로 내려가지 않고 새 줄을 열며, 새 글은 각주 앞에 들어갑니다.
- **목록 끝내기**: 빈 새 항목에서 **↓** 나 **Shift+Tab** 은 한 레벨 밖으로 나가고, 맨 바깥이면 문단이 되어 목록이 끝납니다. **Tab** 은 윗 항목의 하위로 들어갑니다.
- **나누기·합치기**: 글 가운데서 **Ctrl+Enter** 를 누르면 그 자리에서 두 줄로 나눕니다. 줄 맨 앞에서 **Backspace** 를 누르면 윗줄 끝에 잇습니다 — 문단은 문단끼리, 목록은 목록끼리, 코드는 그 블록 안에서만입니다. 제목과 문단처럼 종류가 다르면 합치지 않습니다.
- **옮기기**: **Alt+↑·↓** 로 줄을 옮깁니다. 목록 항목은 하위 항목과 함께 같은 목록 안에서, 문단은 앞뒤 블록과 맞바꾸고, 여러 줄로 나눠 쓴 문단의 한 줄은 그 문단 안에서, 코드는 그 블록 안에서, 표의 행은 머리행 아래에서 옮깁니다. 옮긴 뒤에도 고른 줄이 따라가 거듭 옮길 수 있습니다. 문서 끝의 각주와 본문은 서로 넘어가지 않습니다.
- **지우기**: 줄을 고르고 **Delete**(또는 우클릭 '줄 지우기'), 칸에서는 **Ctrl+Shift+K** 입니다. **Ctrl+X** 는 원문을 복사하고 지웁니다. 10줄이 넘거나 제목이 들어 있으면 먼저 묻습니다. 지운 뒤 빈 줄이 겹치면 하나로 줄이고, 남는 하위 항목은 지운 항목의 자리로 올립니다.
- 표의 머리행이나 구분 줄만 지우면 표가 깨지므로 막습니다 (표 전체를 고르면 표째 지웁니다). 코드 블록의 일부와 그 밖의 줄을 함께 지우는 것도 막고, 코드 줄을 모두 고르면 블록째 지웁니다.
- **복제**: 칸에서 **Ctrl+Shift+D** 를 누르면 아래에 같은 줄을 만들고 그 줄을 이어서 고칩니다. 표의 행은 복제하지 않습니다.
- 번호 목록은 더하고 옮기고 지울 때 뒤 번호를 다시 매깁니다. 모두 `1.` 로 쓴 목록은 그대로 둡니다. 번호까지 **Ctrl+Z** 한 번으로 돌아옵니다.
- 코드 화면과 슬라이드에서도 됩니다. HTML 문서·자료 파일(CSV·텍스트·엑셀)과 보기만 하는 프로젝트에서는 하지 않습니다.
- UTF-8 이 아닌 파일은 볼 수만 있습니다. EViews 프로그램(`prg`)처럼 Windows 인코딩으로 쓴 파일은 코드 화면과 검색에서 한글이 그대로 보이지만, 한 줄 편집과 편집 모드로는 고치지 않습니다. 글이 모두 영문인 `prg` 는 고칠 수 있고, 한글을 넣으면 파일이 UTF-8 로 바뀌어 EViews 에서 깨지므로 저장하지 않습니다.

### 줄 종류와 제목 수준

표시(`#`, `-`, `>`)는 잠겨 있으니 키와 메뉴로 바꿉니다. 키는 칸이나 고른 줄에서 듣습니다.

- **고른 줄의 한 글자 키**: 줄을 고른 뒤(**Shift+Enter**·**Insert**·Shift+누르기) 글자 하나만 누릅니다 — **1~6** 제목, **0**·**P** 문단, **H** 제목 수준을 차례로(제목 2 → 3 → 1 → 문단), **L**·**-** 목록, **N** 번호 목록, **T** 할 일, **Q** 인용, **C** 강조글(강조글이면 다음 종류 — 참고 → 팁 → 중요 → 경고 → 주의), **B** 글을 통째로 굵게. 같은 키를 다시 누르면 문단으로 돌아갑니다(할 일은 목록으로, B 는 굵게를 풂). 바꾼 뒤에도 고른 채 남아 **Tab** 으로 레벨을 이어 바꿀 수 있습니다. 한/영을 바꾸지 않아도 되고, Lectern 모바일과 같은 키입니다. 줄을 고르지 않고 누르면 먼저 고르라고 알립니다 — 읽다가 잘못 눌러 파일이 바뀌지 않게.
- 칸 안에서는 글자가 들어가므로 **Ctrl+Alt+1~6**(제목)·**Ctrl+Alt+0**(문단)을 씁니다. 고른 줄에서도 됩니다. 우클릭 **이 줄 바꾸기…** 로 목록, 번호 목록, 할 일, 인용, 강조글로도 바꿉니다.
- **Alt+Shift+←·→** 는 레벨을 바꿉니다. 제목은 하위 절까지 함께, 목록은 하위 항목까지 함께 옮깁니다. 목록 줄에서는 **Tab**·**Shift+Tab** 도 같습니다. 제목은 **Tab** 으로 바꾸지 않습니다.
- 여러 줄을 고른 뒤 누르면 한 번에 바꿉니다. 문단 여러 개를 고르고 **L** 을 누르면 목록 하나, **C** 를 누르면 강조글 하나가 됩니다. 메뉴로는 우클릭 **고른 줄 바꾸기…** 입니다 — 창의 각 항목 옆에 그 키가 보입니다.
- **번호가 있는 제목**: 문서가 번호를 쓰면 제목을 더하고 옮기고 지울 때 번호를 다시 맞춥니다. 번호까지 **Ctrl+Z** 한 번으로 돌아오고, 이 문서 안의 절 링크도 함께 고칩니다. 칸에서는 번호가 잠깁니다. `참고문헌`, `부록`, `붙임`, `요약` 같은 절에는 번호를 달지 않습니다.
- **절 다루기**: 제목 한 줄을 고르고 **Alt+↑·↓** 를 누르면 같은 수준의 앞뒤 절과 본문까지 바꿉니다. 제목을 우클릭해 **절 지우기**를 고르면 본문과 하위 절까지 지웁니다. 마지막 절을 옮기거나 지워도 문서 끝의 각주는 그대로 남습니다.

### 구성 요소 넣기

빈 줄에서 **/** 를 누르면 넣기 창이 뜹니다. 글자를 치면 거릅니다 (`표`, `박스`, `주`). 글이 있는 줄에서는 **Ctrl+Shift+/**, 마우스는 우클릭 **여기에 넣기…** 입니다 — 표에서는 표 아래에, 고른 줄에서는 **아래에 넣기…** 로 끝 줄 아래에 넣습니다.

- **글**: 제목, 문단, 목록, 번호 목록, 할 일, 인용. 고른 뒤 글을 쓸 때 파일에 들어갑니다. `## `, `- ` 를 직접 쳐도 됩니다.
- **표**: 크기를 `3x4`(열 x 행)처럼 정합니다. `표 1. 제목` 캡션을 다음 번호로 함께 넣고 '제목'을 골라 두니 바로 칩니다. ↓ 로 표에 들어가 **Tab** 으로 칸을 채웁니다. 마지막 칸의 Tab 과 **Ctrl+Enter** 는 새 행, **Ctrl+Shift+Enter** 는 위에 새 행입니다. 열은 칸을 우클릭해 더하고 지우고 옮기고 맞춥니다.
- **강조글**: 참고, 팁, 중요, 경고, 주의. 빈 새 줄에서 **↓** 를 누르면 박스 밖으로 나갑니다. 우클릭으로 종류를 바꾸고, 풀고, 지웁니다.
- **박스글**: 빈 줄에서 **/** 를 눌러 **박스글**을 고르면 여는 줄, 제목(`박스 1. 제목`), 내용 한 줄, 닫는 줄을 넣고 제목 줄을 엽니다. 이미 쓴 글은 줄을 고른 뒤 우클릭 **박스글로 묶기** 로 감쌉니다 — 제목 줄에 걸치면 묶지 않습니다. 안의 줄은 보통 줄처럼 고치고, 박스글을 더하거나 옮기면 번호와 `[박스 1](#박스-1)` 링크를 함께 고칩니다. 박스글 안에서 우클릭하면 **박스글 풀기**(두 표시 줄만 빼고 글은 그대로)와 **박스글 지우기**가 있습니다. Claude Code 와 나눈 대화를 문서에 남기려면 줄에서(또는 줄을 고른 뒤) 우클릭 **Claude 에 박스글 요청** 을 누릅니다. 터미널에 '지금까지의 대화를 정리해 `@문서 12행` 바로 뒤에 박스글로 넣어 줘'라는 요청 글이 들어가고, Enter 를 누르면 Claude 가 그 자리에 박스글을 씁니다 — 자리는 그 줄이 든 블록의 뒤, 고른 줄이면 끝 줄의 뒤입니다. Lectern 은 요청 글만 넣고 파일은 Claude 가 고칩니다. 요청 글은 보내기 전에 고쳐 쓸 수 있습니다.
- **주**: 글 가운데서 **Ctrl+Alt+F** 를 누르면 그 자리에 표시를 넣고 주 내용을 묻습니다. 본문과 내용을 함께 저장합니다. 주 표시 위에서 누르면 그 주를 고칩니다. 번호는 나온 차례로 저절로 매겨지고 내용은 문서 끝에 모입니다. 표시를 지우면 내용도 지울지 묻습니다.
- **그림**: 프로젝트의 그림 파일을 고릅니다. `그림 1. 제목` 캡션을 함께 넣습니다. 그림을 복사해 **Ctrl+V** 로 붙이거나 끌어 넣으면 문서 옆 `문서이름-그림` 폴더에 PNG 로 저장합니다 (현재 줄 뒤에, 줄을 골랐으면 끝 줄 아래에). 덮어쓰지 않습니다.
- **수식·다이어그램·차트**: 보기를 넣고 화면 옆 패널을 엽니다. 있는 것은 **F2** 로 엽니다. 수식·다이어그램은 줄마다 칸으로 고치고, 값이 문서 안에 있는 차트는 값을 표로 고칩니다. 그린 결과는 그 자리에 보입니다. **Esc** 로 접습니다.
- **출처 줄·표 주**: `자료: `, `주: ` 로 시작하는 줄을 엽니다. 표 바로 아래의 이런 줄은 작은 글자로 보입니다.
- **링크**: **Ctrl+K** 로 프로젝트의 파일을 고르거나 주소를 씁니다. 고른 글이 있으면 그 글에 겁니다.
- **첨부**: 프로젝트의 파일을 고르면 문서 끝(각주 앞)의 `## 붙임` 절에 번호와 링크를 더합니다. 절이 없으면 만듭니다. 파일을 복사하지는 않습니다.
- **부록**: `## 부록 A. 제목` 을 다음 글자로 넣습니다. 본문 번호에 들지 않습니다.
- **상호 참조**: 표·그림의 캡션이나 절을 골라 `[표 3](#표-3)` 같은 링크를 넣습니다. 누르면 그 자리로 갑니다. 문장 가운데서는 **Ctrl+Shift+/** 로 엽니다.
- **본문 인용**: `## 참고문헌`(또는 `## References`) 절의 목록에서 문헌을 골라 `(김영삼, 2026)` 을 넣습니다. 창에 문헌마다 본문에 인용한 수가 나오고, 아직 쓰지 않은 문헌이 몇 개인지 알려 줍니다. APA 같은 서식 맞추기는 Claude 에게 요청합니다.
- **목차·표 목차·그림 목차**: `[목차]` 한 줄을 넣으면 그 자리에 제목 목차가 그려집니다 (문서 제목은 빼고 세 단계까지). 표 목차·그림 목차는 번호가 붙은 캡션을 모읍니다. 인쇄·PDF 를 위한 것이고 오른쪽 목차는 그대로입니다.
- **쪽 나눔**: 화면에는 점선과 '쪽 나눔' 으로, 인쇄에서는 다음 쪽으로 넘어갑니다. 다른 뷰어에서는 보이지 않습니다.

**캡션 번호**: 표·그림 캡션의 번호가 1, 2, 3… 차례대로인 문서에서 표·그림을 넣거나 옮기거나 지우면 번호를 다시 매기고, 그 표를 가리키는 상호 참조 링크도 함께 고칩니다. 같은 저장이라 Ctrl+Z 한 번으로 되돌립니다. 링크가 아닌 '표 3' 같은 글자는 다른 문서를 가리킬 수 있어 고치지 않고 몇 곳인지 알려 줍니다 — Ctrl+F 로 찾아 확인하세요. 캡션 하나의 번호만 손으로 고친 것과 '표 2-1' 처럼 장 번호가 든 캡션은 그대로 둡니다.
- **머리 설정**: 맨 위의 문서 정보를 우클릭해 **문서 정보 고치기**를 고르면 키는 잠그고 값만 고칩니다.

### 서식과 붙여 넣기

- 칸 안에서 **Ctrl+B** 는 굵게, **Ctrl+I** 는 기울임, **Ctrl+\`** 은 코드입니다. 고른 글을 `**`, `*`, `` ` `` 로 감쌉니다.
- 여러 줄을 붙여 넣으면 줄마다 나눠 넣습니다. 목록에서는 항목이 됩니다. 되돌리기 한 번으로 돌아옵니다.
- 엑셀 범위를 붙여 넣으면 표로 넣습니다.

### Claude 와 함께 고칠 때

Claude Code 가 같은 문서를 고치는 동안에도 사람이 고친 것과 Claude 가 고친 것이 서로를 덮지 않습니다.

- **칸에 쓰던 글**은 그사이 파일이 바뀌어도 사라지지 않습니다. 위쪽에 줄이 더해져 줄 번호만 밀렸으면 같은 줄을 찾아 그 자리에 저장합니다. 그 줄 자체가 바뀌었거나 같은 줄이 둘 이상이면 저장하지 않고, 고친 줄을 클립보드에 복사해 둡니다.
- **고른 줄**은 글을 따라갑니다. 위쪽에 줄이 더해져도 같은 글이 고른 줄로 남고, 그 글이 바뀌거나 없어지면 고르기를 풉니다 — 다른 줄을 지우지 않게.
- **되돌리기**: 그사이 파일이 바뀌었으면 Ctrl+Z 는 되돌리지 않고 알립니다. 남이 고친 것을 덮어쓰지 않게.
- 화면은 1초 안에 다시 그려지고 보던 자리는 그대로입니다 ('자동 새로고침').

### 원문 줄 보기

상태줄의 **원문 줄 보기**는 md 문서를 줄 번호와 함께 코드 화면으로 봅니다. 빈 줄, 주석, HTML 까지 모든 줄을 칸으로 고칩니다. **md 문서로 보기**로 돌아옵니다.

### md 문서 스타일

상태줄의 **md 문서 스타일**이나 우클릭 메뉴에서 엽니다. **문서 방식**과 **머리글 모양**을 고릅니다.

- **문서 방식**은 본문을 쓰는 방식입니다. 서술식은 문장으로 쓰고, 개조식은 짧은 항목으로 씁니다. 지금 방식은 본문을 보고 알려 줍니다.
- **머리글 모양**은 번호와 기호입니다. 고르면 미리보기가 나오고, 적용하면 md 파일의 제목 줄이 실제로 바뀝니다.

| 문서 방식 | 머리글 모양 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|---|
| 서술식 | 번호 없음 (기고문·칼럼) | 개요 | 시장 현황 | 가격 |
| 서술식 | 논문형 (인문·사회 논문) | Ⅰ. 개요 | 1. 시장 현황 | 1) 가격 |
| 서술식 | 숫자형 (이공계 논문·기술 문서) | 1. 개요 | 1.1 시장 현황 | 1.1.1 가격 |
| 서술식 | 장·절형 (학위 논문·단행본) | 제1장 개요 | 제1절 시장 현황 | 1. 가격 |
| 서술식 | 규정형 (규정·지침) | 제1장 개요 | 제1조 시장 현황 | ① 가격 |
| 개조식 | 보고서형 (보고서) | Ⅰ. 개요 | 1. 시장 현황 | 가. 가격 |
| 개조식 | 숫자형 (기획안·계획서) | 1. 개요 | 1.1 시장 현황 | 1.1.1 가격 |
| 개조식 | 기호형 (공문·요약) | □ 개요 | ○ 시장 현황 | - 가격 |
| 개조식 | 번호 없음 (회의록·메모) | 개요 | 시장 현황 | 가격 |

- 같은 방식 안의 머리글 모양은 바로 바뀝니다. Ctrl+Z 로 되돌립니다.
- **문서 방식을 바꾸면 꼭 묻습니다.** 머리글은 앱이 바꾸지만 본문은 내용을 판단해야 하기 때문입니다. **머리글을 바꾸고 본문은 Claude 에게 요청**을 고르면 터미널에 요청 글이 들어가고 Enter 는 직접 누릅니다. **머리글만 바꾸기**를 고르면 본문은 그대로이니 방식은 바뀌지 않습니다.
- 문서 제목(`#` 하나)에는 번호를 달지 않습니다. 본문과 코드 블록은 그대로입니다.
- 이미 붙은 번호는 떼고 새로 매깁니다. `2026년 전망` 같은 제목의 숫자는 번호로 보지 않습니다.
- 이 문서 안의 절 링크는 함께 고칩니다. 다른 문서에서 이 절로 오는 링크는 그대로입니다.
- **이 문서를 스타일로 만들기:** 머리글에 번호를 단 문서에서 누르면 그 번호 모양을 **내 스타일**로 저장합니다. 지금 고르고 있는 방식(서술식·개조식)의 스타일이 됩니다. 프로젝트가 아니라 Lectern 전체에서 씁니다. 파일은 `%APPDATA%\Lectern\md-styles` 에 있고, **스타일 폴더 열기**로 열어 지웁니다.
- 번호 모양이 복잡해서 잘 뽑히지 않으면 **Claude 에게 스타일 요청**을 누릅니다. 터미널에 요청 글이 들어가고, 이름을 적어 Enter 를 누르면 Claude 가 문서를 보고 만듭니다.
- 스타일이 많으면 찾기 칸에 이름, 용도(`논문`), 번호 글자를 칩니다. 최근에 쓴 스타일은 맨 위에 모입니다.

### 전체 편집 (편집 모드)

한 줄 편집으로 되지 않는 일 — 여러 곳을 한꺼번에 손보거나 HTML 문서를 고칠 때 — 은 파일 전체를 편집기로 엽니다. 대부분의 일은 위의 한 줄 편집으로 됩니다.

- 여는 법: 탭 막대 오른쪽 끝의 **편집** 버튼(목차·터미널 버튼 왼쪽 — 다시 누르면 닫힘, 켜져 있으면 강조색과 밑줄), 아래 상태줄의 **편집**, 코드 화면 머리줄의 **편집**, 본문 우클릭 **이 문서 편집**·**여기서 편집**(그 블록이나 줄에서), 또는 Ctrl+E. 읽던 곳의 원문이 같은 높이에 오게 열립니다.
- **읽는 위치와 이어집니다**: 편집하는 동안 오른쪽 목차는 커서가 있는 절을 표시합니다 (커서가 화면 밖이면 화면 위쪽의 절). 목차·모아 보기·검색 결과에서 이 파일의 곳을 누르면 편집기가 그 줄로 갑니다. 편집을 닫으면 문서 화면이 편집하던 곳에 있습니다 (접힌 절이면 폅니다). HTML 문서는 제목 단위로 이어집니다.
- 줄 번호와 언어 색이 있고, Ctrl+F 찾기, Ctrl+H 바꾸기, Ctrl+G 줄로 가기, F3·Shift+F3 다음·이전 찾기를 씁니다. Tab 은 빈칸으로 들입니다.
- **Ctrl+S** 로 저장합니다. 원래 파일의 줄바꿈(CRLF/LF — 섞여 있으면 많은 쪽)과 BOM, 파일 속성은 그대로 둡니다. 읽기 전용 파일은 저장하지 않습니다. 저장하면 아래의 문서 화면이 고친 내용으로 다시 그려지고, Esc(또는 ✕·Ctrl+E)로 닫으면 보입니다.
- 편집하는 동안 Claude Code 같은 다른 프로그램이 같은 파일을 고쳤으면, 저장할 때 덮어쓸지 묻습니다. 취소하면 저장하지 않고 편집을 이어 갑니다.
- 저장하지 않은 편집이 있으면 편집을 닫거나, 다른 문서로 가거나, 탭이나 창을 닫기 전에 묻습니다.
- UTF-8 글 파일만, 2MB 까지 고칩니다. 새로 만드는 것은 새 Markdown 문서뿐이고(위 '새 문서 만들기'), 파일 이름은 사이드바에서 바꿉니다(위 '파일'). 자료(PDF·엑셀 등)는 편집하지 않습니다.
- 설정의 **전체 편집 방식**을 **vi 방식**으로 고르면 편집기를 vim 처럼 씁니다. Esc 는 편집을 닫지 않고 Normal 모드로 가며, `:w` 저장, `:q` 닫기, `:wq`·`:x` 저장하고 닫기입니다. 닫기는 Ctrl+E 와 ✕ 도 됩니다. 기본은 **기본 방식**이고, 읽는 화면의 vi 키(아래)와 따로 고릅니다. 한글 입력 상태에서는 Normal 모드 키가 글자로 들어갈 수 있으니 영어 입력으로 씁니다.

### vi 키

설정 창(Ctrl+,)에서 **vi 키**를 켜면 문서에서 글자 키로 움직이고 고칩니다. 기본은 꺼져 있고, 켜면 상태줄에 `vi` 가 보입니다. 줄의 상태가 vi 의 모드와 맞습니다 — 현재 줄은 Normal, 고른 줄은 Visual(V), 칸은 Insert 입니다. 마우스와 기본 키는 그대로 씁니다.

- **움직이기**: `j`·`k` 아래·위 줄, `gg`·`G` 첫 줄·끝 줄, `[[`·`]]` 앞·뒤 제목, `zz` 현재 줄을 가운데로. 앞에 숫자를 치면 그만큼 (`3j`, `12G` 는 12행).
- **접기·찾기**: `zc`·`zo`·`za` 절 접기·펴기·바꾸기, `zM`·`zR` 모두 접기·펴기, `/` 찾기, `n`·`N` 다음·이전, `:` 줄로 가기.
- **쓰기**: `i`·`a` 칸 열기 (커서는 줄 처음·끝), `o`·`O` 아래·위에 새 줄. 칸에서 **Esc** 는 저장하고 나옵니다 (vi 키를 끄면 Esc 는 그만두기).
- **고르고 바꾸기**: `V` 로 현재 줄을 고르고 `j`·`k` 로 넓힙니다. 고른 줄에서 `d` 지우기, `y` 원문 복사, `>`·`<` 레벨, `J` 한 줄로 합치기, `V`·Esc 풀기.
- **한 번에**: `dd` 줄 지우기, `yy` 원문 복사, `>>`·`<<` 레벨 — 그 줄을 고르고 하는 것과 같습니다. 지우거나 복사한 줄은 `p`·`P` 로 현재 줄 아래·위에 넣습니다 (앱 안에 담아 둔 것이라 클립보드와 따로입니다). `u` 되돌리기, 다시 하기는 Ctrl+Y.
- 두 글자 명령은 1초 안에 다음 글자를 칩니다. 그동안 상태줄에 `vi d…` 처럼 보입니다.
- Ctrl 이 붙은 키는 바꾸지 않습니다 (Ctrl+D 는 여전히 장 복제, Ctrl+F 는 찾기). 쪽 넘기기는 PageUp·PageDown 입니다.
- 한/영 상태와 관계없이 듣습니다.
- 전체 편집기는 따로 고릅니다 — 설정의 **전체 편집 방식**(위 '전체 편집').
- 예제 — [10 vi 키](../../samples/guide/10-vi-키.md): 해 보기와 기본 키와 나란히 본 표, 전체 편집기의 vi 방식.

## Lectern 슬라이드

예제 — [09 Lectern 슬라이드](../../samples/guide/09-Lectern-슬라이드.md)(이 장의 내용을 md 문서로 자세히 적은 안내)와 [슬라이드 예제](../../samples/slides/README.md)(기초·상황별·복잡한 배치).

Lectern 은 세 가지를 구분합니다.

| 말 | 무엇 |
|---|---|
| **md 문서** | 보통 Markdown 문서입니다 |
| **Lectern 슬라이드** | 맨 앞 설정에 `marp: true` 가 있는 md 입니다. 장마다 배치가 다른 슬라이드로 보입니다. 왼쪽 목록에서 주황색 아이콘으로 나옵니다 |
| **pptx** | PowerPoint 파일입니다 |

작업은 이 순서로 합니다.

1. **새로 만들기**에서 템플릿을 골라 첫 장을 만듭니다.
2. 자리의 안내 글을 내용으로 바꾸고, **Ctrl+M** 으로 다음 장의 템플릿을 고르며 이어 갑니다.
3. 발표하거나, pptx 스타일을 골라 **pptx 로 전환**합니다.

### 만들기

- **새 문서 만들기**(Ctrl+N)에서 제목을 쓰고 종류를 **Lectern 슬라이드**로 고릅니다. 템플릿 갤러리에서 첫 장을 고르면 문서가 만들어집니다.
- 있는 md 문서는 사이드바에서 우클릭해 **Lectern 슬라이드로 바꾸기 요청**을 고릅니다. 터미널에 요청 글이 들어가고, Enter 를 누르면 Claude 가 같은 폴더에 새 파일로 만듭니다.
- pptx 를 Lectern 슬라이드로 옮기는 일은 [Claude 에게 시키기](#claude-에게-시키기)에 있습니다.

### 템플릿

템플릿은 제목, 글, 강조글, 차트 자리를 갖춘 장의 뼈대입니다. 프로젝트가 아니라 Lectern 전체에서 함께 씁니다. Lectern 슬라이드 파일 하나가 **묶음**이고 그 안의 장 하나가 템플릿입니다.

- **갤러리:** 템플릿을 미리 보며 고릅니다. 왼쪽에서 묶음을 고르고(PageUp·PageDown), 누르거나, 번호를 치거나, 화살표로 옮겨 Enter 를 누릅니다. 번호는 묶음 안의 장 차례입니다. 글자를 치면 모든 묶음에서 찾습니다. 최근에 쓴 템플릿은 **최근 쓴 것**에 모입니다. 기본 묶음에 템플릿 12개가 들어 있습니다.
- **새 장:** **Ctrl+M** 을 누르면 갤러리가 뜨고, 고른 템플릿이 지금 장 뒤에 들어갑니다. 제목이 바로 열립니다.
- **템플릿 바꾸기:** 장을 우클릭해 **템플릿 바꾸기…** 를 고릅니다. 쓴 글은 새 칸으로 옮겨 담고, 못 담는 글은 맨 아래 칸에 남습니다. 고치지 않은 안내 글은 옮기지 않습니다. Ctrl+Z 로 되돌립니다.
- **내 템플릿 만들기:** 장을 우클릭해 **이 장을 템플릿으로 저장…** 을 고르고 이름을 적습니다. **내 템플릿** 묶음에 더해집니다. 장의 글이 그대로 저장되니 내용은 안내 글로 고쳐 두면 좋습니다.
- **묶음 고치기:** 갤러리의 **템플릿 폴더 열기**를 누르면 템플릿 폴더(`%APPDATA%\Lectern\templates`)가 Lectern 탭으로 열립니다. 묶음을 평소처럼 한 줄 편집과 점검으로 고칩니다. 장 차례가 번호이고, 장 이름은 `<!-- template: 이름 -->` 입니다.
- **Claude 에게 요청:** **Claude 에게 템플릿 요청**을 누르면 터미널에 요청 글이 들어갑니다. 원하는 모양을 이어서 적고 Enter 를 누릅니다.
- **묶음 기억:** 내가 만든 묶음으로 시작한 문서는 맨 앞 설정에 `templates: 회사 보고` 가 적혀, 다음 장도 그 묶음이 먼저 열립니다.

그림이 든 장을 템플릿으로 저장하면 그림의 경로도 그대로 저장됩니다. 다른 폴더의 문서에서는 그림을 못 찾을 수 있습니다.

### 글 쓰기와 장 다루기

- 슬라이드 안의 글은 **한 줄 편집**으로 고칩니다. 칸 끝에서 Ctrl+Enter 로 더한 줄도 칸 안에 들어가고, 줄을 옮기거나 지워도 칸과 장은 깨지지 않습니다.
- **안내 글**: 템플릿의 안내 글을 열면 글 전체가 골라져 있어 바로 치면 바뀝니다.
- **넣기**: 칸의 빈 줄에서 **/** 를 누르면 제목, 목록, 강조글, 표, 그림, 차트, 다이어그램, 수식, 코드, 출처 줄, 발표자 노트를 고릅니다. 주, 첨부, 부록, 구분선은 슬라이드에 없습니다.
- **서식과 붙여 넣기**: Ctrl+B·I·K·\`, 여러 줄과 엑셀 범위 붙여 넣기, 표의 행과 열, 강조글 메뉴는 md 문서와 같고 모두 칸 안에 들어갑니다. 그림을 붙여 넣으면 칸에 들어가고 **Ctrl+Shift+>·<** 로 폭을 바꿉니다.
- **원문**: 수식·다이어그램은 **F2** 를 누르면 화면 옆 패널에서 줄마다 고칩니다. 칸의 그림은 그대로 보이고 저장할 때마다 바뀝니다. **Esc** 로 접습니다.
- **차트 값**: 차트에서 **F2** 를 누르면 값이 표로 나옵니다. 칸마다 고치고, **Ctrl+Enter** 로 행을 더하고, **Ctrl+Shift+K** 로 지웁니다. 아래 버튼으로 막대, 선, 영역, 원을 바꿉니다. 값이 다른 파일에 있거나 복잡한 차트는 원문으로 열립니다.
- **표를 차트로**: 표를 우클릭해 **이 표를 차트로**를 고릅니다. 첫 열이 항목, 다음 열들이 값입니다. 이렇게 만든 차트는 pptx 에서 PowerPoint 차트가 되어 거기서도 값을 고칩니다.
- **칸**: 칸의 글을 우클릭해 **칸 꾸밈…**(상자, 강조, 메모 등), **이 칸을 앞으로·뒤로**(글을 맞바꿈), **칸 비우기**를 고릅니다.
- **넘쳤을 때**: 넘친 칸을 우클릭하면 **넘친 줄을 다음 장으로**(같은 배치의 새 장으로 옮김)와 **이 칸 줄이기 요청**(터미널에 요청 글)이 나옵니다. 앱이 저절로 줄이지는 않습니다.
- **발표자 노트**: 우클릭 **발표자 노트 쓰기…**. 장 끝에 주석 한 줄로 들어가고 pptx 의 노트로 갑니다.
- 슬라이드를 우클릭하면 새 장·복제·옮기기·지우기가 있습니다. 키는 Ctrl+M, Ctrl+D, Ctrl+Shift+PageUp·PageDown 입니다. 장 제목 줄의 **Alt+↑·↓** 도 그 장을 옮깁니다. 모두 Ctrl+Z 로 돌아옵니다.
- 오른쪽 목차는 장 목록입니다. 점검할 장은 표시됩니다.
- 슬라이드의 체크 칸을 누르면 원문의 `[ ]`·`[x]` 가 바뀝니다. 발표 중에는 바뀌지 않습니다.
- `<!-- hidden: true -->` 를 쓴 장은 숨긴 장입니다. 화면에 흐리게 나오고 발표와 PDF 에서 빠집니다.

### 칸과 배치

템플릿으로 모자라면 칸을 직접 짭니다.

- `---` 마다 한 장입니다. 크기는 1280×720 입니다.
- `::: a card` 부터 `:::` 까지가 칸입니다. 칸 안에 글·표·차트·그림을 넣습니다.
- `<!-- layout: quad -->` 처럼 배치를 고르거나 `<!-- grid: a a b / c d b -->` 로 직접 그립니다. `::: a at 100 200 300 120` 은 자리를 직접 정합니다.
- 슬라이드를 우클릭해 **배치 넣기…** 를 고르면 그 배치의 빈 칸이 들어갑니다. 칸이 있던 장은 칸 이름만 바뀌고, 칸이 없던 장의 글은 첫 칸으로 들어갑니다. F2 로 글을 채웁니다.
- `<!-- links: a>b, c--d -->` 를 쓰면 칸 사이에 화살표와 선을 긋습니다. 칸의 글은 그대로 고칠 수 있습니다.
- Marp 의 `paginate`·`header`·`footer`·`class: lead`·`invert`·배경색, `![bg right:40%](그림)` 같은 배경 그림과 필터, `style:` 과 `<style scoped>` 의 CSS 를 읽습니다. `theme`(gaia 등)은 읽지 않습니다.

### 글자 크기

- 현재 줄에서 **Ctrl+Shift+>** · **Ctrl+Shift+<** 를 누르면 그 장의 표·강조글·제목 같은 구성 요소가 1pt 커지고 작아집니다. 원문에 `<!-- text: 표 14 -->` 한 줄이 생기고 Ctrl+Z 로 돌아옵니다.
- 크기가 적힌 칸(`::: b 16`)에서는 그 칸의 크기가 바뀝니다. 문서 전체는 맨 앞 설정의 `text: 제목 26, 표 12` 로 정합니다.
- 기본은 제목 30, 소제목 20, 본문 18, 표 14, 강조글 16 입니다. 스타일을 바꿔도 크기는 그대로입니다. 차트와 다이어그램 안의 글자는 칸 크기를 따릅니다.
- 표가 12pt, 본문이 14pt 아래로 내려가면 점검에 나옵니다. 화면에 띄우지 않고 읽는 자료면 맨 앞 설정에 `reading: true` 를 씁니다 (기준 10pt, 12pt).

### 구조 보기와 점검

- 상태줄의 **구조 보기**를 켜면 칸 머리 줄과 지시어·노트 줄이 꼬리표로 나옵니다. 꼬리표에서 F2 나 두 번 누르기로 그 줄을 고칩니다. 칸 꾸밈이나 배치를 이렇게 바꿉니다.
- 넘치면 그림·차트는 칸에 맞춰 줄어듭니다. 글은 줄어들지 않고 잘리며 빨간 점선이 붙습니다.
- 문법 실수도 표시합니다. 칸 이름, 빠뜨린 `:::`, 지시어와 낱말의 오타, 잘못된 격자, 닫지 않은 주석·코드 블록, `---` 바로 위의 글, 풀리지 않은 `**` 입니다.
- 화면에서 재는 것도 있습니다. 바탕과 비슷한 글자, 옆으로 잘린 코드·표, 없는 그림, 그리지 못한 차트입니다. 사진 위의 글은 재지 못하니 눈으로 봅니다.
- 상태줄의 **점검**을 누르면 목록이 나오고, 고르면 그 줄로 갑니다. **목록을 터미널에 붙여 넣기**로 Claude 에게 고쳐 달라고 할 수 있습니다.

### 보기와 발표

- Lectern 슬라이드를 누르면 슬라이드 창이 따로 열립니다. 이미 열려 있으면 그 창이 앞으로 옵니다. 터미널은 메인 창의 것을 씁니다.
- 슬라이드 창의 스타일은 메인 창과 따로 고릅니다. 기본은 **발표** 스타일입니다. 여기서 바꾸는 스타일은 화면에서 보는 모습입니다. pptx 스타일은 바뀌지 않습니다.
- 상태줄의 **발표**(Shift+F5) 나 슬라이드의 ▶ 를 누르면 창 전체에 한 장씩 보입니다. → ← Space·PageDown·PageUp 이나 누르기·휠로 넘기고, **N** 은 발표자 노트, **F** 는 전체 화면, **Esc** 는 끝내기입니다.
- 상태줄의 **문서로 보기**를 누르면 칸을 풀어 보통 문서처럼 이어서 봅니다.
- 슬라이드 창에서 본문 여백을 우클릭해 **PDF로 저장…** 을 고르면 슬라이드 크기의 쪽에 한 장씩, 화면과 같은 색으로 PDF 를 만듭니다 (숨긴 장과 발표자 노트는 빠집니다). **인쇄…** 도 한 장에 한 쪽입니다.

### pptx 로 전환

상태줄의 **pptx 로 전환**을 누르고 pptx 스타일을 고르면 문서 옆에 pptx 파일이 만들어집니다. Claude 나 Python 은 없어도 됩니다.

- **pptx 스타일:** Lectern 전체에서 함께 쓰는 양식입니다. 창의 **보관소 폴더 열기**로 폴더(`%APPDATA%\Lectern\pptx-styles`)를 열어 회사 양식 pptx 를 넣으면 목록에 나옵니다. **Claude 에게 스타일 요청**을 누르고 pptx 경로를 적으면 Claude 가 스타일, 같은 이름의 템플릿 묶음, 미리보기 그림을 함께 만듭니다.
- **짝:** 템플릿 묶음과 이름이 같은 pptx 스타일은 짝입니다. '회사 보고' 묶음으로 만든 문서는 '회사 보고' 스타일을 먼저 고릅니다.
- **기억:** 고른 스타일의 이름은 문서의 맨 앞 설정에 `pptxStyle: 회사보고` 로 적힙니다. 다음에는 그 스타일을 먼저 고릅니다. 문서만 다른 PC 로 옮기면 스타일이 없을 수 있습니다. 그때는 알려 주고 다시 고르게 합니다.
- **기본 스타일:** **기본 스타일로**를 켜고 전환하면 스타일을 정하지 않은 문서에 그 스타일이 쓰입니다.
- **적용 차례:** 이번에 고른 스타일, 문서의 스타일(짝 포함), 원본 pptx, 기본 스타일, Lectern 스타일 순서입니다.
- **양식의 내용:** 양식 pptx 의 장과 그림은 결과에 들어가지 않습니다. 장 제목과 표지 그림도 파일 속성에서 지웁니다. 레이아웃에 있는 로고와 꼬리말은 양식의 일부라서 들어갑니다.
- **결과:** 칸의 자리는 Lectern 슬라이드를 따르고, 색·글꼴·로고·꼬리말은 pptx 스타일을 따릅니다. 글은 글, 표는 표, 차트는 값을 고칠 수 있는 차트, 선은 연결선으로 들어갑니다. 복잡한 차트와 Mermaid 는 그림으로 들어갑니다.
- **pptx 에서 옮겨 온 문서:** 스타일을 고르지 않으면 고치지 않은 장은 원본 장이 그대로 쓰이고, 글만 고친 장은 원본 장에서 그 글만 바뀝니다. 디자인과 애니메이션이 살아 있습니다. 칸이나 배치를 바꾼 장만 새로 만듭니다. 그러려면 `문서-변환기록.json` 과 `.pptx-work` 폴더를 지우지 않습니다.
- 같은 이름의 pptx 가 있으면 덮어쓰지 않고 `보고서 2.pptx` 처럼 새 이름으로 만듭니다.

### html 로 전환

상태줄의 **html 로 전환**을 누르면 문서 옆에 impress.js 발표 html 파일이 만들어집니다. 받은 사람은 브라우저로 열어 발표합니다. 장이 한 캔버스 위에 놓이고 화면이 장 사이를 옮겨 다닙니다.

- **배치:** **격자**는 표지·간지(`lead` 장)에서 줄을 바꾸고, 한 줄이 4장을 넘으면 접습니다. **가로 한 줄**도 고를 수 있습니다. 창의 배치 지도에 장 번호가 그 자리에 보입니다. 맨 앞 설정에 `impress: line` 을 적으면 그것이 처음 값입니다.
- **장의 자리 직접 적기:** 장에 `<!-- impress: x=0 y=2400 rotate=90 scale=2 -->` 를 쓰면 그 장이 그 자리에 놓입니다. 적은 축만 바뀝니다. 슬라이드 창의 모양은 바뀌지 않습니다. **Claude 에게 배치 요청**을 누르면 이야기 흐름에 맞게 자리를 적어 달라는 요청 글이 터미널에 들어갑니다 (Enter 는 누르지 않음).
- **전체 보기:** 켜 두면 맨 끝에 모든 장이 한 화면에 보이는 장이 붙습니다.
- **발표:** → ← Space·PageDown·PageUp 으로 넘기고, **Home**·**End** 는 첫 장·마지막 장입니다. **P** 는 발표자 콘솔(노트·다음 장·시계)을 새 창에 엽니다.
- **파일 하나:** 그림, 스타일, 수식 글꼴, impress.js 가 모두 파일 안에 들어갑니다. 인터넷 없이 열리고 아무 데도 요청하지 않습니다. 메일·메신저로 보내도 됩니다. 인터넷 그림만 주소로 남아 받은 사람의 브라우저가 불러옵니다.
- **넣지 않는 것:** 숨긴 장, 동영상·소리. 프로젝트 안의 다른 문서로 가는 링크는 글로 남습니다. HTML 장에 쓴 `class="step"`·`notes`·`substep` 은 impress 가 장·노트로 읽는 이름이라 결과 파일에서 뗍니다.
- **안전:** 파일 안에서는 impress.js 와 시작 줄만 돌도록 막아 둡니다. 문서에 스크립트가 들어 있어도 받은 사람의 브라우저에서 돌지 않습니다.
- **브라우저로 열기:** 만든 뒤의 **브라우저로 열기**는 이번에 Lectern 이 만든 그 파일만 기본 브라우저로 엽니다.
- **Lectern 에서 열면:** 왼쪽 문서 목록에 html 문서로 나옵니다. Lectern 은 문서의 스크립트를 돌리지 않으므로 장이 위에서 아래로 놓인 문서로 보이고 노트도 보입니다.
- 색·글꼴은 지금 고른 스타일 그대로입니다. 같은 이름의 html 이 있으면 덮어쓰지 않고 `보고서 2.html` 처럼 새 이름으로 만듭니다. md 가 원본이므로 고친 뒤 다시 전환합니다.

### Claude 에게 시키기

예제 — [09 Lectern 슬라이드](../../samples/guide/09-Lectern-슬라이드.md)의 12절 'Claude Code 와 함께': 스킬 설치 순서, 요청 예, 요청 메뉴, 함께 다듬는 차례.

pptx 를 Lectern 슬라이드로 옮기거나 pptx 를 참고해 만드는 일은 Claude Code 스킬이 합니다. 스킬은 Lectern 에 들어 있고, 설치는 사용자가 시킬 때만 합니다. 설정 창의 **PowerPoint 스킬** → **Claude Code용 요청 복사**(또는 옆의 터미널 버튼)로 요청 글을 Claude Code 에 넣으면, Claude 가 무엇을 하는 스킬인지 알려 주고 설치할지 묻습니다.

Lectern 이 Claude 를 실행하지는 않습니다. 터미널의 Claude Code 에게 직접 말합니다. 쓰는 말은 이렇습니다. `@문서.md` 는 트리에서 우클릭한 `@경로 복사`입니다.

**pptx 를 Lectern 슬라이드로**

```text
이 pptx 를 Lectern 슬라이드로 옮겨 줘: D:\자료\보고서.pptx
지금 PowerPoint 에 띄워 둔 발표를 Lectern 슬라이드로 옮겨 줘. 결과는 D:\프로젝트\발표 폴더에 둬.
D:\자료\보고서.pptx 를 일단 빨리 md 로만 뽑아 줘. 다듬는 건 나중에 할게.
```

**pptx 를 참고해서 md 문서를 Lectern 슬라이드로**

```text
D:\양식\회사보고.pptx 를 참고해서 @시장-분석.md 내용을 Lectern 슬라이드로 만들어 줘.
화면에 떠 있는 pptx 를 참고해서 @시장-분석.md 를 Lectern 슬라이드로 만들어 줘.
D:\양식\회사보고.pptx 의 색과 표지만 참고해서 @주간보고.md 를 10장 안으로 Lectern 슬라이드로 만들어 줘. 숫자는 그대로 써.
```

**pptx 스타일과 템플릿 만들기**

```text
D:\양식\회사보고.pptx 로 '회사 보고' pptx 스타일과 템플릿 묶음을 만들어 줘.
지금 PowerPoint 에 띄워 둔 발표를 '회사 보고' pptx 스타일로 등록해 줘.
'회사 보고' 묶음에 표와 강조글이 있는 템플릿을 하나 더 만들어 줘.
```

**Lectern 슬라이드를 pptx 로**

```text
@발표.md 를 스타일을 최대한 유지해서 pptx 로 만들어 줘.
pptx 에서 옮겨 온 @보고서.md 를 고쳤어. 고친 장만 반영해서 다시 pptx 로 만들어 줘.
@발표.md 를 D:\양식\회사보고.pptx 양식으로 pptx 를 만들어 줘.
```

- 옮길 때는 글을 빠뜨리지 않고 장을 그대로 지킵니다. 글이 중심인 장은 칸으로 다시 짜고, 지도처럼 자리가 뜻인 도식은 그림으로 남기며 글은 노트에 둡니다. 애니메이션과 정확한 글꼴은 옮기지 않습니다.
- 원본 pptx 는 고치지 않습니다. 띄워 둔 발표도 저장하거나 닫지 않습니다.
- Python 을 설치하지 않아도 됩니다. 스킬은 프로그램 폴더의 `lectern-skill.exe` 로 실행됩니다.
- PowerPoint 가 없어도 `.pptx` 파일을 옮기고 내보낼 수 있습니다. 띄워 둔 발표, `.ppt`, DRM 파일은 PowerPoint 가 있어야 합니다.
- 암호가 걸린 파일은 먼저 풀어 주세요. DRM 이 걸린 파일은 PowerPoint 로 열어 띄워 두고 옮기세요.

프롬프트 예제를 더 보려면 프로그램 폴더의 `skills\README.md` 를 보세요. Claude 가 읽는 작성 안내는 프로그램 폴더의 `web/help/slides.md` 입니다.

## 코드 읽기

- '코드' 목록에서 파일을 한 번 누르면(또는 Enter) 본문 자리에 줄 번호와 언어 색으로 보입니다. 고치거나 실행하지 않습니다.
- 오른쪽 목차에 클래스·함수·메서드와 `# ---- 그리기 ----` 같은 구분 주석이 나오고, 누르면 그 줄로 갑니다. 설정 파일은 키·섹션이 나옵니다.
- 화면 위 **외부 편집기로 열기**·**전체 복사** 버튼이 있고, 줄을 우클릭하면 이 줄 복사·위치 복사·편집기에서 이 줄 열기가 나옵니다.
- 보고 있는 코드가 바뀌면 2초 안에 다시 그리고 바뀐 줄을 잠깐 표시합니다.
- 문서 속 `src/app.py:42` 같은 경로나 코드 파일 링크를 누르면 그 줄로 갑니다. 뒤로 가기(Alt+←)로 문서에 돌아옵니다.
- 4MB 가 넘거나 글자가 아닌 파일은 편집기로 열라고 알려 줍니다.

### CSV·텍스트 파일

'자료' 목록(최근 변경·검색의 이름·모아 보기도)에서 `csv`·`tsv`·`txt`·`log` 파일을 한 번 누르면 Lectern 에서 봅니다. 두 번 누르면 지금처럼 기본 앱(엑셀·메모장)으로 엽니다. 문서 속 링크나 `data/x.csv:5` 같은 경로도 Lectern 에서 엽니다.

- **텍스트**(`txt`·`log`)는 코드처럼 줄 번호와 함께 보입니다.
- **CSV**(`csv`·`tsv`)는 표로 보입니다. 구분자(쉼표·세미콜론·탭)와 머리행은 저절로 알아보고, 막대의 **첫 줄은 머리행**으로 바꿀 수 있습니다.
- **거르기**: 머리행 아래 칸에 글자를 치면 그것을 포함하는 행만 남습니다. `!글자` 는 빼기, `=글자` 는 같은 것, 숫자는 `>100`·`<=5`·`10..20`. 여러 열을 함께 거르고, **거르기 지우기**로 되돌립니다.
- **정렬**: 머리행을 누르면 오름차순 → 내림차순 → 원래 순서.
- **통계**: 표 위 줄에 열마다 — 숫자 열은 개수·합계·평균·최소·최대·중앙값, 글자 열은 개수·고유값·가장 많은 값. 거르면 남은 행으로 다시 셉니다. 막대의 **통계** 버튼으로 감춥니다.
- 행 번호는 원문의 줄 번호입니다. 행을 우클릭하면 이 줄(원문) 복사·위치 복사가 나옵니다.
- 엑셀이 저장한 CSV(CP949)와 '유니코드 텍스트'(UTF-16)도 읽습니다 (상태줄에 인코딩 표시). 고치는 편집 모드는 UTF-8 파일만 됩니다.
- 2,000행까지 보이고, 그보다 많으면 거르기로 좁힙니다 (개수·통계는 모든 행으로 셉니다).

### 엑셀 파일

'자료' 목록에서 엑셀 파일(`xlsx`·`xlsm`)을 한 번 누르거나, 우클릭해 **새 문서 탭에서 열기**를 고르면 Lectern 에서 봅니다. 두 번 누르면 지금처럼 엑셀로 엽니다.

- CSV 와 같은 표로 보입니다 — 거르기·정렬·통계·첫 줄은 머리행이 그대로 되고, 머리줄 아래 **시트 탭**으로 시트를 바꿉니다 (숨긴 시트는 기울임꼴).
- 열 이름 앞에 엑셀의 열 글자(A·B·C…), 행 번호는 엑셀의 행 번호입니다. 값이 없는 행은 빠집니다.
- 칸에는 엑셀에 보이는 값이 나옵니다 — 자리 쉼표·백분율·날짜·소수 자리 같은 표시 형식을 따르고, 수식 칸은 계산된 값(마우스를 올리면 수식). 색·글꼴·셀 병합 같은 서식은 보이지 않습니다.
- 칸을 우클릭하면 **이 칸 복사**(B3 처럼 이름과 함께)·**이 행 복사**·**위치 복사**(`@data/가격.xlsx '1분기' 시트 3행`). **전체 복사**는 지금 시트를 탭으로 나눈 글로 복사해 엑셀에 붙이면 칸이 나뉩니다. 행을 하이라이트하고 Shift+→ 로 Claude 에 보낼 수도 있습니다.
- 보기만 합니다 — 고치려면 엑셀로 여세요. 옛 형식 `xls`·`xlsb` 는 엑셀로 엽니다. 시트마다 5만 행·100만 칸까지 보이고, 넘으면 막대에 알립니다.

### 표를 차트로 보기

표를 그 자리에서 선·막대 차트로 봅니다. 보기만 하고 문서나 파일은 바뀌지 않습니다.

- **여는 곳**: 문서의 표를 우클릭해 **차트로 보기**, 표의 행을 고른 곳을 우클릭하면 그 행만, CSV·엑셀 화면의 **차트로 보기** 버튼(거른 행 그대로)과 열 머리 우클릭.
- 시간을 저절로 알아봅니다 — `2026`, `2026-03`, `2026.3`, `202603`, `2026M03`, `2026-03-15`, `2026. 3. 15.`, `3/31/2026`, `2026Q1`, `1Q26`, `2026년 1분기`, `2026년 1/4분기`, `2026년 3월`, `Mar-26`, `2026H1`, `FY2026`, `2026E` 등. 최근 것이 위에 있는 표도 오래된 것부터 놓고, 머리행이 시점(`2024 | 2025 | 2026`)이면 행과 열을 저절로 바꿉니다. 시점 앞의 글 열(ECOS 의 항목·단위)은 계열 이름과 단위가 됩니다.
- 단위는 머리행의 괄호(`가격 (USD/t)`)에서, 없으면 표의 캡션(`단위: 천톤`)에서 읽습니다. 레벨과 증가율(`%`, `YoY`, `전년비` 등)이 섞이면 양쪽 축으로 나누고 **레벨·증가율·둘 다** 로 고릅니다. 축은 둘까지입니다.
- 빈칸, `-`, `n.a.`, `x`, `#DIV/0!` 는 0 이 아니라 끊긴 곳입니다. `(1,234)` 와 `△3.5` 는 음수이고, `1,234p` 의 잠정 표시는 뗍니다. `▲` 는 뜻이 갈려 숫자로 읽지 않습니다.
- 시간 축이 아니면 `합계`·`평균` 행은 차트에서 뺍니다 (막대의 눈금을 뭉갭니다). 뺀 것은 위에 알려 줍니다.
- **자동** 은 레벨을 막대로, 비율을 선으로 그립니다 (점이 36개를 넘으면 레벨도 선). **선**·**막대** 로 바꾸고, 왼쪽 목록에서 계열을 켜고 끕니다. 처음에는 6개까지 켜 둡니다.
- 어림이 틀리면 **행↔열** 과 계열 고르기로 바로잡습니다. 마우스를 올리면 값이 보이고, 점이 많으면 아래 막대로 확대합니다. **Esc** 로 닫습니다.

### 데이터 분석 (CSV·엑셀)

- **요약 줄**: 표 위에 `월별 · 2015-01 ~ 2026-09 · 숫자 열 6 · 빈칸 2` 처럼 나옵니다. 거르면 남은 행으로 다시 셉니다.
- **계산 열**: 숫자 열 머리를 우클릭해 전기 대비 %, 전년 동기 대비 %(월은 12, 분기는 4를 뺍니다), 차분, 누적, 이동평균, 첫 값=100 지수를 더합니다. 색이 다르고, 거르기·정렬·통계·차트가 그대로 됩니다.
- 계산 열은 화면에만 있습니다. 파일에는 쓰지 않고, 파일이 바뀌어 다시 그려도 남지만 파일을 다시 열면 없습니다. 머리의 **×** 로 뺍니다.
- 계산은 거른 행으로 합니다. 품목별로 쌓은 표는 같은 시점이 여러 행이라 그대로는 계산하지 않고 알려 주니, 품목으로 거른 뒤 계산하면 그 품목의 시계열이 됩니다. 빠진 달이 있으면 그 뒤 달의 전기 대비는 비어 있습니다.
- **보이는 표 복사**: 거른 행과 계산 열까지 복사합니다 (엑셀에 붙이면 칸이 나뉩니다). **문서로 보내기…** 는 Markdown 표로 다른 문서에 넣습니다 (500행까지).

### 여러 표가 든 시트

엑셀에서 온 표는 위에 제목 줄이 있거나, 머리행이 여러 줄이거나, 한 시트에 표가 여럿인 경우가 많습니다. 그런 시트는 표로 나눠 가장 큰 표를 보이고, 위에 단추가 나옵니다. 깔끔한 시트에는 단추가 없고 전과 같습니다. CSV 도 같습니다.

- **표 1**·**표 2** 단추로 표를 고르고, **시트 전체**(CSV 는 **파일 전체**)로 받은 그대로를 봅니다. 행 번호는 원래 번호 그대로입니다.
- 빈 행·빈 열로 표를 나눕니다. 표 안의 간격용 빈 열과 몸통 사이의 빈 줄은 같은 표로 봅니다.
- 표 위의 한 칸짜리 줄은 제목입니다 (`단위: 천톤` 은 차트의 단위로). 표 아래의 `자료:`·`주:` 줄은 표에서 뺍니다.
- 숫자가 시작되는 행 위가 머리행입니다. 여러 줄이면 `수입 · 구리` 처럼 합칩니다 — 병합 칸은 병합한 범위까지 왼쪽 값을 씁니다.
- 어림이 틀리면 **머리행 − · +** 로 줄 수를 고치거나, 시트 전체에서 행을 골라 우클릭 **이 범위를 표로** 를 고릅니다.
- 고른 표와 머리행 줄 수는 앱을 끌 때까지 기억합니다. 파일은 바꾸지 않습니다.

## 링크와 파일 열기

| 링크 대상 | 열리는 곳 |
|---|---|
| 트리에 보이는 md·html 문서 | Lectern 안 |
| 코드 파일 | 코드 읽기 화면 (`#L42` 를 붙이면 그 줄) |
| 그림·PDF·오피스 파일 | 기본 앱 |
| 그 밖의 글 파일 | 편집기 (편집기가 없으면 탐색기에서 선택) |
| 웹 주소 | 기본 브라우저 |
| 프로젝트 폴더 밖 | 열리지 않음 (취소선으로 표시) |

실행 파일과 스크립트는 어디에서도 실행하지 않습니다. 문서 속 절대경로(`C:\...\chart.png`)도 프로젝트 안을 가리키면 열립니다.

## 우클릭 메뉴와 복사

- 본문을 우클릭하면 그 제목·단락·표·그림에 테두리가 생기고 복사 메뉴가 나옵니다.
- 텍스트·Markdown 원문 복사, 제목은 절 전체와 절 링크, 표는 엑셀·워드에 붙일 수 있는 모양으로, 그림은 PNG 로 복사합니다.
- **위치 복사**는 `@docs/보고서.md 40~52행` 처럼 복사됩니다. Claude Code 프롬프트에 붙이면 그 부분을 짚어 줄 수 있습니다.
- 글을 끌어 고른 채 우클릭하면 '고른 글 복사'와 '고른 글 담기'가 맨 위에 나옵니다.
- 메뉴는 어디서나 같은 차례입니다: 그 대상에서만 하는 일 → Claude → 복사 → 담기·보내기 → 편집·열기 → 보기 → 지우기. 오른쪽에는 단축키만 보이고, 설명은 마우스를 올리면 보입니다.
- 키보드로는 **Shift+F10** 이 초점이 있는 곳이나 현재 줄의 메뉴를 엽니다.
- 블록·제목 메뉴의 **담기**·**문서로 보내기…**는 그 조각을 문서 탭에 열린 문서나 새 문서로 보냅니다 (위 '담기').
- 복사 항목 오른쪽의 **터미널 버튼**을 누르면 같은 글이 터미널에 들어갑니다 (Enter 는 누르지 않음). 고른 글·위치·원문·코드·`@경로`·전체 경로 등에 있고, 트리·'코드'·'자료' 목록의 우클릭 메뉴에도 있습니다. 자세한 것은 아래 '터미널'.

## 메모

프로젝트마다 메모를 둡니다. 탭 막대의 **메모** 버튼이나 **Alt+M** 으로 오른쪽 패널을 열고 닫습니다 (Esc 로도 닫습니다). 문서 위를 덮으므로 문서를 보면서 쓸 수 있습니다.

- **새 메모**를 누르고 쓰면 저절로 저장됩니다. 제목·색·고정을 줄 수 있고, 고정한 메모는 맨 위에 옵니다. 위 칸에 글자를 적으면 맞는 메모만 보입니다.
- **할 일로**를 누르면 줄마다 체크 칸이 생깁니다. 끝낸 항목은 아래로 내려가고, 맨 아래 칸에서 항목을 더합니다. 본문에 `- [ ] 할 일` 로 적어도 됩니다.
- **복사**는 Markdown 글로, **터미널**은 터미널에 붙여 넣기로 (Enter 는 누르지 않음), **문서로**는 문서 탭의 문서나 새 문서로 보냅니다.
- **지우기**를 누르면 위에 **되돌리기**가 잠깐 나옵니다.
- 문서를 우클릭해 **새 메모로 보내기**를 고르면 그 글이 메모가 되고, 어디서 왔는지(`@경로 12~20행`)가 아래에 붙습니다. 누르면 그 자리로 갑니다.
- 메모는 프로젝트 폴더의 `.lectern/notes.md` 하나에 Markdown 으로 저장합니다. 메모를 처음 쓸 때 만들고, 트리와 검색에는 나오지 않습니다. 폴더를 옮기면 메모도 따라가고, Claude Code 에 `@.lectern/notes.md` 로 읽힐 수 있습니다.
- git 으로 관리하는 폴더, 특히 공개 저장소에 메모가 올라가지 않게 하려면 `.gitignore` 에 `.lectern/` 을 적으세요.
- 그사이 다른 곳에서 파일을 고쳤으면 다시 읽어 합칩니다. 예제처럼 보기만 하는 프로젝트에서는 메모를 쓰지 않습니다.

## 업무 관리

폴더마다 맨 위에 `WORK.md` 하나를 두면, Lectern 이 그 폴더를 기억하고 여러 폴더의 상태·마감·할 일·일정을 **업무 현황** 한 곳에 모아 보여 줍니다. Lectern 이 켜져 있는 동안 창 안에 알림도 띄웁니다. WORK.md 는 Claude 없이도 쓰고 고칠 수 있는 보통 Markdown 이고, Claude 가 읽고 써도 됩니다.

예제 — [11 업무 관리](../../samples/guide/11-업무-관리.md): 예제 맨 위의 WORK.md 견본과 따라 하기.

### WORK.md

| 부분 | 쓰는 것 | 업무 현황이 읽나 |
|---|---|---|
| 머리 설정 | `status`(예정·진행·지연위험·막힘·보류·완료·중단), `priority`(상·중·하), `due`(YYYY-MM-DD) | 읽음 — 상태·우선·마감 |
| `# 제목` | 과제 이름 | 읽음 |
| 할 일 | `- [ ] 초안 3장 작성 (11/14)` — 끝의 괄호가 기한 | 읽음 — 체크 칸과 기한 |
| 일정 | `- 2026-11-12 14:00-15:00 팀장 보고`, `- 2026-11-20 종일 워크숍` | 읽음 — 오늘 일정과 알림 |
| 현재 상태·결정·기록·자료 | 자유롭게 | 읽지 않음 |

- 절 이름과 차례는 자유입니다. Lectern 은 머리 설정과 할 일·일정의 줄 모양만 봅니다.
- 연도를 뺀 기한 `(11/14)` 은 오늘에서 가장 가까운 해로 읽습니다. 영어 값(`active`·`done` 등)도 됩니다.
- 날짜는 `2026-11-14` 로 쓰는 것이 기본이고, `2026.11.14`·`2026/11/14`·`2026-11-5` 처럼 써도 읽습니다. 키 이름의 대문자(`Status`)·콜론 앞 빈칸도 됩니다.
- 상태·마감은 머리 설정을 우클릭해 **문서 정보 고치기**로, 할 일은 체크 칸을 눌러, 기록은 한 줄 편집으로 고칩니다.
- 프로젝트로 연 폴더 맨 위의 `WORK.md` 만 봅니다. 하위 폴더의 것은 그 폴더를 따로 열 때 카드가 됩니다.

### 업무 카드 만들기

프로젝트 탭이나 문서 트리의 빈 곳을 우클릭해 **업무 카드 만들기…** 를 고릅니다. 제목(처음엔 폴더 이름)·마감·우선을 정하고 **만들기**를 누르면 기본 틀로 `WORK.md` 를 만들어 엽니다. 이미 있으면 메뉴가 **업무 카드 열기**입니다. 만든 폴더는 업무 폴더 목록에 들어갑니다.

### 업무 현황

툴바의 **업무** 버튼이나 **Alt+W**. 공통 폴더를 탭으로 열고, 그 폴더 개요 맨 위에 보입니다.

- **공통 폴더**: 과제 밖의 일정·할 일을 적는 WORK.md 와 주간·월간 정리를 두는 보통 폴더입니다. 처음 업무 현황을 열 때 고릅니다 (예: `문서\Lectern 업무` — 고르는 창에서 새 폴더를 만들 수 있습니다). 공통 WORK.md 는 업무 현황의 **공통 WORK.md 만들기**로 만듭니다.
- **과제 표**: 기억한 폴더마다 한 줄 — 상태, 과제(제목과 폴더 이름), 우선, 마감(D-n), 안 한 할 일 수, 갱신. 주의할 것(막힘·지연위험, 마감이 지났거나 3일 안, 진행인데 14일 넘게 WORK.md 가 안 바뀜)이 먼저이고, 그다음 진행·예정(마감이 빠른 차례), 보류, 완료·중단(접힘)입니다. 줄을 누르면 그 폴더를 탭으로 열고 WORK.md 를 엽니다.
- **기한 있는 할 일**(지남·오늘·이번 주)과 **오늘 일정**: 공통 WORK.md 의 것은 '공통'으로 표시합니다. 누르면 그 줄로 갑니다.
- **확인할 줄**: 오타나 지운 곳 때문에 읽지 못한 줄을 버리지 않고 모아 보입니다. 누르면 그 WORK.md 의 그 줄로 갑니다. 정해진 값이 아닌 상태(`진핸`), 키 이름 오타(`stauts` — 맞는 키를 알려 줌), 읽지 못한 마감·할 일 기한(`(11/31)`, 괄호 빠짐), 체크 칸 오타(`- []`·`-[ ]`), 없는 날의 일정(`2026-11-31`), 읽지 못한 시각(`25:00`, `14:00-1500` — 시각 없는 일정으로 남김), 내용 없는 일정, 닫는 `---` 가 없는 머리 설정이 그렇습니다. 표의 과제 옆에 '확인할 줄 n'이 붙고, 켤 때의 요약에도 나옵니다.
- **읽지 못한 폴더**: 폴더를 옮겼거나 지웠거나 드라이브가 연결되지 않았으면, 또 WORK.md 가 UTF-8 이 아니거나(옛 메모장의 ANSI 등) 2MB 를 넘으면 여기 나옵니다. **목록에서 빼기**로 뺍니다 (파일은 그대로).
- 공통 폴더를 옮기거나 지우면 업무 현황을 열 때 다시 고르라고 묻습니다. 과제 폴더들의 목록은 그대로입니다.
- 확인할 줄·기한 있는 할 일·오늘 일정은 50개까지 보이고, 나머지는 개수로 알립니다.
- 탭을 닫아도 업무 현황에는 남습니다. Lectern 은 기억한 폴더의 `WORK.md` 한 파일만 읽고, 그 폴더의 다른 파일은 읽지 않습니다.
- WORK.md 가 있는 폴더를 열면 저절로 기억합니다. 열지 않고 더하려면 **폴더 더하기** — 고른 폴더에 WORK.md 가 없으면 열고 만들지 묻습니다. Lectern 프로그램 폴더 안(예제)은 기억하지 않습니다.

### 일정 더하기

업무 현황의 **일정 더하기**나 **Alt+S**. 날짜(오늘·내일·요일 단추), 시각(끝나는 시각, 종일), 내용, 넣을 곳(공통 또는 끝나지 않은 과제)을 정하고 **넣기**를 누릅니다. 고른 WORK.md 의 '일정' 절 끝에 한 줄이 들어갑니다 (절이 없으면 문서 끝에 만듭니다). 넣을 곳은 처음에 지금 보는 프로젝트의 WORK.md 입니다. Enter 로 넣고 Esc 로 그만둡니다.

- 내용이 비었거나 끝나는 시각이 시작보다 앞이면 넣지 않고 까닭을 보입니다. 같은 일정을 두 번 넣는 것은 막지 않습니다.
- 넣은 뒤 오른쪽 아래의 **되돌리기**로 뺍니다. 그 뒤에 파일을 고쳤으면 고친 글을 지키려고 되돌리지 않고 알립니다.
- 창을 연 사이 파일이 바뀌었거나 지워졌으면 넣지 않고 알립니다. 같은 WORK.md 를 편집 모드로 고치는 중이었으면, 편집기에서 저장할 때 바뀐 것을 알리고 묻습니다.
- '일정' 절은 `## 일정` 이나 `### 일정` 제목입니다. `## 일정 (11월)` 처럼 뒤에 괄호·콜론이 붙어도 되고, `# 일정 관리 개선` 같은 과제 제목은 일정 절이 아닙니다.

WORK.md 에서 직접 써도 됩니다 — '일정' 절의 마지막 줄에서 Ctrl+Enter 로 새 줄을 열고 `- 2026-11-14 10:00 팀 회의`. 반복 일정(매주 월)은 아직 없습니다. 날짜마다 한 줄씩 씁니다.

### 알림

Lectern 이 켜져 있는 동안 창 오른쪽 아래에 띄웁니다. 닫을 때까지 남습니다.

| 알림 | 언제 |
|---|---|
| 오늘의 업무 | 켤 때 한 번(날짜가 바뀌면 다시) — 마감 지남·오늘·3일 안, 기한이 지났거나 오늘인 할 일, 오늘 일정, 확인할 줄. 알릴 것이 없으면 띄우지 않습니다 |
| 곧 시작 | 시각이 있는 일정의 10분 전, 한 번 — 이미 시작한 일정은 알리지 않습니다 (절전에서 깨어나도 지난 알림이 몰리지 않음) |
| 오늘 기록 | 17:30 이 지나면 한 번 — 오늘 WORK.md 가 바뀌지 않은 진행 중 과제 |

- Windows 알림이나 알림 영역은 쓰지 않습니다. 창이 가려져 있으면 다시 볼 때 쌓여 있습니다. Lectern 을 끄면 알림도 없습니다.
- 설정 창의 **업무 알림**으로 끕니다. 띄운 알림은 기억해 두지 않아서, 다시 켜면 오늘의 업무가 또 나옵니다.

### Claude 와 함께

WORK.md 는 Claude 가 읽고 써도 같은 규칙으로 돌아갑니다. 설정 창의 **Claude Code 에 Lectern 알려 주기**로 작성 안내를 주면 Claude 가 같은 형식으로 씁니다. 예: "이 폴더의 WORK.md 를 만들어 줘", "회의 메모에서 할 일을 뽑아 WORK.md 에 넣어 줘", "오늘 한 일을 기록 절에 적어 줘".

## 터미널

- 탭 막대 오른쪽 끝의 **터미널** 버튼이나 Ctrl+\` 로 본문 오른쪽에 터미널이 열립니다. 지금 탭의 프로젝트 폴더에서 Windows PowerShell 이 시작되고, 탭마다 셸이 따로입니다.
- **터미널 여러 개**: 머리줄의 **+** 로 같은 프로젝트에 터미널을 더 엽니다 (프로젝트마다 5개까지 — 예를 들어 1번은 Claude Code, 2번은 다른 명령). 문서 아래에 두었으면 머리줄의 [1 PowerShell] [2 PowerShell] 를 눌러 고르고, 오른쪽에 두었으면 아래 '위아래로 쌓기'처럼 모두 보입니다. 화면을 다시 불러와도 돌던 터미널들은 그대로 이어집니다.
- **위아래로 쌓기**: 터미널이 문서 오른쪽에 있을 때 둘 이상이면 탭 대신 위아래로 쌓여 모두 보입니다. 1번이 맨 아래이고 번호가 클수록 위입니다. 높이는 똑같이 나뉘고, 칸 사이 경계를 끌어 바꿉니다 (경계를 두 번 누르면 다시 똑같이, 터미널을 더하거나 닫아도 똑같이). 칸마다 머리줄에 번호·셸 이름·× 가 있고, 칸을 누르면 그 터미널을 고릅니다 (↻ 다시 시작·F6 이 그 터미널에). 터미널이 문서 아래에 있으면 지금처럼 탭입니다.
- **터미널 끝내기**: 다 쓴 터미널은 그 탭의 × (또는 가운데 버튼)로 끝냅니다 — 그 셸과 거기서 띄운 프로그램이 끝나고, 프로그램이 돌고 있으면 먼저 묻습니다. 터미널이 하나뿐이어도 되고, 마지막 터미널을 끝내면 패널이 감춰졌다가 다시 열 때 새 셸로 1번이 시작합니다. 패널이 좁으면 고르지 않은 탭은 이름이 줄고 × 는 마우스를 올릴 때 나옵니다.
- 머리줄 오른쪽 끝의 × (또는 Ctrl+\`)는 패널을 감추기만 합니다 — 셸은 계속 돌아, 다시 열면 이어집니다. 머리줄의 ↻ 는 셸을 새로 시작합니다.
- 터미널 안의 키는 셸로 갑니다. Ctrl+P·Ctrl+F·F1 같은 앱 단축키는 본문을 누른 뒤에 씁니다 (Ctrl+Tab 은 터미널 안에서도 다음 탭).
- **F6**(거꾸로는 Shift+F6)은 문서와 터미널 사이로 초점을 옮깁니다 — 터미널 안에서도 됩니다. 터미널이 닫혀 있으면 열면서 가고, 돌아오면 보던 문서로 (편집 중이면 편집기, 한 줄 편집 중이면 그 칸의 그 자리로 — 칸은 저장하지 않고 그대로 둡니다). 사이드바에 초점이 있으면 문서로 갑니다. 터미널을 연 동안 키가 가는 쪽은 강조색 줄로 보입니다 (터미널은 머리줄, 문서는 문서 탭 줄).
- 글을 끌어 고른 뒤 Ctrl+C 나 우클릭으로 복사하고, Ctrl+V 나 우클릭으로 붙여 넣습니다. 고른 글이 없을 때 Ctrl+C 는 실행 중인 명령을 멈춥니다.
- 경계를 끌어 폭을 바꿉니다 (두 번 누르면 기본 폭).
- **자리**: 창이 가로로 넓으면 문서 오른쪽에, 세로로 길면(세로 모니터, 화면 반쪽에 붙인 창 등) 문서 아래에 열립니다. 아래에 있을 때는 경계를 끌어 높이를 바꿉니다. 터미널 머리줄의 자리 버튼으로 오른쪽·아래를 바꾸면 그 자리로 고정되고, 설정 창의 '터미널 자리'에서 다시 '자동'으로 되돌립니다.
- **터미널에 붙여 넣기**: 우클릭 메뉴에서 복사 항목 오른쪽의 **▣ 터미널** 버튼을 누르면 그 글이 지금 탭의 터미널에 들어가고, '1번 터미널에 넣었습니다'처럼 알림이 뜹니다 (항목 이름 쪽을 누르면 복사만 합니다). 터미널이 닫혀 있으면 열립니다. 터미널이 여럿이면 기본은 맨 앞 터미널(가장 작은 번호 — 보통 처음 연 1번)이고 그 터미널로 바꿔 보이니, Claude Code 는 1번 터미널에서 돌리세요 (다른 번호로 보내는 법은 아래 '번호로 보내기'). Enter 는 누르지 않으니 확인하고 직접 Enter 를 누르세요. 여러 줄이면 먼저 묻습니다 — PowerShell 프롬프트에서는 줄마다 명령으로 실행될 수 있기 때문입니다 (Claude Code 처럼 붙여넣기 모드를 켠 프로그램에는 묻지 않습니다).
- **번호로 보내기**: 다른 터미널에 보내려면 메뉴를 연 뒤 **숫자 키(1~5)를 누른 채** ▣ 터미널이나 'Claude로 보내기'를 누릅니다 — 메뉴 위에 '→ 3번 터미널'이 보입니다. 키보드로는 **Shift+숫자**(초점은 터미널로)·**Ctrl+Shift+숫자**(초점은 문서에)가 현재 줄의 위치를 그 번호의 터미널에 넣습니다. 쌓아 둔 칸은 넣은 터미널의 머리줄이 잠깐 빛납니다. 없는 번호면 넣지 않고 알립니다 (새로 만들지 않습니다). 한 줄 편집 칸과 터미널 안에서 Shift+숫자는 그냥 글자(! @ # …)입니다.
- 터미널 색은 문서 스타일을 따릅니다. 늘 어두운 터미널을 원하면 설정 창에서 '터미널 색을 스타일에 맞춤'을 끕니다.
- 터미널 글자 크기는 설정 창의 '터미널 글자 크기'에서 바꿉니다 (10~24, 기본 14). 열린 터미널과 터미널 모음에도 바로 듣습니다.
- 탭을 닫으면 그 셸도 끝납니다. 셸에서 띄운 프로그램이 돌고 있으면 먼저 묻습니다. Lectern 을 닫으면 모든 셸이 함께 끝납니다.
- **멈춘 프로그램 알림**: 셸에서 띄운 프로그램이 시작하다 멈추면(회사 PC 의 보안 프로그램(DRM 등)이 프로그램 실행을 막을 때 생깁니다 — Claude Code 가 git 을 부르다 아무 입력도 받지 않게 됨) 10초쯤 뒤에 터미널 머리줄 아래에 붉은 띠가 나오고 ↻ 가 강조됩니다. 이런 프로그램은 Ctrl+C 로 끝나지 않고 작업 관리자로도 끝나지 않을 때가 많으니 띠의 **다시 시작**을 누르세요. 셸과 멈춘 프로그램을 끝내고 새 셸을 엽니다. Claude Code 는 새 셸에서 `claude --continue` 로 하던 대화를 이어 갑니다. 보이지 않는 탭의 터미널이면 알림이 한 번 뜹니다.

### 터미널 모음

- 툴바의 **터미널 모음** 버튼이나 Ctrl+Shift+\` 로 열린 프로젝트들의 터미널을 한 화면에 격자로 모아 봅니다.
- 칸 머리에 '실행 중'·'대기'가 보여, 여러 프로젝트에서 돌린 Claude Code 를 한눈에 볼 수 있습니다. 터미널이 여럿인 프로젝트는 칸 머리의 번호(1 2 3)로 칸에 보일 터미널을 고릅니다. 프로그램이 시작하다 멈춘 칸은 '멈춤'이 붉게 보이니 그 칸의 ↻ 를 누릅니다.
- 칸 안에서 Ctrl+Tab 은 다음 칸입니다. 칸 머리를 두 번 누르면 그 칸만 크게 봅니다.
- 칸의 → 버튼은 그 프로젝트로 가서 오른쪽 터미널을 엽니다. 프로젝트 탭을 누르면 문서 화면으로 돌아갑니다.

## Claude Code와 함께 쓰기

예제 — [03 Claude Code 와 함께](../../samples/guide/03-Claude-Code와-함께.md): 터미널, 위치 복사, 바뀐 곳 표시, 코드 읽기.

1. Claude Code 로 작업하는 프로젝트 폴더를 Lectern 으로 열어 둡니다.
2. 터미널(Ctrl+\`)에서 `claude` 를 실행하면 문서를 보면서 바로 옆에서 작업할 수 있습니다.
3. Claude 가 문서를 만들거나 고치면 1초 안에 반영되고, 아직 열어 보지 않은 바뀐 문서에는 트리에 호박색 점이 붙습니다.
4. 문서에 대해 물을 때는 트리에서 문서를 우클릭해 `@경로 복사`를 고르고 프롬프트에 붙여 넣습니다. 예: `@docs/보고서.md 의 결론을 세 줄로 줄여 줘`
5. 문서의 한 부분을 짚을 때는 본문을 우클릭해 **위치 복사**를 고릅니다.
6. Claude Code 가 Lectern 에서 잘 보이는 문서를 쓰게 하려면 설정 창의 **Claude Code 에 Lectern 알려 주기** → **Claude Code용 요청 복사**(옆의 터미널 버튼은 지금 탭의 터미널에 바로)를 Claude Code 에 붙입니다. Claude Code 가 Lectern 의 작성 안내(`web/help/writing.md`)를 읽고 그 프로젝트의 `CLAUDE.md` 에 규칙을 정리합니다. 예제의 `CLAUDE.md` 가 그 본보기입니다.
7. 보고서·검토 의견처럼 사람이 읽을 글을 쓸 때는 설정 창의 **글쓰기 스타일** → **Claude Code용 요청 복사**를 Claude Code 에 붙입니다. Claude Code 의 기본 역할은 개발자라 글이 짧은 나열로 흐르기 쉽습니다. 이 출력 스타일은 Claude 를 리서치 동료·편집자로 바꿉니다 — 읽는 사람과 목적을 먼저 정하고, 폴더 밖의 지난 자료와 웹으로 근거를 넓히고, 문단으로 쓴 뒤 읽는 사람이 되어 다시 읽고 고칩니다. Claude 가 설치할지 먼저 묻고, 설치한 뒤 Claude Code 를 다시 시작해 보고서 폴더에서 `/output-style` 로 **리서치 글쓰기**를 고르면 그 폴더에서만 씁니다 (코드를 쓰는 폴더는 그대로). 실제로 시켜 본 요청과 결과는 예제 [12 보고서와 PDF](../../samples/guide/12-보고서와-PDF.md) 에 있습니다.
8. 요청에 읽는 사람과 목적을 붙이면 글이 달라집니다. 예: "읽는 사람은 구매 담당 임원이고 하반기 가격의 하방 위험을 받아들이게 해야 해. 이 폴더와 지난 보고서를 읽고 웹에서 반대 근거도 찾아 출처를 각주로. 쓰기 전에 개요부터." 다 쓴 뒤 "읽는 사람 입장에서 처음부터 읽고 기계적인 곳을 고쳐 줘" 를 한 번 더 시키면 좋습니다.

## 설정

툴바의 톱니 버튼(Ctrl+,)으로 설정 창을 엽니다.

| 설정 | 하는 일 |
|---|---|
| 언어 · Language | 자동(Windows 표시 언어)·한국어·English. 바꾸면 화면을 다시 불러옴 |
| 스타일 목록 묶기 | 스타일 목록을 용도별·분위기별·밝기별로 묶음 |
| 마지막 위치에서 시작 | 폴더를 열면 마지막에 보던 문서와 위치로 |
| 첫 단계 폴더 펼치기 | 폴더를 열 때 트리의 첫 단계 폴더를 펼쳐 둠 |
| 수식 표시 | `$…$`·`$$…$$`·math 코드 블록을 수식으로 그림 |
| 문단 안의 줄바꿈 보이기 | 원문에서 Enter 로 바꾼 줄이 화면에서도 바뀜 (Word 의 Shift+Enter 처럼). 끄면 표준 Markdown 처럼 이어서 보임 |
| vi 키 | 문서에서 글자 키로 움직이고 고침 (위 'vi 키'). 기본은 꺼짐 |
| 전체 편집 방식 | 기본 방식(Esc 로 닫기)·vi 방식(vim 처럼 — `:w`·`:q`). 기본은 기본 방식 |
| 인터넷 그림 표시 | 문서 속 https 그림을 불러옴. 끄면 링크로만 보임 |
| Claude Code 에 Lectern 알려 주기 | 작성 안내를 읽고 CLAUDE.md 에 정리하라는 요청 글 복사·터미널에 붙여 넣기, 예제 열기 |
| PowerPoint 스킬 | 스킬 설치 요청 글 복사·터미널에 붙여 넣기 ('Claude 에게 시키기' 참고) |
| 내 스타일 | 스타일 폴더 열기, Claude Code용 요청 복사 (위 '내 스타일') |
| 업무 관리 | 공통 폴더 고르기·비우기, 업무 폴더 목록에서 빼기 (위 '업무 관리') |
| 업무 알림 | Lectern 이 켜져 있는 동안 창 안의 업무 알림. 기본은 켜짐 |
| 터미널 자리 | 자동(창이 세로로 길면 문서 아래)·오른쪽·아래 |
| 터미널 색을 스타일에 맞춤 | 끄면 터미널이 늘 어두운 색 |
| 터미널 글자 크기 | 10~24 (기본 14). − · + · 기본 크기 버튼이나 숫자로 |
| 글쓰기 스타일 | Claude Code 의 글쓰기용 출력 스타일 설치 요청 글 복사·터미널에 붙여 넣기 (위 'Claude Code와 함께 쓰기') |
| 인쇄·PDF 글꼴 | 'PDF로 저장…'·'인쇄…' 의 본문 글꼴 — 명조(기본)·고딕 (위 '인쇄·PDF') |

설정 창에 없는 설정은 **설정 파일 열기**를 눌러 편집기에서 고칩니다 (`%APPDATA%\Lectern\config.json`). 저장하면 반영되고, 트리에 영향을 주는 설정은 F5 를 누르면 다시 불러옵니다.

| 키 | 하는 일 |
|---|---|
| `language` | `auto`·`ko`·`en` |
| `editor` | 코드 파일을 열 편집기의 전체 경로. 비워 두면 VS Code(`code`) |
| `exclude_dirs` | 트리에서 뺄 폴더 이름 (예: `["data", "output"]`) — '자료' 목록에는 접혀 나옵니다 |
| `terminal_shell` | 터미널 셸의 전체 경로 (예: PowerShell 7). 비워 두면 Windows PowerShell |

경로의 역슬래시는 `\\` 로 두 번 씁니다. 파일에 문법 오류가 있으면 기본 설정으로 열리고 오류 위치를 알려 줍니다.

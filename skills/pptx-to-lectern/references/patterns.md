# 도식을 칸으로 되살리는 패턴

쪽 맨 앞에 지시어, 그다음 제목, 그다음 칸이다. 글은 초안의 노트 '그림 속 글'에서 그대로 옮긴다.

## 글과 도식이 함께 있는 쪽

글은 칸으로 빼고 도식만 오린다. 쪽 전체를 그림으로 두는 것보다 고칠 수 있는 글이 크게 는다.

```bash
python <이 스킬>/scripts/crop.py .pptx-work/문서이름/ref 13 60 300 1160 380 문서이름-그림/쪽013-도식.png
```

좌표는 `outline.md` 와 같은 쪽 좌표(px)다. 이름은 `쪽NNN` 으로 시작한다. 그래야 변환기록이 알아본다.

```markdown
<!-- grid: t / a / b -->
<!-- rows: auto auto 1fr -->

## 제목

::: a
- 글머리
:::

::: b center text-center
![도식](문서이름-그림/쪽013-도식.png)
:::
```

## 가로 흐름 (단계, 공정, 타임라인)

```markdown
<!-- grid: t t t t / a b c d -->
<!-- links: a>b, b>c, c>d -->

## 제목

::: a card center text-center
1단계
:::

::: b card center text-center
2단계
:::
```

칸이 일곱 개까지는 한 줄에 놓는다. 넘으면 두 줄로 접는다 (`a b c d / e f g .`). 칸 사이 선이 보이려면 칸이 떨어져 있어야 한다. 선의 색과 굵기는 바꿀 수 없고 한 쌍의 칸 사이에는 선이 하나뿐이다. 같은 두 칸 사이에 번호 붙은 화살표가 여럿이면 그림으로 둔다.

## 카드 여럿

```markdown
<!-- grid: t t t / a b c / d e f -->
```

아이콘과 설명은 한 칸에 넣는다. 칸마다 `![w:64](…)`, 소제목(`###`), 글 차례로 쓴다.

## 큰 숫자

```markdown
<!-- grid: t t t / a b c / . d e -->

::: a kpi
**13**
digital solutions
:::
```

## 겹친 원 (벤 다이어그램)

겹침이 뜻을 갖지 않고 나열일 뿐이면 카드 셋으로 쓴다. 겹치는 영역에 글이 있으면 그림으로 둔다.

## 허브와 가지

```markdown
::: hub note at 460 280 300 120
가운데
:::

::: a card at 80 130 260 110
가지
:::

<!-- links: a>hub, b>hub, hub>c -->
```

`at` 칸은 x 56~1224, y 110~660 안에 둔다. 4:3 은 x 56~904 다. 칸끼리 작은 칸의 10% 넘게 겹치면 점검에 나온다.

## 겹친 그림

칸은 겹칠 수 없다. 겹친 그림 여럿(입에 문 열쇠, 맞물린 아이콘)은 쪽 그림에서 그 자리를 오려 그림 하나로 쓴다.

## 쪽이 이어지는 묶음

같은 그림이 쪽마다 조금씩 움직이는 묶음은 쪽마다 같은 `at` 좌표를 쓴다. 쪽을 넘길 때 그림이 튀지 않는다. 애니메이션으로 나타나던 것은 마지막 모습으로 둔다.

## 그림 + 글 나란히

```markdown
<!-- layout: two -->

::: a
글
:::

::: b center
![w:520](문서-그림/image3.png)
:::
```

`w:` 는 칸 폭보다 작게 쓴다. 칸보다 큰 `w:` 는 앱이 높이만 줄여 찌그러진다. 칸을 채우려면 `w:` 를 쓰지 않으면 비율대로 맞춘다. `at` 칸의 그림은 칸 높이를 그림보다 12px 쯤 크게 잡는다.

## 한쪽을 채운 사진

초안이 `![bg left:33%](…)` 로 만들어 둔다. 칸은 남은 폭으로 줄어드니 그대로 둔다. 글이 많아 좁으면 비율을 줄인다 (`right:60%`).

## 표지

`lead` 장의 제목은 칸 없이 크게 나온다. 길면 글자를 줄인다. `<!-- text: 제목 22 -->` 처럼 쓰는데 표지 제목은 이 값의 약 1.45배로 나온다. `lead` 장에서 쓸 수 있는 곳은 16:9 에서 약 1112×592, 4:3 에서 약 792×592 다. 큰 제목과 그림을 한 장에 두면 넘치기 쉬우니 그림을 먼저 줄인다.

## 색

칸의 색은 초안의 `c` 로 시작하는 낱말이다 (`::: a c123abc`). 맨 앞 설정의 `style:` 에 규칙이 있다. 새 색이 필요하면 같은 꼴로 더한다.

```css
.cffd24e { background: #FFD24E; color: #000000; --md-fg: #000000; --md-strong: #000000; --md-heading: #000000; --md-link: #000000; border-radius: 6px; padding: 12px 16px; }
.cffd24e h3 { color: inherit; }
```

- `kpi` 칸의 큰 숫자 색은 낱말에 `.낱말 strong { color: #… }` 를 더해 바꾼다.
- `_color` 는 제목, 본문, 굵은 글, 링크까지 바꾼다. 칸 안의 색은 칸의 낱말을 따른다.
- 인터넷 주소는 저절로 링크가 되어 링크 색이 된다. 바탕과 같은 색이면 안 보인다.

## 글자 크기

칸 머리의 수가 칸 글자 크기다 (`::: a 24`). 원본 크기를 따르되 넘치면 줄인다. 본문 14, 표 12 아래로 내려가야 하면 맨 앞 설정에 `reading: true` 를 쓴다. 이것은 점검의 기준만 12, 10 으로 낮추고 화면의 글자는 바꾸지 않는다.

글 안의 `<u>`·`<sub>`·`<sup>`·`<br>` 은 그냥 써도 된다. 한 줄 편집도 된다.

코드는 줄이 바뀌지 않는다. 14pt 한 줄은 칸 폭 ÷ 11 글자다. 넘치면 칸 크기를 줄인다 (`::: a 12`).

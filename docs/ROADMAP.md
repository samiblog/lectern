# 로드맵

진행 상황과 다음 작업. 작업을 시작하면 해당 항목 아래에 메모를 남기고, 끝나면 `[x]` 로 바꾼다.

## 방향

Markdown을 중심으로 AI와 함께 작업하는 통합 리서치 작업 환경(Integrated Research Work Environment)을 지향한다. 장기 지향점은 마름모형 리서치 방법의 구조화이고 지금은 구현하지 않는다 (`docs/VISION.md`, D87). 새 기능은 어느 단계·구간을 돕는지 적는다.

## 다음 후보

정해진 순서가 아니라 후보다. 새 기능은 `docs/VISION.md` 의 어느 단계를 돕는지 본다.

- 미룬 것: 책갈피, 문서 점검, 템플릿.
- 메모(D92) 첫 판에서 뺀 것: 끌어서 순서 바꾸기, 알림, 라벨.
- 구조: 첫 리서치 기능과 함께 `docmodel`(Markdown 구조 읽기)·`handoff`(Claude 에 넘기기) — 그것만 따로 만들지 않는다. 명령 등록부는 새 명령부터, 큰 모듈은 그 기능을 고칠 때 나눈다.

## 알려진 문제·한계

- Windows 숨김 속성 판정, 폴더 대화상자, 편집기 열기, 창 크기 저장은 자동 테스트가 없어 Windows 실기 점검(2-1)이 필요하다. (정션 제외는 Windows에서 pytest가 확인한다.)
- 트리 제목은 파일 앞 16KB(html 은 64KB)에서만 찾는다. 앞부분이 아주 긴 frontmatter나 코드 블록이면 제목이 파일명으로 나온다.
- 파일을 지우면 열려 있던 문서는 '문서 없음' 화면으로 바뀐다 (의도한 동작).
- 터미널은 Windows 10 1809 이상에서만 된다 (ConPTY). 창을 닫을 때는 셸에서 프로그램이 돌고 있어도 묻지 않고 함께 끝낸다. 셸의 출력은 남기지 않아 앱을 다시 실행하면 새 셸이다 (D38).

# 점검용 프로젝트

화면 점검(`tools/ui_smoke.py`)이 쓰는 프로젝트입니다. 점검이 파일 이름·제목·문장·개수를 그대로 확인하므로, 고치면 점검도 함께 고칩니다. 사용자와 AI 가 보는 예제는 저장소의 `samples/` 입니다 (D57).

| 폴더 | 확인할 것 |
|---|---|
| `docs/` | 표·체크리스트·코드·콜아웃·각주·링크, 수식과 달러 표기, Mermaid, 차트(`06-차트.md` — `docs/data` 의 CSV 는 [차트] 점검 동안만 둔다), HTML 문서(자체 스타일 / 스타일 없음) |
| `research/` | 리서치 문서 형식, 상대경로 이미지 |
| `plans/` | frontmatter, 자연 정렬(2 → 10) |

트리에 **보이면 안 되는** 것도 들어 있습니다.

- `.hidden-note.md`, `.claude/` — 점으로 시작하는 이름
- `node_modules/` — 제외 폴더 ('자료' 목록에만 흐린 접힌 폴더로)
- `empty-folder/` — 문서가 없는 폴더
- `code/` — 문서가 없는 폴더 ('코드' 목록에만). `example.py` 는 `docs/01-기능-점검.md` 의 'example.py 13번째 줄' 링크 대상
- `src/index.html` — 앱 소스 폴더의 html (문서로 보지 않음)

점검을 돌리면 이 폴더를 임시 폴더에 `samples` 라는 이름으로 복사해 엽니다 (점검이 프로젝트 이름 `samples` 를 확인한다).
